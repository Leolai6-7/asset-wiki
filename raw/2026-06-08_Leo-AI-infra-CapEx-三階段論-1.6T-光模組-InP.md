# AI infra CapEx 三階段論

## 高盛預估（anchor 數字）

**Google + Meta + Microsoft + Amazon 四大雲端巨頭，2025-2030 年合計資本支出可能來到 $5.3 兆**

主要全部砸向 AI 資料中心跟基礎建設

## 我認為目前處於第三階段前期（Leo 自提 framework）

| 階段 | 內容 | 受惠主角 |
|---|---|---|
| **第一階段** | 雲廠商開始講 CapEx | CSP（已過）|
| **第二階段** | NVDA 設備跟訂單全面落地 | NVDA / AVGO（已落地）|
| **第三階段** ⭐ | **上游材料跟光通訊開始真正爆掉** | **光通訊 + 上游材料**（**目前位置**）|

## 三階段判斷依據（具體訊號）

### 1. 1.6T 光模組量爆增

- **2025**：~180 萬顆
- **2026**：直接看到 **3000 萬顆以上**
- 差不多是**十幾倍的跳升**
- **NVDA 可能吃掉 60% 以上**
- 剩下才是 Google / Meta / Microsoft / Oracle 在分

**已確認首批採購者**：
- CoreWeave
- Lambda
- Meta
- Microsoft
- Oracle

### 2. InP 供應鏈現在是一起在喊緊（最關鍵）

- **Coherent**：InP delivery 已經拉到**超過 26 週**，還會影響 **15-20% 營收**
- **Lumentum**：直接講**供應限制會到 2026 (全年)**
- **IQE**：甚至**剛融資**然後給 **20%+ 成長**

這三個其實很可怕——因為它們剛好是**從材料到雷射到晶圓整條鏈**同時講一件事

**通常不是巧合，比較像是整條鏈一起到瓶頸了**

### 3. NVDA 自己直接下來鎖供應鏈

- 對 Lumentum 跟 Coherent 投資**超過 40 億美元**
- 同時還在推 **Coherent 擴產翻倍**
- 這種感覺比較像**不是投資、是把供應直接綁起來**

### 4. Broadcom Tomahawk 6 CPO 開始跟 NVDA Spectrum-X 直接對打

- 這時候其實就不是概念市場了
- **是開始搶標準**

### 5. POET / Ayar Labs 這些生態公司也開始加速

- 融資跟商業化都明顯變快
- **整個鏈條是一起動的**

### 6. NVIDIA Spectrum-X 已經進入量產節奏

## 真正台灣鏈條

- **台積電**負責先進製程
- **日月光 / 矽品**負責先進封裝
- **鴻海 / 緯創 / 廣達**負責 AI server 系統落地
- **智邦**負責 AI networking / switch 架構

## ⚠️ 但最後還是要留一個冷靜點

> 現在比較像是 NVIDIA 自用加少數 early adopter 在跑

**真正關鍵還在後面**：
- AWS / Azure / Google 會不會全面跟上
- 那才是**下一段行情的分水嶺**
