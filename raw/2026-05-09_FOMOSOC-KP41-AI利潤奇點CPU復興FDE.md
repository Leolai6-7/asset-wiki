## 主題一：AI 利潤奇點（高盛框架）

### Token 經濟學拐點

| 指標 | 趨勢 |
|---|---|
| Token **售價**年降 | 40%（**趨緩**）|
| Token **成本**年降 | 60-70%（**仍快**）|
| → 邊際毛利擴大 | 2026 起出現「毛利率拐點」|

### Agentic AI 引發的用量爆炸

| 指標 | 數字 |
|---|---|
| Token 用量 2030 年 | **2026 年的 25 倍**（+2,400%）|
| 日查詢數 2025→2030 | 50 億 → **230 億**次 |
| Agent 發出查詢佔比 2030 | **30%** |
| 企業端成長倍數 2030 | **24 倍** |
| 企業端成長倍數 2040 | **55 倍**（巔峰）|

### 自我強化飛輪

```
運算成本 ↓
  ↓
催生更強 Agent
  ↓
基建利用率 ↑
  ↓
利潤 ↑
  ↓
投資優化 ↑
  ↓
運算成本 ↓ (continue)
```

## 主題二：企業買單能力（ROI 量化）

| 應用 | 日均成本 | 對標人力日薪 | ROI |
|---|---|---|---|
| **程式開發 Agent** | $13.39 | ~$300 | ✓ 極佳 |
| **資料輸入 Agent** | $59.68 | ~$80 | ✓ 可行 |
| **客服 Agent** | $92.90 | ~$90 | ✗ 略高 |

**核心洞察**（KP 引高盛）：
> 「AI 的終極價值不是 1:1 替代勞動力來省錢、而是透過釋放『**未滿足需求**』來把餅做大」

### 採用曲線：S 型而非 J 型

| 階段 | 內容 |
|---|---|
| 初期 | 企業需時清理數據、建立數據治理、確認 ROI |
| 中期（2030 前後）| 競爭 FOMO 推動加速採用 |
| 頂部 | **35-40% 滲透率**（非 100%）|

**現況**：70-90% 企業在做 POC、不到 25% 規模化部署。

## 主題五：Forward Deployed Engineer 戰略（OpenAI / Anthropic 學 Palantir）

### FDE 核心
派駐**資深工程師至客戶現場**、親自代碼實現端對端部署，解決系統整合、安全、合規等「**髒活**」。

### 規模化執行

| 公司 | 動作 |
|---|---|
| **OpenAI** | 成立「The Deployment Company」合資企業（估值 **$100 億**、背後私募基金控制數千投資組合公司）|
| **Anthropic + Accenture** | 多年合約、訓練 **3 萬員工**使用 Claude |
| **Anthropic + Blackstone / Goldman / Hellman** | 成立 **$15 億**公司專攻中型企業 |

### 市場含義

- **直接解決企業「試點煉獄」瓶頸**
- 預期 2027-2028 年企業 AI 真實上線數量明顯增加
- 改變 AI 公司收入結構（API + 高價值服務）→ 增強客戶黏性與護城河
- **與 Palantir 在企業 IT 預算上正面交鋒**

## 跟既有 wiki 連結

### 強化 [[Jevons Paradox（投資版）]]
- Token 成本下降 → 用量爆炸 25x → 整體 TAM 不會收斂 = Jevons 在 AI Token 經濟的最強驗證
- 採用 S 曲線 35-40% 巔峰 = 滲透率設天花板、但 TAM 倍數爆炸 → 兩個變數抵消後仍向上

### 強化 [[賣水人選股邏輯（投資版）]]
- 高盛四軸框架對應賣水人選股：
  1. 成本壓制者（半導體）= 算力供應鏈賣水人
  2. 規模與分發（雲端）= 平台層賣水人
  3. **軟體商業模式升級** = Cloudflare / Accenture / 微軟「TAM 擴張型」賣水人 ⭐⭐ 新軸
  4. 採用加速者 = IT 服務 / FDE 模式賣水人

### 強化 [[AI infra CapEx 三階段論]]
- 高盛拐點論證 = 三階段第三階段的「**毛利率拐點**」量化 anchor
- 2026 起出現拐點 → 對應第三階段「上游材料 + 光通訊 + 電力 + 散熱」獲利重估

### 新概念 anchor：**Forward Deployed Engineer（FDE）戰略**
- 是「**AI 應用層的 chokepoint**」
- 跟 [[Palantir]] 戰略 10 年驗證直接對應
- 是 [[資訊擴散四階段]] 第 3-4 階段（從機構轉企業實裝）的關鍵 enabler

### 對應 [[控制點轉移（投資版）]]
- **軟體商業模式「人頭→工作量」**：訂閱費跟產出綁定 = 控制點從 SaaS 廠商轉向白領薪資池
- **FDE 戰略**：AI 公司從「賣 API」升級為「賣垂直 deployment + service」、控制點從 platform 轉向 vertical solution
