## 核心 thesis：五個永久結構轉變

### 1. 油價地板墊高
- 新地板 **USD $80-90 / barrel**（vs 戰前 $65-70）
- 含「風險溢價」premium **$10+**

### 2. Hormuz 海峽保險費重估
- 過運保險費較戰前 **8x**、且**「不太可能回到」**原定價結構

### 3. 伊朗能源產能物理性下降
- Qatar LNG 設施被打、產能 **-17%**
- 修復需要 **3-5 年**

### 4. 核能政治翻身
- 地緣政治敘事轉為「能源安全對沖」
- → 對接 [[AI infra 電力戰場]] 核電 anchor

### 5. 中東能源重組
- UAE 退出 OPEC、Hormuz 周邊「繞路」基礎建設競爭升溫
- 沙烏地紅海港 + UAE 富查伊拉港繞 Hormuz

## LNG 市場結構分析

### 戰前 consensus（錯誤）
- **Oxford Energy** 預測 2027 供給過剩 **260 億立方公尺**
- 市場原預期 supply glut

### 戰後物理影響
- Ras Laffan（Qatar 生產 hub）受損、17% 產能 offline
- Qatar 擴產計畫**因保險費 + 區域風險凍結**
- 2030 前全球累積供給缺口達 **1,200 億立方公尺**

### 為什麼 LNG 是 oligopoly market（高度資本密集）
- 液化廠：**USD $10-30B**
- 專用 LNG 船：**USD $200M+**
- 再氣化終端：再 USD $1-10B
- → **高進入門檻 + 寡占結構**：突發供給衝擊 → 結構性短缺

## 跟既有 wiki 概念連結（推導）

### 補強 [[AI infra 電力戰場]] firm power 第五選擇
- 之前已建：核電（Constellation / Vistra / Talen）+ 氣電（Vistra / CEG Calpine）+ 變壓器（GEV / ABB / Hitachi）+ SOFC（Bloom Energy）
- **第五選擇 LNG 出口 anchor**：Cheniere / Sempra LNG / Cameron LNG 是 hyperscaler 海外資料中心（歐洲 / 日韓 / 新加坡）能源 anchor
- AI 資料中心電力 demand → LNG 出口需求結構性放大

### 對接 [[宋分 #20 — 能源結構性剛需]]
- 宋分 #20 結構性重估三標準：
  - 1. 長期供給結構改變 ✅（戰後 LNG 5 個不可逆 + Qatar 修復 3-5 年）
  - 2. 持續性 CapEx ✅（液化廠 USD $10-30B 高資本密集）
  - 3. 可持續現金流 ✅（LNG 長約 20 年類同 PPA）
- → 三標準全滿，LNG 是「能源結構性剛需」第二個個案（核電已是第一個）

### 對接 [[Bottleneck Theory（瓶頸論）]]
- Hormuz 海峽 = 全球 1/5 石油 / 天然氣供應通道
- 保險費 8x + 不可逆 → chokepoint pricing 結構性 lock-in

### 對接 [[控制點轉移（投資版）]]
- 過去：俄烏戰爭後歐洲被迫向美國買 LNG（美國 LNG 出口 #1）
- 現在：美伊戰爭後亞洲（日韓台中）被迫向美國 / 卡達買 LNG（**Qatar 17% 缺口 → 美國 LNG 出口 anchor**）
- = **美國 LNG 從「價格接受者」變「價格制定者」**

### 對接 [[賣水人選股邏輯（投資版）]]
- LNG 出口 = AI 數據中心海外電力 anchor 賣水人
- 不依賴任何 AI 技術路徑、唯一物理性 anchor
