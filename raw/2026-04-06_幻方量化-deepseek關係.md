# 幻方量化（High-Flyer）與 DeepSeek 的關係

> 整理日期：2026-04-06
> 來源：WebSearch 綜合整理

---

## 幻方量化基本資料

- **全名**：浙江九章資產管理有限公司（品牌名：幻方量化 / High-Flyer）
- **成立**：2015 年
- **創辦人**：梁文鋒（Liang Wenfeng）
- **本業**：量化對沖基金，用數學模型和 AI 做量化投資
- **關鍵基礎設施**：「螢火超算」，萬卡級 GPU 算力

## DeepSeek 的誕生

- **時間**：2023 年 5 月，幻方將 AI 部門拆分獨立成立 DeepSeek
- **定位**：專注通用人工智慧（AGI）和大模型研究
- **首期投資**：自有資金 30 億人民幣（約 4 億美元），不需要外部融資
- **截至 2026 年**：拒絕外部融資的傳聞，包括阿里等潛在投資者

## 商業模式的結構性優勢

### 為什麼 DeepSeek 能免費開源

1. **幻方的本業是量化交易**，不是賣 AI 模型
2. DeepSeek 的模型**反過來服務幻方的量化投資業務**——降低技術成本、提升交易策略
3. 幻方提供算力、資金、數據支持；DeepSeek 維持獨立研發和運營
4. 因此 DeepSeek **不需要靠模型營收活**，可以把前沿模型免費開源

### 對比 OpenAI / Anthropic

| | DeepSeek | OpenAI | Anthropic |
|---|---------|--------|-----------|
| 模型營收依賴 | 不需要 | 核心收入來源 | 核心收入來源 |
| 能否免費開源 | 可以 | 不行（會摧毀自己的營收） | 不行 |
| 資金來源 | 母公司自有資金 | 外部融資 1,220 億 | 外部融資 |
| 定價壓力 | 可以極低定價（$0.28/百萬 token） | 必須維持高定價（$15/百萬 token） | 必須維持高定價 |

### 「開源作為武器」的完美案例

DeepSeek 的開源策略符合「不靠 X 賺錢的公司把 X 免費送出去，壓縮靠 X 賺錢的公司」的模式：
- Google 不靠模型賺錢 → 開源 Gemma → 壓縮付費模型空間
- Netflix 不靠工具賺錢 → 開源 VOID → 壓縮 Runway/Adobe
- 幻方不靠模型賺錢 → 開源 DeepSeek → 壓縮 OpenAI/Anthropic 的 API 定價

## V4 訓練成本

- DeepSeek V3 訓練成本約 520 萬美元（業界同級模型需數億美元）
- V4 使用華為昇騰晶片訓練，進一步降低對 NVIDIA 的依賴
- 極低訓練成本 + 不需要營收回收 = 結構性競爭優勢
