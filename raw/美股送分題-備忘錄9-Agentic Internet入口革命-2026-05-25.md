# 《宋分分析師備忘錄 #9》下一個 20 年的入口革命開始了｜AI Agent、流量重分配與新的 Alpha

## 核心主題

AI 普及將重構網際網路入口——**從搜尋和 App 轉向 Agent 時代**，帶來流量重新分配。
過去的「資訊優勢」將消失，未來 alpha 來自於**問題設計能力、產業理解與市場嗅覺**。

---

## 一、資訊商品化反而創造新 alpha

### 反直覺機制

當資訊被 AI 商品化（人人都能拿到一樣的研究、一樣的數據）：
- 表面看 alpha 消失
- 實際上**新 alpha 浮現**

### 新 alpha 來源

1. **框架完整性**：知道該問什麼問題
2. **產業理解**：能識別 AI 答案的偏誤
3. **市場嗅覺**：能看到 AI 看不到的「人類視角」

### 反向風險

- AI 同質化資訊 → 容易形成**羊群效應**
- 機構間策略趨同 → **擁擠交易**風險擴大
- 短期市場波動性可能上升

→ 「資訊優勢」變成「**問題優勢**」。

## 二、Agentic Internet 改變流量分配（核心 anchor）

### iPhone 時刻類比

iPhone 改變網路入口、催生了：
- Uber（行動入口的服務化）
- TikTok（行動入口的內容化）
- WhatsApp / 微信（行動入口的通訊化）

AI Agent 將從「**資訊入口**」演進為「**交易入口**」、催生下一波相同等級的 winner。

### Google UCP（Universal Commerce Protocol）

- **Universal Commerce Protocol**（通用商務協定）
- Google 推出、象徵電商進入 Agent 時代
- 流量掌握權轉向「**最常替用戶做決定的 AI**」

### 投資意義

- 控制 Agent 入口 = 控制下一個 20 年的流量
- Google / Meta / Amazon / Apple 四家爭 Agent 入口
- OpenAI / Anthropic 也在搶 chokepoint
- 應用層 winner 重新洗牌

## 三、Meta 的隱藏 call option

### 三層 thesis 升級

Meta 從廣告平台轉向 AI 商業入口：
- **商品推薦**：Instagram / WhatsApp 推薦商家
- **交易導流**：Shop on Instagram + WhatsApp Pay
- **workflow 執行**：AI agent 代用戶完成購物

### 估值意義

> Meta 是現階段被低估的基本面 **call option**。

- 市場目前定價 Meta = 廣告公司
- 真正 thesis = AI 商業入口
- 估值差距 = call option 價值

## 四、流動性轉向實體經濟的影響

### Fed 決策影響

| 情境 | 結果 |
|---|---|
| **QE**（過去） | 流動性流向金融資產（股市、債市） |
| **縮表 + 適度通膨**（現在） | 流動性流向實體投資（CapEx、AI infra） |

### 投資意義

- 有獲利、有生產力的公司**有利**
- 無法將 AI 支出轉換為現金流的公司**受罰**
- → 連結 [[AI 變現能見度分歧（證明給我看階段）]]

## 五、四大重點整合

1. 資訊商品化 → 新 alpha 來自問題設計能力
2. Agentic Internet → 流量重分配 + UCP chokepoint
3. Meta call option → 從廣告公司到 AI 商業入口
4. 流動性轉向實體 → 有現金流公司勝出
