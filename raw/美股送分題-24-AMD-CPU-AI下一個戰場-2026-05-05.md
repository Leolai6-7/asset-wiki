# 《市場解碼深度｜AMD：CPU 是 AI 下一個戰場，但市場是不是已經把終局價格提前買完了？》

## 核心主題

透過 AMD 過去兩年案例，教如何判斷「合理重估」與「過度定價」的分界。CPU 在 AI 架構中重要性確實提升，市場已將最樂觀情景定價：估值從 20 倍升至 30 倍屬合理重估，若繼續攀升至 40-50 倍則進入過度定價。

---

## 一、資金流向擴散（GPU → 記憶體 → CPU）

AI 投資鏈條的依序傳導：
- 第一階段：GPU 暴漲（NVDA / AMD）
- 第二階段：記憶體跟漲（HBM iPhone moment）
- **第三階段：CPU 補漲**（AMD、Intel）

CPU 不再是 commodity——是 AI 系統「協調者」（orchestrator）的關鍵節點。GPU 越多越貴，CPU 配比越要拉高才能餵飽。

## 二、結構性重估三要素

AMD 的 CPU 重估邏輯成立於三件事同時改變：

### 1. 定價權出現
- 過去 CPU vs Intel 是價格戰，現在 AMD 在 server CPU（EPYC）拿到 30%+ 市佔 + 對 AI workload 有差異化（EPYC 9005 + Instinct MI300 整合）
- 售價可以漲、不需要折讓

### 2. CPU/GPU 成本比例改變
- 過去 GPU:CPU = 1:8（CPU 便宜、GPU 貴）
- AI server 演進：GPU:CPU = 1:2（高階 CPU 與 GPU 同等重要）
- 單台 server 用更貴的 CPU、單台價值上升

### 3. TAM 暴增
- 從原本 825-1,100 億美元（PC + traditional server）擴張至 3-4.5 兆美元（AI 算力 orchestration）
- 不是漲一倍、是漲三十倍

→ 三件事同時改變才叫「結構性重估」、缺一不可。

## 三、AMD 估值校準

### EPS / PE 動態
- 2026 EPS：6+ 美元
- 2027 EPS：11-13 美元
- 當前 27 倍本益比對應 70-80% 成長率（合理）

### 業務結構轉變
- 資料中心營收比重從 37% → 52%
- Embedded 段營益率最高、Data Center 次之、Client 第三

### 估值區間判斷
- **20-30 倍 PE**：CPU AI 重估合理區間
- **30-40 倍 PE**：開始 stretched、預期完美執行
- **40-50 倍 PE**：定價終局、不容許任何失誤

## 四、過熱警訊三條件

判斷「合理重估」轉「過度定價」的訊號：

1. **成長率停滯但 PE 持續拉高**：基本面與估值脫鉤
2. **敘事變極端**：從「CPU 受益」變「CPU 一統江湖」
3. **市場不容許失誤**：任何小 miss 都引發暴跌

→ 三條同時出現 = 過度定價、開始 trim。

## 五、教學重點

> 最難的不是看對趨勢，是判斷市場何時從「未充分定價」轉向「過度定價」的轉折點。

分析師工作不是抓底、是**判斷邊界**：
- 重估開始前：alpha
- 重估進行中：守
- 過度定價：trim
