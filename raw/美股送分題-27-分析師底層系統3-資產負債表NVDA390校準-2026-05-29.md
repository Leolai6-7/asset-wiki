# 《宋分｜分析師底層系統 #3》90% 散戶只看損益表，真正的分析師都在看資產負債表

## 核心主題

資產負債表才是判斷公司真實健康度的關鍵，散戶只看損益表容易踩雷。
分析師透過追蹤**現金流、應收帳款、存貨、負債**等細項，能提前發現需求真假、成長延續性與潛在風險。

**以 NVDA 為案例**（時點為 $390 股價）。

---

## 一、為什麼資產負債表才是重點

### 損益表的盲點

- 容易做帳：營收可以提前認列、費用可以遞延
- 表面好看但實質爛
- 看不出**現金到底有沒有進來**

### 資產負債表的優勢

- 現金流真實、難造假
- 應收帳款 / 存貨變化揭露需求真實性
- 負債結構揭露公司財務健康

→ 「會做帳的公司也騙不過資產負債表。」

## 二、五大關鍵指標（NVDA 為例 / $390 時點）

### 1. 營運現金流（CFO）

- **YOY 持續強勁成長**
- QOQ 除轉換期外均穩定季增
- → 驗證需求真實、不是訂單堆積

### 2. 融資活動

- 長期為負
- 公司靠本業現金流自給自足
- 股票回購 + 配息達 **$200 億**
- → 不缺錢、不依賴外部融資

### 3. 應收帳款

- 增速**未超越**營收增速
- DSO（應收天數）**未惡化**
- → 收款品質良好、客戶付款健康

### 4. 庫存結構（關鍵）

**健康訊號**：
- **原料 + 在製品上升**（供應追不上需求）
- **成品未失控**（沒堆積）
- 配合 CapEx 維持高檔
- → 呈現「**做不完**」而非「賣不掉」

**警訊（若反過來）**：
- 成品堆積 + 原料下降 = 「賣不掉」
- 庫存失控 = 需求衰退前兆

### 5. 長期負債

- 幾乎無增加
- 負債比僅 **25%**
- 利息保障倍數達 **528 倍**
- → 槓桿極低、抗風險能力強

## 三、額外健康指標

### 股東權益

- 一年內從 $838 億增加至 **$1,954 億**
- 留存收益持續累積
- → 不是「靠新發股集資」、是內生增長

### 合約負債

- 年增 **50%** 至 **$31.17 億**
- 客戶**提前付款**驗證需求強度
- → 「客戶搶交期」的具體量化證據

## 四、判斷邏輯：「變化」而非絕對

> **「變化」比絕對數字重要。**

### 健康組合（NVDA 案例）

```
營收成長 ✓
+ 現金流轉強 ✓
+ 合約負債增加 ✓
+ 毛利改善 ✓
= 真正大成長循環
```

### 危險組合（反面教材）

```
營收成長
+ 應收帳款暴增（強推銷）
+ 庫存堆積（賣不掉）
+ 現金流惡化（錢沒進來）
= 龐氏騙局徵兆
```

## 五、NVDA $390 校準結論

NVDA 資產負債表呈現「**真正的大成長循環**」、而非龐氏騙局：
- 五大指標全部健康
- 合約負債 + 庫存原料結構 揭露「做不完」
- 槓桿極低 + 自由現金流強勁

→ 在這個時點 thesis 校準是：**結構性大成長、不是泡沫**。
