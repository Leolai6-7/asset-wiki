# 《市場解碼 #20｜分析師流程》為什麼有些公司「看起來不賺錢」，卻最容易誕生大牛股？

## 核心觀點

> 「**會計上的「利潤」，從來不等於企業真正的價值創造能力**。」

很多被低估的成長股，最初被誤解是因為他們的**策略投資被當作費用而非資產**。

## Framework：費用化的策略投資 ≠ 真正燒錢

| 案例 | 性質 | 結果 |
|---|---|---|
| Amazon 物流網 | 費用化但建護城河 | 後來爆發 |
| Amazon Prime 補貼 | 費用化但鎖客 | 後來收費 |
| Amazon 早期 AWS | 費用化但建市場 | re-rate 觸發 |
| Netflix 內容庫 | 費用化但建用戶資產 | 訂閱複利 |
| Microsoft license → subscription | 短期表現變差 | 長期估值大爆發 |
| **WeWork** | **真燒錢** | **失敗** |

差別在於：**支出是否創造防禦性（defensibility）**？

## 三條評估準則（不要盲目追高費用公司）

| 準則 | 問什麼 |
|---|---|
| 1. 防禦性 | 支出是否創造 moat / lock-in？ |
| 2. 現金流可預測性 | 投資後現金流會不會更穩？ |
| 3. 規模效率 | 投資能不能複利擴張？ |

三個都符合 → 可能是「**被偽裝成費用的資產**」。

## 6 題 checklist

文末給了「**6 題 checklist**」識別「費用化但實為資產」的公司：
1. 這筆支出是一次性還是持續性的？
2. 是否提升 customer LTV / retention？
3. 是否建立難以複製的競爭優勢？
4. 規模化後 unit economics 會不會改善？
5. 管理層解釋邏輯是否清晰？
6. 同業是否做不到 / 做不起？

（具體實戰可對 hyperscaler / SaaS / 半導體 fab / 衛星 / AI infra 全部測一遍）

## 投資啟示

**Forward PE 看起來貴 ≠ 真的貴**——若大部分「貴」來自「**費用化的策略投資**」，那是估值幻象。
