# Claude 花 4,000 美元找到 22 個 Firefox 漏洞——但這不是你該興奮的原因

Anthropic 跟 Mozilla 合作，讓 Claude Opus 4.6 掃描 Firefox 的程式碼。兩週，掃了近 6,000 個 C++ 檔案，提交了 112 份報告，其中 22 個是確認的安全漏洞——14 個高嚴重性。

第一個漏洞在 20 分鐘內就被找到。那 14 個高嚴重性漏洞，相當於 Firefox 2025 年全年修補的高嚴重性漏洞的近五分之一。

**聽起來像是 AI 資安研究的突破時刻。但如果你只記住「AI 好棒棒能找漏洞」，你就漏掉了這件事真正有趣的地方。**

## 表面是找漏洞，賭注是安全研究的經濟學重寫

用「表面 vs 賭注」的模型看。

**表面上，** 這是 Anthropic 展示 Claude 在資安領域的能力。好的 PR——跟 Mozilla 合作找真漏洞，修了，Firefox 148 已經推送補丁，數億用戶更安全了。

**實際上，** Anthropic 在重新定義安全審計的成本結構。

一個資深資安研究員的年薪大約 15-30 萬美元。Bug bounty 獎金每個漏洞從幾百到幾萬美元不等。一次完整的程式碼安全審計，對 Firefox 這個規模的專案，通常需要團隊花數月、成本六位數。

Claude 用了兩週，成本——花在試圖把漏洞變成可利用攻擊的 API 費用——大約 4,000 美元。而且每個漏洞都附帶最小化測試案例、概念驗證和修補建議。人類研究員做到同樣品質的報告，光寫文件就不只兩週。

但這裡有一個關鍵轉折。

## 能找到，但幾乎不會利用

那 4,000 美元花在嘗試讓 Claude 把漏洞「變成武器」——寫出真正可以攻擊的利用程式碼。結果：在數百次嘗試中，只有 2 次成功。

**Claude 很會找到房子的哪扇窗戶沒鎖。但它幾乎不會爬進去。**

這不是壞消息——對防守方來說，這正是理想的工具。你要的就是一個能大規模掃描弱點但不會自己變成攻擊者的東西。問題是：這個不對稱能力會持續多久？

Claude 找到了傳統模糊測試（fuzzing）抓不到的全新類別的邏輯錯誤。這意味著 AI 的漏洞發現能力已經超越了自動化工具，正在逼近——某些地方甚至超過——人類研究員的水準。如果發現能力持續進步，利用能力遲早會跟上。

## Use After Free：用生活化的方式理解

Claude 找到的第一個漏洞是 Use After Free（UAF）。這是什麼？

想像你退房離開飯店，但飯店系統出錯，沒有把你的房卡註銷。你走了，房間分配給了新客人。但你的房卡還能打開那扇門——你能進去看到新客人的行李、文件、筆電。

在程式碼裡，「你」是一塊已經被釋放的記憶體，「房卡」是還指向那塊記憶體的指標。攻擊者可以利用這個「忘記註銷的房卡」，在程式以為安全的記憶體空間裡塞進惡意程式碼。

Firefox 用 C++ 寫的，C++ 的記憶體管理是手動的——等於飯店讓每個員工自己決定什麼時候註銷房卡。Claude 在兩週內找到了 14 張忘記註銷的房卡。

## 對軟體安全產業的意義

把時間軸拉長，這件事的影響不是「Anthropic PR 很成功」。是兩個結構性變化：

**第一，安全審計從奢侈品變成日用品。** 過去只有大公司和關鍵基礎設施才做得起完整的程式碼安全審計。如果 AI 能把成本壓到幾千美元、時間壓到幾週，中型公司和開源專案也負擔得起。安全會從「有預算才做」變成「不做就是失職」。

**第二，攻防不對稱可能翻轉。** 資安的基本困境是「防守方要堵住所有洞，攻擊方只要找到一個」。如果 AI 能讓防守方以極低成本掃描全部程式碼、找到大部分弱點——而攻擊方暫時還不太會利用這些弱點——防守方有一個短暫的窗口期佔據優勢。

但「短暫」是關鍵字。當利用能力跟上發現能力，攻擊方也會有同樣的 AI 工具。這不是一個永久的優勢，是一場軍備競賽的開場。

**Claude 找到 22 個 Firefox 漏洞不是終點。是 AI 重寫資安攻防經濟學的第一章。**
