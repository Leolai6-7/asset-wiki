# 《為什麼左側價值投資人總是賺不到右側？股票越漲越不敢買？結果當你決定加入右側交易，卻迎來第一根大跌》

## 核心主題

區分兩種投資策略的根本差異——**左側交易**建立於「價格錯了」、**右側交易**建立於「**價值變了**」。

在 AI 等時代級行情中，市場不斷重新計算價值，左側框架失效。

---

## 一、左側 vs 右側的根本差異

### 左側交易

**核心假設**：價格錯了、等待回歸內在價值。

- 看到下跌 → 加碼（because 安全邊際）
- 看到上漲 → 賣出 / 觀望（because 泡沫）
- 心理錨點：**內在價值**

### 右側交易

**核心假設**：**價值變了**、不斷驗證證據增加部位。

- 看到上漲 + 驗證 → 加碼（because 上修確認）
- 看到下跌 + 證據惡化 → 減碼
- 心理錨點：**邊際變化**

### 關鍵差異

| | 左側 | 右側 |
|---|---|---|
| 假設 | 價格錯了 | 價值變了 |
| 操作 | 越跌越買 | 越漲越驗證 |
| 安全感來源 | 低價 | 證據累積 |
| 適合行情 | 週期股、深度價值 | 時代級趨勢、re-rate |

## 二、AI 時代為什麼左側失效

### AI 行情的特殊性

> 在 AI 等時代級行情中，市場**不斷重新計算價值**（從 100 → 200 → 300）。

此時股價上升並非泡沫、而是**「驗證成功後提高部位」**。

### 左側框架的盲點

- 把「每次上修」都當成「泡沫」
- 用過去的內在價值錨定（已過時）
- 心理上不願承認「**我可能看錯了**」

→ 「擅長避開泡沫、卻不一定擅長參與新科技革命、**因為革命剛開始時通常都很貴**」。

## 三、右側交易的機構套路

> 試單 → 驗證 → 確認 → 趨勢延續

| 階段 | 動作 | 目的 |
|---|---|---|
| **試單** | 小部位（5-10%） | 開始追蹤、不錯過 |
| **驗證** | 季度確認 thesis | 證據累積 |
| **確認** | 加碼到核心比例 | 主升段持有 |
| **趨勢延續** | 持續觀察 + trim 點 | 把握主升段 |

→ 在「**不確定**」中參與、用部位管理對沖風險。

## 四、左側投資人的心理難題

### 錯過牛市的真正原因

不只是估值考量、更多是**心理因素**：
- 不願承認「我可能看錯了」
- 不願承認「我錯過了」
- 把所有右側加碼定義為「追高」
- 忽視市場重新評估基本面的合理性

### 價值投資的雙面性

> 「擅長避開泡沫、卻不一定擅長參與新科技革命。」

- 優勢：避免血洗（2000 .com、2008）
- 限制：錯過時代級行情（2014-2024 美股、2024-2026 AI）

## 五、面對「**沒有答案的時候**」做決定

### 兩種安全感來源

| | 左側 | 右側 |
|---|---|---|
| 安全感來源 | 低價、犯錯空間 | 證據累積、驗證 |
| 接受的波動 | 帳面虧損但便宜 | 高位震盪但有 confirmation |

### 沒有絕對對錯

> 兩者都無對錯、**關鍵在於理解自己在交易什麼**、並**接受相應的波動風險**。

### 風險警示

- 左側風險：時代轉換期、價值再也回不來
- 右側風險：證據反轉、賣得不夠快

## 提及標的 / 概念

- 標的：NVDA、PLTR、記憶體、AWS、GPU、HBM
- 概念：AI 行情、估值倍數（PE）、盈利成長（EPS）、升息對估值影響、安全邊際雙面性、機構部位管理

## 核心金句

> 擅長避開泡沫、卻不一定擅長參與新科技革命、因為革命剛開始時通常都很貴。

> 在沒有答案的時候做決定 = 投資的核心難題。

> 左側從低價獲得安全感、右側從證據累積獲得安全感。
