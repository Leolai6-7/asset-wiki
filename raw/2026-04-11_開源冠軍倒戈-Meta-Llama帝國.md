# 開源冠軍倒戈——Meta 的 Llama 帝國為什麼守不住

**類型：** Leo 原創文章（Threads 發布）
**日期：** 2026-04-11
**發布平台：** Threads @haochianlai
**來源：** CNBC, Axios, The Register, TNW, gHacks, Bloomberg

## 核心論點

開源是武器，不是信仰。武器有保質期。保質期長短，看你靠什麼活。

## 分析框架

用「開源作為武器」模型 + 控制點轉移模型分析 Meta 從 Llama 開源到 Muse Spark 閉源的轉向。

## 關鍵數據
- Llama 累計 12 億下載
- Meta $14.3B 收購 Scale AI 49%，挖角 Alexandr Wang
- Muse Spark：完全閉源，私人 API 預覽
- Muse Spark Contemplating 模式：Humanity's Last Exam 58%
- 算力效率：不到 Llama 4 Maverick 十分之一

## 開源可持續性條件表
| 公司 | 開源什麼 | 靠什麼賺錢 | 可持續？ |
|------|---------|-----------|---------|
| Google | Gemma | Cloud + Android | ✅ |
| 幻方量化/DeepSeek | DeepSeek | 量化交易 | ✅ |
| Netflix | VOID | 串流訂閱 | ✅ |
| Anthropic | MCP | API 服務 | ✅ |
| Meta | Llama → Muse Spark 閉源 | 廣告 | ❌ |

## 結論
開源策略的可持續性 = 公司是否有獨立於被開源產品的營收來源。賺的錢離開源產品越遠，武器越耐用。
