## 主題核心 thesis（AI PC 時代）

PC 產業正經歷**結構性轉變**從「模組化」→「**協同設計**」（collaborative hardware-software design）。AI workloads 要求軟硬整合、NVIDIA RTX Spark 平台 = CUDA 作為 Windows 系統的 de facto compute layer、Microsoft 同時把 Windows 定位為 AI agent 的基礎 OS。

### 中心命題
> 「**NVIDIA 變成了所有租客都必須打交道的水電公司**」

## 主題 5：NVDA 記憶體配置

### Vera Rubin NVL72 LPDDR5X 配置
- 減少 ~**50%**（不是 GPU HBM4）
- **戰術決策**：優先快速量產 vs 規格極致
- 供應鏈瓶頸緩解、單櫃 TCO 降低 **USD $800k**

### 三層記憶體架構
| Tier | 角色 | 元件 |
|---|---|---|
| Hot | GPU on-package | **HBM4** |
| Warm | CPU side | **LPDDR5X** |
| Cold | Storage | **SSD（NAND）** |

→ Samsung / SK Hynix / Micron 三家受惠（HBM + LPDDR + NAND 全棧）
