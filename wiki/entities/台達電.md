# 台達電（2308.TW）

## 1. 一句話定位

**全球 AI server PSU 60% 市佔絕對龍頭 + 800V HVDC 共定義者 + 液冷產品 24-25 年從 <1% 衝到 8-11% 雙軌轉型**——多元組合分散（資料中心 40% + 電動車 + 5G + 樓宇自動化 + 工業 + 家電）、跟 [[Vertiv]] / Schneider 在電源 + 散熱 turnkey 同台對打但走 **ODM 友好 + 亞洲供應鏈** 不同路線、跟 NVDA Rubin 2026 H2 量產時序對齊（GB300 NVL72 4RU In-Rack 140kW CDU + 2.4MW/3MW L2L CDU）、[[AI infra 散熱戰場]] **anchor #3**（在 Vertiv / 雙鴻之後）。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] + [[AI infra 電力戰場]] **雙戰場同時受惠的台廠 #1**
  - 2026 液冷滲透率衝 76%（券商估）
  - 800V HVDC 取代 ±400V → 2027 主升段
  - NVDA Rubin 1MW 機櫃 2026 H2 量產
- 跟 [[AI infra CapEx 三階段論]] 第三階段同步：散熱滯後光通訊 1-2 季
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：「**共識**」階段（題材已上頭條、Q1 EPS 7.91 元年增 100% 已 ETF 化）
- 跟 [[資訊擴散四階段]]：機構 → 賣方 → 媒體 → ETF（已 ETF 化，0050 / 0056 / 多檔 AI 主題基金重倉）

### 目的層

- **業務組合**（FY2025 推估）：
  - **資料中心電源 + 散熱**：~40%（2026 Q1 提升、AI server PSU 60% 市佔絕對龍頭）
  - 電動車（EV powertrain + 充電 + IGBT 模組）：~15-20%
  - 工業自動化 + 樓宇 + 能源：~25%
  - 5G / 網通 + 家電 + 視覺：~15%
- **液冷產品營收占比**：
  - 2024 < 1%
  - 2025 全年 **8%**
  - 2025 Q3 一度衝 **11%**
  - 2026 預估持續上升（CDU 2025 Q4 小量出貨 → 2026 主升段）
- **AI 直接曝險**：40%+（資料中心電源 + 散熱）= 比 Vertiv 80% 低、比奇鋐 / 雙鴻 純散熱低、**整合性最強**
- 客戶結構：
  - **NVDA reference architecture 共展廠商**（2026-03 GTC + Data Center World）
  - **ODM 友好**（鴻海 / 廣達 / 緯創 / 美超微 / 緯穎 / 鴻佰）→ 間接餵 NVDA + 直接 hyperscaler
  - **hyperscaler 直接**：Meta / Microsoft / Google 部分直接（規模較 Vertiv 小）
- 商業模式核心：
  - **「**雙軌整合 turnkey**」**：power + cooling + microgrid 一條龍（跟 Vertiv 同型但 ODM 友好）
  - **800V HVDC 規格共定義者**（跟 NVDA + Vertiv 同列）
  - **2.4MW / 3MW L2L CDU**：頂級高密度 CDU 規格、業界少數能做到 4°C approach 溫度 + 1.5 LPM/kW
  - **4RU In-Rack 140kW L2L CDU**：專為 NVDA GB300 NVL72 設計、跟 MGX 架構對齊
  - **規模 + 製造效率**（台灣供應鏈）：價格 + 速度比 Vertiv / Schneider 強
- 對應 [[賣水人選股邏輯（投資版）]]：**整合 turnkey 賣水人**——但**多元組合稀釋 AI 純度**（vs Vertiv 80%）
- 對應 [[控制點轉移（投資版）]]：800V HVDC 共定義 + AI server PSU 60% 市佔 = **拿到台廠最高的 AI infra 規格參與權**

### 供應層

- 跟 [[NVDA]] 路線：
  - 2026-03 NVDA GTC 共同展出 800 VDC 架構（power + cooling + microgrid）
  - 2026-04 Data Center World 整合架構 unveiling（power + cooling + infrastructure）
  - 4RU In-Rack 140kW L2L CDU 直接 align NVDA MGX 架構（GB300 NVL72）
  - AI server PSU 60% 市佔 = NVDA 各代 Blackwell / Rubin 都得用
- 跟 [[Vertiv]] 對比（**核心對標**）：
  - **重疊**：power module（PSU + UPS + 800V DC）+ cooling（CDU）兩軌**完全重疊**
  - **客戶不同層**：Vertiv 走 hyperscaler turnkey、台達走 ODM 友好 + 部分 hyperscaler 直接
  - **規模**：Vertiv FY26 $13.5B vs 台達電 FY25 $20B+（**台達規模略大但多元稀釋**）
  - **純度**：Vertiv 80% AI 資料中心 vs 台達 40% = **Vertiv 純度勝**
  - **AI 速度**：台達 Q1 2026 EPS +100% YoY（**台達速度勝**）
  - **服務 moat**：Vertiv 有 17% services / 維護 recurring、台達弱（製造業 model）
  - → **兩家在 800V DC + CDU 是直接對手、但客戶結構不同避免正面對打**
- 跟 Schneider Electric 對比：
  - Schneider 規模更大（€40B）、但純度更低（30%）
  - 台達 vs Schneider 在 UPS 同台對打、Schneider 強在歐洲 + 工業客戶、台達強在亞洲 + ODM
- 跟 [[雙鴻]] / [[奇鋐 3017|奇鋐]] / [[高力 8996|高力]] 關係：
  - **雙鴻 / [[奇鋐 3017|奇鋐]]**：台達在 cold plate / manifold 段**對打 + 採購並存**（自家 CDU 可能向雙鴻採購 cold plate）
  - **高力 8996**：台達 CDU 內部 BPHE **採購**高力（高力台灣 9 成市佔）
  - → 台達是 cold plate 玩家**最大潛在客戶**、跟雙鴻 / 奇鋐**競合**
- 跟 DEI（泰達電子）股權關係：
  - 台達電持有 **Delta Electronics (Thailand) PCL（DEI）約 41-50%**（透過泰國子公司 + 海外控股）
  - DEI 是台達在東南亞的主要製造基地、台達系**整合**而非完全獨立
  - ⚠️ 數字未交叉驗證（推測 medium confidence）、官方比例待 2025 年報確認
- 跟 [[鴻海]] / [[廣達]] / [[緯創]]（AI server ODM 三雄、待建 entity）關係：
  - ODM 友好供應商：台達 PSU + CDU **必經之路**
  - 跟 [[信昌電]]：信昌電 MLCC 賣電源 ODM → 電源 ODM 賣 PSU 給鴻海 / 廣達 → 鴻海 / 廣達 組 AI server → 餵 NVDA
  - → 台達在「**電源 ODM 餵 ODM**」這一層比信昌電 / 高力位階高
- 護城河：
  - **AI server PSU 60% 市佔**（規模 + 認證 + 良率三軸不可動搖）
  - **800V HVDC 規格參與權**（跟 NVDA + Vertiv 並列）
  - **多元組合分散**（資料中心 + EV + 工業 + 5G + 家電）= 抗景氣循環
  - **ODM 友好供應鏈**（鴻海 / 廣達 / 緯創 / 美超微）= 客戶高黏性
  - **規模 + 製造**：台灣供應鏈 → 比 Vertiv / Schneider 成本 / 速度勝
- 風險：
  - **多元組合稀釋 AI 純度**（vs Vertiv 80%）→ Re-rate 動能弱於 pure-play
  - **CDU 段晚於 Vertiv 起跑**（2025 Q4 才小量、Vertiv 已 reference architecture co-developer）
  - **NVDA universal QD 標準化**削弱所有供應商定價權
  - **電動車 / 工業段**逆風（EV 滲透率減速、工業景氣循環）
  - **匯率**（美元 / 台幣）
  - **估值已部分 price in**（Q1 2026 EPS 7.91 元 + 外資調升目標價 + Forward PE ~25-30x）

### 台達電 vs [[Vertiv]] power module 重疊度（**核心回答**）
