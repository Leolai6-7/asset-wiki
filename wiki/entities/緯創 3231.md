# 緯創 3231（Wistron）

## 1. 一句話定位

**台灣 AI server #3 代工 + GPU baseboard 主代工 + Wiwynn 緯穎子公司 AI HPC 主力 + Acer 派系系統廠**——2001 起源（自 Acer 宏碁分拆獨立、Tucheng 新北土城）、目前全球 NB 代工 #3（市佔 ~12-15%、僅次廣達 / 仁寶）、市值 NT$500-700B；**從 NB 代工分流轉型 AI server + AI HPC niche**：2023-2026 大舉重 pivot AI server + 透過子公司 **Wiwynn 緯穎（6669.TW）+ Wistron NeWeb 啟基**（**Wiwynn 是 AI HPC + DC 機櫃系統主力**、緯穎獨立掛牌、市值 NT$700-900B）+ 緯創自家 **GPU baseboard ODM**（NVDA HGX 8GPU baseboard 主代工）；vs 鴻海 / 廣達 兩大差異：(1) **規模較小**（年營收 NT$1.0 兆 vs 鴻海 NT$6.86 兆 / 廣達 NT$1.5 兆）、(2) **GPU baseboard niche specialist**（緯創自家主代工 NVDA HGX H100 / H200 / B200 8-GPU baseboard、市佔 ~30-40%）+ Wiwynn 子公司 AI HPC anchor、(3) **Wiwynn 緯穎獨立掛牌**（緯創持股 27.5% Wiwynn）= 雙軌掛牌結構；**[[AI infra CapEx 三階段論]] 第三階段台灣鏈條 niche 整合廠**——把 NVDA HGX baseboard + Wiwynn AI HPC 機櫃在台灣完成、出貨給 Meta / AWS / Microsoft。

## 2. 三層 thesis

### 產業層

- AI server 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——緯創從 NB 代工分流轉型 AI server + GPU baseboard niche
  - 主軸 AI server 代工市佔 10-20%（含 baseboard 整機）、業界估、僅次鴻海 + 廣達
  - **GPU baseboard 主代工**：NVDA HGX 8-GPU baseboard 緯創市佔 ~30-40%
  - **Wiwynn 緯穎子公司**：AI HPC + DC 機櫃系統主力、Meta / AWS / Microsoft 客戶
- vs 鴻海 / 廣達 / 智邦 結構性差異：
  - **規模較小**：緯創 NT$1.0 兆 < 廣達 NT$1.5 兆 < 鴻海 NT$6.86 兆、但仍是台灣 AI server 第三大整合廠
  - **GPU baseboard niche specialist**：緯創自家主代工 NVDA HGX baseboard = niche 但毛利率高
  - **Wiwynn 緯穎獨立**：緯穎是 Meta + AWS + Microsoft AI HPC 機櫃主供、規模 NT$700-900B 接近母公司 = 雙軌掛牌結構
- **「緯創 + Wiwynn 雙軌結構」結構性論點**：
  - 緯創（母公司）= NB + GPU baseboard + 雲端設備
  - Wiwynn 緯穎（27.5% 持股子公司）= AI HPC + DC 機櫃系統
  - **雙軌掛牌**：緯創持股 27.5% Wiwynn = 緯創市值的 ~40-50% 來自 Wiwynn 持股價值
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（緯創 + Wiwynn 股價 12 月 +80-120%、機構持股 + 媒體頭條飽和）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1 + 6 + 7 層 NVDA stack 整合 anchor 之一
  - **2026 Q3** Rubin 平台首批出貨：緯創是 NVDA Rubin baseboard niche 代工（與 鴻海 / 廣達 並列）
- vs 鴻海 / 廣達 / 智邦：
  - **緯創 = AI server #3 代工 + GPU baseboard niche specialist + Wiwynn 子公司 AI HPC anchor**
  - **鴻海 = NVDA reference design 主代工 + AI cloud / edge 雙引擎**
  - **廣達 = AI server #2 代工 + Meta MTIA + NB 龍頭 + Apple Mac**
  - **智邦 = AI networking switch（純白牌交換器）**

### 目的層

- 業務 mix（FY2025 公司公告）：
  - **AI server + 雲端設備 = 40-45% 營收**（**FY2026 預估升至 45-50%**）
    - **GPU baseboard 主代工**（NVDA HGX 8-GPU baseboard、市佔 30-40%）
    - **NVDA GB200 NVL72 次代工**（市佔 10-20%、僅次鴻海 50-60% / 廣達 30-40%）
    - **Wiwynn 緯穎 27.5% 持股**：AI HPC 機櫃系統主力
  - **NB（筆電）= 30-35%**
    - HP + Dell + Lenovo + Acer 主代工
    - 規模較廣達小、毛利率約 6-8%
  - **顯示器 + 其他（含 IoT、車用、醫療）= 20-25%**
- 客戶結構（中度分散）：
  - **NVDA = GPU baseboard 主代工 anchor**（HGX 8-GPU baseboard 緯創 30-40% 市佔）
  - **Meta（透過 Wiwynn）= AI HPC 機櫃主供**（OCP 規格）
  - **AWS（透過 Wiwynn）= AI HPC 機櫃主供**（自家規格）
  - **Microsoft（透過 Wiwynn）= AI HPC 機櫃主供**
  - **HP + Dell + Lenovo + Acer**：NB 大宗代工
- 商業模式 = **「NB 基底 + GPU baseboard niche + Wiwynn 子公司雙軌」**：
  - **NB 基底**：HP / Dell / Lenovo / Acer 主代工、毛利率 6-8%
  - **GPU baseboard niche**：NVDA HGX baseboard 緯創 30-40% 市佔、毛利率 12-15%（高於 NB / AI server 整機）
  - **Wiwynn 持股價值**：27.5% Wiwynn 市值 = 緯創市值的 40-50%（雙軌掛牌結構）
  - **AI server 毛利率拉升**：FY2024 整體 GM ~5.5% → FY2025 ~6.8% → FY2026 估 ~7.5-8%
- → 連 [[賣水人選股邏輯（投資版）]]：**「GPU baseboard niche specialist + Wiwynn AI HPC 雙軌賣水人」**——不押 NVDA / AMD / Meta MTIA 誰贏、押所有 AI server / HPC 系統都需要的 GPU baseboard + 機櫃整合
- [[控制點轉移（投資版）]]：拿到「**NVDA HGX baseboard 主代工 + Wiwynn AI HPC 機櫃 anchor + Meta / AWS / Microsoft 透過 Wiwynn 鎖死 + NB 全球 #3**」四重 anchor

### 供應層

- 跟 [[NVDA]] 關係（**GPU baseboard 主代工**）：
  - **NVDA HGX 8-GPU baseboard 主代工**（H100 / H200 / B100 / B200、緯創市佔 ~30-40%）
  - **GB200 NVL72 次代工**（市佔 10-20%、僅次鴻海 / 廣達）
  - **Rubin baseboard first wave 次代工**（2026 Q3、與 鴻海 / 廣達 並列）
- 跟 Wiwynn 緯穎（27.5% 持股子公司、6669.TW）：
  - **AI HPC + DC 機櫃系統主力**
  - **Meta + AWS + Microsoft 主供**
  - **緯穎獨立掛牌**、規模 NT$700-900B（接近母公司緯創 NT$500-700B）
  - **緯創 27.5% 持股 = 市值貢獻 ~40-50%**
- 跟 [[Meta]] 關係：
  - 透過 Wiwynn 緯穎主供（OCP 規格 AI HPC 機櫃）
  - Meta MTIA 部分 baseboard 代工
- 跟 [[AMZN]] AWS 關係：
  - 透過 Wiwynn 主供（AWS 自家 AI HPC 機櫃）
  - AWS Trainium 部分 baseboard 代工
- 跟 [[Microsoft]] 關係：
  - 透過 Wiwynn 主供（Azure AI HPC 機櫃）
  - Microsoft Maia ASIC 部分 baseboard 代工
- 跟 Acer 派系關係：
  - 緯創自 Acer 分拆、施振榮派系
  - NB 代工 Acer 主代工 partner
- 跟 鴻海 / 廣達 / 智邦 關係：
  - **競爭**：AI server 代工互相搶單
  - **互補**：智邦 switch + 緯創 baseboard 互補（部分 hyperscaler 訂單）
- 護城河：
  - **GPU baseboard 主代工 + 30-40% 市佔**
  - **Wiwynn 緯穎 27.5% 持股 + Meta / AWS / Microsoft AI HPC 主供 anchor**
  - **NB 全球 #3 + 12-15% 市佔**
  - **AI server 毛利率高於 廣達**（baseboard niche 結構性）
- 風險：
  - **規模較小**（vs 鴻海 / 廣達 規模差 1.5-5x）
  - **Wiwynn 持股價值波動**：Wiwynn 股價 12 月 +120-180% 已 price in、若 Wiwynn 回檔 → 緯創市值連動受壓
  - **NVDA Stack 採購 ramp 集中**：與 鴻海 / 廣達 並列、若 NVDA 賽道放緩 → 緯創連鎖
  - **AI server 競爭加劇**：鴻海 + 廣達 + Inventec + Compal 同期 ramp、定價壓力
  - **毛利率薄**：NB 6-8% + GPU baseboard 12-15%、結構性低於 SaaS / IC 設計
  - **股價 12 月 +80-120% 已 price in 多年 AI server 拉動**
- → 連 [[控制點轉移（投資版）]]：拿到「**NVDA HGX baseboard 主代工 + Wiwynn AI HPC anchor + NB 全球 #3**」三重 anchor、但「規模 + Wiwynn 持股波動 + 客戶集中」三重風險

## ⭐ vs 鴻海 / 廣達 / 智邦 三家代工龍頭 AI server 站別差異

詳見 [[鴻海 2317]] 內表格。**核心摘要**：

- **緯創 = AI server + GPU baseboard niche specialist + Wiwynn 子公司 AI HPC anchor**
- **鴻海 = NVDA reference design 主代工 + AI cloud / edge 雙引擎**
- **廣達 = AI server #2 代工 + Meta MTIA + NB 龍頭 + Apple Mac**
- **智邦 = AI networking switch（白牌交換器）**

緯創 vs 廣達 主要差異：**緯創 GPU baseboard niche specialist 主代工 + Wiwynn AI HPC anchor**（vs 廣達 AI server pure-play 整機）、規模緯創略小、但**niche IP + Wiwynn 雙軌掛牌結構**是緯創獨特賣點。

### Wiwynn 緯穎（6669.TW）獨立掛牌邏輯

**Wiwynn 緯穎於 2017-07 從緯創分拆獨立掛牌**：
- 緯創持股 27.5%
- Wiwynn 主供 Meta / AWS / Microsoft AI HPC 機櫃（OCP 規格）
- 緯創 NT$500-700B + Wiwynn NT$700-900B = 雙軌結構
- **投資人需求**：直接押 Wiwynn 是「Meta / AWS / Microsoft AI HPC 主供 pure-play」、間接押緯創是「Wiwynn 持股 + GPU baseboard niche specialist 雙軌」

| 路線敏感 | **3** | 主代工 NVDA HGX baseboard + Wiwynn 多 source（Meta MTIA / AWS Trainium / Microsoft Maia）= 多路線但 NVDA HGX 集中 |
