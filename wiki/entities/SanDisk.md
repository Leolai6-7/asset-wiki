# SanDisk（NASDAQ: SNDK / 2025-02-24 從 WDC spin-off 完成）

## 1. 一句話定位

**全球 NAND #3-4（13% 市佔、與 [[Micron]] 並列）+ 從 [[Western Digital]] 切出純 NAND 公司 + HBF（High Bandwidth Flash）標準化共同推動者**——2025-02-24 完成 WDC spin-off 取得獨立股票代號 SNDK、繼承 BiCS NAND 技術線 + Yokkaichi/Kitakami JV fab 50% 權益（與 [[Kioxia]] 共用）、把「**從 brand legacy 轉型為 AI Enterprise SSD pure-play + 2026-02-25 與 [[SK Hynix]] 共同發布 HBF 全球標準化 + NVDA Rubin / Vera 平台 3D NAND 多源 design-in + FY2026 Q3 datacenter 營收 +233% / 整體 +97% QoQ**」綁進同一個故事。在 [[AI infra 3D NAND 戰場]] 6 家分食的格局裡，SanDisk 是「**美國本土 NAND 唯一 pure-play + HBF 標準參與者**」——跟 [[Kioxia]] 構成「美日 NAND 同盟」（capex 同步 +40% YoY）、跟 [[Samsung Electronics]] / [[SK Hynix]] / [[Solidigm]] 競爭 NVDA Vera Rubin ICMS（每 rack 1,152TB SSD）多源訂單。

## 2. 三層 thesis

### 產業層

- **NAND BIG 6 排名**（Q1 2026 Counterpoint）：Samsung（29%）→ SK Hynix+Solidigm（22%）→ Kioxia（14%）→ **SanDisk（13%）= Micron（13%）= YMTC（13%）**
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」過渡期**——
  - 驗證已完成：2025-02-24 spin-off 後三季財報持續超預期、FY2026 Q3 datacenter +233% YoY、HBF 標準化 2026-02-25 公告、Capex +40% YoY 同步 Kioxia
  - 共識未完成：spin-off 後估值仍在被市場重新定義（前 WD legacy 拖累 sentiment）、Forward PE 仍偏低（vs Kioxia 15-20x、vs HBM 廠 40-60x）
- 在 [[資訊擴散四階段]]：機構 → 賣方分析師覆蓋進行中、媒體（Tom's Hardware / Blocks & Files / StorageNewsletter）已熱炒、ETF 配置剛開始
- TAM：Enterprise SSD 市場 2024 181 EB → 2030 1,078 EB（CAGR 35%）、3D NAND 全市場 2026 USD 58.7B → 2031 USD 76B（CAGR 5.3%、但 Enterprise SSD 段拉到 35%）
- 黃仁勳 2026-06-08 定調「AI 記憶體結構性短缺」的**間接受惠**：HBM 短缺加上 NVDA Vera Rubin ICMS 1,152TB/rack 結構性 NAND 需求 → SanDisk 為 6 家分食受益者之一

### 目的層

- 真實角色：**「美國 NAND 純度王 + HBF 規格定義權共同持有者 + 與 Kioxia 共用 fab 但客戶分離的獨立 NAND 廠」**——不是「綜合記憶體廠」（vs Samsung / SK Hynix）、是「**純 3D NAND 製造商 + 賣 BiCS NAND + 自有 Enterprise SSD product line**」、靠「**BiCS 製程共承 + HBF 標準化主導 + Yokkaichi/Kitakami JV 規模 + 美國 CHIPS Act 友好政治窗口**」拿到 Hyperscaler design-in
- 商業模式三段：
  - **Datacenter Enterprise SSD**（成長引擎、FY2026 Q3 +233% YoY）：AI / cloud / NVDA Rubin ICMS 多源供應
  - **Client SSD**（穩定）：消費 PC、外接 SSD 品牌零售（前 WD 品牌資產）
  - **Mobile / Embedded / Memory cards**（收割）：手機 UFS、Action camera、相機記憶卡（brand legacy 資產）
- 真實戰略：**「spin-off pure-play + HBF 標準化主導 + 美日聯盟 capex 同步 + brand legacy 變現 + NVDA Rubin/Vera 多源 design-in」五重 catalyst 同步**——
  - 2025-02-24 完成 spin-off → 估值從「WDC 綜合儲存集團」打散為「純 NAND 廠」
  - 2026-02-25 與 [[SK Hynix]] 共同發布 HBF（NAND-as-DRAM 替代 HBM 部分推理用途、容量 8-16× HBM、2027 量產）= **拿到下一代記憶體規格定義權**
  - 2026-06-01 TrendForce 報 SanDisk + Kioxia capex +40% YoY 同步擴產 Yokkaichi/Kitakami JV fab
  - NVDA Rubin / Vera 平台 3D NAND 多源策略確認（SanDisk 為 6 家分食之一）
- [[控制點轉移（投資版）]]：拿到「**HBF 規格定義權 + Enterprise SSD 製程共享權（與 Kioxia 共用 BiCS）+ 美國本土 NAND 唯一 pure-play 政治護城河**」

### 供應層

- **路線雙押**：BiCS（與 Kioxia 共製程）+ HBF（與 SK Hynix 標準化）
- 護城河四層：
  - **BiCS 製程共享護城河**：與 Kioxia 共用 Yokkaichi（Mie Prefecture）+ Kitakami（Iwate Prefecture）fab、共擔設備折舊但客戶分離 50/50 = **規模效應分攤但市場獨立**
  - **HBF 標準化主導護城河**：2026-02-25 與 SK Hynix 共推 HBF 全球標準 = NAND-as-DRAM 路線的**規格定義權**（2027 量產、8-16× HBM 容量、推理 server 用）
  - **美國本土 pure-play 政治護城河**：CHIPS Act 友好、美 NAND 唯一純 play（Micron NAND 是配角）、地緣政治對沖 YMTC 替代論
  - **brand legacy 資產**：SanDisk 品牌（記憶卡 / 外接 SSD）+ 消費 / 商業客戶綁定（從 1988 SanDisk 創立累積）
- 對 [[Samsung Electronics]] NAND 部門領先程度：**規模 ~2x 落後**（13% vs 29%）但**HBF 標準化參與 +1 個身位**（Samsung 仍觀望）
- 對 [[SK Hynix]] + [[Solidigm]] 領先程度：規模略小（13% vs 22% 合計）、但**HBF 是同盟合作關係**（標準化共同推動者）
- 對 [[Micron]] 領先程度：**NAND 純度高得多**（Micron NAND 是 secondary、HBM 才是 anchor）、市佔近似（13% = 13%）
- 跟 [[Kioxia]] 關係：**「製造 JV 共享、市場合作重建」**——歷史上 Toshiba Memory + Western Digital BiCS 共投 Yokkaichi/Kitakami fab、2024-2025 spin-off 後 SanDisk 從 WDC 分離繼承 JV 權益、雙方在 HBF 標準化重建合作但**製造線分離 + 客戶獨立**
- 跟 [[Western Digital]] 關係：**「已分家、共享 brand legacy 但運營完全分離」**——2025-02-24 spin-off 後 WDC 不再有 NAND 業務、SanDisk 接收 brand + NAND 資產獨立經營（SanDisk 品牌名 1988-2016 獨立、2016 被 WDC 收購、2025 重生為獨立公司）

### ⚠️ 風險

- **Spin-off 後估值仍在重定價**：股東結構轉換 + 前 WDC ETF holders 拋售 → 短期股價波動高
- **HBF 取代 vs 互補定論不明**：若 HBF 不能取代 HBM 推理用途 → 只是 niche、HBF 上行打折扣
- **Kioxia 為直接 NAND 對手且共享 fab**：JV 內客戶分離 50/50 但 BiCS 製程路線一致 = 純粹拼客戶 + ASP，無製程差異化
- **Samsung V10 / SK V9 / Kioxia BiCS 10 332-layer ramp（2026-2028）**：競爭對手製程同步進化、SanDisk 跟 Kioxia 共用 BiCS 製程是否能持續領先未明
- **缺乏 HBM 護城河**：純 NAND 在 AI infra 估值上輸 HBM 一個量級、Forward PE 拉不到 HBM 廠水準
- **客戶結構未充分揭露**：NVDA Vera Rubin ICMS 多少分給 SanDisk 仍未明、Hyperscaler 訂單能見度透明度低
- **中國 YMTC 國產替代**：YMTC Q1 2026 已拿 13% 全球市佔（並列 SanDisk）、3-5 年內可能切 Enterprise SSD 中國市場
- **brand legacy 包袱**：SanDisk 消費業務（記憶卡 / 外接 SSD）週期性 + 利潤率較低 → mix 仍需向 datacenter 傾斜

## ⭐ HBF（High Bandwidth Flash）規格定義權（重要差異化）

> SanDisk 在 NAND 戰場最獨特的差異化是 **HBF 標準化主導**——2026-02-25 與 [[SK Hynix]] 共同發布全球標準。

- HBF 規格特性：
  - **NAND-based 替代 HBM 部分推理用途**（不取代 HBM 訓練用途）
  - **容量 8-16× HBM**（同成本下密度大幅領先）
  - **延遲仍比 HBM 高 1000×** = 純 inference / 不熱 cache 路線
  - **2027 H1 量產**目標
- HBF 對 SanDisk 的戰略意義：
  - 拿到「**下一代記憶體規格定義權**」（HBM 標準是 SK Hynix / Samsung / Micron 三家 + JEDEC、HBF 是 SanDisk + SK Hynix 兩家定義）
  - **進入 HBM 範式的姊妹篇**：HBF 若被 NVDA Rubin Ultra 或 Feynman 採用 → SanDisk 估值會從「NAND 廠 15-20x PE」拉到「HBM 廠 40-60x PE」mirror
  - **跟 [[Kioxia]] 差異化關鍵**：兩家共用 BiCS 製程、但 SanDisk 拿到 HBF 標準化主導 = 規格層贏 Kioxia 一個身位
- HBF 風險：
  - 若 NVDA 不採用 HBF（推理 server 仍走 HBM）→ HBF 只是 niche、SanDisk 估值無 anchor
  - 若 Samsung / Micron 推競爭規格 → HBF 三足鼎立、SanDisk 失先發優勢

→ **SanDisk 18/25 = 美 NAND pure-play 第二高分**（僅次於 Kioxia 19）、跟 [[Marvell]]（18/25）/ [[Lumentum]]（19）/ [[Coherent]]（19）/ [[Ciena]]（19）/ [[Nokia]]（18）同層。**HBF 規格定義權是唯一加分項**——若 HBF 真被 NVDA Rubin Ultra 或 Feynman 採用 → SanDisk 估值會 mirror SK Hynix HBM 路徑。

## ⭐ 對 [[AI infra 3D NAND 戰場]] 的意義（補位第 6 家分食的純度王）

SanDisk 在 NAND 戰場的位置：

- **Tier 2 NAND 純 + 雙鏈 storage AI 受惠**（與 [[Western Digital]] 同 Tier 但運營分離）
- **NAND 戰場 6 家分食中「美 pure-play」唯一身位**：Samsung / SK / Kioxia 是亞洲廠、Micron NAND 是配角、YMTC 中國國產替代 → SanDisk 是美 NAND 唯一純 play
- **HBF 規格定義權 = 升級為「半主戰場」的關鍵 anchor**：若 HBF 被 NVDA 採用 → NAND 升級為「HBM 範式的姊妹篇」、SanDisk 估值從 NAND 廠 15-20x PE 拉到 HBM 廠 40-60x PE

對 [[AI infra 3D NAND 戰場]] 的補強：
- Tier 2 加入 SanDisk 補位（原本只有 Kioxia 為 Tier 1、Solidigm 為 Tier 1、SanDisk + WDC 為 Tier 2）
- HBF 規格定義權新加為「NAND 升級主戰場」的 trigger anchor
- 美日 NAND 同盟（SanDisk + Kioxia capex +40% YoY 同步擴產）成為對抗 SK + Samsung + YMTC 的 anchor

## ⭐ 對台股 / 美股 AI 半導體基礎建設的意義

對 [[NVDA]]：
- Vera Rubin ICMS（1,152TB/rack）多源策略受惠者之一（6 家分食）
- HBF 標準化參與 → 若 NVDA Rubin Ultra 或 Feynman 採用 HBF → SanDisk 從「NAND 配角」升級為「規格共定義者」

對 [[Kioxia]]：
- **共用 fab、客戶分離、製程共享 + HBF 規格共同推動**（透過 SK Hynix 三方）
- 兩家是「美日 NAND 同盟」核心（capex +40% YoY 同步）
- 競爭：同 BiCS 製程、客戶分離 50/50、純拼 ASP + 客戶執行

對 [[SK Hynix]]：
- **HBF 標準化夥伴**（2026-02-25 共同發布）
- 競爭：NAND 戰場直接競爭（SK + Solidigm 22% vs SanDisk 13%）

對 [[Western Digital]]：
- **前同公司、2025-02-24 spin-off 後完全分離**——brand legacy 共享、運營 / 財報 / 股東結構完全獨立
- WDC 變身純 HDD 公司、SanDisk 接 NAND 業務 = 兩者已在 [[AI infra 3D NAND 戰場]] vs HDD AI 戰場分屬不同戰場

對 [[Samsung Electronics]]：
- NAND 戰場直接競爭（Samsung 29% vs SanDisk 13%）
- HBF 規格 Samsung 仍觀望 → SanDisk 拿到先發優勢

對 [[Micron]]：
- NAND 市佔近似（13% = 13%）、但純度差異大（Micron NAND 是配角、HBM 是主軸）
- 競爭：Enterprise SSD 段直接競爭、SanDisk 純度勝

對台廠：
- 鴻海 / 廣達 / 緯穎 / 緯創 server ODM 採購 SanDisk Enterprise SSD（多源策略）
- 力成 [[Powertech 力成]] 主供 Micron 封測、跟 SanDisk 無直接合作
