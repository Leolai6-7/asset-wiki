# Nokia（NOK）

## 1. 一句話定位

**全球通訊基礎設施雙頭之一（vs Ericsson）+ 光網路+ DCI 「廣度王」**——成立 1865 年的芬蘭通訊巨頭、2026-01 大改組後拆成 **Network Infrastructure（光網路 / IP / 固網）+ Mobile Networks** 兩大段；併購 [[Infinera]]（$2.3B、2025-02 完成）後光網路產能 +80%、coherent DWDM 端口出貨量翻倍、**Q1 2026 光網路營收 €821M（YoY +20% comparable / +56% reported）= 升上集團第二大業務**；推 **1830 GX RD66 + D2ILA hyperscale OLS / Multi-Rail** 與 [[Ciena]] HyperRail 概念同、架構規格略勝（160 fiber pairs / rack vs CIEN 128），**2026 H2 出貨**；hyperscaler 滲透率「9 of top 10 都用 Nokia 光網路」、Q1 2026 接 hyperscaler 訂單 **€1B**（YoY +49%）= 直接承接 [[Ciena]] supply-constrained 訂單外溢；**Forward PE 43x vs Ciena 80-91x = 折價一半的 DCI 對沖配置**。

## 2. 三層 thesis

### 產業層

- DCI 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 在「**驗證 → 共識加速**」段（與 [[Ciena]] 相同）——hyperscaler AI infra CapEx 把 DCI 從電信外圍拉成 AI infra 必經之路
- **Nokia 在 DCI 賽道的特殊位置**：
  - 不像 CIEN 是 DCI 純度王、Nokia 是「**寬度 + 深度 + 跨領域**」玩家
  - Mobile Networks（5G）= 老本（在萎縮 / 進入 maintenance phase、亞太+歐洲市佔被 Huawei + Ericsson + Samsung 蠶食）
  - Network Infrastructure（光網路 / IP / 固網）= **AI 紅利吃下**（hyperscaler DCI 需求爆炸）
  - **Infinera 併購（2025-02 完成）= 關鍵轉折**：拿到 hyperscaler 直接客戶 + 美國北美光網路市場份額（2.3B 美金、預估 2027 帶來 €200M synergy + 10%+ EPS accretion）
- 競爭格局：
  - **[[Ciena]]**：DCI 純度王、HyperRail 拿首單、估值已 price in
  - **Nokia**：廣度王、Multi-Rail 跟進、估值折價一半、business mix 緩衝
  - Cisco：交換 ASIC + 路由 + DCI 子業務、AI 槓桿低
  - Ericsson：**已實質退出 DCI / 光網路**（聚焦 5G + 開放 RAN、跟 NVDA 5G/6G 沒走 hyperscaler DCI 路線）
  - 中國 Huawei + 中興：被美 entity list 排除在西方 hyperscaler 外
- → 跟 Ericsson 對比：**Nokia 走 hyperscaler 光網路、Ericsson 走 NVDA 5G/6G 獨立 RAN**——同樣是無線設備商出身、但**策略徹底分歧**

### 目的層

- 主業 mix（FY2025 全年、2026-01 改組後新架構）：
  - **Mobile Infrastructure（無線網路設備）= €11.41B、占 ~60%**：傳統老本、CSP 重資本支出、在萎縮
  - **Network Infrastructure（光網路 + IP + 固網）= €7.65B、占 ~40%**：AI 紅利吃下
    - **Optical Networks**（含 Infinera）：Q1 2026 €821M、YoY +20% comparable、占 NI ~50%、AI cloud 主場
    - **IP Networks**：路由 / 交換、跟光網路同 segment
    - **Fixed Networks**：固定寬頻、5G fixed wireless access
  - **Nokia Technologies**（IP 授權，含手機品牌授權）：高毛利但小
- 客戶結構：
  - **9 of top 10 hyperscaler 都用 Nokia 光網路**（Nokia 法說會原話）= 廣度王、單一客戶集中度遠低於 CIEN
  - Q1 2026 hyperscaler 訂單 **€1B**（YoY +49%）= AWS / Google / Microsoft / Meta 全在加碼
  - **Google WAN award** 已揭露（pluggables + transponders + line systems + switching 跨產品線）
  - Service Provider（電信 CSP）= 全球 Tier 1 廣布（歐洲 + 北美 + 拉美 + 印度 + 亞太）= 客戶集中度低
  - 政府 / 國防：北約 + 歐盟 sovereign infrastructure 受惠
- 商業模式：**多元業務 + 廣度滲透**
  - Mobile Networks 在萎縮、但提供現金流穩定性（vs CIEN 純 DCI 集中度風險）
  - Network Infrastructure 是成長引擎、毛利率 Q1 2026 達 **43.4%**（拜 Infinera synergy 所賜）
  - Infinera 整合：vertical integration（自研 coherent DSP + InP optical components）+ 美國 hyperscaler 直銷渠道 + 北美光網路市占
- → 連 [[賣水人選股邏輯（投資版）]]：Nokia 是「**DCI 賽道對但不確定哪家拿單**」的對沖配置——9 of top 10 都用、誰贏 Nokia 都吃得到

### 供應層

- 跟 hyperscaler 路線：**廣度第一、深度第二**
  - 9 of top 10 hyperscaler 都用、單一客戶最大也才占個位數
  - Google WAN award 已揭露（跨產品線）
  - Microsoft / AWS / Meta 都在採購（Q1 2026 €1B 季訂單分散在多家）
  - **1830 GX RD66 + D2ILA hyperscale OLS 2026 H2 出貨**（與 CIEN HyperRail 概念同、規格略勝）
- 跟 [[Lumentum]]（LITE）/ [[Coherent]]（COHR）關係：**Nokia 是 pump laser 採購方 + Infinera 自研 InP 光元件雙路徑**
  - **路徑一（外採）**：1830 GX RD66 整合 C+L band amplifier + WSS + pump laser → 採購 [[Lumentum]] / [[Coherent]]（與 CIEN 同 supply chain）
  - **路徑二（自研，Infinera 帶入）**：Infinera 自有 InP fab（San Jose + Allentown）= **自研 coherent DSP + 光元件**部分內製 = 對 LITE/COHR 依賴度低於 CIEN
  - 這代表 **Nokia ramp ≠ LITE/COHR 全部受惠**（部分內製化）、但 1830 GX RD66 hyperscale OLS 大部分仍外採 → LITE/COHR 仍受惠
  - [[Coherent]] Q3 FY2026「leading DCI OEM」design win 客戶極大概率 CIEN 或 Nokia 或兩家
- 跟 [[NVDA]] 關係：**獨特路線——5G/6G + 光網路雙曝險**
  - Nokia 跟 NVDA 簽 **5G/6G AI-RAN 戰略合作**（2025）= Ericsson 走獨立路線、Nokia 抱 NVDA 大腿
  - 光網路段沒有像 [[Coherent]] 直接拿 NVDA $2B 投資、但 hyperscaler 蓋 NVDA AI factory → 必然要連 site → Nokia 1830 GX RD66 受惠
- 跟 [[Ericsson]] 關係：**直接對手、已策略分歧**
  - Ericsson 2025 營收 $22B / OP margin 17%、聚焦 5G + 北美電信
  - Nokia 2025 營收 $26B / OP margin 9% reported (17% comparable)、跨 5G + 光網路 + IP + 固網 + AI cloud
  - **Ericsson 沒走 DCI / hyperscale 光網路**——這是 Nokia 在 hyperscaler 段的「沒有歐美對手」護城河
- 護城河：
  - **Infinera 併購帶來的美國 hyperscaler 直銷渠道 + 北美光網路市占 + InP 自製 fab**
  - 廣度滲透（9 of top 10 hyperscaler）= 客戶集中度遠低 [[Ciena]]
  - 多元業務（Mobile + NI + Technologies）= 業務 mix 緩衝
  - **政治位置**：北約 + 歐盟 sovereign infrastructure、無中國設備商威脅
- 風險：
  - **Mobile Networks 萎縮**（5G CSP CapEx 進 maintenance phase、中國市場流失）= 拖累整體營收成長
  - **整體毛利率被 Mobile 拖累**（Network Infrastructure 43.4% vs Mobile <30%）
  - Infinera 整合 execution 風險（2025-02 才完成、synergy 預估 €200M by 2027）
  - **NVDA 5G/6G 路線實質執行**：Nokia 跟 NVDA 抱大腿、但 AI-RAN 是新路線、商業化時程不明
  - hyperscaler 換供應商風險（雖然 9 of top 10 都用、但份額可能被搶）
  - [[Ciena]] HyperRail 2027 ramp 順利 → 部分 hyperscaler 標準化 CIEN 而非 Nokia
  - 歐元升值 → 北美營收（含 Infinera）匯率壓縮
- → 連 [[控制點轉移（投資版）]]：Nokia 在「**hyperscaler 光網路廣度滲透**」拿到控制點、但「**DCI 純度單純度**」輸 [[Ciena]]、「**5G 控制權**」輸 [[Ericsson]]、「**光元件 IP 控制權**」輸 [[Coherent]]/[[Lumentum]]——廣度王但每段都不是極致

## ⭐ DCI 賽道 thesis 校準（Leo 原 thesis 對比）

**Leo 原文觀察（2026-06-05 raw 筆記）**：
- CIEN: Hyper Rail 2027 部署、供應跟不上需求
- NOK: Multi-Rail 2026 H2 出貨、訂單外溢承接者
- 「在 DCI 的技術發展上，NOK 沒有落後」
- 「Hyper Rail 跟 Multi-Rail 概念相同、細節有差異」

**實證驗證（2026-06 WebSearch 抓取）**：

| Leo 判斷 | 實證結果 | 校準 |
|---|---|---|
| NOK Multi-Rail 2026 H2 出貨 | ✅ **完全正確**——Nokia 1830 GX RD66 hyperscale OLS + D2ILA dual amp sled **2026 H2 availability** 已官方確認、與 Multi-Rail in-line amplifier 同期上市 | high confidence |
| Hyper Rail 跟 Multi-Rail「概念同、細節有差異」 | ✅ **完全正確**——兩家都是「**multi-fiber-pair 共用 amplifier / pump laser 整合架構**」、目標都是 hyperscale DCI 密度。CIEN HyperRail = 128 fiber pairs/rack、Nokia Multi-Rail = **160 fiber pairs/rack（規格略勝）**、Nokia 1830 GX RD66 C+L band 全整合進 single sled（比 CIEN 集成度高）。**架構哲學完全相同、Nokia 略勝細節** | high confidence |
| 「NOK 在 DCI 沒落後」 | ✅ **完全正確、甚至樂觀有理**：（1）1830 GX RD66 規格略勝 CIEN HyperRail；（2）2026 H2 出貨 vs CIEN 2027 ramp = **時程領先**；（3）9 of top 10 hyperscaler 都用 Nokia 光網路 = 滲透深度；（4）Q1 2026 hyperscaler 訂單 €1B / AI & Cloud +49% / Optical Networks +20% comparable = AI 紅利吃得到；（5）Google WAN award 已揭露 | high confidence |
| 訂單外溢承接 | ✅ **方向正確、可量化**——Nokia Q1 2026 hyperscaler 訂單 €1B（YoY +49%）+ Optical Networks +20% / AI&Cloud +49% = **Nokia 明顯承接 CIEN supply-constrained 卡住的需求**。但無法 1:1 對應「哪筆訂單原本是 CIEN 的」 | medium confidence |

**新增校準**：
- **Nokia 廣度王 vs CIEN 純度王**：Nokia 9 of top 10 都用 vs CIEN 兩家占 34%——Nokia 客戶集中度低、business mix 緩衝、是「DCI 對沖配置」
- **Nokia Multi-Rail 出貨時程領先 CIEN（2026 H2 vs 2027）**：但 CIEN 已收「industry's first multi-rail order」、Nokia 是否能收同等量級首單待觀察
- **Nokia 估值折價一半**：Forward PE 43x vs CIEN 80-91x——「同樣看好 DCI 賽道、買 Nokia 估值風險低一半、但 Mobile Networks 稀釋 50% AI 紅利」
- **Nokia 跟 [[Ericsson]] 已策略分歧**：Ericsson 退出 DCI / hyperscaler 光網路、聚焦 5G + 開放 RAN + NVDA 獨立——Nokia 走 hyperscaler 光網路 + NVDA 5G/6G AI-RAN 抱大腿——**兩家不再是直接對手**

## ⭐ 跟 [[Lumentum]] / [[Coherent]] 採購關係

Nokia 1830 GX RD66 + D2ILA Multi-Rail OLS 也整合 **pump laser + amplifier + WSS**，是 LITE / COHR 兩家光元件採購方，但 **Infinera 帶入自研 InP fab（San Jose + Allentown）= 對 LITE/COHR 依賴度低於 CIEN**：

| 採購項 | 來源 |
|---|---|
| **EDFA pump laser** | [[Lumentum]] 980nm 主導、[[Coherent]] uncooled 3-pin micropump + 部分 Infinera 自研 |
| **Coherent DSP** | **Infinera 自研**（併購帶入）= 不外採 |
| **WSS（Wavelength Selective Switch）**| [[Lumentum]] / [[Coherent]] / II-VI 三家寡占 |
| **InP optical components**| **Infinera 自研 InP fab**（San Jose + Allentown）= 部分內製 |
| **線性 / 非線性 photonic IC** | Infinera PIC（photonic integrated circuit）自研 |

**對 LITE/COHR 的意義（vs CIEN 對比）**：
- **CIEN ramp = LITE/COHR 高槓桿受惠**（CIEN 100% 外採 pump laser + WSS + DSP 自研但其他元件外採）
- **Nokia ramp = LITE/COHR 中度受惠**（部分 InP 元件 Infinera 自研、但 pump laser + WSS 仍外採）

→ 連 [[CPO 供應鏈圖譜]] 第七層「電源 / 雷射」：Nokia 在 DCI 賽道是「**部分內製的整合方**」、削弱了上游 LITE/COHR 的議價權、但 hyperscale OLS 大部分仍依賴外採。

→ **Leo thesis 校準**：「CIEN 跟 Nokia 都要 pump laser、所以 LITE/COHR 雙頭受惠」**方向對、但 Nokia 受惠程度比 CIEN 低**（因 Infinera 部分內製）。
