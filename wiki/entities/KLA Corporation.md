# KLA Corporation（NASDAQ: KLAC / 科磊）

## 1. 一句話定位

**半導體檢測 / 量測（Process Control）全球 #1 + Process Control >50% 全球市佔 + pattern wafer / mask / reticle defect inspection 全產品線 + e-beam + DUV inspection 全棧 + 1976 在加州 Milpitas 創立 + 客戶 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[SK Hynix]] / [[Micron]] / [[GlobalFoundries]] 全 AVL**——納斯達克上市、總部 Milpitas CA、市值 **USD ~$95-110B（Mega Cap）**；客戶覆蓋 [[TSMC]] ~28% + [[Samsung Electronics]] ~22% + [[Intel]] ~13% + [[SK Hynix]] + [[Micron]] + [[GlobalFoundries]] 全球先進製程 fab AVL；**FY2025 營收 ~USD $10-12B** + EBIT margin **40%+**（半導體設備龍頭最高）+ Forward PE **22-28x**；不押任何 fab / 任何 fabless / 任何技術路線、所有先進製程都要 KLA 檢測——在 [[賣水人選股邏輯（投資版）]] 是「**架構級『賣水人之中的賣水人』前段設備三巨頭 #2**」（跟 [[Applied Materials]] + [[Lam Research]] 並列、預估 **22/25**）、在 [[Bottleneck Theory（瓶頸論）]] 是「**七層之外的「層 -1 製程檢測層」+ Process Control >50% 唯一 chokepoint**」；跟 [[ASML]] / [[Applied Materials]] / [[Lam Research]] 互補非競爭（不同站別）。

## 2. 三層 thesis

### 產業層

- **半導體 Process Control（檢測 / 量測）全球市佔**：**KLA >50%（壟斷）** vs Applied Materials ~12% vs Hitachi High-Tech ~7% vs ASML metrology + Onto Innovation 其他分食
- **產品線完整覆蓋**（檢測 + 量測 + e-beam + DUV）：
  - **pattern wafer defect inspection**：KLA #1（broadband plasma + e-beam + 多波長）
  - **mask + reticle defect inspection**：KLA #1（EUV mask inspection 進入 ramp）
  - **e-beam inspection**：KLA + Hermes Microvision（被 KLA 收購）+ Hitachi High-Tech 三家分食、KLA 寡占
  - **overlay / CD-SEM metrology**：KLA + ASML（HMI）+ Hitachi 分食、KLA #1
  - **wafer inspection + film thickness + CMP control**：KLA 主導
  - **5x optical microscope + 多波長偵測**：KLA 業界標竿
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「共識中」高位**——AI capex + 先進製程 + EUV mask 檢測都已是市場共識
- 在 [[資訊擴散四階段]]：機構 + 賣方 + 媒體 + ETF 全部已配置（SOX / SMH 主要成份）
- TAM：
  - FY2025 ~USD $10-12B
  - **FY2030E ~USD $18-22B**（推估 CAGR ~12-15%）
  - 結構性驅動：先進製程 + EUV mask inspection 普及 + AI fab process control automation + HBM/DRAM 製程升級 = 缺陷檢測敏感度倍增
- 跟 [[半導體基礎建設化]] 視角：KLA 是「**製程檢測設備基礎建設化 #1 anchor**」（檢測設備是唯一 >50% 寡占的設備細分）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：KLA = **製程檢測 chokepoint**（先進製程缺陷檢測敏感度結構性提升、唯一供應商可達 EUV / High-NA EUV 精度）

### 目的層

- 真實角色：**「不是賣晶片、是賣『晶片製造的良率守護神』+ inspection + metrology + e-beam + 軟體分析 service」**——不是「跟 fab 競爭」、不是「跟 fabless 競爭」、是「**所有 fab / IDM 都要 KLA 才能管良率**」、靠「**Process Control >50% 寡占 + 50+ 年 inspection R&D 累積 + 軟體分析 service**」維持壟斷
- 業務組合（FY2025 推估）：
  - **Semiconductor Process Control（檢測 + 量測）**：~85%
  - **Specialty Semiconductor Process（specialty fab + PCB / display inspection）**：~10%
  - **PCB, Display & Component Inspection**：~5%
- 核心 IP / 護城河：
  - **inspection algorithm + 多波長偵測**（50+ 年累積、業界唯一可達 EUV defect 精度）
  - **e-beam inspection（Hermes Microvision）**（2016 USD 3.4B 併購整合）
  - **EUV mask inspection** Actinic Patterned Mask Inspection（APMI）2022 量產
  - **軟體分析 + AI fab control**（process control 全棧軟體 + AI 缺陷分類）
  - **客戶 lock-in**（fab 製程整合 + service + spare parts 35%+ recurring）
- **跟 ASML 互補非競爭**：ASML 微影 + AMAT 製程 + Lam etch + KLA 檢測 = fab 必四家分頭採購
- 對應 [[賣水人選股邏輯（投資版）]]：**「架構級『賣水人之中的賣水人』前段設備三巨頭 #2 anchor」**（跟 [[Applied Materials]] + [[Lam Research]] 並列）
- 對應 [[控制點轉移（投資版）]]：拿到「**Process Control >50% 寡占 + EUV mask inspection + e-beam + 軟體分析**」四層 chokepoint

### 供應層

- 客戶結構（**全球先進製程 fab AVL 完全分散**）：
  - **[[TSMC]] ~28%**：N5 / N3 / N2 / A16 + CoWoS / SoIC 後段全棧 KLA inspection、KLA 最大客戶
  - **[[Samsung Electronics]] ~22%**：HBM4 + 2nm Foundry + DRAM 製程升級 KLA inspection
  - **[[Intel]] ~13%**：Intel 18A + Terafab + Magdeburg fab 全 KLA inspection
  - **[[SK Hynix]] + [[Micron]] ~15-20%**：HBM4 / HBM4E / DRAM 1c / 1d nm 製程 KLA inspection
  - **[[GlobalFoundries]] + 其他 ~10-15%**：成熟製程 + 中國 fab 部分 AVL
  - 客戶分散度（無單一客戶 > 30%、5 大客戶集中度略高於 [[ASML]] / [[Applied Materials]] = **客戶分散 3/5 略遜**）
- 跟 [[ASML]] 互補（**非競爭**）：ASML 微影 + KLA inspection、不同站別
- 跟 [[Applied Materials]] 互補（**非競爭**）：AMAT 製程設備 + KLA 製程檢測、不同站別
- 跟 [[Lam Research]] 互補（**非競爭**）：Lam etch / depo + KLA 檢測、不同站別
- 跟 Hitachi High-Tech / ASML HMI（**檢測對手**）：Hitachi e-beam + ASML HMI metrology 部分競爭、但 KLA >50% 結構性壟斷
- 跟 Onto Innovation / Camtek（**niche metrology 對手**）：Onto Innovation + Camtek 在 advanced packaging metrology niche 競爭、但 KLA Process Control 主流壟斷
- 跟 [[SK Hynix]] / [[Micron]] / [[Samsung Electronics]] 記憶體三巨頭：HBM4 / HBM4E / DRAM 1c / 1d nm 製程**缺陷檢測敏感度倍增** → KLA inspection 結構性 ramp
- 跟中國市場關係：
  - 中國成熟製程（28nm+）fab 擴張 → KLA 中國市場短期受惠 ~20%
  - 但美國 BIS 限制 14nm 以下對中出口 → KLA 中國敞口長期下修
  - 中國國產替代（精測科技 / 中科飛測）尚在追趕、KLA 結構性領先 5-10 年
- 護城河：
  - **Process Control >50% 寡占 + 50+ 年 R&D 累積**
  - **EUV mask inspection（APMI 2022 量產）+ e-beam（Hermes Microvision）整合**
  - **軟體分析 + AI fab control + service recurring 35%+**
  - **客戶結構性 lock-in**
- 風險：
  - **客戶集中度略高於 ASML / AMAT**（TSMC 28% 集中）
  - **中國市場長期下修**（BIS 限制 + 國產替代）
  - **競爭加劇**（Hitachi e-beam + ASML HMI metrology + Onto Innovation niche）
  - **AI capex 週期性**
  - **EBIT margin 40%+ 估值已 price in**
