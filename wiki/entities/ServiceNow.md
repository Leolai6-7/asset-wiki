# ServiceNow（NYSE: NOW）

## 一句話定位（Sticky）

> **IT workflow 自動化全球 #1（ITSM / ITOM / ITAM 寡占），AI 時代「軟體賣水人」anchor、Now Platform AI agent + GenAI workflow 全棧整合 pure-play。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **共識期 + GenAI 二次驗證**——IT workflow 自動化 + GenAI 商業化 + AI agent for enterprise workflow 三線重疊。

TAM：Forrester / Gartner 估 enterprise workflow + ITSM + AI agent 2030 ~$300-400B、ServiceNow 跨多模組覆蓋。

### 目的層

**「Now Platform 軟體賣水人 + AI agent first-mover」**：跟 [[Synopsys]] 24（EDA 賣水人）+ [[Cadence]] 22（EDA #2）並列「**架構級賣水人之中的賣水人**」軟體側 anchor——所有 Fortune 500 IT 部門 + customer service + HR + finance 都要用 Now Platform。

商業模式：100% SaaS subscription、ARR $11B+、跟 [[Accenture]] 19（諮詢三巨頭 #1）「上下游互補」（Accenture 部署 + ServiceNow 平台）。

[[Forward Deployed Engineer 戰略（FDE）]] 受惠：AI agent for enterprise 大規模部署 → Now Assist + Now AI Agent 商業化加速、ARR 增速二次拉升。

### 供應層

**頂級軟體賣水人**（[[賣水人選股邏輯（投資版）]]）：100% 路線中立、不押任何 LLM / hyperscaler / 終端 SaaS、所有玩家都依賴 Now Platform 做 IT workflow。
[[控制點轉移（投資版）]]：Now Platform 是企業 IT 控制點 + AI agent for enterprise workflow chokepoint。
