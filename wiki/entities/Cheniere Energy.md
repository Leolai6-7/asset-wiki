# Cheniere Energy（NYSE: LNG）

## 1. 一句話定位

**美國 LNG 出口 #1 + 全美 50%+ 出口量寡占 + Sabine Pass + Corpus Christi 兩大 train 全棧 + SPA 長約 80% 結構性現金流 anchor + AI infra 電力戰場 firm power 第五選擇 anchor**——總部 Houston Texas、1996 創立、原本是 LNG 進口商（美國頁岩氣革命前）、2010-2012 戰略轉型成出口商（CEO Charif Souki 押注成功）；**Sabine Pass Liquefaction（SPL、Louisiana、6 trains ~30 MTPA）**＋**Corpus Christi Liquefaction（CCL、Texas、3 trains 已運轉 + Stage 3 七 mid-scale trains 2026-2028 ramp 加 ~10 MTPA）**= 兩大廠合計超過 ~45 MTPA 出口能力、佔全美 LNG 出口 ~50%+（Cheniere 自家揭露）；**SPA（Sales Purchase Agreements）長約結構 ~80%**：客戶含 BP / Shell / TotalEnergies / Equinor / 中海油 CNOOC / 韓國 KOGAS / 日本 JERA / 西班牙 Naturgy + 葡萄牙 Galp + 印度 PetroNet + Vitol，**每 LNG 船 D2DES（Delivered Ex-Ship）+ FOB 雙模式 + Henry Hub +115% 公式 + 20 年期限**= 現金流鎖死至 2040+；**業務組合**：(1) SPL Stage 1-6 + CCL Stage 1-3 long-term SPA ~70%（含 IPM 中游 pipeline）+ (2) Cheniere Marketing International 自營交易 ~25%（短期 spot + medium-term）+ (3) **Cheniere Energy Partners（CQP）LP 結構持股 ~48.6%**（IDR 結構已收編）；FY2025 估算營收 USD ~$15-18B / Adjusted EBITDA $6-7B / Distributable Cash Flow $3-4B、FY2026 指引營收 USD ~$17-20B / EBITDA $6.5-7.5B、Forward PE **12-15x**、市值 USD ~$50-55B / Mega Cap；12 個月漲幅 **+20-50%**（部分已 price in、但 LNG long-cycle 結構性 thesis 尚未 reflected fully）；**美伊戰後 firm power 第五選擇 anchor**：跟 [[Constellation Energy]] 核電 22 / [[Vistra]] 23 氣電+核電 / [[GE Vernova]] 22 變壓器+燃氣輪機 / [[Bloom Energy]] 19 SOFC 並列 [[AI infra 電力戰場]] 第五選擇——**美國 LNG 出口 anchor 是 hyperscaler 歐洲 / 日韓 / 新加坡 / 印度海外資料中心 firm power 上游**、跟核電 / 氣電（境內）形成「**境內 firm power + 境外 LNG firm power**」雙層完整覆蓋；五軸 **22/25**（路線 5 + 站別 5 + 耗材 4 + IP 4 + 客戶分散 4）= 跟 [[Constellation Energy]] 22 / [[GE Vernova]] 22 / [[Eaton]] 22 / [[Schneider Electric]] 22 / [[Hitachi]] 22 anchor tier 同分。

## 2. 三層 thesis

### 產業層

- LNG 產業 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - 戰前 consensus（錯誤）：Oxford Energy 預測 2027 supply glut **260 億立方公尺**過剩、市場 price in over-supply
  - 戰後（美伊戰爭後）物理現實：**Qatar Ras Laffan 受損 -17% 產能**（修復 3-5 年）+ Qatar 擴產計畫凍結 → 2030 累積缺口 **1,200 億立方公尺**
  - **5 個不可逆結構轉變**（[[FOMO SOC KP #46 — LNG 能源結構重塑（美伊戰後五大不可逆轉變）]]）：
    1. **油價地板墊高**：USD $80-90/barrel + 風險溢價 $10+（vs 戰前 $65-70）
    2. **Hormuz 海峽過運保險費 8x 戰前、不可逆**
    3. **伊朗 / Qatar 能源產能物理性下降**：Ras Laffan -17%、修復 3-5 年
    4. **核能政治翻身**：對接 firm power 第一選擇 anchor
    5. **中東能源重組**：UAE 退 OPEC、Hormuz 繞路基建（沙紅海港 + UAE 富查伊拉港）
- AI 數據中心放大訊號：
  - hyperscaler 歐洲 / 日韓 / 新加坡 / 印度資料中心 firm power 缺口
  - vs 境內核電 / 氣電 → 海外 LNG 缺口被結構性放大、跟 [[AI infra 電力戰場]] 同步
- 美國 LNG 出口三波：
  - **第一波**（2016-2022）：Cheniere 出口先發、歐洲 / 亞洲緩慢轉向 LNG
  - **第二波**（2022-2024）：俄烏戰後歐洲被迫向美國買 LNG、美國 LNG 出口爆炸式增長
  - **第三波 ⭐**（2025-2030）：美伊戰後 + AI 海外 hyperscaler firm power + Qatar 修復延宕 → 結構性供需逆轉、Cheniere 是最大受惠者
- 對應 [[AI infra 電力戰場]]：**第五選擇 firm power anchor**（境外擴展）
- 對應 [[宋分 #20 — 能源結構性剛需]]**三標準全滿**：供給結構改變（5 個不可逆）+ Cheniere CapEx $20B+ + SPA 20 年現金流鎖死
- 對應 [[控制點轉移（投資版）]]：**美國 LNG 從「價格接受者」→「價格制定者」**、Cheniere 作為美國 LNG 出口 #1 受惠最大
- 對應 [[Bottleneck Theory（瓶頸論）]]：**Hormuz 海峽 = 全球 1/5 石油 / 天然氣 chokepoint**、保險費 8x 不可逆 = chokepoint pricing 結構性 lock-in、Cheniere 是 chokepoint 規避者（美國 / 大西洋路徑、不過 Hormuz）

### 目的層

- **業務組合（2025 為主、2026-2028 Stage 3 ramp 後 mix 改變）**：
  - **SPL Stage 1-6（30 MTPA）+ CCL Stage 1-3（13.5 MTPA + Stage 3 ~10 MTPA pending）long-term SPA**：~70% 營收（含 IPM 中游 pipeline）
  - **Cheniere Marketing International（CMI）自營交易**：~25% 營收（短中期 spot + medium-term cargoes）
  - **Cheniere Energy Partners LP（CQP）48.6% 持股**：IDR 結構已 2017 收編、CQP 是 SPL 的 holding LP
- **核心產品 LNG**：
  - 液化天然氣（甲烷主導）+ 冷卻至 -162°C 體積縮 600x
  - 從 Henry Hub natural gas 採購 → 液化 train → LNG 船 → 全球出口
  - **D2DES（Delivered Ex-Ship）+ FOB（Free On Board）雙模式**：DES 是 Cheniere 負責運輸到買方港口、FOB 是買方負責船運
  - **定價公式 = Henry Hub × 115% + fixed liquefaction fee**（典型結構、20 年期限）
- **客戶結構**（hyperscaler 海外資料中心間接 anchor）：
  - **歐洲**：BP / Shell / TotalEnergies / Equinor / Naturgy / Galp（俄烏戰後加碼）
  - **亞洲**：CNOOC（中海油）/ KOGAS / JERA / PetroNet（印度）/ Vitol（trader）
  - **長期 SPA 占 ~80%**、剩餘 ~20% 是 CMI 自營 spot / medium-term
  - hyperscaler 間接連結：Cheniere LNG → 歐洲 / 日韓 / 新加坡電力公司 → hyperscaler 海外資料中心
- **2026-2028 重大催化**：
  - **CCL Stage 3 七 mid-scale trains ramp**（2026-2028 分批商業運轉、~10 MTPA 加上去）
  - **SPL Expansion**（Sabine Pass Liquefaction Expansion Project pending FID）
  - **Corpus Christi Stage 4-5 long-term planning**
- 商業模式核心：
  - **「美國 LNG 出口 #1 + SPA 長約 80% + 兩大廠地理分散 + Henry Hub +115% 公式 + 20 年現金流」**
  - **規格控制權**：標準化 LNG train（每 train ~4.5-5 MTPA）+ Henry Hub 採購公式 + 美國 Jones Act 不適用（LNG 船國際標）
  - **服務 recurring**：SPA 20 年合約 = 長期現金流鎖死（vs SBOM 一次性）
  - **地理分散護城河**：Sabine Pass Louisiana + Corpus Christi Texas 兩大廠 = 颶風 / 政治 / 法規分散
- 對應 [[賣水人選股邏輯（投資版）]]：**LNG 出口 anchor + 賣水人之中的賣水人**（不押 hyperscaler 誰贏、押**所有 hyperscaler 海外資料中心都需要 firm power**）
- 對應 [[控制點轉移（投資版）]]：拿到「**LNG 液化規格 + Henry Hub 採購公式 + 20 年 SPA 鎖定 + 兩大廠地緣分散**」四段控制點

### 供應層

- 跟 [[NVDA]] / hyperscaler 路線：**間接綁定**（不直接賣 NVDA / hyperscaler、賣給歐洲 / 日韓電力公司 / utility → 為 hyperscaler 海外資料中心發電）
  - Cheniere LNG → 歐洲 (TotalEnergies / Shell / BP) → 歐洲電力公司 → AWS Frankfurt / Azure Dublin / Google Belgium
  - Cheniere LNG → JERA / KEPCO → 日韓電力公司 → AWS Tokyo / Azure Singapore / Google Tokyo
- 跟 hyperscaler 海外資料中心連結（**2026-2030 結構性放大**）：
  - **AWS / Azure / Google / Meta** 歐洲擴張 + 日韓擴張 + 印度擴張 + 新加坡擴張
  - **LNG anchor 第五選擇**：歐洲 / 日韓 / 新加坡資料中心無核電復役選項（vs 美國境內 CEG TMI / VST Comanche Peak）、LNG 是即時 firm power 主力
  - Qatar -17% 缺口 → 美國 LNG 出口接管缺口 → Cheniere 受惠最大
- 跟 [[Constellation Energy]] / [[Vistra]] / [[GE Vernova]] / [[Bloom Energy]] 對比（**firm power 五選一**）：
  - **CEG**：核電 + Calpine 氣電、規模 60GW+、**境內 baseload 純度勝**、需 PPA 直接鎖
  - **VST**：核電 + 氣電 + retail + 跨三 ISO、規模 41GW、**境內地緣分散勝**
  - **GEV**：變壓器 + 燃氣輪機，**設備供應商角色**、不持有電廠
  - **Bloom**：SOFC 分散式 firm power、**快速部署 + 跳電網瓶頸**、境內 niche
  - **Cheniere**：**境外 LNG 出口 anchor + hyperscaler 海外資料中心 firm power**、地理擴展戰場
  - → **不是零和、是地理互補**：CEG / VST / Bloom / GEV 是境內 firm power 鏈、Cheniere 是境外 firm power 鏈
- 跟 [[Sempra LNG]] 對比（**LNG 出口雙頭**）：
  - **Cheniere LNG**：**美國 LNG 出口 #1（50%+）+ pure-play 出口商 + SPL + CCL 兩大廠 + SPA 80% 長約**
  - **Sempra**：**LNG #2 + Cameron LNG 50.2% + Port Arthur + 整合 Sempra Energy（utility）多元 + ECA LNG（Mexico）**
  - → Cheniere 是 pure-play / Sempra 是 utility 母公司含 LNG 子段、不同曝險度
- 跟 [[Cameron LNG]] 對比（**reference only / 非投資標的**）：
  - Cameron LNG 是 Sempra Infrastructure 50.2% 持股 + Total 16.6% + 三井 16.6% + 三菱 16.6% 合資、**非獨立上市**
  - Cheniere SPL + CCL 是獨立 Cheniere 100% 持股、結構更乾淨
- 跟 [[Tellurian]]（→ Woodside Driftwood LNG）對比（**reference only / 已被 Woodside 收購**）：
  - Tellurian 2024 被 Woodside Energy（澳洲 LNG）以 USD $1.2B 收購、改名 Woodside Driftwood LNG
  - Driftwood LNG Texas 27.6 MTPA（4 phases）= 仍是美國本土廠、但澳洲股東主導
  - Cheniere 是 100% 美國股東 / 美國上市的 pure-play、結構性 sovereign 風險不同
- 跟 Qatar Energy / QatarEnergy LNG（**全球 LNG 出口 #1 競爭者**）：
  - Qatar 全球 LNG 出口 #1（77 MTPA、~22% 全球）vs Cheniere 美國 #1（45 MTPA、佔美國 50%+）
  - 美伊戰後 Qatar Ras Laffan -17% + 修復 3-5 年 → Cheniere 接管缺口受惠
- 跟 ExxonMobil / Shell / TotalEnergies LNG integrated majors 對比：
  - 整合石油大廠 LNG 業務是 mix-and-match（上游 + 下游 + LNG），Cheniere 是 pure-play LNG 出口商、純度勝
- 護城河：
  - **物理資產**：Sabine Pass + Corpus Christi 兩大廠 ~45 MTPA、複製 8-10 年 + USD $20-30B CapEx
  - **SPA 20 年長約 ~80%**：客戶 BP / Shell / Total / Equinor / 中海油 / KOGAS / JERA / PetroNet 全球分散
  - **Henry Hub +115% 公式**：天然氣成本 + 固定 liquefaction fee = 上游氣價波動 pass-through 給買方、Cheniere 利潤率穩定
  - **規模 + 製造 know-how**：12 年 LNG 出口運營經驗、SPL Train 1 2016-02 首次出口（美國 lower 48 historically）
  - **地理分散**：Louisiana + Texas 兩州、颶風 / 政治 / FERC 法規分散
  - **政治紅利**：Trump 政府支持化石燃料 + LNG 出口、批准新 LNG 出口許可（Biden 政府 2024-01 凍結後 2025 解凍）
- 風險：
  - **天然氣價格波動**：Henry Hub 暴漲（如 2022 $9+ USD/MMBtu）影響 Cheniere 自營交易 spot 利潤、但 SPA 長約 pass-through 給買方
  - **LNG spot 價暴跌**：若 Qatar 修復快於 3-5 年 / 美國新廠擴產過快 → spot LNG 價暴跌、CMI 自營利潤受壓
  - **SPA 客戶違約**：歷史上罕見、但中海油 / 國有 utility 政治風險
  - **FERC 法規調整**：美國 LNG 出口許可審批週期 + 環評要求
  - **Biden 政府 LNG 凍結重現**：2028 政權更替 / 進步派環保政策可能再凍結
  - **歐洲再生能源加速**：歐洲若加速 wind + solar + 儲能 → LNG 中期需求下修
  - **CSP 自建氣電**：CSP 直接買 hyperscaler 自建氣電 / LNG terminal 規避中介商
  - **颶風 + 氣候風險**：Sabine Pass + Corpus Christi 兩廠都在墨西哥灣颶風走廊
  - **CCL Stage 3 ramp 延宕**：七 mid-scale trains 工程風險
  - **Qatar Ras Laffan 修復快於預期**：3-5 年估算可能下修
  - **替代燃料**：氫氣 + 氨氣 + SOFC 分散式 firm power 中長期取代部分 LNG 需求
