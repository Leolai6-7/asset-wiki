# 南電（8046.TW）

## 1. 一句話定位

**ABF 載板第二大 + 高階交換器 / 1.6T 800G 載板隱形龍頭**（IC 載板 占營收 85%、ABF 占 50-55%、BT 占 30%）、ASIC 三巨頭客戶綁定極深（[[AVGO]] + [[AMD]] + Marvell **合計 60% 營收**），ASIC 路線是公司核心引擎；在 [[ABF 載板 vs 玻璃基板 displacement]] 的命運最初被看「純受害」，但 2026 後事實校準：**Vera Rubin 仍走 CoWoS-L + ABF**、ASIC 玻璃化進度 2027-2028 才開始 → 南電在 2026-2027 是「**最大 ABF 受惠者**」，2028 後才面對玻璃化考驗。

## 2. 三層 thesis

### 產業層

- ABF 載板 [[市場四階段：懷疑／驗證／共識／反轉]] 在「驗證 → 共識」中段加速
  - 大摩 NYPCB EPS 2025-2028 CAGR **113%**（三雄最高）
  - 外資（部分）目標價曾喊 1,115 元
  - ABF 2028 缺口 35% / 2030 缺口 42%
- 800G / 1.6T 高階交換器載板**市佔 >70%**（隱形龍頭）= 跟 CPO/光通訊週期同步
- 與 [[玻璃基板與 FOPLP 賽道]] 的關係：**最複雜**——一面 Tomahawk 6/7/8 走 [[Broadcom]] + Toppan 新加坡玻璃線、一面 NVDA Rubin 仍走 CoWoS-L 矽橋 + ABF
- 在 [[ABF 載板 vs 玻璃基板 displacement]]：原 thesis「純受害」**已被校準**——2026-2027 是受惠週期、2028 後才面對 ASIC 玻璃化

### 目的層

- 主業 mix（2025-2026）：
  - **IC 載板 = 85%**：ABF 50-55% + BT 30%
  - **網通應用比重 49%**（AI 伺服器 + 800G 交換器升級）
  - **網通 ABF substrate（高階交換器）**：占產品組合 65-70%
  - **AMD CPU/GPU substrate**：占 ~15%
- **AI ASIC 集中綁定**：[[AVGO]] + [[AMD]]（含 Xilinx）+ Marvell **合計 60% 營收**
  - 也參與 [[AMZN]] Trainium / [[Meta]] MTIA / [[Microsoft]] Maia 自研 ASIC
- 高階 ABF 載板占南電營收：2025 H1 **<20%** → 2027 **>40%**（翻倍以上）
- 2026 800G 載板比重預估 7%（小但 ASP/margin 高）
- 商業模式：高階 ABF + 高階交換器專業戶（非長約客戶多 = 漲價傳導快）
- → 跟 [[賣水人選股邏輯（投資版）]]：是 ASIC 自研時代的隱形賣水人

### 供應層

- 跟 [[NVDA]] 路線：Vera Rubin 仍走 **CoWoS-L（矽橋中介層）**、Rubin Ultra 因 yield 縮成 dual-die；**南電 Rubin 載板放量 2026 H2 開始、2027 Q1 量產**
- 跟 [[AVGO]] 路線：Tomahawk 7-8 開始玻璃化（Broadcom + Toppan 新加坡 / 日本玻璃合資線）= **南電中長期 ASIC 玻璃化曝險**
- 跟 [[AMD]] EFB 體系深度合作（2026-2027 在台百億美金擴產欽點供應商）
- 玻璃基板對應策略：**研發樣品已做出、但卡在雷射槽孔 + 穿孔電鍍**
  - 自建研發樣品中、增層端材質需重做
  - 2026 = 小量試驗送樣、2027-2028 放量
  - 落後欣興（欣興已 3 月通過 Intel sample 一階驗證）
- 客戶集中極高、Bargaining power 隨 ASIC 客戶分散度上升
- 護城河：800G/1.6T 高階交換器**寡占** + 非長約 = ASP 漲價傳導快
- 風險：押 ASIC 三大客戶（AVGO/AMD/Marvell）= 任一家轉玻璃 → 直接被切
- → 連 [[控制點轉移（投資版）]]：南電拿到的是 ASIC 高階載板「中間層」控制點，但**沒拿玻璃下一階段**

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ 800G/1.6T 寡占 + AI ASIC 三巨頭綁定 |
| 毛利率 | ⚠️ **15.85% 仍低**（vs 欣興 ~25%+）= 仍在第 2 層損益表復原 |
| OpEx | ⚠️ CapEx 強度高、折舊壓力遞延 |
| 營業利益 | ✅ Q1 OP YoY +534% = 營業槓桿開始作用 |

→ **Re-rate 三角形 2/4 滿**——買的是「ASIC 載板高速放量 + 800G/1.6T 寡占」，但毛利率還沒回到歷史高峰、PE 已先 price in。

### ✅ 催化

- 2026 Q2-Q4 ABF 漲價週期延續、價格 +15-20%
- **NVDA Vera Rubin 仍走 CoWoS-L + ABF（不轉 CoWoP）= 南電 NVDA 線繼續吃**
- 2026 Q4 Rubin R100 sample、2027 Q1 量產 = 南電 NVDA 載板正式 ramp
- ASIC 三巨頭 2026-2027 全面放量（Broadcom $300 億 AI 訂單能見度到 2028）
- 高階交換器 800G/1.6T → CPO 升級
- AMD EFB 體系欽點、AMD 在台百億美金擴產
- IBIDEN 擴產 = 整體 ABF 需求 anchor
- 大摩 EPS 2025-2028 CAGR 113%（三雄最高）

### ⚠️ 風險

- **Forward PE 100+ 倍**——估值已 price in 多年漲價、ramp 延後 → 重 de-rating
- 毛利率 15.85% 仍低，需要漲價 + mix 改善才能進入「毛利率擴張」階段
- 玻璃基板研發**落後欣興 + IBIDEN**（樣品做出但卡製程）
- ASIC 客戶玻璃化路徑：
  - Broadcom Tomahawk 8 走玻璃 = 中長期 ASIC 載板被切
  - AVGO + AMD 任一家 ASIC 玻璃化 → 60% 營收曝險
- **客戶集中度高**（前三大 60%）= 任一家轉走風險 binary
- T-glass 缺料對 BT 載板影響
- NVDA Rubin 量產可能因 HBM4 延遲（高階 dual-die yield）

## ⭐ Displacement 風險評估

| 維度 | 評估 |
|---|---|
| 高階 ABF 被切（AI ASIC 玻璃化） | ⚠️⚠️ **中高**——AVGO Tomahawk 8 走玻璃 + 60% 營收押 ASIC |
| 中階 ABF 守住（伺服器 CPU / HPC） | ✅ 受惠——但中階非南電強項 |
| 自己轉玻璃機會 | ⚠️ **較弱**——研發樣品有但落後欣興、無 Intel design partner 位 |
| 客戶轉走風險 | ⚠️⚠️ **較高**——ASIC 玻璃化路線啟動後南電是 displacement 主受害者 |

→ Displacement 總體：**短期受惠（2026-2027）/ 中期受害（2028+）**

> **Thesis 校準（vs concept 內預測）**：concept 內「純受害？取決於 NVDA 路線」**已部分翻案**——Vera Rubin Q4 2026 sample、2027 Q1 量產，**南電 NVDA 載板在 2026-2027 是受惠**；但 ASIC 玻璃化路線（Tomahawk 8 + AMD/Marvell 跟進）會在 2028 後切走 ASIC 高階 ABF TAM = **「短期 ABF 王者、中期 displacement 主受害者」**。
