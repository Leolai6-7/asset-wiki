# Ayar Labs（私人公司 / 未上市 / NOT-INVESTABLE）

## ⚠️ Public/Private 確認（2026-06-08）

**Ayar Labs 仍是私人公司、未上市、不可直接投資**：
- **2026-03-03** 完成 **Series E $500M 融資**（Neuberger Berman 領投、NVIDIA + AMD + ARK Invest 跟投）= 估值 **$3.75B**、累計融資 $870M
- **2026-06-02** 公告加入 **NVIDIA NVLink Fusion ecosystem**（partnership、不是 acquisition）
- ⚠️ **網路有傳「NVDA $6.5B 收購 Ayar Labs 2026-05」是錯誤訊息** —— 經多源交叉驗證、SEC 8-K 確認 = NVDA 仍以**投資人 + 生態合作**形式參與、Ayar Labs 仍獨立經營
- 之前 [[Marvell]] entity「NVDA 收 Ayar Labs $6.5B」+ [[POET Technologies]] entity 中的相同陳述**需修正**

## 1. 一句話定位（短 stub）

**矽光「optical I/O chiplet」純度首選**——TeraPHY optical I/O chiplet（8 Tbps 帶寬 + 10 ns latency + 16-wavelength SuperNova 光源）= **業界首發 UCIe 標準的 optical chiplet**、目標把光電轉換推進到 GPU / XPU 旁邊（in-package 矽光 I/O）；2015 創立（CEO Mark Wade + CTO Vladimir Stojanovic）、創業 11 年、累計融資 $870M、Series E 2026-03 $500M @ $3.75B valuation；**戰略投資人陣容**：NVIDIA + AMD + Intel Capital + GlobalFoundries + HPE + Lockheed Martin + ARK Invest = 矽光 chiplet 賽道**最受機構支持的純 play**；**2026-06-02 加入 NVIDIA NVLink Fusion ecosystem** = 與 NVDA 光學 + SerDes 技術全面兼容、CPO 進 rack-scale AI infrastructure；競爭對手：[[POET Technologies]]（整合 platform 端、規模較小）/ Lightmatter（光學運算）/ Celestial AI（被 [[Marvell]] 收）/ AVGO 自研。

## 2. CPO 戰場位置

Ayar Labs 在 CPO 圖譜的位置：

- **第 2 層 光引擎（chiplet 端）+ 跨第 5 層先進封裝 + 跨第 1 層 ASIC 整合**：
  - 不是整機光引擎（vs [[Lumentum]] / [[Coherent]]）
  - 不是整合 platform（vs [[POET Technologies]]）
  - **是「光 I/O chiplet」**：放在 GPU/XPU 旁邊的 in-package 矽光 I/O
- **TeraPHY chiplet 規格**：8 Tbps bandwidth + 10 ns latency + UCIe 標準 + SuperNova 16-wavelength laser
- **NVLink Fusion 兼容**（2026-06-02）：可進 NVIDIA AI rack-scale infrastructure

## 4. 為什麼 Ayar Labs 仍重要（即使不可投資）

- **NVDA 矽光路線圖的關鍵 design-in partner**：NVLink Fusion + CPO rack-scale = Ayar TeraPHY chiplet 直接進 NVDA AI factory
- **vs [[POET Technologies]] 競爭**：Ayar 是 NVDA 生態系 + 大客戶（HPE / Intel Capital / Lockheed），POET 是獨立 + 小規模 + 客戶集中度低 = **Ayar 規模碾壓 POET**
- **影響 [[Marvell]] thesis**：Marvell 2025 收 [[Celestial AI]] 是對抗 Ayar Labs 的策略動作
- **校準 [[NVDA]] 光化路線**：NVDA Spectrum-X Photonics + NVLink Fusion + Ayar Labs CPO chiplet = 三線並進
- **可作為 [[POET Technologies]] 投資的 sanity check**：
  - Ayar $3.75B Series E 估值（私人）vs POET $0.93-2.27B 市值（公開）
  - Ayar 11 年累積 + NVDA 大客戶 vs POET 同年 + Lumilens 小客戶
  - → POET 是「Ayar Labs 的窮人版替代品」、不應作為 anchor
