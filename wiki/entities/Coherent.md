# Coherent（COHR）

## 1. 一句話定位

**全球光通訊 + SiC 功率半導體「雙曲線」光引擎廠**——前身 II-VI Incorporated，2022 年收購舊 Coherent + 2019 年收購 Finisar（光收發器領導者）形成今天規模、2026-04 全面改名 Coherent Corp；做**光通訊（占 75%）= 1.6T transceiver 龍頭 + EDFA + pump laser + InP 雷射 die**、**SiC 功率半導體（占 25% Industrial）= 150mm/200mm 量產、300mm 平台 / 10kV MOSFET 切入 AI datacenter power**；Q3 FY2026 營收 **$1.81B（YoY +21%）**、Datacenter & Communications 子段 **YoY +41%**、是 [[CPO 供應鏈圖譜]] 第 2 層光引擎「**規模 + 多軌**首選」（vs [[Lumentum]] 純度首選）；2026-03-02 與 [[Lumentum]] 同日各拿 [[NVDA]] **$2B 戰略投資 + 多年購買承諾 + 未來雷射 / 光通訊產能優先權**；AI 訂單能見度延伸到 **2028**；12 個月股價 **+362%**（vs LITE +1,542%）。

## 2. 三層 thesis

### 產業層

- 光通訊 + 功率半導體**雙引擎**進入 [[市場四階段：懷疑／驗證／共識／反轉]] 不同階段
  - 光通訊：「**驗證 → 共識**」加速段（與 [[Lumentum]] 相同）
  - SiC 功率半導體：「**懷疑 → 驗證**」（AI datacenter 用 SiC 是 2026 新需求、剛從工業 + EV 擴展到 datacenter）
- 1.6T 模組需求 **2025 1.8M units → 2026 30M+ units**（17 倍增量）、NVDA 占 60%
  - Coherent 是**光收發器市場份額龍頭**（FY2025 營收 $5.81B、~25% 市佔）
  - COHR transceiver = II-VI + Finisar 整合的「**規模優勢**」
- SiC 市場 2026-2030 CAGR **21%（Yole）/ 14.66%（Mordor）/ 24.3%（Fortune）**
  - AI datacenter power 是新驅動（[[Wolfspeed]] / Coherent / STMicro / ROHM / SK Siltron **前 5 大占 ~50% 全球產能**）
  - 高壓 SiC（10kV）是 AI datacenter 配電 + 工業電力新需求
- DCI 賽道進入 [[Hyper Rail / Multi-Rail（光通訊整合技術）]] 過渡期
  - [[Ciena]] Hyper Rail 確定 **2027 部署**
  - [[Nokia]] 1830 GX Multi-Rail OLS **2026 H2** 出貨
- CPO（[[CPO 供應鏈圖譜]] 第 2 層）2026 H2 NVDA Spectrum-X Photonics 開始出貨

### 目的層

- 業務 mix（Q3 FY2026，2026-04 改新分段）：
  - **Datacenter & Communications = 75% 營收**（$1.36B、YoY **+41%**）：
    - 1.6T transceiver 出貨領導者
    - **800G / 1.6T / CPO 全面平台化**（OFC 2026 展示）
    - 6-inch InP 線（單 wafer 更多 die、單 die 成本低於 LITE）
    - **next quarter InP 產能 2 倍**、2027 年底再 2 倍
    - pump laser 全球前三（與 Lumentum / Furukawa 並列）
    - EDFA / 光放大器組件
  - **Industrial = 25% 營收**（$453M、YoY +2%）：
    - **SiC 功率半導體**（150mm/200mm 量產、300mm 平台、10kV MOSFET）
    - 工業雷射（laser welding、雷射切割、光刻系統）
    - Thermadite 散熱 / XPU cooling（SiC-based）
    - 半導體製程設備
- **「雙曲線」vs 「純度」對比**：
  - [[Lumentum]]：純光通訊曝險（~85-90% 純度）= **集中**
  - **Coherent：光通訊 75% + SiC 25%**（雙引擎）= **分散**
  - Leo 原 thesis 校準：「功率半導體發酵後 SiC 反而成優勢」**完全成立**——2026 SiC 從拖後腿變成第二曲線
- 客戶結構（vs [[Lumentum]]）：
  - **AI / 雲端**：[[NVDA]]（$2B 戰略、anchor + CPO 多年供應）、[[Microsoft]]、[[Meta]]、[[Google]]、[[AMZN]] 透過 transceiver 直接拿
  - **電動車 / 工業**：BYD、Tesla、博世、Infineon 二供（透過 SiC）= 與 LITE 完全不重疊的客戶
  - **半導體製程**：[[ASML]] EUV 光源 + 製程設備內部雷射 + KLA 檢測
  - = COHR 客戶**比 LITE 分散 2-3 倍**（多軌 hedge）
- 商業模式：
  - **整合 II-VI + Finisar + Coherent 三公司 IP + 規模**（vs LITE 純 InP）
  - 6-inch InP 大 wafer + 整合製造 = 規模成本優勢
  - SiC 從工業 → EV → datacenter 三軌切換
- → 連 [[賣水人選股邏輯（投資版）]]：**「光通訊 + 功率雙引擎賣水人」**
  - 不只押 AI 算力（光通訊）、也押 AI **配電**（SiC）
  - AI datacenter 兩條物理瓶頸（光通訊 + 配電）COHR 雙拿

### 供應層

- 跟 [[NVDA]] 路線：**2026-03-02 戰略投資 $2B（與 LITE 同日同額對倒）**
  - 非獨家、但含**多年購買承諾**（multi-billion）+ **未來雷射 + 光通訊產能優先權**
  - **CPO 多年供應協議**——COHR 是 NVDA Spectrum-X Photonics 第一代 CPO 模組主供之一
  - COHR + LITE 兩家綁定可能 **lock up 全球高階雷射元件供應至 2027**
  - SiC 部分：NVDA 與 Coherent 在 XPU cooling + 高壓配電合作（透過 300mm SiC + Thermadite）
- 跟 [[Ciena]] Hyper Rail / [[Nokia]] Multi-Rail：
  - 兩家光通訊 OEM 用 COHR transceiver + 光放大器組件
  - Ciena WaveLogic chipset 給 LITE / NeoPhotonics / Oclaro 製作 coherent 模組——COHR 自家 transceiver 與此分流（COHR 自有 ASIC + DSP 整合方案）
- 跟 [[AVGO]] Tomahawk / [[Marvell]] 路線：
  - COHR transceiver 給博通 / Marvell 交換 ASIC 配套
- pump laser / EML 競爭地位（vs LITE）：
  - pump laser 全球前三（與 LITE 並列龍頭）
  - **EML**：LITE 是 200G EML 唯一量產者、COHR 用 **6-inch InP 線追趕**
    - 單 wafer die 數更多、單 die 成本更低
    - 中長期可能反超 LITE（短期仍落後 1-2 季）
- transceiver 競爭地位：
  - **光收發器市場第一**（FY2025 $5.81B、~25% 市佔）
  - 1.6T 模組規模優勢 = 一旦 ramp 良率上來、單模組成本可低於 LITE
- SiC 競爭地位（vs Wolfspeed / STMicro / ROHM）：
  - 全球前 5（與 Wolfspeed / STMicro / ROHM / SK Siltron 並列）
  - **150mm/200mm thick epitaxy 量產（10kV 架構）**
  - **300mm SiC 平台**（AI datacenter 用、與 Wolfspeed 競爭）
  - Wolfspeed 300mm 已**單 crystal wafer 量產**（2026-01）
  - COHR vs Wolfspeed：Wolfspeed 純 SiC 龍頭、COHR 是光通訊主業 + SiC 第二曲線（多元 hedge）
- 護城河：
  - **整合規模**（II-VI + Finisar + Coherent 三公司 IP + 製造）
  - **跨光通訊 + SiC 兩條獨立物理路徑**（AI 算力 + 配電）= 反脆弱
  - 6-inch InP 大 wafer 規模 + 良率
  - NVDA $2B 戰略 + AI 訂單能見度 2028
- 風險：
  - **整合複雜度**（三家公司 IP / 文化 / 製造 / 客戶結構整合仍進行中）
  - **EML 短期落後 [[Lumentum]]**（200G EML 唯一量產者是 LITE）
  - SiC 端 [[Wolfspeed]] 300mm 已先行（2026-01 量產）
  - Industrial 段（25%）僅 YoY +2% = 工業雷射 / 半導體製程設備拖後腿
  - SiC 行業 oversupply 風險（中國 SiC 廠擴產）
  - **Forward PE 44-49 + 12 個月 +362%**——估值已 price in 多年 ramp + 雙曲線完美執行
- → 連 [[控制點轉移（投資版）]]：拿到「光收發器市場第一控制點 + SiC 雙曲線 hedge」、未拿 200G EML 純 die 控制點（LITE 拿）

## ⭐ 對 [[CPO 供應鏈圖譜]] 第 2 層的意義（光引擎）

COHR 在 CPO 第 2 層的地位：

- **transceiver 模組層**：全球規模龍頭（~25% 市佔、FY2025 $5.81B）
- **InP 雷射 die 層**：6-inch 大 wafer、與 LITE 競爭中（短期落後 200G EML）
- **CPO 模組整合方**：NVDA Spectrum-X Photonics 第一代 CPO 主供之一
- **第 7 層雷射光源**：pump laser 全球前三（與 LITE 並列）
- **加分項：SiC 第二曲線**（與 LITE 完全不重疊的 hedge）

對 [[CPO 供應鏈圖譜]] 第 2 層的補強：
- COHR = 「**規模 + 多軌**首選」
- LITE = 「**純度 + IP**首選」
- 兩家是真正的 **2-3 家寡占**（vs 過去寫「光引擎誰贏不確定」）
- NVDA 同日同額投資兩家 = **戰略上「兩家都要、防 single supplier failure」**

## ⭐ 對台股 CPO 供應鏈的意義

對 [[SiTime]]（timing）、[[AVGO]]（交換 ASIC）、[[Marvell]]、[[TSMC]]：

**Bull case**：
- COHR transceiver 規模 + InP 產能 4x 擴張 → 1.6T 模組總量 ramp 順利 → [[SiTime]] timing 三倍 BOM 受惠
- COHR + LITE 兩家供應充足 → [[AVGO]] Tomahawk / Jericho CPO 模組順利出貨
- COHR SiC 300mm 進入 AI datacenter 配電 → 開拓 AI 第三軌道（配電半導體）
- COHR 美國產能政策（NVDA + CHIPS Act）= 抗中美技術脫鉤 → 台廠 CPO 設備鏈穩定

**Bear case**：
- COHR transceiver 規模優勢 + LITE 雷射 die 整合 → 模組層被吃掉
- 中國 Innolight 50-60% 市佔 + COHR 25% = 2-3 家寡占 → 台 OEM 模組廠（旭創、新易盛、海信）模組生意被擠壓
- COHR SiC 300mm + Wolfspeed 300mm → SiC oversupply 連帶影響台灣 SiC 廠（環球晶 / 漢磊）
- COHR + LITE 高度集中 NVDA → 整合度太高、上下游空間被擠壓

對 [[CPO 供應鏈圖譜]] 第 2 層的影響：
- 第 2 層光引擎 **2-3 家寡占成形**（LITE + COHR + 博通自研）= 不再是「誰贏不確定」
- 押法：LITE + COHR **一籃子**（兩家都受 NVDA 投資 + 都會吃到 CPO TAM）
- COHR 額外 hedge：SiC 第二曲線 = 即使光通訊 ramp 放緩、SiC 還能補
