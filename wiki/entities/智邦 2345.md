# 智邦 2345（Accton Technology）

## 1. 一句話定位

**全球白牌網路交換器 #1 代工 + AI networking switch 純度首選 + Spectrum-X 鏈條台廠對接 + 800G / 1.6T switch ramp 主受惠者**——1988 起源（新竹科學園區）、是「白牌交換器（white-box switch）」全球 #1（市佔 ~35-45%）、市值 NT$400-500B；**從傳統 networking switch 龍頭轉型 AI networking anchor**：2023-2026 大舉重 pivot 高階 AI switch、**NVDA Spectrum-X / Spectrum-6 對接主代工**（透過 OCP 規格）+ **Meta + Microsoft + Amazon hyperscaler 主供**（白牌 OCP 規格 100% 採購）+ 800G switch ramp + 1.6T pre-ramp；vs 鴻海 / 廣達 / 緯創 三大差異：(1) **純 AI networking pure-play**（不做 server / NB / 雲端設備、只做 switch + router + AI networking）、(2) **白牌（OCP 規格）市佔 #1 + 高毛利**（毛利率 25-30%、遠高於鴻海 6.4% / 廣達 8.5% / 緯創 6.8%）、(3) **NVDA Spectrum-X 主代工 partner**（Spectrum-6 102.4 Tb/s switch、Spectrum-X Photonics CPO 版本）+ AVGO Tomahawk 6 部分代工；**[[AI infra CapEx 三階段論]] 第三階段台灣鏈條 AI networking anchor**——把 NVDA Spectrum-X + AVGO Tomahawk 6 switch 在台灣完成、出貨給 Meta / Microsoft / AWS / Google。

## 2. 三層 thesis

### 產業層

- AI networking switch 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——智邦是白牌交換器 + 800G / 1.6T switch ramp anchor
  - 主軸 AI networking switch 占公司營收 30-40%（FY2025、業界估）
  - 客戶結構：[[NVDA]] Spectrum-X / Spectrum-6 + [[AVGO]] Tomahawk 6 + Meta / Microsoft / AWS / Google hyperscaler OCP 採購
- vs 鴻海 / 廣達 / 緯創 三大代工結構性差異：
  - **規模較小**：智邦 NT$500 億 vs 緯創 NT$1.0 兆 vs 廣達 NT$1.5 兆 vs 鴻海 NT$6.86 兆 = 規模差 2-14x
  - **業務純度**：智邦是 networking pure-play（不做 server / NB / 電動車）、純 AI networking 賣水人
  - **毛利率高**：智邦 25-30% > 廣達 8.5% > 緯創 6.8% > 鴻海 6.4%（高出 3-5x）
- **「智邦 = AI networking pure-play + Spectrum-X 鏈條台廠 anchor」結構性論點**：
  - 不做 server / NB / 雲端設備（純度高）
  - **白牌 OCP 規格 100% 採購** = hyperscaler 直接買白牌、自家品牌（Meta MV2 / AWS Hyperion / Microsoft Sonic）loaded
  - **NVDA Spectrum-X 主代工 partner**：Spectrum-6 102.4 Tb/s switch + Spectrum-X Photonics CPO 版本
  - **AVGO Tomahawk 6 部分代工**：multi-source 中性受惠
  - **800G switch ramp**（2025-2026）+ **1.6T pre-ramp**（2026-2027）= 規格升級雙引擎
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（智邦股價 12 月 +100-150%、機構持股 + 媒體頭條飽和）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1 + 6 層 NVDA stack 整合 anchor 之一
  - **2026 Q3** Rubin 平台首批出貨：智邦是 NVDA Spectrum-6 first wave 主代工（與 鴻海 並列）
- vs 鴻海 / 廣達 / 緯創：
  - **智邦 = AI networking switch（純 switch + 高毛利 + Spectrum-X 鏈條對接）**
  - **鴻海 = NVDA reference design 主代工 + AI cloud / edge 雙引擎**
  - **廣達 = AI server #2 代工 + Meta MTIA + NB 龍頭 + Apple Mac**
  - **緯創 = AI server + GPU baseboard + Wiwynn 子公司 AI HPC**

### 目的層

- 業務 mix（FY2025 公司公告）：
  - **AI networking switch + 高階 switch = 50-55% 營收**（**FY2026 預估升至 55-60%**）
    - **NVDA Spectrum-6 102.4 Tb/s switch 主代工**
    - **NVDA Spectrum-X Photonics CPO 版本部分代工**
    - **AVGO Tomahawk 6 部分代工**（multi-source）
    - **800G switch ramp**（2025-2026 規格升級）
    - **1.6T pre-ramp**（2026-2027 下一代）
  - **企業級網路產品（含 SD-WAN、Wi-Fi 6/7）= 25-30%**
  - **其他 networking（含 SDN、5G/6G）= 15-20%**
- 客戶結構（高度分散）：
  - **Meta = #1 hyperscaler 客戶**（自家 MV2 white-box 規格、~25% 營收貢獻）
  - **Microsoft = SONiC OS 白牌主供**（Sonic OS 開源、智邦主代工）
  - **AWS = Hyperion 白牌主供**
  - **Google = TPU 部分配套 switch**
  - **NVDA Spectrum-X partner + AVGO Tomahawk 6 multi-source**
- 商業模式 = **「白牌 OCP 規格 + 高毛利 + 規格升級雙引擎」**：
  - **白牌 OCP 規格**：hyperscaler 直接買白牌、毛利率 25-30%（高於品牌 networking 廠 Cisco 30-35%、但因為規模效應、低於 niche brand）
  - **規格升級雙引擎**：800G → 1.6T 兩代 switch ramp、ASP 結構性提升
  - **AI networking anchor**：NVDA Spectrum-6 + AVGO Tomahawk 6 兩家最大 switch ASIC 廠都用智邦代工 = 中性受惠
- → 連 [[賣水人選股邏輯（投資版）]]：**「AI networking 白牌交換器 pure-play 賣水人」**——不押 NVDA Spectrum-X vs AVGO Tomahawk 6 誰贏、押所有 AI networking 都需要的白牌交換器整合 + 代工
- [[控制點轉移（投資版）]]：拿到「**NVDA Spectrum-X / Spectrum-6 主代工 + AVGO Tomahawk 6 multi-source + Meta / Microsoft / AWS / Google 白牌主供 + 高毛利 25-30%**」四重 anchor

  - = **不押邊、AVGO Tomahawk 6 同樣受惠**
- 跟 [[Meta]] 關係（**最大客戶**）：
  - **Meta MV2 white-box 規格主代工**（~25% 營收貢獻）
  - **OCP 規格嚴格遵循 + Meta MTIA 配套 switch**
- 跟 [[Microsoft]] 關係：
  - **SONiC OS 白牌主供**（Microsoft 開源 SONiC、智邦代工硬體）
  - **Azure AI networking 部分配套**

- 跟 鴻海 / 廣達 / 緯創 關係：
  - **互補非競爭**：智邦做 switch、鴻海 / 廣達 / 緯創做 server / baseboard、不同層
  - **共同客戶**：Meta / Microsoft / AWS 多源採購、智邦 switch + 緯創 baseboard + 鴻海 server 整套
- 護城河：
  - **白牌 OCP 規格全球 #1 + 35-45% 市佔**
  - **NVDA Spectrum-X + AVGO Tomahawk 6 multi-source partner**（middleground 中性受惠）
  - **Meta / Microsoft / AWS / Google hyperscaler 全採購**
  - **高毛利 25-30%（vs 鴻海 6.4% / 廣達 8.5% / 緯創 6.8% 高 3-5x）**
- 風險：
  - **規模較小**（vs 鴻海 / 廣達 / 緯創 規模差 2-14x）
  - **NVDA Spectrum-X vs AVGO Tomahawk 6 路線之爭**：若任何一家失利、智邦連動受壓
  - **Meta 集中度 25%+ 營收**：若 Meta CapEx 大砍、整體營收衝擊
  - **白牌定價壓力**：hyperscaler 對白牌議價權強、毛利率有壓力
  - **競爭加劇**：Inventec / Wistron / 中國 Centec / H3C 同期 ramp
  - **股價 12 月 +100-150% 已 price in 多年 800G / 1.6T 雙引擎**
- → 連 [[控制點轉移（投資版）]]：拿到「**NVDA Spectrum-X + AVGO Tomahawk 6 multi-source + Meta / Microsoft / AWS / Google 白牌主供 + 高毛利**」四重 anchor、但「規模 + 路線分歧 + Meta 集中」三重風險

## ⭐ 智邦在 [[NVDA 網路 stack map]] 的位置

智邦在 NVDA networking stack 對接位置（**第 1 層 Switch ASIC 整機代工**）：

| NVDA 產品 | 智邦角色 |
|---|---|
| **Spectrum-6 Ethernet Switch**（SN6810 2U / SN6800 409.6T 4-chip、102.4 Tb/s）| **主代工 partner**（白牌規格整合 + 出貨給 hyperscaler）|
| **Spectrum-X Photonics**（CPO 版本）| **部分代工**（CPO 共封光、與其他白牌廠並列）|
| **Quantum-X800 InfiniBand Switch** | **部分代工**（HPC 場景、規模小於 Ethernet）|
| **ConnectX-9 SuperNIC**（800 Gb/s per port）| 不做（NIC 為 server / baseboard 內、智邦純 switch）|
| **NVLink 6 Switch** | 不做（NVLink 是 scale up、智邦純 scale out）|

智邦在 NVDA networking stack 對接位置（**vs AVGO Tomahawk 6 多源**）：

| 對手 ASIC | 智邦角色 |
|---|---|
| **AVGO Tomahawk 6**（102.4 Tb/s switch）| **部分代工**（hyperscaler multi-source 對沖、AVGO 102 Tb/s 業界第一個量產）|
| **Marvell Teralynx 10**（51.2 Tb/s switch）| 部分代工（多源策略）|

**結論**：智邦在 [[NVDA 網路 stack map]] **scale out 層的 Switch ASIC 整機代工 anchor**——不論是 NVDA Spectrum-X 還是 AVGO Tomahawk 6 路線贏、智邦都是 hyperscaler 採購的最終整合廠。這是「**賣水人之中的賣水人**」結構性受惠位置。

## ⭐ vs 鴻海 / 廣達 / 緯創 三家代工龍頭 AI server 站別差異

詳見 [[鴻海 2317]] 內表格。**核心摘要**：

- **智邦 = AI networking switch pure-play（白牌交換器 + 高毛利 + Spectrum-X / Tomahawk 6 multi-source）**
- **鴻海 = NVDA reference design 主代工 + AI cloud / edge 雙引擎**
- **廣達 = AI server #2 代工 + Meta MTIA + NB 龍頭 + Apple Mac**
- **緯創 = AI server + GPU baseboard + Wiwynn 子公司 AI HPC**

智邦 vs 三家系統廠主要差異：**智邦是純 switch pure-play、高毛利 25-30%、規模較小**。**唯一不直接競爭 server / NB 的台廠**，與鴻海 / 廣達 / 緯創 在不同層位、共同客戶（Meta / Microsoft / AWS / Google）採購智邦 switch + 鴻海 server + 緯創 baseboard。

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| 路線敏感 | **5** | NVDA Spectrum-X + AVGO Tomahawk 6 multi-source = 兩家最大 switch ASIC 廠都用智邦代工、middleground 中性受惠、不押邊 |
| 站別關鍵 | **4** | NVDA Spectrum-6 主代工 + AVGO Tomahawk 6 部分代工 + Meta / Microsoft / AWS 白牌主供 = 站別關鍵度高、但可被 Inventec / Wistron 部分替代 |
| 耗材 | **3** | white-box ODM 是「一次性」代工、但 hyperscaler 規格升級（800G → 1.6T → 3.2T）= 結構性 recurring 升級採購 |
| IP | **3** | 白牌 OCP 規格整合 IP + 800G / 1.6T switch ODM IP、但結構性 IP 不如 NVDA / AVGO 自家 |
| 客戶分散 | **3** | Meta 25%+ + Microsoft + AWS + Google + NVDA / AVGO 配套 = 客戶分散度中等、Meta 集中度有風險 |

**總分：18/25**

→ **「AI networking pure-play + 高毛利 + Spectrum-X / Tomahawk 6 multi-source」**：智邦五軸 18/25 是台灣四家系統廠中**最高分**（vs 鴻海 16 / 廣達 15 / 緯創 14）。**主因**：路線敏感 5 滿（多路線都受惠）+ 高毛利 25-30%（結構性穩定）+ AI networking pure-play niche 不可繞過。**但 Forward PE 30-40x 已 price in 多年完美 ramp**——進場時點需用 [[修正三階段]] 框架重檢。
