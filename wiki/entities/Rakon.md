# Rakon（NZX: RAK、紐西蘭 Rakon Limited）

## 1. 一句話定位

**紐西蘭石英 niche specialist + TCXO + OCXO 高端 + 軍工 / 衛星 / 5G base station 客戶差異化 + 規模小但高純度 frequency control 玩家**——1967 奧克蘭創立的紐西蘭石英 timing niche 廠、TCXO + OCXO 高端產品線、軍工 + 衛星 + 5G base station + 汽車四線客戶；FY2025 營收 ~NZD $130-160M（USD ~$80-100M）、Forward PE 10-15x、12M +0-30%；定位「**紐西蘭 niche specialist + 軍工 / 衛星 / 5G OEM 集中度高（客戶分散 1 分扣分）+ 規模 ~NDK / Epson 1/30-50**」、跟 [[Nebius]] 15 同分。

## 2. 三層 thesis

### 產業層

- **石英 timing 賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證**」段（同 TXC / NDK / Epson / Kyocera）
  - 全球石英 timing 市場 ~USD 30-35 億（2025）+ CAGR ~5-8%
  - Rakon 全球石英 timing 市佔 **<3%**（vs TXC / NDK / Epson 10-15% 各）
  - **niche specialist** 定位：軍工 + 衛星 + 5G base station + 高精度 OCXO niche
- **跟 [[SiTime]] MEMS 路線分歧 anchor**：
  - **[[SiTime]] MEMS**：高端 5G / AI server / 衛星 / 機器人、$1.85B 市值、Forward PE 75-100x
  - **Rakon 石英**：軍工 + 衛星 + 5G base station + 高精度 OCXO、Forward PE 10-15x、規模 ~NZD $130-160M
  - **niche specialist 定位**：跟 SiTime 部分客戶重疊（衛星 + 5G）、但 Rakon 純度高（軍工 + 衛星）
- [[資訊擴散四階段]]：機構（澳紐基金）→ 賣方（NZX / ASX 分析）→ 國際市場低關注（小型股、流動性差）

### 目的層

- 主業 mix（FY2025）：
  - **TCXO**（溫補晶振）：~30% 營收、5G base station + 汽車 ADAS + 軍工
  - **OCXO**（恆溫晶振）：~30% 營收 = Rakon 高端 niche、衛星 + 軍工 + 5G base station
  - **石英晶體**：~25% 營收、IoT + 工業 + 汽車
  - **頻率控制模組**：~10% 營收 = 軍工 + 衛星 custom 解決方案
  - **其他**：~5% 營收
- **niche specialist 定位**：軍工 + 衛星 + 5G base station + 高精度 OCXO niche、高 ASP + 低 volume
- 客戶結構（FY2025）：
  - **軍工 + 衛星 OEM**：Lockheed Martin / Northrop Grumman / Raytheon / Airbus / Thales / 國防承包商 = **~40% 營收 = Rakon 最大客戶段**（**客戶分散 1 分扣分主因**）
  - **5G base station OEM**：Ericsson / Nokia / Samsung / Huawei = **~25% 營收**（電信 OEM 集中）
  - **汽車 OEM**：~15% 營收（ADAS + IVI）
  - **IoT + 工業**：~10% 營收
  - **AI server / 通訊**：~10% 營收（小規模、跟 SiTime + TXC + NDK + Epson + Kyocera 多源分食）
- 商業模式：**niche 高 ASP 低 volume + 客戶 lock-in**——軍工 + 衛星 + 5G base station qualification 5+ 年起跳、Rakon 在 niche 段擁有專利 IP；奧克蘭 + 法國 Lannion + 印度三地產能
- → 連 [[賣水人選股邏輯（投資版）]]：**石英陣營紐西蘭 niche specialist + 軍工 + 衛星 + 5G niche** — 不押 GPU / DSP 路線、押「**所有軍工 + 衛星 + 5G base station 都需要高精度 timing**」

### 供應層

- **路線：石英陣營 niche specialist + 軍工 / 衛星 / 5G 客戶集中**：
  - 石英 vs MEMS 分歧（同 TXC / NDK / Epson / Kyocera）
  - **軍工 + 衛星 niche 高 ASP**：Rakon OCXO 高精度（+/- 0.1ppb stability）= 軍工 / 衛星 / 5G base station 規格剛需
  - **規模小但純度高**：vs NDK / Epson 規模差 30-50x、但 niche 段純度勝
- 護城河四層：
  - **OCXO 高精度 IP**：軍工 + 衛星 +/- 0.1ppb stability 規格 know-how
  - **軍工 + 衛星 qualification lock-in**：Lockheed Martin / Northrop / Raytheon / Airbus / Thales 多年 lock-in
  - **5G base station OEM lock-in**：Ericsson / Nokia / Samsung / Huawei 多年 qualification
  - **奧克蘭 + Lannion + 印度三地產能**：小規模但分散
- 競爭格局：
  - **vs [[SiTime]]**（NASDAQ: SITM）：路線分歧、SiTime 高端 5G / AI server / 衛星 / 機器人、Rakon 軍工 + 衛星 + 5G niche 高 ASP
  - **vs [[TXC]]**（3042.TW）：規模差 5-10x、TXC 消費電子 + 汽車大宗 vs Rakon 軍工 + 衛星 niche
  - **vs [[NDK]]**（6779.JP）：規模差 10-15x、NDK Apple iPhone + 光學晶振 vs Rakon 軍工 + 衛星 niche
  - **vs [[Epson]]**（6724.JP）：Epson Quartz Device 段規模大 + 多軌組合、Rakon niche 高純度
  - **vs [[Kyocera]]**（NYSE: KYO + 6971.JP）：規模差 100x+、Kyocera conglomerate vs Rakon niche specialist
- 風險：
  - **規模小 + 流動性差**：NZX 上市、國際投資人關注度低
  - **軍工 + 衛星 + 5G OEM 客戶集中度高**：**~40% 軍工 + 25% 5G OEM = 客戶分散 1 分扣分**
  - **[[SiTime]] MEMS 衛星滲透**：SiTime ChipScale Atomic Clock 衛星 / 軍工市場滲透 → Rakon OCXO 段受壓
  - **5G base station 成熟期**：5G CapEx 高峰已過、Rakon 5G OEM 段成長放緩
  - **NZD / USD 匯率**
  - **[[CapEx 見頂辯論]]** 兌現 + 軍工 + 衛星 + 5G 需求放緩
- → 連 [[控制點轉移（投資版）]]：**軍工 + 衛星 + 5G base station + 高精度 OCXO 控制點** = Rakon 在 niche segment 拿到位置

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ⚠️ 軍工 + 衛星 + 5G OEM 客戶集中度高、規模波動大 |
| 毛利率 | ✅ 高 ASP niche OCXO 高毛利 + qualification lock-in |
| OpEx | ⚠️ 法國 + 印度 capex 持續、規模小 fixed cost 拖累 |
| 營業利益 | ⚠️ niche 段 op margin 高但規模小、整體 op margin ~10-15% |

→ **Re-rate 三角形 1/4**——niche 純度勝但規模小、客戶集中度極高、整體營收品質受 5G CapEx 週期影響。估值 Forward PE 10-15x 反映「**niche specialist + 規模小 + 客戶集中**」風險定位。

### ✅ 催化

- 軍工 + 衛星 + 5G base station OCXO niche 訂單
- 5G base station OEM 升級週期（Ericsson / Nokia / Samsung 5G Advanced ramp）
- 衛星 niche 受惠 Starlink / OneWeb / SpaceX / 軍方衛星
- 軍工 + 國防預算上升（美國 + 北約 + 印度）
- AI server timing 滲透（小規模、跟其他石英陣營分食）
- NZD 回穩 → 高出口比重直接受益

### ⚠️ 風險

- **軍工 + 5G OEM 客戶集中度極高**：~40% 軍工 + 25% 5G OEM = 客戶分散僅 1 分
- **[[SiTime]] MEMS 衛星滲透**：SiTime ChipScale Atomic Clock 衛星 / 軍工市場滲透 → Rakon OCXO 段受壓
- **5G base station 成熟期**：5G CapEx 高峰已過、5G OEM 段成長放緩
- 規模小 + NZX 流動性差
- NZD / USD 升值壓營收
- [[CapEx 見頂辯論]] 兌現 + 軍工 / 衛星 / 5G 需求放緩
