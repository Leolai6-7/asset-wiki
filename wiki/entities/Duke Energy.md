# Duke Energy（NYSE: DUK）

## 1. 一句話定位

**美國最大 utility 之一（北卡 + 南卡 + 佛州 + 印第安納 + 俄亥俄 + 肯塔基六州 8.4M 電力客戶 + 1.6M 天然氣客戶）+ 核電 fleet 6 站 ~10GW（McGuire + Catawba + Oconee + Brunswick + Harris + Robinson）+ 30+GW 多元 fleet（核電 + 燃煤 + 氣電 + 太陽能 + 風電）+ AI 資料中心客戶（Google + Microsoft + AWS 北卡 + 南卡 + 佛州 ramp）**——總部 Charlotte NC、紐約證券交易所上市、市值 **USD ~$80-95B（Mega Cap）**；客戶覆蓋 **8.4M 電力 + 1.6M 天然氣 utility 客戶**；FY2025 營收 **USD ~$30-33B** + EBIT margin ~18-22%（utility-anchored 防守性勝）+ Forward PE **16-20x**（vs CEG 30-32x / VST 20-22x / TLN 22-26x 估值最便宜）；是 [[AI infra 電力戰場]] **第一層電力產生 + utility 區域 anchor**（vs CEG 純 IPP / PSEG niche utility）；核電 6 站 ~10GW 是「**utility-anchored 核電 fleet 規模 #2（次 CEG）**」+ AI 資料中心客戶間接受惠（北卡 + 南卡 + 佛州 data center hub）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - Duke 是「**utility 95% + 核電 baseload + 跨六州區域 anchor**」三軌組合
  - 跟 [[Constellation Energy]] 22 對照：CEG 純 IPP + 32.4GW 核電 + Calpine 26GW 氣電 + hyperscaler PPA、Duke utility 95% + 6 核電廠 ~10GW + 跨六州 utility = **utility 監管防守 vs 純 IPP narrative**
  - 跟 [[PSEG]] 19 對照：PSEG 新澤西 + 3.75GW 核電 niche、Duke 跨六州 + 6 核電廠 ~10GW 規模 = 跨六州規模勝
- 美東南 + 中西部電力市場：
  - **北卡 + 南卡**（Carolinas）：Charlotte / Research Triangle / Raleigh data center 集中區、Google / Microsoft / AWS 多個 data center
  - **佛州**（Florida）：Tampa / Orlando data center 區域、AWS 美東南 hub
  - **印第安納 + 俄亥俄**：中西部工業 + AI ramp
- 對應 [[AI infra 電力戰場]]：**第一層電力產生 + utility 區域 anchor（規模 #2 utility + 核電）**
- 對應 [[宋分 #20 — 能源結構性剛需]]：**部分滿足**（utility + 核電 baseload + AI 資料中心客戶間接受惠、但無已公開大型 hyperscaler PPA = 三標準滿足 2/3）

### 目的層

- 業務 mix（2025 為主）：
  - **Electric Utilities & Infrastructure（regulated electric）**：**~85-90%**（跨六州 8.4M 電力客戶）
  - **Gas Utilities & Infrastructure（天然氣）**：**~10-12%**（北卡 + 南卡 + 田納西 + 肯塔基 + 俄亥俄 1.6M 天然氣客戶）
  - **Commercial Renewables（已剝離 2023-04 - 太陽能 + 風電開發）**：~0%（已賣給 Brookfield）
- 核電 fleet（**6 站 ~10 GW**）：
  - **McGuire 1 + 2**（Carolinas、Duke 100% 持股）
  - **Catawba 1 + 2**（南卡、Duke 19-25% + South Carolina Electric & Gas 19-25% + multiple co-owners）
  - **Oconee 1 + 2 + 3**（南卡、Duke 100% 持股）
  - **Brunswick 1 + 2**（北卡海岸、Duke 100% 持股）
  - **Harris**（北卡、Duke 100% 持股）
  - **Robinson**（南卡、Duke 100% 持股）
  - **6 站合計 ~10 GW（vs CEG 32.4GW / PSEG 3.75GW）**
- 30+ GW 多元 fleet 組合：
  - **核電 ~10 GW（35%）**
  - **燃煤 ~7-9 GW**（逐步退場至 2035）
  - **氣電 ~10-12 GW**
  - **太陽能 ~7 GW**（北卡 + 佛州、美東南太陽能 #1）
  - **風電 + 儲能 ~1-2 GW**
- **AI / hyperscaler 直接客戶**：
  - 2025：~3-5%（北卡 + 南卡 + 佛州 data center 客戶間接 retail / wholesale）
  - 2030+：估算 ~10-15%（後續 hyperscaler PPA 簽約潛力 + retail 增量）
- 客戶結構：
  - **utility 客戶**（8.4M 電力 + 1.6M 天然氣 跨六州）
  - **AI 資料中心客戶**（Google + Microsoft + AWS 北卡 + 南卡 + 佛州 + 維吉尼亞外溢）
  - **無已公開大型 hyperscaler 20 年 PPA**（vs CEG 5,650MW+ / VST 2.6GW Meta / TLN 1.92GW AWS）
- 商業模式核心：
  - **utility-anchored 95%**（regulated + 監管收益穩定 + 低 beta）
  - **核電 fleet 規模 #2 utility-owned**（vs CEG IPP）
  - **跨六州區域分散**
  - **太陽能 + 風電 + 儲能多元組合**（Carolinas Carbon Plan 2050 淨零）
- 對應 [[賣水人選股邏輯（投資版）]]：**「utility 監管 + 核電 baseload + 跨六州」三軌**（vs CEG 純 IPP / PSEG niche utility）
- 對應 [[控制點轉移（投資版）]]：拿到「**utility 監管收益 + 核電執照 + 跨六州區域 anchor + AI 資料中心客戶 retail**」四段控制權

### 供應層

- 跟 [[Constellation Energy]] 對比（**utility vs 純 IPP**）：
  - **CEG**：32.4GW 核電 + Calpine 26GW + hyperscaler PPA 5,650MW+ = 規模 + IPP narrative
  - **Duke**：6 核電廠 ~10GW + utility 95% + 跨六州 utility = 防守性 + 估值乾淨
  - 規模差 3.2x（CEG 32.4GW vs Duke ~10GW）+ business model 完全不同（IPP vs utility）
- 跟 [[PSEG]] 對比（**utility 雙頭**）：
  - **PSEG**：3.75GW 核電 + 新澤西 niche utility + 海上風電 + Forward PE 18-22x
  - **Duke**：~10GW 核電 + 跨六州 utility + 太陽能多元 + Forward PE 16-20x
  - **Duke 規模 8.4M utility 客戶 vs PSEG 2.4M = 3.5x 規模勝**
  - PSEG / Duke 雙頭並列「**utility + 核電 anchor**」、Duke 規模 + Forward PE 略勝
- 跟 [[Vistra]] / [[Talen Energy]] 對比：純 IPP + hyperscaler PPA narrative、Duke utility-anchored 防守
- 跟 NextEra Energy 對比：NextEra 太陽能 + 風電 規模龍頭 + 跨州 utility、Duke 核電 fleet 第二大 utility-owned
- 跟 [[GE Vernova]] / Siemens Energy 關係：氣電 + 變壓器供應商
- 跟 [[Google]] / [[Microsoft]] / [[AMZN]] AWS hyperscaler 關係：
  - **北卡 + 南卡 + 佛州 data center 客戶 retail + wholesale**（間接受惠）
  - 但**無已公開大型 hyperscaler 20 年 PPA** = AI narrative 弱
  - Google + Microsoft + AWS 美東南 data center hub ramp = Duke 長期增長 anchor
- 護城河：
  - **跨六州 utility 監管收益**（穩定 ~95% 營收）
  - **核電 fleet 規模 #2 utility-owned**（~10GW）
  - **AI 資料中心客戶 retail + wholesale 間接受惠**（北卡 + 南卡 + 佛州 data center hub）
  - **Forward PE 16-20x 估值最便宜**（vs CEG 30-32x / VST 20-22x）
- 風險：
  - **無 hyperscaler 20 年 PPA = AI narrative 弱**
  - **燃煤退場進度**（2035 目標、跨六州監管推進不一）
  - **核電老化 uprate**（Oconee + Robinson 1970s-80s 建造、license 延長）
  - **跨六州 utility 監管風險**（Rate case 審核多州不同）
  - **政治風險**：2028 政權更替
