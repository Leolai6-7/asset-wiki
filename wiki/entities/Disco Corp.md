# Disco Corp（6146.JP）

## 1. 一句話定位

**半導體後段切割研磨設備幾近壟斷（60-70% 市佔）**——東京老牌（1937 創立）「賣水人之中的賣水人」；雷射隱形切割（Stealth Dicing）+ 砂輪切割雙王牌；CoWoS / 先進封裝量產期的最大設備受惠者。對 [[雷科]] 是**直接威脅** + **天花板**：Disco 任何擴張動作（厚板、玻璃、SiC）都會壓死台廠 niche 機會。

## 2. 三層 thesis

### 產業層
- 半導體後段設備 **dicing + grinding 全球市佔 60-70%**、整體後段設備市佔約 20%
- [[市場四階段：懷疑／驗證／共識／反轉]]：**共識階段**（已被市場認證的賣水人，本益比已反映）
- 切割設備 TAM 2026：USD 0.88B → 2031 USD 1.20B（CAGR 6.33%，平淡）
- 但 **AI/先進封裝爆發拉動單價提升**：CoWoS 月產能 2024 末 35K → 2026 末目標 130K（[[TSMC]]）→ Disco 是直接受益者
- Stealth Dicing 是 SiC、GaN 等脆性材料**標準工法**

### 目的層
- 真實角色：**雙軌主業**（資本設備 + 耗材）
  - 設備：dicing saw、grinder、polisher、laser saw（DFL7341 等）
  - 耗材：blade、grinding wheel（年金式現金流，本益比承受得起）
- 戰略：守住矽晶圓切割 + 趁先進封裝 ramp 賣更貴的 laser dicer + 切入新材料（SiC、GaN）
- **新動向**：2025-12 發表 **DFD6080 package singulation dicing saw**，明確支援 **resin substrate + glass substrate + lead frame** 多材料、1.8 kW 高功率 → **正式插旗玻璃基板切割**
- 跟 [[控制點轉移（投資版）]] 對應：拿到「設備 + 耗材 + 客戶 install base」三重控制點

### 供應層
- **賣水人原型**——不押路線、誰用什麼材料都要 Disco 設備
- 護城河三層：
  - **install base 鎖死**（全球 60-70% 切割設備市佔，工程師訓練、recipe library 都在 Disco 上）
  - **耗材年金**（blade/grinding wheel 持續消耗 → recurring revenue）
  - **Stealth Dicing 雷射隱形切割專利 know-how**（SiC、GaN 標準工法）
- 風險：(a) 估值已 price in、(b) 先進封裝若用非切割工法（如雷射打孔 + 化學蝕刻）會直接受傷、(c) 中國設備商低端替代

- FY2026 Q1 指引營收 +18% / 營業利益 +20%+

### ⚠️ 風險
- 估值高（已 price in 確定性）
- 中國本土設備商在低端 dicing/grinding 替代

- 日圓匯率波動
- 半導體景氣 cycle 反轉（雖然 AI 透支了 cycle 但仍是風險）

## ⭐ 對台廠的意義

### 對 [[雷科]]（雷射打孔 + 厚板切割路線）

**Bull case for 雷科**（Disco 留 niche 給雷科）：
- Disco 主力是**標準工法 SiC / GaN 切割**——若 Disco 守舊在矽晶圓 + SiC，**1mm+ 厚板切割 niche** 留給雷科（飛秒雷射 + 多製程整合）
- Disco 對 ABF 板廠（[[南電/欣興/景碩]]）→ AMD / NVDA 鏈不直接服務（雷科切的是 CoWoS interposer 段）
- Disco 估值已高、毛利率優先，**不會打價格戰搶 niche 應用**
- 雷科 TGV 雷射打孔切的是 **Disco 沒進的 step**（打孔 ≠ singulation）→ 短期無直接衝突

**Bear case for 雷科**（Disco 全面壓死）：
- **DFD6080（2025-12）已明確支援 glass substrate dicing**——這是 Disco **正式插旗玻璃基板切割**的訊號
- Disco 一旦把 DFD6080 系列推向 ABF 板廠 / TGV 客戶，**雷科厚板切割直接撞日系巨頭**
- Disco install base + 耗材年金 → 客戶 switching cost 極高
- 雷科市值 NT$122 億 vs Disco JPY 7.59T（NT$1.5 兆）= 體量差 1200 倍 → 任何正面對撞雷科死
- Stealth Dicing 是 SiC 切割**事實標準** → 雷科 SiC 飛秒切割成長性受 ceiling
- Disco 1.8 kW 高功率主軸新品 → 直接覆蓋雷科的「厚板切割」差異化點

### 最大威脅（Disco 對雷科）

**DFD6080 系列把 Disco 從「矽晶圓切割」延伸到「玻璃 + 樹脂多材料 package singulation」**——這是 **Disco 主動進攻雷科 niche** 的明確訊號（2025-12 發表）。雷科過去靠「日系不做的厚板雷射切割 + ABF 板鏈關係」站穩，若 Disco 用 1.8 kW 高功率主軸 + install base + 耗材鎖客戶，**雷科厚板切割 niche 會被擠壓**。binary 風險：雷科必須在 2026-2027 期間用 [[AMD]]/[[NVDA]] 認證鎖死 ABF 板鏈 design-in，否則 Disco 一旦進場就回不來。
