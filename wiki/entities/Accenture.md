# Accenture（ACN）

## 1. 一句話定位

**全球 IT 諮詢 + 系統整合 + 服務 #1（vs Deloitte / IBM Consulting / TCS / Infosys / Capgemini / Cognizant 五家分食）+ Anthropic 3 萬員工 Claude 訓練 FDE 戰略 anchor（KP41 Palantir Playbook 樣本）+ AI 賣水人之中的賣水人 + Fortune 500 + 政府 + 跨產業客戶完全分散**——1989 從 Arthur Andersen 諮詢部門分拆（原名 Andersen Consulting）、2001 改名 Accenture + 上市 NYSE、2009 改為 Accenture plc 註冊在愛爾蘭都柏林（稅務優化）；現任 CEO **Julie Sweet**（2019 接任、前法律顧問 + 北美 CEO）；員工 **~789,000**（vs Deloitte ~457,000 / IBM ~270,000 / TCS ~615,000 / Infosys ~336,000）= **業界規模最大**；業務組合：**Strategy 5-7% + Consulting 23-27% + Technology 35-40% + Operations 23-27% + Industry X（工業 AI / IoT）8-12%**；FY2025（August year end）營收 **~$65-70B**（YoY +5-8%）+ Forward PE **22-26x**（vs SaaS 30-90x / IT 服務 同業 18-25x 中段）+ 12 月 **+5-20%**（落後 NVDA + Cloud 三巨頭、估值未 re-rate）；五軸 **19/25**（路線 4 + 站別 4 + 耗材 5 諮詢年金 + IP 3 + 客戶分散 5 Fortune 500 + 政府 + 跨產業）；**AI 賣水人之中的賣水人** — 不押任何 AI 模型 / 任何 AI 應用、所有企業導入 AI 都要 Accenture / Deloitte / IBM Consulting；**KP41 FDE 戰略 anchor**：Anthropic + Accenture 多年合約訓練 3 萬員工使用 Claude = Accenture 變成 Anthropic 的「**外部 FDE 工廠**」、是 [[Forward Deployed Engineer 戰略（FDE）]] Palantir Playbook 三大規模化執行的「anchor 樣本」之一。

## 2. 三層 thesis

### 產業層

- IT 諮詢 + 系統整合賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——AI 帶來企業 IT 預算結構性放大（Accenture 自家研究估算 2026-2030 全球企業 AI / Data 服務 TAM 從 ~$650B → ~$1,500B）
  - **賽道分歧**：Strategy 諮詢（McKinsey / BCG / Bain）vs **IT 諮詢 + 系統整合（Accenture / Deloitte / IBM Consulting）**vs **印度 IT 服務（TCS / Infosys / Wipro / Cognizant）**
  - **Accenture 在三類中**：規模 #1 + AI 投入 #1 + 全球佈局 #1
- vs **Deloitte / IBM Consulting / TCS / Infosys 五家分食**三大結構性差異：
  - **規模 + 客戶分散**：Accenture 789K 員工、客戶 Fortune 500 ~95%+ AVL、政府客戶 250+ 國家機構、跨 13 大產業
  - **諮詢 + 技術 + 操作三軌整合**（vs 印度 IT 服務 ~70% 技術、Accenture 35-40% 技術 + 多軌平衡）
  - **AI 投入比例 + 速度**：FY2024 Accenture AI / GenAI 投入 $3B+（vs Deloitte ~$2B / IBM Consulting ~$1.5B），AI / GenAI 業務 ARR 預估 $4-5B（FY2025）+ +130% YoY
- **「AI 賣水人之中的賣水人」結構性論點**：
  - 不押 NVDA / AVGO / 任何半導體（不押半導體賽道）
  - 不押 [[Anthropic]] / [[OpenAI]] / Google Gemini / Meta Llama / DeepSeek（不押模型）
  - 不押 [[Snowflake]] / [[Databricks]] / [[Microsoft]] Fabric / AWS Bedrock（不押平台）
  - **所有企業導入 AI 都要 Accenture / Deloitte / IBM Consulting**（FDE + 數據治理 + 系統整合 + 流程改造 + 培訓 + 變革管理）
  - = **AI 應用層 chokepoint 的「人力 + 服務」維度**（[[Forward Deployed Engineer 戰略（FDE）]] 中介）
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 2-3（機構持股普及 + 估值未 re-rate = 仍在「驗證 → 共識」階段，散戶仍以「傳統 IT 服務」舊框架看 ACN）
  - **2024-09 Anthropic + Accenture 多年合約**：訓練 **3 萬員工** Claude 使用（KP41 anchor）
  - **2024-12 Accenture 中國新加坡公告 GenAI 業務 ARR 達 $1B**（YoY +200%）
  - **2025-09 Accenture 收購 BBHC + Cynozure + AI consulting boutique 多家**（補強 AI / Data 能力）

### 目的層

- 業務 mix（FY2025、August year end）：
  - **Strategy = 5-7% 營收**（最高毛利、戰略諮詢）
  - **Consulting = 23-27% 營收**（業務流程 + 變革管理）
  - **Technology = 35-40% 營收**（系統整合 + cloud 遷移 + AI / data）
  - **Operations = 23-27% 營收**（業務流程外包 BPO + managed services）
  - **Industry X = 8-12% 營收**（工業 AI + IoT + 數位孿生 + Engineering R&D 服務）
- 客戶結構（**極度分散**）：
  - **Fortune 500 ~95%+ AVL**（vs Snowflake 90%+、Accenture 客戶最深）
  - **Fortune 100 100% AVL**（無遺漏）
  - **Top 100 客戶 ~50% 營收**（集中度仍存）
  - **政府客戶 + 公部門 ~20% 營收**（含美國聯邦、英國、澳洲、加拿大、日本、新加坡、各州政府）
  - **跨 13 大產業**：金融、保險、零售、媒體、通訊、能源、化工、健康、製造、汽車、航太、政府、公部門 = 不押任何產業
  - **地理分散**：北美 ~50% + 歐洲 ~30% + 成長市場 ~20% = 全球佈局完整
- 商業模式 = **「諮詢年金 + 多軌 service 整合」**：
  - **長期 outsourcing 合約 5-7 年**（Operations + Technology managed services = recurring）
  - **AI / GenAI 訂閱式 service**（Cortex AI for clients、Accenture AI Refinery）
  - **每年 Top 客戶平均合約 $50-100M**（高 ACV）
  - **客戶 churn rate < 5%**（vs SaaS 同業 10-20% = 結構性 retention 領先）
  - **FY2025 bookings >$70B**（vs revenue $65-70B = book-to-bill 1.0-1.1x）
- → 連 [[賣水人選股邏輯（投資版）]]：**「AI 賣水人之中的賣水人」**——架構級「不押任何商業路線、所有企業導入 AI 都要 Accenture / Deloitte / IBM Consulting」、跟 [[Synopsys]] 24 + [[Cadence]] 22 + [[Imec]] 24 同等級「架構級賣水人之中的賣水人」哲學
- [[控制點轉移（投資版）]]：拿到「**Fortune 500 client lock-in + 政府客戶 + 跨 13 大產業 + 諮詢年金 5-7 年合約 + Anthropic FDE 工廠 anchor**」五重控制點
