# Palantir（PLTR）

## 1. 一句話定位

**Forward Deployed Engineer 戰略原型 + 10 年驗證 + 政府 + 商業雙引擎 + KP41 Palantir Playbook 原型（OpenAI / Anthropic 模仿樣本）+ AI Platform AIP 商業推動 + Re-rate 已 price in 估值警惕**——2003 起源（Peter Thiel + Alex Karp + Joe Lonsdale + Stephen Cohen + Nathan Gettings 五人創辦於 Palo Alto、CIA In-Q-Tel 投資 backed）、原為 9/11 後反恐情報平台、2020-09 直接上市 NYSE（DPO 不是 IPO）；現任 CEO **Alex Karp**（哲學博士、跟 Peter Thiel 史丹佛法學院校友、激進言論派）；業務組合：**Gotham（政府）~30-40% + Foundry（商業）~50-60% + AIP（AI Platform）2025 推升至 ~25-30%**；客戶 **政府 50% + 商業 50%**（美國聯邦 + 國防 + 情報 + Fortune 500 + 中型企業）；FY2025 全年營收 **~$3-3.5B**（YoY +30-35%）+ AIP launch 後 commercial ramp 加速；Forward PE **150-200x**（估值已 stretch）+ 12 月 +200-500%；五軸 **18/25**（路線 5 + 站別 4 + 耗材 4 + IP 4 + 客戶分散 1 政府 + Fortune 100 集中）；**「FDE 戰略 anchor + Palantir Playbook 原型」**：[[Forward Deployed Engineer 戰略（FDE）]] 概念的 10 年驗證原型、OpenAI Deployment Company + Anthropic + Accenture + Anthropic + Blackstone $15 億合資都是模仿 Palantir 模式；**Re-rate 已 price in、估值警惕**：12 月 +200-500% 股價爆漲、Forward PE 150-200x 已 price in 完美「Palantir Playbook」兌現 + 政府客戶持續放量 + AIP 商業 ARR 突破 $5B 等多年完美 ramp。

## 2. 三層 thesis

### 產業層

- 政府 + 商業 AI / data platform 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**共識 → 反轉**」加速段——12 月 +200-500% 已過機構持股 + 媒體頭條飽和、進入散戶 FOMO 階段
  - 政府客戶賽道：美國國防 + 情報 + 聯邦 + 國土安全 + 司法 + 各州政府 + 盟友政府（英國 NHS、烏克蘭軍方、Israel、Japan、Korea、Singapore）
  - 商業客戶賽道：Fortune 100 / Fortune 500 + 中型企業（自 2022 AIP launch 後 commercial ramp 加速）
- vs **「全棧 AI / data platform」對手**：
  - **vs [[Snowflake]] / [[Databricks]]**：Palantir Foundry 比兩家更深、含 ontology + AI agent + workflow + 部署整合 = 一站式（vs Snowflake SQL + 治理 / Databricks Lakehouse + ML）
  - **vs [[Accenture]] / [[Deloitte]] / IBM Consulting**：Palantir Foundry 是「**自家 platform + FDE 派駐**」（vs Accenture / Deloitte 純諮詢 + 系統整合）
  - **vs C3.ai / DataBricks 等其他 AI platform**：Palantir 10 年政府 + 國防客戶經驗 + 國土安全認證 + Top Secret clearance 結構性護城河
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 4-5（**共識 → 反轉**飽和 + 散戶 FOMO、ARK Cathie Wood 連續減持、ARK Trust 賣壓）
  - **2023-04 AIP launch**：AI Platform 第一次商業化 AI agent（Foundry 內建 AI workflow）
  - **2024-2025 商業 ARR 加速**：商業 ARR 從 ~$700M（FY2023）→ ~$1.5B（FY2024）→ ~$3B（FY2025E）= 100%+ YoY
  - **2025-09 Trump 政府 federal 訂單延續**（DOGE + 國防 + 國土安全 + 移民 ICE 應用）+ Trump 跟 Karp 公開支持
- **「FDE 戰略原型 + Palantir Playbook」結構性論點**：
  - **Palantir FDE 模式 10 年驗證**：派駐資深工程師至客戶現場、親自代碼實現端對端部署、解決系統整合 + 安全 + 合規「髒活」
  - **是 [[Forward Deployed Engineer 戰略（FDE）]] 的原型**：OpenAI Deployment Company + Anthropic + Accenture + Anthropic + Blackstone $15 億合資都是模仿 Palantir
  - **Palantir 股價長期 re-rate 樣本**：PE 從 30x → 200x、是「**Palantir Playbook**」估值 re-rate 的範本

### 目的層

- 業務 mix（FY2025、Q4 December year end）：
  - **Gotham（政府）= ~30-40% 營收**
    - 美國國防 + 情報 + 聯邦 + 國土安全 + 司法 + 各州政府
    - 結構性護城河（10 年累積 + Top Secret clearance）+ 高毛利
  - **Foundry（商業）= ~50-60% 營收**
    - Fortune 100 + Fortune 500 + 中型企業
    - 自 2023 AIP launch 後 commercial ramp 加速
  - **AIP（AI Platform）= ~25-30% 營收**（部分計入 Foundry 內）
    - 2023-04 launch、AI agent + workflow + 部署整合
    - 商業 ARR 加速 100%+ YoY
- 客戶結構（**極度集中**）：
  - **US Government Top 10 客戶 ~40-50% 政府營收**（DOD + CIA + ICE + DHS + FBI + Air Force + Navy + Marines + Space Force + NRO）
  - **商業 Top 100 客戶 ~70%+ 商業營收**（Wendy's + AIG + Cleveland Clinic + Stellantis + Airbus + BP + Citi 等）
  - **總客戶數 ~1,000+**（vs Snowflake 10,000+ / Accenture 跨產業數十萬）= **客戶數量結構性集中**
  - **AIP Bootcamp 加速企業 sample 滲透**：自 2023 AIP launch 後、2,000+ AIP Bootcamp 完成、加速商業 ARR 爆發
- 商業模式 = **「FDE + 自家 platform + 多年合約 + 用量計費 + AIP ramp」**：
  - **FDE 派駐 senior engineer 至客戶現場**（核心模式）
  - **Foundry + AIP platform 訂閱 + 用量計費**（recurring revenue）
  - **多年合約 5+ 年**（政府 + 大型企業）
  - **AIP Bootcamp 加速企業 sample → POC → production 升級**（**首批商業 ramp 飛輪**）
  - **客戶 LTV 結構性高**：Top 10 政府客戶 $50-100M/年、Top 100 商業客戶 $5-20M/年
- → 連 [[賣水人選股邏輯（投資版）]]：**FDE 戰略原型 + 政府 anchor**——不押任何 AI 模型、不押任何 cloud platform、押自家 FDE + Foundry + AIP 一站式整合
- [[控制點轉移（投資版）]]：拿到「**FDE 派駐 + Foundry / Gotham 30 年國防 / 政府客戶 lock-in + AIP 商業 ramp + Top Secret clearance 結構性護城河**」四重控制點
