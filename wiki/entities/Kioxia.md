# Kioxia（TYO: 285A / 鎧俠 / 原 Toshiba Memory）

## 1. 一句話定位

**全球 NAND #3（14% 市佔）+ Enterprise SSD 純度最高的 AI 受惠者 + 日本國家半導體最後一張牌**——2024-12-18 從 Bain Capital 私有化 6 年後 IPO 重返東京證交所 Prime Market（**1,455 yen → 2026-04 衝到 36,000 yen / 18 個月 +2,400%**），把「**BiCS 8（218-layer）量產 + BiCS 10（332-layer）2026 提前量產 + FY2025 營收 ¥2.34T / OP +95% 創新高 + Nikkei 225 納入 + Bain 仍 30% 大股東**」綁進同一個故事。在 [[AI infra 3D NAND 戰場]] 6 家分食的格局裡，Kioxia 是「**最 pure-play NAND**」——母公司沒有 HBM、沒有 HDD、沒有 DRAM 分散注意力，**100% 押 3D NAND + Enterprise SSD**，與 [[SanDisk]]（原 WD JV 夥伴 2025 分家後 reunion 在 HBF 標準化）+ Bain Capital 三方關係定義。跟 [[SK Hynix]]（HBM 主戰場 / Solidigm 是配角）和 [[Samsung Electronics]]（記憶體 + Foundry + 終端三條腿）不同，Kioxia 是 **AI Enterprise SSD pure-play 純度王**。

## 2. 三層 thesis

### 產業層

- **NAND BIG 6 排名**（Q1 2026 Counterpoint）：Samsung（29%）→ SK Hynix+Solidigm（22%）→ **Kioxia（14%）**→ Micron（13%）= SanDisk（13%）= YMTC（13%）
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」過渡期**——
  - 驗證已完成：FY2025 營收 ¥2.34T（YoY +37%）+ OP ¥876.2B（YoY +95%）創歷史新高、Q4 單季 OP ¥599B（QoQ +314%）、Bain 套現 $3.5B + Nikkei 225 納入
  - 共識未完成：18 個月 +2,400% 漲幅市場仍辯「景氣循環 vs 結構性」、Forward PE 仍 15-20x 區間（vs HBM 廠 40-60x）
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體 → ETF 配置進行中、Bain 減持為散戶接盤訊號（典型 [[散戶 vs 機構買股差異]] 階段 3-4 警訊）
- TAM：Enterprise SSD 市場 2024 181 EB → 2030 1,078 EB（CAGR 35%）；3D NAND 全市場 2026 USD 58.7B → 2031 USD 76B（CAGR 5.3%、但 Enterprise SSD 段拉到 35%）
- 黃仁勳 2026-06-08 定調「AI 記憶體結構性短缺」的**間接受惠**：NAND 雖非黃仁勳主推 anchor（HBM 才是），但 NVDA Vera Rubin ICMS 1,152TB/rack 直接帶動 NAND 需求

### 目的層

- 真實角色：**「日本國家半導體最後一張牌的 Enterprise SSD pure-play」**——不是「綜合記憶體廠」（vs Samsung / SK Hynix）、是「**純 3D NAND 製造商 + Enterprise SSD 純度最高的賣水人**」、靠「**BiCS CMOS bonded array 製程領先 + 規模二供之首**」拿到 Hyperscaler design-in
- 商業模式三段：
  - **Enterprise SSD**（成長引擎）：FY2025 Q4 營收 doubled QoQ、AI / cloud / enterprise customers 是主力、FY2026 Q1 outlook 持續上升
  - **Mobile / eMMC / UFS**（穩定）：Yokkaichi 廠 BiCS 8 218-layer 持續供應手機 BiCS 9
  - **Client SSD**（壓力源）：價格被 wafer 切走 wafer 到 Enterprise 自我擠壓、margin 反而上升
- 真實戰略：**「BiCS 路線+ JV 重組 + IPO 解放 + 美日聯盟 + Nikkei 225 收編」五重 catalyst 同步**——
  - BiCS 8（218L）2024 量產 → BiCS 10（332-layer）原 2027 提前到 2026 量產
  - 跟 WD（現 [[SanDisk]]）的 JV 2024-2025 解體後重建「**獨立 + 合作**」模式（HBF 標準化合作但製造獨立）
  - 2024-12-18 IPO 收 ¥118B / $800M、Bain Capital 持股從 ~60% 降至 <30%（仍最大股東）
  - 2026-06-01 TrendForce 報日美 NAND 聯盟 capex +40% YoY = Kioxia + SanDisk 同步擴產
  - 2025 H2 Nikkei 225 納入 → 被動買盤 anchor 加分
- [[控制點轉移（投資版）]]：拿到「**Enterprise SSD 製程定義權 + AI 推理 storage 標準參與權**」+「**日美 NAND 同盟核心地位**」

### 供應層

- **路線雙押**：BiCS 8（218L）+ BiCS 10（332L）+ HBF（與 SanDisk + SK Hynix 三方標準化）
- 護城河四層：
  - **製程護城河 CBA（CMOS Bonded to Array）**：CMOS 控制邏輯直接 bonded 到 NAND array、密度更高、效率更高（vs Samsung V9 string stacking）
  - **規模 + 客戶 lock-in**：Yokkaichi（Mie Prefecture）+ Kitakami（Iwate Prefecture）雙廠 + SanDisk JV 共用設備（90% 客戶分離）= 規模效應
  - **日美聯盟政治護城河**：Bain Capital 主導 2017 收購、美 Apollo + KKR 參與、美日政府視為「半導體最後一張牌」、CHIPS Act 友好
  - **IPO + Nikkei 225 加分**：流動性 + 被動買盤 anchor + 估值能見度
- 對 [[Samsung Electronics]] NAND 部門領先程度：**BiCS CBA 製程 vs Samsung V9 string stacking** = 製程哲學分歧（Kioxia 偏密度、Samsung 偏堆疊速度）
- 對 [[SK Hynix]] + [[Solidigm]] 領先程度：規模略小但**單顆 NAND 製程更先進**（BiCS 8 218L vs SK 238L V8）；HBF 合作鏈與 SanDisk 平行
- 對 [[Micron]] 領先程度：**規模 ~1.5x**（Kioxia 14% vs Micron 13%）、NAND 純度高得多（Micron HBM 才是主軸）
- 跟 [[SanDisk]] 關係：**「製造 JV 解體、市場合作重建」**——歷史上 Toshiba Memory + Western Digital BiCS 共投 fab、2024-2025 spin-off 後 SanDisk 從 WDC 分離、雙方在 HBF 標準化重建合作但製造線分離

### ⚠️ 風險

- **18 個月 +2,400% 漲幅**：[[資訊擴散四階段]] 階段 3-4、散戶恐怕已大量進場、回檔風險高
- **Bain Capital 還剩 ~30% 持股**：未來減持壓力 = 結構性 overhang（vs SK Hynix 國家持股穩定）
- **Enterprise SSD 仍週期屬性**：NAND 廠擴產追上時間表（2028 H2）+ Kioxia BiCS 11 / Samsung V10 / SK V9 全廠 ramp = 供給端可能 2028 H2 追上
- **缺乏 HBM 護城河**：純 NAND 在 AI infra 估值上輸 HBM 一個量級、Forward PE 拉不到 HBM 廠水準
- **客戶結構未充分揭露**：NVDA Vera Rubin ICMS 多少分給 Kioxia 仍未明、Hyperscaler 訂單能見度透明度低
- **跟 SanDisk JV 解體後合作邊界模糊**：Yokkaichi fab 共用設備、客戶分離 50/50、HBF 標準化合作但製造分離 → 競合關係複雜
- **HBF 取代 vs 互補**：若 HBF 在推理 server 真能取代部分 HBM → Kioxia 受惠；若 HBF 是 niche → Kioxia 仍保持「Enterprise SSD 純 play」軌
- **中國 YMTC 國產替代**：YMTC Q1 2026 已拿 13% 全球市佔、3-5 年內可能切 Enterprise SSD 中國市場
