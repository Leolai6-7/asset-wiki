# Lasertec（6920.JP / レーザーテック）

## 1. 一句話定位

**全球唯一 actinic（13.5nm、與 EUV 曝光同波長）patterned mask 檢測設備商——≤5nm 節點 actinic 檢測 ~100% 壟斷、EUV 光罩檢測整體 ~90% 市佔、ACTIS A150（2019 全球首發、單價 >$75M 市場推估）至今無第二家商用機（KLA 因 $500M 產業募資失敗棄做 APMI）**——東證 Prime、橫濱、輕資產（製造大量外包）、市值 ~¥4.0T（≈USD $25B）；FY2025（至 2025-06）營收 ¥251.5B（+17.8%）、OP ¥122.8B（+51.0%、margin 48.8%）；受注劇烈波動（FY2025 ¥105.2B → FY2026 guidance ¥200-240B）；High-NA 過渡：ACTIS A300（URASHIMA 高亮度光源）＋ A200HiT（2025-10 發布、推升 FY2026 受注）；12M 股價 **+183%**、PE（FY2026E）~55x——[[檢測賣水人 pattern（良率地獄賣檢測）]] 的**最強形態案例：檢測站本身變 chokepoint**（mask 沒過 actinic = 缺陷複製到每片 wafer = 不能上機）。

## 2. 三層 thesis

### 產業層

| 維度 | 內容 |
|---|---|
| 賽道 | EUV 微影良率地獄：mask 一顆 printable defect 複製到每片 wafer、上機後不可返修 → actinic 檢測 = 上機前最後篩選閘門 |
| 壟斷結構 | actinic patterned mask 檢測 **~100%（唯一商用機）**；EUV 光罩檢測整體 ~90%；廣義 EUV mask inspection 市場（含 e-beam／DUV 手法）KLA 約 34% 分食非 actinic 段 |
| 物理門檻 | actinic 需自製高亮度 EUV 光源（URASHIMA）——KLA 曾開發 APMI、因產業不願出 $500M 資金而中止、至今無量產品 |
| 結構性驅動 | 節點推進 → EUV 層數增加 + High-NA（薄吸收層、pellicle 困難）→ print-check 繞道越來越難、actinic 越來越必要（Photomask Japan 2025 共識方向） |
| 在 [[資訊擴散四階段]] | 第三→四階段：Bloomberg／賣方全面覆蓋、12M +183%、訂單復甦已是共識 |

### 目的層

- 真實角色：賣「**mask 上機資格認證**」——不押任何 fab／架構／晶片，只要有人用 EUV 就要過這一站；對應 [[Bottleneck Theory（瓶頸論）]] 的單點 chokepoint
- 產品線：ACTIS（patterned mask、營收主力）＋ ABICS／MATRICS（EUV blanks 檢測、de facto 標準）＋ FPD 光罩檢測＋ SiC 晶圓檢測（SICA）——非 EUV 佔比小
- High-NA 路徑：A300（2023-11 發布、新光學系＋URASHIMA、對應 High-NA 量產需求）→ A200HiT（2025-10-31 發布、throughput 大幅提升、現役 NA 與 High-NA 過渡通吃）
- 商業模式弱點：**機台一次性認列、無真耗材年金**——service 佔比約兩成（精確值待補）、受注因此劇烈波動

### 供應層

- 客戶集中（本檔最大結構性弱點）：**TSMC＋Intel＋Samsung ≈ 77% 營收**（Scorpion 引用揭露資料、FY2023-24 期）；Intel 為 High-NA 先鋒客戶、其 2024-25 capex 危機直接造成 FY2025 受注崩跌
- 其餘客戶：mask shop（Toppan／DNP／Photronics）＋ blanks 廠（Hoya／AGC）——家數多但金額小
- [[TSMC]] 特殊性：歷史偏好 wafer print-check 流程、actinic 採購保守（Scorpion 宣稱 TSMC 停購、未經獨立證實）→ TSMC 是否轉向大量採購 = 最大上行選項
- 競爭：[[KLA Corporation]]（Teron／eSL10、DUV＋e-beam、無 actinic）、NuFlare／Applied（Aera）／Zeiss／Hitachi High-Tech——皆為非 actinic 替代手法、靈敏度在 High-NA 世代受限

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| 路線敏感（逆向） | **3 / 5** | 押單一生態（EUV）＋單一方法論（actinic）：High-NA 延後／print-check 繞道是真實路線風險、FY2025 受注 -58% 為實證；但 EUV 本身已是無對手路線、層數成長對沖 High-NA 延期 |
| 站別關鍵 | **5 / 5** | actinic = 上機前最後閘門、~100% 壟斷、KLA 棄做證明門檻——檢測站即 chokepoint（pattern 最強形態） |
| 耗材 recurring | **3 / 5** | 無接觸式耗材、service ~2 成（推估、待補）；裝機基數成長中但機台一次性認列主導 |
| IP | **5 / 5** | 唯一商用 actinic 光學系＋自製 URASHIMA 光源＋30 年 blanks 檢測 de facto 標準；競爭者退出（KLA $500M 募資失敗）反向驗證門檻 |
| 客戶分散 | **2 / 5** | top 3 ≈ 77%、Intel 單一客戶 capex 決策即可令受注腰斬（FY2025 實證）；mask shop／blanks 客戶多而金額小 |

**總分 = 18 / 25（區間 18-19）**——⚠️ **低於 [[檢測賣水人 pattern（良率地獄賣檢測）]] 概念檔預估的 22-24、明確修正**：概念檔以「壟斷深度」（站別 5＋IP 5）外推總分，但五軸量的是賣水人位置的**韌性**——路線（單一生態）、耗材（無年金）、客戶（top3 77%）三軸把 Lasertec 拉到 [[Teradyne]] 級（19-20）之下、與鴻勁／致茂同帶。**壟斷強度全 wiki 最強 ≠ 五軸分最高**；對照 [[KLA Corporation]] 22/25（路 5 耗 4 客 3）：同為檢測、KLA 用廣度換韌性、Lasertec 用深度換波動。Thesis-dependent 上修路徑：TSMC 轉向大量採購 actinic ＋ High-NA 全面 ramp → 路線 4＋客戶 3 → 20-21。
