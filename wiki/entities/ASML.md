# ASML Holding N.V.（NASDAQ: ASML / AEX: ASML）

## 1. 一句話定位

**全球微影設備 >90% 市佔 + EUV 100% 壟斷（無對手）+ High-NA EUV first-mover（0.55 NA、2023 量產）+ 50+ 年 R&D 累積 + 1,000+ 供應商整合（Zeiss optics + 200+ Tier 1 modules）+ 全球唯一無法替代的「製造晶片的機器」供應商**——荷蘭 Veldhoven 總部、1984 從 Philips 分拆、NASDAQ + AEX 雙重上市、市值 **~€280-320B（USD ~$310-360B Mega Cap）**；客戶覆蓋 [[TSMC]] 30% + [[Samsung Electronics]] 25% + [[Intel]] 15% + [[SK Hynix]] + [[Micron]] + [[GlobalFoundries]] 全球先進製程 fab AVL；FY2025 營收 ~€30B + backlog €36B+（2025 末）+ EBIT margin 35%+；不押任何 fab / 任何 fabless / 任何技術路線、所有先進製程都要 ASML EUV / DUV——在 [[賣水人選股邏輯（投資版）]] 是「**頂級真賣水人 #1 + 賣水人之中的賣水人核心 anchor**」（唯一可能 25/25 的 entity）、在 [[Bottleneck Theory（瓶頸論）]] 是「**全球半導體鏈最終極 chokepoint**」（七層之外的微影設備層、所有 chokepoint 突破前都要透過 ASML 機台量產）、在 [[半導體基礎建設化]] 是「**製造設備基礎建設化最完美樣本**」（從設備供應商升級為製程定義者）、跟 [[Imec]] High-NA EUV first pilot fab 互鎖（2023 H2 首台 0.55 NA 出貨給 Imec、預備層 anchor）。

## 2. 三層 thesis

### 產業層

- **微影設備全球市佔 >90%**（EUV / DUV / multi-patterning 全棧）
- **EUV 100% 壟斷**：Nikon / Canon 早已退出 EUV 賽道（2010s 中期、無法達 EUV 13.5nm 光源 + 反射鏡精度）= ASML 是全球唯一可量產 EUV 機台的供應商
  - DUV ArFi（193nm immersion）市場 ASML ~80-85%、Nikon ~12-15%、Canon < 5%
  - EUV 市場 ASML 100% 壟斷（無對手、2017 EXE:3400 量產起算）
  - High-NA EUV（0.55 NA、EXE:5000 系列）2023 H2 首台出貨給 [[Imec]]、Intel 18A / TSMC N2 / Samsung 2nm 領先客戶採用
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「共識 → 反轉初期」高位**——
  - 共識已完成：50+ 年 R&D 累積、EUV 量產 8+ 年、High-NA EUV 商業 ramp 開始
  - 反轉初期警示：美中 EUV 對中出口禁令（2024-2026）+ DUV 設備中國市場 2025 起緩衝 + 短期週期性訂單調整
- 在 [[資訊擴散四階段]]：機構 + 賣方 + 媒體 + ETF 全部已配置（成份股 SOX / SMH / Nasdaq 100 / Stoxx 50 / MSCI 全球）+ 散戶層級認知度高（但仍多認為「賣水人但已 price in」）
- TAM：
  - FY2025 ~€30B
  - **FY2030E ~€60-80B**（CAGR 15%+ ASML 自家 Investor Day 2024 指引）
  - 結構性驅動：先進製程 + AI capex + Foundry 擴產 + memory HBM/DRAM 製程升級 + High-NA EUV 普及
- 跟 [[半導體基礎建設化]] 視角：ASML 是「**製造設備基礎建設化最完美案例**」、從週期性設備供應商升級為「製程定義者」（與 Foundry 共同定義先進製程的物理可能性）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：ASML EUV = **全球半導體鏈最終極 chokepoint**（七層之外的「層 -1 微影設備層」、所有 chokepoint 突破前都要透過 ASML 機台量產）
- 跟 [[控制點轉移（投資版）]] 視角：ASML 從「設備供應商」升級為「製程定義者」、拿到「光源 + 反射鏡 + 機台 + 製程 know-how + Imec pilot 預備層」五層控制權

### 目的層

- 真實角色：**「不是賣晶片、是賣『製造晶片的機器』+ R&D 服務 + 全球 service 網 + 製程定義權」**——不是「跟 fab 競爭」（vs TSMC / Samsung / Intel）、不是「跟 fabless 競爭」（vs NVDA / AMD / Apple）、是「**所有 fab / fabless / IDM / memory 廠商都要 ASML 機台才能量產**」、靠「**EUV 13.5nm 光源 IP + Zeiss optics 獨家 + 1,000+ 供應商整合 + 50+ 年 R&D 累積 + service + spare parts 50%+ recurring + Imec pilot 預備層 + 製程 know-how**」維持壟斷
- 業務組合（FY2025 推估）：
  - **EUV 機台**（含 High-NA EUV）：~50-55%（每台 EXE:5000 ~€350M、TWINSCAN NXE 系列 ~€180M）
  - **DUV 機台**（ArFi + KrF + ArF）：~25-30%（每台 ~€80-120M、中國市場 2024-2025 短暫激增後 2026 緩衝）
  - **Service + spare parts + upgrade + retrofits**：**~20-25%**（recurring 50%+ install base ~5,000+ 機台）
  - **Applications / Holistic Lithography**：~5%（YieldStar / NXE 計算微影軟體 + design-tech co-optimization）
- 核心商業模式：
  - **資本設備 + 耗材 + service 三位一體**（不只賣機台一次性、後續 service + spare parts + upgrade recurring）
  - **與客戶共同定義製程**（TSMC N2 + Intel 18A + Samsung 2nm + Rapidus 2nm 全部要先跟 ASML 共同 ramp）
  - **與 [[Imec]] 共建 pilot fab**（High-NA EUV 首台 pilot 在 Imec、預備層 anchor）
  - **客戶 lock-in 製程依賴**（一旦客戶用 ASML 機台量產、製程 know-how 全綁定 ASML、無法 switch）
- 核心 IP / 護城河（五層）：
  - **EUV 13.5nm 光源 IP**（Cymer 2013 收購、唯一規模化 13.5nm 光源）
  - **Zeiss optics 獨家**（Carl Zeiss SMT 是 ASML 25% 股東、共同開發 EUV 反射鏡、精度 < 0.05nm rms）
  - **1,000+ 供應商整合**（200+ Tier 1 modules + 800+ Tier 2 components、全球無第二家整合得起來）
  - **50+ 年 R&D 累積**（1984 創立、累計 R&D 投入 €40B+、現年 R&D €4B+ ~13% 營收）
  - **共用 [[Imec]] pilot fab 預備 5 年 High-NA EUV R&D**（2023 H2 首台 0.55 NA 出貨 Imec、商業 ramp 前的 pre-competitive R&D 平台）
- **High-NA EUV first-mover 5 年領先**：
  - 2023 H2 首台 EXE:5000（0.55 NA）出貨給 [[Imec]] pilot fab
  - 2024-2026 Intel 18A + TSMC N2 + Samsung 2nm 領先客戶接收 commercial High-NA EUV
  - 2027-2030 普及到 1.4nm / 1nm 製程
  - Nikon / Canon 進入 EUV 需 5-10 年（光源 + 光學 + 製程 know-how 全部要重來、實質不可能）
- 對應 [[賣水人選股邏輯（投資版）]]：**「頂級真賣水人 #1 + 賣水人之中的賣水人核心 anchor」**——不押任何 fab / 任何 fabless / 任何技術路線、所有先進製程都要 ASML
- 對應 [[控制點轉移（投資版）]]：拿到「**光源 + 反射鏡 + 機台 + 製程 know-how + Imec pilot 預備層**」五層控制權、從「設備供應商」升級為「製程定義者」
- 對應 [[半導體基礎建設化]]：ASML 是「**製造設備基礎建設化最完美樣本**」（從週期性設備供應商升級為基礎建設、估值從週期 PE → infrastructure PE）
