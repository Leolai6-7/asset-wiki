# Absolics（SKC 子公司，母公司 KRX:011790）

## 1. 一句話定位

**全球第一條「商業化量產」玻璃中介層產線**——韓國 SK 集團旗下材料公司 [[SKC]] 70.1% 控股 + [[Applied Materials 投資（待建）|AMAT]] 29.9% 策略入股的合資公司，於美國 Georgia Covington 設廠（CHIPS Act + NIST $175M 補貼），**2026 年底量產**目標客戶 [[AMD]] MI400 / [[AVGO]] / [[AMZN]] AWS Trainium / Graviton。在 [[TGV 製程鏈圖譜]] 中卡「**Interposer Fab**」位置——不是設備商，是把 [[LPKF]] LIDE + [[Corning]]/[[AGC]] 玻璃 + [[Disco Corp]] 切割整合起來、直接交付 OSAT 等級成品給 fabless 客戶的**中游 panel-level foundry**。

## 2. 三層 thesis

### 產業層

- TGV 製程鏈第 8+ 站「Interposer Fab + Panel-Level 成品交付」的**唯一 merchant 量產玩家**（Intel 自用、Samsung SEMCO 至少 2027 才量產 → Absolics 2026 年底領先 6-12 個月）
- [[市場四階段：懷疑／驗證／共識／反轉]]：「**驗證 → 共識**」過渡—AMD/AWS prototype 已進、Q3 2025 expected AMD approval announcement、2026 Q1 起 AMD MI400 volume sample
- 賽道 timing：**第一年「能商業出貨」**（embedding 路徑 2026 末、non-embedding 路徑 2026 內可能更早）vs [[Intel]] 2030 roadmap、[[Samsung Electro-Mechanics]] 2027+、Powertech 力成 2.5D panel 1H 2026 → Absolics 在 **2026 年是唯一可被 fabless 直接下單的 merchant 玻璃 interposer 供應商**
- TAM：玻璃中介層 / FOPLP 載板 2025 USD 0.74B → 2030 USD 1.67B（CAGR 17.6%），但 AI 場景驅動 + Intel 自用 + Samsung SEMCO/Absolics 雙頭 merchant → 長尾爆發空間遠超此估算

### 目的層

- 主業：**單一產品 pure play**——玻璃 RDL 中介層 + 通孔玻璃載板（Through-Glass Interposer / Carrier），沒有副業
- 真實角色：在 [[控制點轉移（投資版）]] 中卡的不是設備層（賣給 [[LPKF]]、[[Disco Corp]]、[[F&S Electron]]），不是材料層（買 Corning/AGC sheet），而是 **「panel-level 玻璃 interposer 第一個能 SCM 化的 merchant fab」** 控制點
- 商業模式雙軌：
  - **Embedding 路徑**：玻璃內嵌 IPD 被動元件（電容/電感）→ 直接競 [[ABF 載板 vs 玻璃基板 displacement]] 的 ABF 載板 + interposer 雙位
  - **Non-Embedding 路徑**（2026 Q2 新揭露）：純玻璃載板無嵌入元件 → 較簡單、更快商業化、首客是「美國通訊半導體公司」（疑似 [[AVGO]] 或 Marvell，未公開）
- 客戶結構：**全部 fabless / hyperscaler**，無消費電子→ 跟 [[AVGO]] / [[NVDA]] / [[AMD]] / [[AMZN]] 直接綁定，不依賴消費 cycle
- 戰略股東 [[Applied Materials 投資（待建）|AMAT]] 出資 USD 39M（51 億韓元，2023）→ AMAT 同時是 SEMCO / Intel 等對手鏈的設備商，**形成「AMAT 站全韓國 + 全美 fab 賣鏟子」中性賣水人結構**

### 供應層

- **路線**：embedding + non-embedding 雙軌、Intel 2024 開始 IP 授權 → Absolics 是少數正式取得 Intel TGV 授權的 merchant 玩家
- 護城河四層：
  - **時間差**：2026 年量產領先 Samsung SEMCO 至少 1 年、領先 [[Intel]] / [[TSMC]] 自用線
  - **資本綁定**：SKC 注資 KRW 590B（2026 rights offering 70% 分配給 Absolics）+ AMAT 策略入股 + CHIPS Act USD 75M + NAPMP USD 100M
  - **客戶 lock-in**：AMD 已過 prototype 驗證、AWS Trainium / Graviton 入測（雖 quality test 一度延後）、Intel 授權技術反向受惠
  - **Georgia 地利**：靠近 [[Intel]] Arizona、[[TSMC]] Arizona、Samsung Austin、[[Amkor]] Arizona、Applied Materials Texas → 客戶交付半徑短
- 競爭格局：vs [[Samsung Electro-Mechanics]]（2027+ 量產 + 內部 Samsung Foundry 鏈封閉）、vs [[Intel]] 自用（不外賣 merchant）、vs [[Amkor]]（OSAT 整合而非 fab 玩家）、vs LG Innotek（落後）、vs Powertech 力成（2.5D panel 互補不衝突）
- 風險：
  - 量產 ramp 不順（Yole 報告指 yield 仍在 stabilization 階段）
  - AWS quality test 延後 → 大客戶採用節奏不可控
  - 60,000 sqm Phase 2 擴產暫延（從原計劃 72,000 縮至「premature」）= demand 真實放量不如預期
  - SKC 母公司 2025 全年淨損 KRW 734B → 資本壓力大

### ✅ 催化

- 2026 年底**首條商業化量產玻璃中介層**正式 ramp（SK 集團主席 Chey Tae-won 親自督軍）
- AMD MI400 volume sample 2026 Q1 起 → Q3 quality approval 預期 → 2026 末 ramp
- [[AVGO]] 系 non-embedding 通訊半導體 design-in（2026 Q2 揭露）
- [[Intel]] glass substrate IP licensing 2025-08 開啟 → Absolics 從技術跟隨者升為 Intel 授權鏈受惠者
- 第二代 non-embedding 路線縮短 commercial timeline
- AMAT 策略入股 + CHIPS Act 補貼 + NAPMP 補貼 = 美韓政府聯合背書

### ⚠️ 風險

- SKC 2025 全年淨損 KRW 734B、財務承壓
- Phase 2 擴產暫延 = 管理層自己承認下游需求尚未爆發
- AWS quality test 延後 = 大客戶採用節奏不可控
- Samsung SEMCO 2027 量產追上 + Samsung Foundry 內部鏈封閉 → 整個 Samsung 鏈 design-in 機會極低
- 「[[Intel]] 自用 + Samsung 自用 + 台廠 [[TSMC]] CoWoS 自用」三大客戶內製 → Absolics 真實 merchant market 規模 cap 在 fabless（AMD / AVGO / NVDA） + hyperscaler（AWS / Meta） 兩塊
- 與 F&S Electron 獨家 TGV 設備合約 2026-03 到期 → 改 dual sourcing（疑似引入 [[LPKF]] 或新供應商），轉換成本 + yield 風險

## ⭐ 對台股 TGV 設備廠的意義

### bull case 對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]]

- **Absolics 自己不做設備、不做切割、不做檢測**——它買 [[LPKF]] LIDE、[[Disco Corp]] 切割、TSMC/SEMCO 級濕製程 → **與台廠 8 站設備生意 100% 無衝突**
- Absolics 是 panel-level **「demand creator」**：每多一條 12,000 m²/年產線 = 多一條雷射改質設備 + 切割 + 蝕刻 + 電鍍 + AOI 需求 → 台廠 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[德律]] **全鏈受惠**
- F&S Electron 獨家 TGV 合約到期 + dual sourcing → **第二供應商 slot 空出**，鈦昇雷射改質若能繞過 [[LPKF]] LIDE 專利範圍 → 可能切入
- Absolics 量產**先於** Intel/Samsung 自用線 → 證明 panel-level glass interposer 路線商業化可行 → derisk 整個 [[TGV 製程鏈圖譜]] 賽道 → 台廠 design-in 路徑被 derisk
- AMD MI400 用 Absolics 載板 = AMD/AVGO ASIC 鏈未來推進 panel-level → [[雷科]]（AMD 認證 2026 Q1 定案）、[[弘塑]]、[[辛耘]] 的 AMD/AVGO 鏈聯動

### bear case 對台廠

- Absolics + Samsung SEMCO 兩家「韓國系」打通 **panel-level interposer fab 中游**——台廠長期想做 TGV 整廠 turnkey（[[東捷]] 志聖 G2C+ 聯盟）的策略 → 在韓國本土被堵
- Absolics 與 Intel licensing 鎖死 → **Intel Arizona pathfinding 玻璃基板採用 Absolics 為 merchant 供應商**（非台廠 TPK Solution）→ 鈦昇 Intel Clearwater Forest design-in 雖領先，但 Intel 量產若選 Absolics merchant 而非自製 → 鈦昇 Intel 鏈訂單 visibility 模糊
- AMAT 同時是 Absolics 大股東 + 台廠 process equipment 對手 → 玻璃 fab 設備層的 [[控制點轉移（投資版）]] 不在台廠手上
- Absolics + SK Hynix（同集團）+ Samsung SEMCO + Samsung Foundry → 韓國 HBM4 + 玻璃基板**整鏈閉環**，台廠 PT 力成 panel HBM 路線（[[Powertech 力成]] 與 Micron 獨家綁定）變成「非韓系唯一替代」，但客戶數量被限

### 最大威脅 / 機會

**Absolics 對 [[鈦昇]] 是「中性 demand creator」+「Intel 鏈 merchant 競爭者」雙重身分**：

1. **設備層**：Absolics 不做設備 → 鈦昇 / 雷科 / 弘塑 / 辛耘 / 萬潤 / 德律 全部受惠（demand 加成）
2. **fab 服務層**：Absolics 直接吃 Intel Arizona 鏈 merchant 訂單 → 鈦昇若想透過台 OSAT（如 [[日月光 ASE]] TPK pilot）打進 Intel 鏈 → Absolics 是直接競爭者
3. **F&S Electron 合約到期窗口**：dual sourcing 的第二位 slot 空出 → 鈦昇若有繞過 [[LPKF]] LIDE 專利範圍的雷射改質工法 → **理論上可以入 Absolics 鏈**（極小機率但路徑存在）

→ **總結：Absolics 是「加大餅」**（驗證玻璃基板路線 + 創造設備需求），**但搶 Intel/AMD 鏈 fab 服務層的餅**（從 [[Amkor]] / [[日月光 ASE]] / TPK 等台廠 OSAT 手中拿單）。對台廠設備是受惠、對台廠 OSAT 是分食。

### 五軸評分（對 [[鈦昇]] / 對台廠設備）

| 軸 | 分數 | 說明 |
|---|---|---|
| 路線敏感（embedding/non-embedding） | 4/5 | 雙軌路線、技術自由度高、Intel licensing 解鎖 |
| 站別關鍵（fab 整合站） | 5/5 | 唯一商業化的 panel-level merchant fab、TGV 製程鏈整合者 |
| 耗材性（重複性需求） | 2/5 | 載板是製成品而非耗材、客戶量產後續單性質為「rolling order」 |
| IP 護城河 | 2/5 | 主要靠 Intel licensing + AMAT 設備整合 know-how、無自己的核心 IP |
| 客戶分散 | 3/5 | AMD/AWS/AVGO 三大客戶集中、缺乏 [[NVDA]] / [[TSMC]] / [[Apple]] 鏈 |

**Absolics 五軸 16/25**——比 [[LPKF]]（20/25）低、比 [[Disco Corp]]（21/25）低，但與 [[Amkor]] (16/25) 並列「美亞 OSAT-style 整合方」位置。
