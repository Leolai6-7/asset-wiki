# 村田 Murata（6981.JP）

## 1. 一句話定位

**全球 MLCC 絕對龍頭（40-50% 市佔）+ AI 伺服器被動元件「賣水人之中的賣水人」**——1944 年京都創業的日本被動元件巨頭、全球 MLCC #1（高階 AI server MLCC **70%+ 市佔**）、矽電容（silicon capacitor）跟 [[TSMC]] 並列**歷史寡占雙頭**；在 [[MLCC 嵌入式基板賽道]] 是**唯一「不被切的純被動元件廠」**——其他純 MLCC 廠（[[國巨]] / [[華新科]] / [[太陽誘電 Taiyo Yuden]]）面臨「載板廠把 MLCC 吃進去」的 displacement、村田自己**就有 iPaS™ 嵌入式基板產品**（鋁電解電容 + 平面 coil 整合）且 silicon capacitor 是高階替代品，**兩線都吃**；FY2026（截 2026-03）營收 **¥1.83 兆**（+5%）、AI server MLCC 訂單**約已售空產能 2 倍**、市值 ¥18.97 兆（USD ~1,300 億）、FY2027 自家指引 OP +34.8%。

## 2. 三層 thesis

### 產業層

- **MLCC 賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]] 「**共識**」段
  - 全球 MLCC 市場 USD ~150 億、村田 40-50% 市佔（高階 70%+）
  - AI server MLCC 需求 **FY2030 預計為 FY2025 的 3.3 倍**（CAGR ~27%）（[BigGo Goldman 報告](https://finance.biggo.com/news/KCJLaZ4BNl__-4_GHdDp)）
  - 高階 MLCC 交期從 8-12 週（2024）拉長至 **26-40 週**（2026）= 結構性短缺
  - 村田 2026-03 高容 MLCC 漲價 **15-35%**（[Astute Group 2026](https://www.astutegroup.com/news/general/mlcc-price-increases-threaten-ai-server-build-costs/)）
- **矽電容（silicon capacitor）賽道**在「驗證 → 共識」加速段
  - 市場 2025 USD 18 億 → 2035 USD 34 億（CAGR ~6.5%）
  - **村田 + [[TSMC]] 歷史寡占**（[Tech Times 2026-05](https://www.techtimes.com/articles/316907/20260521/samsung-electro-mechanics-wins-1b-silicon-capacitor-deal-murata-tsmc-duopoly-faces-new-rival.htm)）
  - [[Samsung Electro-Mechanics]] 2026-05 拿 USD 10 億合約（2027-01 起兩年）= **村田寡占破局訊號**
- **[[MLCC 嵌入式基板賽道]]**「驗證初期」
  - 村田 iPaS™ 已商業化（鋁電解電容 + 平面 coil + Vertical Power Delivery）
  - 客戶：AI 數據中心 power module、AI accelerator package
  - 但**真嵌入式 MLCC**（vs 模組整合）：[[太陽誘電 Taiyo Yuden]] 2025 世界首發、村田跟進中
- [[資訊擴散四階段]]：機構（日本基金）→ 賣方（Goldman、JPMorgan）→ 西方媒體（TrendForce、Investing.com）三階段已擴散完成

### 目的層

- 主業 mix（FY2026）：
  - **電容器（MLCC 為主）**：~45% 營收、AI server / smartphone / 車用三線
  - **EMI 對策元件**：~15%
  - **電感 / coil**：~10%
  - **通訊模組 / SAW filter**：~15%
  - **電池 / 其他**：~15%
- **AI server MLCC 直接受惠**：[[NVDA]] VR200 NVL72 機櫃單台 MLCC BOM **USD 4,320**（GB300 USD 1,530 → +182%）
- 客戶結構：
  - **AI 伺服器**：村田佔高階 MLCC **70%+ 全球**、是 [[NVDA]] / [[AMD]] / [[Intel]] AI rack 的**必經之路**
  - **智慧型手機**：Apple / Samsung 都是大客戶
  - **汽車**：村田佔自動車級 MLCC **40-50%**（[Mordor Intelligence](https://www.mordorintelligence.com/industry-reports/automotive-mlcc-market)）
  - **HBM**：silicon capacitor 嵌入 HBM stack power delivery（與 TSMC 並列）
- 商業模式：**Asset-light expansion**——多數產線可在現有設備加站點擴容、新建廠時間長（24-30 月）但 marginal ROI 高
- → 連 [[賣水人選股邏輯（投資版）]]：**AI 算力擴張時代「賣水人之中的賣水人」**——不押 GPU / CPU / 封裝路線、純押「所有 AI 晶片都需要 MLCC + 矽電容」

### 供應層

- **路線雙押 + 三線並進**：
  - **線 1**：分立 MLCC（現金牛、AI 漲價週期受惠）
  - **線 2**：matriculated 矽電容（高階寡占、與 TSMC 並列）
  - **線 3**：iPaS 整合基板（被動元件「自我嵌入式化」）
- 護城河四層：
  - **MLCC IP**：高介電陶瓷 know-how 80 年累積、AI 級 MLCC 配方寡占
  - **整合能力**：iPaS™ 把電容 + 電感 + 矽電容做成同一套解決方案 = 客戶 design-in 困難
  - **產能彈性**：Izumo（島根）+ Batangas（菲律賓）+ Wuxi（中國）三地 ASEAN/JP/CN 分散
  - **客戶 lock-in**：Apple iPhone / NVDA AI rack / Tesla 車用 MLCC qualification 三年起跳
- 競爭格局：
  - **vs [[Samsung Electro-Mechanics]]**（韓國 KRX: 009150）：SEMCO 是「載板廠 + MLCC 廠」**雙陣營玩家**、規模 USD 92B、與村田 USD 130B 接近、SEMCO 2026 矽電容 USD 10 億合約破局
  - **vs [[太陽誘電 Taiyo Yuden]]**（5237.JP）：日陣營協同對手、嵌入式 MLCC 世界首發（1005 size 22μF）但規模 ~村田 1/10
  - **vs [[TDK]]**（6762.JP）：日陣營協同、SESUB 整合模組
  - **vs [[國巨]]**（2327.TW）：MLCC #3 全球、AI 營收佔比 15%、嵌入式產品線未公開
  - **vs [[華新科]] / [[信昌電]]**（2492/6173.TW）：中高壓 MLCC 利基、AI rack 高壓 MLCC 倍增受惠、嵌入式未明確
  - **vs [[TSMC]]**：silicon capacitor 並列寡占、TSMC 製程優勢 vs Murata 客戶整合優勢、SEMCO 來搶
- 風險：
  - **嵌入式 MLCC 滲透**：若 [[太陽誘電 Taiyo Yuden]] / [[Samsung Electro-Mechanics]] 嵌入式 MLCC 成為主流、分立 MLCC TAM 被切
  - **SEMCO 矽電容破局**：USD 10 億合約是「Murata + TSMC 二家寡占」首度破口
  - **日圓升值**：高出口比重、JPY/USD 反轉壓營收
  - **AI CapEx 週期反轉**：MLCC 是 power delivery 強剛需、但若 [[CapEx 見頂辯論]] 兌現 → 順週期 OP margin 回落
  - **產能配置失誤**：交期 26-40 週、若 AI server 訂單延遲、產能配置給智慧型手機反而吃不到漲價
- → 連 [[控制點轉移（投資版）]]：拿到「**分立 MLCC + 嵌入式被動元件 + 矽電容**三層控制點」、是少數**載板廠 displacement 也吃得到的被動元件廠**

## ⭐ 對 [[MLCC 嵌入式基板賽道]] 各玩家的意義

### 結構性意義

村田是 **MLCC 嵌入式賽道唯一「不被切的純被動元件廠」**——三線並進策略讓 displacement 對它變成新 TAM 而非威脅：

| 線 | 內容 | 受惠程度 |
|---|---|---|
| 分立 MLCC | 高階 AI server 70%+ 市佔 | ✅ AI rack BOM 倍增直接吃到 |
| iPaS 嵌入式 | 鋁電解電容 + 平面 coil + VPD 模組 | ✅ 載板廠（IBIDEN / SEMCO）若做嵌入式、村田 iPaS 可整體外包 |
| 矽電容 | 與 TSMC 寡占 | ⚠️ SEMCO USD 10 億合約破局 = 局部受威脅 |

### 對 [[Samsung Electro-Mechanics]]（最直接對手）

- **競合並存**——SEMCO 越南嵌入式產線 + USD 10 億矽電容合約是直接威脅
- 但 Murata MLCC 70%+ 高階市佔仍難動搖（SEMCO MLCC 純度不夠）
- SEMCO「載板廠 + MLCC 廠」雙陣營 vs Murata「純被動 + iPaS 整合」的**結構性差異**
- **vs SEMCO 五軸對照**：村田勝在「IP + 客戶分散」、SEMCO 勝在「集團整合 + 載板優勢」

### 對 [[IBIDEN]]（互補）

- IBIDEN 是載板廠、Murata 是被動元件廠 = **不直接競爭、是供應關係**
- IBIDEN ¥5,000 億 CapEx 含嵌入式產線 = Murata iPaS / 嵌入式 MLCC **直接受惠**（IBIDEN 嵌入式載板需要 Murata 供料）
- 但若 IBIDEN 學 SEMCO 走「自製嵌入式 MLCC」路線 → Murata 才會被切

### 對 [[太陽誘電 Taiyo Yuden]]（日陣營協同對手）

- 日陣營協同——Taiyo Yuden 嵌入式 MLCC 世界首發、Murata 自家 iPaS 跟進
- 規模差 10 倍（Taiyo Yuden ¥1.96 兆市值 vs Murata ¥18.97 兆）= Murata 是大哥、Taiyo Yuden 是 niche 玩家
- 兩家 + [[TDK]] 構成 **日本被動元件三巨頭**對抗韓陣營 SEMCO + 台陣營國巨/華新科

### 對 [[國巨]] / [[華新科]] / [[信昌電]] 台廠 MLCC 三角

- **規模差數十倍**：Yageo USD ~9B 市值 vs Murata USD 1,300B
- 台廠 MLCC 三家全在「分立元件」、嵌入式進度幾乎為零
- 村田 iPaS / 矽電容 / 嵌入式 MLCC 三線同時推進 → **台廠純 MLCC 廠的中期 displacement 風險被放大**
- 信昌電高壓 MLCC 利基（NVDA Rubin 1MW 機櫃）目前受惠、但若 Murata 高壓嵌入式 MLCC 出來會被切

### 對 [[TSMC]]（silicon capacitor 並列寡占）

- 並列「Murata + TSMC」寡占、SEMCO 來搶
- 結構性差異：TSMC 是「製程 + 晶圓 fab」優勢、Murata 是「客戶整合 + iPaS 整體解決方案」優勢
- 短期共同抵擋 SEMCO、中期可能在不同客戶端各自分流

## ⭐ 對台廠 MLCC 三角的意義（[[國巨]] / [[華新科]] / [[信昌電]]）

### bull case 對台廠

- **AI server MLCC BOM 倍增**（USD 1,530 → 4,320）= 整體 MLCC TAM 暴增、台廠跟著吃
- 村田高階 70%+ 市佔 + 漲價 15-35% → 台廠中階 MLCC 也跟著漲（量價齊揚）
- 村田交期 26-40 週 → 客戶**分流訂單給台廠**（國巨 Q1 AI 營收佔 15%、信昌電 AI 機櫃高壓單一規格放量 10 倍）
- 村田 CapEx asset-light（加站點 vs 新建廠）→ 短期產能 cap、台廠中階補位

### bear case 對台廠

- **嵌入式 displacement**：村田 iPaS™ + 矽電容 + 嵌入式 MLCC 三線並進 → 載板廠（IBIDEN / SEMCO）整體解決方案綁村田 → **台廠純分立 MLCC TAM 被切**
- **規模差數十倍**：村田 USD 1,300B 市值 + 80 年 IP vs Yageo USD 9B + 嵌入式進度為零 = **AI 客戶議價時自然優先村田**
- **日陣營協同**：村田 + Taiyo Yuden + TDK 三家在 AI server 高階 MLCC + 嵌入式 + 矽電容**全鏈共識**、台廠在 design partner 位上極弱
- **信昌電高壓 MLCC 利基**：村田高壓 + 嵌入式產品若出 → 切利基

### 給 TGV 投資人的對沖視角

- 押 TGV 設備鏈（[[鈦昇]] / [[雷科]] 等）做多 AI 載板的同時、不該重壓台廠 MLCC（國巨 / 華新科）
- 真正不被切的被動元件廠是**村田**——三線並進 + 寡占 + 客戶分散
- pair trade：**做多村田（耗材 + 漲價）vs 做空台廠純 MLCC 廠（中期 displacement）**

- [[ABF 載板 vs 玻璃基板 displacement]]：村田跟 displacement 平行——MLCC displacement 而非 ABF displacement、但同樣是「載板廠把上游吃進來」
- [[半導體基礎建設化]]：AI 算力擴張的物理基礎之一（power delivery 必需 MLCC）
- [[賣水人選股邏輯（投資版）]]：**AI 算力時代「賣水人之中的賣水人」**——不押 GPU / CPU / 封裝路線、純押 power delivery
- [[控制點轉移（投資版）]]：拿到「分立 MLCC + 嵌入式 + 矽電容」三層控制點、是少數 displacement 也吃得到的被動元件廠
- [[市場四階段：懷疑／驗證／共識／反轉]]：MLCC 漲價週期在「共識」段、嵌入式在「驗證初期」雙頭壓注
- [[五層損益表（營業槓桿）]]：FY2027 自家指引 OP +34.8% = 營業槓桿全開
- [[CapEx 見頂辯論]]：村田是少數 CapEx 見頂後仍受惠的「耗材型」標的
- [[NVDA]]、[[AMD]]、[[Intel]]、[[Apple]]、[[Tesla]] 五家旗艦客戶
- [[Samsung Electro-Mechanics]]、[[IBIDEN]]、[[TSMC]]：三大競爭/合作對手
- [[太陽誘電 Taiyo Yuden]]、[[TDK]]：日陣營協同對手
