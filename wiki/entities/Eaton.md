# Eaton（ETN）

## 1. 一句話定位

**全球電力管理 turnkey 龍頭 + 800V HVDC reference architecture 首發者 + NVDA 共同制定 31 家 Tier 1**——總部都柏林（愛爾蘭、稅務）/ 運營總部 Beachwood Ohio；事業群：**Electrical Americas（北美電氣）+ Electrical Global（全球電氣）+ Aerospace + Vehicle + eMobility**；2025-10 跟 [[NVDA]] 共同首發 **800V DC reference architecture（從電網入口 → 變壓器 → 開關 → PDU → 機架配電 turnkey 整合）**= 全球第一家把 NVDA 800V HVDC 標準做成可量產 reference design 的整合系統廠；**800V switchgear**（中壓開關櫃 / busway）= 機房配電核心、跟 [[Schneider Electric]] 全球兩大頭；過去 12 個月電氣事業群 backlog **+25-30% YoY**、其中 **data center end-market backlog 翻倍以上**；Q1 2026 營收 **~$6.5B（YoY +12%）**、Electrical Americas Q1 organic +14%、segment EBIT margin 上至 **~24%**、FY 2026 EPS guidance **$12.30-12.70**（YoY +12%）；股價 12 個月 **+50-90%**；是 [[AI infra 電力戰場]] **第三層「電力分配」第 #1 anchor（turnkey 整合 + 800V HVDC reference architecture）**。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - Eaton 是 NVDA 800V HVDC 31 家伙伴中**唯一拿到「首發 reference architecture」位置**的整合系統廠
  - 過去：data center 電力管理是分立元件採購（UPS / PDU / switchgear 各自為政）
  - 2025-10：Eaton 把 800V DC 做成**從變壓器 → switchgear → PDU → busway 機架配電 turnkey** = 重新定義「電力 SI」角色
- 800V HVDC 標準化大轉場（NVDA 31 家伙伴體系）：
  - 過去 54V 機架 → 132kW 物理極限
  - 800V HVDC → 1MW 機架物理可行
  - **Eaton + Schneider Electric + ABB** = 系統廠三巨頭、Eaton 在北美 turnkey 整合最強
- 全球 switchgear 緊缺：
  - 中壓 switchgear（4.16kV - 38kV）交期 12-24 個月
  - 美國 / 歐洲 grid 升級 + data center 新建雙頭吃 = 結構性 backlog 累積
- 對應 [[AI infra 電力戰場]]：**第三層電力分配 #1 anchor**（800V HVDC turnkey + switchgear 雙引擎）
- 對應 [[宋分 #20 — 能源結構性剛需]]**三標準全滿**：800V HVDC 結構改變 + 持續 CapEx + backlog $13B+ 鎖死

### 目的層

- 業務 mix（2025）：
  - **Electrical Americas ~42%**：北美 switchgear + UPS + PDU + busway + 配電軟體（**AI data center 主受惠**）
  - **Electrical Global ~24%**：歐洲 / 亞太電氣設備
  - **Aerospace ~15%**：航太電力系統
  - **Vehicle ~12%**：商用車輛電氣化
  - **eMobility ~7%**：EV 充電 + 電池管理
- **AI / data center 直接占比**：
  - 過去 5 年 data center end-market 從 ~5% → **>15% Electrical Americas**（CEO Craig Arnold 法說）
  - Q1 2026 data center backlog 翻倍 YoY
- 客戶結構：
  - **Hyperscaler 直接**：[[Microsoft]] / [[AMZN]] / [[Meta]] / [[Google]] / OpenAI 都是 Eaton 客戶（規模分散）
  - **Colo 廠**：Equinix / Digital Realty / CyrusOne
  - **電力公司 / IPP**：[[Constellation Energy]] / [[Vistra]] / [[GE Vernova]] 上游配對
  - **OEM**：跟 [[NVDA]] / SuperMicro / Vertiv 整合方案
- 商業模式核心：
  - **turnkey 整合**：從變壓器 → switchgear → PDU → busway → 機架配電完整供應
  - **800V HVDC reference architecture**：跟 NVDA 共同定義標準 = 規格控制權延伸
  - **服務 + 軟體 + 配電 EMS**：硬體 + 軟體（Brightlayer 配電軟體）= 長期 recurring 收入
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人 + turnkey 整合版**——比純元件廠（如 Navitas / TI）大、比純發電廠（如 CEG）多客戶分散
- 對應 [[控制點轉移（投資版）]]：拿到「**800V HVDC reference architecture + turnkey 整合 + 配電軟體**」三段控制點 = 從硬體 → 標準 → 軟體完整

### 供應層

- 跟 [[NVDA]] 路線：**2025-10 首發 800V DC reference architecture**（NVDA 31 家伙伴之一）
  - Eaton 是**唯一拿到 reference architecture 首發位置的整合系統廠**
  - vs [[Schneider Electric]]、ABB、Vertiv 也在 31 家、但 Eaton 是 turnkey + 北美首發
- 跟 hyperscaler 路線：規模分散、沒有單一大客戶集中
  - [[Microsoft]] data center 電氣設備主要供應商
  - [[AMZN]] AWS / [[Meta]] / [[Google]] 都使用
- 跟 [[Schneider Electric]] 競爭：
  - **ETN**：800V HVDC reference architecture 首發 + turnkey 整合 + 北美 backlog 領先
  - **SU**：EcoStruxure 整合平台 + 全球 #1 data center power（特別歐洲）+ EcoStruxure IT 軟體深
  - **ETN**：北美 anchor 勝、軟體弱於 SU EcoStruxure
  - **SU**：歐洲 / 全球 anchor 勝、北美 backlog 弱於 ETN
  - → **兩家是 turnkey 配電 dual leader、不是零和**
- 跟 ABB 競爭：
  - **ETN**：800V HVDC turnkey + UPS 主場（switchgear 也強）
  - **ABB**：變壓器 + HVDC 高壓段主場（中壓 switchgear 強但 turnkey 弱於 ETN）
  - → ABB 在「電力傳輸」更強、ETN 在「電力分配」turnkey 更強
- 跟 [[GE Vernova]] 關係：
  - **GEV**：變壓器 OEM + 燃氣輪機（上游發電 + 傳輸）
  - **ETN**：機房內 turnkey 配電（下游分配）
  - → 同戰場互補、不直接競爭
- 跟 Vertiv（VRT）競爭：
  - **VRT**：機房液冷 + 機架 UPS（機架級 / 模組化）
  - **ETN**：建築級 turnkey + switchgear + 配電架構（整廠級）
  - → 不同層級、ETN 更上游
- 護城河：
  - **800V HVDC reference architecture 首發**：跟 NVDA 共同定義 = 規格控制權延伸到機房電力
  - **turnkey 整合能力**：從變壓器到機架完整供應、減少業主整合成本
  - **Brightlayer 配電軟體 + EMS**：硬體 + 軟體生態 = 客戶綁定
  - **北美 backlog 規模**：$13B+ electrical backlog + data center 翻倍
  - **歐洲基地**：Electrical Global 在歐洲基礎建設電氣化受惠
- 風險：
  - **Schneider EcoStruxure 軟體優勢**：SU 軟體生態更深、ETN 軟體追進中
  - **中國品牌進入**：上海電氣 / 西電 等 switchgear 價格戰
  - **800V HVDC 標準化延後**：若 NVDA 31 家伙伴生態 ramp 慢 → ETN reference architecture 變現延後
  - **CSP 自製電氣設備**：MSFT / AMZN 中長期可能自製部分配電
  - **景氣循環**：Aerospace / Vehicle 段對景氣敏感
  - **PE 32-36 倍**：估值已 price in 多年 AI 增長、下檔保護弱於 GEV

## ⭐ 800V switchgear（電力分配中壓核心）

**switchgear 定位**：
- 中壓開關櫃（4.16kV - 38kV）= 電網入口到變壓器之間的開關控制
- AI data center 需要：高可靠度 + 高功率密度 + 遠端監控
- 全球供應吃緊：交期 12-24 個月

**ETN 800V switchgear**：
- 跟 NVDA 800V HVDC 配套
- vs Schneider 800V switchgear（兩家 dual leader）
- 北美市占率 #1（Q1 2026 Eaton 自述）

## ⭐ Vistra / Constellation 下游配電必經

> Eaton 不直接擁有電廠、但**每一座 hyperscaler data center 從電網接電的「最後一公里」都要走 Eaton / Schneider switchgear + UPS + PDU**

**路徑**：
```
電網 → 變壓器（GEV / Hitachi / ABB）→ switchgear（Eaton / Schneider / ABB）→ UPS / PDU（Eaton / Schneider / Vertiv）→ 機架 → 800V HVDC bus converter（STM / TI / Navitas）→ GPU
```

→ **Eaton 在「電網入口到機架」turnkey 配電必經之路 = 結構性護城河**

## pair trade / 配置建議

### 多 ETN（turnkey 配電龍頭）

**論點**：ETN 是 AI 電力戰場第三層 #1 anchor、800V HVDC reference architecture 首發、客戶分散、$13B+ backlog 結構性。

**配置**：核心持倉、5-8% 配置上限。

### 配對思路

**多 ETN / 多 GEV（電力戰場雙頭）**：
- ETN 第三層分配 + GEV 第二層傳輸 = 同戰場互補
- 共同受惠 NVDA 800V HVDC ramp

**多 ETN / 空 SU（北美 vs 歐洲）**：
- ETN 北美 backlog 領先 + 800V HVDC 首發
- SU 歐洲 anchor + 軟體深、但北美 ramp 慢於 ETN
- → 結構性勝負中等（兩家都受惠）

**多 ETN / 空 Vertiv（建築級 vs 機架級）**：
- ETN 建築級 turnkey + switchgear
- VRT 機架級 UPS + 液冷
- → 不同層級、ETN 更上游

→ **結論**：ETN 是核心持倉、可跟 GEV / CEG 形成電力戰場三層曝險組合。
