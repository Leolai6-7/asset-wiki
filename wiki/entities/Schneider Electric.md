# Schneider Electric（SBGSY / SU.PA）

## 1. 一句話定位

**全球 #1 data center power 整合平台 + EcoStruxure 軟體深度生態 + UPS / PDU / 配電 turnkey 跟 [[Eaton]] 全球雙頭**——總部 Rueil-Malmaison 法國（1836 創立）；事業群：**Energy Management（能源管理 ~75%）+ Industrial Automation（工業自動化 ~25%）**；**APC by Schneider** 全球 UPS / PDU #1 品牌；**EcoStruxure** 整合平台 = 硬體 + 軟體 + 服務 + 配電 EMS + IT data center 管理 = AI data center 整合平台首選；2025-10 跟 [[NVDA]] / [[Eaton]] / [[ABB]] **共同制定 800V HVDC architecture standard**（NVDA 31 家伙伴之一）；2025-10 法說預估 **1MW AI rack 2027 量產 → 800V DC 是唯一物理可行解**（Schneider 自己白皮書定義）；2026-01 收購 **Motivair**（800V HVDC 液冷整合）+ **Vertiv-clone 散熱業務擴張**；Q1 2026 營收 **~€10.6B（YoY +9%）**、Energy Management organic Q1 +12%、operating margin **~18%**、orders backlog 2025 **~€26B**；股價 12 個月 **+40-70%**（vs ETN +50-90%）；是 [[AI infra 電力戰場]] **第三層「電力分配」第 #2 anchor**（vs ETN #1 turnkey 北美 / SU #2 整合平台 + 全球 + 軟體深）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - SU 是 NVDA 800V HVDC 31 家伙伴中**整合平台 + 軟體生態最深**的玩家
  - 過去：data center power 分立採購（UPS / PDU / 軟體各自為政）
  - 現在：**EcoStruxure** 一站整合 = SU 重新定義「data center power + IT + cooling」整合解決方案
- 800V HVDC 標準化大轉場：
  - SU 自家白皮書 2025-10 提出「**1MW rack 2027 量產 → 800V DC 唯一物理可行**」
  - vs Eaton 首發 reference architecture / SU 整合平台 + 軟體
  - 兩家是 turnkey 配電 dual leader
- 全球 UPS / PDU TAM 結構性增長：
  - data center power 全球年 ~$30B、預估 2030 年 ~$70B
  - SU APC + Eaton 兩家全球 ~40-50% 合計市占
- 對應 [[AI infra 電力戰場]]：**第三層電力分配 #2 anchor（整合平台 + 軟體深）**
- 對應 [[宋分 ＃20 — 能源結構性剛需]]**三標準全滿**：800V HVDC 結構改變 + 持續 CapEx + backlog €26B 鎖死

### 目的層

- 業務 mix（2025）：
  - **Energy Management（能源管理）~75%**：UPS（APC）+ PDU + 配電 + EcoStruxure 軟體 + busway + 中壓 switchgear（**AI data center 主受惠**）
  - **Industrial Automation（工業自動化）~25%**：PLC + SCADA + 機器人（vs ABB Process Automation）
- **AI / data center 直接占比**：
  - Energy Management 中 ~25-30% 來自 data center end-market
  - 整體 SU ~18-22% AI direct exposure（比 ETN 的 ~12-15% 高）
- 客戶結構：
  - **Hyperscaler 直接**：[[Microsoft]] / [[AMZN]] / [[Meta]] / [[Google]]（規模分散）
  - **Colo 廠**：Equinix / Digital Realty / NTT Data
  - **電力公司**：歐洲 / 北美 utility（配電 + EcoStruxure EMS）
  - **OEM**：跟 [[NVDA]] / SuperMicro 整合方案
- 商業模式核心：
  - **EcoStruxure 整合平台**：硬體 + 軟體 + 服務 + IT data center 管理 = 一站整合（vs ETN 的 Brightlayer 軟體弱）
  - **APC UPS / PDU 全球 #1**：規模 + 品牌議價權
  - **800V HVDC 共同制定**：NVDA 31 家伙伴之一
  - **服務 + 軟體 recurring**：硬體 + 軟體 + 服務生態 = 長期 recurring 占比高
  - **2026-01 Motivair 收購**：800V HVDC + 液冷整合擴張
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人 + 整合平台 + 軟體深版**——比 ETN 軟體深、比 ABB 純度高、AI 純度勝
- 對應 [[控制點轉移（投資版）]]：拿到「**EcoStruxure 整合平台 + APC UPS + 800V HVDC + 服務軟體 recurring**」四段控制點

### 供應層

- 跟 [[NVDA]] 路線：**2025-10 共同制定 800V HVDC architecture**（31 家伙伴之一）
  - SU 提供 EcoStruxure data center 整合平台 + APC UPS + PDU + 中壓配電
  - vs Eaton 首發 reference architecture / SU 整合平台 + 全球 + 軟體深
- 跟 hyperscaler 路線：規模分散、全球市場主力
- 跟 [[Eaton]] 競爭：
  - **ETN**：800V HVDC reference architecture 首發 + turnkey 整合 + 北美 backlog 領先
  - **SU**：EcoStruxure 整合平台 + 軟體深 + 全球 data center power #1 + APC UPS 龍頭
  - **ETN**：北美 anchor + turnkey 首發勝
  - **SU**：歐洲 + 全球 anchor + 軟體 / EcoStruxure 生態深勝
  - → 兩家是 dual leader、互補大於對抗（全球市場夠大）
- 跟 [[ABB]] 競爭：
  - **ABB**：配電 + switchgear + Process Automation + Robotics 多元
  - **SU**：EcoStruxure 軟體 + IT data center 整合 + APC UPS
  - **ABB**：跨工業多元勝（Robotics 獨家）
  - **SU**：data center 純度勝 + 軟體深勝
  - → SU 是 AI data center 最純的整合平台 + 軟體生態
- 跟 Vertiv（VRT）競爭 / 補完：
  - **VRT**：機房液冷 + 機架 UPS（機架級 / 模組化）
  - **SU**：建築級 turnkey + 中壓配電 + EcoStruxure 軟體（整廠級）
  - **SU**：2026-01 收 Motivair 是 **VRT 競爭加碼**（800V 液冷整合擴張）
  - → SU 開始侵入 VRT 機架液冷主場
- 跟 [[GE Vernova]] / [[Hitachi Energy]] / [[Siemens Energy]] 關係：
  - **GEV / Hitachi Energy / Siemens Energy**：上游發電 + 大型 transformer + 燃氣輪機
  - **SU**：機房內 turnkey 配電 + EcoStruxure 整合 + APC UPS
  - → 同戰場互補、不直接競爭
- 護城河：
  - **EcoStruxure 整合平台**：硬體 + 軟體 + 服務 + IT data center 管理 = 客戶綁定強（vs ETN Brightlayer 弱）
  - **APC UPS / PDU 全球 #1**：規模 + 品牌議價權
  - **800V HVDC 共同制定 + 1MW rack 白皮書定義者**：規格控制權
  - **服務 + 軟體 recurring 占比高**：硬體 + 軟體 + 服務生態 = 長期穩定
  - **歐洲 anchor + 全球分散**：跨地緣風險低
- 風險：
  - **Eaton 800V HVDC reference architecture 首發**：北美 backlog 領先、SU 追進中
  - **中國品牌進入**：華為 / 上海電氣 UPS 價格戰
  - **CSP 自製**：MSFT / AMZN 中長期自製部分 UPS / PDU
  - **景氣循環**：Industrial Automation 段對景氣敏感
  - **PE 26-29 倍 + 12 個月 +40-70%**：估值已 price in
  - **法國勞工 / 稅務環境**：相比愛爾蘭（ETN）稅率較高

## ⭐ 1MW rack 白皮書定義者

> 2025-10 Schneider Electric 發表白皮書「**The 1 MW AI IT rack is coming – and it needs 800 VDC power**」= **SU 是「1MW rack → 800V HVDC 物理可行性」narrative 定義者**

關鍵內容：
- 1MW rack 2027 量產 → 54V 配電物理上不可能（需 64U 銅排 + 200kg 銅 / rack）
- 800V HVDC 解：電壓提高 14.8 倍 → 銅用量減少 45% + 效率提升 5%
- 推動 NVDA 31 家伙伴體系標準化

→ **SU 是「為什麼必須 800V」narrative 定義者 = thought leadership**
