# 雙鴻（3324.TW）

## 1. 一句話定位

**台廠液冷散熱純度首選 + 完整 cold plate / manifold (CDM) / CDU 三鏈整合 + 1.6MW L2L CDU 超前部署 + NVDA Rubin 客製化 sample 驗證中 + 2026 液冷營收占比衝 55%**——UBS 估**rack manifold 27% 全球市佔（2025）+ Supermicro 主供 + 美系 cloud top 5 客戶**、2025 EPS 28.26 元創新高 + 2026 年初營收 121% YoY 跳升、跟 [[奇鋐 3017|奇鋐]]（3017）並列「**台廠液冷散熱雙頭**」(奇鋐強在 cold plate 50%+ 市佔 / 雙鴻強在 **CDU + manifold 三鏈完整 + 1.6MW CDU IP**)、[[AI infra 散熱戰場]] **anchor #5**。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**共識**」階段、比通用 MLCC（[[華新科]]）超前但比 [[Vertiv]] / [[台達電]] 較滯後 1-2 季
- 機櫃功率密度 5 年 30kW → 1MW（**33x**）= 散熱**從零件升級為基礎建設**
- 2026 液冷滲透率衝 **76%**（券商估）+ 單櫃散熱產值跳升 **4 倍**
- 跟 [[AI infra CapEx 三階段論]] 第三階段同步：散熱是「**從 NVDA 設備往下游機櫃**」傳導的 BOM 倍增戰場
- 跟 [[AI infra 電力戰場]]（孿生戰場）：**[[信昌電]] / [[台達電]] / 雙鴻 / [[高力 8996|高力]] / [[奇鋐 3017|奇鋐]] = 800V HVDC 五角賣水人**；niche specialist 三角賣水人 = [[信昌電]]（電源 MLCC）+ 雙鴻（液冷三鏈）+ [[高力 8996|高力]]（CDU 心臟 BPHE）
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體（媒體層滲透中、2025 EPS 28.26 元已上頭條 + 2026 1 月營收 121% YoY 已 ETF 化、但細部技術差異仍在賣方層）

### 目的層

- **業務組合**（FY2025 → FY2026 推估）：
  - **AI 伺服器散熱**：~70% +（液冷產品從 2024 ~30% → 2025 ~50% → **2026 衝 55%+**）
  - **桌機 / 筆電 / 工作站散熱**：~20-30%（傳統 base + 高階電競）
  - **車用 / 其他**：<10%
- **液冷產品全鏈**：
  - **Cold Plate（水冷板）**：銅基直接觸晶 GPU/CPU、Boyd 級規格、**月產 ~30 萬顆**（持續擴產中）
  - **Manifold（CDM / 分流管）**：UBS 估 **rack manifold 27% 全球市佔（2025）**、月產 ~4,000 顆
  - **CDU**：**1.6MW L2L CDU 超前部署**（超越市場主流 1.4MW 規格）、業界少數能做到 MW 級
- **AI server 客戶結構**：
  - **主供 [[Supermicro]]**（美超微，cold plate 主要供應商）
  - **美系 top 5 cloud（hyperscaler）主供 manifold**
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 餵 NVDA + AWS Trainium + AMD MI300/MI400
  - NVDA Rubin **客製化高利潤 sample 驗證中**（2026 Q2 法說自揭）、跟 NVDA Rubin H2 2026 量產時序對齊
- **2026 營收目標上修**：原 +50% YoY → 上修 **+70% YoY**（~NT$40 億）+ 毛利率衝 **30%+**
- 商業模式核心：
  - **「**台廠液冷純度首選 + 完整全鏈整合**」**：cold plate + manifold + CDU 三鏈合一 = 台廠**唯一**（奇鋐 CDU 弱、高力 BPHE niche、台達多元）
  - **1.6MW L2L CDU IP**：業界少數能做 MW 級、面向 NVDA Rubin 1MW 機櫃 + 浸沒式過渡架構
  - **泰國新廠 2026 1 月開出**：營收 121% YoY 跳升、低成本擴產
  - **規格深度**：cold plate / manifold / CDU 三鏈各自有 IP（vs 奇鋐純零件廠模式）
- 對應 [[賣水人選股邏輯（投資版）]]：**液冷純度賣水人**——不押 NVDA / AMD / Trainium 誰贏、押**所有 1MW 機櫃都得用液冷三鏈**
- 對應 [[控制點轉移（投資版）]]：拿到「**液冷三鏈完整 + 1.6MW CDU IP + Supermicro 主供 + Rubin sample 驗證**」綁定 = 議價權**結構性高於純零件廠**

### 供應層

- 跟 [[NVDA]] 路線：
  - **Rubin sample 驗證中**（2026 Q2 法說自揭、客製化高利潤）
  - 跟 NVDA Rubin H2 2026 量產時序對齊
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 間接餵 NVDA（具體比例未揭露）
- 跟 [[奇鋐 3017|奇鋐]]（3017）對比（**核心對標**）：
  - **cold plate**：奇鋐 50%+ 市佔（主供 4 大 CSP）vs 雙鴻 15-20%（主供 Supermicro）→ **奇鋐勝**
  - **CDM / manifold**：奇鋐 4 大 CSP 主供 vs 雙鴻 27% rack manifold 全球市佔 → **奇鋐市佔略勝、雙鴻純度勝**
  - **CDU**：雙鴻 **1.6MW L2L CDU 超前部署** vs 奇鋐弱 → **雙鴻勝（重要 IP）**
  - **全鏈整合**：雙鴻 cold plate + manifold + CDU **三鏈完整** vs 奇鋐純零件廠（cold plate + manifold） → **雙鴻勝**
  - **客戶結構**：奇鋐 4 大 CSP 集中 vs 雙鴻 Supermicro + top 5 cloud + NVDA Rubin sample → **雙鴻略勝（更分散）**
  - **規模**：奇鋐市值 / 營收略大、雙鴻成長速度更快（+121% Jan YoY）
  - **2026 毛利率**：雙鴻衝 30%+ vs 奇鋐 25-30% 區間 → **雙鴻略勝**
  - → **奇鋐強在 cold plate 市佔、雙鴻強在 CDU + 全鏈整合 + 高利潤客製化、兩家是「**主流產品 vs 全鏈深度**」**
- 跟 [[Vertiv]] 對比：
  - 重疊：cold plate + manifold + CDU（雙鴻無 power 軌）
  - Vertiv 走 hyperscaler turnkey、雙鴻是**潛在零件供應商 + 部分競爭**
  - Vertiv 2026-04 併購 Strategic Thermal Labs（cold plate IP）→ 跟雙鴻部分競爭加劇
  - 但 Vertiv 規模 + 服務 + 認證遠超雙鴻 → 兩家不正面對打（**Vertiv 系統 / 雙鴻零件**）
- 跟 [[台達電]] 對比：
  - 重疊：CDU + cold plate + manifold（台達多元 + 規模 + ODM 友好）
  - 台達電源 + 散熱整合勝、雙鴻純度勝
  - 台達 4RU In-Rack 140kW vs 雙鴻 1.6MW L2L = **規模 vs 純度**對比
- 跟 [[高力 8996|高力]] 關係：
  - 雙鴻 CDU 內部 BPHE 採購高力（高力台灣 9 成市佔）
  - 高力是**潛在供應商 + 不直接競爭**
- 跟 Boyd / CoolIT 對比：
  - Boyd（被 Eaton 2026-03 併購）：cold plate + manifold + CDU 全鏈、規模略大但被 Eaton 整合後變 power + cooling 雙軌
  - CoolIT：純液冷 IP（CHx2000 2MW / OMNI 4,000W）、技術 IP 強但無台廠規模成本
  - → 雙鴻是**亞洲 cost-effective 領頭**（跟深圳 Cotran 並列拿 35% cold plate volume 市佔）、Boyd / CoolIT 走 IP / 規模高階路線
- 跟 [[Supermicro]] 關係：
  - 雙鴻是 Supermicro cold plate **主供**（其他玩家份額少）
  - Supermicro 是 NVDA Blackwell / Rubin 整機代工 top 玩家
  - → 雙鴻間接拿 Supermicro 的 NVDA 業務
- 跟 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] 關係：
  - **AI server ODM 必經之路**：cold plate / manifold 採購雙鴻
  - 跟 [[信昌電]]（MLCC）+ [[台達電]]（PSU）+ [[高力 8996|高力]]（BPHE）並列 ODM 鏈條 4 大零件供應商
- 護城河：
  - **CDU + cold plate + manifold 三鏈完整**（台廠唯一）
  - **1.6MW L2L CDU IP**（超前部署、業界少數能做 MW 級）
  - **Supermicro 主供 + 美系 top 5 cloud manifold 主供 + NVDA Rubin sample 驗證**
  - **泰國新廠**（2026 1 月開出、低成本擴產）
  - **規格深度**（vs 奇鋐純零件廠 model）
- 風險：
  - **2026 營收上修 70% 已 price in**（PE 18-25x 區間、媒體層滲透）
  - **NVDA universal QD 標準化**削弱供應商定價權
  - **奇鋐 cold plate 50%+ 市佔壓制**雙鴻 cold plate 規模成長
  - **Vertiv 自製 cold plate + Eaton-Boyd 整合**形成國際對手收斂壓力
  - **cold plate 價格戰**（亞洲 cost-effective 模式毛利率上限有限）
  - **Rubin 量產時序延後風險**
  - **NVDA Rubin sample 未必拿到大份額**（cold plate 4 認證供應商分配）
