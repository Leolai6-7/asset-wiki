# Cameron LNG（**⚠️ 非獨立上市 / Sempra Infrastructure 50.2% 持股 / reference entity only**）

> **⚠️ 重要警語**：Cameron LNG 非獨立上市公司、不可直接投資。本 entity 為 **reference only**（拆解 Cameron LNG 的所有權結構 + 對 [[Sempra LNG]] 業務貢獻的對照表）、用於跟 Sempra entity 內 LNG segment 對照、不適用五軸 25 分制評分。

## 1. 一句話定位

**Sempra Infrastructure 50.2% 持股主控 + TotalEnergies / 三井 / 三菱各 16.6% 合資的非獨立上市 LNG 液化廠 + Phase 1 ~12 MTPA（2019 完成）+ Phase 2 ~6.75 MTPA（2025-2027 擴張）+ Louisiana 墨西哥灣 anchor + 美國 LNG 出口前五大廠之一**——位於 Louisiana Hackberry、2014 開工、2019-08 Train 1 首次商業運轉、2020-05 Train 3 全 Phase 1 商業運轉；**持股結構**（截至 2026 已知）：[[Sempra LNG|Sempra Infrastructure]] **50.2% 主控** + TotalEnergies SE **16.6%** + 三井物產 Mitsui & Co **16.6%** + 三菱商事 Mitsubishi Corp **16.6%** = **「美 50%+ + 法日合資」結構**；**Phase 1（已運轉 2019）= ~12 MTPA（3 trains）**、**Phase 2（2025-2027 ramp）= +~6.75 MTPA**（兩 mid-scale trains）、**Phase 3（pending FID）= +~6.75 MTPA**；客戶 = TotalEnergies + 三井 + 三菱 + Saudi Aramco 等多元；美伊戰後 firm power 第五選擇 anchor 一部分（透過 Sempra Infrastructure 50.2% 持股給 [[Sempra LNG]] entity 業務貢獻）；**非五軸評分**（reference only / 非可投資 entity）；對沖 Sempra Infrastructure 業務曝險、是 [[Sempra LNG]] entity 的「LNG segment 拆解 anchor」。

## 2. 三層 thesis（reference only / 跟 Sempra Infrastructure 對照）

### 產業層

- LNG 產業 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
- Cameron LNG 作為美國前五大 LNG 出口廠：
  - **2019 Phase 1 商業運轉**：俄烏戰後（2022）受惠歐洲緊急採購美國 LNG、Cameron Phase 1 滿載運轉
  - **2025-2027 Phase 2 ramp**：跟進美伊戰後 Qatar -17% 缺口、Cameron Phase 2 是美國 LNG 出口擴張第二波重要 anchor
- 對應 [[AI infra 電力戰場]]：**第五選擇 firm power anchor 一部分**（透過 [[Sempra LNG]] 50.2% 持股給 hyperscaler 海外資料中心發電）
- Hackberry, Louisiana 地理：墨西哥灣沿岸 LNG 出口走廊（跟 Cheniere Sabine Pass 同一走廊）

### 目的層

- **業務組合（Cameron LNG 全部營收）**：
  - **Phase 1**：~12 MTPA × 三 trains × Tolling agreement（toller pays liquefaction fee）
  - **Phase 2（2025-2027 ramp）**：+~6.75 MTPA × 兩 mid-scale trains
  - **Phase 3（pending FID）**：+~6.75 MTPA
  - **完整 ramp 完成（2030）= ~25-26 MTPA**
- **核心產品**：
  - 液化天然氣（甲烷主導）+ 冷卻至 -162°C + Tolling agreement 結構（toller 提供天然氣、Cameron 收 liquefaction fee）
- **客戶結構**：
  - **TotalEnergies** Phase 1 主客戶（16.6% 股權對應 toller）
  - **三井物產** Phase 1 主客戶（16.6% 股權對應 toller）
  - **三菱商事** Phase 1 主客戶（16.6% 股權對應 toller）
  - **Saudi Aramco** Phase 2 + Phase 3 推測客戶
  - JV partners 同時是 toller（vertical 結構）
- 商業模式核心：
  - **「Sempra 50.2% + Total 16.6% + 三井 16.6% + 三菱 16.6% 合資 + Tolling agreement」**
  - **規格控制權**：標準化 LNG train 設計
  - **服務 recurring**：Tolling 20 年合約 = 結構性現金流（轉化為股東分紅）
- 對應 [[賣水人選股邏輯（投資版）]]：透過 Sempra 50.2% 持股 = LNG 出口 anchor 間接受惠

### 供應層

- 跟 [[Sempra LNG]] 路線：**Sempra Infrastructure 50.2% 主控 = Cameron LNG 全部營收 50.2% 進 Sempra Infrastructure 報表**
  - Cameron LNG 是 Sempra Infrastructure 業務組合中的最大單一資產（vs Port Arthur Phase 1 待 ramp / ECA Mexico 規模較小）
  - Sempra 透過 Cameron LNG 50.2% 持股取得「**Phase 1 已運轉現金流 + Phase 2 擴張 ramp + Phase 3 FID 期權**」三層曝險
- 跟 TotalEnergies 路線：**16.6% 股權 + 主要 toller**
  - TotalEnergies 透過 Cameron LNG 取得美國 LNG 出口曝險、規避歐洲 / 俄羅斯 LNG 依賴
- 跟 三井物產 / 三菱商事 路線：**各 16.6% 股權 + toller**
  - 日本商社透過 Cameron LNG 取得美國 LNG 出口曝險、服務日本 JERA / 東京 Gas / 大阪 Gas 等日本電力公司
  - 跟 [[ECA LNG Mexico]] 太平洋路徑共同形成 Sempra 「**美墨日韓 LNG 走廊**」
- 跟 [[Cheniere Energy]] Sabine Pass 對比（**同一 Louisiana 走廊**）：
  - Cheniere Sabine Pass ~30 MTPA（單一公司持股）vs Cameron LNG ~25-26 MTPA（四方合資）
  - Cheniere 持股結構更乾淨（100% Cheniere）vs Cameron 多方治理複雜
- 跟 [[Sempra LNG]] Port Arthur 對比（**Sempra 內部姊妹 LNG 資產**）：
  - Cameron Phase 1 已運轉 + Phase 2 ramp（2025-2027）= 短期主力
  - Port Arthur Phase 1 ramp（2027-2028）= 中期主力
  - ECA Mexico Phase 1（2025-2026 ramp）= 太平洋差異化
  - → Cameron 是 Sempra LNG 第一曲線、Port Arthur 是第二曲線、ECA Mexico 是太平洋差異化曲線
- 跟 [[Tellurian]]（→ Woodside Driftwood LNG）對比（**reference only / 已被 Woodside 收購**）：
  - Tellurian Driftwood LNG 在 Louisiana（vs Cameron Louisiana 同走廊）
  - Tellurian → Woodside（澳洲股東主導）vs Cameron（美法日合資、Sempra 主控）
  - 結構性對比：Cameron 是「美主控合資」vs Driftwood「澳洲收購美國 brownfield」
- 治理風險：
  - 四方合資治理：Sempra 50.2% 主控 + 三家 JV partners 各 16.6%
  - Total / 三井 / 三菱可能在 Phase 3 FID 退出 / 加碼
- 護城河：
  - **物理資產**：Phase 1 已運轉 + Phase 2 ramp + Phase 3 FID 期權三層
  - **客戶 = JV partners**：天然 lock-in 結構
  - **Louisiana 地理**：靠近 Henry Hub 天然氣供應 + 墨西哥灣航道
- 風險：
  - **非獨立上市 / 不可直接買進**：只能透過 Sempra 50.2% 間接持有
  - **JV partners 治理複雜**：四方決策週期長
  - **颶風 + 氣候風險**：Louisiana 墨西哥灣
  - **Phase 3 FID 不確定性**：取決於 LNG 市場前景 + JV partners 共識
  - **Trump 政府 LNG 出口許可**：vs Biden 凍結反覆風險
  - **Qatar Ras Laffan 修復快於 3-5 年**
