# Fortinet（NASDAQ: FTNT）

## 一句話定位（Sticky）

> **NGFW（Next-Gen Firewall）全球 #1 by unit shipped、中小企業 + 全球渠道密度龍頭、ASIC 自研 + 防火牆硬體 + SASE 整合 anchor。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **共識期**——NGFW 賽道穩定成長 8-12% CAGR、SASE / FortiSASE 二次成長曲線。

TAM：[[AI 資安戰場（CSP vs Endpoint vs Network 三軌）]] Network 軌 NGFW + SASE 段 ~$50B（2030）。

### 目的層

**「NGFW 中小企業 + 渠道密度王 + ASIC 自研垂直整合」**：FortiGate ASIC 自研（FortiASIC、NP/CP/SP 系列）= 同等規格下成本比 [[Palo Alto Networks]] / 純軟體競爭低 30-50%。

跟 PANW 30-35% NGFW 市佔（by revenue）對比：Fortinet 在 unit shipped 端全球 #1（30%+）、但 ASP 較低、營收市佔較 PANW 略小。

商業模式：硬體 + service 訂閱混合（vs ZS 100% SaaS / CRWD 100% SaaS 不同）= 估值倍數較低（**Forward PE 25-30x** vs ZS 50-70x / CRWD 60-80x）。

### 供應層

**賣水人**（[[賣水人選股邏輯（投資版）]]）：AI 時代中小企業資安需求結構性放大、Fortinet 是 NGFW + SASE 中小企業段主要受惠。
[[控制點轉移（投資版）]]：NGFW 硬體 + ASIC 自研是 Fortinet 對抗純軟體 / 雲端 SSE 的差異化護城河。
