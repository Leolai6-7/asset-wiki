# Synopsys（NASDAQ: SNPS / 新思科技）

## 1. 一句話定位

**EDA（電子設計自動化）全球 #1（~33% 市佔，跟 [[Cadence]] ~28% + [[Siemens]] EDA ~17% 形成「**EDA 三巨頭分食**」）+ 1986 成立 + AI 晶片設計 AI.Copilot first-mover + 2024-2025 完成 Ansys USD 35B 巨型併購（multiphysics simulation 整合）+ 跨晶片設計 / IP 授權 / verification / AI 智能設計鏈整合 + 任何晶片設計都要用 SNPS 工具 = 全行業 fabless / IDM AVL**——納斯達克上市、總部 Mountain View；不做晶片本身、**只做設計工具 + IP**；產品涵蓋 RTL synthesis / placement & routing / verification / DFT / multiphysics simulation（Ansys 併購補齊）/ DesignWare IP / FPGA-based prototyping / formal verification；跟 [[Cadence]] 形成「**EDA 雙頭 + Siemens EDA 第三**」結構性寡占、毛利率 ~70%+、**全行業 fabless / IDM / SoC 設計都要用 SNPS**。在 [[賣水人選股邏輯（投資版）]] 是「**真正的『賣水人之中的賣水人』**」（不押 NVDA / AMD / TSMC / 任何晶片公司、押**所有晶片設計都要 SNPS**）、估值 24-25/25 頂級、跟 [[Disco Corp]] / [[村田 Murata]] / [[信越化學]] / [[SUMCO]] 並列「**頂級真賣水人**」。

## 2. 三層 thesis

### 產業層

- **EDA 全球市佔**（Q1 2026 推估）：**Synopsys（~33%）**+ [[Cadence]]（~28%）+ Siemens EDA（~17%）+ 其他（~22%）
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——
  - 驗證已完成：FY2024-2025 多季財報持續超預期、AI 晶片設計 AI.Copilot 全面導入
  - 共識中：Forward PE 仍 35-45x（vs Cadence 40-50x、跟 EDA 全球寡占地位匹配）
- 在 [[資訊擴散四階段]]：機構長期覆蓋、賣方深度分析、媒體層熱炒 AI 設計、ETF 大量配置（軟體 + 半導體 ETF）
- TAM：
  - EDA 全市場：2024 USD 14B → 2030 USD 30B+（CAGR ~13%）
  - AI 晶片設計 + AI Copilot 自動設計：新增 TAM 翻倍
  - Ansys 併購後 multiphysics simulation 整合：跨產業擴張 TAM（航太 + 汽車 + 工業）
- 跟 [[AI infra CapEx 三階段論]] 視角：
  - 第一階段（CSP CapEx）：間接受惠（NVDA / AMD / hyperscaler 自家 ASIC 設計需求）
  - 第二階段（NVDA 落地）：直接受惠（NVDA / AVGO / Marvell / 自研 ASIC 都要 SNPS）
  - 第三階段（上游材料爆掉）：間接受惠（fab 製程 R&D 設計工具需求）
- [[Bottleneck Theory（瓶頸論）]] 視角：SNPS = **設計鏈 chokepoint**（任何晶片設計繞不開、IP 授權生態 lock-in）
- 跟 [[賣水人選股邏輯（投資版）]]「賣水人之中的賣水人」：跟 [[Disco Corp]] / [[村田 Murata]] / [[信越化學]] / [[SUMCO]] 同級

### 目的層

- 真實角色：**「EDA 全球 #1 + 任何晶片設計都要用 SNPS + DesignWare IP 標準 + Ansys multiphysics simulation 整合 + AI Copilot 自動設計 first-mover」**——不是「跟 fab 競爭」（vs TSMC / Samsung / Intel）、不是「跟 fabless 競爭」（vs NVDA / AMD / Apple）、是「**所有 fab / fabless / IDM 共用的設計工具供應商**」
- 業務組合（FY2025）：
  - **EDA Software（synthesis / P&R / verification / DFT）**：~50%
  - **Designware IP（USB / PCIe / DDR / Ethernet / SerDes 等標準 IP 授權）**：~25%
  - **Ansys multiphysics simulation**（2025 整合）：~15%
  - **Software Integrity（軟體品質檢測、原 Black Duck 等）**：~10%
- 商業模式：
  - **訂閱制 + maintenance**（recurring 高、毛利率 70%+）
  - **AI Copilot 加價**（AI-powered EDA 工具 = 額外 ARR）
  - **IP 授權**（DesignWare IP / Ansys IP / 自有專利）
  - **跨產業 multiphysics**（Ansys 併購後 = 跨晶片 / 航太 / 汽車 / 工業擴張）
- 核心 IP / 護城河：
  - **EDA 工具生態 lock-in**（晶片設計流程 30 年累積、切換成本極高）
  - **DesignWare IP 標準**（業界標準 USB / PCIe / DDR / Ethernet / SerDes 全部用 SNPS IP）
  - **Ansys multiphysics simulation**（USD 35B 併購、跨晶片 / 航太 / 汽車）
  - **AI Copilot first-mover**（生成式 AI 自動設計 RTL / verification）
  - **跨產業 lock-in**（fabless + IDM + 航太 + 汽車 + 工業 + AI 晶片設計）
- 對應 [[賣水人選股邏輯（投資版）]]：**「真正的『賣水人之中的賣水人』」**——不押 NVDA / AMD / TSMC / 任何晶片公司、押**所有晶片設計都要 SNPS**
- 對應 [[控制點轉移（投資版）]]：拿到「**EDA 工具生態 lock-in + DesignWare IP 標準 + Ansys multiphysics integration + AI Copilot first-mover**」四層 chokepoint、控制權結構性
- 對應 [[半導體基礎建設化]]：EDA 是「**全行業設計基礎建設**」、Re-rate 從週期軟體 → AI infra 元件級
- 對應 [[開源作為武器（投資版）]]：⚠️ SNPS 是**閉源 / 訂閱制**、跟開源 EDA（Yosys / Berkeley ABC）對比反向

### 供應層

- 跟 [[Cadence]] 關係（**核心對手**）：
  - **EDA 雙頭壟斷**（合計 ~61% 全球市佔）
  - 競爭 / 互補：SNPS synthesis + verification 領先 / Cadence custom IC + analog 領先
  - 客戶通常**雙頭採用**（fabless / IDM 用 SNPS + Cadence 雙頭工具）
  - 兩家不正面降價戰、共同壓制 Siemens EDA + 開源
- 跟 Siemens EDA 關係（EDA 第三）：
  - Siemens EDA ~17% 市佔（Mentor Graphics 併購後品牌）
  - 跟 Siemens Digital Industries 整合 / 工業軟體加值
  - 落後 SNPS + Cadence 雙頭壟斷
- 跟 [[NVDA]] / [[AMD]] / [[AVGO]] / Marvell / Apple 關係：
  - **所有 fabless 都採用 SNPS（多數雙頭 SNPS + Cadence）**
  - NVDA Rubin / Vera / Blackwell SoC 設計：SNPS 工具主導
  - AMD MI300 / MI400 / Genoa：SNPS 工具主導
  - AVGO Tomahawk 5/6 + Marvell DSP：SNPS 工具主導
  - Apple M / A 系列：SNPS 工具部分（也用 Cadence）
- 跟 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[GlobalFoundries]] 關係：
  - **fab 全部支援 SNPS 工具 PDK（process design kit）**
  - TSMC 2nm / 3nm / Samsung 2nm / Intel 18A / GlobalFoundries 22FDX 全 PDK 都用 SNPS + Cadence 雙頭
- 跟 [[Imec]] 關係：
  - Imec R&D + SNPS PDK / EDA 工具支持 pre-competitive R&D
  - SNPS 是 Imec 200+ 會員之一
- 跟自研 ASIC / hyperscaler 關係：
  - **Google TPU / AWS Trainium + Inferentia / Microsoft Maia / Meta MTIA 全部用 SNPS 工具設計**
  - hyperscaler 自研 ASIC ramp → SNPS TAM 結構性擴張
- 跟 [[AI infra CapEx 三階段論]] 視角：
  - SNPS 跨三個階段都受惠（軟體 + IP 訂閱制）
- 跟 Ansys 併購（2024-2025 完成）：
  - **USD 35B 巨型併購**（業界最大 EDA 整合案）
  - 整合 multiphysics simulation（航太 + 汽車 + 工業）
  - **TAM 翻倍**（從純 EDA → 跨產業 simulation）
- 跟開源 EDA（Yosys / Berkeley ABC / iVerilog 等）對比：
  - 開源 EDA 在 RISC-V 社群有部分採用
  - 商業 fab / fabless 仍 100% 用 SNPS + Cadence（驗證 / DFT / sign-off 工具開源無法替代）
  - SNPS 結構性壟斷不被開源威脅
- 護城河：
  - **EDA 工具生態 lock-in + 30 年累積**
  - **DesignWare IP 標準**
  - **Ansys multiphysics integration + 跨產業**
  - **AI Copilot first-mover**
  - **訂閱制 + maintenance recurring + 毛利率 70%+**
- 風險：
  - **Ansys 整合 ramp 不確定**（USD 35B 巨型併購整合風險）
  - **AI Copilot 競爭**（Cadence 也推 AI 自動設計、Google / OpenAI 部分競爭）
  - **開源 EDA long term**（RISC-V 社群推開源 EDA）
  - **EDA TAM 增速放緩**（核心 EDA 軟體 CAGR ~10%、AI Copilot 額外溢價）
  - **晶片設計 cycle 週期性**（fabless / IDM CapEx 波動）
  - **Forward PE 35-45x 已 price in**（vs Cadence 40-50x）
  - **中美脫鉤 + 中國市場限制**（美 BIS 限制 SNPS 對中國 fab 出口）
