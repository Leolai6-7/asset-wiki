# 信越化學（Shin-Etsu Chemical, 4063.JP）

## 1. 一句話定位

**全球 #1 矽晶圓（300mm + 200mm）+ 全球 #1 PVC + 半導體光阻劑全球三強 + pBN crucible（InP 必需）日本單一供應商 + 稀土磁鐵 + 矽利康 + 矽烷 + 多元化學品集團**——[[Bottleneck Theory（瓶頸論）]] **第 2 層 pBN crucible 單一供應商**（[[AXTI]] / [[Sumitomo Chemical]] / [[IQE]] 的 InP boule 拉晶必需）+ 跨多賽道 chokepoint、典型「**真賣水人之中的真賣水人**」、[[Bottleneck Theory（瓶頸論）]] 補完第 2 層 entity 空缺。

## 2. 三層 thesis

### 產業層

- 多賽道並行（每條都在 [[市場四階段：懷疑／驗證／共識／反轉]] 不同階段）：
  - **矽晶圓**（300mm + 200mm）：成熟 + 共識，跟 SUMCO 雙頭壟斷
  - **半導體光阻劑**（EUV / ArF）：共識，三強之一（JSR / TOK / 信越）
  - **pBN crucible**（InP 必需）：⚠️ **驗證 → 共識**（CPO 光通訊爆發、Serenity 框架 anchor）
  - **稀土磁鐵 / 矽利康 / 矽烷 / PVC**：成熟多元化（穩定現金流）
- 跟 [[AI infra CapEx 三階段論]] **三階段全鏈受惠**：
  - 第一階段（CSP CapEx）→ 信越 PVC + 矽利康（資料中心建設材料）
  - 第二階段（NVDA 設備）→ 信越光阻劑 + 矽晶圓（先進製程必須）
  - 第三階段（光通訊 + 上游材料）→ 信越 **pBN crucible + InP 化學品**（chokepoint anchor）
- 跟 [[Bottleneck Theory（瓶頸論）]]：第 2 層 **pBN crucible（pyrolytic boron nitride 坩堝）= InP boule 拉晶必需**、Serenity 框架單一供應商
- 跟 [[賣水人選股邏輯（投資版）]]：**「賣水人之中的賣水人」**——多賽道任何 fab / wafer / 製程 / boule 拉晶都要用
- 在 [[資訊擴散四階段]]：機構層滲透深（日經 225 成分股 + 全球 chemical fund 必持）、媒體層尚未爆發（pBN crucible niche 過於專業）

### 目的層

- **業務組合**（FY2025 預估）：
  - **PVC / Chlor-Alkali**：~30%（全球 #1 PVC、Shintech 美國子公司）
  - **半導體事業**（矽晶圓 + 光阻劑 + pBN + 矽烷氣體）：~30-35% ⭐（**真半導體曝險核心**）
  - **矽利康 / Specialty Chemicals**：~15-20%（包含矽烷 + 矽利康橡膠）
  - **稀土磁鐵 / 電子材料 / 其他**：~15-25%（NEOMAX 稀土磁鐵 + LED 用螢光粉）
- **半導體段細拆**：
  - **矽晶圓**：跟 SUMCO 雙頭壟斷（合計全球 50-60%）、300mm + 200mm 主導
  - **半導體光阻劑**：跟 JSR / TOK 三強分食（信越 ~20% 全球）、EUV + ArF + KrF 全線
  - **pBN crucible**：日本單一供應商（[[Bottleneck Theory（瓶頸論）]] 第 2 層 anchor）、InP / GaAs / Ge boule 拉晶必需
  - **矽烷氣體**：高純度 SiH4、3D NAND / DRAM 必需
- **AI infra 直接曝險**：
  - 矽晶圓：所有 fab 擴產（[[TSMC]] / [[Intel]] / [[Samsung Electronics]] / [[SK Hynix]] / [[Micron]] / [[GlobalFoundries]]）必經
  - 光阻劑：先進製程（EUV）必須、跟 EUV ramp 同步放量
  - pBN crucible：InP boule 拉晶必需，[[AXTI]] / [[Sumitomo Electric]] / [[IQE]] / Coherent / Lumentum InP wafer 上游
  - 矽烷氣體：HBM / 3D NAND 製程必需
- 客戶結構（多賽道分散度全球最高）：
  - **矽晶圓**：[[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[Micron]] / [[SK Hynix]] / [[GlobalFoundries]] 全部
  - **光阻劑**：所有 fab + photomask 廠
  - **pBN crucible**：[[AXTI]]（中國）/ [[Sumitomo Electric]] / [[IQE]] / Coherent / Lumentum + 學術機構
  - **PVC**：建材 + 醫療 + 工業多元
- 商業模式核心：
  - **「**多賽道全球 #1 / #2 + Bottleneck Theory 第 2 層 pBN crucible 單一供應商 + 跨光通訊 InP 整鏈上游**」**：典型百年化學集團 + 半導體賣水人雙引擎
  - **跨業務集團 portfolio**：PVC 現金流 + 半導體成長 + 稀土磁鐵 niche 多元穩定
  - **三條結構性護城河**：(1) 矽晶圓雙頭壟斷規模 (2) 光阻劑 IP + 製程 know-how (3) **pBN crucible 單一供應商 + InP 上游 anchor**
  - **日本國家半導體最後一張牌**（跟 SUMCO / [[Kioxia]] 並列國家戰略材料 anchor）
- 對應 [[賣水人選股邏輯（投資版）]]：**「賣水人之中的賣水人」純度最高版本**（多賽道任何技術路徑都要用）
- 對應 [[控制點轉移（投資版）]]：拿到「**矽晶圓雙頭壟斷 + 光阻劑三強 + pBN crucible 單一供應商**」三層 chokepoint、控制權**結構性**（化學 + 製程 know-how 護城河）

### 供應層

- 跟 [[Bottleneck Theory（瓶頸論）]] / Serenity 框架：
  - **第 2 層 pBN crucible 單一供應商**（Serenity 框架 anchor）
  - 「**pBN crucible 是 InP boule 拉晶必需**」（Bottleneck Theory 原文確認）
  - vs Soitec（SOI wafer）並列「**Safest Longs**」defensible compounder 候選（與 [[Tower Semiconductor]] 並列）
  - **間接受惠 [[AXTI]] / [[IQE]] / [[Sumitomo Chemical]] / [[Lumentum]] / [[Coherent]] / [[SIVE]] InP ramp**
- 跟 SUMCO 對比（矽晶圓雙頭壟斷主對手）：
  - 信越 ~30% 全球 + SUMCO ~25% 全球 = 雙頭壟斷 55-60%
  - 信越多元化更深（光阻劑 + pBN + PVC）、SUMCO 純矽晶圓更純度
  - 兩家不正面對打、共同壓制中國 GlobalWafers / Siltronic（被併購後）
- 跟 JSR / TOK 對比（光阻劑三強）：
  - 信越光阻劑 ~20% 全球 + JSR ~22% + TOK ~17% = 三強分食
  - 信越 EUV + ArF + KrF 全線 vs JSR EUV 領先、TOK 多元化
  - 三家共同壓制 [[Sumitomo Chemical]] / DuPont
- 跟 [[Sumitomo Chemical]] 對比（光阻劑 + 化學品多賽道對手）：
  - 信越多賽道全球 #1 / #2、Sumitomo 多元化但無單一賽道全球領先
  - **信越是 Sumitomo 在光阻劑 + 矽烷氣體的主要對手**（vs Sumitomo 在 SEMCO Glass Core JV 走玻璃陶瓷 niche）
  - 信越市值 ¥10-12 兆 (USD ~70-85B) >> Sumitomo Chemical ¥747B (USD ~5B) 14x+ 規模壓制
- 跟 [[AXTI]] 關係：
  - **AXTI 透過 BoYu JV 跟信越雙頭壟斷 pBN crucible**（Bottleneck Theory 標明）
  - 信越是日本單一供應商、AXTI BoYu JV 是中國本土製造
  - **兩家共同壟斷 pBN crucible global supply**（vs 印度 / 美國少數玩家無量級）
- 跟 [[IQE]] / [[Coherent]] / [[Lumentum]] / [[Sumitomo Electric]] 關係：
  - 全部都需要信越 pBN crucible 拉 InP boule
  - **信越是 InP 整鏈最上游 chokepoint anchor**（上游 [[AXTI]] 也共軛壟斷 pBN）
  - InP ramp 直接拉動信越 pBN segment（雖佔信越總營收 niche、但毛利率高）
- 跟 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[Micron]] / [[SK Hynix]] 關係：
  - 所有先進製程 fab 必經（矽晶圓 + 光阻劑 + 矽烷氣體）
  - 跟 ASML / 應材 並列「**fab 必經供應商**」
  - HBM 擴產 + 3D NAND 增層 + CoWoS / CoPoS 都間接拉動信越多賽道
- 跟 [[GlobalFoundries]] 關係：
  - 信越是 GFS 矽晶圓主要供應商之一（200mm + 300mm SOI 訂單）
  - GFS SiPho foundry + 對應 SOI wafer = 信越雙引擎
- 護城河：
  - **多賽道 #1 / #2 規模**（矽晶圓 + PVC 全球 #1、光阻劑 + pBN 全球 top 3）
  - **化學 + 製程 know-how IP**（百年 chemical engineering 累積）
  - **pBN crucible 單一供應商**（InP 整鏈上游 chokepoint）
  - **跨業務 portfolio**（PVC 現金流 + 半導體成長 + 稀土 niche）
  - **日本國家半導體戰略 anchor**（跟 SUMCO / [[Kioxia]] 並列）
- 風險：
  - **PVC 業務景氣循環風險**（建材週期）
  - **矽晶圓擴產追上**（SUMCO + GlobalWafers 競爭 + 中國國產替代 long tail）
  - **EUV 光阻劑 JSR 領先 + ASML JV 整合**（信越 EUV 慢一步）
  - **稀土磁鐵地緣風險**（中國國家管制 + 美國 IRA 補貼擾動）
  - **估值已 price in 多元龍頭**（Forward PE 20-25x、相對化學業 +30-50% 溢價）
  - **AI niche 段（pBN crucible）占總營收 < 3%**（純度低於 [[AXTI]] / [[IQE]] pure-play）
