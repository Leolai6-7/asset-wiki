# Wolfspeed（NYSE: WOLF）⚠️ Chapter 11 重組中

## 1. 一句話定位

**全球唯一純 SiC（碳化矽）pure-play + 200mm SiC wafer first-mover + Mohawk Valley NY fab + 2025-06 Chapter 11 申請（pre-packaged）+ 2025-09 重組計畫批准 → 2026 Q1 重新上市**——總部 Durham NC、1987 創立（原 Cree LED 母公司、2021 改名 Wolfspeed + 賣掉 LED 業務）；2024-2025 「AI 救不及 + EV 需求 ramp 慢於預期 + Mohawk Valley fab 良率不達 + 利息支付壓垮」**Chapter 11 申請 2025-06-30**；2025-09 重組計畫批准、債務從 USD $6.5B → ~$2B、Apollo / Renesas / SiC 客戶為主要新股東；**2026 Q1 重新上市（pre-packaged 重組、大多原股東 wipeout）**；目前估值 distressed、五軸僅供 reference / **NOT-INVESTABLE**（除非 AI ramp 突然救火 + Mohawk Valley 良率 2026 H2 達 50%）；是 [[800V HVDC 灰白區重劃（物理鐵壁論）]] 的反面教材——SiC 純度高 + 賽道領先但執行失敗 + 估值崩盤的 distressed case。

## 2. 三層 thesis

### 產業層

- **全球 SiC（碳化矽）市場**：~USD $5-7B（2025）、CAGR ~25-30%、2030 預估 ~USD $15-20B
- **SiC pure-play vs IDM 玩家**：
  - **Wolfspeed**：**100% 純 SiC pure-play**（wafer + device + MOSFET 全鏈，但 Chapter 11 重組中）
  - **STMicroelectronics + onsemi + Infineon**：SiC IDM（自有 SiC wafer + device + MOSFET、跨產品線）
  - **Bosch + Rohm**：SiC device 玩家（不做 wafer）
  - **中國 SiC**：Sanan IC + TankeBlue + SICC 規模化追趕
- **SiC 應用市場驅動**：
  - **EV powertrain**（Tesla / VW / BYD / Lucid）= 主場 65-70%（2025-2030）
  - **AI server 800V HVDC**（NVDA Rubin / GB200）= 新興 ~10-15%（2026 起）
  - **工業 + 太陽能 + 充電樁** = ~15-20%
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「反轉」**——SiC 需求 ramp 落後預期 + Wolfspeed Chapter 11 已驗證投資人共識崩盤
- 在 [[資訊擴散四階段]]：機構 + 賣方 + ETF 全部已撤、99%+ drawdown
- **Wolfspeed Chapter 11 timeline**：
  - 2024-Q1：股價從 $60+ → $20 區間（Mohawk Valley 良率不達公告）
  - 2024-Q3-Q4：股價 $5-10、Renesas $2B 預付款合作 + Apollo lending
  - 2025-03：CEO Gregg Lowe 下台、Robert Feurle 接任
  - 2025-06-30：申請 Chapter 11（pre-packaged）
  - 2025-09：重組計畫批准、債務從 $6.5B → ~$2B、Apollo + Renesas + SiC 客戶為主要新股東
  - 2026 Q1：重新上市（pre-packaged 重組、大多原股東 wipeout）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：⚠️ Wolfspeed 案例驗證「**chokepoint 領先 ≠ 投資成功**」——技術領先 200mm SiC wafer first-mover 但執行失敗 + capex 龐大 + 利息壓垮、是「**護城河 + 執行力 + 財務體質**」三軸缺一不可的反面教材

### 目的層

- 真實角色：**「曾經是純 SiC 龍頭」**（pre-Chapter 11 期間）+ **「現在是重組中的 distressed SiC 玩家」**（post-Chapter 11）
- 業務組合（FY2025 推估）：
  - **SiC wafer（200mm first-mover）**：~30-35%（賣給其他 SiC IDM）
  - **SiC MOSFET + 設備**：~50-55%（EV + 工業 + 太陽能）
  - **GaN（小段）**：~5-10%
  - **Legacy（已剝離 LED）**：~5%
- 核心 IP / 護城河（pre-Chapter 11）：
  - **200mm SiC wafer first-mover**（業界唯一 2024-2025 量產 200mm SiC wafer 廠商）
  - **Mohawk Valley NY fab**（全球最大 SiC fab、CHIPS Act 補助 USD 750M）
  - **SiC 全鏈整合**（wafer + device + MOSFET）
  - **30+ 年 SiC R&D 累積**（原 Cree 母公司）
- ⚠️ **執行失敗 + 財務崩盤**：
  - Mohawk Valley fab 良率 < 20%（vs 目標 50%）= EV ramp 慢於預期
  - capex USD $6-7B（Mohawk Valley + Building 10 NC fab）+ 利息支付 USD $200-300M/年壓垮現金流
  - Tesla / VW EV 銷量低於預期 → SiC 訂單 ramp 落後
  - Renesas $2B 預付款 2024-Q4 + Apollo lending 2024-Q4 都救不及

### 供應層

- 客戶結構（pre-Chapter 11）：
  - **Tesla**（SiC inverter 部分供應、但 Tesla 自家 ON / IFX SiC 多源）
  - **VW + Lucid + Ford + GM**（EV powertrain SiC inverter）
  - **Renesas（SiC IDM 客戶）**：2024-Q4 簽 $2B 10 年 SiC wafer 預付款 = 救命合約
  - **NVDA 800V HVDC AI server**（2026-起 nascent）
- 跟 [[onsemi]] 競爭（**SiC IDM 雙頭**）：onsemi SiC ~25-30% 全球市佔 + IDM 整合（自有 6"/8" SiC wafer + MOSFET + module）= 結構性穩定、Wolfspeed Chapter 11 釋出市佔給 onsemi
- 跟 [[Infineon]] 競爭（**SiC + GaN 雙料 IDM**）：Infineon SiC ~25-28% + GaN 雙料、汽車工業 AI 三軸最分散、8" SiC 量產領先 Wolfspeed = Wolfspeed Chapter 11 釋出市佔給 Infineon
- 跟 STMicroelectronics 競爭（**SiC IDM**）：STM SiC ~15-20% + Catania 義大利 fab、Tesla SiC inverter 主供 = STM 受惠 Wolfspeed 退場
- 跟中國 SiC（Sanan IC + TankeBlue + SICC）競爭：中國 SiC 規模化追趕 + 6" → 8" 升級、Wolfspeed Chapter 11 不影響中國 SiC ramp
- 跟 [[Navitas Semiconductor]] 對比（**GaN pure-play vs SiC pure-play**）：
  - **Navitas 19/25**（GaN pure-play、AI server 800V HVDC IC 主場、2026 OK）
  - **Wolfspeed 10-12/25 推估**（SiC pure-play、Chapter 11、distressed）
  - → 純 pure-play 在化合物半導體的兩條完全相反命運（GaN 成 / SiC 敗）
- 護城河（pre-Chapter 11）：
  - **200mm SiC wafer first-mover**
  - **Mohawk Valley fab + CHIPS Act 750M**
  - **SiC 全鏈整合**
  - **30+ 年 SiC R&D**
- 護城河（post-Chapter 11）：
  - **Renesas $2B 10 年合約鎖死部分需求**
  - **Apollo + 大客戶為新股東 + 重組後債務減半**
  - **Mohawk Valley fab 良率若 2026 H2 達 50% → AI ramp 救火**
- 風險：
  - **Mohawk Valley fab 良率執行**（2026 H2 達 50% 是 binary outcome）
  - **EV 需求 ramp 慢於預期**（Tesla / VW SiC inverter 訂單）
  - **AI 800V HVDC SiC 滲透慢**（NVDA Rubin 2027 才 ramp、Wolfspeed 救不及）
  - **Infineon + onsemi + STM 三家 SiC IDM 結構性蠶食市佔**
  - **中國 SiC 國產替代壓力**
  - **CHIPS Act 政治風險**（2028 政權更替）
  - **股東結構新洗（pre-packaged 重組 → 大多原股東 wipeout）**

### 對 [[800V HVDC 灰白區重劃（物理鐵壁論）]] thesis 影響

- ⚠️ **「800V HVDC SiC pure-play」單押的反面教材**——技術領先 + chokepoint 純度高 ≠ 投資成功
- **「800V HVDC 整鏈五站」白區功率 IC 段**：原 Wolfspeed 在 [[Infineon]] / [[Navitas Semiconductor]] / [[Texas Instruments TXN]] 並列、Chapter 11 後**從投資視角剔除**、僅作為 **reference 警惕** 留存
- **真正受惠 800V HVDC SiC**：[[Infineon]] 22（SiC + GaN 雙料 + 跨汽車工業 AI 三軸最分散）+ [[onsemi]] 19（SiC #2 + IGBT + Image Sensor 三軌）+ STMicroelectronics（未 entity）= **三家 SiC IDM 接管 Wolfspeed 退場後的市佔**

### 對 SiC pure-play 賽道 thesis 影響

- ⚠️ **「SiC pure-play」在賽道結構性弱於「SiC IDM」**——SiC IDM 有自有 wafer + device + MOSFET + 跨產品線（汽車 + 工業 + AI）+ 跨產業現金流穩定、SiC pure-play 一旦 capex 龐大 + 利息壓垮 → Chapter 11 結構性風險高
- **驗證 [[賣水人選股邏輯（投資版）]]「五軸評分」中「客戶分散」+「IP 控制」+「站別關鍵度」+「耗材 recurring」四軸都重要**：Wolfspeed 客戶分散 2/5 + IP 4/5 + 站別 5/5 + 耗材 3/5 + 路線 5/5 但仍因「**執行 + 財務體質 + capex/cash flow 失衡**」Chapter 11
- **教訓**：純度 pure-play 在化合物半導體賽道風險極高、IDM 跨產品線分散現金流結構性穩定
