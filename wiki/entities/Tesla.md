# Tesla（NASDAQ: TSLA）

## 1. 一句話定位

**全球 EV #2 整車品牌（2025 銷量被 BYD 超越）+ FSD / robotaxi anchor + Optimus 人形機器人 AI 實體資料收集 platform + Musk 控股 AI 生態（Tesla / SpaceX / xAI / Neuralink）拼圖一角**——2003 創辦（Martin Eberhard + Marc Tarpenning + Musk 後加入）、目前全球市值 USD ~$1-1.4T（vs NVDA / Microsoft / Apple Mega Cap top tier 略小一階）、Model 3 / Y 全球 EV 主流量產、Cybertruck + Model S/X 高階補位、**FSD（Full Self-Driving）+ robotaxi 2026-2027 商業化 anchor**（CyberCab + Optimus 雙引擎）+ **Dojo 自研 AI 訓練超算**；**雙身分定位**：(1) **EV 整車品牌**（Model 3/Y/S/X/Cybertruck）+ (2) **AI 實體資料 platform**（FSD / Optimus / Dojo / robotaxi）；Tesla 不是純 EV 公司、是 Musk 控股「**整合 AI 生態**」拼圖（與 SpaceX / xAI / Neuralink 互補）；Dan Ives 2026-05 預測 **Tesla / SpaceX 合併機率 80-90%**（vs 預測市場 ~40%）、垂直整合 AI 基礎建設 stack；治理風險顯著（Musk 個人決策 + SolarCity 2016 self-dealing 前例）。

## 2. 三層 thesis

### 產業層

- **全球 EV 整車賽道 [[市場四階段：懷疑／驗證／共識／反轉]]「共識 → 反轉」段**——Tesla 從 2018-2024 EV 全球 #1 → 2025 被 BYD 超越、競爭加劇
  - 2025 Tesla 全球交付 ~1.7M 台（vs BYD ~4M+ 含 PHEV）、純 EV Tesla 仍 #1-2 互拼
  - vs 比亞迪 / 廣汽 / 小米汽車 中國市場萎縮 + 歐美關稅戰
  - 中國市場（占 Tesla 25-30%）競爭最激烈
- **FSD / robotaxi 賽道 [[市場四階段]] 「驗證」段**：
  - **FSD v12-v13** end-to-end neural network 訓練、跟 Waymo / Cruise / Mobileye 路線競爭
  - **robotaxi（CyberCab）2026 量產**：$25,000-30,000 價格錨點、Tesla 首批 robotaxi fleet
  - **Dojo 自研超算**：FSD 訓練 anchor、跟 NVDA H100 / B200 fleet 雙軌
- **Optimus 人形機器人賽道 [[市場四階段]] 「懷疑 → 驗證」段**：
  - 2026 計畫小批量內部部署（Tesla 自家工廠）
  - 2027-2028 對外銷售（target price $20-30K）
  - **跟 Figure / Apptronik / Boston Dynamics 競爭**
  - **AI 實體資料收集 anchor**（Tesla 車輛 + Optimus = 物理世界 multimodal data）
- vs [[Apple]] / [[NVDA]] / [[Microsoft]] 結構性差異：
  - Apple = Edge AI 終端品牌、Tesla = **物理 AI（Embodied AI）終端品牌**
  - NVDA = AI infra 算力 anchor、Tesla = **AI 訓練自研 + 物理應用**雙軌
  - Tesla 跟 Apple 結構性類似（自有生態 + 終端硬體 + AI），但賽道完全不同（EV vs smartphone）

### 目的層

- 業務 mix（FY2025 ~$100-110B 營收估算）：
  - **汽車（Automotive）= ~80% 營收**（~$80-90B）
    - Model 3 / Y 主力（80%+ 銷量）
    - Cybertruck + Model S/X 補位
    - 毛利率（2025 H2）~17-19%（vs 2022 high 30%+）
  - **能源產生 + 儲存（Energy）= ~10%**（~$10-12B）
    - Megapack + Powerwall + Solar Roof
    - 高成長 segment、毛利率拉升至 25%+
  - **服務 + 其他（Services）= ~10%**（~$10B）
    - 充電網路（Supercharger）+ Service Center + 保險
- 客戶結構（C-end 消費者全球分散 + 能源 B2B 雙軌）：
  - 汽車 = C-end 消費者全球（北美 + 歐洲 + 中國 + 其他）
  - 能源 Megapack = B2B 大客戶（utility / hyperscaler / 政府）
  - **無單一客戶 > 5%**
- 商業模式 = **「整車 OEM + 自有充電網 + AI 自研 + 能源 + Optimus + robotaxi」六軸**：
  - **整車 OEM**：垂直整合（電池 + motor + 整車 + 軟體）
  - **自有充電網（Supercharger）**：全球 50,000+ 樁、對外開放（其他車廠付費）
  - **AI 自研（FSD + Dojo + Hardware 4.0/5.0）**：不依賴 NVDA / Mobileye / Waymo
  - **能源（Megapack + Powerwall）**：對沖 EV 競爭
  - **Optimus 人形機器人**：AI 實體資料 + 工廠自動化
  - **robotaxi（CyberCab）**：fleet 經濟 + ride-hailing 對抗 Waymo / Uber
- → 連 [[賣水人選股邏輯（投資版）]]：**Tesla 不是賣水人**——是「終端品牌 + 自有生態 + 物理 AI 應用」platform；類似 [[Apple]] 結構（雙身分定位）
- [[控制點轉移（投資版）]]：拿到「**EV 整車 + Supercharger 充電網 + FSD 軟體 + Dojo 自研超算 + Optimus 機器人 + robotaxi fleet**」六重 anchor、但「Musk 集中決策 + 治理紅旗」是雙刃劍

### 供應層

- **是 chokepoint platform / 不是賣水人**：終端品牌 + 自有 AI 自研、跟 [[Apple]] 結構同類但賽道完全不同
- 跟 [[NVDA]] 關係：
  - **Tesla 採購 NVDA H100 cluster（Cortex 100k GPU）**：FSD + Optimus 訓練用、~$2-4B 規模
  - **但 Dojo 自研超算**並行、降低對 NVDA 依賴
  - = **雙軌訓練 stack**（NVDA cluster + Dojo 自研）
- 跟 [[SpaceX]] 關係（**Musk 控股 sister company**）：
  - **2026-05 Dan Ives 預測 Tesla / SpaceX 合併 80-90%**（vs 預測市場 40%）
  - **長期 thesis**：整合 AI 生態（Tesla 車輛 / Optimus 實體資料 + Starlink 全球連網 + SpaceX 太空 anchor）
  - **2016 SolarCity 收購 self-dealing 前例**：合併執行面法律阻礙
  - **互補 anchor**：Tesla 物理 AI + SpaceX 太空 AI（Starshield 軌道算力 2028）
- 跟 [[xAI]] 關係（**Musk 控股 AI 公司**）：
  - Grok 跟 Tesla FSD / Optimus AI **可能共享資料 + 模型 IP**（待 Musk 整合確認）
  - Tesla 客戶資料 + Optimus 物理資料 → xAI 訓練 anchor
- 跟 Neuralink 關係：
  - BCI（腦機介面）長期 anchor、跟 Optimus 互補
- 跟 [[TSMC]] 關係：
  - **HW 4.0 / 5.0 晶片 TSMC 生產**（FSD 晶片自研設計、TSMC fab）
  - Dojo D1 晶片 TSMC 7nm（後續代可能升級）
- 跟 [[Apple]] 關係：
  - **結構性類比**（不直接競爭）：Apple = Edge AI smartphone、Tesla = 物理 AI vehicle / robot
  - 兩家都是「自有生態 + 自研 chip + 終端硬體」雙身分典範
- 護城河：
  - **EV 整車垂直整合 + Gigafactory 規模**
  - **Supercharger 全球 50,000+ 樁 + 對外開放收費**
  - **FSD + Dojo + Hardware 自研 4.0/5.0 全棧**
  - **Musk 個人品牌 + 粉絲文化（雙刃劍）**
  - **Optimus + robotaxi 2026-2028 商業化 first-mover 預期**
  - **Energy Megapack 高成長 + 毛利拉升對沖**
- 風險：
  - **EV 競爭加劇 + 毛利壓縮**：2022 30%+ → 2025 H2 17-19%、中國競爭最激烈
  - **Musk 集中決策 + 治理紅旗**：SolarCity 2016 self-dealing 前例、Tesla 董事會獨立性疑慮
  - **FSD / robotaxi 監管 + 法律責任**：自駕事故法律責任未定、跟 Waymo 路線競爭
  - **Optimus 商業化未驗證**：2027-2028 對外銷售計畫、競品（Figure / Boston Dynamics）並進
  - **中國市場萎縮**：BYD + 比亞迪 + 小米汽車競爭
  - **Tesla / SpaceX 合併執行風險**：Dan Ives 80-90% vs 預測市場 40% 差距、若合併失敗 → 股價回吐
  - **股價高估值風險**：Forward PE 80-100x、市場已 partial price in robotaxi + Optimus
- → 連 [[控制點轉移（投資版）]]：拿到「六重 anchor」、但「Musk 集中決策 + 法律治理 + FSD 監管 + Optimus 未驗證」四重風險

## ⭐ Tesla 在 Musk 控股 AI 生態的位置

Tesla 不獨立分析、需放在 **Musk 控股「整合 AI 生態」**框架：

| Musk 控股 | 角色 | AI 路線 |
|---|---|---|
| **Tesla** | **物理 AI 終端 + 實體資料**（車輛 / Optimus）| Embodied AI、FSD + robotaxi + Optimus |
| **SpaceX** | **太空 AI infra**（Starlink 全球連網 + Starshield 軌道算力）| 太空算力 + 衛星 AI |
| **xAI** | **大型語言模型**（Grok）+ **可能整合 Tesla / SpaceX 資料** | 跟 Anthropic / OpenAI / Gemini 競爭 |
| **Neuralink** | **腦機介面 + 神經科學 AI** | BCI + 神經訊號 |

→ Dan Ives 2026-05 預測 **Tesla + SpaceX 2027 合併 80-90%**（vs 預測市場 40%）= 整合 AI 生態垂直整合典範。
