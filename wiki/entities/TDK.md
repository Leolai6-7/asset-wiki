# TDK（6762.JP）

## 1. 一句話定位

**全球被動元件 + 矽負極電池 + 感測器多元組合王、MLCC 全球 top 3、SESUB 嵌入式模組獨家技術、Apple iPhone 電池主要供應商**——1935 年東京創業的日本被動元件巨頭、原是磁性材料 + Ferrite 起家、後續整合 Atotech / Tronics / Chirp / Faraday / InvenSense / Qeexo 等併購擴張至**四大事業群**（能源裝置 ¥1.37 兆營收占 55% / 被動元件 ¥593 億 / 磁性 ¥263 億 / 感測器 ¥225 億）；在 [[MLCC 嵌入式基板賽道]] 走「**SESUB（Semiconductor Embedded in SUBstrate）整合模組**」差異化路線（300μm 厚 1-2-1 4 層基板把 IC + passives 全埋進去、面積比傳統模組減 65%）、與 [[村田 Murata]] iPaS™ 並列日陣營兩大嵌入式平台、與 [[太陽誘電 Taiyo Yuden]] 純嵌入式 MLCC 形成**互補三角**；FY2026（截 2026-03）營收 **¥2.50 兆**（+13.6%）、OP **¥272.4 億**（+21.5%、創新高）、CEO Saito 宣告 **「AI data center 用被動元件營收成長 10 倍」**目標至 FY2031；市值 **¥7.50 兆**（USD ~470 億）、Forward PE 33.12。

## 2. 三層 thesis

### 產業層

- **多元化平台**——四大事業群、不是純 MLCC 廠
  - **能源裝置（Energy Applications）**：¥1.37 兆營收 / 55% = **核心**（含 Apple iPhone 電池主供 = ATL 母公司、矽負極電池技術領先）
  - **被動元件（Passive Components）**：¥593 億 / 24%（MLCC + 鋁電解電容 + 電感 + 薄膜電容）
  - **磁性應用（Magnetic Applications）**：¥263 億 / 11%（HDD 磁頭 / FY2027 預估 +50%）
  - **感測器應用（Sensor Application）**：¥225 億 / 9%（TMR 感測器、MEMS 麥克風、磁性/溫度/壓力感測器）
- 在 [[MLCC 嵌入式基板賽道]] 站「**SESUB 模組差異化**」位
  - SESUB 是「IC + passives 全埋進 300μm 4 層基板」、不是純嵌入式 MLCC（vs Taiyo Yuden ECP）
  - SESUB 1-2-1 4 層結構 = 4 個微結構基板層 + 含 IC 連接 + via，全部 300μm
  - **面積比傳統模組減 65%**（[TDK 官方產品頁](https://product.tdk.com/en/products/substrate/substrate/sesub/index.html)）
  - 主應用：smartphone PMU（電源管理 IC）+ Bluetooth Smart 模組 + 健康/穿戴裝置
- **AI server 被動元件**——CEO Saito FY2026 全年法說會明確宣告「**AI data center 用 passive components 營收 10 倍成長**」（[TDK FY2026 法說會](https://www.tdk.com/en/ir/ir_events/conference/2026/4q_2.html)）
  - 目標 FY2031 達成 + AI 市場營收 CAGR ~25-30%
  - 重點：高壓 MLCC（400→800V）+ 低壓高容 MLCC + 薄膜電感 + 鋁電解 / 薄膜電容（snap-in 為 Infineon 8kW/12kW AI server PSU 用）
  - AI / data center 目標占 TDK 總營收 **15% by FY2027**
- [[資訊擴散四階段]]：日本機構（村田 / 京瓷 sell-side）→ 西方主流（Bloomberg Apple 電池供應商敘事）→ ETF 三段擴散完成

### 目的層

- **真實角色**：「**被動元件 + 能源 + 感測器 + 磁頭多腳老牌平台**」——不是單純 MLCC 純度玩家
  - FY2026 4 事業群皆 +6 ~ +18.6% YoY、無弱點 = 抗 cyclical 強
  - vs Taiyo Yuden（純 MLCC 利基）+ vs Murata（純被動 + iPaS）= TDK 多元 + 規模
- 主業 mix（FY2026 全年）：
  - **能源裝置**：¥1,370 億 OP / OPM 18%、含 Apple iPhone 鋰電池主供（ATL 母公司、市佔 30%+）
  - **被動元件**：¥593 億 / OP ¥41.8 億（OPM 7%）、MLCC + 鋁電解 + 電感全 line up
  - **磁性應用**：¥263 億 / OP ¥27.0 億、HDD 磁頭 + 鐵氧體 + 薄膜
  - **感測器應用**：¥225 億 / OP ¥20.7 億（OPM 9.2%）、TMR + MEMS
- 客戶結構：
  - **Apple iPhone**：能源裝置段主供電池、矽負極第 4 代 2026-09 上市配合 Apple 新機 / 折疊機
  - **AI server**：被動元件段主推（鋁電解 + 高壓 MLCC + 薄膜電感 + 鋁電解 snap-in）、CEO 宣告 10 倍成長
  - **自動車**：MLCC（自動化 / EV）+ 感測器（TMR / MEMS / 溫度 / 壓力）+ 磁頭
  - **資料中心 HDD**：FY2027 預估 +50% 量產（[FY2027 指引](https://www.tdk.com/en/ir/ir_events/conference/2026/4q_2.html)）
- **戰略路徑**：「**多元組合 + AI 重押 + 規模化嵌入模組**」
  - SESUB 模組做 smartphone PMU + Bluetooth + 健康穿戴 → 但**還沒切到 AI server / 純 MLCC 嵌入式**
  - 跟 Infineon 合作把 inductor + capacitor 共封 SiC 模組（EV traction 系統 100kHz+ switching）
  - TDK Ventures 投資 C2i Semiconductors 革新 AI data center 電源傳輸（[BusinessWire 2026-05-27](https://www.businesswire.com/news/home/20260527489510/en/TDK-Ventures-Invests-in-C2i-Semiconductors-to-Revolutionize-AI-Data-Center-Power-Delivery)）
- → 連 [[賣水人選股邏輯（投資版）]]：是「**多腳賣水人**」、Apple 電池 + AI 被動 + HDD 磁頭三條曲線同向

### 供應層

- **路線多押**：被動元件 + SESUB 模組 + 矽負極電池 + 感測器 + 磁頭 + Infineon 合作 SiC 嵌入
- 護城河四層：
  - **SESUB IP**：300μm 4 層 IC 嵌入式基板獨有技術（vs Murata iPaS 是鋁電解 + 平面 coil 整合、不同範式）
  - **矽負極電池技術**：第 4 代 2026-09 上市、能量密度比傳統石墨高 15%、Apple 折疊機 / iPhone 17 Air 採用
  - **規模 + 多元**：USD 470 億市值、四事業群均成長、cyclical 風險分散
  - **客戶 lock-in**：Apple iPhone 電池 / Infineon 8-12kW PSU / 多個 hyperscaler PSU 供應
- 競爭格局：
  - **vs [[村田 Murata]]**（日陣營協同 + 規模次級）：規模差 1/2.5（TDK ¥7.5 兆 vs Murata ¥18.97 兆）；MLCC TDK ~12-15% 市佔 vs Murata 40-50%；**SESUB vs iPaS 並行**（不同範式、不直撞）
  - **vs [[太陽誘電 Taiyo Yuden]]**（日陣營協同 / 互補）：Taiyo Yuden 純嵌入式 MLCC（ECP）vs TDK SESUB 全模組嵌入 + 鋁電解 AI 電源 = **路線完全不重疊**
  - **vs [[Samsung Electro-Mechanics]]**（韓陣營間接威脅）：SEMCO 越南嵌入式 MLCC 產線 + 矽電容 USD 10 億合約 → 在 AI server BOM 各層搶 TDK 份額；但 TDK 多元組合 + Apple 電池 + HDD 磁頭抗衝擊強
  - **vs [[國巨]]**（規模對撞）：TDK USD 470 億 vs 國巨 USD ~30 億 = 規模差 15 倍；國巨鉭電容 #1 + 晶片電阻 #1，TDK MLCC + 矽負極 + 感測器多元
  - **vs [[華新科]] / [[信昌電]]**（mid-tier MLCC 對撞）：TDK MLCC 高壓 + 多元 vs 華新科 mid-low、信昌電高壓利基
- 風險：
  - **被動元件 OPM 僅 7%（vs 能源裝置 18%）**：MLCC 部分本期 ASP 跌，靠車用補
  - **規模差村田 1/2.5**：分立 MLCC 戰爭打不過 Murata、要靠 SESUB + AI 高壓利基突圍
  - **SESUB 應用偏 smartphone PMU + Bluetooth**：尚未滲透 AI server / NVDA / Apple Baltra 鏈、嵌入式 MLCC 賽道 IP 仍輸 Taiyo Yuden
  - **HDD 磁頭 cyclical**：FY2027 +50% 是「補貨潮」、不是結構性成長
  - **Apple 議價力強**：能源裝置段 OP 雖高、Apple 折疊機進度延遲會傳導
- → 連 [[控制點轉移（投資版）]]：拿到「**矽負極電池 + SESUB 模組 + 鋁電解 AI PSU + HDD 磁頭**」四層控制點、是少數「**載板 + MLCC + 電池 + 感測器**全棟嵌入式機會」的混合玩家

## ⭐ 對 [[村田 Murata]] / [[Samsung Electro-Mechanics]] / [[國巨]] / [[華新科]] 的意義

對既有玩家：

### vs [[村田 Murata]]（日陣營協同 + 規模次級）

- **bull case**：TDK SESUB + Murata iPaS = 日陣營兩大嵌入式範式並行、整鏈推進市場接受度
- **bear case**：Murata 規模 + 客戶 + iPaS 商業化都領先、TDK SESUB 還在 smartphone PMU 階段；分立 MLCC TDK 12-15% 市佔 vs Murata 40-50% = 永遠 underdog
- **結構性差異**：TDK SESUB（IC + passives 全嵌 300μm 模組）vs Murata iPaS（鋁電解 + coil + VPD power module）= **不同範式、不直撞**；TDK 多元（電池 + 磁頭 + 感測器）vs Murata 純被動 + 矽電容寡占

### vs [[Samsung Electro-Mechanics]]（韓陣營間接威脅）

- **bull case**：SEMCO 越南產線 + 矽電容 USD 10 億合約是 niche 點突破、不影響 TDK 多元組合 + Apple 電池 + HDD
- **bear case**：SEMCO 在 AI server BOM 多層搶份額 + Samsung HBM4 集團整合 → TDK 在 AI server 被動元件鏈被擠壓
- **結構性差異**：TDK 多元組合 vs SEMCO 載板 + MLCC + 矽電容 + Samsung 集團整合 = TDK 不在 Samsung 集團體系外圍

### vs [[太陽誘電 Taiyo Yuden]]（日陣營協同 + 互補）

- 兩家路線完全不重疊：Taiyo Yuden 純嵌入式 MLCC（ECP）vs TDK SESUB（IC + passives 模組）+ 鋁電解 + 感測器 + 電池
- **bull case 雙方**：日陣營三家（村田 + Taiyo Yuden + TDK）整鏈受惠 AI server 漲價、合計市佔 ~70%
- **bear case**：TDK 規模 + 多元若也跟進嵌入式 MLCC 純品（vs SESUB 模組）→ Taiyo Yuden first-mover IP 優勢面臨擠壓
- 五軸 TDK 19/25 ≈ Taiyo Yuden 19/25（IP 軸 Taiyo Yuden 領先 1 分、客戶分散 TDK 領先 2 分）

### vs [[國巨]] / [[華新科]] / [[信昌電]]（台陣營間接威脅）

- **bull case 對台廠**：TDK 嵌入式仍是 mid-end SESUB 模組、台廠 mid-low end 分立 MLCC TAM 暫不受 immediate 影響
- **bear case 對台廠**：TDK CEO 宣告 AI data center 用被動元件 10 倍成長 → 直接擠 [[國巨]] AI 占比 14-15% 的擴張空間；TDK 高壓 MLCC + 鋁電解 AI PSU 直接威脅 [[信昌電]] 高壓 MLCC 利基
- **規模對照**：TDK USD 470 億 vs 國巨 USD ~30 億 = 規模差 15 倍

## ⭐ 對台廠 MLCC 三角的意義（[[國巨]] / [[華新科]] / [[信昌電]]）

### bull case 對台廠

- TDK 多元組合 + 規模差 15 倍 → 台廠 niche 中階 MLCC 仍有差異化空間
- AI server PSU 鋁電解 snap-in 是 TDK 主推、台廠不在這條鏈、短期不衝擊
- TDK SESUB 偏 smartphone PMU、未切 AI server → 台廠 mid-end 分立 MLCC TAM 不受 immediate 影響
- 整體 AI server 用 MLCC 30 倍 vs 手機（GB300 機架 45 萬顆）→ 台廠跟著吃漲價傳導

### bear case 對台廠

- **CEO Saito 宣告 AI data center 用被動 10 倍成長 by FY2031**：直接擠 [[國巨]] / [[華新科]] AI 占比擴張空間
- TDK 高壓 MLCC（100V 3225 size + soft termination）+ 鋁電解 800V → **直接威脅 [[信昌電]] 高壓 MLCC 利基**（NVDA Rubin 1MW 機櫃高壓 MLCC 倍增 10 倍）
- TDK 規模 + IP + Apple 鏈綁定 → 台廠 design partner 機會更窄
- 日陣營協同（村田 + Taiyo Yuden + TDK）整鏈閉環、TDK 增加日陣營 AI 鏈份額 = 台廠 niche 機會被擠壓

### 給 TGV 投資人的對沖視角

- TDK 是「**多元組合王**」、適合作為 [[村田 Murata]]（純被動高純度）的「**多元期權型**」對沖
- pair trade：**做多 TDK（多元組合 + Apple 電池 + HDD 補貨）vs 做空台廠純 MLCC 廠（規模差 15 倍 + 無多元線）**
- 跟村田 / Taiyo Yuden 比：TDK 適合「**穩健 + 中速成長**」、村田適合「**純被動 + AI 純度**」、Taiyo Yuden 適合「**niche IP first-mover**」
