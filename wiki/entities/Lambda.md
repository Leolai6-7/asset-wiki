# Lambda（private、無 ticker、⚠️ 私募追蹤）

> ⚠️ **Lambda 為私募未上市公司、NOT directly investable**（無 ticker、無公開股價）。本 entity 為 reference 追蹤、用於對照 [[CoreWeave]]、預判潛在 IPO（業界傳言 2026 H2 - 2027 H1 上市窗口）。

## 1. 一句話定位

**neocloud #2 + NVDA NCP Elite tier + 1.6T 光模組首批採購者 + GPU AI cloud 開拓者**——2012 起源（San Francisco、Stephen Balaban + Michael Balaban 兄弟創辦）、最早是「DeepArt 風格遷移」AI consumer 公司、2017 pivot 到「**GPU workstation + GPU cloud**」、現在是「**AI native 純 GPU 雲**」（不做 general purpose cloud）；vs [[CoreWeave]] 三大差異：(1) **更早起家**（2012 vs CoreWeave 2017）但**規模較小**（私募估值 $4-6B vs CoreWeave 上市市值 $70B）、(2) **NVDA NCP Elite tier**（與 CoreWeave 並列 NVDA Cloud Partner 頂級認證）、(3) **research-first 客戶結構**（Anthropic / Microsoft Research / OpenAI early days / 學術 + AI native）；**[[AI infra CapEx 三階段論]] 第三階段 anchor 客戶**——與 [[CoreWeave]] 並列五大 1.6T 光模組首批採購者；2024-02 Series C $320M @ $1.5B valuation (lead by 770 Capital)、2025-07 Series D 完成 $480M @ $4-5B（lead Andra Capital）、**2026-04 傳言準備 IPO**（高盛 + 摩根士丹利掛帥）但時程未定 → **本 entity 標 ⚠️ 私募追蹤**。

## 2. 三層 thesis

### 產業層

- neocloud 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——與 [[CoreWeave]] 同處同階段
  - 不做 general purpose cloud（vs AWS / Azure / GCP）
  - 不做 retail（純 enterprise + research）
  - 只做 GPU 算力 + 配套 networking + Lambda 1-Click Cluster（簡化部署）
- vs [[CoreWeave]] 結構性差異（**「Lambda 是 neocloud 創始者、CoreWeave 是 neocloud 規模王」**）：
  - **歷史**：Lambda 2012 創立、2017 GPU workstation 開賣、2018 Lambda Cloud GA → **業界最早 GPU cloud**
  - **規模**：私募估值 $4-6B vs CoreWeave 上市 $70B = **規模差 15-20x**
  - **客戶結構**：Lambda 50% research / academic / AI native、CoreWeave 60%+ Microsoft 一家
  - **採購策略**：Lambda 更分散買 NVDA + AMD MI300、CoreWeave 100% NVDA stack
  - **網路 reference architecture**：Lambda 有 Spectrum-X + Quantum-X 部署（與 CoreWeave 並列 NCP Elite），但 vs CoreWeave 規模更小
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 2-3（私募估值仍偏 niche 機構發掘、IPO 時程未定 = 散戶尚未直接接觸）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1-2 層 anchor 客戶
  - **2026 Q3** Rubin 平台首批出貨：Lambda 與 [[CoreWeave]] 並列 first wave 採購者
- vs Crusoe / Nebius / Vast.ai 等 neocloud 同業：
  - **Lambda = neocloud 全球 #2**（vs CoreWeave 第一、Crusoe / Nebius / Vast.ai 屬第三梯）
  - 護城河：Lambda 1-Click Cluster + 13 年 GPU cloud 經驗 + NVDA NCP Elite tier + research / AI native 客戶忠誠

### 目的層

- 業務 mix（推估、無公開財報）：
  - **Lambda Cloud（GPU 雲）= 70-80%**
    - On-demand GPU instances（H100 / H200 / B200）
    - **1-Click Cluster**（一鍵部署 multi-node GPU cluster）= 簡化客戶採購
    - 客戶 prepay + 長約模式
  - **Lambda Workstation + Server（硬體銷售）= 20-30%**
    - Lambda Tensorbook（深度學習 laptop）= 創始業務
    - Lambda Echelon GPU server（NVIDIA HGX 平台）
    - 硬體銷售毛利率 thin、但帶動 cloud 業務 lock-in
- 客戶結構（推估）：
  - **AI 研究實驗室與大公司 internal team**：Anthropic、Microsoft Research、OpenAI（early days）、Apple、IBM Research
  - **學術機構**：Stanford、MIT、UC Berkeley、CMU 等（discount tier）
  - **AI native startup**：Hundreds of small AI native 公司、初創、無 hyperscaler 預付金
  - **Enterprise**：Sony、Samsung Research、Disney Research 等
  - vs CoreWeave 集中度低很多（Lambda Top 5 客戶 ~40-50% vs CoreWeave Top 3 90%+）
- 商業模式 = **「GPU 雲 + Workstation + 1-Click Cluster」三軌混合**：
  - 比 CoreWeave 更分散（multi-revenue stream）
  - 但規模小（年營收 $500M-1B 推估 vs CoreWeave FY2026 指引 $15-18B = 規模差 15-30x）
  - **2025-12 推 1-Click Cluster 8-512 GPU**：自助化降低客戶採購門檻
- → 連 [[賣水人選股邏輯（投資版）]]：**GPU 雲端「分散版受惠者」**——vs CoreWeave 是集中版、Lambda 是 niche / research / AI native 客戶分散版
- [[控制點轉移（投資版）]]：拿到「**NVDA NCP Elite tier + 13 年 GPU cloud 經驗 + 1-Click Cluster IP + 研究機構客戶忠誠**」四重 anchor、但**比 CoreWeave 控制點外溢少**（NVDA 沒有 backstop Lambda）

### 供應層

- 跟 [[NVDA]] 關係：
  - **NVDA NCP Elite tier**（與 CoreWeave 並列頂級認證）
  - **NVDA 戰略投資**：2024-02 Series C NVDA 跟投（金額未公開、估 $50M 級）
  - **NVDA 首批 Spectrum-X 部署**（2026 H2 Rubin 平台首批採購）
  - **NVDA 沒有 backstop**（不像 CoreWeave $6.3B）= Lambda 結構性風險缺乏 NVDA 兜底
- 跟 OpenAI 關係：
  - **OpenAI early days 主力**（2018-2020 Lambda 是 OpenAI 主訓練設施之一）
  - 後期 OpenAI 移到 Microsoft Azure + 自家 Stargate
  - Lambda 仍與 OpenAI 保持聯絡（部分推理 workload）
- 跟 Anthropic 關係：
  - **Anthropic 主訓練 cluster 之一**（2023-2025）
  - 但 Anthropic 主要轉向 AWS Trainium（$4B 投資）+ Google TPU
  - Lambda 保留 Anthropic part of training fleet
- 跟 [[Microsoft]] 關係：
  - **Microsoft Research 主訓練 cluster**
  - Microsoft 不是 Lambda 主要長約客戶（不像 CoreWeave）
- 跟 [[AVGO]] 關係：
  - Lambda 部分 fleet 採用 Tomahawk 6 + multi-source（與 CoreWeave 類似）
  - reference architecture 仍以 NVDA Spectrum-X 為主
- 護城河：
  - **NVDA NCP Elite tier + 13 年 GPU cloud 經驗**
  - **1-Click Cluster IP**（自動化 GPU cluster 部署）= 自助化降低客戶採購門檻
  - **research / AI native 客戶忠誠**（vs CoreWeave 集中 enterprise）
  - **Lambda Tensorbook + Echelon 硬體**（雙軌混合營收）
- 風險：
  - **規模小 + 私募 + 競爭加劇**：vs CoreWeave 規模差 15-20x、vs Crusoe / Nebius 規模差小 → Lambda 中間夾擊
  - **NVDA 沒有 backstop**：Lambda 不享 CoreWeave $6.3B 安全網、結構性風險裸露
  - **IPO 時程未定**：私募 valuation 已飆 $4-6B、二級市場退場路徑不明
  - **AI infra CapEx 拐點風險**：若 [[FCF 拐點]] 提前 → neocloud 整體賽道折價（CoreWeave 已 IPO 有資本緩衝、Lambda 無）
  - **hyperscaler 自家 ASIC 擠壓**：AWS Trainium / Google TPU 等切走 Lambda 部分客戶
  - **AI native 客戶 churn 風險**：Anthropic / OpenAI 轉向自建 / hyperscaler → Lambda backlog 風險
- → 連 [[控制點轉移（投資版）]]：拿到「**neocloud 創始者位置 + NCP Elite + 1-Click Cluster IP**」三重 anchor、但**規模天花板**（vs CoreWeave）+ **IPO 時程未定**（vs CoreWeave 已 IPO）兩個結構性劣勢

## ⭐ 對 [[NVDA]] / 三階段論的意義

對既有 wiki entity：

### Bull case

- **1.6T 光模組首批採購者**：Lambda 與 CoreWeave 並列、雙頭加總增量達 [[Lumentum]] / [[Coherent]] / [[IQE]] 整鏈受益

- Lambda IPO 延後或失敗 → neocloud 賽道唯一 entity 只剩 CoreWeave + 集中度風險加重
- Lambda 中間夾擊（vs CoreWeave 規模 + Crusoe / Nebius 競爭）失血 → neocloud 賽道整體 thesis 受質疑
- NVDA Stack 採購被 hyperscaler ASIC 擠壓 → Lambda + CoreWeave 連動受壓
