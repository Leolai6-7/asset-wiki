# 雷科（6207.TW）

## 1. 一句話定位

**跨製程多刀流的雷射設備廠**（CoWoS / TGV / SiC / 厚板切割），正在用 TGV 與厚板切割挑戰日系獨佔；客戶為 ABF 板廠（南電/欣興/景碩）→ [[AMD]] / [[NVDA]] 終端。

## 2. 三層 thesis

### 產業層
- TGV 製程鏈**第 1 站雷射打孔 + 第 9 站切割**雙站
- [[市場四階段：懷疑／驗證／共識／反轉]]：早期驗證階段
- **anchor 訊號**：[[AMD]]/[[NVDA]] 認證 2026 Q1 定案、Q4 隨 NVIDIA 終端產品放量
- 同時暴露 CoWoS（已 ramp）+ TGV（驗證中）+ SiC（成長中）+ 厚板切割（替代日系）—**比鈦昇更分散**

### 目的層
- 賣設備為主，**自製比例提升是核心策略**
- 自製設備出貨佔比由 40% → 50%+（2026 目標）→ 把毛利率從外購 OEM 拉回自有設備的 40% 水準
- → 從「代理 OEM」變「自製設備商」是 [[Re-rate 捕捉法]] 第二層觸發

### 供應層
- **是「賣水人」也是「挑戰者」**
- CoWoS 段：中性受惠（已 in [[NVDA]] 主力封測廠供應鏈）
- TGV 段：**押直接打孔路線**（vs [[鈦昇]] 雷射改質）— 連 [[TGV 路線分歧（雷射改質 vs 雷射打孔）]]
- 厚板切割（1mm+）：挑戰日系三菱獨佔
- 護城河：飛秒雷射技術 know-how + **多製程整合能力**
- 風險：認證若被頂掉 / TGV 路線輸給鈦昇

### ✅ 催化
- [[AMD]]/[[NVDA]] 認證 2026 Q1 定案、Q4 放量
- 半導體雷射設備已**打入 NVIDIA 主力封測廠供應鏈**（CoWoS 應用）
- 2026 設備營收指引 +35% YoY
- 自製比例提升 → 毛利率結構性改善
- SiC 飛秒切割成長中（多元支撐）

### ⚠️ 風險
- 與 [[鈦昇]] 雷射改質路線競爭，TGV 賽道 binary outcome
- AMD/NVIDIA 認證若被頂掉 → 直接失血
- 連 6 漲 +48% = 已被炒高、短期回調風險
- 2026 Q1 EPS 大幅衰退（季減 70%）說明短期壓力大
- **[[Disco Corp]] DFD6080 正式進攻玻璃切割（2025-12 發表，最大 binary risk）**：
  - 明確支援 resin + **glass substrate** + lead frame 多材料
  - **1.8 kW 高功率主軸**直接覆蓋雷科賴以差異化的「厚板切割」（1mm+）
  - **1200 倍體量差**（Disco JPY 7.59T vs 雷科 NT$122 億）+ 龐大 install base + 耗材年金 + Stealth Dicing 是 SiC/GaN 事實標準
  - 雷科必須在 2026-2027 用 AMD/NVDA 認證鎖死 ABF 板鏈 design-in，否則 Disco 一旦正面進場就回不來
