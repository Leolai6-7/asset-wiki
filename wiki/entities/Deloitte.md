# Deloitte（私募合夥制、非上市）

> **⚠️ 重要警語**：Deloitte 是私募合夥制 Limited Liability Partnership（LLP）、**非上市公司、NOT-INVESTABLE**（沒有 ticker、無法直接投資）。本 entity 主要作 **[[Accenture]] 對照組 + 「企業 AI 諮詢三巨頭」結構性 reference**、五軸評分**不適用**（無法跟上市公司同框比較）、僅作 reference entity 記錄業務組合 + AI 投入 + 客戶結構。

## 1. 一句話定位

**全球 IT 諮詢 + 系統整合 + 服務 #2（vs [[Accenture]] #1、PwC / EY / KPMG 並列）+ Big Four 之一（含 Audit + Tax + Consulting + Risk Advisory）+ 私募合夥制、非投資標的 + Deloitte AI Institute + Generative AI accelerator + 跨產業企業 AI 導入 + 「企業 AI 諮詢三巨頭」之一**——1845 William Welch Deloitte 創於倫敦、1989 跟 Touche Ross + Tohmatsu Aoki 合併形成 Deloitte Touche Tohmatsu、1993 改名 Deloitte Touche Tohmatsu Limited（DTTL）；現任 Global CEO **Joe Ucuzoglu**（2023-01 接任、前 Deloitte US CEO）；員工 **~457,000**（vs [[Accenture]] 789K / IBM 270K / TCS 615K / EY 400K / PwC 295K / KPMG 273K）；業務組合（FY2024 8 月年結）：**Audit & Assurance ~30% + Consulting ~35% + Tax & Legal ~15% + Risk Advisory + Financial Advisory ~20%**；FY2024 全球營收 **~$67B**（vs [[Accenture]] $65B 同級）；AI 諮詢：**Deloitte AI Institute** + **Generative AI accelerator** + 跨產業企業 AI 導入（金融 + 健康 + 政府 + 零售 + 製造）；客戶 Fortune 500 + 政府（含 GSA / DoD / EU government + UK 政府）+ 跨產業；私募合夥制：dispersed partner 結構（~7,000 全球合夥人、各國家分屬不同 member firm）、無上市計畫；跟 [[Accenture]] / IBM Consulting / PwC / EY / KPMG 形成「**企業 AI 諮詢五家分食格局**」、其中 [[Accenture]] / Deloitte / IBM Consulting 是 **AI 投入三巨頭**。

## 2. 三層 thesis（reference only / 跟 [[Accenture]] 對照組）

### 產業層

- IT 諮詢 + 系統整合賽道 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證 → 共識**」加速段——AI 帶來企業 IT 預算結構性放大
  - **賽道分歧**：Strategy 諮詢（McKinsey / BCG / Bain）vs **IT 諮詢 + 系統整合（[[Accenture]] / Deloitte / IBM Consulting）**vs **印度 IT 服務（TCS / Infosys / Wipro / Cognizant）**vs **Big Four Audit-led（Deloitte / PwC / EY / KPMG）**
  - **Deloitte 在三類中**：規模 #2（vs Accenture #1）+ AI 投入 #2 + Audit-led 多軌覆蓋
- vs **[[Accenture]] / IBM Consulting / PwC / EY 四家 + 印度 IT 服務 TCS / Infosys 三大結構性差異**：
  - **規模 + 客戶分散**：Deloitte 457K 員工、客戶 Fortune 500 ~90%+ AVL、政府 + 跨產業、含 Big Four Audit-led 額外 anchor
  - **Audit + Consulting + Tax + Risk Advisory 四軌整合**：跟 [[Accenture]] Consulting + Technology + Operations + Industry X 四軌不同範式
  - **AI 投入比例 + 速度**：FY2024 Deloitte AI / GenAI 投入 ~$2B（vs [[Accenture]] $3B+ / IBM Consulting ~$1.5B），AI / GenAI 業務 ARR 預估 $3B+（FY2025）+ +100%+ YoY
- **「AI 賣水人之中的賣水人」結構性論點**：
  - 不押 NVDA / AVGO / 任何半導體（不押半導體賽道）
  - 不押 [[Anthropic]] / [[OpenAI]] / Google Gemini / Meta Llama / DeepSeek（不押模型）
  - 不押 [[Snowflake]] / [[Databricks]] / [[Microsoft]] Fabric / AWS Bedrock（不押平台）
  - **所有企業導入 AI 都要 [[Accenture]] / Deloitte / IBM Consulting**（FDE + 數據治理 + 系統整合 + 流程改造 + 培訓 + 變革管理）
  - = **AI 應用層 chokepoint 的「人力 + 服務」維度**（[[Forward Deployed Engineer 戰略（FDE）]] 中介）
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 2-3（私募合夥制無估值 timing 訊號、但 AI 投入規模化）
  - **2024 Deloitte AI Institute 公告 GenAI accelerator**：跨產業 AI 導入加速
  - **2025 Deloitte 跟 NVIDIA + AWS + Microsoft + Google + Anthropic + OpenAI 全 platform 合作 announcement**

### 目的層

- 業務 mix（FY2024、August year end、$67B 估算）：
  - **Audit & Assurance = 30% 營收**（最高毛利、稅務 + 審計、Big Four 主場）
  - **Consulting = 35% 營收**（業務流程 + 變革管理 + 系統整合 + AI 諮詢）
  - **Tax & Legal = 15% 營收**（稅務 + 法律諮詢）
  - **Risk Advisory + Financial Advisory = 20% 營收**（合規 + 風險管理 + 併購）
- 客戶結構（**極度分散 + Big Four Audit-led 額外 anchor**）：
  - **Fortune 500 ~90%+ AVL**（vs [[Accenture]] 95%+ = Deloitte 客戶滲透略遜）
  - **Fortune 100 ~95%+ AVL**
  - **政府客戶 + 公部門 ~25% 營收**（含美國聯邦、英國、歐盟、加拿大、日本、新加坡、各州政府）
  - **跨 14 大產業**：金融、保險、零售、媒體、通訊、能源、化工、健康、製造、汽車、航太、政府、公部門、Audit 主場客戶
  - **地理分散**：北美 ~50% + 歐洲 ~25% + 亞太 ~15% + 成長市場 ~10%
- 商業模式 = **「Audit + Consulting + Tax + Risk Advisory 四軌整合 + 私募合夥制」**：
  - **Audit 多年週期性收入**（Big Four 強制 audit rotation）
  - **Consulting 5-7 年 outsourcing 合約**（managed services = recurring）
  - **AI / GenAI 訂閱式 service**（Generative AI accelerator + 自家 AI tools）
  - **Tax 多年週期性收入**（年度報稅 + 跨境稅務）
  - **Risk Advisory + Financial Advisory**（合規 + 併購 + 風險管理）
  - **私募合夥制 dispersed structure**：~7,000 全球合夥人各持股 + member firm 分國家
- → 連 [[賣水人選股邏輯（投資版）]]：**「AI 賣水人之中的賣水人」**——架構級「不押任何商業路線、所有企業導入 AI 都要 [[Accenture]] / Deloitte / IBM Consulting」、跟 [[Synopsys]] 24 + [[Cadence]] 22 + [[Imec]] 24 同等級「架構級賣水人之中的賣水人」哲學
- [[控制點轉移（投資版）]]：拿到「**Fortune 500 client lock-in + 政府客戶 + Big Four Audit 強制 anchor + 跨產業 + 諮詢年金 5-7 年合約**」五重控制點

### 供應層

- 跟 [[Anthropic]] / [[OpenAI]] / [[Microsoft]] / [[Google]] / [[NVDA]] 關係：
  - **Deloitte 同時是所有 AI / cloud platform 的執行夥伴**（不選邊）
  - 跟 [[Accenture]] 類似策略、但 Deloitte 額外有 Big Four Audit 客戶 anchor
  - 訓練員工 ChatGPT Enterprise + Claude + Gemini + Copilot 等多平台
- 跟 [[Accenture]] 關係（**最大競爭對手**）：
  - 全球 IT 諮詢 + 系統整合 #1（Accenture）vs #2（Deloitte）
  - 員工數：Accenture 789K vs Deloitte 457K（Accenture 規模勝）
  - AI 投入：Accenture $3B vs Deloitte $2B（Accenture AI 領先）
  - 但 Deloitte Audit + Tax 業務 anchor 是 Accenture 沒有的
- 跟 IBM Consulting 關係（**「企業 AI 諮詢三巨頭」之一**）：
  - Deloitte 457K vs IBM Consulting 270K
  - AI 投入：Deloitte $2B vs IBM Consulting $1.5B
  - IBM Consulting 額外有 IBM Watson + Red Hat OpenShift + Hybrid Cloud 整合（Deloitte 沒有）
- 跟 PwC / EY / KPMG 關係（**Big Four 同業競爭**）：
  - Deloitte $67B vs PwC $53B / EY $50B / KPMG $36B = Big Four #1
  - Big Four Audit 強制 rotation 限制單一客戶 audit 連續年限
- 跟 [[Palantir]] 關係（**FDE 戰略對手**）：
  - Palantir 走「FDE 派駐工程師 + Foundry + Gotham + AIP」高深度路線
  - Deloitte 走「諮詢 + 系統整合 + Audit + 跨產業 + 多 platform」寬度路線
  - 政府 + 大型企業客戶部分重疊
- 跟 [[Snowflake]] / [[Databricks]] 關係：
  - Deloitte 是 Snowflake / Databricks 的執行夥伴（IT 諮詢 + 整合）
  - Deloitte 自家不開發 data platform、跟 Accenture 同
- 護城河：
  - **457K 員工 + 全球 150+ 國家 member firm + 跨產業專業團隊**
  - **Fortune 500 90%+ AVL + 政府客戶 + Big Four Audit 強制 anchor + 跨 14 大產業**（客戶分散完全 + Audit-led 額外 lock-in）
  - **Microsoft / AWS / Google / NVDA / Anthropic / OpenAI 全 platform 合作**
  - **諮詢年金 5-7 年合約 + Audit 多年週期性收入**
  - **AI 投入 ~$2B + Generative AI accelerator + Deloitte AI Institute**
  - **私募合夥制 → 沒有上市股價波動干擾**
- 風險：
  - **私募合夥制 → 沒有公開財報 + 沒有 IPO 預期**
  - **AI 自動化反噬風險**：GenAI 部分蠶食傳統 IT 服務 + Audit 部分流程
  - **Wage inflation**：員工成本上升（特別是 AI 工程師）
  - **DXC / Cognizant / TCS 等同業 cut prices 跟進競爭**
  - **政府客戶監管風險**（美中科技戰、川普政府 federal contracting 變動、DOGE cut）
  - **Big Four Audit 強制 rotation 限制**
  - **Audit 客戶利益衝突**：Audit + Consulting 同客戶 SOX 法規限制
  - **Anthropic / OpenAI / Palantir 自家 FDE 規模化反噬風險**
- → 連 [[控制點轉移（投資版）]]：拿到「**Fortune 500 + 政府 + Big Four Audit 強制 + 跨產業客戶 lock-in**」四重控制點、但「私募合夥制 → 無公開估值 + 自動化反噬風險」雙重壓力
