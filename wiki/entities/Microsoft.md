# Microsoft

M7 之一，AI 時代最複雜的曝險點。**持股 OpenAI 27% + 最大 Azure CSP** = 雙重曝險於 AI 模型層風險。

## AI 業務四層

| 層 | 業務 |
|---|---|
| 模型層 | 持股 OpenAI 27% |
| 平台層 | Azure（最大 OpenAI 算力供應商） |
| 應用層 | Copilot（$30/月 SaaS） |
| 開發者層 | GitHub Copilot |

## 「Copilot 條款僅供娛樂」事件（2026-04-06）

→ 完整見 [[AI 訂閱制 unit economics]]

- Copilot 條款明文「**僅供娛樂**」+ 免責
- 揭穿：**$30/月不夠 cover 推論成本**
- NPS **-19.8**、滲透率卡在 **3.3%**
- = AI 訂閱制 unit economics 不 work 的證據

- OpenAI 任何危機 → 27% 持股價值 + Azure 訂單兩端皆受傷
