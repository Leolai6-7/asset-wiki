# 國巨（2327.TW）

## 1. 一句話定位

**全球被動元件「全產品線併購王」+ 台廠 MLCC 第一**——全球**鉭電容 #1**（值佔 ~35.4%／產能 40%+；⚠️ #P10 修正、原「>50%」膨脹）、全球**晶片電阻 #1**、全球 **MLCC #3**（追村田 / Samsung Electro-Mechanics），靠 KEMET（鉭電容）、Pulse Electronics（磁性）、Shibaura（感測）連環併購建構**「一站式被動元件」**護城河；AI 伺服器營收占比快速從 2024 年 4% 飆到 2026 Q1 **14-15%**（鉭電容線 AI 占比 >30%）、整體 75% 營收已落在 AI / 車用 / 工規 / 醫療 / 國防航太等高門檻市場；在 [[MLCC 嵌入式基板賽道]] 中**位置尷尬**——MLCC 給載板廠（村田 / SEMCO 自己用 / IBIDEN 採購）= 國巨**沒拿到第二戰場的入場券**。

## 2. 三層 thesis

### 產業層

- **MLCC 產業**位在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**驗證 → 共識**」加速段：
  - 2026 全球 MLCC 市場 USD 318 億、CAGR 15% 到 2031 年 USD 642 億
  - AI server MLCC 市場 2025 USD 48 億 → 2034 USD 168 億（CAGR 21.2%）
  - 一台高階 AI server MLCC 用量是手機 30 倍、傳統 server **10-15 倍**
  - GB200 規格從 25,000 顆衝到 400,000-600,000 顆 / 台
  - 高盛喊「MLCC 將成下一個記憶體」/ 大摩 / 摩根大通**目標價突破千元**（NT$1,010）
- **鉭電容 / SP-CAP 子賽道**：AI GPU 旁邊 PCB 空間越來越小、需要低 ESR 高密度，鉭聚合物 + SP-CAP 是稀缺解 → Panasonic 漲價 20-65% / 國巨子公司 KEMET 跟漲 + 6 月起最高 65%
- 跟 [[ABF 載板 vs 玻璃基板 displacement]] 的關係：**新戰場「[[MLCC 嵌入式基板賽道]]」開打**——SEMCO 先發（用自家 MLCC 嵌進載板）、村田有 iPaS + EMSC 系列、IBIDEN 5,000 億日圓擴產跟進；**國巨缺載板廠盟友 = 不在第二戰場**
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體（已到媒體層、ETF 在進）= **散戶階段啟動中**（陳泰銘 2026/05/20 登台灣首富 NT$4,900 億新聞）

### 目的層

- 2025 Q4 產品 mix：
  - 磁性元件（Pulse）**26.4%**
  - 鉭電容（KEMET）**21.7%**
  - MLCC **17.7%**
  - 晶片電阻 ~11-13%
  - 其他（感測 / Shibaura 整合中）
- 75% 營收落在 AI / 車用 / 工規 / 醫療 / 國防航太
- **AI 相關營收**：
  - 2024 = 4% → 2025 = 10-12% → 2026 Q1 = **14-15%**
  - 鉭電容 AI 占比 >30% / 訂單能見度創高 / 接單出貨比 1.3
- 商業模式核心：「**併購王 + 漲價傳導**」雙引擎
  - 併購：Pulse（2018）+ KEMET（2020 USD 18 億）+ Shibaura（2026 Q1 完成子公司化、TOB ¥7,130/股、總額 ~¥110B ≈ **US$7.3 億**；⚠️ #P10 修正、原「USD 44 億」吞了錯誤標題、差 6 倍）
  - 漲價傳導：高階產品 ASP +30-50% / 鉭電容單筆漲價 +25-65%（4 月 Panasonic + 11 月 KEMET）
- 對應 [[賣水人選股邏輯（投資版）]]：**所有 AI server / GPU / 車用都需要**鉭電容 + 高階 MLCC = 國巨是 AI 的「全平台賣水人」、不押單一晶片廠
- 對應 [[控制點轉移（投資版）]]：拿到「鉭電容全球壟斷」+「晶片電阻全球壟斷」的控制點 = 議價權結構性高、但**未拿載板「嵌入層」控制點**

### 供應層

- 跟 [[NVDA]] 路線：透過 NVIDIA AVL（approved vendor list）代工廠切入 GB200 / Rubin 鏈
  - X6S / X7S / X7R 耐高溫品項在 GB200 主板用量達 **85%**（國巨是台廠最大供應商）
  - 鉭聚合物電容（KEMET 品牌）= GPU 旁邊低 ESR 必備
- 跟 [[AVGO]] / [[AMD]] / [[Microsoft]] / [[Meta]] 自研 ASIC：全是客戶（陳泰銘：「全球 AI 領域主要參與者都是我們客戶」）
- 跟 [[Intel]] / [[Apple]] / Tesla / Cisco / Bosch：傳統客戶 anchor
- 跟村田 / [[Samsung Electro-Mechanics]] / Taiyo Yuden / TDK 關係：
  - 高階 AI server MLCC **村田 + SEMCO 合計 >80% 市佔**（國巨 + Taiyo Yuden + TDK 分剩下 <20%）
  - 國巨強項：低階 / 中階 MLCC + 鉭電容絕對龍頭 + 晶片電阻絕對龍頭 + 高階 X6S 跟上但量級小
- 嵌入式被動元件 / [[MLCC 嵌入式基板賽道]]：
  - **國巨沒有公開 embedded MLCC 產品線**（搜尋多次無結果）
  - 村田 iPaS / EMSC / GRU 0402 embedded 已商業化
  - SEMCO LSC（laminate substrate capacitor）+ silicon capacitor 2027-2028 大量出貨給 GPU / HBM 客戶
  - → **國巨在第二戰場是「賣 MLCC 給 SEMCO / IBIDEN 用」的角色**、不是直接玩家
- 護城河：
  - 全產品線（電阻 + 電容 + 磁性 + 感測）整合（一站式採購）
  - 鉭電容上游垂直整合 + 全球壟斷市佔
  - 多次併購累積 IP + 海外產能（Taiwan + Mexico + Czech + Japan）
- 風險：
  - **載板嵌入化 = MLCC 通路從 EMS 轉到載板廠** = 國巨議價權被載板廠（SEMCO / IBIDEN）擠壓
  - 村田 + SEMCO 高階 MLCC + 嵌入式 + silicon capacitor 全鏈優勢
  - PE 60+ 倍已 price in 多年漲價週期

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ AI / 車用 / 工規 / 醫療 / 國防 = 75% / 訂單能見度創高 / 接單出貨比 1.3 |
| 毛利率 | ✅ **38.1%**（同業最高 / 連續四季擴張）|
| OpEx | ✅ Shibaura 整合進行中、併購折舊已認列 |
| 營業利益 | ✅ Q1 EPS +44.7% YoY、營業槓桿釋放 |

→ **Re-rate 三角形 4/4 滿**——買的是「鉭電容全球壟斷 + 高階 MLCC 量價齊揚 + 75% 高門檻 mix」**結構性 re-rating**，PE 已從 30 倍補漲到 60+ 倍，目標千元等於 PE 60x 配 EPS 17。

### ✅ 催化

- AI server MLCC 用量 2025 → 2026 翻倍 / 2027 = 2025 的 4 倍
- 鉭電容 / SP-CAP 漲價週期延續（Panasonic +20-65% / KEMET 跟漲）
- 大摩 / 摩根大通 / 高盛三大外資齊喊千元（PE 60 為基準）
- Shibaura 整合 2026 Q2-Q4 開始貢獻車用 / 工業感測營收
- 鉭電容 NVIDIA AVL 切入深、隨 Rubin / Vera 升級放量
- 陳泰銘登首富 NT$4,900 億 = 資訊擴散到媒體 / 散戶層（資金面催化）
- 跟 [[Samsung Electro-Mechanics]] 嵌入式 / [[IBIDEN]] 5,000 億擴 ABF 都是「擴 MLCC 採購量」= 國巨外溢受惠

### ⚠️ 風險

- **PE 60-80 倍已 price in 多年漲價週期** → 任何漲價低於預期都會重 de-rating
- **[[MLCC 嵌入式基板賽道]] 國巨**：
  - 載板廠（SEMCO / IBIDEN / 欣興）開始**內嵌 MLCC** → 改變 MLCC 採購通路
  - 嵌入式 MLCC 規格集中在村田 / SEMCO（高階）= 國巨被擠到「賣標準品給載板廠」的角色（議價權↓）
- 高階 AI server MLCC 仍由村田 + SEMCO 合計 >80% 壟斷（國巨高階份額**結構性受限**）
- 中國風華 / 三環 / 微容低階 MLCC 持續國產替代 → 中階 MLCC 毛利侵蝕
- 銀 / 鈀 / 鉭原物料價格波動（鉭礦 70% 來自剛果）
- 併購整合風險：Shibaura ~US$7.3 億＋76% 溢價收購（#P10 金額修正）、回收期仍待驗證
- 中美關稅 + 出口管制（KEMET 美國資產 + Yageo 台廠雙重曝險）

## ⭐ MLCC 嵌入式戰場曝險評估

| 維度 | 評估 |
|---|---|
| 嵌入式產品線（自家 embedded MLCC）| ❌ **無公開產品**（vs 村田 iPaS / EMSC / GRU 已商業化）|
| 跟 ABF 載板廠合作度 | ⚠️ **被動賣零組件**（沒看到跟欣興 / 南電 / 景碩 / IBIDEN 共同開發嵌入式專案）|
| AI server 客戶滲透 | ⚠️ **中等**——透過代工廠進 NVDA AVL、AVGO + AMD 客戶、但高階 AI MLCC 仍輸村田 + SEMCO |
| 對 SEMCO / 村田差距 | ⚠️⚠️ **顯著**——高階 AI server MLCC 村田 + SEMCO >80%、國巨在低中階 + 鉭電容打 |

→ MLCC 嵌入式曝險總體：**落後**（在 MLCC 本身強、但在「**嵌入式 + 載板整合**」第二戰場無位置）

> **但要小心區分兩件事**：
> 1. **MLCC 本業**：國巨是漲價週期主受惠者、估值 re-rate 4/4
> 2. **MLCC 嵌入式新戰場**：國巨**沒拿到入場券**、長期 TAM 被 SEMCO / 村田 / IBIDEN 切走
>
> 因此國巨是「**MLCC 第三波超級週期受惠 + 第四波嵌入式革命缺席**」的雙面結構。
