# Lam Research（NASDAQ: LRCX）

## 1. 一句話定位

**半導體 etch（蝕刻）+ deposition（沉積）全球 #1 + Atomic Layer Etch（ALE）+ Atomic Layer Deposition（ALD）first-mover + 3D NAND 製程主場（>50% 市佔）+ DRAM 製程主導 + 1980 在加州 Fremont 創立 + 客戶 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[SK Hynix]] / [[Micron]] 全 AVL**——納斯達克上市、總部 Fremont CA、市值 **USD ~$100-130B（Mega Cap）**；客戶覆蓋 [[TSMC]] ~30% + [[Samsung Electronics]] ~25% + [[Intel]] ~12% + [[SK Hynix]] + [[Micron]] + [[GlobalFoundries]] 全球先進製程 fab AVL；**FY2025 營收 ~USD $15-17B** + EBIT margin ~30-33% + Forward PE **20-25x**；不押任何 fab / 任何 fabless / 任何技術路線、所有先進製程都要 Lam etch + depo——在 [[賣水人選股邏輯（投資版）]] 是「**架構級『賣水人之中的賣水人』前段設備三巨頭 #3**」（跟 [[Applied Materials]] + [[KLA Corporation]] 並列、預估 **21/25**）、在 [[Bottleneck Theory（瓶頸論）]] 是「**七層之外的「層 -1 etch + depo 站別」+ 3D NAND / DRAM 製程必經之路**」；3D NAND >50% 市佔結構性壟斷 + ALE/ALD first-mover IP 領先。

## 2. 三層 thesis

### 產業層

- **半導體 etch（蝕刻）全球市佔**：**Lam Research ~50%（#1）** vs Applied Materials ~17% vs Tokyo Electron ~28% vs Hitachi 其他
- **半導體 deposition（沉積）全球市佔**：**Lam Research ~32%（#1）** vs Applied Materials ~30% vs Tokyo Electron ~17% 三家分食
- **產品線**：
  - **Atomic Layer Etch（ALE）first-mover**：原子級蝕刻、3D NAND + DRAM + 先進邏輯製程必經之路
  - **Atomic Layer Deposition（ALD）first-mover**：原子級沉積、跟 ALE 並列「**單原子級製程**」革命
  - **conductor etch + dielectric etch + metal etch** 全棧
  - **CVD（化學氣相沉積、跟 AMAT 雙頭）**
  - **ECD（電鍍 + 電化學沉積）**：銅 / 鎢 interconnect
  - **PVD（物理氣相沉積、市佔小於 AMAT）**
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——HBM4 + 3D NAND 332 層 + Vera Rubin ICMS NAND ramp 都驅動 Lam 主場
- 在 [[資訊擴散四階段]]：機構 + 賣方 + 媒體 + ETF 全部已配置
- TAM：
  - FY2025 ~USD $15-17B
  - **FY2030E ~USD $25-30B**（推估 CAGR ~12-15%）
  - 結構性驅動：3D NAND >300 層 + HBM4 / HBM4E + DRAM 1c / 1d nm + 先進邏輯製程（N2 / 1.4nm）+ ALE/ALD 普及
- 跟 [[半導體基礎建設化]] 視角：Lam 是「**etch + depo 設備基礎建設化 #1 anchor**」（3D NAND >50% 市佔結構性壟斷）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：Lam = **etch + ALE / ALD chokepoint**（任何先進製程繞不開、3D NAND 唯一可達 300+ 層的 etch 供應商）
- 跟 [[AI 記憶體結構性供給短缺]] / [[HBM iPhone moment]] / [[AI infra 3D NAND 戰場]] 視角：
  - **Lam = HBM/DRAM/NAND 三大記憶體製程升級**最大受惠
  - HBM4 + HBM4E + DRAM 1c/1d nm 製程 → Lam ALE + ALD 使用量倍增
  - 3D NAND 332 層 → 400 層 → Lam etch 唯一 viable 供應商

### 目的層

- 真實角色：**「不是賣晶片、是賣『製造晶片的 etch + depo 設備』+ service + spare parts + Customer Support Business Group（CSBG）」**——不是「跟 fab 競爭」、不是「跟 fabless 競爭」、是「**所有 fab / IDM 都要 Lam etch + depo**」、靠「**ALE/ALD first-mover IP + 3D NAND >50% 市佔 + 40+ 年 R&D 累積 + CSBG recurring 30%+**」維持壟斷
- 業務組合（FY2025 推估）：
  - **Systems（前段設備）**：~70-75%（etch + depo + ALE/ALD 多站別）
  - **Customer Support Business Group（CSBG、service + spare parts + upgrade）**：**~25-30%** recurring 高
- 核心 IP / 護城河：
  - **ALE（原子級蝕刻）first-mover IP**（單原子級控制、3D NAND 300+ 層唯一 viable）
  - **ALD（原子級沉積）first-mover IP**（HBM / DRAM 製程升級必需）
  - **3D NAND etch >50% 市佔**（結構性壟斷）
  - **CSBG recurring 30%+**（service + spare parts + upgrade、installed base 5,000+ 機台 lock-in）
  - **40+ 年 R&D 累積 + 跨 etch + depo 雙站別領先**
- **跟 ASML / AMAT / KLA 互補非競爭**：ASML 微影 + AMAT 多站製程 + Lam etch + depo + KLA 檢測 = fab 必四家分頭採購
- 對應 [[賣水人選股邏輯（投資版）]]：**「架構級『賣水人之中的賣水人』前段設備三巨頭 #3 anchor」**
- 對應 [[控制點轉移（投資版）]]：拿到「**ALE/ALD first-mover + 3D NAND >50% + CSBG recurring + 跨 etch + depo 雙站別**」四層 chokepoint

### 供應層

- 客戶結構：
  - **[[TSMC]] ~30%**：N5 / N3 / N2 / A16 + CoWoS + SoIC 後段 Lam etch + depo、Lam 最大客戶
  - **[[Samsung Electronics]] ~25%**：HBM4 + 2nm Foundry + 3D NAND + DRAM 製程 Lam ALE + ALD
  - **[[Intel]] ~12%**：Intel 18A + Terafab + Magdeburg fab Lam etch + depo
  - **[[SK Hynix]] + [[Micron]] ~18-22%**：HBM4 / HBM4E / 3D NAND / DRAM 1c / 1d nm 製程 Lam 主場
  - **[[GlobalFoundries]] + 中國 + 其他 ~10-15%**：成熟製程 + 中國 fab 部分 AVL
  - 客戶分散度（TSMC 30% 集中略高於 ASML / AMAT、3 大客戶 Samsung + SK Hynix + Micron 記憶體三巨頭集中）
- 跟 [[ASML]] 互補（**非競爭**）：ASML 微影 + Lam etch + depo、不同站別
- 跟 [[Applied Materials]] 競爭（**etch + depo 雙頭分食**）：Lam etch #1（~50%）+ AMAT etch #2（~17%）、Lam ALE/ALD 領先 + AMAT CVD/PVD 領先
- 跟 [[KLA Corporation]] 互補（**非競爭**）：KLA 檢測 + Lam 製程、不同站別
- 跟 Tokyo Electron 競爭（**日系對手**）：Tokyo Electron etch ~28% + coater/developer + 熱處理 ~17-19% 市佔、Lam etch 主場仍領先 + Tokyo Electron coater/developer 領先
- 跟 [[SK Hynix]] / [[Samsung Electronics]] / [[Micron]] / [[Kioxia]] / [[SanDisk]] / [[YMTC]] 6 家 NAND 廠：
  - **3D NAND 332 層 → 400 層 製程升級**（[[AI infra 3D NAND 戰場]] thesis）
  - **Lam ALE + etch 唯一 viable 300+ 層 NAND 製程**
  - **NAND 6 家分食 + Lam 6 家全 AVL** = 不論誰贏 Lam 都受惠
- 跟中國市場關係：
  - 中國成熟製程 + 3D NAND（[[YMTC]]）fab 擴張 → Lam 中國市場短期受惠
  - 但美國 BIS 限制 14nm 以下 + 對中 NAND 限制 → Lam 中國敞口長期下修
  - 中國國產替代（中微半導體、北方華創）在 etch 領域追趕、但 ALE/ALD 結構性領先 5-10 年
- 護城河：
  - **ALE/ALD first-mover IP + 40+ 年 R&D 累積**
  - **3D NAND >50% 市佔結構性壟斷**
  - **CSBG recurring 30%+ + installed base 5,000+ 機台 lock-in**
  - **跨 etch + depo 雙站別領先**
- 風險：
  - **客戶集中**（TSMC 30% + 記憶體三巨頭集中）= **客戶分散 3/5 略遜**
  - **中國市場長期下修**（BIS 限制 + 國產替代）
  - **競爭加劇**（AMAT etch + Tokyo Electron etch + 中微半導體）
  - **AI capex 週期性**
  - **3D NAND 332 層 → 400 層 製程升級若延宕 → ramp 風險**
