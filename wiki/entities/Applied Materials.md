# Applied Materials（NASDAQ: AMAT）

## 1. 一句話定位

**半導體設備全球 #2（僅次 [[ASML]]）+ CVD / PVD / etch / CMP / implant / RTP 多站別最廣供應商（vs ASML 單一微影站）+ 1967 在加州 Santa Clara 創立的 IDM-grade 設備龍頭 + 整廠 fab 設備 turnkey + 客戶 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[SK Hynix]] / [[Micron]] / [[GlobalFoundries]] 全球先進製程 fab AVL**——總部 Santa Clara CA、NASDAQ 上市、市值 **USD ~$130-160B（Mega Cap）**；客戶覆蓋 [[TSMC]] ~20-25% + [[Samsung Electronics]] ~15-20% + [[Intel]] ~10-15% + [[SK Hynix]] + [[Micron]] + [[GlobalFoundries]] + Display + Solar 全產業 AVL；**FY2025 營收 ~USD $27-30B**（vs [[ASML]] ~€30B、規模略小但站別覆蓋廣）+ EBIT margin 28-32% + Forward PE **20-25x**（vs ASML 30-35x 折價）；不押任何 fab / 任何 fabless / 任何技術路線、所有先進製程都要 AMAT 設備——在 [[賣水人選股邏輯（投資版）]] 是「**架構級『賣水人之中的賣水人』前段設備三巨頭 #1**」（跟 [[KLA Corporation]] + [[Lam Research]] 並列、預估 **22/25**）、在 [[Bottleneck Theory（瓶頸論）]] 是「**七層之外的「層 -1 製程設備層」+ CVD/PVD/etch/CMP 多站別 chokepoint**」。

## 2. 三層 thesis

### 產業層

- **半導體前段設備全球市佔**：AMAT ~22-24%（#2）vs ASML ~22-25%（#1、微影壟斷）vs Lam Research ~17-19%（#3）vs KLA ~12-14%（#4）vs Tokyo Electron ~17-19%（#3 並列）
- **站別覆蓋**（前段製程多站）：
  - CVD（Chemical Vapor Deposition、化學氣相沉積）：AMAT #1 全球
  - PVD（Physical Vapor Deposition、物理氣相沉積）：AMAT 寡占 #1
  - etch（蝕刻）：AMAT vs Lam Research 雙頭（Lam #1、AMAT #2）
  - CMP（Chemical Mechanical Planarization、化學機械研磨）：AMAT #1（vs Ebara 日系第二）
  - implant（離子植入）：AMAT 壟斷 ~70%+ 全球市佔
  - RTP（Rapid Thermal Processing、快速熱處理）：AMAT 寡占
  - epi（外延生長）：AMAT 主導
- **與 ASML 互補關係**：ASML 是「微影單一站」+ EUV 100% 壟斷、AMAT 是「微影以外多站」+ 多製程主導
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「共識中」**——AI capex + 先進製程 + HBM ramp 都已是市場共識
- 在 [[資訊擴散四階段]]：機構 + 賣方 + 媒體 + ETF 全部已配置（SOX / SMH / Nasdaq 100 全成份）
- TAM：
  - FY2025 ~USD $27-30B
  - **FY2030E ~USD $50-60B**（推估 CAGR ~12-15%）
  - 結構性驅動：先進製程 + AI capex + Foundry 擴產 + memory HBM/DRAM 製程升級 + 中國成熟製程 fab 擴張（短期）
- 跟 [[半導體基礎建設化]] 視角：AMAT 是「**前段製程設備基礎建設化 #2 anchor**」（跟 [[ASML]] 微影並列、估值從週期 PE → infrastructure PE）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：AMAT = **CVD/PVD/etch/CMP/implant 多站別 chokepoint**（vs ASML 單一微影 chokepoint）

### 目的層

- 真實角色：**「不是賣晶片、是賣『製造晶片的多站設備』+ service + spare parts + upgrade + Applied Global Services（AGS）+ Display + Solar 跨產業」**——不是「跟 fab 競爭」（vs TSMC / Samsung / Intel）、不是「跟 fabless 競爭」、是「**所有 fab / IDM 都要 AMAT 多站設備**」、靠「**CVD/PVD/etch/CMP/implant 多站別領先 IP + 60+ 年 R&D 累積 + 全球 service 網 + AGS recurring 25%+ 營收**」維持寡占
- 業務組合（FY2025 推估）：
  - **Semi Systems（前段設備）**：~70-75%（CVD + PVD + etch + CMP + implant + RTP + epi 多站別）
  - **Applied Global Services（AGS）**：**~22-25%**（service + spare parts + upgrade + 100Wh installed base 4,000+ 機台 recurring 高）
  - **Display + Solar**：~3-5%（顯示器 + 太陽能設備、小段）
- 核心 IP / 護城河：
  - **CVD / PVD / etch / CMP / implant 多站別領先 IP**（60+ 年累積、每站別 patent 數千件）
  - **Process integration 整合能力**（fab 全製程 turnkey + 跨站 co-optimization）
  - **AGS recurring 25%+**（service + spare parts + upgrade、installed base 4,000+ 機台 lock-in）
  - **AI / Industry 4.0 fab automation**（Applied AIx for fab process control）
- **跟 ASML 競爭關係**：⚠️ **互補非競爭**——ASML 微影單一站 + EUV 100% 壟斷、AMAT 微影以外多站 + 多製程主導；fab 採購 ASML + AMAT 雙頭必備、不是 zero-sum
- 對應 [[賣水人選股邏輯（投資版）]]：**「架構級『賣水人之中的賣水人』前段設備三巨頭 #1 anchor」**（跟 [[KLA Corporation]] + [[Lam Research]] 並列）
- 對應 [[控制點轉移（投資版）]]：拿到「**CVD/PVD/etch/CMP/implant 多站別領先 + service recurring + Display + Solar 跨產業**」四層控制權

### 供應層

- 客戶結構（**全球先進製程 fab AVL 完全分散**）：
  - **[[TSMC]] ~20-25%**：N5 / N3 / N2 / A16 / CoWoS 全棧 AMAT 多站設備、AMAT 最大客戶
  - **[[Samsung Electronics]] ~15-20%**：HBM4 + 2nm Foundry + DRAM + Pyeongtaek + Hwaseong + Taylor TX 多廠 AMAT 多站設備
  - **[[Intel]] ~10-15%**：Intel 18A + Terafab + Arizona / Ohio / Israel + Magdeburg fab 全 AMAT 多站
  - **[[SK Hynix]] + [[Micron]] ~15-20%**：HBM4 / DRAM 1c / 1d nm 製程 AMAT etch + CMP + implant
  - **[[GlobalFoundries]] + 中國 fab ~15-20%**：成熟製程 + 中國 SMIC / Hua Hong / CXMT 全 AMAT 設備（短期紅利）
  - 客戶分散度結構性（無單一客戶 > 25%、5 大客戶分散）
- 跟 [[ASML]] 互補（**非競爭**）：ASML 微影壟斷 + AMAT 微影以外多站 = fab 必雙頭採購
- 跟 [[Lam Research]] 競爭（**etch + depo 雙頭**）：Lam etch + ALD/ALE #1、AMAT etch + CVD/PVD #2、雙頭分食 etch + depo 市場
- 跟 [[KLA Corporation]] 互補（**設備 + 檢測**）：KLA 製程檢測 + AMAT 製程設備、不重疊
- 跟 Tokyo Electron 競爭（**日系對手**）：Tokyo Electron coater/developer + etch + 熱處理 ~17-19% 市佔、AMAT etch + depo + CMP 重疊度高
- 跟 [[SK Hynix]] / [[Micron]] / [[Samsung Electronics]] 記憶體三巨頭：HBM4 / HBM4E / DRAM 1c / 1d nm 製程全要 AMAT etch + CMP + implant、[[AI 記憶體結構性供給短缺]] thesis → capex +30-50% YoY → AMAT 記憶體段營收持續成長
- 跟中國市場關係（**短期紅利、中期受限**）：
  - 中國成熟製程（28nm+）fab 擴張 → AMAT 中國市場 ~30-35% 短期受惠
  - 但美國 BIS 限制 14nm 以下對中出口 → AMAT 中國敞口長期下修至 15-20%
  - [[CXMT]] / SMIC / Hua Hong 短期 AMAT 大客戶、中期被中國國產替代（北方華創 / 中微半導體）侵蝕
- 護城河：
  - **多站別領先 + 60+ 年 R&D 累積**
  - **整廠 turnkey + process integration**
  - **AGS recurring 25%+ + installed base 4,000+ 機台 lock-in**
  - **客戶分散 + 跨產業（Display + Solar）**
  - **AI fab automation + Applied AIx**
- 風險：
  - **中國市場長期下修**（BIS 限制 + 國產替代）：中國敞口從 30-35% → 15-20%
  - **競爭加劇**：Lam Research etch + ALD 領先、Tokyo Electron 日系對手
  - **AI capex 週期性**：第二階段過後可能週期波動
  - **設備折舊週期**：installed base 4,000+ 機台 service 收入可預測但設備新賣可能放緩
