# AGC（TSE: 5201）

## 1. 一句話定位

**全球玻璃材料三巨頭（與 Corning、SCHOTT 並列）+ EUV mask blank 世界僅 3 家之一**——119 年日本老牌（1907 創立，舊名旭硝子），TGV 玻璃基板**規格揭露最完整、樣品已開放接單**；FY2024 電子段 Electronic Materials 營收 JPY 183.6B（首次超過 Display），EUV mask blank 銷售 YoY +50%。**在玻璃材料三巨頭中半導體製程 know-how 最深**（從 mask blank 到 polishing slurry 到 TGV 基板全鏈），但**玻璃基板對 AGC 業績是中尾期權**，主業仍是面板 / 汽車 / 化學。

## 2. 三層 thesis

### 產業層
- 玻璃材料三巨頭之一：與 Corning、SCHOTT、NEG 控全球 90%+ 低 CTE 玻璃配方
- **玻璃基板 design-in 揭露最具體**：
  - EN-A1 non-alkali 玻璃 + 直徑 20-150μm + 玻璃厚度 0.1-1.0mm
  - 晶圓 φ150/200/300mm + 面板 510×515mm
  - 應用：**Substrate for Semiconductor Packaging + Glass Interposer + 3D Glass IPD + MEMS / Sensor**
  - 直接點名 **Chiplet + CPO substrate + RF devices**
- 賽道 timing：玻璃基板 2026 樣品 → 2027-2028 量產；EUV mask blank 與 polishing slurry 是當下成長引擎
- **AGC 是全球僅 3 家 EUV mask blank 供應商之一**——2024 銷售 JPY 40B（USD 272M）、YoY +50%、預期雙位數續增
- 六大事業部：Architecture Glass、Automotive、Ceramics & Others、Chemicals、**Electronics**（半導體所在）、Life Sciences

### 目的層
- 真實角色：**特殊玻璃 + 半導體上游材料 + 化學品 platform 公司**
- 在 TGV 製程鏈位置：
  - **第 0 站材料供應**（玻璃基板、TGV 加工）— 與 Corning、SCHOTT 並列
  - **第 4 站 PVD / sputter 上游**（光罩 / mask blank）
  - **第 7 站 CMP 研磨**（ceria slurry 全球領先）
  - = AGC 在 TGV 八站中**橫跨 3 站材料供應**，比 Corning（主要載板）更深入
- 玻璃基板相關產品：
  - **EN-A1 non-alkali TGV 玻璃**（已商業化、開放客戶報價）
  - **新型玻璃**（2024 發表抑制電子封裝熱應力）
  - **Low-CTE 硼矽玻璃 sheet**（供 Intel Arizona 早期評估）
- 商業模式：(a) 客製化規格 TGV 玻璃（一次性 + 長尾）、(b) EUV mask blank（高毛利、消耗品）、(c) Ceria slurry（耗材年金）
- 與 [[控制點轉移（投資版）]] 對應：拿到「**TGV 玻璃 + mask blank + CMP slurry + 面板**」四重控制點

### 供應層
- **路線**：玻璃 + 化學 + 光罩 + slurry 多軌並進（vs Corning 純玻璃聚焦光纖、SCHOTT 私有 / 細分專業）
- 護城河三層：
  - **半導體製程材料 IP**（EUV mask blank、Ceria slurry 都是極高准入門檻）
  - **客戶 lock-in**（與 ASML、TSMC、Samsung 鏈深度綁定）
  - **R&D 規模**（2024 年單年玻璃科技 R&D 投入 >USD 500M）
- 玻璃基板競爭格局：vs Corning（並列領先、TSMC 直接合作）、vs SCHOTT（HermeS 細分高純度）、vs NEG（細分）、vs 韓國 KCC / LX Glass（落後）
- 客戶集中度：分散
- 風險：**玻璃基板對 AGC 整體營收占比仍小（<5%）**、Intel 等 design-in 仍多停留在「pathfinding line」、無大型獨家長約揭露

### ✅ 催化
- EUV mask blank 銷售 YoY +50%、雙位數續增
- TGV 玻璃規格已完整揭露 + 樣品階段
- Electronic Materials 首度超 Display → 結構性敘事轉變
- 韓國 / 台灣 / 美國 fab 擴產直接受惠（mask blank + slurry 必用）
- 玻璃基板 2027-2028 量產 → option value
- 日圓貶值（出口受惠）

### ⚠️ 風險
- 玻璃基板對整體業績仍微小（<3%、不是 pure play）
- 主業 Architecture / Automotive 受全球景氣循環
- Intel pathfinding 仍非 commercial design-in
- 韓國競爭者 KCC / LX Glass 在低端追趕
- **無類似 Corning-Nvidia 等級的單一大客戶綁定**（敘事吸引力次於 GLW）
- 化學品段營收結構性波動

## ⭐ 對台股 TGV 設備廠的意義

### bull case 對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]]

- **AGC TGV 玻璃規格已開放接單** = 台廠拿玻璃毛胚不缺供應、不需擔心上游卡脖子
- AGC 客戶分散（ASML / TSMC / Samsung / Intel）= 玻璃材料**不會被單一終端鎖死**
- AGC 自己**不做下游 TGV 加工 / 雷射改質 / 蝕刻 / 切割** → **不搶台廠 8 站設備生意**
- AGC EUV mask blank YoY +50% → 確認半導體 capex 結構性上升 → 台廠檢測 / 電鍍 / CMP 全部受惠
- AGC + Corning + SCHOTT 三足鼎立 → **玻璃材料價格不會被單一壟斷** → 台廠下游加工毛利空間 preserved

### bear case 對台廠

- AGC 在 mask blank、CMP slurry 控制權極強 → **如果這些上游材料漲價 / 缺貨**，台廠 fab 客戶會壓低設備支出
- AGC 與 Samsung、Intel 早期合作 → 韓國 SKC Absolics / Samsung SEMCO 鏈強化 → **台廠 TGV 鏈相對被邊緣化的風險**（如果 AGC 玻璃 → Samsung 鏈、Corning 玻璃 → TSMC 鏈、SCHOTT 玻璃 → 歐美鏈，台廠需要選邊）
- 但**目前並無證據 AGC 把玻璃**綁定**給任何 OSAT 或 fab**，仍是中性供應

### 最大 takeaway

**AGC 是玻璃材料三巨頭中估值最便宜（Forward PE 14.45）、半導體製程材料覆蓋最廣（玻璃 + mask blank + slurry 三軌）、但 TGV 純度最低（<3% 業績）的一家。** 對台廠最關鍵的意義：**確認玻璃材料供應充足、不是 bottleneck**——這釋放了「材料缺貨會殺台廠 thesis」的擔憂。台廠真實風險仍在下游 LPKF / Disco 設備競爭與 IP 戰，**不在 AGC**。
