# Oracle（ORCL）

## 1. 一句話定位

**老牌資料庫龍頭 + Stargate + OpenAI $300B 訂單 anchor + Larry Ellison AI infra 押注 + 1.6T 光模組首批採購者**——1977 起源（Larry Ellison、Bob Miner、Ed Oates 在 Santa Clara 創辦）、世界第一大 enterprise database 公司、市值 USD ~$700-900B、12 月漲幅 +130-180%；**從 enterprise SaaS 老牌轉型 AI cloud + DC 建商**：OCI Gen 2 在 2024-2026 重 pivot 為「**AI 訓練專用 cloud**」+ **OpenAI $300B 五年合約**（2025-09 公告、世界最大 AI infra 採購、Stargate 計畫主力 DC 建設）+ **Trump 政府站台**（Stargate 公開儀式 Trump + Ellison + Altman 三人合照）；**[[AI infra CapEx 三階段論]] 第三階段 anchor 客戶**——1.6T 光模組首批採購者之一（與 [[CoreWeave]] / [[Meta]] / [[Microsoft]] / Lambda 並列）+ Spectrum-X 早期部署 + OCI Supercluster 用 NVDA GB200 / Blackwell Ultra；**循環投資典型樣本**——[[Microsoft]] $13B 投 OpenAI + Oracle 借 $50-100B 蓋資料中心 + OpenAI 五年 $300B 預付 OCI = **三角閉環、Microsoft + Oracle + OpenAI 三家互鎖**；Larry Ellison 個人持股 ~40%、是市值最大上市公司中個人持股最高 CEO。

## 2. 三層 thesis

### 產業層

- 雲端賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——Oracle 從 enterprise database 老牌轉型 AI cloud + DC 建商
  - OCI 起步晚（vs AWS / Azure / GCP）、但 2024-2026 進入 AI cloud niche specialty 階段
  - 走「**OpenAI / Anthropic / xAI / Meta 訓練客戶優先**」差異化路線、非 enterprise general purpose
  - 主推 OCI Supercluster（NVDA GB200 / Blackwell Ultra fleet）
- vs hyperscaler 結構性差異：
  - **資料庫 + 雲混合**：Oracle 仍有 60-70% 營收來自 enterprise database / SaaS（高毛利 + 客戶忠誠）
  - **OCI growth 高**：Q4 FY2025 OCI YoY +52%、占總營收 ~25-30%（仍小於 AWS / Azure / GCP）
  - **AI 訓練專用 cloud**：OCI Supercluster 32,768 GPU per cluster、AI workload optimized
  - **OpenAI $300B 五年合約**：世界最大 AI infra 採購、其他 hyperscaler 無此規模長約
- **Stargate + OpenAI $300B 結構性論點**：
  - **Stargate 計畫**：OpenAI + Oracle + SoftBank 三家共建 $500B AI 資料中心 + 算力 fleet（2024-12 啟動、目標 5 年完成）
  - **OpenAI $300B 五年合約**：Oracle 拿 OpenAI 預付金 + 蓋專屬 DC 給 OpenAI 用
  - **第一個 Stargate site：Abilene Texas**（Crusoe Energy 建設、2025 H2 上線、Oracle 經營）
  - **2025-09 公告**：Oracle 拿 $300B from OpenAI = 世界最大單一 AI 採購合約
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（Oracle 股價 12 月 +130-180%、市值 USD 700-900B、機構持股 + 媒體頭條全飽和）
  - **2025-09-09** Oracle 公告 $300B OpenAI 合約 → 股價 + 35% 單日跳升（紀念性事件）
  - **2026 Q3** Rubin 平台首批出貨：Oracle 與 [[CoreWeave]] + [[Meta]] 並列 Spectrum-X 部署
- vs [[Microsoft]] 採購 OpenAI 算力的關係：
  - Microsoft 是 OpenAI 第一供應商（$13B 投資 + Azure 主力）
  - Oracle 是 OpenAI 第二供應商（$300B 合約、補位 Microsoft 容量瓶頸）
  - **Microsoft + Oracle 雙頭供應 OpenAI**（OpenAI 把 Microsoft + Oracle 都鎖死）

### 目的層

- 業務 mix（FY2025、4Q May）：
  - **Cloud Services & Licensing Support = 75% 營收**
    - 含 OCI（infrastructure）+ Cloud Apps（SaaS）+ License 維護
    - OCI 佔比 ~25-30% + 上升中
  - **Cloud Licensing & On-Premise = 18%**
    - 傳統資料庫授權（高毛利、客戶忠誠）
  - **Hardware（硬體）+ Services = 7%**
- 客戶結構（極度多元）：
  - **Top 5 客戶 < 15%**（vs hyperscaler 集中度差不多、但 Oracle 客戶總數百萬級）
  - **重要 anchor 長約**：
    - **OpenAI $300B 五年**（2025-09 公告、anchor、未來營收 anchor）
    - **TikTok（ByteDance）$45B 五年合約**（2024、Oracle 經營 TikTok US 部分業務）
    - **Anthropic** 部分訓練 cluster（規模未公開、估 $10B+）
    - **xAI** 部分訓練 cluster（與 Microsoft + Oracle 並列）
    - **Microsoft 跨夥伴雲合作**（Oracle Database on Azure、Azure 用 Oracle 資料庫）
  - **Enterprise 客戶基數**：百萬企業（Oracle Database / Fusion / Netsuite 全棧）
- 商業模式 = **「資料庫高毛利 + 雲端高成長」雙引擎**：
  - **Database license + 維護**：高毛利 (~95%) + 客戶忠誠（lock-in 30 年）+ 現金流穩定
  - **OCI 高成長**：YoY +52%、毛利率 ~70%（比 hyperscaler 高）、Sustained CapEx 需要
  - **資本結構**：$163B 長期債（含 Stargate 籌資、2025 Q3 公告 + $20B 新債）
- → 連 [[賣水人選股邏輯（投資版）]]：**「資料庫護城河 + AI cloud 雙引擎」**——不押模型公司誰贏、押所有 AI 公司都需要的資料庫 + 算力
- [[控制點轉移（投資版）]]：拿到「**OpenAI $300B 五年合約 + Stargate 主力 DC 建商 + 1.6T 光模組首批採購 + Trump 政府站台 + Larry Ellison 個人 40% 持股**」五重 anchor

### 供應層

- 跟 [[NVDA]] 關係：
  - **OCI Supercluster GB200 / Blackwell Ultra fleet**：32,768 GPU per cluster
  - **NVDA Spectrum-X 早期部署**（與 CoreWeave / Meta 並列）
  - **NVDA NCP 認證**（與 CoreWeave / Lambda 並列頂級）
  - **2026 Q3 Rubin first wave**：Oracle 是 NVDA Rubin first deployment 三家之一
- 跟 OpenAI 關係（**$300B anchor 合約**）：
  - **2025-09-09 公告**：$300B 五年（2027 起算）= 世界最大單一 AI 採購合約
  - Stargate 第一個 site：Abilene Texas、Crusoe Energy 建、Oracle 經營
  - OpenAI 用 OCI 算力訓練 + 推理 + agent workloads
  - **5 sites by 2028 計畫**：Abilene + Cypress + Atlanta + 兩處未揭
- 跟 [[Microsoft]] 關係：
  - **跨夥伴雲合作**：Oracle Database on Azure（雙向整合）
  - **Microsoft 借 Oracle 容量給 OpenAI**：Microsoft 對 OpenAI 算力承諾的部分外包給 Oracle
  - = **Microsoft + Oracle + OpenAI 三角閉環**
- 跟 SoftBank / Masayoshi Son 關係：
  - **Stargate $500B 共同投資**：OpenAI + Oracle + SoftBank 三家
  - SoftBank 部分財務 anchor、Oracle 主要 DC 建商
- 跟 Crusoe Energy 關係：
  - **Stargate 第一 site Abilene Texas**：Crusoe Energy 蓋、Oracle 經營
  - = Oracle 是 Stargate 計畫的「**經營合夥人 + 客戶獲取**」、Crusoe 是「**建設方**」
- 護城河：
  - **資料庫 30 年護城河**（Oracle Database 全球第一、不可替代）
  - **OpenAI $300B 五年合約 + Stargate 主力 DC 建商**
  - **Trump 政府站台 + Larry Ellison 個人 40% 持股**
  - **OCI YoY +52% 跑出 hyperscaler 增速**
- 風險：
  - **$300B 五年合約 anchor 客戶集中**：若 OpenAI 違約 / 減量、Oracle backlog 衝擊巨大
  - **巨量 CapEx + $163B 長期債**：Stargate 籌資 + Sustained CapEx → 利率敏感
  - **OCI 增速可能放緩**：hyperscaler 自家 ASIC 量產加速 + AWS / Azure 補位
  - **資料庫客戶轉移到 cloud-native**（PostgreSQL / Snowflake / Databricks）= 長期 thin moat
  - **Larry Ellison 個人 40% 持股 / 接班風險**（82 歲、過渡期不明）
  - **股價 12 月 +130-180% 已 price in 多年完美 ramp**
  - **[[循環投資（CSP-Model 互鎖）]] 反向爆破連鎖**：若 OpenAI 估值大幅折價 / 業務崩塌 → Oracle 連鎖受壓（與 Microsoft 同步）
- → 連 [[控制點轉移（投資版）]]：拿到「**Stargate 主力 + OpenAI $300B + Trump 政府背書**」三重控制點外溢、但「**$300B 集中 + $163B 債 + 接班風險**」三重風險疊加

### Bull case

- **1.6T 光模組首批採購者**：Oracle 拿 NVDA stack 全棧優先採購權 = NVDA / [[Lumentum]] / [[Coherent]] / [[IQE]] / [[Ciena]] / [[Nokia]] 全鏈受惠
- **OpenAI $300B 五年合約**：補位 Microsoft Azure 容量瓶頸、Microsoft + Oracle 雙頭供應 OpenAI、Oracle 是 OpenAI 第二大算力供應商
- **Stargate $500B 計畫**：Oracle 是「經營合夥人 + 客戶獲取」+ Crusoe Energy 是「建設方」+ SoftBank 部分財務 anchor
- **OCI Supercluster GB200 / Blackwell Ultra**：Oracle 是 NVDA NCP Elite tier 三家之一（CoreWeave / Lambda / Oracle）

### Bear case

- OpenAI 違約 / 減量 → Oracle $300B backlog 重估 → 連鎖反應到 [[Microsoft]] / Anthropic / Stargate 整鏈
- Stargate 籌資失敗 / 延後 → Oracle CapEx 不順、$163B 債務壓力放大
- OCI 增速放緩 → 雲端 thesis 失效、股價 -50%+ 風險

→ **校準 Leo 三階段論第三階段 1.6T 採購者**：CoreWeave 是「最強 NVDA-aligned」、Lambda 是「first-mover 分散」、Oracle 是「**老牌雲 + OpenAI $300B + Stargate 主力**」最重型採購者、Meta + Microsoft 是「hyperscaler 混搭採購」。五大採購者各有差異化定位。

|---|---|---|
| 路線敏感 | **4** | OCI Supercluster 全 NVDA stack、但 Database 部分業務獨立、不完全押 NVDA 路線 |
| 站別關鍵 | **4** | OpenAI $300B 五年合約 + Stargate 主力 DC 建商 = 站別關鍵度高、但有 AWS / Azure 替代風險 |
| 耗材 | **3** | Database 高毛利 95% + 維護年金 + OCI cloud 訂閱、recurring 性質強 |
