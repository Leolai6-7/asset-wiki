# GlobalWafers（環球晶圓，6488.TW）

## 1. 一句話定位

**全球矽晶圓 #3（~17% 市佔，跟 [[信越化學]] 30% / [[SUMCO]] 25% 雙頭壟斷追趕）+ 台廠矽晶圓 #1 + 中美科技戰結構性受惠者（CHIPS Act + 美國 Texas 新 fab + 義大利 fab 雙軌擴張）+ SiC 第二曲線（環球晶 + Coherent 競合）**——1981 年成立、台灣中美晶（5483）子公司、2011 年從中美晶切出獨立、台股上市；2022 年 GlobalWafers 試圖併購德國 Siltronic（~11% 全球市佔）打造 28% 市佔挑戰雙頭壟斷、被歐盟 + 中國反壟斷阻擋失敗、~$1B 違約金；之後走「**美國 Texas 新 fab + 義大利 Sherman fab + CHIPS Act 美元補貼 + SiC 第二曲線**」獨立擴張路線。在 [[賣水人選股邏輯（投資版）]] 是「**信越 + SUMCO 雙頭壟斷的追趕第三家 + 美國 + 義大利地緣分散 + CHIPS Act 政治紅利**」（18/25 推估）、跟 SUMCO 並列「**矽晶圓真賣水人**」、但**規模 + 議價權 + 客戶 lock-in 都落後雙頭**。

## 2. 三層 thesis

### 產業層

- **全球矽晶圓市佔**（Q1 2026 推估）：[[信越化學]]（~30%）+ [[SUMCO]]（~25%）+ **GlobalWafers（~17%）**+ Siltronic（~11%）+ 中國新昇 / 中環股份（~10%）+ 其他 ~7%
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」過渡期**——
  - 驗證：2024-2026 AI capex driven 300mm 結構性短缺、Texas Sherman fab 2026 H2 量產、義大利 Bedollo fab 擴張
  - 共識未完成：市場仍把環球晶當週期股 + Siltronic 併購失敗陰影、Forward PE ~20x（vs SUMCO 25-30x）
- 在 [[資訊擴散四階段]]：台灣機構 / 賣方深度覆蓋、媒體層尚未爆炒、外資 ETF 配置中
- TAM：300mm 矽晶圓 2024 USD 9.5B → 2030 USD 17B+（CAGR ~10%）；環球晶在 300mm + 200mm + SOI + SiC 全線布局
- 跟 [[AI 記憶體結構性供給短缺]] mirror image：**矽晶圓上游同樣結構性短缺**、但環球晶在雙頭壟斷下議價權弱
- [[Bottleneck Theory（瓶頸論）]] 視角：環球晶 = **第 0 層矽晶圓 substrate 第三家**（跟雙頭壟斷對手位、不在 chokepoint 內）

### 目的層

- 真實角色：**「全球矽晶圓 #3 + 台廠 #1 + CHIPS Act 政治紅利 + Texas 新 fab + 義大利 fab 多元地緣 + SiC 第二曲線」**——不是「跟雙頭壟斷正面對打」（資金 + 規模 + 客戶 lock-in 都落後）、是「**追趕第三家 + 地緣分散 + 政治紅利 + 多元產品線」**、靠「**台灣 + 美國 + 義大利 + 日本 + 韓國 fab + CHIPS Act 補貼 + SiC + SOI 第二曲線**」拿到部分市場
- 業務組合（FY2024 推估）：
  - **300mm 矽晶圓**：~50%（AI / 先進製程主力）
  - **200mm 矽晶圓**：~30%（成熟 + Power IC + 特殊製程）
  - **SOI + epi wafer**：~10%
  - **SiC + GaN wafer**（第二曲線）：~10%（環球晶 + Coherent / Wolfspeed 競爭）
- 商業模式：
  - **多元產品線**（300mm + 200mm + SOI + SiC + GaN）
  - **多元地緣 fab**（台灣 + 美國 + 義大利 + 日本 + 韓國）
  - **CHIPS Act 政治紅利**（Texas Sherman fab USD 4-5B 補貼）
- 核心 IP / 護城河：
  - **晶體生長 IP**（追趕雙頭壟斷）
  - **多元地緣 fab + CHIPS Act 補貼**
  - **SiC + SOI 第二曲線**
  - **台廠 anchor**（國家半導體政策保護 + 台積電合作）
- **美國 Texas Sherman fab**（CHIPS Act anchor）：
  - 投資 USD 4-5B + CHIPS Act 補貼 ~$406M
  - 2026 H2 量產（300mm 矽晶圓）
  - 服務美國 fab（[[Intel]] / [[GlobalFoundries]] / [[Samsung Electronics]] / [[Micron]] / [[TSMC]] Arizona）
- 對應 [[賣水人選股邏輯（投資版）]]：**「矽晶圓真賣水人第三家 + 美國 + 義大利地緣分散 + CHIPS Act 政治紅利」**——但規模 + 議價權 + 客戶 lock-in 都落後雙頭壟斷
- 對應 [[控制點轉移（投資版）]]：拿到「**全球矽晶圓 17% 市佔 + 多元地緣 fab + CHIPS Act 補貼 + SiC 第二曲線**」三層 chokepoint、但**控制權弱於雙頭壟斷**
- 對應 [[半導體基礎建設化]]：跟 SUMCO + 信越化學一樣、矽晶圓從週期商品升級為 AI infra 上游元件

### 供應層

- 跟 [[信越化學]] / [[SUMCO]] 關係（**核心對手 + 落後雙頭壟斷**）：
  - **正面對打**（差距 8-13 pp 全球市佔）
  - 信越 + SUMCO 不正面對打（規模分割）、但**共同壓制環球晶**（拒絕降價戰 + 客戶 lock-in）
  - 環球晶議價權 + ASP 都弱於雙頭
- 跟 Siltronic（德國、Wacker 子公司、~11% #4）對比：
  - **2022 環球晶併購 Siltronic 失敗**（被歐盟 + 中國反壟斷阻擋）
  - ~$1B 違約金 + 整合機會喪失（雙方拉開差距）
  - Siltronic 仍獨立經營、Wacker 子公司
- 跟 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[Micron]] / [[SK Hynix]] / [[GlobalFoundries]] 關係：
  - 全 AVL（但比例小於信越 + SUMCO）
  - 美國 Texas Sherman fab 2026 H2 量產後 → 美 fab 採購占比上升
- 跟 [[Coherent]] / [[Wolfspeed]] 關係（SiC 軸）：
  - SiC wafer 競爭（Coherent 150mm / 200mm 量產 + Wolfspeed 200mm 量產）
  - 環球晶 SiC 規模較小、追趕中
- 跟 CHIPS Act / 美國政府關係：
  - **CHIPS Act 補貼 ~$406M**（Texas Sherman fab）
  - 政治紅利 anchor、跟 [[Intel]] / [[Micron]] / [[Samsung Electronics]] / [[TSMC]] Arizona / [[GlobalFoundries]] 等 CHIPS Act 受惠者並列
- 跟中國國產替代關係：
  - 中國 fab 採購中國新昇 / 中環股份比例上升、環球晶在中國市場份額下降
  - 但環球晶**主要市場在美 / 歐 / 日 / 韓 / 台**、中國市場份額下降影響有限
- 跟 [[Bottleneck Theory（瓶頸論）]] 第 0 層位置：
  - 環球晶 = 矽晶圓 substrate 第三家
  - 不在 chokepoint 內（vs SUMCO + 信越雙頭壟斷）
  - 但**全球矽晶圓緊張時期會受惠**（雙頭壟斷漏出來的需求）
- 護城河：
  - **多元地緣 fab + CHIPS Act 補貼**
  - **SiC + SOI 第二曲線**
  - **台廠 anchor**（國家半導體政策保護）
  - **300mm + 200mm 全線**
- 風險：
  - **規模 + 議價權落後雙頭壟斷**（信越 + SUMCO 結構性壓制）
  - **Siltronic 併購失敗後追趕困難**（雙方拉開差距）
  - **中國國產替代 long term**（中國市場份額下降）
  - **CHIPS Act 政治風險**（美國政府預算 / 補貼變動）
  - **Forward PE 仍 20x 落後 SUMCO 25-30x**（市場仍把環球晶當週期股、Re-rate 慢）
  - **Texas Sherman fab ramp 風險**（建廠 + 良率 + 客戶取得時程）
  - **SiC 第二曲線競爭加劇**（Coherent / Wolfspeed 200mm 量產 oversupply）

- 想要 **AI capex 矽晶圓最純的 beta + 純度勝** → **SUMCO**

- 想要 **多元地緣 + CHIPS Act 補貼 + SiC 第二曲線 + 台廠 anchor + 較低估值** → **環球晶**

## ⭐ 「Siltronic 併購失敗」回顧（2022 結構性事件）

- **2020-2022 GlobalWafers 試圖收購 Siltronic**（USD 4-5B）
- **目標**：整合 GW + Siltronic = ~28% 全球市佔、挑戰 SUMCO 25% + 信越 30% 雙頭壟斷
- **失敗**：
  - 歐盟 + 中國反壟斷局阻擋
  - 2022-02 GlobalWafers 撤回案、~$1B 違約金支付給 Siltronic
- **結構性影響**：
  - 雙頭壟斷穩固維持（信越 + SUMCO 不被挑戰）
  - 環球晶現金流受 $1B 違約金衝擊、隨後走「**獨立擴張**」路線（Texas + 義大利）
  - Siltronic 仍獨立、Wacker 子公司、~11% 市佔
  - 雙方拉開差距、後續可能再無機會挑戰雙頭
