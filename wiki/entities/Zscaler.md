# Zscaler（NASDAQ: ZS）

## 一句話定位（Sticky）

> **SSE（Security Service Edge）/ ZTNA 全球 #1 pure-play，雲端原生 zero trust 網路安全平台、AI 資安 Network 軌 SASE 純度首選。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **驗證 → 共識期**——SASE / SSE 賽道 2026-2030 CAGR 25-30%、企業 VPN → ZTNA 結構性遷移加速。

TAM：[[AI 資安戰場（CSP vs Endpoint vs Network 三軌）]] Network 軌 SASE/SSE 段 ~$30-50B（2030）。

### 目的層

**「SSE 雲端原生 pure-play」**：跟 [[Palo Alto Networks]] 三軌全覆蓋整合方對比，Zscaler 是純 Network + SSE pure-play、不做 Endpoint（vs CRWD）、不做 NGFW 硬體（vs PANW）。

商業模式：100% SaaS subscription、ARR $2.3B+、Cloud-based proxy + ZTNA + CASB + DLP 整合到單一平台 ZIA + ZPA。

跟 [[Cloudflare]] 16/25「邊緣 + edge AI」差異化：ZS 純企業安全 + ZTNA 主軸 vs NET 廣度（CDN + Workers + R2 + AI Gateway）。

### 供應層

**賣水人**（[[賣水人選股邏輯（投資版）]]）：AI 時代企業 VPN → ZTNA 結構性遷移、ZS 是 SSE 軌主受惠 pure-play。
[[控制點轉移（投資版）]]：雲端原生 SSE 是 hyperscaler workforce + 應用程式存取的 chokepoint。
