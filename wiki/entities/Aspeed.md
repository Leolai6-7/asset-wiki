# Aspeed（4555.TW / 信驊科技）

## 一句話定位（Sticky）

> **BMC（Baseboard Management Controller）全球 #1（>70% 市佔），AI server 必裝管理晶片、台廠最被低估的真賣水人 pure-play。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **驗證 → 共識期**——所有 server（cloud + AI + enterprise）必裝 BMC、AI server BMC 規格升級（多 chip + DPU + 安全功能）= 量 × ASP 雙放大。

TAM：BMC 全球市場 ~$0.5-1.5B（2030 推估），CAGR 15-20%。

### 目的層

**「BMC 全球 #1 + 70%+ 市佔壟斷」**：是 [[賣水人選股邏輯（投資版）]] 中「**真賣水人之中的賣水人**」典範——所有 hyperscaler（[[Amazon]] / [[Microsoft]] / [[Google]] / [[Meta]] / [[Oracle]] / [[CoreWeave]]）+ OEM（[[Dell]] / HPE / Lenovo / SuperMicro / [[鴻海 2317|鴻海]] / [[廣達 2382|廣達]] / [[緯創 3231|緯創]]）+ AI server 都要用 Aspeed BMC。

跟 NVDA / AMD / [[AVGO]] AI 晶片 narrative 對比：Aspeed 是「**bom 必裝、不論誰贏、不論架構**」純度型賣水人。

商業模式：晶片 ASP $5-15 USD + 量大 + 高毛利、跟下游 OEM lock-in 強。

### 供應層

**真賣水（純度頂級）**（[[賣水人選股邏輯（投資版）]]）：BMC 70%+ 全球市佔、AI server 量爆炸 = Aspeed 結構性受惠。
[[控制點轉移（投資版）]]：BMC 是 server 系統管理 chokepoint、Aspeed 拿著結構性壟斷。
