# Eoptolink（新易盛 300502.SZ）

## 1. 一句話定位

**中國光模組 #2 + LPO（Linear Pluggable Optics）+ Pluggable optics 純度型 OEM 模組廠 + 1.6T 量產追趕 [[Innolight]] 2026 H2 ramp + NVDA + 4 大 CSP + AT&T / Verizon 電信差異化客戶 + Thailand + Vietnam 海外產能**——[[Innolight]] 300308.SZ 中國光模組 #1 的**姊妹廠 + 雙頭代表**（合計中國 60-70% 市佔）、跟 [[Lumentum]] / [[Coherent]] / [[AAOI]] vertical integration **不同層**（OEM 模組廠定位、跟 Innolight 同層）、[[CPO 供應鏈圖譜]] 第 5 層光模組組裝 + **LPO 路線 first-mover 差異化**+ [[Bottleneck Theory（瓶頸論）]] 第 5 層 Beneficiary 純度型（vs Innolight 規模型）、[[AI infra CapEx 三階段論]] 第三階段 1.6T 光模組量爆增**首批 30 倍跳升**雙頭受惠者之一。

## 2. 三層 thesis

### 產業層

- 光模組賽道進入 [[市場四階段：懷疑／驗證／共識／反轉]] **共識階段**、Eoptolink 是「光通訊賽道從共識到反轉前」的**中國 OEM 雙頭其二 + LPO 路線純度首選**
- 1.6T 光模組 2025 ~180 萬顆 → **2026 3,000 萬顆+（NVDA 占比 60%+）**= **十幾倍跳升**（見 [[AI infra CapEx 三階段論]] 訊號 1）
- 跟 [[賣水人選股邏輯（投資版）]] 連結：**OEM 模組賣水人 LPO 純度型**（vs Innolight 全產品線規模型、vs AAOI vertical integration 純度型 = 三種不同 OEM 賽道哲學）
- 跟 [[Hyper Rail / Multi-Rail（光通訊整合技術）]]：1.6T 模組 17 倍增量結構性放大 = Eoptolink 跟 Innolight 雙頭受惠
- 跟 [[CPO 供應鏈圖譜]] 第 5 層：光模組組裝同層 [[Innolight]] / [[Lumentum]] / [[Coherent]] / [[AAOI]]
- 在 [[資訊擴散四階段]]：已 ETF 化（中國 A 股、12M +400-700% 漲幅、外資配置滿了）
- vs [[Innolight]] 全球 transceiver 30%+ 市佔（LightCounting #1）：Eoptolink **全球 transceiver 8-12% 市佔**（推估、LightCounting top 5）= 「**規模略小但 LPO + 電信客戶差異化**」分歧路線

### 目的層

- **業務組合**（FY2025 推估）：
  - **光模組（transceiver）**：~88-92%（**主力業務**）—— 100G / 200G / 400G / 800G / **1.6T 全線**
  - **光器件 + 客製化**：~8-12%
- **光模組細拆**（按速率 + 技術路線）：
  - **800G**：[[NVDA]] / [[Google]] / [[Microsoft]] / [[AWS]] / [[Meta]] 全 hyperscaler 供應、市佔 15-20%（vs Innolight 25-30%、規模略小）
  - **1.6T**：**2026 H2 量產追趕**（vs Innolight 2026 H1 / [[AAOI]] 2026-03 / [[Coherent]] 2026 H2 並列）、目標市佔 15-25%
  - **LPO（Linear Pluggable Optics）路線 first-mover**：跟 [[AAOI]] 北美 LPO 並列、**Eoptolink 是中國 LPO 首發廠商**（vs Innolight 走傳統 transceiver + LPO 並重）
  - **Pluggable optics 純度型**：以 pluggable 為主軸、vs CPO（co-packaged optics）策略上偏謹慎、跟 [[POET Technologies]] / [[Ayar Labs]] 不同 layer
  - **200G / 100G**：規模出貨穩定 base
- **AI server + 電信客戶結構**：
  - **NVDA**：Blackwell + Rubin 800G/1.6T 供應（推估 15-25%、vs Innolight 25-35% 略小）
  - **Google**：TPU + Spectrum-X + Hyper Rail 配套（傳統大客戶）
  - **Microsoft / AWS / Meta**：4 大 CSP 直供（覆蓋率跟 Innolight 接近、規模略小）
  - **AT&T + Verizon**：⭐ **美國電信運營商直供**（Innolight 較弱）= 差異化通道
  - **中國電信運營商**：⭐ 中國電信 / 中國移動 / 中國聯通三大電信 OEM 直供 = 中國電信網路升級 anchor
  - 客戶結構**比 Innolight 略電信化**（Innolight 偏 hyperscaler 純度高、Eoptolink 雙軌 hyperscaler + telco）
- **產能 + 擴張**：
  - 成都 + 深圳 + 廣州 大陸主廠
  - **Thailand + Vietnam 雙海外廠**（規避美國 ITAR + Section 301、Vietnam 廠是跟 Innolight 差異化亮點）
  - 1.6T 量產 line 2026 H2 開出（追趕 Innolight 2026 H1）
- 商業模式核心：
  - **「**中國光模組 #2 + LPO + Pluggable optics 純度 + 電信客戶差異化**」**：規模略小於 Innolight、但 LPO + 電信 + 多海外廠三軸差異化
  - **OEM 模組廠模式**：採購 [[Lumentum]] / [[Coherent]] / [[IQE]] EML / pump laser → 組裝 + 測試 + 客製化（跟 Innolight 同層）
  - **「LPO + Pluggable 路線純度」**：策略上不押 CPO、跟 [[AAOI]] LPO 路線並列、但純度型差異化
  - **「**多海外廠 hedge**」**：Thailand + Vietnam 雙廠 vs Innolight Thailand 單廠（地緣 hedge 多一層）
- 對應 [[賣水人選股邏輯（投資版）]]：**OEM 模組賣水人 LPO 純度型**——不押 NVDA / Google / Meta / Microsoft 誰贏、押**所有 hyperscaler + 電信運營商 1.6T LPO 都要用**
- 對應 [[控制點轉移（投資版）]]：**沒有強控制權**（OEM 模組廠定位、跟 Innolight 同層被 [[Lumentum]] / [[Coherent]] / [[IQE]] InP 上游 chokepoint 壓制）——**LPO 路線純度 + 電信客戶分散**提供差異化 alpha

### 供應層

- 跟 [[Bottleneck Theory（瓶頸論）]] / Serenity 框架：
  - **第 5 層 Beneficiary**（非 chokepoint）——「跟著賽道漲、可替代、有競爭」
  - 跟 [[AAOI]] vertical integration 不同：Eoptolink 採購 EML / pump laser → OEM 組裝（跟 Innolight 同層）
  - 跟 [[Innolight]] 並列「中國 OEM 雙頭」**LPO 純度型 vs 全產品線規模型分歧路線**
  - vs [[Lumentum]] / [[Coherent]] vertical integration EML 自製 = **不同層級**
- 跟 [[Lumentum]] 關係（**上游 + 部分對手**）：
  - **採購 LITE EML / pump laser → OEM 組裝**（依賴 LITE 上游、跟 Innolight 同樣是 LITE 客戶）
  - 同時跟 LITE transceiver 業務間接對打（LITE 自做模組、規模較小）
  - LITE 2026 H1 EML 供應 >30% 缺口（[[AI infra CapEx 三階段論]] 訊號 2）= **Eoptolink 1.6T 2026 H2 量產取得直接受影響**
  - → **Eoptolink 是 LITE 客戶 + 弱對手雙重關係**（vs Innolight 規模型壓力更直接）
- 跟 [[Coherent]] 關係：
  - **採購 COHR EML → OEM 組裝**（依賴 COHR 上游、跟 Innolight 同層）
  - COHR FY2025 transceiver $5.81B / 25% 市佔 vs Eoptolink 8-12% 市佔 = **COHR 規模 > Eoptolink transceiver 業務**
  - COHR vertical integration EML 自製 + SiC 第二曲線多元 = COHR 規模 + 純度雙勝
  - → 跟 LITE 同樣是「客戶 + 弱對手」
- 跟 [[AAOI]] 對比（中國 LPO vs 美國 LPO）：
  - **AAOI 北美本土 vertical integration + LPO**（2026-03 量產、Microsoft ROFR）
  - **Eoptolink 中國 LPO first-mover + Thailand + Vietnam 海外廠**（2026 H2 量產追趕）
  - **AAOI 純度更高（laser chip 自製）+ Eoptolink 規模略大 + LPO 路線 + 多海外廠 hedge**
  - 兩家**都是 LPO 路線首發、但 layer 不同**（AAOI 跨第 4-5 層、Eoptolink 純第 5 層）
- 跟 [[Innolight]] 對比（**中國 OEM 雙頭 + 差異化**）：
  - **中國 OEM 雙頭**（Innolight + Eoptolink、合計中國 60-70% 市佔）
  - Innolight 規模略大（~6x 營收、全球 transceiver 30%+ 市佔 vs Eoptolink 8-12%）
  - Innolight 客戶 NVDA + Ciena + Nokia 全直供 + 客戶分散 5/5 滿；Eoptolink AT&T + Verizon 電信差異化 + 中國電信運營商 anchor
  - Innolight 全產品線 transceiver 規模型；Eoptolink **LPO + Pluggable optics 純度型**
  - → **共同壓制中國 OEM 第三梯隊**（光迅 002281 + Accelink / 武漢光訊 + 海信）+ **互補不互相消滅**（Innolight 規模 + Eoptolink LPO/telco 差異化）
- 跟 [[NVDA]] 路線：
  - **NVDA Blackwell / Rubin 800G / 1.6T 供應**（推估 15-25%、vs Innolight 25-35%）
  - NVDA 2026-03 投資 [[Lumentum]] $2B + [[Coherent]] $2B 後 = NVDA 直接綁 EML 上游、Eoptolink 透過 LITE/COHR 拿到 EML
  - 跟 NVDA Spectrum-X / Quantum-X 配套（光通訊配置 LPO transceiver 一定要用）
  - NVDA 多源策略：Innolight + Eoptolink + AAOI + Coherent 4 家 1.6T 供應商 = NVDA 不會把 1.6T 全綁在單一家
- 跟 [[Ciena]] / [[Nokia]] 關係（DCI 廠商）：
  - Ciena / Nokia 做 DCI 系統、需要 1.6T transceiver
  - Eoptolink 透過 Ciena / Nokia 配套出貨（vs Innolight 直供 hyperscaler 為主）

  - **美國電信運營商**：AT&T + Verizon 5G/6G 回程網路 + 光纖到家 + edge 算力配套 = Eoptolink 直供（Innolight 較弱）
  - **中國電信運營商**：中國電信 + 中國移動 + 中國聯通三大電信網路升級 + 光纖到府 + 5G/6G fronthaul/backhaul 配套
  - 電信客戶結構**比 Innolight 略電信化**（Innolight 偏 hyperscaler 純度高、Eoptolink 雙軌 hyperscaler + telco）

  - POET / Ayar Labs 做光晶片整合 platform = 跟 Eoptolink OEM 模組廠**不同 layer**
  - Eoptolink 偏好 pluggable / LPO 路線、CPO 策略上謹慎 = 跟 POET / Ayar Labs CPO ecosystem 不直接競爭、但中長期 CPO 量產 = Eoptolink Pluggable 業務 displacement 風險

  - InP 供應緊繃 → EML 缺貨 → Eoptolink 1.6T 2026 H2 量產取得受限（中期風險、跟 Innolight 同樣）

  - **中國光模組 #2 + 全球 transceiver 8-12% 市佔**（LightCounting top 5）
  - **LPO 路線 first-mover**（中國 first / 跟 AAOI 全球並列）

  - **Thailand + Vietnam 雙海外廠**（規避美國 ITAR / Section 301、地緣 hedge 多一層）
  - **跟 Innolight 共同壓制中國 OEM 第三梯隊**（光迅 + Accelink + 海信）

  - **OEM 模組廠定位 = 沒強控制權**（被 LITE / COHR / IQE 上游 chokepoint 壓制、跟 Innolight 同樣）
  - **規模略小於 Innolight**（~6x 營收差、全球 transceiver 市佔差距 8-12% vs 30%+）
  - **美國 ITAR / Section 301 出口管制升級風險**（Thailand + Vietnam 廠 hedge 但不完全）
  - **NVDA 直接綁 LITE / COHR EML = 中期可能繞過 OEM 中間商**（跟 Innolight 同樣）
  - **CPO 取代 plug-in optic 風險**（2027-2028 hyperscaler 全面 CPO 化 → LPO / Pluggable 業務萎縮、Eoptolink CPO 策略上謹慎反成劣勢）
  - **AAOI 北美本土 LPO 在 NVDA / Microsoft 拿走部分高端市場份額**
  - **Innolight 全產品線壓制 + 規模 6x 差距**（中長期客戶 lock-in 跟 Innolight 比落後）
  - **中國 A 股流動性 + 外資配置滿了**（估值 stretched、Forward PE 25-40x）
  - **Eoptolink 不是 chokepoint = 中長期 displacement 風險**（跟 Innolight 同樣）
  - **電信客戶結構需求 vs hyperscaler 結構性增速差距**（電信 5G/6G 升級節奏比 hyperscaler 慢）

| **客戶分散** | **5 / 5** ⭐ | **NVDA + 4 大 CSP + AT&T + Verizon + 中國電信運營商三大電信 = hyperscaler + 電信雙軌**（與 Innolight 並列光通訊賽道客戶分散度最高、但不同類差異化）|
