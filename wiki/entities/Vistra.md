# Vistra（VST）

## 1. 一句話定位

**美國核電 #2 + 氣電 firm power 規模龍頭 + 跨 PJM/ISO-NE/ERCOT 地緣分散**——總部 Irving, Texas（2016 Energy Future Holdings 拆分而來）；**41GW 多元發電 fleet**（核電 6.4GW 美 #2 + 氣電 30GW+ 美最大私營 + 再生能源 + 儲能）；2026-01 簽 [[Meta]] **20 年 PPA 約 2,600MW** 跨 PJM 三座核電廠（含 uprate）= 美國 IPP 跟單一 hyperscaler 簽的最大規模核電 PPA 之一；同期宣布 **$4-4.7B 收購 Cogentrix 5,496MW 氣電 portfolio**（10 廠跨 PJM/ISO-NE/ERCOT、中後期 2026 完成）= **氣電容量翻倍**；同時與 [[AMZN]] AWS 簽長期 PPA、進一步綁定 hyperscaler；Q1 2026 營收 **$5.63B** + 淨利 **$1,029M** + Adj EBITDA **$1.494B**、FY 2026 Adj EBITDA guidance **$6.8-7.6B**、2027 預估營收上修 $18.8B → $23.3B；股價 12 個月 +140-260%（thematic）；是 [[AI infra 電力戰場]] **三層分工中第一層「電力產生」的 #2 anchor**（CEG 規模 / TMI 政治焦點 第一、VST 多元地緣分散 + 氣電 firm 第二）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - VST 跟 CEG 同走 narrative：核電 stranded asset → AI 必需資產
  - **2026-01 Meta 2.6GW PPA + Cogentrix $4.7B 收購同日宣布** = market re-rate 集中事件
- 美國 PJM Interconnection 容量緊缺：
  - PJM 容量市場價格 2025-2026 創新高（單 zone 最高 $269/MW-day）
  - AI data center load 推升 PJM 區電力批發價 / 容量價同步走高
  - VST PJM 核電 + 氣電 fleet = 容量市場最大受惠者
- 美國 ERCOT（德州）電力需求 2025-2030 預估 **+40-60% / 5 年**（AI + 電動車 + 工業回流）
  - VST 在 ERCOT 是最大私營發電商
- 對應 [[AI infra 電力戰場]]：**第一層電力產生 #2 anchor**（核電 + 氣電 firm 雙引擎、跟 CEG 形成 dual anchor）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]**三標準全滿**：供給結構改變 + Cogentrix CapEx $4.7B + Meta 20 年 PPA 鎖死

### 目的層

- 業務 mix（2025 為主、2026 Cogentrix 併入後改變）：
  - **氣電（含 Cogentrix 後）~55-60%**：30GW+ 現有 + Cogentrix 5.5GW（pending）= **35-40GW 美國最大私營氣電 fleet**
  - **核電 ~15-18%**：6.4GW（Comanche Peak Texas + Beaver Valley + Davis-Besse + Perry Ohio）= 美國 #2
  - **再生能源 ~10%**：太陽能 + 風電 + 儲能（PV + battery storage）
  - **零售 retail electricity provider**：TXU Energy（德州最大）= 直接賣電給終端
- **AI / hyperscaler 直接 PPA 占未來營收占比**：
  - 2025：~3-5%（Meta + AWS PPA 剛簽、未跑滿）
  - 2030+：估算 **>15-20%**（PJM 核電 PPA 跑滿 + 額外簽約）
- 客戶結構（hyperscaler PPA 明細）：
  - **[[Meta]]**：**20 年 PPA 2,600MW** 跨 PJM 三廠核電（含 uprate）（2026-01 簽、2030+ 跑滿）
  - **[[AMZN]] AWS**：多年期 PPA（具體規模未公開、part of broader hyperscaler deals）
  - 其他簽約客戶 / spot market：零售 retail（TXU Energy 德州 #1）+ 商業 / 工業客戶
- 商業模式核心：
  - **核電 baseload + 氣電 firm + 儲能 peaker** 三段組合 = 涵蓋 base / mid / peak load 全段
  - **跨地緣分散**：PJM（核電 + 氣電）+ ISO-NE（氣電）+ ERCOT（氣電 + retail）= 三大 ISO 全覆蓋
  - **零售 retail（TXU Energy）**：vertical integration 至終端 = 從發電到賣電完整
  - **長期 PPA + 容量市場**：發電 1/3 PPA + 1/3 容量市場 + 1/3 spot energy 混合定價
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人 + 地緣分散版**——比 CEG 多 ERCOT 曝險
- 對應 [[控制點轉移（投資版）]]：拿到「**核電 + 氣電 + 零售 retail + 跨 ISO**」四段控制點

### 供應層

- 跟 [[Meta]] 路線：**2026-01 20 年 PPA 約 2,600MW**（含 uprate）跨 PJM 三廠核電
  - 跟 CEG 的 Meta PPA 不同：VST 是**多廠合計 2.6GW + uprate**、CEG 是**單廠 Clinton 1,121MW**
  - → Meta 同時簽 CEG + VST = **hyperscaler 分散採購策略**（避免單一電力公司 lock-in）
- 跟 [[AMZN]] AWS 路線：多年期 PPA + 商業 / 工業客戶
  - vs Talen Energy Susquehanna 1.92GW PPA 對 AWS = **AWS 也雙頭採購**（VST + TLN）
- 跟 [[Microsoft]] / [[Google]]：未公開 PPA、但 Cogentrix 5.5GW 整合後可後續配對
- 跟 [[Constellation Energy]] 競爭：
  - **CEG**：核電 baseline 32.4GW > VST 6.4GW = **CEG 5x 規模優勢**（核電）
  - **VST**：氣電 30GW+ + Cogentrix 5.5GW > CEG Calpine 26GW = **VST 氣電優勢**
  - **VST**：跨 PJM + ISO-NE + ERCOT 三 ISO（CEG 主要 PJM）= **VST 地緣分散優勢**
  - **VST**：TXU Energy 零售（CEG Calpine 整合後有 retail，但 VST 累積品牌深）
  - → **不是零和**：VST + CEG 共同擴大電力公司 re-rating narrative
- 跟 Talen Energy（TLN，⚠️ 待 ingest）對比：
  - **VST**：41GW 多元 fleet + Meta 2.6GW + AWS PPA = 規模 + 多客戶
  - **TLN**：2.5GW Susquehanna 1 廠 + AWS $18B 17 年 PPA = **單一 PPA pure-play**
  - → VST 是多角化 baseline + 高客戶分散、TLN 是高純度 alpha
- 跟 [[GE Vernova]] 補完關係：
  - VST 是「**電力產生**」、GEV 是「**電力傳輸 / 變壓器**」= 同戰場不同層
  - VST 氣電擴建用 GEV gas turbine（VST 是 GEV gas turbine 重要客戶之一）
- 護城河：
  - **物理資產**：6.4GW 核電執照 + 30-40GW 氣電 fleet = 複製不可能
  - **跨地緣 ISO**：PJM + ISO-NE + ERCOT 三 ISO 覆蓋 = 單一區域風險分散
  - **TXU Energy retail**：德州最大零售品牌 = 終端議價權
  - **氣電 firm power**：跟核電配對成 24/7 + dispatchable peak load
  - **Cogentrix 5.5GW**（pending）= 氣電容量再翻倍
  - **CHIPS Act / IRA PTC**：核電 $15/MWh 補貼至 2032
- 風險：
  - **Cogentrix 整合風險**：$4.7B 收購 mid-late 2026 完成、整合 12-18 個月觀察期
  - **核電老化 + uprate**：Comanche Peak Texas（1980s 建造）+ PJM 廠老化 uprate 風險
  - **ERCOT 電網脆弱**：2021 德州冬季電網崩盤、未來極端天氣風險
  - **PJM 容量市場改革**：FERC 法規調整可能影響 IPP 競價結構
  - **氣價波動**：氣電 30GW+ 對天然氣價格敏感 = LNG 出口擴大可能推升 Henry Hub 價
  - **CSP 自建電力**：MSFT + AMZN 直接簽 PPA、可能繞過 IPP
  - **政治風險**：Trump 政府支持化石燃料 + 核電、但 2028 政權更替可能反轉

## pair trade / 配置建議

### 多 VST（不需 pair）

**論點**：VST 是 AI 電力戰場 #2 anchor（23/25 高分）、跨三 ISO 地緣分散、PE 20-22 比 CEG 30-32 折價、20 年 PPA 鎖死。

**配置**：核心持倉、5-10% 配置上限。

### 配對思路

**多 VST / 多 CEG（雙頭做多）**：
- 兩家形成 dual anchor、不是對手
- VST 提供地緣分散、CEG 提供 TMI 政治焦點
- → 對 AI 電力 narrative 雙腳壓

**多 VST / 空 NRG Energy**：
- 多 baseload firm（核 + 氣）/ 空純 peaker 氣電
- NRG 沒有核電、純氣電 + retail、AI anchor 弱於 VST
- → 結構性勝負明確

**多 VST / 空 NextEra（多 firm / 空 renewable）**：
- 多 firm power（核 + 氣）/ 空 intermittent renewable
- 但 NextEra 太陽能護城河強、空單風險

→ **結論**：VST 獨立做多倉、不需 pair；如要對沖、可空 utility ETF（XLU）部分。
