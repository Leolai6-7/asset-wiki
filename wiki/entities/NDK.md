# NDK（6779.JP、Nihon Dempa Kogyo / 日本電波工業）

## 1. 一句話定位

**日本石英 #1 + 石英晶體龍頭 + Apple iPhone A 系列 timing anchor + 光學晶振（光通訊用）+ 石英陣營日台三巨頭之一**——1948 東京創立的日本石英 timing 元件龍頭、石英晶體 + TCXO + OCXO + 光學晶振四產品線、Apple iPhone A 系列 timing 主供 + Samsung + Sony + 汽車 OEM 客戶；FY2025 營收 ~¥600-800 億 JPY（USD ~$4-5 億）、Forward PE 15-20x、12M +5-25%；定位「**石英陣營日本 anchor + Apple 集中度高（客戶分散僅 1 分扣分）+ 光學晶振 differentiator**」、跟 [[TXC]] / [[Epson]] 並列日台三巨頭。

## 2. 三層 thesis

### 產業層

- **石英 timing 賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證**」段
  - 全球石英 timing 市場 ~USD 30-35 億（2025）+ CAGR ~5-8%（vs [[SiTime]] MEMS ~25-30% CAGR 高 3-5x）
  - NDK 全球石英晶體 top 3、市佔 ~10-15%（跟 [[TXC]] 並列）
  - **日本石英 #1**：跟 [[TXC]] 台灣 #1 / [[Epson]] Quartz Device 段並列日台三巨頭
- **跟 [[SiTime]] MEMS 路線分歧 anchor**：
  - **[[SiTime]] MEMS**：高端 5G / AI server / 衛星 / 機器人、$1.85B 市值、Forward PE 75-100x（high growth premium）
  - **NDK 石英**：智慧手機（Apple iPhone）+ 消費電子 + 汽車 + 光通訊、Forward PE 15-20x
  - **NDK 光學晶振 differentiator**：光通訊（DCI / 5G transport）光晶振 niche 賽道、跟 [[Lumentum]] / [[Coherent]] 並列受惠
- [[資訊擴散四階段]]：機構（日本基金 + Apple 供應鏈分析）→ 賣方（日經 / 野村 / 大和）→ 西方媒體有限擴散

### 目的層

- 主業 mix（FY2025）：
  - **石英晶體**（基礎元件）：~40% 營收、智慧手機 / IoT / 汽車主場
  - **TCXO**（溫補晶振）：~25% 營收、智慧手機（Apple iPhone A 系列主供）+ 5G base station + 汽車 ADAS
  - **OCXO**（恆溫晶振）：~15% 營收、5G base station + 衛星 + 軍工 + 高精度
  - **光學晶振**（光通訊用）：~10% 營收 = **NDK differentiator**、DCI / 5G transport / 100G/400G/800G/1.6T 光模組 timing
  - **其他**：~10% 營收（汽車 OEM 模組 / Custom 模組）
- **Apple iPhone A 系列 timing anchor**：NDK Apple iPhone timing 主供 ~10+ 年、A 系列 Bionic SoC timing 配套 design-in
- 客戶結構（FY2025）：
  - **Apple iPhone A 系列**：~30-40% 營收 = NDK 最大單一客戶（**客戶分散僅 1 分扣分主因**）
  - **Samsung Galaxy + Sony**：~15-20% 營收
  - **汽車 OEM**（Toyota / Honda / Nissan / 中國 EV）：~20-25% 營收 = ADAS + IVI
  - **AI server / 通訊**：~10-15% 營收 + 光通訊 niche 段
  - **工業 / 軍工**：~5-10% 營收
- 商業模式：**設備重資產 + Apple 共生 lock-in**——石英 wafer 切割 + 精密加工 + Apple iPhone qualification 多年 lock-in、東京 + 山形 + 大阪 + 馬來西亞 + 泰國產能
- → 連 [[賣水人選股邏輯（投資版）]]：**石英陣營日本 anchor + Apple iPhone 共生 + 光學晶振 niche** — 不押 GPU / DSP 路線、押「**所有 iPhone + Samsung + 光通訊 1.6T 都需要 timing**」

### 供應層

- **路線：石英陣營 vs [[SiTime]] MEMS 路線分歧 + Apple anchor**：
  - 石英成熟 50 年 IP vs MEMS 規格升級空間大
  - **Apple iPhone 共生 anchor**：NDK 是 Apple iPhone A 系列 timing 主供、Apple 集中度極高、是 NDK 護城河但也是風險
  - **光學晶振 differentiator**：光通訊用光晶振 niche 賽道、跟 Lumentum / Coherent 並列受惠
- 護城河四層：
  - **Apple iPhone qualification lock-in**：A 系列 Bionic SoC timing 配套 ~10+ 年共生、qualification 5+ 年起跳
  - **石英晶體 IP**：50 年精密加工 know-how
  - **光學晶振 IP**：光通訊 timing differentiator（vs TXC / Epson 純電晶體陣營）
  - **產能彈性**：東京 + 山形 + 大阪 + 馬來西亞 + 泰國五地分散
- 競爭格局：
  - **vs [[SiTime]]**（NASDAQ: SITM）：路線分歧、SiTime 高端 5G / AI server / 衛星 / 機器人、NDK 智慧手機 + Apple anchor + 光學晶振 niche
  - **vs [[TXC]]**（3042.TW）：規模相當（NDK ¥600-800 億 JPY ≈ TXC NT$120-150 億 ≈ USD $4-5 億）、NDK 勝 Apple iPhone anchor + 光學晶振、TXC 勝客戶分散
  - **vs [[Epson]]**（6724.JP）：Epson Quartz Device 段佔 Epson 整體 ~10%、Epson 屬於 conglomerate（印表機 + 投影機 + 機器人）、NDK 純 timing 玩家
  - **vs [[Kyocera]]**（NYSE: KYO + 6971.JP）：Kyocera 石英只是 conglomerate 一段、規模較 NDK 大 30x
  - **vs [[Rakon]]**（NZX: RAK）：niche 玩家、NDK vs Rakon 規模差 10-15x
- 風險：
  - **Apple iPhone 集中度極高**：~30-40% 營收 = **客戶分散僅 1 分扣分主因**、若 Apple 切換供應商（如 SiTime MEMS）NDK 衝擊極大
  - **[[SiTime]] MEMS 高端滲透**：5G / AI server / 衛星市佔提升、NDK 高端 OCXO 受壓
  - **智慧手機萎縮**：Apple iPhone 銷量大跌（中國市場 + 印度競爭）、NDK 基本盤受壓
  - **JPY/USD 匯率**：高出口比重、日圓升值壓營收
  - **[[CapEx 見頂辯論]]** + 光通訊 1.6T ramp 延遲 → 光學晶振 niche 受壓
- → 連 [[控制點轉移（投資版）]]：**Apple iPhone timing 控制權 + 光學晶振 niche** = NDK 在「Apple 供應鏈 + 光通訊」兩個 chokepoint 拿到位置

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ Apple iPhone + Samsung + 汽車 + 光通訊四引擎 |
| 毛利率 | ⚠️ Apple 集中度壓低 ASP、毛利率 ~10-15% 中段 |
| OpEx | ⚠️ 馬來西亞 + 泰國 capex 持續 |
| 營業利益 | ⚠️ AI server 高毛利但佔比仍小、整體 op margin 平緩 |

→ **Re-rate 三角形 2/4**——Apple iPhone + 汽車 + 光通訊四引擎仍 ramp、整體營收品質改善、但 Apple 集中度 + capex 壓力延後 op margin 提升。估值 Forward PE 15-20x 反映「**日本石英大宗 + Apple anchor**」定位。

### ✅ 催化

- AI server timing 滲透：1.6T 光模組 timing 受惠（光學晶振 niche）
- Apple iPhone A 系列 timing 持續配套（NDK 主供 lock-in）
- 汽車 ADAS / IVI / 車聯網 ramp
- 1.6T DCI Hyper-Rail / Multi-Rail 光學晶振受惠
- 日圓回穩 → 高出口比重直接受益
- FY2026 自家指引 +10-20%（待 NDK 法說會校準）

### ⚠️ 風險

- **Apple iPhone 集中度極高**（~30-40%）= 客戶分散僅 1 分扣分主因、Apple 若切換供應商衝擊極大
- **[[SiTime]] MEMS 高端滲透**：5G / AI server / 衛星市佔提升 → NDK 高端 OCXO 受壓
- **Apple iPhone 銷量大跌**：中國市場萎縮 + 印度競爭
- JPY/USD 升值壓營收
- [[CapEx 見頂辯論]] 兌現 + 光通訊 1.6T ramp 延遲
