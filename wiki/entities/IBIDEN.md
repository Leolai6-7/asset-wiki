# IBIDEN（4062.JP）

## 1. 一句話定位

**全球 ABF 載板 #1 + AI 伺服器 IC 基板絕對龍頭**——成立 1912 年的日本岐阜縣大垣陶瓷／印刷電路板老牌、AI server build-up substrate 2023 市佔 **85%**（2026 降至 55% 仍 #1）、[[NVDA]] AI GPU **歷史獨家供應商**、Blackwell 載板 **75% 市佔**（[[欣興]] 25%）、Intel EMIB 全球僅兩家有量級供應之一（搭 [[欣興]]）；在 [[ABF 載板 vs 玻璃基板 displacement]] 的命運是「**受惠 + 觀望**」雙頭——一面用 5,000 億日圓擴 ABF 產能（2028 倍增至 2.5 倍）押 AI server ABF 大循環、一面玻璃基板還停在「R&D / 探索期」（落後 [[Samsung Electro-Mechanics]] / [[Absolics]]，跟 [[南電]] 同檔）；FY2026（截至 2026-03）營收 ¥4,162 億日圓（+12.7% YoY）、淨利 ¥637 億（+89% YoY）、股價 12 個月 **+530%**。

## 2. 三層 thesis

### 產業層

- ABF 載板 [[市場四階段：懷疑／驗證／共識／反轉]] 在「驗證 → 共識」加速段
  - 全球 ABF/FC-BGA 2026 市場 USD 55.6 億、2035 CAGR 5.6% 至 90 億
  - Unimicron + Ibiden + Shinko 三家合計 **75%** 全球 ABF
  - AI server build-up 子市場（IBIDEN 主場）：2023 IBIDEN **85% 一家獨大** → 2026 **55%**（[[欣興]] 拉高至 ~25%）
- 玻璃基板賽道 [[玻璃基板與 FOPLP 賽道]] 在「樣品驗證 → 早期商業化」、2026 小量、2030 主流
- 跟 [[ABF 載板 vs 玻璃基板 displacement]] 關係：**最複雜**
  - NVDA Vera Rubin / Rubin Ultra **仍走 CoWoS-L + ABF**（不轉 CoWoP）= IBIDEN 主場繼續吃到 2028
  - [[Intel]] EMIB / EMIB-T 推上 AI ASIC 領域 = IBIDEN 受惠（EMIB 客戶基板預付款計畫已成形）
  - 玻璃化主要打 [[Intel]] Clearwater Forest（[[欣興]] design partner）+ [[Apple]] Baltra（[[Samsung Electro-Mechanics]] 拿）+ [[AVGO]] Tomahawk 8（Toppan JV）= **IBIDEN 目前在玻璃 side 是「觀望者」**
- MLCC 嵌入式基板（下一賽道）：[[Samsung Electro-Mechanics]] 先發、IBIDEN 用 5,000 億日圓追擊 = 開第二戰場

### 目的層

- 主業 mix（FY2026）：
  - **Electronics（IC 基板）= 65% 營收**：¥2,433 億日圓（+23.4% YoY）、OP ¥453 億（+68.5% YoY）= 主成長引擎
  - **Ceramics（陶瓷 DPF / 觸媒載體）= 23% 營收**：汽車排氣濾清器、FY2026 -1.8%、OP -37.4% = 拖後腿
  - 其他 ~12%
- AI server IC 基板**獨大** = 公司命脈所在
  - 2023 AI build-up substrate 市佔 85%、2026 55%
  - [[NVDA]] Blackwell 載板 75%（[[欣興]] 25%）
  - Apple iPhone 18 / M5 mac 載板（旗艦消費級 ABF）
  - 開始 allocate（限量）給次級客戶 = 賣方市場
- 客戶結構（vs 台廠 ABF 三雄）：
  - **大客戶**：[[NVDA]]（歷史獨家）+ [[Intel]]（EMIB 主供）+ [[Apple]]（M 系列 + iPhone）
  - 未明確：TSMC（[[欣興]] 跨體系優勢、IBIDEN 未確認）、AMD（[[南電]] EFB 體系優勢）、AVGO（[[南電]] 強）
  - = **IBIDEN 客戶結構偏「Intel + NVDA + Apple 美日歐三強」、ASIC 客戶相對較弱**
- 商業模式：高階 ABF 純度最高 + 設備 / IP 自有 + 大垣總部 + Gifu 在地化（Ono / Gama 兩廠）
- → 連 [[賣水人選股邏輯（投資版）]]：AI 算力擴張時代**最賺錢的賣水人**（毛利率三雄之上）

### 供應層

- 跟 [[NVDA]] 路線：Blackwell 75% 份額 + Vera Rubin / Rubin Ultra 仍走 ABF（**不轉 CoWoP**）
  - Rubin Ultra 載板**比 Rubin 更大、層數更多** = ABF 用量 15-18 倍 = IBIDEN 受惠倍增
  - NVDA 占用全球 CoWoS 50% 以上 = IBIDEN 載板綁定
- 跟 [[Intel]] 路線：EMIB 全球僅兩家有量級供應（搭 [[欣興]]、加上 Shinko + AT&S）
  - Intel EMIB-T 推 ASIC、IBIDEN 在預付款合作名單
  - Intel Clearwater Forest 玻璃 core 雖由 [[欣興]] design partner、但商業化後 IBIDEN 仍會被列為合作夥伴
- 跟 [[Apple]] 路線：iPhone 18 / M5 mac 載板（旗艦消費級）+ Apple Baltra AI server chip
  - 但 Baltra 玻璃 substrate 由 [[Samsung Electro-Mechanics]] 搶下、IBIDEN 在玻璃 side 沒拿到
- 玻璃基板對應策略：**觀望 / 探索**
  - 2023-2027 CapEx 計畫明確列「glass core substrate」R&D
  - 但仍停在「exploration stage」、未 sample 通過 / 未量產時程
  - 跟 [[南電]] 同檔（兩家都「樣品有但落後」）、落後 [[欣興]]（Intel design partner）
  - 落後 [[Samsung Electro-Mechanics]]（Apple Baltra design-in）+ [[Absolics]]（AMD MI400 / Trainium）
- MLCC 嵌入式基板：5,000 億日圓擴產涵蓋這條路線（[[Samsung Electro-Mechanics]] 先發、IBIDEN 追擊）
- 護城河：
  - AI server ABF **唯一全製程內製能力 #1**（材料 + 製程 + 設備自有）
  - 大垣 / Gifu 在地化 + 日本政府背書（半導體戰略物資）
  - NVDA 綁定 = AI 算力時代基礎設施
- 風險：
  - 玻璃化路徑**沒拿到 design partner 位**（最大隱憂）
  - ASIC 玻璃化加速 → ABF TAM 被切（Tomahawk 8 / Apple Baltra）
  - 大野 / 河間擴產 5,000 億日圓 = 折舊壓力 2027-2030
- → 連 [[控制點轉移（投資版）]]：IBIDEN 拿到「AI ABF 載板絕對控制點」、但**玻璃下一階段控制點未拿**

## ⭐ 對台廠 ABF 三雄的意義

| 對台廠 | 直接影響 |
|---|---|
| [[欣興]]（3037） | **既競爭又互補**——Blackwell 載板 IBIDEN 75% vs 欣興 25% 分食；Intel EMIB 全球僅兩家有量級供應（IBIDEN + 欣興）；**玻璃 side 欣興反超**（Intel design partner）= 欣興用玻璃當「跳島戰術」反包 IBIDEN |
| [[南電]]（8046） | **平行 + 間接威脅**——南電強 ASIC（AVGO + AMD + Marvell 60% 營收）、IBIDEN 強 GPU + Intel；兩家**玻璃化進度相當「都樣品有但落後」** = 中期 displacement 雙雙曝險 |
| [[景碩]]（3189）| **間接受惠**——景碩中階 ABF + BT、IBIDEN/欣興產能爆滿 → 訂單外溢 → 景碩美系 AI CPU 供貨率 10%→50% + 打入 NVDA AI GPU 第三供應商（IBIDEN #1 + 欣興 #2 + 景碩 #3） |

**IBIDEN 動向是「先行指標」**（東京端 ABF / NVDA 鏈動向）：
- IBIDEN 擴產 5,000 億日圓 → 三雄共識「ABF 漲價週期確認」（2026-02 公告當天台股 ABF 三雄齊漲）
- IBIDEN 玻璃進度落後 → 三雄看到「玻璃化沒那麼快、ABF 至少還有 3-5 年大循環」
- IBIDEN 開始 allocate（限量）→ 景碩拿到外溢、欣興拿到 Blackwell 25%

**Bull case for 台廠**：
- IBIDEN 守舊不轉玻璃（目前實況）→ [[欣興]] 在玻璃 side 有機會 catch up + Intel design partner 位 = 玻璃化過渡期欣興是雙曲線受惠者
- IBIDEN 擴產確認 ABF 大循環、訂單外溢給 [[景碩]] = 景碩 risk-adjusted 最佳

**Bear case for 台廠**：
- IBIDEN 自己轉玻璃成功 → 鎖死 NVDA / Apple / Intel 鏈 → [[欣興]] 只剩 ABF 老本、[[南電]] 失去 ASIC 路徑
- IBIDEN 5,000 億 CapEx 倍增產能 → 2028 後 ABF 供過於求 → ABF 漲價週期提前結束、三雄毛利率回落
- IBIDEN 借日圓貶值 + 日本政府補貼補上玻璃缺口

## ⭐ 對台廠 TGV 設備廠的意義

對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]] / [[敘豐]]：

**Bull case**：
- IBIDEN 玻璃化進度**慢** → 玻璃化過渡期長 → TGV 設備廠（特別 [[鈦昇]] / [[雷科]]）有更長 ramp 窗口確立 IP 護城河
- IBIDEN 5,000 億擴 ABF 同時也在 R&D 玻璃 = 設備需求兩條軌道
- 大野廠 + 河間廠擴產 = 上游設備需求溢出（不只台 [[欣興]] / [[南電]]、IBIDEN 也買）
- [[敘豐]]（94% 銷貨集中欣興）→ IBIDEN 若擴 ABF → 欣興同步擴 → 敘豐受惠
- 玻璃化若由 [[欣興]] + [[Samsung Electro-Mechanics]] 主導、IBIDEN 後跟 → TGV 設備鏈台廠先吃

**Bear case**：
- IBIDEN 玻璃化突破 → 採購 [[LPKF]] / [[Disco Corp]] 設備（日德陣營）→ 台 TGV 設備廠被擋在 IBIDEN 鏈外
- IBIDEN 自做玻璃 → ABF 擴產減速 → 上游設備鏈兩頭受壓
- 大野 / 河間擴產若部分轉玻璃 → 高階 ABF TAM 縮、台設備廠 ABF 端需求縮
