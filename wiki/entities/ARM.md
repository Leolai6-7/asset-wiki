# ARM Holdings plc（NASDAQ: ARM）

## 1. 一句話定位

**全球 CPU 架構 IP #1（>99% 智慧手機 + 50%+ 資料中心 CPU 滲透加速 + 全 Edge AI 終端設備設計鏈共用基礎）+ Licensing + Royalty 雙引擎商業模式（前置授權費 + 出貨版稅年金）+ Compute Subsystem（CSS）新業務 platform 整合 + 軟銀 87% 控股 + 「賣水人之中的賣水人」第八位 anchor**——1990 創辦（Acorn Computers / Apple / VLSI 三方合資、英國劍橋）、目前全球所有先進 SoC（[[Apple]] A/M/U/R、[[NVDA]] Grace、AMD MI300、AWS Graviton 4 / Trainium 2、Qualcomm Snapdragon、Mediatek Dimensity、Samsung Exynos、Google TPU host CPU、Microsoft Cobalt 100 / Maia 100）全部用 ARM 架構；**雙身分定位**：(1) **IP licensing fabless company**（不自家造晶片、純授權 IP + service）+ (2) **CPU 架構標準制定者**（ARMv9 ISA + Neoverse 資料中心系列 + Cortex 端點系列 + Mali GPU IP + Ethos NPU IP）；**CPU 復興 KP41 anchor**：FY2026 全年資料中心版稅 YoY +100%+（KP41 揭露）= NVDA Grace + AMD MI300 host CPU + AWS Graviton 4 / Trainium 2 + Microsoft Cobalt 100 / Maia 100 全用 ARM 架構 → ARM 是「**所有 hyperscaler 自研 chip 都必經之路**」；**SoftBank 87% 持股**（孫正義「AI 帝國」核心資產、市值 +$220B 利潤）；2023-09 IPO @ $51（市值 $54B）→ 2026-05 突破 $300B（5.5x、SoftBank 帝國最大單一資產）；CEO Rene Haas 2022-02 接任、Q4 FY2026 營收首破 $1B → 全年 $4.92B（YoY +24%）；**「賣水人之中的賣水人」第八位 anchor**：跟 [[ASML]] 25 / [[Disco Corp]] 24 / [[村田 Murata]] 24 / [[信越化學]] 24 / [[SUMCO]] 24 / [[Synopsys]] 24 / [[Imec]] 24 並列頂級真賣水人池、ARM 24/25 補位「**IP 授權年金 + CPU 架構標準制定**」新類別 anchor。

## 2. 三層 thesis

### 產業層

- **CPU 架構 IP 賽道 [[市場四階段：懷疑／驗證／共識／反轉]]「共識 → 反轉」結構性穩定段**——ARM 在智慧手機 99%+ 滲透、目前無對手（x86 兩家 Intel + AMD 都退出移動、RISC-V 仍 niche < 5%）
  - 智慧手機 99%+ 滲透：[[Apple]] A 系列 + Qualcomm Snapdragon + Mediatek Dimensity + Samsung Exynos + Google Tensor 全用 ARMv9 ISA
  - 資料中心 CPU 賽道 [[市場四階段]]「驗證 → 共識」加速段：FY2026 資料中心版稅 YoY +100%+、滲透率 ~25% → 50%+ 趨勢（NVDA Grace + AMD MI300 + AWS Graviton 4 / Trainium 2 + Microsoft Cobalt 100 / Maia 100）
  - Edge AI 賽道 [[市場四階段]]「驗證」加速段：Cortex-A + Ethos NPU + Mali GPU 全棧 IP、ARM Intelligence 多模態 + 邊緣 LLM 部署典範
- **「賣水人之中的賣水人」第八位 anchor 賽道**：跟 [[ASML]] / [[Synopsys]] / [[Cadence]] / [[Imec]] 並列「不押任何商業路線、所有玩家都依賴」的架構級 chokepoint
  - **NVDA + AMD + AWS + Apple + Microsoft + Google + Meta + Qualcomm + Mediatek 全部依賴 ARM 架構**
  - 跟 [[ASML]] 是「製造設備 chokepoint」、[[Synopsys]] / [[Cadence]] 是「設計工具 chokepoint」對應、ARM 是「**架構 IP chokepoint**」
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（ARM 12M +50-100%、機構持股 + 媒體頭條飽和、Forward PE 190x stretched）
  - **2026-2030 NVDA Grace + AWS Trainium / Graviton + Microsoft Cobalt / Maia 量產 ramp 完整週期 anchor**
  - **CSS N3 / V3 新業務 2026-2027 全面 ramp**：next-gen Neoverse CSS 提供「reference IP block + verification 已驗證 + 客戶縮短設計週期 6-12 個月」、跟「**Compute Subsystem ARM 從架構 → 接近 silicon products**」戰略轉型
- vs RISC-V 競爭結構：
  - RISC-V = 開源 + 免授權費 + 中國 / 印度政府支持替代 anchor
  - **2026 滲透率 < 5%**（vs ARM > 99% 智慧手機 + > 50% 資料中心趨勢）
  - 短期不威脅 ARM、但 2030+ 長期看是「**結構性替代風險 anchor**」
  - [[華為]] / [[幻方量化]] / [[CXMT]] 中國閉環可能加速 RISC-V 滲透中國市場

### 目的層

- 業務組合（FY2026 ~$4.92B 全年營收）：
  - **Licensing 段（~$2.31B = 47% 營收、YoY +25%）**：前置授權費 = 客戶設計新 chip 時付給 ARM 一次性 + multi-year licensing fee
    - 主力 IP：ARMv9 ISA + Neoverse（資料中心）+ Cortex（端點 / 智慧手機）+ Mali GPU + Ethos NPU + DesignStart 中小客戶
    - **CSS（Compute Subsystem）= 新業務、~30% Licensing 段**：reference IP block + verification 完整、客戶 + Foundry 縮短設計週期 6-12 個月
  - **Royalty 段（~$2.61B = 53% 營收、YoY +21%）**：出貨版稅 = 客戶每出貨一顆 SoC 付 ARM 1-2% 售價
    - 智慧手機（~40% Royalty 段）：Apple + Qualcomm + Mediatek + Samsung + Google
    - 資料中心（~15% Royalty 段、YoY +100%+ 快速擴張）：NVDA Grace + AMD MI300 + AWS Graviton 4 / Trainium 2 + Microsoft Cobalt 100 / Maia 100
    - IoT + Edge AI（~25% Royalty 段）：汽車 + 工業 + 智慧家庭
    - Automotive（~15% Royalty 段、ramp 中）：[[Tesla]] AI4/AI5 + 中國 EV + 傳統汽車 ADAS / 自駕系統
    - PC + AI PC（~5%、ramp 中、KP45 補強）：[[Apple]] M-series + Qualcomm Snapdragon X Elite + NVDA RTX Spark N1/N1X
- 客戶結構（全球分散 + lock-in 結構性強）：
  - **[[Apple]] 占 18-22% Royalty 段**（智慧手機 + Mac M-series + Vision Pro 全棧 ARM）
  - **[[NVDA]] 占 16-18% Royalty 段**（Grace CPU + RTX Spark N1/N1X + Vera Rubin host CPU）
  - **Qualcomm + Mediatek 占 25-30% Royalty 段**（智慧手機 SoC）
  - **AWS 占 ~5-8% Royalty 段**（Graviton 4 + Trainium 2 自研 chip）
  - **Microsoft + Google + Meta + Samsung + 其他**：< 10%
  - **無單一客戶 > 25%**（vs [[Cerebras]] 客戶 OpenAI 81%、[[CoreWeave]] Microsoft 60%+ 結構性對沖）
- 商業模式 = **「IP Licensing + Royalty 年金 + CSS platform + ARM Foundation Models 四軸」**：
  - **IP Licensing**：前置授權費 + multi-year service contracts（年金結構）
  - **Royalty 年金**：每顆 SoC 出貨抽 1-2%、結構性復合（[[Disco Corp]] 耗材年金等效模式）
  - **CSS（Compute Subsystem）**：reference IP block + verification 已驗證、跟 [[Synopsys]] / [[Cadence]] EDA 雙頭整合
  - **ARM Foundation Models（陪 NVDA AI Foundation Models for Chip Design 跟進）**：Cerebrus / DSO.ai / Aprisa AI 同軌、ARM 也在跟進
- → 連 [[賣水人選股邏輯（投資版）]]：**ARM 是「賣水人之中的賣水人」第八位 anchor**——不押 NVDA / AMD / Apple / 任何商業路線、所有 fab/fabless/IDM/hyperscaler 自研 SoC 都依賴
- [[控制點轉移（投資版）]]：拿到「**CPU ISA 架構標準制定 + IP licensing chokepoint + Royalty 年金 + CSS platform 整合 + ARM Foundation Models AI for chip design**」五重 chokepoint
