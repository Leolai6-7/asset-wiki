# Amazon.com（NASDAQ: AMZN）

## 1. 一句話定位

**全球 #1 雲服務 AWS（$150B 年化、Q1 2026 +28% YoY）+ #1 電商零售（北美 + 國際合計 $588B）+ #1 hyperscaler 自研晶片廠（Trainium 2 / Inferentia 2 / Graviton 4、$20B 年化、三位數成長）+ Anthropic $25B 投資 / 5GW Trainium / $100B AWS commitment 戰略綁定 + RPO $364B 結構性 anchor + Prime Video + 1.6T 光模組首批採購者 + 三次資本支出循環當前進行中**——1994 創辦（Jeff Bezos、Seattle）、現 CEO Andy Jassy 2021-07 接任（ex-AWS CEO）、全球市值 ~$2.6-2.8T（Mega Cap top 5、僅次 NVDA / Microsoft / Apple / Alphabet 之一）；**雙身分定位**：(1) **AI infra hyperscaler CSP 三巨頭之一**（vs Microsoft Azure + Google Cloud）+ (2) **電商 + Logistics + Prime + Advertising 平台龍頭**（vs Walmart + Alibaba）+ (3) **AI 自研晶片廠**（Trainium 2 + Inferentia 2 + Graviton 4 + 自研 Nitro）；**M7 中「最便宜的 hyperscaler」**（Forward PE 30-35x vs Microsoft 30-35 / Google 22-26 / NVDA 35-45）；**Anthropic 戰略 anchor**（2026-04 expanded：$25B 投資 + 5GW Trainium 部署 + Anthropic $100B AWS commitment over 10 years）；**OpenAI 也加入 AWS**（2GW Trainium capacity 2027 ramp）= AWS 成「**Anthropic + OpenAI 雙模型公司同居**」hyperscaler 唯一；**hyperscaler 5 家完整 ingest 完成**：[[Microsoft]] / [[Google]] / Amazon AMZN / [[Meta]] / [[Oracle]] 五家全部 entity 建檔。

## 2. 三層 thesis

### 產業層

- **AWS 全球 #1 雲服務賽道 [[市場四階段：懷疑／驗證／共識／反轉]]「共識」階段、結構性復合**——AWS 2025 全年 $128.7B（+20% YoY）、Q1 2026 $37.6B（+28% YoY、reacceleration）、目前年化 $150B run rate
  - 跟 [[Microsoft]] Azure + [[Google]] Cloud 三家分食 hyperscaler 市場（vs Oracle / IBM / Alibaba / Tencent 第二梯隊）
  - **AWS RPO $364B**（Q1 2026 揭示）= 結構性 anchor、跟 Google RPO $462B 並列 hyperscaler top 2
  - **AWS YoY growth reaccelerated from 19% → 28%**：被認為是「**hyperscaler reacceleration anchor**」
- **電商零售賽道 [[市場四階段]]「共識 → 反轉」段**——北美 $426.3B（+10%）+ 國際 $161.9B（+13%）= 合計 $588B（FY2025）
  - 仍是全球 #1 電商、跟 Walmart + Alibaba 三足鼎立、中國市場面對 Pinduoduo / Temu 競爭
  - **Same-day delivery 擴張 + Prime $200B+ 廣告 + 邊緣物流自動化**結構性放大零售 unit economics
- **自研晶片 ramp 結構性受惠 AI 賽道**：[[市場四階段]]「驗證 → 共識」加速段
  - **Trainium 2 / Inferentia 2 / Graviton 4 / Nitro 自研全棧**：$20B 年化（YoY 三位數）+ 2.1M+ AI chips landed 過去 12 個月（half 是 Trainium）
  - **Anthropic 5GW Trainium 部署**（2026-04 announced、$25B 投資 + $100B AWS commitment over 10 years）
  - **OpenAI 2GW Trainium capacity**（2027 ramp 開始）= OpenAI 把雞蛋分散到 AWS（vs Microsoft Azure 主場）
  - = **AWS hyperscaler 唯一同時拿到 Anthropic + OpenAI 雙模型公司 anchor**

  - [[資訊擴散四階段]] 階段 3-4（AMZN 12 月漲幅 mid-double 20-50%、機構持股 + 媒體頭條飽和、vs NVDA 三位數差距、vs Google 12 月 +60-100%）

- vs [[Google]] / [[Microsoft]] / [[Meta]] 結構性差異（[[AI 變現能見度分歧（證明給我看階段）]] KP40）：
  - **AWS = AI infra hyperscaler 三軌之一**（vs Azure OpenAI + Google Gemini / TPU）
  - **AMZN = 中高正面評等**（RPO $364B + AWS +28% + 自研晶片 $20B 年化）
  - vs Google **最高大漲**（RPO $462B 超 AWS + Gemini 2,800 企業客戶）/ Microsoft 中溫和 / Meta **最低大跌**（元宇宙累積 $83B 虧損）/ Apple 有限平穩

### 目的層

- 業務 mix（FY2025 ~$700B 營收、FY2026 估 ~$750-800B、+13-15% YoY）：
  - **電商零售 = ~75% 營收**

    - **國際電商**：$161.9B FY2025（+13% YoY）、印度 + 巴西 + 歐洲擴張
  - **AWS 雲服務 = ~17-20% 營收**
    - **AWS 全年 $128.7B FY2025**（+20% YoY）→ Q1 2026 $37.6B（+28%、annualized $150B run rate）
    - AI infra primary anchor、Trainium 2 / Inferentia 2 / Graviton 4 自研全棧
  - **Advertising = ~9-10% 營收**
    - **零售廣告 + Prime Video + Twitch + 第三方廣告 platform**
    - YoY +20-25%、高毛利、結構性 ramp
  - **Prime + Subscription + 其他**：~5%
- 客戶結構（C-end + B2B 全球分散 + Anthropic / OpenAI 戰略 anchor）：
  - **電商**：~3-4 億全球 Prime 會員 + 北美 / 歐洲 / 印度 / 巴西 / 日本主力市場
  - **AWS**：F500 全部 AVL + 政府機構（CIA / DoD CIA cloud $10B+ 合約）+ AI 新創 / 模型公司
  - **戰略 AI anchor 客戶**：[[Anthropic]]（$25B 投資 + $100B AWS commitment over 10 years + 5GW Trainium）+ [[OpenAI]] 2GW Trainium 2027 ramp + Apple Trainium 2 採用（TechCrunch 報導）
  - **單一客戶占比極低**（vs 鴻海 Apple 30%+ 結構性風險、AMZN 對 C-end + B2B 全球分散）
- 商業模式 = **「電商 + 雲服務 + 自研晶片 + Logistics + Prime + 廣告 + 自有生態 platform」7 軸**：
  - **電商**：第三方賣家 platform + 自營商品 + Logistics 全棧 + Prime 訂閱
  - **AWS 雲服務**：EC2 + S3 + RDS + Lambda + Bedrock LLM + SageMaker + Trainium / Inferentia / Graviton 自研全棧
  - **自研晶片**：Trainium 2 + Inferentia 2 + Graviton 4 + Nitro DPU、全棧成本下降 + 跟 NVDA 議價權升
  - **Advertising**：零售廣告 + Prime Video + Twitch + 第三方 platform、毛利率 60%+
  - **Prime 訂閱**：~3-4 億會員 + Prime Video / Music / Reading / 其他、結構性年金
  - **Logistics**：全球 fulfillment center + 自有貨運 + Last-mile + Drone delivery + Same-day delivery
- → 連 [[賣水人選股邏輯（投資版）]]：**AMZN 是「hyperscaler 三巨頭之一 + AI infra 平台 + 自研晶片廠 三軸 anchor」**——不是純賣水人（屬「淘金者」），但 AWS = 賣水給所有 AI 玩家的 platform
- [[控制點轉移（投資版）]]：拿到「**AWS 雲服務 platform + 自研晶片 Trainium / Inferentia / Graviton + Anthropic / OpenAI 模型公司 source locking + Prime 訂閱 + Logistics + Advertising platform**」六重 chokepoint
