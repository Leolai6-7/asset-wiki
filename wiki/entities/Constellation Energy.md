# Constellation Energy（CEG）

## 1. 一句話定位

**全美核電 #1 + AI 算力電力 anchor 龍頭**——總部 Baltimore（Exelon 2022-02 拆分而來）、營運 **21 座核電機組** + 額外 32.4GW 核電容量；2024-09 跟 [[Microsoft]] 簽 **20 年 PPA、Three Mile Island Unit 1（已重命名 Crane Clean Energy Center / CCEC）復役** 賣 **835MW** 給 MSFT AI data center——是**首次美國退役核電廠為單一商業客戶復役**；2026-03 完成 **$16.4B 併購 Calpine（總 EV $26.6B）**補 26GW 氣電 firm power、整合後總容量 **>58GW（核電 + 氣電 + 地熱）**= 美國最大碳零電力 / 24/7 firm power IPP；過去 12 個月**累計拿 5,650+ MW hyperscaler PPA**（MSFT + [[Meta]]）+ **PJM submit 5,000MW 新容量**（核電 uprates + 氣電 + 儲能），Q1 2026 EPS $2.74 / 營收 **$11.12B（YoY 翻倍 / Calpine 整合貢獻）**，是 [[AI infra 電力戰場]] **三層分工中第一層「電力產生」的 #1 anchor**。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - 過去：核電是 stranded asset（被當包袱、Three Mile Island 1979 事故後社會反對）
  - **2024-09 起**：MSFT 簽 TMI PPA = **全社會 narrative 大反轉**——核電從包袱變 AI 必需資產
  - 12 個月內：CEG / VST / TLN 股價 **+200-400%** = **完整 re-rate**（但 backlog 仍 booking 到 2030+ = ramp 未完成）
- 美國 AI infra CapEx：四大 hyperscaler 2026 預估 **$710B**（vs 2025 $410B、YoY +73%）
  - 電力 anchor 占 CapEx **~12-15%**（電廠 + PPA + 電網）
- Hyperscaler 對 24/7 carbon-free baseload 需求暴增 = 核電 + 氣電 firm power 最終解
  - vs 太陽能（白天）+ 儲能（4-8 小時）= 無法滿足 1MW rack 24/7 拉滿
  - vs 風電（間歇性）= 容量係數 30-40%
- 對應 [[AI infra 電力戰場]]：**第一層電力產生 #1 anchor**（核電 + 氣電 firm 雙引擎）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]**三標準全滿**：供給結構改變 + 持續 CapEx + 20 年 PPA 鎖死現金流

### 目的層

- 業務 mix（2025 為主、2026 Calpine 併入後改變）：
  - **核電發電 ~70%**：21 機組 32.4 GW（美國最大）
  - **氣電 ~26%**：Calpine 整合後 26GW
  - **地熱 + 其他 ~4%**：The Geysers（California，全球最大地熱複合體）
- **AI / hyperscaler 直接 PPA 占未來營收占比**：
  - 2025：~5-10%（MSFT TMI 尚未上線）
  - 2028 上線後：**>25%**（TMI 835MW + Meta 1,121MW + 其他擴增 = 5,650MW 已簽）
- 客戶結構（hyperscaler PPA 明細）：
  - **[[Microsoft]]**：Three Mile Island Unit 1 復役 **20 年 PPA 835MW**（2024-09 簽、2028 上線、**首次** US 商業退役核電復役）
  - **[[Meta]]**：Clinton Power Station 20 年 PPA **1,121MW** + 30MW uprate（2025-06 簽、現有 PJM 核電廠長期延伸）
  - 其他簽約客戶（部分未公開）：合計累積 **5,650+ MW** hyperscaler PPA
  - 商業 / 工業 / 零售：Calpine retail business 帶入零售端客戶
- 商業模式核心：
  - **核電 + 氣電 雙引擎**（CEG 核電 baseload + Calpine 氣電 dispatchable）
  - **長期 PPA 鎖死現金流**（20 年合約 = DCF 折現率敏感度極低）
  - **零售 retail 端**（Calpine 整合後可走 retail electricity provider 模式 = grid-connected front-of-the-meter，類似 Talen-AWS 結構）
  - **CHIPS Act / IRA 補貼**：核電 PTC（Production Tax Credit）$15/MWh、Trump 政府 $1B 貸款支持 TMI 復役
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人**——**不押誰贏 AI**，所有 hyperscaler 都需要 24/7 carbon-free baseload
- 對應 [[控制點轉移（投資版）]]：拿到「**核電 baseline + Calpine 氣電 firm + retail 終端**」三段控制點 = 議價權結構性高於純發電 IPP

### 供應層

- 跟 [[Microsoft]] 路線：**2024-09 Three Mile Island 20 年 PPA 直接**
  - Unit 1 復役 → **2028 上線**（提前一年 vs 原計畫）
  - 2026-06-01 FERC 核准 **760MW Capacity Interconnection Rights 從 Eddystone 廠轉移到 Crane**
  - 2026 Q1 收 **Trump 政府 $1B 貸款**（covering majority of $1.6B 復役成本）
  - MSFT data center 跨 PJM Mid-Atlantic + Midwest 用電
- 跟 [[Meta]] 路線：**Clinton Power Station 20 年 PPA 1,121MW**（2025-06 簽）+ 30MW uprate
  - 跟 [[Vistra]] 的 Meta PPA 不同：CEG 是**現有核電廠延伸 PPA**、VST 是**多廠合計 2.6GW 含 uprate**
- 跟 [[Amazon]] / [[Google]] / [[OpenAI]]：未公開 PPA、但 PJM submit 5,000MW 新容量可後續配對
- 跟 [[Vistra]] 競爭：
  - **CEG**：核電 baseline 32.4GW > VST 6.4GW = **5x 規模優勢**
  - **CEG**：Calpine 氣電 26GW < VST 30GW+ + Cogentrix 5.5GW = 氣電稍輸
  - **CEG**：MSFT TMI PPA 是「核電復役 anchor 第一案」=**政治正確 + 媒體焦點頂峰**
  - **VST**：Cogentrix 收購跨 PJM / ISO-NE / ERCOT 三區域 = 地緣分散優勢
  - → **不是零和**：兩家共同擴大電力公司 re-rating narrative
- 跟 Talen Energy（TLN，⚠️ 待 ingest）對比：
  - **CEG**：32.4GW 核電 + 26GW 氣電 + 多 hyperscaler PPA = 規模龍頭
  - **TLN**：2.5GW Susquehanna 1 廠 + AWS $18B 17 年 PPA = **單一 PPA pure-play**
  - → CEG 是多角化 baseline、TLN 是高純度 alpha（也高波動）
- 跟 [[GE Vernova]] 補完關係：
  - CEG 是「**電力產生**」、GEV 是「**電力傳輸 / 變壓器**」= 同戰場不同層
  - CEG 核電 / 氣電擴建用 GEV 燃氣輪機（CEG 是 GEV gas turbine 重要客戶）
- 護城河：
  - **物理資產**：32.4GW 核電執照 + Calpine 26GW 氣電 = **複製不可能**（核電廠新建 8-12 年 + $5-10B/GW）
  - **20 年 PPA 鎖定**：MSFT + Meta 合計 ~2,000MW 已鎖、現金流可見度極高
  - **政治正確過濾**：碳零核電 + 氣電 firm = ESG 過關 + 拜登 / Trump 兩黨支持
  - **地理優勢**：PJM Interconnection 內最大核電 fleet = data center 集中區
  - **CHIPS Act / IRA PTC**：核電 $15/MWh 補貼至 2032
- 風險：
  - **Three Mile Island 復役延宕**：2028 H1 上線承諾、若延後 → MSFT 算力 ramp 延後 + CEG re-rate 部分回吐
  - **Calpine 整合風險**：$16.4B 併購剛完成（2026-01）、文化 + IT 整合 12-18 個月觀察期
  - **政治風險**：Trump 政府支持核電 = 政治紅利、但 2028 政權更替可能反轉
  - **CSP 自建電力**：MSFT + AMZN 都已開始自簽 PPA = 中長期可能繞過 IPP
  - **SMR 競爭**：2030+ small modular reactor 商業化 = 新建核電競爭威脅
  - **核電事故風險**：1979 TMI 事故後 NRC 法規極嚴、復役過程任何意外 = 政治海嘯
  - **PJM 容量市場改革**：FERC 法規調整可能影響 IPP 競價結構

| 維度 | 數值 / 邏輯 |
|---|---|
| 機櫃功率（GB200）| 132 kW |
| 機櫃功率（Rubin Ultra Kyber）| **600-1,000 kW（~1MW）** |
| 倍數 | **~5-8x 電力需求** |
| MSFT data center 配 Rubin 機櫃量（估算）| MSFT 2026-2030 CapEx ~$200B、若 30-40% 進 AI infra → ~$60-80B in racks + power |
| MSFT 從 TMI 取得電力（CEG 供應）| **835MW = ~835 個 1MW Rubin rack 同時跑滿**（單廠保守估算）|
| 全美 hyperscaler 新增電力需求 2026-2030 | 估算 **+50-80 GW**（CEG/VST/TLN 加總 PPA 已鎖 ~10GW）|
| CEG 新 PPA 潛力（PJM 5,000MW + uprate）| 對應 **~5,000 個 1MW Rubin rack 同時跑滿** |

> **重要警語**：MSFT TMI 835MW 對應「1MW rack」的數字是**單純物理上限對照**、實際 1MW rack 有 PUE 1.2-1.4 + 散熱開銷 → 實際 servable rack 數量 60-80% × 上限。但**方向上 CEG 是 Rubin 1MW 機櫃時代美國電力供給最大 anchor**。

## pair trade / 配置建議

### 多 CEG（不需 pair）

**論點**：CEG 是 AI 電力戰場 #1 anchor、22/25 高分、20 年 PPA 鎖死、Re-rate 3/4。

**配置**：核心持倉、5-10% 配置上限（單一 mega cap）。

### 配對思路（如要 pair）

**多 CEG / 空純太陽能 IPP（如 NextEra 部分）**：
- 多 firm power（核 + 氣）/ 空 intermittent renewable
- 但 NextEra 規模 + 護城河強、空單風險高、不建議

**多 CEG / 空純氣電 IPP（如 NRG）**：
- 多 baseload firm / 空 peaker
- 但 NRG 退休資產處置正向、空單時點不確定

→ **結論**：CEG 獨立做多倉、不需 pair；如要對沖系統性電力風險、可空 utility ETF（XLU）部分。
