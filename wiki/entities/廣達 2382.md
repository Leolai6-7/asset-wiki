# 廣達 2382（Quanta Computer）

## 1. 一句話定位

**全球 NB 代工龍頭 + AI server #2 代工（市佔 30-40%）+ Meta / AWS / Google / Apple Mac 主代工 + NVDA DGX 系列主代工**——1988 起源（林百里創辦、桃園龜山）、世界最大 NB 代工廠（市佔 ~25-30%）、市值 NT$1.0-1.2 兆；**從 NB 代工龍頭轉型 AI server #2 代工**：2023-2026 大舉重 pivot AI server、NVDA DGX H100 / H200 / B100 / B200 / GB200 NVL72 **次代工**（市佔 30-40%、僅次於鴻海 50-60%）、Meta + AWS + Google AI server 主代工、Apple Mac 主代工；vs 鴻海 三大差異：(1) **NB 為基底**（全球 NB 市佔 25-30%、HP / Dell / Lenovo / Apple Mac 主代工 = 規模穩定 + 高 NB 利潤率）、(2) **AI server 純度更高**（無 iPhone + 無電動車 + 無 AI edge = 純 server / NB / 雲端設備）、(3) **NVDA DGX 系列主代工 + 拿 Meta MTIA ASIC 部分代工**；**[[AI infra CapEx 三階段論]] 第三階段台灣鏈條 anchor 整合廠**——把 NVDA DGX + Meta / AWS / Google AI server 在台灣完成系統整合 + 量產 + 出貨；林百里董事長 80+ 歲、Tim Lin 林楊智接任副董，過渡期管理層穩定。

## 2. 三層 thesis

### 產業層

- AI server 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——廣達從 NB 代工龍頭轉型 AI server #2 代工
  - 主軸 AI server 代工市佔 30-40%（FY2025、業界估）、僅次於鴻海 50-60%
  - 客戶結構：NVDA DGX 系列 + Meta MTIA + AWS Trainium 部分 + Google TPU 部分 + Apple Mac
- vs 鴻海 / 緯創 / 智邦 結構性差異：
  - **規模**：廣達 NT$1.5 兆 < 鴻海 NT$6.86 兆、但 vs 緯創 / 智邦 規模高（廣達 = 鴻海 1/5 / 緯創 1.5 倍 / 智邦 30 倍）
  - **客戶結構**：Meta MTIA + AWS / Google 自家 ASIC 比例高、AI native 客戶（Anthropic / OpenAI 部分）也接
  - **業務 mix**：純 server + NB + 雲端設備、無 iPhone 拖累毛利、AI server 純度高於鴻海
- **「廣達 = AI server pure-play」結構性論點**：
  - 不做 iPhone（純 server + NB 純度）、毛利率高於鴻海
  - **NVDA DGX 系列主代工**：DGX H100 / H200 / B200 主要外包對象（包括 Lambda / Anthropic 等 cluster）
  - **Meta MTIA ASIC 主代工**：Meta 自家 AI accelerator 廣達主要代工 partner
  - **AWS Trainium / Google TPU 部分代工**：CSP 自家 ASIC 多 source 代工策略
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（廣達股價 12 月 +60-90%、機構持股 + 媒體頭條飽和）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1 + 6 + 7 層 NVDA stack 整合 anchor 之一
  - **2026 Q3** Rubin 平台首批出貨：廣達是 NVDA Rubin first wave 次代工（與 鴻海 並列）
- vs 緯創 3231 / 智邦 2345 差異：
  - **廣達 = AI server #2 代工 + NB 龍頭 + Meta / AWS / Google 客戶（規模 / 客戶分散勝緯創 / 智邦）**
  - **緯創 = AI server + GPU baseboard（Wiwynn 子公司主力 AI HPC、更 niche）**
  - **智邦 = AI networking switch（與廣達不直接競爭、不同層）**

### 目的層

- 業務 mix（FY2025 公司公告）：
  - **NB（筆電）= 55-60% 營收**
    - HP + Dell + Lenovo + Apple Mac 主代工
    - 大宗 NB 龍頭、毛利率 ~7-9%（比鴻海 EMS 5-7% 高 2-3pp）
    - **Apple Mac 主代工** = M-series Mac mini / iMac / Mac Studio / MacBook Pro 代工
  - **雲端伺服器 + AI server = 30-35%**（**FY2026 預估升至 35-40%**）
    - **NVDA DGX 系列主代工**（DGX H100 / H200 / B200）
    - **NVDA GB200 NVL72 次代工**（市佔 30-40%）
    - **Meta MTIA ASIC 主代工**
    - **AWS Trainium / Google TPU 部分代工**
    - Microsoft / Meta / AWS / Google 全棧 cloud server
  - **其他（含 IoT、家電、車用）= 10-15%**
- 客戶結構（高度分散）：
  - **Meta = #1 AI server 客戶**（MTIA + 自家 fleet 全套代工、~20%+ 營收貢獻）
  - **AWS + Google + Microsoft**：hyperscaler 全棧 + 自家 ASIC 部分
  - **NVDA = DGX + GB200 NVL72 partner**
  - **Apple = Mac 主代工**（M-series 全系列）
  - **HP + Dell + Lenovo**：NB 大宗代工
- 商業模式 = **「NB 規模 + AI server ODM 雙引擎」**：
  - **NB 規模**：HP / Dell / Lenovo / Apple Mac 主代工、毛利率 7-9%
  - **AI server ODM**：NVDA DGX + Meta MTIA + AWS / Google ASIC ODM 設計 + 代工、毛利率 8-12%
  - **AI server 毛利率拉升**：FY2024 整體 GM ~6.8% → FY2025 ~8.5% → FY2026 估 ~9-10%
- → 連 [[賣水人選股邏輯（投資版）]]：**「AI server pure-play 系統整合賣水人」**——不押 NVDA / AMD / Meta MTIA / AWS Trainium / Google TPU 誰贏、押所有 AI server 系統都需要的代工 + 整合
- [[控制點轉移（投資版）]]：拿到「**NVDA DGX 系列主代工 + Meta MTIA 主代工 + Apple Mac 主代工 + NB 全球 #1**」四重 anchor

### 供應層

- 跟 [[NVDA]] 關係：
  - **NVDA DGX 系列主代工**：DGX H100 / H200 / B200（Lambda / Anthropic / OpenAI 等 cluster 主要從廣達 ODM 出貨）
  - **GB200 NVL72 次代工**（市佔 30-40%、僅次於鴻海 50-60%）
  - **Rubin first wave 次代工**（與鴻海並列、2026 Q3）
- 跟 [[Meta]] 關係（**最大 AI server 客戶**）：
  - **Meta MTIA ASIC 主代工**：Meta 自家 AI accelerator
  - **Meta 自家 AI server fleet 主代工**：Meta 2026 CapEx $60-80B 中、AI server 部分主要從廣達出貨
  - **單一客戶 20%+ 營收貢獻**
- 跟 [[AMZN]] AWS 關係：
  - **Trainium 部分代工**（多 source）
  - AWS 自家 cloud server fleet 部分代工
- 跟 Google 關係：
  - **TPU 部分代工**（Google 主要 vendor 是 Broadcom + Marvell，廣達拿 server 整機代工部分）
- 跟 Apple 關係：
  - **Mac 主代工**（M-series 全系列、iMac + Mac Studio + Mac mini + MacBook Pro）
  - 不做 iPhone（鴻海主代工）= 廣達跟鴻海客戶分工互補
- 跟 鴻海 / 緯創 / 智邦 關係：
  - **競爭**：AI server 代工互相搶單（NVL72 主代工 = 鴻海 vs 廣達 + 緯創 分立）
  - **互補**：智邦 switch + 廣達 server 互補（部分 hyperscaler 訂單）
- 護城河：
  - **NB 全球 #1 + 25-30% 市佔 + HP / Dell / Lenovo / Apple Mac 主代工**
  - **NVDA DGX 系列主代工 + GB200 次代工 + Meta MTIA 主代工**
  - **AI server 毛利率高於鴻海**（pure-play 結構性）
- 風險：
  - **Meta 集中度 20%+ 營收**：若 Meta CapEx 大砍、整體營收衝擊
  - **NVDA Stack 採購 ramp 集中**：與鴻海並列、若 NVDA 賽道放緩 → 廣達連鎖
  - **NB 終端需求軟**：消費電子大盤、NB 滲透率成熟
  - **AI server 競爭加劇**：鴻海 + 緯創 + Inventec + Wistron 同期 ramp、定價壓力
  - **毛利率薄**：NB 7-9% + AI server ODM 8-12%、結構性低於 SaaS / IC 設計
  - **接班過渡**：林百里 80+ 歲、Tim Lin 副董接任、過渡期管理層
  - **股價 12 月 +60-90% 已 price in 多年 AI server 拉動**
- → 連 [[控制點轉移（投資版）]]：拿到「**NVDA DGX + Meta MTIA + Apple Mac + NB 全球 #1**」四重 anchor、但「Meta 集中 + NB 軟 + 競爭加劇」三重風險

## ⭐ vs 鴻海 / 緯創 / 智邦 三家代工龍頭 AI server 站別差異

詳見 [[鴻海 2317]] 內表格。**核心摘要**：

- **鴻海 = NVDA reference design 主代工（GB200 NVL72 市佔 50-60%、AI cloud 規模王）+ Apple iPhone 30%+ 營收**
- **廣達 = AI server #2 代工 + Meta / AWS / Google 客戶 + NB 龍頭 + Apple Mac 主代工**
- **緯創 = AI server + GPU baseboard（Wiwynn 子公司主力 AI HPC、更 niche）**
- **智邦 = AI networking switch（白牌交換器 + Spectrum-X 鏈條台廠對接）**

廣達 vs 鴻海 主要差異：**廣達 AI server 純度高（無 iPhone + 無 EV + 無 AI edge）**、毛利率略高、但規模和 anchor 客戶（Apple iPhone）不及鴻海。**廣達 vs 緯創**：廣達規模大 1.5x、客戶結構更分散（Meta + AWS + Google + Apple）。

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| 路線敏感 | **4** | 代工 NVDA + Meta MTIA + AWS Trainium + Google TPU = 多路線都代工、middleground 中性受惠 |
| 站別關鍵 | **3** | NVDA DGX 主代工 + GB200 次代工 + Meta MTIA 主代工 = 站別關鍵度中、但可被鴻海部分替代 |
| 耗材 | **2** | ODM 是「一次性」代工（每批訂單獨立）、不是耗材年金 |
| IP | **3** | NVDA DGX 整合 IP + Meta MTIA ODM 設計 IP + Apple M-series 整機 IP、但結構性 IP 不如 NVDA / Apple 自家 |
| 客戶分散 | **3** | Meta 20%+ + NVDA Stack 集中 + AWS + Google + Apple + HP + Dell + Lenovo = 客戶數多但 Top 2 集中 |

**總分：15/25**

→ **「AI server pure-play + NB 龍頭 + Meta 大客戶」**：廣達五軸 15/25 是台灣四家系統廠中第二高（vs 鴻海 16 / 緯創 14 / 智邦 18）。**主因**：AI server 純度高 + NB 規模穩 + Meta anchor、但**規模天花板**（vs 鴻海）+ **客戶集中度（Meta 20%+）** 兩個結構性弱點。
