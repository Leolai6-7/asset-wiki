# TSMC（台積電）

全球最大晶圓代工廠。在宋分框架中是 **「半導體基礎建設化」的範例**——從「低毛利代工」轉型為「高價值基礎設施」。

## 為什麼台積電在 wiki 是核心 entity

1. **[[HBM iPhone moment]] 的類比基礎**：HBM 之於記憶體 ≈ 台積電當年之於晶圓代工
2. **[[半導體基礎建設化]] 的活案例**：從訂單式 → 長期合作夥伴；CapEx 從擴產 → 基礎設施
3. **備忘錄 #6 財報季關鍵**：宋分明確點名觀察「**各終端配比**」（AI 是否填補消費電子/手機/汽車的空缺）

## 財報季觀察重點（備忘錄 #6）

宋分點名：

> 觀察的不是總營收，而是**各終端的配比**
> - AI 是否填補消費電子、手機、汽車的需求空缺

## 記憶體底部訊號的關聯

> **記憶體漲幅預估有一點點放緩 → 反而是消費電子的底**

而消費電子的底會反映到台積電的非 AI 終端營收。

- **AI 算力供應鏈**：所有 AI 晶片 [[NVDA]]、[[AVGO]] 都要過台積電

## ⭐ ASML 客戶關係（核心供應商 + 製程定義者）

[[ASML]] 是 TSMC 最大微影設備供應商、TSMC 是 ASML **最大客戶（~30% 營收）**：

- **N5 / N3 / N2 / A16 全用 EUV + High-NA EUV**：TSMC 先進製程節點完全依賴 ASML 機台
- **TSMC Investor Day 2024-2025**：公開 ASML 是 N2 + A16 ramp **唯一 critical path 供應商**
- **CoWoS-L + InFO + 後段封裝**：TSMC CoWoS 月產能 2024 末 35K → 2026 末目標 130K（3.7x）→ ASML 後段 lithography 連動成長
- **High-NA EUV 商業客戶**：TSMC 是 ASML High-NA EUV（0.55 NA、EXE:5000）首批 commercial 客戶之一（跟 Intel + Samsung 並列）
- **製程共定義**：TSMC + ASML + [[Imec]] 三方共同定義 2nm + 1.4nm + A16 物理製程可能性、不是「客戶 vs 供應商」、是「製程共建夥伴」
- 跟 [[半導體基礎建設化]]「五大 chokepoint」位置：TSMC（晶圓代工）+ ASML（微影設備）+ [[信越化學]] / [[SUMCO]]（矽晶圓）+ [[Disco Corp]]（切割）+ [[Synopsys]] / [[Cadence]] EDA = 五大 chokepoint 完整鏈條

## CoPoS（CoWoS 玻璃中介層版）

TSMC 的 panel-level 玻璃中介層路線、跟 [[Absolics]] / [[Samsung Electro-Mechanics]] 的 panel-level glass interposer 對撞、但**主要走自用 + 委外 [[Amkor]] / [[日月光 ASE]] 模式**。

### ✅ 玻璃基板催化

- 🆕 **2026-06-08 魏哲家校準（via [[Serenity]] X + TrendForce）**：CoPoS（CoWoS 封裝中介層替換玻璃中介層或有機材質為玻璃版本）**仍需 2-3 年量才放大**——跟市場預期相當接近；魏哲家 2026-06 股東會明確表態「先進封裝永遠是世界第一、CoPoS 試產線已建置」
- CoPoS pilot line 2026-06 啟動（設備供應商名單揭露 trigger，台廠 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]] 追蹤窗口）
- TSMC 台灣廠 CoWoS 玻璃載板與 [[Corning]] 直接合作（2026 公布、玻璃 sheet 供應端 anchor）

### ⚠️ 玻璃基板風險

- **量產時程「2-3 年」= 2028-2029**——晚 [[Absolics]] 2026 H2 約 2-3 年 + 晚 [[Samsung Electro-Mechanics]] 2027 H2 約 1-2 年
- TSMC 玻璃中介層走「**自用 + 委外**」模式 → 不直接搶 merchant 市場、但**對台廠 OSAT 委外鏈（[[Amkor]] 180-190k wafer / [[日月光 ASE]] 60-80k wafer）影響大**
- CoPoS pilot line 2026-06 設備供應商名單未公開 → 台廠 design-in 追蹤是 binary 訊號
