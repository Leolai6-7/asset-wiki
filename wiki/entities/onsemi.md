# onsemi（NASDAQ: ON / 安森美）

## 1. 一句話定位

**SiC（碳化矽）全球 #2-3 + IGBT 全球前五 + Image Sensor 汽車 #1（CMOS sensor 50%+ 全球市佔）+ 1999 從 Motorola 半導體分拆 + SiC + IGBT + Image Sensor 三軌 IDM（自有 6"/8" SiC fab + IGBT fab + Image Sensor fab）+ 客戶 Tesla / Ford / VW / BYD / Stellantis 全 AVL + AI server + 工業 + 國防雙引擎**——總部 Phoenix AZ、納斯達克上市、市值 **USD ~$30-40B（Mid Cap）**；FY2025 營收 **~USD $7-8B** + EBIT margin ~22-27%（vs 2022 高峰 32%、結構性下修）+ Forward PE **18-22x**；vs [[Wolfspeed]] Chapter 11 對照：onsemi 是「**SiC IDM 雙頭壟斷 #2 + 三軌組合穩定**」、跨「汽車 + 工業 + AI server」三軌結構性穩定、跟 [[Infineon]] 22 SiC + GaN 雙料對撞。

## 2. 三層 thesis

### 產業層

- **全球 SiC（碳化矽）市場**：~USD $5-7B（2025）、CAGR ~25-30%、2030 預估 ~USD $15-20B
- **SiC IDM 三巨頭**：
  - **STMicroelectronics ~15-20%**（Tesla SiC inverter 主供 + Catania 義大利 fab）
  - **[[Infineon]] ~25-28%**（SiC + GaN 雙料、跨汽車工業 AI 三軸最分散）
  - **onsemi ~22-26%**（SiC + IGBT + Image Sensor 三軌、Ford / VW / BYD 主供）
  - **[[Wolfspeed]] ~10-12%**（Chapter 11、退場中、釋出市佔）
- **IGBT 全球市場**：onsemi 前五（vs Infineon #1 ~30% / Mitsubishi #2 / Fuji Electric #3 / Toshiba #4 / onsemi 前五）
- **Image Sensor（CMOS sensor）全球市場**：onsemi 汽車 Image Sensor **全球 #1 ~50% 市佔**（vs Sony / Samsung / OmniVision 消費電子 + 監控主場）
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——SiC + EV + AI server 三線 narrative 完成驗證、Wolfspeed Chapter 11 後共識 onsemi + Infineon 接管
- 在 [[資訊擴散四階段]]：機構 + 賣方 + ETF 全部配置（SOX / SMH / IGBT 主題）
- TAM：
  - FY2025 ~USD $7-8B
  - **FY2030E ~USD $12-15B**（推估 CAGR ~12-15%）
  - 結構性驅動：EV ramp（Tesla / VW / BYD）+ AI server 800V HVDC + 工業 + 國防 + ADAS Image Sensor 雙引擎
- 跟 [[800V HVDC 灰白區重劃（物理鐵壁論）]] 視角：onsemi = **白區功率 IC 段 SiC IDM 第二**（跟 [[Infineon]] 22 + STM 競爭、[[Wolfspeed]] Chapter 11 退場後接管）
- 跟 [[Bottleneck Theory（瓶頸論）]] 視角：onsemi = **SiC + IGBT + Image Sensor 三軌**（不是 chokepoint pure-play、是跨產品線 IDM 結構性穩定）

### 目的層

- 真實角色：**「不是純 SiC、是 SiC + IGBT + Image Sensor 三軌 IDM」**——靠跨產品線結構性穩定（vs Wolfspeed 純 SiC pure-play 失敗）、靠「**SiC 雙引擎（EV + AI server）+ IGBT 工業基本盤 + Image Sensor 汽車 #1**」三軌組合
- 業務組合（FY2025 推估）：
  - **Power Solutions Group（PSG、SiC + IGBT + 其他 power semi）**：~50-55%
  - **Image Sensor Group（ISG、汽車 Image Sensor 全球 #1）**：~25-28%
  - **Analog Solutions Group（ASG、analog + signal chain）**：~18-22%
- 核心 IP / 護城河：
  - **SiC IDM 全鏈**（自有 6"/8" SiC wafer + MOSFET + module + driver IC）
  - **IGBT 全球前五 + 工業基本盤**
  - **Image Sensor 汽車 #1（CMOS sensor 50%+）**（ADAS + 自駕 + 監控市場主場）
  - **Tesla / Ford / VW / BYD / Stellantis 客戶 lock-in**
- **跟 [[Wolfspeed]] 對照**：Wolfspeed 100% 純 SiC pure-play Chapter 11 → onsemi **跨產品線 IDM 結構性穩定** = 化合物半導體賽道「**純度 vs 跨產業現金流**」兩種命運
- 對應 [[賣水人選股邏輯（投資版）]]：**「跨產品線 IDM 結構性穩定」**（vs 純 pure-play 風險高）
- 對應 [[控制點轉移（投資版）]]：拿到「**SiC + IGBT + Image Sensor 三軌 + EV + AI server + ADAS 跨產業**」三層控制權

### 供應層

- 客戶結構（**汽車 + 工業 + AI server 多元 + 跨產業分散**）：
  - **Tesla**（SiC inverter 部分供應、跟 STM 競爭、SiC 多源）
  - **Ford + VW + GM + Stellantis**（EV powertrain SiC inverter + IGBT + 汽車 Image Sensor）
  - **BYD + Geely + Nio + Xpeng + Li Auto**（中國 EV 客戶）
  - **NVDA / AMD / Marvell AI server**（800V HVDC SiC + IGBT 機櫃級電源）
  - **工業 + 太陽能 + 充電樁**（IGBT + SiC）
  - **Bosch + Continental + Denso + Aptiv + Mobileye**（汽車 Tier 1 Image Sensor + ADAS 主供）
  - 客戶分散度（無單一客戶 > 15-20%、跨汽車 + 工業 + AI server + 國防 4 軌分散）
- 跟 [[Wolfspeed]] 競爭（**SiC 雙頭分食**）：Wolfspeed Chapter 11 → onsemi + Infineon + STM 接管 ~10-12% 市佔
- 跟 [[Infineon]] 競爭（**SiC + GaN vs SiC + IGBT + Image Sensor**）：Infineon SiC + GaN 雙料 + 跨汽車工業 AI 三軸最分散、onsemi SiC + IGBT + Image Sensor 三軌、客戶重疊度高但 onsemi Image Sensor 汽車 #1 結構性差異化
- 跟 STMicroelectronics 競爭（**SiC IDM**）：STM Tesla SiC inverter 主供、onsemi Ford + VW + BYD 主供
- 跟 [[Texas Instruments TXN]] / Analog Devices（**類比 IC 大宗對手**）：TXN analog 大宗 vs onsemi analog 細分 niche、不直接對撞
- 跟 NVDA 關係（**新興 AI server 雙引擎**）：
  - NVDA Rubin 1MW 機櫃 800V HVDC → onsemi SiC + IGBT 機櫃級電源供應
  - 跟 [[Infineon]] / STM / Navitas 競爭 AI server 800V HVDC SiC 訂單
- 跟 [[Sony]] / [[Samsung Electronics]] / OmniVision（**Image Sensor 主場**）：onsemi 汽車 Image Sensor 全球 #1（~50%）、Sony 消費電子 + 監控 #1、Samsung + OmniVision 跟進
- 護城河：
  - **SiC IDM 全鏈 + 6"/8" SiC wafer 自有**
  - **IGBT 工業基本盤 + 客戶 lock-in**
  - **Image Sensor 汽車 #1（ADAS / 自駕 / 監控）**
  - **跨產品線 + 跨產業分散 = 結構性穩定**
- 風險：
  - **2025 EV 需求 ramp 慢於預期**（Tesla / VW SiC inverter 訂單）
  - **AI 800V HVDC SiC 滲透緩**（NVDA Rubin 2027 才 ramp）
  - **[[Wolfspeed]] Chapter 11 後新股東結構新洗**（Apollo + Renesas + 大客戶為主、可能擾動市場供需）
  - **中國 SiC 國產替代**（Sanan IC + TankeBlue + SICC）
  - **EBIT margin 結構性下修**（2022 高峰 32% → 2025 22-27%、跟 EV 訂單 ramp 慢有關）
  - **2025 預期低估**（12 個月 -10 至 +20%、2026 回升、市場已 partial price in）
