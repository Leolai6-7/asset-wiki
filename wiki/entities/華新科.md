# 華新科（2492.TW）

## 1. 一句話定位

**台廠 MLCC 二哥 + 大中華區 MLCC 第一 + 全球第四**（全球市佔 ~14%、僅次村田 / SEMCO / TDK）——**MLCC 占營收 46.4%（純度比國巨高 3 倍）**、AI 占整體 5-10%（AI 應用毛利率比公司平均高 10pp）、靠**中高壓 MLCC + LTCC + 安規電容**切入 AI 電源 + 車用利基；2026 起轉型「**AI + 車用雙引擎**」、產品線從消費電子轉向高毛利車規 / 工業 / AI 電源系統；在 [[MLCC 嵌入式基板賽道]] 跟 [[國巨]] 同病——**沒嵌入式產品線、沒載板廠盟友**、但「**規模較小 + 技術跟隨者 + 二供轉單受惠**」反而是純度更高的「**漲價週期 + 轉單**」beta 標的。

## 2. 三層 thesis

### 產業層

- **MLCC 產業**位在 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段（跟 [[國巨]] 共享產業層）
  - 2026 全球 MLCC 市場 USD 318 億、CAGR 15%
  - AI server MLCC 用量是傳統 16-24 倍（25k → 400k-600k 顆 / 機櫃）
  - 華新科總裁估「2025 → 2026 AI server 被動元件用量翻倍 / 2027 = 2025 的 4 倍」
- **中高壓 MLCC + LTCC + 安規電容**子賽道：
  - AI 伺服器電源系統用「高壓 MLCC（630V → 1,000V+）」= 高 ASP + 高毛利
  - 華新科目前主力 630V、研發 1,000V+ 跟上 AI HVDC 趨勢
  - 法人估「高壓 MLCC + 特殊電阻**放量 = ASP + 毛利率走揚**」
- **產業結構性缺貨**：2026 標準品供需平衡、車規 / AI / 高壓特殊品**結構性短缺** → 漲價週期分化
- 跟 [[ABF 載板 vs 玻璃基板 displacement]]：跟 [[國巨]] 一樣**間接受惠**（MLCC 採購量增）/ 不在 displacement 直接戰場
- 跟 [[MLCC 嵌入式基板賽道]]：**規模太小 + 技術跟隨者** = 連間接玩家都進不去
- 對 [[資訊擴散四階段]]：機構 → 賣方 → 媒體（已到媒體層、但跟國巨綁定討論、獨立 thesis 還在「賣方研究」段）

### 目的層

- 2026 Q1 產品 mix：
  - **MLCC = 46.4%**（YoY +4pp、純度提升中）
  - 晶片排容 / 晶片排組 / 射頻元件 / 安規電容 / 特殊電阻 ~54%
- 客戶結構：
  - AI 相關營收 **5-10%**（AI 客戶為 EMS 廠 + 電源供應器廠）
  - 車用：馬來西亞廠專攻車規電阻 + MLCC、3-5 個月訂單能見度、含主要車廠認證
  - 一般消費電子 / 工業電源 / 通訊裝置
- **AI 應用毛利率比公司平均高 10pp**（很重要的 mix 指標）
- 商業模式核心：「**台灣 R&D + 馬來西亞量產**」分散地緣風險（vs 中國風華 / 三環）
- 競爭定位：跟 [[國巨]] 比規模小 70%、但**MLCC 純度高 3 倍**（46.4% vs ~17.7%）→ 「**純 MLCC 漲價週期 beta**」標的
- 對應 [[賣水人選股邏輯（投資版）]]：是 AI 電源 + 車用電容次級供應商（**二供轉單受惠**）
- 對應 [[控制點轉移（投資版）]]：**沒拿到**任何結構性控制點（中高壓 MLCC 仍輸村田 / TDK 車規 + SEMCO 高階）

### 供應層

- 跟 [[NVDA]] 路線：透過 GB200 EMS 廠（緯創 / 廣達 / 鴻海等）供應 X6S MLCC + 中高壓 MLCC + 安規電容
- 跟 [[AVGO]] / [[AMD]] 路線：未公開直接客戶關係（透過代工廠 / 電源廠間接打入）
- 跟村田 / [[Samsung Electro-Mechanics]] / TDK：
  - 全球 MLCC 排名 **#4**（市佔 ~14%）
  - 高階 AI server MLCC 仍是村田 + SEMCO >80%
  - 車規 MLCC 村田 ~50% + TDK 35-40% 合計 ~85% → 華新科進入是「**份額外溢 / 二供轉單**」邏輯
- 中高壓 MLCC + LTCC：
  - 切入 AI 伺服器 + 車用供應鏈（自家發言：「**質變重生**」、潛在漲幅 15%）
  - 1 月營收創 45 個月新高
  - 法人估 EPS 從 4.74（2025）→ 5.5-7.5（2026）
- 嵌入式被動元件 / [[MLCC 嵌入式基板賽道]]：
  - **無公開 embedded MLCC 產品線**（同 [[國巨]]）
  - 規模太小（市值僅 NT$2,000 億 vs 國巨 NT$1 兆 vs SEMCO USD 920 億）→ 沒議價權跟載板廠合作
  - 嵌入式戰場「**完全缺席**」
- 護城河：
  - 大中華區 MLCC 第一（出貨量規模 + 中國本土供應鏈）
  - 馬來西亞廠（地緣分散 + 車規認證）
  - 高壓 MLCC + LTCC + 安規電容利基
- 風險：
  - 規模較 [[國巨]] 小 70% → 議價權 + R&D 投入弱
  - 高階 AI server MLCC 仍輸村田 + SEMCO
  - 中國風華 / 三環 / 微容**直接競爭低中階**
  - 銀 / 鈀 / 鎳原物料價格波動（Q1 法說警示 raw material spike）

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ⚠️ MLCC 純度高（46.4%）但 AI mix 仍低（5-10%）= 結構性弱於 [[國巨]] |
| 毛利率 | ⚠️ **18.3% 偏低**（vs 國巨 38.1%、村田 35%+）= 仍在中低階拉鋸 |
| OpEx | ✅ 馬來西亞廠擴產進入投產期、折舊已認列 |
| 營業利益 | ✅ Q1 EPS +40-69.7% YoY = 營業槓桿初啟動 |

→ **Re-rate 三角形 2/4 滿**——買的是「**MLCC 純度高 + 漲價週期 beta + AI mix 改善預期**」，但毛利率還沒回到歷史高峰（2018 漲價高峰毛利率曾 30%+）、PE 81 倍已 price in 多年漲價。

### ✅ 催化

- AI server MLCC 用量 2025-2026 翻倍 / 2027 = 2025 的 4 倍
- 中高壓 MLCC（630V → 1,000V+）切入 AI HVDC 電源系統
- 車用 MLCC + 馬來西亞廠車規認證放量
- 漲價週期延續（華新科總裁明示「raw material spike 將推漲價」）
- AI 應用毛利率 +10pp = mix 改善槓桿
- 法人 EPS 估從 5.5 上修到 7.5（+36%）
- **次級轉單受惠**：村田 + 國巨產能滿載 → 二供溢出 + 標準品轉到華新科

### ⚠️ 風險

- **PE 81 倍 + 毛利率僅 18.3%** = **估值 / 體質落差顯著**（如果是純漲價週期 beta、PE 應該 30-40 倍）
- AI 營收占比僅 5-10% = AI 故事 thin（需要 2026-2027 倍增驗證）
- 高階 AI server MLCC 規格仍輸村田 + SEMCO
- 嵌入式 MLCC 戰場**完全缺席**
- 中國風華 / 三環 / 微容**直接競爭低中階**（毛利率擠壓）
- 原物料（銀 / 鈀 / 鎳 / 鈦酸鋇粉）漲價未必能 100% 轉嫁
- 規模較 [[國巨]] 小 70% → R&D 跟不上高階 + 嵌入式 + 1,000V+ 高壓
- 散戶持股比例高 → 短線波動劇烈

## ⭐ MLCC 嵌入式戰場曝險評估

| 維度 | 評估 |
|---|---|
| 嵌入式產品線（自家 embedded MLCC）| ❌ **無**（規模太小無資源做） |
| 跟 ABF 載板廠合作度 | ❌ **無公開合作**（無欣興 / 南電 / 景碩共同 R&D） |
| AI server 客戶滲透 | ⚠️ **較弱**——透過 EMS / 電源廠間接、不直接綁 NVDA / AVGO |
| 對 SEMCO / 村田差距 | ❌ **巨大**——車規 + 高階 + 嵌入式三維度全面落後 |

→ MLCC 嵌入式曝險總體：**完全落後**（連間接玩家都不是、是「**MLCC 漲價週期 beta**」但**沒有結構性護城河**）

> **跟 [[國巨]] 的差異**：
> - [[國巨]]：MLCC 純度低（17.7%）但鉭電容 + 晶片電阻**全球壟斷** + Shibaura 感測 + 高階 X6S = **多軌全方位**
> - 華新科：MLCC 純度高（46.4%）但僅 **MLCC 一軌 + 中階為主** = **純漲價週期 beta + 次級轉單受惠**
>
> 因此華新科是「**MLCC 第三波超級週期 pure-play beta + 缺第四波嵌入式戰場 + Re-rate 三角形不完整**」的雙缺結構。
