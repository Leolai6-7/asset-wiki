# Google（Alphabet）

M7 之一。2026 處在**「搜尋廣告護城河 vs AI 廣告信任危機」雙頭壓力**下；**2026-05 FOMO SOC KP40 補位**——Q1 財報後成為「**AI 變現能見度最高**」的 hyperscaler、市場大漲。

## 雙頭壓力

### 1. 搜尋廣告護城河受侵蝕
- ChatGPT / Perplexity / Claude 拿走 query
- 但 Google **仍然是廣告分發龍頭**（Gemini 反擊 + AI Overviews）

### 2. AI 廣告信任危機（核心）
→ 完整見 [[AI 廣告信任危機]]

- 聊天廣告與搜尋廣告**不可分離**——同一公司既當答案提供者又當廣告主
- **20 年信任契約被 2 年打碎**
- 影響 Google + Meta + Amazon 三巨頭

## 估值定位

- **AI 廣告危機**：**最大個股風險 + 機會並存**
- 風險：搜尋 query 流失 → 廣告 inventory 下降
- 機會：Gemini + AI Overviews 抓住答案層 → 仍是廣告分發龍頭
- **AEO（Answer Engine Optimization）取代 SEO** 是 Google 的存亡題

## 雙重身份的張力

- **搜尋公司**（廣告 + 答案）
- **CSP 公司**（GCP，HBM/TPU 自研 + AVGO 合作）
- TPU 對 [[AVGO]] 是核心客戶——這條 supply 鏈和 search disruption 是 parallel 風險

- → 連 [[控制點轉移（投資版）]]：hyperscaler 把控制點上移到「晶片」
