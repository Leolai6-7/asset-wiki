# Navitas Semiconductor（NVTS）

## 1. 一句話定位

**全球唯一 GaN + SiC 雙路線 pure-play 功率半導體 + 全球第一家 10kW 98.5% 效率 800V HVDC GaN platform + NVDA 31 家共同制定者**——總部 Torrance California（2014 創立、2021 SPAC 上市）；單一產品線：**GaNFast（高頻 GaN power IC）+ GaNSense（保護整合）+ GeneSiC（SiC MOSFET 1200V-6500V）**；2025-05 跟 [[NVDA]] 共同推出 **10kW DC-DC platform 98.5% peak efficiency for 800VDC AI data center** = 全球第一個量產 GaN 800V HVDC 解決方案；**vs [[Wolfspeed]] 對照**：Wolfspeed 2025-06 Chapter 11、SiC 段已收縮 → NVTS 是「SiC + GaN 雙路線 pure-play 唯一仍 going concern」；2025-11 跟 [[GE Vernova]] / Eaton / Schneider 一起進 NVDA 31 家伙伴清單；FY 2026 Q1 營收 **~$22M**（YoY +24%）、毛利 **~30%**、仍虧損（FY 2025 Net Loss ~$80M、AI ramp 2026-2027 期）、現金 ~$140M、Cash burn 6-8 季可控；股價 12 個月 **+180-320%**（從 ~$1.6 → ~$5-7、高波動）；是 [[AI infra 電力戰場]] **第三層「電力分配」高 alpha pure-play**（vs ETN / SU 整合系統廠 / NVTS 純功率半導體）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - NVTS 是「800V HVDC GaN pure-play」唯一上市標的
  - vs Wolfspeed Chapter 11 後、SiC pure-play 機會也部分流向 NVTS
- 800V HVDC 標準化大轉場（NVDA 31 家伙伴體系）：
  - 過去 54V rack → 12V/6V 多階段 LDO（線性穩壓）+ buck converter
  - 800V HVDC → 一階段 800V → 12V/6V GaN bus converter（高效率 + 高功率密度）
  - **NVTS GaN 在「800V → 中間電壓 48V/12V」這段是唯一全 GaN 800V 量產商**
- 功率半導體競爭格局：
  - **大廠多軌**：STM / TI / Infineon / onsemi（都有 GaN + SiC + 矽 IGBT 多元）
  - **Pure-play 高 alpha**：NVTS（GaN + SiC 雙）/ Wolfspeed（SiC pure-play、已破產）
  - NVTS 是**唯一 SiC + GaN 雙路線 pure-play going concern**
- TAM 結構性增長：
  - GaN power IC 全球 2025 ~$2B、2030 預估 ~$10-15B（CAGR ~30-40%）
  - 800V HVDC 帶動高頻 GaN + 高壓 SiC 需求暴增
- 對應 [[AI infra 電力戰場]]：**第三層電力分配高 alpha pure-play**
- 對應 [[宋分 #20 — 能源結構性剛需]]**三標準全滿但客戶集中**：GaN 結構改變 + 持續 CapEx + 800V HVDC 鎖死

### 目的層

- 業務 mix（FY 2026）：
  - **AI / Data Center ~25-30%**（成長最快、800V HVDC 主力）
  - **EV / 汽車 ~35-40%**：GaN + SiC 在 EV 800V 充電 + on-board charger
  - **Solar / 工業 ~20-25%**：再生能源 inverter + 工業電源
  - **Consumer / 快充 ~10-15%**：GaN 快充充電器
- **AI / 800V HVDC 直接占比**：
  - 2025：~10-15%（10kW platform 剛起步）
  - 2028+：**>40-50%**（AI 1MW rack ramp 主動）
- 客戶結構：
  - **[[NVDA]] 800V HVDC AI factory**：跟 NVDA 共同開發 10kW platform、生態夥伴第一梯隊
  - **EV OEM**：BYD / 比亞迪 / Tesla / Hyundai / Lucid（GaN + SiC EV 充電 + on-board charger）
  - **太陽能 inverter**：Enphase / SolarEdge（部分）
  - **快充 OEM**：Anker / Belkin / Apple supplier
- 商業模式核心：
  - **GaNFast + GaNSense 整合方案**：GaN 高頻 + 控制 IC + 保護 整合 single chip
  - **GeneSiC SiC MOSFET 1200V-6500V**：跟 Wolfspeed / II-VI（Coherent）/ Infineon 競爭
  - **Pure-play 純度 + design-in 深**：跟 NVDA / 系統廠多年共同開發 = design-in moat
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人 + 高 alpha pure-play 版**——vs 大廠多軌（STM / TI / Infineon）、NVTS 是 pure-play 純度首選但客戶集中 + 規模小

- 跟 [[NVDA]] 路線：**2025-05 共同推出 10kW DC-DC platform 98.5% peak efficiency for 800VDC**
  - 全球第一個 GaN 800V HVDC 量產解決方案
  - NVDA AI factory 設計參考 architecture 之一
  - **vs STM / TI / Infineon**：他們是 GaN + SiC 大廠多軌、單一產品線深度遜於 NVTS
- 跟 hyperscaler 路線：透過系統廠（Eaton / Schneider / Vertiv）+ NVDA reference 間接
- 跟 [[Wolfspeed]] 對照：
  - **Wolfspeed**：SiC pure-play、2025-06 Chapter 11 / 重整（Wolfspeed Mohawk Valley 廠產能未滿、需求 EV 慢、AI ramp 來不及救）

  - → NVTS 是 SiC + GaN 雙路線 pure-play 唯一 going concern
- 跟 [[Infineon]] 競爭 / 補完：
  - **IFX**：SiC + GaN + IGBT + 矽 MOSFET 多軌大廠（年營收 ~€15B、市值 ~€60B）
  - **NVTS**：GaN + SiC pure-play（年營收 ~$80M、市值 ~$1.2B）
  - **IFX**：規模 + 客戶分散 + 多元路線勝
  - **NVTS**：GaN 純度 + AI 800V HVDC 純度勝
  - → IFX 是 baseline 大廠、NVTS 是 alpha pure-play
- 跟 [[STMicroelectronics]] / [[Texas Instruments TXN]] / [[onsemi]] 競爭：
  - **STM**：GaN 強 + 跟 NVDA 共同開發 800V → 12V/6V GaN power module（NVDA 31 家伙伴）
  - **TI**：跟 NVDA 共同 800V → 6V GaN bus converter 97.6% efficiency（NVDA 31 家伙伴）
  - **onsemi**：SiC + GaN 多軌（vs Wolfspeed 重整收購談判）
  - → 大廠多軌 + 規模優勢 + 多客戶分散勝、NVTS 在「Pure-play + design-in 純度」勝
- 跟 [[Eaton]] / [[Schneider Electric]] / [[ABB]] 路線：
  - 系統廠在 800V HVDC architecture 用 NVTS 10kW platform 作為 IC 解決方案之一
  - vs STM / TI / Infineon GaN / SiC IC 多選
  - → NVTS 是 GaN 800V 純度首選
- 護城河：
  - **GaN 800V HVDC first-mover**：全球第一個 10kW 98.5% 效率量產 platform
  - **NVDA design-in**：跟 NVDA 多年共同開發 = 切換成本極高
  - **GaNFast + GaNSense 整合 IC**：減少 BOM 數量 + 提升效率
  - **GeneSiC SiC MOSFET 1200V-6500V**：跟 Wolfspeed Chapter 11 後分到的市場機會
- 風險：
  - **規模小 + 現金 burn**：FY 2025 Net Loss ~$80M、現金 ~$140M、Cash burn 6-8 季
  - **客戶集中**：NVDA + 少數 EV OEM = 客戶集中度高、單一客戶風險
  - **大廠多軌進攻**：STM / TI / Infineon 加碼 GaN 800V → NVTS 純度優勢被稀釋
  - **EV demand 慢**：BYD / Tesla EV 銷售放緩 → 35-40% 營收受壓
  - **Wolfspeed 重整出售風險**：onsemi / Infineon 收購 Wolfspeed → NVTS SiC 段競爭加碼
  - **PE / EV 倍數高**：仍虧損、EV / Sales ~15-20x 高估值
  - **2021 SPAC 上市後波動極大**：股價 12 個月 +180-320%、6 個月波動幅度 ~50%+

### 多 NVTS（高 alpha pure-play option）

- 系統廠 baseline + NVTS option = balanced 曝險

**多 NVTS / 空 Wolfspeed（如未重整完成）**：
- pure-play GaN going concern / 純 SiC Chapter 11
- 結構性勝負明確（但 Wolfspeed 已破產、空單已有限）

- NVTS GaN 純度 / IFX 多軌規模
- 但 IFX 護城河強、空單風險

→ **結論**：NVTS 是高 alpha 衛星倉、不適合 core 配置；如要對沖、可加 Infineon / STM / TI 形成「GaN + SiC pure-play vs 多軌大廠」對沖組合。
