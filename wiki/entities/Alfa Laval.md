# Alfa Laval（STO: ALFA）

## 1. 一句話定位

**全球板式熱交換器（BPHE）規模龍頭 + 全球 BPHE >15% 市佔（vs [[高力 8996|高力]] 5.1% 全球前五大 30x 規模）+ 跨產業多元組合王（HVAC + 食品 + 製藥 + 海運 + AI 資料中心 + 能源）+ Energy / Food & Water / Marine 三大事業群 + 130 年瑞典老牌工業 conglomerate**——總部 Lund 瑞典、創立 1883、Stockholm 主板上市；事業群：**Energy（能源、~38%、含 HVAC + 製冷 + AI 資料中心 + 油氣 + 核電冷卻）+ Food & Water（食品水處理、~37%、含乳品 + 啤酒 + 飲料 + 廢水）+ Marine（海運、~25%、含船用熱交換 + 推進 + 排氣）**；核心產品：**板式熱交換器（PHE）**（gasket plate + 真空硬銲 BPHE + 焊接 plate）+ 離心分離機 + 流體處理；2026 全年營收推測 **SEK 600-700 億**（USD ~60-70 億、30x 高力規模）、毛利率 30-35%、Forward PE 25-30x；**AI 資料中心 BPHE 佔比 <5%**（vs 高力 AI 液冷 ~20%）= **「**規模碾壓但 AI 純度低**」**——跟 [[高力 8996|高力]] niche specialist 形成「**規模王 vs niche 純度**」分歧路線；[[AI infra 散熱戰場]] **規模對照組 anchor**（非高 alpha 玩家、但是全球 BPHE 龍頭背景驗證高力 niche 定位）。

## 2. 三層 thesis

### 產業層

- AI infra 散熱 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段、Alfa Laval 是「**全球 BPHE 龍頭背景驗證 + AI 資料中心 niche specialist 從 industrial 切入**」
  - 過去 130 年：HVAC + 食品 + 製藥 industrial heat exchanger 全球龍頭
  - 2024-2026：AI 資料中心 BPHE 需求暴增 → Alfa Laval 從「industrial 多元化」切入「AI 液冷 niche」
  - 跟 [[高力 8996|高力]] niche specialist 差別：Alfa Laval 是「**industrial 主場 + AI niche 第三或第四曲線**」、不是純 AI 受惠
- 全球 BPHE 市場格局（2026 推測）：
  - **Alfa Laval >15%**（全球 #1、industrial 主力）
  - **SWEP（Danfoss 子公司）+ Kelvion（德國）+ API Heat Transfer（美國）**：三家並列前 5（合計 ~30%）
  - **高力 5.1%**（全球前五大、台灣 9 成市佔）
  - **其他中國 + 韓國廠商**：~50%（碎片化）
- BPHE 市場 TAM：~$50-70 億 USD（2026 推測）、AI 液冷 BPHE 子市場 ~$5-10 億 USD（推估 10-15%）
- 對應 [[AI infra 散熱戰場]]：**規模對照組 anchor**（非高 alpha 玩家、跟高力 niche specialist 形成對比）
- 對應 [[控制點轉移（投資版）]]：Alfa Laval 拿到「**全球 BPHE 龍頭 + 130 年 IP 累積 + 跨產業 platform**」三段控制點 = 比高力規模大、但**AI 純度低**

### 目的層

- **業務組合**（2025 → 2026 推估）：
  - **Energy（能源）**：~38%（HVAC + 製冷 + AI 資料中心 + 油氣 + 核電冷卻）⭐ AI 液冷在此段
  - **Food & Water（食品水處理）**：~37%（乳品 + 啤酒 + 飲料 + 廢水）
  - **Marine（海運）**：~25%（船用熱交換 + 推進 + 排氣）
- **核心產品**：
  - **Gasket Plate Heat Exchanger（GPHE）**：可拆解 + 維修方便、industrial 主場
  - **Brazed Plate Heat Exchanger（BPHE）**：真空硬銲 + 密封 + 高壓、CDU + HVAC + 食品主場
  - **Fusion Bonded Heat Exchanger（融合鍵合）**：純不鏽鋼 + 更耐腐蝕、製藥 + 半導體
  - **離心分離機 + 流體處理 + 加熱系統**：跨產業
- **AI 資料中心 BPHE niche**（2024-2026 切入）：
  - 全球 CDU 廠採購對象（[[Vertiv]] / Schneider Electric / [[Eaton]]-Boyd / CoolIT 都採購 Alfa Laval / 高力 / SWEP / Kelvion 雙頭多頭）
  - 規格：**plate 厚度 0.4-0.6mm + 焊接溫度 1,100°C + 不鏽鋼 316L + 高壓 32 bar**
  - 佔 Energy 段營收 <10%（推測 USD ~3-5 億 / 全年）= 佔 Alfa Laval 全集團 <5%
- **客戶結構**：
  - **HVAC OEM**：Carrier、Trane、Daikin、Johnson Controls（最大客戶段）
  - **食品 OEM**：Tetra Pak（Alfa Laval 姊妹公司、創辦人共同 root）+ GEA + SPX
  - **海運 OEM**：MAN + Wärtsilä + 三大日本船廠
  - **AI 資料中心 CDU 廠**（新增）：Vertiv / Schneider / Eaton-Boyd / CoolIT / 雙鴻 / 奇鋐 / 台達 / 高力**對手**雙頭採購（推測）
- **2026 全年指引**：Alfa Laval 沒有公開 AI 資料中心專屬 guidance、整集團營收成長 ~5-10% YoY（推測）
- 商業模式核心：
  - **「**130 年 BPHE 規模龍頭 + 跨產業 platform + 全球 OEM 通路 + industrial recurring 維護**」**
  - **規模 + 通路**：全球 100+ 國銷售網 + 50+ 製造廠
  - **跨產業對沖**：HVAC + 食品 + 海運 + AI 多軌、單一賽道風險低
  - **R&D 持續**：每年 ~3-4% 營收 R&D、BPHE 設計 + 真空硬銲製程持續優化
- 對應 [[賣水人選股邏輯（投資版）]]：**多元 industrial 賣水人**（不押 AI 誰贏、不押 HVAC 誰贏、押**全球熱處理需求結構性放量**）
- 對應 [[控制點轉移（投資版）]]：跨產業 platform = 控制權分散在多個產業

### 供應層

- 跟 [[NVDA]] 路線：**間接綁定**（不直接賣給 NVDA、賣給 NVDA 客戶 CDU 廠 → 餵 hyperscaler）
- 跟 [[高力 8996|高力]] 關係（**規模王 vs niche 純度分歧路線**）：
  - **Alfa Laval >15% 全球市佔** vs **高力 5.1% 全球前五大**（規模差 3x）
  - **Alfa Laval ~SEK 600-700 億營收** vs **高力 NT$60-100 億 USD$2-3.5 億**（規模差 30x）
  - **Alfa Laval industrial 多元主場、AI 純度低** vs **高力 AI 液冷 + SOFC 雙引擎純度高**
  - → 「**規模 + 工業多元 + 通路 + 估值 conservative**」vs「**AI niche + 雙引擎 + alpha 速度**」分歧
  - **競爭 + 互補並存**：Alfa Laval / 高力同為 CDU 廠採購對象、Vertiv 等可能雙頭採購
- 跟 SWEP（Danfoss 子公司）對比：
  - SWEP 規模略小於 Alfa Laval、Danfoss 集團 industrial automation + power electronics + HVAC 三軌
  - SWEP 強在 industrial cooling、Alfa Laval 強在跨產業多元 + 海運 + 食品獨家
- 跟 Kelvion（德國）對比：
  - Kelvion industrial 主力（油氣 + 化工 + 電力）、AI niche 弱
  - Alfa Laval 跨產業多元勝
- 跟 API Heat Transfer（美國）對比：
  - API industrial 主力、規模小於 Alfa Laval
  - Alfa Laval 全球 + 規模 + 通路勝
- 跟 [[Vertiv]] / Schneider / [[Eaton]] / CoolIT 關係：
  - Alfa Laval 是這些 CDU 廠 BPHE **採購對象之一**（跟高力雙頭採購）
  - Vertiv 採購 Alfa Laval / 高力 / SWEP **三頭分散**（推測）
  - Schneider / Eaton-Boyd 採購 Alfa Laval / Kelvion **歐洲偏好**
  - CoolIT 採購 Alfa Laval / API（北美偏好）
- 跟 [[Eaton]]-Boyd 關係（**新興競爭**）：
  - Boyd 被 Eaton 2026-03 併購後、Eaton-Boyd 自製 cold plate / manifold / CDU
  - Eaton-Boyd 仍採購 Alfa Laval / 高力 BPHE（不自製 BPHE）
- 護城河：
  - **130 年 BPHE 規模龍頭**（全球 #1 市佔）
  - **跨產業 platform**（HVAC + 食品 + 海運 + AI）
  - **全球 OEM 通路**（100+ 國、50+ 製造廠）
  - **R&D 持續**（每年 ~3-4% 營收）
  - **industrial recurring 維護**（gasket 更換 + spare parts）
- 風險：
  - **AI 純度低 < 5%**：vs 高力 ~20%、Alfa Laval AI 受惠不夠純
  - **industrial 景氣循環**：HVAC + 海運 + 食品都跟景氣相關
  - **歐洲基地**：歐元匯率波動 + 歐洲產業 destock 影響
  - **新興市場威脅**：中國 + 韓國 BPHE 廠商價格戰
  - **AI niche 切入慢於高力**：高力先發、Alfa Laval 後進、可能被高力分食 AI niche
  - **燃料電池 SOFC niche 缺位**：vs 高力 Bloom Energy hot box 主供、Alfa Laval 沒有 SOFC 第二曲線
  - **估值合理**：Forward PE 25-30x、無 AI 暴衝 alpha

**配置**：核心持倉、3-5% 配置（穩定 industrial anchor）。

### 配對思路

**多 Alfa Laval / 多 [[高力 8996|高力]]（規模 + niche 互補）**：
- Alfa Laval 規模 + 多元 + 估值合理
- 高力 AI niche + 雙引擎 + alpha 速度
- → 跨「**規模 conservative + alpha pure-play**」籃子

**多 Alfa Laval / 空 SWEP（Danfoss）**：
- Alfa Laval 規模 + 多元 + 通路勝
- SWEP industrial niche + Danfoss 工業整合
- → 結構性勝負中等

**多 Alfa Laval / 多 [[Vertiv]]（BPHE 供應 + CDU 整合 turnkey）**：
- Vertiv 採購 Alfa Laval BPHE
- 兩家上下游配對
- → Vertiv alpha 速度 + Alfa Laval 規模穩定

→ **結論**：Alfa Laval 是 conservative anchor、適合做「**規模 + industrial + 估值合理**」配置。比高力規模大 30x、AI 純度低 4x、適合不想暴衝風險的投資人。
