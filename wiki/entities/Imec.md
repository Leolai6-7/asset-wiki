# Imec（比利時 Interuniversity Microelectronics Centre）

## 1. 一句話定位

**全球頂尖半導體 R&D 公共財 + 比利時 Leuven 總部 + 1984 年成立 + 非營利 R&D consortium + 不上市 + 預算 ~€870M/年 + 員工 5,000+ 人 + 200+ 全球合作會員（[[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[ASML]] / [[GlobalFoundries]] / NXP / [[Infineon]] / [[Texas Instruments TXN]] / Bosch 等都是會員）+ 全球唯一規模化「**前競爭性 pre-competitive R&D + 共用 EUV pilot fab + 全產業中立平台**」+ 在 SiPho / 2nm / GAA FET / EUV / High-NA EUV / 量子 / 神經形態運算等多軸 R&D 領先**——非上市、不商業化、純 R&D + 授權 + 共用 pilot fab；跟 [[Tower Semiconductor]] / [[GlobalFoundries]] / [[TSMC]] CoWoS 並列「**SiPho foundry 全球 4 強分食**」（但 Imec 是 R&D 端、不是商業 foundry）；在 [[賣水人選股邏輯（投資版）]] 是「**上游 R&D 公共財賣水人（不可投資但結構性影響全產業）**」、在 [[Bottleneck Theory（瓶頸論）]] 是「**七層之外的第 0+ 層 R&D 預競爭 anchor**」（任何 fab 任何技術都要透過 Imec R&D 預備）。

## 2. 三層 thesis

### 產業層

- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——
  - 驗證已完成：1984 年成立、過去 40 年是 EUV / 300mm wafer / FinFET / GAA FET / SiPho 等多軸 R&D 主導者
  - 共識：全球半導體業界共識「Imec 是 R&D 公共財」、會員越來越多（200+）
- 在 [[資訊擴散四階段]]：機構長期覆蓋、媒體層深度報導、AI 散戶層級認知度低（因為非上市）
- TAM：⚠️ **不適用**——Imec 不商業化、非營利、預算來自比利時政府 + EU + 200+ 會員會費 + 部分項目資助
- [[Bottleneck Theory（瓶頸論）]] 視角：Imec = **七層之外的「R&D 預備層」**（不是 chokepoint、但是任何 chokepoint 突破前的 pre-competitive R&D 平台）
- 跟 [[半導體基礎建設化]] 視角：Imec 是「**全球半導體 R&D 公共基礎建設**」、跟政府 + EU + 200+ 會員共建
- 跟 [[控制點轉移（投資版）]] 視角：Imec 不拿控制權、但**結構性影響全產業技術路線**（A 路線會贏？看 Imec 怎麼選；B 路線後續？看 Imec 怎麼授權）

### 目的層

- 真實角色：**「全球半導體 R&D 公共平台 + pre-competitive R&D + 不商業化 + 共用 pilot fab + 200+ 會員中立性 anchor」**——不是「跟 fab 競爭」（vs TSMC / Samsung / Intel）、不是「跟 ASML 競爭」（vs ASML 設備 supplier）、是「**所有 fab / 設備 / 材料廠商共用的 pre-competitive R&D 平台**」、靠「**非營利地位 + 比利時政府 anchor + EU 資助 + 200+ 會員會費 + 共用 EUV pilot fab + 授權 IP**」維持中立性
- 業務組合（FY2024）：
  - **R&D 項目（2nm / GAA / High-NA EUV / SiPho）**：~70% 預算
  - **共用 pilot fab 收費（會員使用 + 服務）**：~20% 預算
  - **教育 + 培訓 + 研究合作**：~10% 預算
- 核心商業模式：
  - **會員制 R&D consortium**（200+ 會員、會費 + 項目分攤）
  - **共用 EUV / High-NA EUV pilot fab**（會員可以共用做 pilot 製程 + 學 know-how）
  - **IP 授權 + 技術轉移**（成熟技術授權給商業 fab）
  - **政府 + EU anchor**（比利時政府 + EU Horizon 2020/Europe 資助、預算穩定）
- 核心 IP / 護城河：
  - **全球唯一規模化 pre-competitive R&D 平台**
  - **共用 EUV / High-NA EUV pilot fab**（vs 商業 fab 不開放）
  - **200+ 會員中立性**（任何商業 fab 都不能拒絕跟 Imec 合作）
  - **40 年 R&D 累積 know-how**（EUV / 300mm / FinFET / GAA / SiPho / 量子）
- 對應 [[賣水人選股邏輯（投資版）]]：**「上游 R&D 公共財賣水人（不可投資但結構性影響全產業）」**——⚠️ **不可投資**（非上市、不商業化）、但 R&D 路線預定影響所有商業 fab + 設備 + 材料廠
- 對應 [[控制點轉移（投資版）]]：Imec 不拿控制權、但**結構性影響全產業技術路線**（R&D 預備層 chokepoint）
- 對應 [[半導體基礎建設化]]：Imec = 全球半導體 R&D 公共基礎建設

### 供應層

- 跟 [[ASML]] 關係（**最重要合作 + 互鎖 anchor**）：
  - **ASML High-NA EUV 首台 0.55 NA pilot 機在 Imec**（2023 H2 安裝、EXE:5000 系列、共用 ramp）= 全球第一台 commercial-ramp 預備機台
  - ASML 跟 Imec 是長期 strategic partner（2018-2026 累計 5+ 年 High-NA EUV / EUV 全套 R&D）
  - **2026-2027 High-NA EUV 商業 ramp 前的 5 年 R&D 全部在 Imec**（Intel 18A + TSMC N2 + Samsung 2nm 商業 ramp 都是 Imec pilot 預備後接續）
  - **互鎖意義**：Imec 24/25 ⚠️ 特殊評估（R&D 公共財）+ [[ASML]] 25/25（製造設備）= 「**設計 → R&D → 製造**」鏈條最終極兩層 anchor 互鎖
  - 在 [[Bottleneck Theory（瓶頸論）]] 框架：**ASML 層 -1（微影設備）+ Imec 層 0+（R&D 預備）**「上游兩層 anchor」共軛壟斷
- 跟 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[GlobalFoundries]] 關係：
  - 四家都是 Imec 主要會員、合作 2nm / GAA / High-NA EUV / SiPho 等
  - TSMC 2nm + Samsung 2nm + Intel 18A + GlobalFoundries SiPho 全部受惠 Imec R&D
- 跟 [[Tower Semiconductor]] / [[GlobalFoundries]] 對比（SiPho foundry）：
  - Imec = SiPho R&D 領先、但**不商業化**（純 R&D + 授權）
  - Tower / GFS = 商業 foundry、拿 Imec 部分 SiPho IP 商業化
  - **Imec SiPho R&D + Tower / GFS 商業 foundry 形成「R&D → 商業化」生態鏈**
- 跟 [[NVDA]] / hyperscaler 關係：
  - **NVDA 是 Imec 會員**（部分公開、推測為 high-tier member）
  - NVDA Rubin / Vera / Blackwell 製程 R&D 路線受惠 Imec pre-competitive R&D
- 跟 [[Lumentum]] / [[Coherent]] 關係：
  - SiPho R&D 跟 LITE / COHR 自家 InP fab 是不同層次（Imec 純 R&D / LITE / COHR 商業 InP fab）
- 跟 [[信越化學]] / [[SUMCO]] 關係：
  - 信越 / SUMCO 矽晶圓給 Imec pilot fab 用、Imec 是材料商重要 R&D 客戶
- 跟 [[Bottleneck Theory（瓶頸論）]] 七層位置：
  - **七層之外的「層 0+」**：R&D 預備層、不是商業 chokepoint
  - 但**所有 chokepoint 突破前都要經過 Imec R&D**（EUV / SiPho / 2nm 都是這個邏輯）
- 跟 [[AI infra CapEx 三階段論]] 關係：
  - 第一階段（CSP CapEx）：間接受惠（會員預算上升）
  - 第二階段（NVDA 落地）：間接受惠（R&D 路線預定 Rubin / Vera）
  - 第三階段（上游材料爆掉）：直接受惠（材料 R&D 加速）
- 政府 + EU 資助關係：
  - 比利時政府是 Imec 主要 anchor（總部 Leuven）
  - EU Horizon Europe / Chips Act 資助（European Chips Act 2023 anchor 增加 Imec 預算）
  - 美 CHIPS Act 雖然 Imec 不在美國、但跟 SEMATECH（美 R&D consortium）+ Albany NanoTech 形成「**全球三大 R&D consortium**」（vs IBM Research）
- 護城河：
  - **全球唯一規模化 pre-competitive R&D 平台**
  - **共用 EUV / High-NA EUV pilot fab**
  - **200+ 會員中立性 + 不商業化**
  - **40 年 R&D 累積 know-how**
  - **比利時政府 + EU 資助 anchor**
- 風險：
  - ⚠️ **歐盟政治風險**（比利時 / EU 預算波動）
  - ⚠️ **美 CHIPS Act 競爭**（美 SEMATECH / Albany NanoTech 想替代 Imec 部分角色）
  - ⚠️ **中國脫鉤風險**（Imec 跟中國 fab 合作受美 EU 制裁影響）
  - ⚠️ **下一代 R&D 預算上升壓力**（High-NA EUV / 量子 / 神經形態運算 R&D 成本爆增）
  - ⚠️ **不可投資**（非上市、純研究機構）

### 可投資五軸分 = **N/A 不適用**
