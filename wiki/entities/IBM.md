# IBM（NYSE: IBM）

## 1. 一句話定位

**全球老牌 IT 企業 + IBM Consulting + IBM Watson AI + watsonx + Granite Foundation Models + Red Hat OpenShift Hybrid Cloud 全棧整合 + IBM Software（Hybrid Cloud + Data + Automation 多軌）+ IBM Z Mainframe（金融 + 政府 anchor）+ Quantum + Power Systems**——1911 在 Endicott NY 創立、1924 改名 International Business Machines；總部 Armonk NY；現任 CEO **Arvind Krishna**（2020-04 接任、前 IBM Cloud + Cognitive Software 主管、推動 Red Hat + watsonx 戰略轉型）；員工 **~270,000**（vs [[Accenture]] 789K / [[Deloitte]] 457K）；業務組合（FY2025 12 月年結）：**Software ~45%（含 Red Hat + watsonx + Data + Automation + Security + Hybrid Cloud platform）+ Consulting ~30%（IBM Consulting、含 strategy + tech + Operations）+ Infrastructure ~20%（IBM Z Mainframe + Power + Storage）+ Financing ~5%**；FY2025 全年營收 **~$65-68B**（YoY +4-6%）+ Forward PE **18-22x**（vs Accenture 22-26x 略折價、vs SaaS 50-90x 大幅折價）+ 12 月 +30-50%（Red Hat + watsonx + AI Foundation Models narrative 推升）；市值 **~$220-260B**（Mega Cap）；IBM Consulting 段 FY2025 營收 **~$22-24B**（占 IBM 營收 ~32-35%）+ AI / GenAI 投入 **~$1.5B** + GenAI ARR **~$2B+** + Fortune 500 + 政府客戶（含 GSA / DoD / EU / UK 政府）；推測五軸 IBM 整體 **17/25**（路線 4 + 站別 3 + 耗材 4 + IP 4 + 客戶分散 2 Fortune 500 + 政府 + Mainframe 客戶）= 跟 [[Accenture]] 19 + [[Snowflake]] 19 + [[Databricks]] 19 略遜（純度被 Mainframe + Infrastructure 稀釋）、但 IBM Consulting 段是「**企業 AI 諮詢三巨頭**」之一（Accenture / Deloitte / IBM Consulting）；**獨特差異化**：IBM Consulting 含 IBM Watson + Red Hat OpenShift + Hybrid Cloud 整合（vs Accenture / Deloitte 純諮詢 + 系統整合）= 「**諮詢 + 自家 platform + AI Foundation Models**」三軸整合。

## 2. 三層 thesis

### 產業層

- IT 諮詢 + Hybrid Cloud + AI Foundation Models 三賽道 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證 → 共識**」加速段
  - **IT 諮詢賽道**：跟 [[Accenture]] / [[Deloitte]] 同層、IBM Consulting #3 規模
  - **Hybrid Cloud + Red Hat OpenShift**：跟 AWS / Azure / GCP 跨多雲 vendor neutral 策略
  - **watsonx + Granite Foundation Models**：跟 [[Anthropic]] / [[OpenAI]] / Google Gemini / Meta Llama / Microsoft 模型公司賽道
  - **IBM Z Mainframe + Power Systems**：傳統金融 + 政府 anchor（low-growth but high-margin）
- vs **[[Accenture]] / [[Deloitte]] / TCS / Infosys** IBM Consulting 差異化：
  - **自家 AI Foundation Models**（Granite 系列）：vs Accenture / Deloitte 是「整合 platform 但不自研模型」
  - **Red Hat OpenShift Hybrid Cloud 整合**：vs Accenture / Deloitte 純諮詢 + 多 platform integration
  - **IBM Watson + watsonx AI 平台**：vs Accenture Cortex AI for Clients / Deloitte Generative AI accelerator
  - **規模較小**：IBM Consulting 段 ~$22-24B vs Accenture $65-70B / Deloitte $67B
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 2-3（IBM 從「old-economy IT」→「AI Foundation Models + Hybrid Cloud」narrative shift）
  - **2019-07 Red Hat $34B 收購**：IBM 戰略轉型 Hybrid Cloud anchor 事件
  - **2023-05 watsonx 發布**：IBM 跟 OpenAI / Anthropic / Google Gemini 並列 AI Foundation Models 玩家
  - **2024-04 Granite Foundation Models 開源**：IBM 自家 LLM 進入開源生態
  - **2025-Q1 IBM Consulting AI / GenAI bookings $1B 公開揭露**
