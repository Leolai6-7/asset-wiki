# IQE（IQE.L）

## 1. 一句話定位

**全球純 play 化合物半導體 epi（磊晶）代工龍頭、6 吋 InP 平台 industry-first**——1988 年起源 Cardiff、1999 與美國 Quantum Epitaxial Designs 合併形成今天的 IQE plc（International Quantum Epitaxy），是 **InP / GaAs / GaN / Sb / VCSEL 整合 epiwafer foundry**、做 [[Lumentum]] / [[Coherent]] 自家 InP fab 之外**唯一規模化外部 epi 供應源**（與 LandMark Optoelectronics、VPE 並列三家獨立 pure-play epi house）；2024 推出**全球首條 6" InP DFB Laser 平台**（同業仍主流 4 吋）+ 2024 加上 6" InP PIN photodetector / FP / EML，**單晶圓 die 數提升至 ~2.25x**、是給 [[Coherent]] 6 吋 InP 線追趕 [[Lumentum]] 200G EML 的**技術範式祖宗**；2026-04 完成 **£81M 融資（含 MACOM £45M 戰略入股 11.5% + 長期供應協議）**、淨現金回正 +£27.9m、FY 2026 自家指引 **>20% 營收成長 + 高個位數～低雙位數 adjusted EBITDA 轉正**；FY 2025 photonics 段 **£57.1M（+15% YoY）**、是公司主成長軌；2026 年股價最高 +1,300%、目前回檔仍 +900%、市值 **£594M（USD ~$690M）**；是 [[AI infra CapEx 三階段論]] 第三階段最關鍵 **anchor 上游 InP 供應源**——與 [[Coherent]] InP delivery >26 週、[[Lumentum]] 供應限制延伸 2026 全年**三家同月喊緊（2026-05）**。

## 2. 三層 thesis

### 產業層

- **化合物半導體 epi foundry** 賽道處於 [[市場四階段：懷疑／驗證／共識／反轉]] **「驗證 → 共識」加速段**
  - InP 是 1.6T / 800G / next-gen 光模組**絕對標準**（矽光無法處理頻寬）
  - 與 [[Lumentum]] / [[Coherent]] 全球前瞻訊號**完全同步**（2026-05 三家同月喊緊）
  - 賽道從 wireless（手機 PA）+ VCSEL（消費）擴到 InP（AI / 雲端 / 國防）**結構性 mix shift**
- InP 賽道結構（[[AI infra CapEx 三階段論]] 第三階段最關鍵上游）：
  - 1.6T 模組需求 **2025 1.8M units → 2026 30M+ units**（17 倍增量）
  - 對應 **InP wafer 用量結構性放大** = wafer 供給端瓶頸
  - **InP epi 全球僅 3 家獨立 pure-play**：IQE / LandMark Optoelectronics / VPE
  - [[Lumentum]] / [[Coherent]] 有自家 InP fab、但**容量永遠不夠**（COHR 自揭 next quarter 2x、2027 再 2x；LITE 公開 30%+ 供需缺口；日本 wafer fab 利用率「fully allocated + premium pricing」）→ 外部 epi house 補位
  - **2026-05 整鏈三家同月喊緊** = 不是 plant by plant 局部短缺、是賽道結構性瓶頸
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（IQE 股價 12 個月 +900-1,300% 已過 KOL / 機構發掘）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 2 層光引擎全 InP 結構性放大
  - **2026-04 £81M 融資是 InP 賽道題材引爆點**——與 NVDA 對 [[Lumentum]] / [[Coherent]] $4B 戰略投資（2026-03）形成「上游補位」呼應
- vs [[Sumitomo Chemical|住友化學]]（4005.JP）+ Sumitomo Electric（5802.JP）+ Sumitomo Electric Semiconductor Materials（SESMI, Hillsboro Oregon）：
  - **Sumitomo Electric 是 InP substrate 全球龍頭**（純 wafer 基板、與 SCI / AXT 競爭）
  - **IQE 是 substrate 之上 epi 層代工**（基板再長 epi 結構）
  - = **不是直接競爭、是上下游關係**（IQE 可能向 Sumitomo Electric 買 InP substrate）
  - [[Sumitomo Chemical]] 4005.JP 主要做半導體光阻劑 + 高純度製程化學品 + 玻璃 JV，**不直接做 InP wafer / epi**
  - → 在化合物半導體鏈：**Sumitomo Electric = InP 基板龍頭、IQE = 6" InP epi 全球唯一**

### 目的層

- 業務 mix（FY 2025）：
  - **Photonics = 58.6% 營收**（£57.1M、YoY **+15%**）
    - InP epi（lasers、photodetectors）：next-gen optical interconnect 主軸
    - VCSEL（智慧手機 3D 感測、雷射雷達）：周期性訂單反彈
    - Aerospace & Defence：H2 2025 美國軍方資金釋出
  - **Wireless = 41.2% 營收**（£40.1M、YoY **-40%**）
    - GaAs PA / RF：手機庫存去化 + 終端需求軟
    - 反映消費電子大盤 weakness（非結構性問題）
  - **CMOS++ ~ 0%**（£65K、已退場）
    - 南威爾士 silicon fab 已關閉、IP 全部轉到化合物
- 商業模式 = **「epi foundry pure play」**：
  - 不做自家 laser / 不做自家模組 / **只做 epi wafer foundry**
  - 客戶包含 [[Lumentum]] / [[Coherent]] 等模組廠（補自家 fab 容量）、MACOM、IDM / fabless InP 設計商
  - **與 LandMark Optoelectronics / VPE 形成「非 captive InP epi 鏈三家寡占」**
- 客戶結構（公開度有限）：
  - **MACOM（NASDAQ: MTSI）**：2026-04 £45M 戰略投資 + **長期供應協議**（11.5% 股權 + COO + VP 任董事）
  - **Coherent / Lumentum**：兩家自家 InP fab 容量不足時的外部補位（**未直接揭露但業界共識，confidence: medium**）
  - **美國國防 / 航太**（DARPA、Lockheed、Northrop Grumman 等、aerospace & defence 段 H2 2025 美國資金釋出）
  - **智慧手機 VCSEL**（透過模組廠間接出貨給 Apple iPhone / Android 3D 感測，受 Lumentum 自家 VCSEL 競爭）
- 客戶高度集中風險：[[AVGO]] / [[Apple]] 終端、MACOM 集中、加上 [[Lumentum]] / [[Coherent]] 自家內部 InP 線擴張 = 客戶**雙曲線收縮風險**
- → 連 [[賣水人選股邏輯（投資版）]]：**「epi wafer 賣水人」**——不押 InP 模組 / 雷射廠誰贏、押 [[Lumentum]] / [[Coherent]] / MACOM **背後共同的 epi 結構**
  - 比 LITE / COHR 更上游、wafer 階段就拿
  - 但 wafer 利潤率比 die / 模組低、ASP 不如 LITE EML（$14→$20 漲價）
- [[控制點轉移（投資版）]]：拿到「**6" InP epi 平台 industry-first + MACOM 11.5% 股權 anchor + 美國 / 英國 / 台灣三地產能 hedge**」三重控制點

### 供應層

- 跟 [[Lumentum]] / [[Coherent]] 關係：
  - **互補非完全對手**：兩家有 captive InP fab、IQE 補容量瓶頸
  - [[Coherent]] 走 **6" InP 線追趕 [[Lumentum]] 200G EML**——COHR 路線與 IQE 6" InP 範式**直接對應**
  - 2026-05-06 [[Coherent]] 揭露 InP delivery >26 週 = **承認自家 fab 無法滿足訂單** = IQE 補位窗口開
  - 2026-05-05 [[Lumentum]] Q3 揭露日本 wafer fab fully allocated + premium pricing = IQE 等獨立 epi 廠的議價力上升
- 跟 MACOM 路線：
  - 2026-04 £45M 戰略投資 + **長期供應協議**（multi-year multi-product epi services）
  - = MACOM 用股權 + 長約綁定 IQE 容量（類似 NVDA 對 LITE / COHR 的綁定模式、規模較小）
  - MACOM 是 InP 模組廠（光通訊 + RF + 國防）、自有 4" InP MOCVD 線但需要 6" 升級 → IQE 補位
- 跟 [[Sumitomo Chemical]] / Sumitomo Electric / [[AGC]] 等日系材料對比：
  - **完全不同位階**：Sumitomo Electric 做 InP **substrate**（IQE 的原料）、IQE 做 epi 層代工
  - 不直接競爭、是上下游關係
- pump laser / EML / DFB epi 競爭地位：
  - **6" InP DFB 平台 industry-first**（2024 推出、全球首家）
  - 6" InP PIN photodetector + FP + EML（2024 portfolio expansion）
  - 同業多仍走 4" InP → IQE 單晶圓 die 數提升 ~2.25x（150²/100² 面積比）
  - 1.6T epi（200G EML / VCSEL / 100G PD）design wins multiple tier-1（具體客戶未公開）
- 護城河：
  - **6" InP 平台 industry-first IP**（150mm wafer + DFB / FP / EML / PD 整合 lineup）
  - **40 年 MOCVD know-how**（從 1988 起源、廣譜化合物 epi 能力）
  - **美 / 英 / 台三地產能 hedge**（中美技術脫鉤反脆弱、政治紅利雙拿）
  - **MACOM 11.5% 股權 anchor + 長期供應協議**（COO + VP 進董事會）
- 風險：
  - **[[Lumentum]] / [[Coherent]] 兩家自家 InP fab 擴張**——COHR next quarter 2x、2027 再 2x、LITE Greensboro NC 廠 2028 中量產
    - = IQE 在 2028 後可能**容量過剩風險加劇**
  - **客戶集中度高**：MACOM + 兩家模組廠 + 美國國防 + 智慧手機 VCSEL 四軌、但每軌都偏少數大客戶
  - **EBITDA 仍微薄**：FY 2026 指引 high-single digit ~ low double-digit £M、轉盈剛起步
  - **Wireless 段 -40% YoY 拖累整體**（FY 2025 整體營收 -17.6%）
  - **股價 +900-1,300% 12 個月**：估值 price in 後續 2-3 年完美執行 + InP 賽道 anchor 不變
  - **未上市美國納斯達克**：英國 LSE 流動性差、機構買盤受限（但近 1 月成交量明顯放大）
- → 連 [[控制點轉移（投資版）]]：「**6" InP epi 全球唯一 + MACOM 11.5% 股權 + 美/英/台三地產能**」三重 anchor、但模組層被 LITE / COHR 切走（與 LITE EML 模組層被 OEM 切走同理）

## ⭐ 對 [[Coherent]] / [[Lumentum]] / DCI / CPO 鏈的意義

對既有 wiki entity：

### Bull case

- **IQE 6" InP 平台投產 + £81M 融資解 balance sheet → 為 LITE / COHR 補容量** → 兩家在 ramp 1.6T EML / pump laser / CPO 模組時**有外部 epi 補位**
- [[Coherent]] 自家 6" InP 線 2026 H2 投產之前的**過渡產能** = IQE 的 6" 平台是直接補位
- 對 [[CPO 供應鏈圖譜]] 第 2 層光引擎：**IQE = 第 2 層的上游 wafer 層、與 LITE InP die / COHR 6" InP 形成補位 + 競爭雙軌**
- 對 [[AI infra CapEx 三階段論]] 第三階段：**最關鍵 anchor 上游 entity** = LITE / COHR 模組 ramp 順利的物理前提
- 對 [[Hyper Rail / Multi-Rail（光通訊整合技術）]]：pump laser 三倍 BOM 對 IQE 是**整鏈放大器**（每 rack 多 30+ pump laser × 多 rack × 多 fiber pair）

### Bear case

- IQE 自己 6" InP 平台 ramp 跟不上 LITE / COHR 訂單拉量速度 → **整鏈瓶頸延長 = 1.6T / 800G 模組 ramp 延後** → CapEx 第三階段 narrative 失效 → [[NVDA]] / [[AVGO]] CPO 時間表推遲
- IQE 客戶集中 MACOM + LITE + COHR、若 LITE Greensboro NC 廠 2028 中量產提前 / COHR 6" 線 2027 再 2x 提前 → IQE **被去庫存 + 容量過剩** = 反向 derate

→ **校準 Leo 三家喊緊 thesis**：
- Coherent 2026-05-06 法說 InP delivery >26 週 + 影響 15-20% 營收
- Lumentum 2026-05-05 法說供應限制延伸 2026 全年 + 30%+ EML 缺口、日本 wafer fab fully allocated + premium pricing
- IQE 2026-05-28 FY 2025 results 揭露 photonics +15% + 4 月 £81M 融資 + FY 2026 指引 >20% 成長
- = **三家在 2026-05 4 週內同時揭露**、整鏈訊號**時序高度收斂、不是巧合**

## ⭐ 三階段論第三階段最有 alpha 的 entity 是 IQE 還是 LITE/COHR？

### 三家對照（2026-06-08）

| 維度 | IQE | LITE | COHR |
|---|---|---|---|
| 12 個月漲幅 | +900-1,300% | +1,542% | +362% |
| 市值 | $688M | $64-73B | $70.7B |
| Forward PE | n/a（虧損→剛轉盈） | 52-59 | 44-49 |
| 五軸 | **17/25** | **19/25** | **19/25** |
| 賽道位階 | 最上游（wafer） | 中游（die + 模組） | 中游（模組 + 規模） |
| 結構性 anchor | MACOM 11.5% | NVDA $2B + Greensboro 2028 | NVDA $2B + 2028 訂單能見度 |
| 主要風險 | LITE/COHR 自家 fab 擴張 | NVDA 集中、Greensboro 2028 才量產 | 整合 II-VI + Finisar 複雜度 |
| Beta | 最高（小市值 + 純 thesis） | 中（IP 純度 + EML 唯一量產者） | 中（SiC 第二曲線 hedge） |

### Alpha 結論

**IQE 是「第三階段最尖端 alpha 但風險最濃」、LITE 是「第三階段最確定品質 alpha」、COHR 是「最 hedged 但 alpha 較小」。**

#### 三段論：

1. **若 thesis 完美實現（InP 三家喊緊 → 整鏈瓶頸延長至 2026 H2-2027）**：
   - IQE alpha 最大（最小市值 + 純 thesis + 6" 平台 industry-first option）
   - 翻倍空間：IQE +200% > LITE +50% > COHR +30%
2. **若 thesis 部分實現（LITE / COHR 自家 fab 順利 ramp、上游補位窗口 2 年）**：
   - LITE alpha 最大（200G EML 唯一量產者 + NVDA $2B anchor 確定）
   - IQE / COHR 都是「對沖型」
3. **若 thesis 失效（CSP 跟進緩慢 + 1.6T ramp 推遲）**：
   - IQE 回檔最劇（-50%+、估值無錨點）
   - LITE 回檔中度（-30%、NVDA $2B 是 floor）
   - COHR 回檔最輕（-15%、SiC 第二曲線 hedge）

#### Leo 的最佳策略：

**「LITE + COHR 一籃子 anchor 部位 + IQE 小倉位期權」**——
- LITE + COHR 是已驗證的 19/25 + NVDA $2B + 2028 訂單能見度 = thesis 不變的核心
- IQE 是「**第三階段最尖端 alpha + 最尖端風險**」的選擇權型衛星部位
- IQE 倉位上限：5-10%（純期權性質、輸贏對總組合不要 binary）
- Lint 點：IQE 必須**季季追蹤** photonics 段成長率 + LITE/COHR fab 進度 + MACOM 關係穩定性
