# Western Digital（NASDAQ: WDC / 純 HDD 公司 2025 起）

⚠️ **2025-02-24 分拆後重要結構變化**：本檔是**分家後的純 HDD 公司**。原 WD 的 **NAND / Flash 業務全部劃給 [[SanDisk]]**（NASDAQ: SNDK 獨立上市）。如果你在找「WD 的 NAND 業務」、請看 [[SanDisk]]。WDC 現在**只做 HDD + UltraSMR / nearline drives + AI 資料中心儲存**——是 **3D NAND 戰場的「rival 賽道」** 而不是「戰場玩家」。

## 1. 一句話定位

**全球 HDD 雙頭壟斷之首（45% 市佔 / nearline 主導）+ AI 資料中心儲存「rival storage」最大受惠者**——2025-02-24 完成 SanDisk spin-off 後變身「**純 HDD pure-play**」，把「**2026 全年 HDD 產能售罄 + 多年合約延伸到 2028 + Q3 FY2026 營收 $3.34B / Cloud +48% YoY / nearline +37% YoY / 毛利率 50.2% / EPS +90% YoY + 12 個月股價 +880-970%**」綁進同一個故事。在 [[AI infra 3D NAND 戰場]] 6 家分食的 NAND 戰場裡，**WDC 已不是戰場玩家**——但是「**HDD-NAND 雙鏈 storage AI**」的另一條腿。跟 [[Seagate]]（HDD 雙頭另一家）構成全球 HDD 寡占 85%+；跟 [[SanDisk]]（前自家 NAND 部門）是「**已分家但共享 brand legacy**」關係。對 [[Kioxia]] / [[Solidigm]] 是「**HDD vs SSD 替代率**」的反方論據。

## 2. 三層 thesis

### 產業層

- **HDD 雙頭壟斷**：WDC（45%）+ Seagate（45%）+ Toshiba HDD（剩餘 ~10%）= CR2 90%（極端集中）
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」過渡期**——
  - 驗證完成：2026 全年 HDD 產能售罄、多年合約延伸 2027-2028、UltraSMR nearline drives margin signature 完成、Cloud 89% revenue mix
  - 共識未完成：仍有人視 WDC 為「夕陽 HDD」（被 SSD 取代論）、但 nearline HDD 顯然是 AI 訓練資料集儲存的成本最佳化解（10-30× 便宜於 SSD）
- 在 [[資訊擴散四階段]]：機構（華爾街 buy-side）→ 賣方（Goldman / Morgan Stanley）→ 媒體（Tom's Hardware / TIKR）→ ETF 配置進行中、**S&P 500 top-5 performer YTD 2026**
- TAM：HDD 全球市場 USD 25B（穩定）+ nearline / cloud HDD 段 CAGR 15-20%；AI 訓練資料集 + 模型 checkpoint + 不熱 inference cache 都是 nearline HDD 最佳載體
- 黃仁勳 2026-06-08 定調的「**AI 記憶體結構性短缺持續多年**」**間接受惠**：HBM 短缺 + NAND 短缺擠壓 → 客戶**回頭找 nearline HDD 做 cost-effective 儲存層**

### 目的層

- 真實角色：**「AI 資料中心 storage cost-down 對沖配置」+「HDD-NAND 替代論的反方論據」**——不是「賣 NAND 給 NVDA」（[[SanDisk]] / [[Kioxia]] 才是）、是「**Hyperscaler 不想 NAND 太貴所以買 HDD**」的最大受惠者、靠「**UltraSMR + HAMR + 規模 + 45% nearline 主導**」拿到 multi-year 合約
- 商業模式三段：
  - **Cloud（nearline HDD）**：Q3 FY2026 占 89% 營收（$3B）= **絕對主力**、YoY +48%、Hyperscaler 主供
  - **Client + Consumer HDD**：剩餘 ~11%、穩定
  - **NAND 業務**：**已 2025-02-24 全部劃給 [[SanDisk]]**、WDC 不再參與
- 真實戰略：**「純 HDD pure-play + UltraSMR margin 提升 + HAMR 路線 + 多年合約鎖供 + 純 HDD valuation re-rate」五重 catalyst 同步**——
  - 2025-02-24 完成 spin-off → WDC 估值不再被 NAND wave 拖累
  - UltraSMR 超過 nearline 50%+ mix → 同樣 wafer 面積、密度更高 → 毛利率 50%+ 創新高
  - HAMR（Heat-Assisted Magnetic Recording）下一代技術路線、Seagate 已先行、WDC 追趕中
  - 2026 全年產能售罄 + 多年合約延伸 2027-2028
- [[控制點轉移（投資版）]]：拿到「**Cloud Storage 成本曲線主導權**」+「**HDD 雙頭壟斷一席**」+「**AI 訓練資料集儲存標準載體**」

### 供應層

- **路線雙押**：UltraSMR（現金牛、CMR/SMR 升級）+ HAMR（下一代、追 Seagate）
- 護城河四層：
  - **HDD 雙頭壟斷護城河**：CR2 90%，幾乎不可進入（資本門檻 + 技術積累 + IP 護城河）
  - **UltraSMR margin 護城河**：同樣製程、密度高、毛利率 50%+ vs 傳統 CMR 35-40%
  - **規模 + 客戶 lock-in**：Hyperscaler 7 大客戶多年合約延伸 2027-2028
  - **替代論反證護城河**：SSD 替代 HDD 論被反證——nearline HDD $/TB 仍是 SSD 的 1/10-1/30，AI 訓練資料集太大無法全 SSD
- 對 [[Seagate]] 領先程度：**短期 nearline 領先（UltraSMR 50%+ mix）+ HAMR 落後**（Seagate 已先 ramp HAMR、WDC 2026 H2 起追）
- 對 [[Toshiba HDD]] 領先程度：規模 4-5x、純度更高
- 對 [[SanDisk]] 關係：**「已分家、不再合作」**——2025-02-24 spin-off 後 WDC 不再有 NAND 業務、SanDisk 接 brand 但獨立經營
- 跟 [[Kioxia]] / [[Solidigm]] 關係：**「替代論的兩端」**——客戶選 HDD（WDC）vs SSD（Kioxia / Solidigm）的 trade-off

### ✅ 催化

- **2026 全年 HDD 產能售罄 + 多年合約延伸 2027-2028**：能見度極長、訂單 visibility 史上最強

- **HAMR 2026 H2 ramp**：追 Seagate、長期 cost structure 跟齊
- **NVDA Vera Rubin 「rival storage」受惠**：1,152TB SSD/rack 對應 NAND 短缺 → 部分 datacenter 工作負載 fallback 到 nearline HDD
- **Q4 FY2026 guidance**：$3.65B（+40% YoY）+ EPS $3.25 + 毛利率 52% → 又一個 beat 機會
- **股利上修 20%**：管理層發現金流訊號 = 內部對 cash generation 有信心
- **黃仁勳 2026-06-08 定調 + Samsung 2027 警告**：HBM + NAND 短缺擠壓 → 客戶找 HDD 對沖
- **多年合約結構性轉化**：歷史上 HDD 訂單以季度為基準、Cloud / hyperscaler 2026 起轉 multi-year LTA

### ⚠️ 風險

- **12M +880-970% 漲幅**：[[資訊擴散四階段]] 階段 3-4、回檔風險高
- **SSD 替代 HDD 長期論**：雖然當前 $/TB 仍是 SSD 1/10-1/30、但 QLC 245TB SSD 普及後**會壓力**到 nearline HDD 價值主張
- **HAMR 路線追 Seagate 落後**：Seagate 2024 已 ramp HAMR、WDC 落後 12-18 個月、長期 cost structure 仍是劣勢
- **Hyperscaler 議價力**：7 大客戶占 80%+、長期合約鎖了量但 ASP 仍 hyperscaler 主導
- **NAND 業務劃出 = 估值不再有 NAND wave 加成**：但這也是 spin-off 的目的（pure HDD valuation）
- **HDD 製造業仍週期性**：歷史上 HDD 廠財報波動劇烈、毛利率 50%+ 是否能持續仍待驗證
- **若 NVDA Vera Rubin ICMS 完全靠 SSD 而非 HDD**：HDD 在 AI 增長 narrative 中地位被擠
- **SanDisk 分家後協同效應消失**：原 WD JV 對 Kioxia BiCS 的議價力 spin-off 後消失

## ⭐ AI / Enterprise SSD 曝險量化

**WDC 已無 NAND 業務、本段以「AI HDD 曝險」替代**：

- **Cloud 占 Q3 FY2026 營收 89%**（vs 一般 HDD 廠 60-70%）= AI / hyperscaler 純度極高
- **Nearline HDD 出貨 199 EB / Q（YoY +37%）**= AI 資料中心儲存軸結構性放量
- **AI 訓練資料集儲存需求**：Vera Rubin ICMS 之外的「冷儲存層」、nearline HDD 是主要載體
- **AI 占 WDC 整體營收推估 70-80%**（含 Cloud nearline + 多年合約 + AI 訓練資料集）

## ⭐ 對 [[PB 估值法（記憶體週期）]] thesis 的對應

**HDD 雖非「記憶體」、但週期屬性相同**：

| PB 框架（景氣循環論）| WDC 現況支持哪邊？ |
|---|---|
| **PB 派**（PE 高 = 該賣 / 週期反轉）| Q3 FY2026 EPS +90% / Forward PE 15-25x = 接近「景氣高、PE 高」訊號 |
| **HBM iPhone moment 派 + [[AI infra 3D NAND 戰場]] 派**（結構性短缺論）| AI 訓練資料集儲存軸結構性放量、多年合約延伸 2028、HDD 雙頭壟斷護城河 |

→ **Leo 校準**：WDC 不是純粹的「PE 高 = 該賣」——這次 EPS inflection 由結構性 cloud / hyperscaler / AI 訓練資料集需求驅動。但與 [[SK Hynix]] 的 PE 5.9x + 結構性綁定相比，**WDC 沒有「multi-year NVDA 合約」這層 anchor**——更接近 [[Kioxia]] 結構（強盈利 inflect + 結構性需求 + 但無 NVDA 寡占合約）。**現在進場是接「12M +880% 漲幅尾巴」**，不是「再翻倍」格局。
