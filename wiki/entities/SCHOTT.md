# SCHOTT（德國非上市 / Carl Zeiss Foundation 100% 持有）

## 1. 一句話定位

**德國特殊玻璃技術龍頭 + HermeS TGV 玻璃晶圓專利擁有者**——135 年德國老牌（1884 由 Otto Schott 創立、發明硼矽玻璃），由 **Carl Zeiss Foundation 唯一持股、不能 IPO**（章程禁止）；2024-08 成立**半導體專屬事業部**（由 Dr. Christian Leirer 領銜，15 年半導體經驗），2025 年估算半導體玻璃營收 **USD 150-180M**，是 AGC、Corning 之外**全球四大低 CTE 玻璃配方擁有者之一**。**在玻璃材料三巨頭中最 niche、最技術導向、但因非上市 → 無法直接押注**。

## 2. 三層 thesis

### 產業層
- 玻璃材料三巨頭之一：與 Corning、AGC、NEG 並列控全球 90%+ 低 CTE 玻璃配方；**2025 估算 Corning + AGC + SCHOTT + PlanOptik 四家合計 ~90% 半導體玻璃營收**
- **HermeS Glass Wafer with TGV** 是 SCHOTT 旗艦半導體產品（2014 開始量產 MEMS 應用、超短脈衝雷射 TGV 鑽孔專利）
- 主要玻璃配方：
  - **BOROFLOAT 33**（浮法硼矽玻璃）
  - **AF 32 eco**（無鹼平板玻璃）
  - **D 263 T eco**（硼矽玻璃）
- 賽道 timing：MEMS / RF 已商業化、先進封裝 TGV 2026-2028 量產期過渡
- 2024-08 成立**半導體專屬事業部**：Dr. Christian Leirer 領銜、15 年半導體經驗、聚焦「快速 sampling + 客製化玻璃基板」服務 chipmaker
- 2025-09 SEMICON Taiwan 公開展示：FO-WLP / FO-PLP / 3D IC 玻璃載板 + 大尺寸 panel + 高 TGV 密度薄 interposer
- 2025-01 收購 **QSIL GmbH Quarzschmelze Ilmenau**：強化石英玻璃能力（chip / wafer 製程關鍵）

### 目的層
- 真實角色：**特殊玻璃 + 醫藥包裝 + 光學 platform 公司**
- 在 TGV 製程鏈位置：
  - **第 0 站材料供應 + 玻璃 wafer with TGV 加工**（橫跨材料 + 部分加工，比 Corning 純載板更深）
  - HermeS = **預製好 TGV 的玻璃晶圓**，直接交給客戶填充銅 → 等於 SCHOTT 把第 1 + 2 站（雷射改質 + 蝕刻）一體化打包
- 玻璃基板相關產品：
  - **HermeS Glass Wafer with TGV**（已商業化、原以 MEMS 為主、現擴至先進封裝）
  - **SCHOTT low-loss glass**（新發表、低介電損失）
  - **ZERODUR**（光罩 / 微影設備用、零膨脹玻璃陶瓷）
- 商業模式：(a) 客製化玻璃 wafer / panel（高毛利、低量）、(b) 預製 TGV 玻璃（**比純玻璃片更高附加價值**）、(c) 醫藥玻璃（pharma 子公司獨立上市）
- **SCHOTT Pharma 是已上市子公司**（FY2025 營收 EUR 986M）→ SCHOTT AG 母公司本身仍 100% Carl Zeiss Foundation 持有
- 跟 [[控制點轉移（投資版）]] 對應：拿到「**材料 + TGV 加工一體化 + 微影 ZERODUR + 醫藥**」四重控制點

### 供應層
- **路線**：玻璃 + TGV 一體化（比 Corning 純玻璃更下游一步、比 AGC 多材料更聚焦特殊應用）
- 護城河三層：
  - **超短脈衝雷射 TGV 鑽孔專利**（HermeS 核心技術，與 LPKF LIDE 不同路徑）
  - **無 IPO 壓力**（Carl Zeiss Foundation 章程禁止 → 不需短期績效，可投長期 R&D）
  - **歐洲 / 美國 chipmaker 信任綁定**（Otto Schott 發明硼矽玻璃 = 行業背書）
- 玻璃基板競爭格局：vs Corning（規模大、AI 期權溢價高）、vs AGC（半導體深度大、估值便宜）、vs PlanOptik、vs LPKF（**LPKF 也用雷射鑽 TGV、但聚焦設備銷售；SCHOTT 直接賣 wafer**）
- 客戶集中度：分散到「key industry players」、未具名揭露
- 風險：**非上市 = 投資人無法直接押注**、業績透明度低、TGV 純度高但規模相對小（USD 150-180M）

## ⭐ 對台股 TGV 設備廠的意義

### bull case 對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]]

- SCHOTT HermeS **跟 LPKF 是「技術路線競爭關係」而非台廠對手**——SCHOTT 用自家超短脈衝雷射 TGV，跟 LPKF LIDE 走不同路徑 → **LPKF 專利對 SCHOTT 自家 HermeS 無效**
- SCHOTT 直接賣「**預製 TGV 的玻璃 wafer**」給客戶 → 客戶買來不需要再做雷射改質 / 蝕刻
- **但 SCHOTT HermeS 規模小（USD 150-180M），不足以威脅 TSMC / Intel / Samsung 鏈下游加工**
- SCHOTT + Corning + AGC 三家鼎立 → 確認玻璃材料供應充足、台廠下游不缺料

### bear case 對台廠

- **SCHOTT HermeS 模式 = 玻璃 + TGV 一體化**——如果這個 model 被 chipmaker 規模採用，**意味著台廠雷射改質設備（鈦昇）、蝕刻設備（弘塑 / 辛耘）會被「上游一體化」吃掉一部分**
- 換言之：HermeS 模式類似 **LPKF Vitrion**——上游廠跨界做下游加工的威脅
- 但目前 HermeS 規模仍以 MEMS 為主、先進封裝 chipmaker design-in 未具名揭露 → 短期威脅有限

### 最大 takeaway

**SCHOTT 對 Leo 不是可投資標的，是「玻璃基板賽道 thesis 校準」的對照組。** SCHOTT HermeS 已商業化 TGV wafer 多年（2014 起）→ 證明「玻璃 + TGV 一體化加工」技術可行；現在 chipmaker 等的是**規模 + 良率 + 成本**，不是技術可不可行。對台廠最關鍵的訊息：**TGV 不是 binary 賭技術會不會成功，而是賭哪條路線（LPKF LIDE / SCHOTT HermeS / 鈦昇雷射改質 / 雷科直接雷射打孔）勝出 + 量產良率拐點**。SCHOTT HermeS 是「**雷射改質型雷射 TGV 已存在多年的證據**」——對應到鈦昇 / LPKF 路線的技術可行性 derisk。
