# MACOM Technology（NASDAQ: MTSI）

## 1. 一句話定位

**美系 GaAs / InP / GaN 化合物半導體 IC 設計 + 高頻 RF / 微波 / 光通訊 / 國防四軸 fabless（部分自有 fab）+ 2026-04 完成 £45M（USD ~$56M）戰略入股 [[IQE]] 11.5% + COO + VP 進 IQE 董事會 + 長期供應協議**——1950 年代成立、原 M/A-COM 經數次併購重組為現在的 MACOM Technology Solutions、2012 年從 Tyco / Cobham 切出獨立、納斯達克上市；不做矽 IC、**只做化合物半導體**（GaAs / InP / GaN）；產品線涵蓋光通訊（DWDM / 100G/400G/800G/1.6T transceiver IC）、RF / 微波（5G / 雷達 / 國防）、Power（GaN 功率放大器 PA）；2024-2025 完成 Wolfspeed RF 業務（價值 ~$125M）+ ENGIN-IC（gallium nitride MMIC）併購、補齊 GaN MMIC 線；在 [[AI infra CapEx 三階段論]] 第三階段（InP / 光通訊爆掉）是「**InP 模組 + 雷射 IC 雙重位階**」、跟 [[Lumentum]] / [[Coherent]] / [[IQE]] 共同形成「**InP 鏈三家 + 1（MACOM 美系）+ epi foundry**」的**美系 / 英系混合 chokepoint 池**。在 [[Bottleneck Theory（瓶頸論）]] 是「**跨第 3-5 層光通訊 IC + 模組 + 雷射**」混合位階。

## 2. 三層 thesis

### 產業層

- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——
  - 驗證已完成：2024-2025 FY 5G optical 收入 +30% YoY、IQE 戰略入股確認長期 InP 6" wafer 容量綁定
  - 共識未完成：MTSI Forward PE 仍 25-30x（vs LITE / COHR 30-40x、IQE FY26 預期 +20%）
- 在 [[資訊擴散四階段]]：機構 + 賣方覆蓋深、媒體層尚未爆炒（仍被當「中型 RF / 光通訊 IC 廠」）、ETF 配置中
- TAM：
  - 光通訊 IC（DWDM / transceiver）：2024 USD 2.5B → 2030 USD 8B+（CAGR ~20%）
  - 5G RF / 微波：穩定成長 5-10%
  - 國防 / 雷達：穩定 + 美 DoD 訂單能見度高
  - GaN Power（PA + 800V HVDC）：2024 USD 1B → 2030 USD 5B+（CAGR ~30%）
- 在 [[AI infra CapEx 三階段論]] 第三階段：光通訊 + InP 上游同步喊緊（[[Lumentum]] / [[Coherent]] / [[IQE]] 三家同月喊緊、MACOM 透過 IQE 11.5% 股權 anchor 鎖定 InP wafer 容量）
- [[Bottleneck Theory（瓶頸論）]] 視角：MACOM = **InP 模組 / 雷射 / IC 跨第 3-5 層** + **GaN power 跨白區 chip 級電源 IC**（vs [[Infineon]] / [[Texas Instruments TXN]] / [[Wolfspeed]] / [[Navitas Semiconductor]] 對手位）

### 目的層

- 真實角色：**「美系 GaAs / InP / GaN 化合物半導體 IC 純度首選 + 跨 5G optical + 國防 + Power 四軸組合 + IQE 11.5% 戰略股東 + InP wafer 雙向綁定」**——不是純光通訊 IC（vs 純 photodiode / EML 設計商）、是「**化合物半導體 IC 多元組合**」+ **長期 InP 6" wafer 容量綁定**（透過 IQE 戰略入股）
- 業務組合（FY2025 推估）：
  - **Data Center / 光通訊**：~40%（DWDM、coherent、transceiver IC / driver / TIA / SerDes）
  - **Industrial & Defense**：~35%（雷達、衛星、5G base station MMIC）
  - **Telecom（5G + RF）**：~25%（5G mmWave、衛星、RF front-end）
- 商業模式：
  - **fabless 主導 + 部分 6" InP MOCVD 自家 fab + 4" GaAs fab 仍在用**
  - **化合物半導體 IC 設計 IP + manufacturing know-how**
  - **長期供應協議綁定上游**（IQE 11.5% 股權 + 多年產品 multi-year multi-product 供應協議）
- 核心 IP / 護城河：
  - **InP DWDM driver / TIA / SerDes IC**（800G / 1.6T 模組必需、跟 [[Lumentum]] / [[Coherent]] 模組廠形成 IC 對 module 的供應關係）
  - **GaAs RF / 雷達 MMIC IP**（美 DoD / Lockheed Martin / Northrop Grumman / Raytheon 國防訂單）
  - **GaN MMIC + Power**（Wolfspeed RF 業務併購 + ENGIN-IC 補齊 PA 線、跟 [[Infineon]] / [[Navitas Semiconductor]] 競爭 800V HVDC）
  - **IQE 11.5% 戰略股東 + COO + VP 任董事**（鎖定 6" InP wafer 容量、業界 InP wafer 緊張時期的雙向安全網）
- 對應 [[賣水人選股邏輯（投資版）]]：**「光通訊 IC + 國防 RF + GaN power 跨三軸組合 + IQE 11.5% upstream lock-in」**——不押純 800G / 1.6T 路線、押**多路線光通訊 + 國防 + power 三軸組合**
- 對應 [[控制點轉移（投資版）]]：拿到「**化合物半導體 IC IP + 美 DoD 國防 lock-in + IQE 11.5% 戰略股權 + 多年 InP wafer 供應協議**」三層 chokepoint、控制權結構性
- 對應 [[Hyper Rail / Multi-Rail（光通訊整合技術）]]：MACOM IC 在 [[Ciena]] / [[Nokia]] / [[Lumentum]] / [[Coherent]] 1.6T / Hyper Rail 模組裡是**內部 driver / TIA / SerDes IC**（vs Lumentum / Coherent module 級競爭）

### 供應層

- 跟 [[IQE]] 關係（**核心戰略合作**）：
  - **2026-04 完成 £45M（USD ~$56M）戰略投資**（11.5% 股權 + COO + VP 進董事會）
  - **長期供應協議**（multi-year multi-product epi services）
  - **雙向關係**：MACOM 鎖 IQE 6" InP wafer 容量 / IQE 拿 MACOM 長期訂單 anchor
  - 跟 NVDA 對 [[Lumentum]] / [[Coherent]] $4B 戰略投資的**規模較小版本**（NVDA $4B vs MACOM £45M = ~70x 規模差）
  - 但**結構意義相同**：化合物半導體鏈整合 + wafer 容量 lock-in
- 跟 [[Lumentum]] / [[Coherent]] 關係：
  - **不是直接競爭**（LITE / COHR 做 module + 自家 InP fab、MACOM 做 IC 設計）
  - **既是客戶也是對手**：
    - 客戶面：MACOM IC 賣給 LITE / COHR 模組裡（DWDM driver / TIA / SerDes）
    - 對手面：MACOM 6" InP MOCVD 線跟 LITE / COHR 自家 InP fab 部分重疊
- 跟 [[Sumitomo Chemical]] / Sumitomo Electric 關係：
  - Sumitomo Electric = InP substrate 上游、MACOM 透過 IQE 拿 epi 層、不直接採購 Sumitomo
- 跟 [[Bottleneck Theory（瓶頸論）]] 七層位置：
  - **第 3 層 InP substrate 加工**：MACOM 透過 IQE 11.5% 拿到 InP wafer 容量 anchor
  - **第 4 層雷射光源**：MACOM 跟 LITE / COHR / [[SIVE]] 形成 IC + module 互補
  - **第 5 層光收發器**：MACOM 提供 IC，不做整機 module（vs LITE / COHR 整機）
- 跟 [[NVDA]] 路線：
  - **間接綁定**（透過 LITE / COHR 模組賣給 NVDA）
  - NVDA Hyper Rail 1.6T 模組 ramp 結構性受惠（MACOM IC 在模組裡）
- 跟 [[AVGO]] / Marvell 關係：
  - 競爭面：AVGO Tomahawk 6 + Marvell DSP segment 也做 1.6T 模組 IC（不同位階：AVGO / Marvell 在 switch / DSP 層、MACOM 在 driver / TIA 層）
  - 互補面：MACOM 化合物半導體 IC + AVGO / Marvell 矽 IC = 1.6T 模組裡兩種 IC 互補
- 跟 [[Infineon]] / [[Wolfspeed]] / [[Navitas Semiconductor]] / [[Texas Instruments TXN]] 關係（GaN PA 軸）：
  - MACOM GaN MMIC + Power = 跟四家競爭 + 部分互補
  - MACOM 強在 RF / 5G / 國防 GaN MMIC（vs 800V HVDC power IC）
  - **不直接競爭 PoL / HVDC chip**（vs Infineon / Vicor 對手位）
- 跟美 DoD / 國防客戶關係：
  - **DARPA + Lockheed Martin + Northrop Grumman + Raytheon 主要國防 anchor 客戶**
  - 國防 / 雷達 MMIC IC 長期合約 = 穩定基本盤（vs 5G / 光通訊週期性）
- 護城河：
  - **化合物半導體 IC IP 深度**（GaAs / InP / GaN 三軸）
  - **6" InP MOCVD 自有 fab + 4" GaAs fab + Wolfspeed RF 業務併購**
  - **IQE 11.5% 戰略股東 + 長期 InP wafer 供應協議**
  - **美 DoD 國防 anchor 客戶 lock-in**
  - **跨光通訊 + RF + Power 三軸組合**（vs 純 photonic IC 競爭者）
- 風險：
  - **光通訊 IC 競爭**（AVGO Tomahawk DSP + Marvell DSP segment 部分重疊）
  - **InP wafer 上游成本上升**（IQE 雖綁定但 epi cost 仍受制 wafer ASP）
  - **GaN MMIC 規模仍小**（vs Infineon / TXN）
  - **5G CAPEX 週期性**（5G 設備出貨節奏波動）
  - **客戶集中於國防 / 模組廠**（單一大客戶風險）
  - **Wolfspeed Chapter 11 後 RF 業務整合 ramp 不確定**

## ⭐ MACOM 在「InP 鏈五家」位置

來自 [[AI infra CapEx 三階段論]] 第三階段 + [[Bottleneck Theory（瓶頸論）]] 第 3-5 層：

| 層 | 公司 | 位置 | 戰略入股關係 |
|---|---|---|---|
| **InP substrate**（第 3 層）| [[AXTI]] / Sumitomo Electric | 雙頭壟斷 80-90% | — |
| **InP epi foundry**（第 3-4 層）| **[[IQE]]** + LandMark Optoelectronics + VPE | 非 captive 三家寡占 | **MACOM 11.5% 戰略股東** |
| **InP IC 設計**（第 4-5 層）| **MACOM** + Marvell + AVGO | IC + driver / TIA | — |
| **InP 模組廠**（第 5 層）| [[Lumentum]] + [[Coherent]] | 自家 InP fab + 外部補位 | NVDA $4B 戰略入股（LITE + COHR 各 $2B）|
| **AI 模組買家**（第 5-6 層）| [[NVDA]] / hyperscaler | 1.6T 模組 30M+ units | NVDA 直接綁定 |

→ **重要 thesis**：MACOM 的 IQE 11.5% 入股 = **「InP 鏈第 3-4 層上游 lock-in」**、跟 NVDA 對 LITE / COHR $4B 入股的「**第 5 層模組廠 lock-in**」形成**上下游互補綁定**。整條 InP 鏈在 2025-2026 走「**雙向 lock-in 化**」（NVDA 鎖模組廠 + MACOM 鎖 epi foundry）。

| 軸 | 分數 | 理由 |
|---|---|---|
| **路線敏感度（逆向）** | **4 / 5** | 光通訊 + 國防 + Power 三軸組合 + IC 路線中性、扣 1 因 GaN / SiC 部分押 |

| **IP 控制** | **4 / 5** | 化合物半導體 IC IP 深度 + Wolfspeed RF 整合（vs LITE / COHR InP pure-play 弱 1 分）|
