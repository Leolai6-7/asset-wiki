# 奇鋐（3017.TW）

## 1. 一句話定位

**台廠液冷散熱規模王 + GB200 cold plate 全球市佔 50%+（4 大 CSP 主供）+ CDM(manifold) 4 大 CSP 主供 + NVDA Hopper/Blackwell/Rubin 三世代延續最大份額供應商**——跟 [[雙鴻]] 並列「**台廠液冷散熱雙頭**」（奇鋐強在 **cold plate 規模 + 4 大 CSP 直供** / 雙鴻強在 **CDU + 三鏈整合 + 1.6MW CDU IP**）、規模 + 認證 + 客戶集中度全勝、CDU 弱是 thesis 唯一缺口、[[AI infra 散熱戰場]] anchor **#2**。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**共識**」階段、跟 [[雙鴻]] 同步進入媒體層
- 機櫃功率密度 5 年 30kW → 1MW（**33x**）= 散熱**從零件升級為基礎建設**
- 2026 液冷滲透率衝 **76%**（券商估）+ 單櫃散熱產值跳升 **4 倍**
- 跟 [[AI infra CapEx 三階段論]] 第三階段同步：散熱是「**從 NVDA 設備往下游機櫃**」傳導 BOM 倍增戰場
- 跟 [[AI infra 電力戰場]]（孿生戰場）：奇鋐**無 power 軌**、純散熱賽道（vs 信昌電 / 台達 / Vertiv 雙軌）
- 在 [[資訊擴散四階段]]：已 ETF 化（單一股價 12M 漲幅 +200-300% 為散熱題材主導股、2025 EPS 估 35-40 元、外資調研頻繁）

### 目的層

- **業務組合**（FY2025 → FY2026 推估）：
  - **AI 伺服器散熱**：~60-70%（液冷產品 2024 ~15% → 2025 ~40% → 2026 衝 50%+）
  - **桌機 / 筆電 / 工作站散熱**：~25-35%（傳統 base + 高階電競 / 商用）
  - **遊戲機 / 車用 / 其他**：<10%
- **液冷產品全鏈**：
  - **Cold Plate（水冷板）**：銅基直接觸晶 GPU/CPU + 多 cold plate 整合（GB300 模式）+ Compute Tray 級客製化、**GB200 全球 cold plate 市佔 50%+ ⭐**（4 大 CSP 主供 / NVDA 認證 supplier）
  - **CDM / Manifold（分流管 + rack manifold）**：**4 大 CSP 主供**、北美 hyperscaler 直供管路系統 + sidecar CDU 框架
  - **CDU**：弱 / 整合度低（vs 雙鴻 1.6MW L2L IP 缺口、vs 台達 2.4MW/3MW 規模缺口）
- **AI server 客戶結構**：
  - **4 大 CSP 直供**：[[AMZN]] / [[Microsoft]] / [[Google]] / [[Meta]] cold plate + CDM
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 餵 NVDA + AWS Trainium + AMD MI300/MI400
  - **NVDA Hopper / Blackwell / Rubin 三世代延續最大份額供應商**（Compute Tray cold plate 主供、未公開具體比例）
  - **Apple 高階 MacBook Pro 散熱 mix-in**（消費級高階）
- **產能 + 擴張**：
  - **越南新廠 2025-12 開出**（產能 doubling）+ **泰國規劃 2026 開出**（cost-effective 多元）
  - cold plate 月產 ~50 萬顆 + 銅板 base 擴產（規模壓制 [[雙鴻]] 30 萬顆）
- 商業模式核心：
  - **「**台廠液冷散熱規模王 + cold plate 50%+ 全球市佔 + 4 大 CSP 直供 + NVDA 三世代延續**」**：規模 + 認證 + 客戶集中度全勝
  - **Compute Tray cold plate 整合**：跟 NVDA GB200 / GB300 多 cold plate 設計（6 個獨立 cold plate per Compute Tray）對齊 + Rubin 回大 cold plate 設計仍延續
  - **越南 + 泰國雙廠**：低成本擴產 + 規避地緣風險
  - **規模深度**：cold plate / manifold 高度集中（vs 雙鴻三鏈整合）
- 對應 [[賣水人選股邏輯（投資版）]]：**規模型液冷賣水人**——不押 NVDA / AMD / Trainium 誰贏、押**所有 1MW 機櫃 cold plate 都得用且都得認證**
- 對應 [[控制點轉移（投資版）]]：拿到「**4 大 CSP 直供 + NVDA 三世代延續 + Compute Tray 整合**」綁定 = 議價權**規模型結構性高於 [[雙鴻]] 純度型**（兩家不同 thesis）

### 供應層

- 跟 [[NVDA]] 路線：
  - **Hopper（H100）→ Blackwell（GB200 / GB300）→ Rubin（2026 H2）三世代延續 cold plate 最大份額**
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 間接餵 NVDA（具體比例未揭露、推估 30-50%）
  - 跟 NVDA universal QD 標準化對齊（雖然減少差異化）+ 45°C 冷卻液（從 32°C 升）
- 跟 [[雙鴻]] 對比（**核心對標**）：
  - **cold plate**：奇鋐 50%+ 市佔（4 大 CSP）vs 雙鴻 15-20%（Supermicro 主供）→ **奇鋐勝 2.5-3x**
  - **CDM / manifold**：奇鋐 4 大 CSP 主供 vs 雙鴻 27% rack manifold 全球市佔（UBS 估）→ **奇鋐市佔略勝、雙鴻數字更明確**
  - **CDU**：雙鴻 **1.6MW L2L 超前部署 IP** vs 奇鋐弱 → **雙鴻完勝**
  - **全鏈整合**：雙鴻 cold plate + manifold + CDU 三鏈 vs 奇鋐 cold plate + manifold 兩鏈 → **雙鴻完勝**
  - **客戶結構**：奇鋐 4 大 CSP 集中 vs 雙鴻 Supermicro + top 5 cloud + Rubin sample → **雙鴻分散勝、奇鋐質量勝**
  - **規模**：奇鋐市值 / 營收略大（5,000-8,000 億 NT vs 雙鴻 300-450 億）→ **奇鋐勝**
  - **2026 毛利率**：雙鴻衝 30%+ vs 奇鋐 25-30% 區間 → **雙鴻略勝**（客製化 sample vs 大量 cold plate）
  - → **「**奇鋐 cold plate 市佔王 + CSP 直供 + 三世代延續**」vs「**雙鴻 CDU IP + 三鏈整合 + 客製化高利潤**」分歧路線**
- 跟 [[Vertiv]] 對比：
  - 重疊：cold plate + manifold（Vertiv 2026-04 Strategic Thermal Labs 自製 cold plate）
  - Vertiv 走 hyperscaler turnkey、奇鋐**直供零件**——兩家**從客戶角度看為合作 + 競爭並存**
  - Vertiv 系統規模 + 服務 + 認證遠超奇鋐 → 兩家不正面對打
- 跟 [[台達電]] 對比：
  - 重疊：cold plate + CDU（台達多元 + power + 規模）
  - 台達電源 + 散熱整合勝、奇鋐純散熱規模勝
  - 兩家鏈條不同（台達 ODM 友好 / 奇鋐 CSP 直供）
- 跟 [[高力 8996|高力]] 關係：
  - 奇鋐 CDM 內部 BPHE 採購高力（高力台灣 9 成市佔）
  - 高力是**潛在供應商 + 不直接競爭**（同 [[雙鴻]]）
- 跟 Boyd / Eaton-Boyd / CoolIT 對比：
  - Boyd 規模略大 + Eaton 整合後 power 加持 + CoolIT IP（CHx2000 2MW / OMNI 4,000W）
  - 奇鋐速度 + 成本 + 4 大 CSP 直供認證勝（亞洲鏈優勢）
- 跟 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] 關係：
  - **AI server ODM 必經之路**：cold plate / manifold 採購奇鋐（4 大 CSP 直供 + ODM 雙鏈）
  - 跟 [[信昌電]]（MLCC）+ [[台達電]]（PSU）+ [[高力 8996|高力]]（BPHE）並列 ODM 鏈條零件供應商
- 護城河：
  - **GB200 cold plate 50%+ 全球市佔**（4 大 CSP 直供）
  - **NVDA Hopper / Blackwell / Rubin 三世代延續**（規格 + 認證 + 規模 lock-in）
  - **Compute Tray 整合能力**（多 cold plate 設計、GB200/GB300）
  - **越南 + 泰國雙廠**（低成本擴產 + 規避地緣）
  - **規模深度**（5,000-8,000 億市值 vs 雙鴻 300-450 億）
- 風險：
  - **CDU 弱**：缺 1.6MW L2L IP 大規格、未來面對 [[雙鴻]] / Vertiv / 台達 + Eaton-Boyd 規模化整合會被擠壓
  - **NVDA universal QD 標準化 + cold plate 互通**削弱供應商定價權
  - **Rubin 回大 cold plate 設計**（vs GB300 多 cold plate）削弱**奇鋐 Compute Tray 整合 IP 優勢**
  - **Vertiv Strategic Thermal Labs 併購 + Eaton-Boyd**形成國際 turnkey 對手收斂壓力
  - **4 大 CSP 集中度過高**（客戶 risk-adjusted 風險 < [[雙鴻]] 分散）
  - **散熱題材已部分 burn out**（12M 漲幅 +200-300%、Forward PE 已 25-35x）
  - **cold plate 價格戰**（亞洲 cost-effective 模式毛利率上限有限）
