# GlobalFoundries（NASDAQ: GFS）

## 1. 一句話定位

**全球 #3 純粹 wafer foundry（vs [[TSMC]] / [[Samsung Electronics]]）+ 特殊製程 specialty foundry（FD-SOI 22FDX + RF + 嵌入式 NVM + matured node）+ SiPho silicon photonics platform（與 [[Tower Semiconductor]] / [[TSMC]] / IMEC 並列全球能規模化生產 PIC foundry < 5 家）+ [[Ayar Labs]] 戰略投資人 + Mubadala 阿布達比主權基金 88% 持股**——[[Bottleneck Theory（瓶頸論）]] 第 4-5 層 SiPho foundry 對手位、跟 [[Tower Semiconductor]] / [[TSMC]] CoWoS / IMEC R&D 形成「**SiPho foundry 全球 4 強分食**」、是 [[Ayar Labs]] 矽光 chiplet 量產合作 foundry + NVDA NVLink Fusion ecosystem 上游 foundry、典型「**多元化特殊製程 foundry 賣水人**」（vs [[Tower Semiconductor]] 純 SiPho 純度首選）。

## 2. 三層 thesis

### 產業層

- 多賽道並行（每條都在 [[市場四階段：懷疑／驗證／共識／反轉]] 不同階段）：
  - **FD-SOI 22FDX**：成熟 + 共識（汽車 + IoT + RF + 5G/6G base）
  - **RF / 5G/6G**：成熟 + 共識（[[Apple]] + Qualcomm + MediaTek 客戶）
  - **嵌入式 NVM**：成熟 + 共識
  - **SiPho silicon photonics**：⚠️ **懷疑 → 驗證**（AI 光通訊 ramp、跟 [[Tower Semiconductor]] 並列 anchor）
  - **CMOS-SOI**（特殊製程）：成熟 + 共識（GE / IBM 派生）
  - **AI / hyperscaler**：客戶分散尚未爆發（vs [[Tower Semiconductor]] NVDA / [[Coherent]] 集中度）
- 跟 [[AI infra CapEx 三階段論]] **第三階段間接受惠**：
  - SiPho foundry 配套 1.6T 光模組 + CPO 整合
  - FD-SOI 22FDX 配套 AI edge + 5G/6G + IoT
- 跟 [[CPO 供應鏈圖譜]] / [[Bottleneck Theory（瓶頸論）]]：
  - **第 4-5 層 SiPho foundry 對手位**（vs [[Tower Semiconductor]] 並列 anchor）
- 跟 [[NVDA 網路 stack map]]：
  - **NVLink Fusion ecosystem 上游 foundry**（透過 [[Ayar Labs]] 量產合作）
- 跟 [[賣水人選股邏輯（投資版）]]：**多元化特殊製程 foundry 賣水人**（vs Tower Semi 純 SiPho 純度型）
- 在 [[資訊擴散四階段]]：機構 → 賣方層滲透深、媒體層尚未爆發（SiPho 業務在 GFS 占比仍 niche）

### 目的層

- **業務組合**（FY2025 預估）：
  - **Communications (Wireless + Wireline)**：~30%（5G/6G + WiFi + RF + Wireline）
  - **Smart Mobile Devices**：~25%（智能手機 + RFFE Qualcomm / MediaTek base）
  - **Automotive + Industrial + IoT**：~25%（汽車 ADAS + 工業 + IoT base）
  - **Compute & Wired Infrastructure**：~15-20%（AI edge + 嵌入式 + 部分 hyperscaler）
- **製程 portfolio**：
  - **FD-SOI 22FDX**：旗艦特殊製程（低功耗 + 高效能 + RF / Sensor 整合）
  - **40nm / 28nm / 22nm**：成熟 base
  - **CMOS-SOI**（180nm / 130nm / 65nm）：特殊 RF + 汽車 base
  - **SiPho silicon photonics**：GF Photonics 平台（與 Ayar Labs / Marvell / Cisco 合作）
  - **嵌入式 NVM / Flash**：car / IoT base
- **AI infra 曝險**：
  - **SiPho silicon photonics**：跟 [[Ayar Labs]] 矽光 chiplet 量產合作 + Marvell / Cisco 配套
  - **FD-SOI 22FDX**：AI edge + 邊緣 inference 配套
  - **RF / 5G/6G**：Nokia / Ericsson / 高通 5G/6G AI-RAN 上游
- **客戶結構**（全球分散）：
  - **Qualcomm**：5G/6G RF + 邊緣 inference base
  - **AMD**：Zen 系列 + 嵌入式 + AI edge 部分
  - **Apple**：Watch / iPhone RF + 部分 base
  - **[[Ayar Labs]]**：矽光 chiplet 量產合作（戰略投資人 + foundry）
  - **MediaTek + STMicroelectronics + NXP + Marvell + 多元 OEM**：全球分散
- **產能 + 擴張**：
  - **Malta NY**（紐約 Saratoga County、ex-IBM、12-inch）+ Dresden + Singapore + Burlington VT 多廠
  - **CHIPS Act 補助 $1.5B**（Malta NY 擴產、2024 簽）
  - **Mubadala 阿布達比主權基金 88% 持股**（穩定 long-term 持股 / 部分減持中）
- 商業模式核心：
  - **「**全球 #3 純粹 wafer foundry + 特殊製程 specialty + SiPho 全球 top 4 + 多元客戶分散**」**：規模 + 特殊製程 + 多元化三軸並重
  - **「**矽光 chiplet 量產合作 foundry**」**：跟 [[Ayar Labs]] 戰略 + foundry 雙引擎
  - **「**Mubadala 阿布達比主權基金 88% 持股 + CHIPS Act 補助 + 美國本土多廠**」**：地緣政治 anchor
  - **多元客戶分散**（規模化但跨多個 end market、無單一 client >15%）
- 對應 [[賣水人選股邏輯（投資版）]]：**多元化特殊製程 foundry 賣水人**——不押 NVDA / AMD / Apple / Qualcomm 誰贏、押**所有 specialty silicon 都需要**

| **製造產品（量子段）** | **cryo-CMOS controls**（低溫 CMOS 控制晶片）+ **advanced packaging**（先進封裝）+ **3D heterogeneous interconnects**（3D 異質整合互連）|
| **KP anchor 比喻** | 「**混凝土裡的鋼筋**」（rebar in concrete）= 必要但不搶眼 |

→ **「**多元化 specialty foundry 賣水人**」核心 thesis 強化**：GFS 在量子計算複製 SiPho 平台型基礎設施邏輯。

### 對 KP「3% 營收成長卻股價翻倍」隱含 thesis

KP 標題暗示「**Re-rate 三角形 reset**」、付費牆擋住具體深展：
- **3% 營收成長**——成熟製程 + 多元化 + 量子第二曲線剛 ramp、整體 top-line 成長慢
- **股價翻倍**——市場已開始 price in：**量子第二曲線 + 政府 1% 入股 anchor + Mubadala stability**
- 對應 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證 → 共識**」加速段：GFS 在量子段從「**懷疑 → 驗證**」、整體還在「**驗證**」段

### 對 [[CPO 供應鏈圖譜]] SiPho 段 — 付費牆擋住強化
