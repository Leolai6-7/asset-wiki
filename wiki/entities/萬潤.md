# 萬潤（6187.TW）

## 1. 一句話定位

**CoWoS / SoIC 後段封裝設備龍頭**（點膠 + 散熱貼合 + AOI 三條產品線、半導體設備佔營收 77-90%）；客戶集中 [[TSMC]] CoWoS + [[ASE]]/日月光；**CoWoS 三傑**（弘塑、辛耘、萬潤）裡**最靠近後段、最受惠 WoS 端產能擴張**的一家，2026 起新增 CPO / 矽光子點膠+貼合作為第二曲線。

## 2. 三層 thesis

### 產業層
- **CoWoS 製程鏈 WoS（Wafer-on-Substrate）後段**：點膠（Underfill / Dam & Fill / Flux Jetting）+ 散熱片熱壓貼合（Heat Sink Attach / Heat Clamp）+ AOI 檢測（Post-Die Bond / Post-Dispenser / Post-Bumping / Six-side）
- TGV 製程鏈**間接受惠**——TGV 玻璃中介層做完還是要回到 WoS 後段做點膠+散熱+AOI，所以**不論 TGV / 矽中介贏，都要過萬潤的後段機台**
- [[市場四階段：懷疑／驗證／共識／反轉]]：CoWoS 已在「成長爆發 + 共識形成」、CPO 在「驗證初期」
- 高盛預估 [[TSMC]] 2026-2028 CoWoS 產能 YoY **+89% / +95% / +27%**，達 127.5 萬 / 249 萬 / 315 萬片 → WoS 後段機台訂單同步放大

### 目的層
- **真正的「設備商」**（不是 service）——半導體設備佔營收 77-90%，純設備收入結構
- 三大產品線：
  - **點膠**：Underfill、Dam & Fill、Flux Jetting、Silver Paste（CoWoS-S 主要應用）
  - **貼合**：Die Bonding、Heat Sink Attach、Heat Clamp 熱壓合（散熱模組關鍵）
  - **AOI**：Post-Die Bond / Post-Dispenser / Post-Bumping / Six-side / Wafer AOI
- 主要客戶：[[TSMC]] CoWoS / SoIC（核心）、[[ASE]] 日月光（後段封測）
- **獨家供應部分關鍵機種給 [[TSMC]]**——後段點膠+散熱模組是 lock-in 性質
- 2026 新增第二曲線：**矽光子 / CPO 點膠+貼合+AOI**——已進入客戶 sample testing

### 供應層
- 「**WoS 後段近壟斷的賣水人**」——點膠+散熱+AOI 三段同時拿，國內缺乏對等競爭者
- 護城河：
  - 多年 [[TSMC]] CoWoS 線 design-in、機種獨家
  - 點膠精度 know-how（先進封裝對 underfill 容錯 < 微米級）
  - 設備交期短 = 客戶擴產時的「快反應供應商」（與弘塑/辛耘濕製程設備不同特性）
- 跟弘塑/辛耘的差異化：
  - **弘塑** = 跨蝕刻+電鍍+CMP **濕製程上游**，「化學品 + 設備」雙引擎、賣消耗品
  - **辛耘** = 濕製程 + 12 吋晶圓再生 + Intel 18A 代理「**三條腿賣水人**」
  - **萬潤** = WoS **後段封裝最後一哩路**，點膠+散熱+AOI **後段準壟斷** → 跟 CoWoS 出貨量同步、不依賴上游濕製程節奏
- → 連 [[賣水人選股邏輯（投資版）]]：三傑各據製程鏈一段，互為補強而非競爭分餅

### Re-rate 三角形
| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ **訂單能見度到 2027**、[[TSMC]] WoS 後段獨家 + CPO 第二曲線 |
| 毛利率 | ⚠️ **2026 Q1 從 60% 降到 51.78%**（產品組合稀釋）— 需追蹤是否能反彈 |
| OpEx | ✅ 控制中（自動化機台量產化、單機 ASP 高） |
| 營業利益 | ⚠️ Q1 EPS YoY -5.6%（短期承壓）但 4 月營收 YoY +26% = 訂單已轉強 |

→ **Re-rate 三角形 2/4**——故事最性感（訂單到 2027 + CPO 第二曲線 + 高盛目標翻倍三次），但**毛利率下滑**與 **Q1 EPS YoY 衰退**是真實警訊；買的是 2026 H2 - 2027 CoWoS 與 CPO 同時爆發的雙倍曲線。

### ✅ 催化
- [[TSMC]] 2026-2028 CoWoS 產能 YoY +89% / +95% / +27%（高盛）→ 直接放量
- **訂單能見度到 2027** = 結構性需求（不是短期搶單）
- 高盛目標價從 365 → 800 → 1,800 **三次大幅上修** = 外資完全翻多
- **CPO 矽光子設備已進入客戶驗證**（2026 sample testing）
- CPO 營收占比 2026 → 2028 從 3% → 69%（高盛預估）→ 第二曲線
- 4 月營收 YoY +26% = 谷底反轉訊號浮現
- 後段點膠+散熱+AOI **國內缺乏對等競爭者** → 高市占護城河

### ⚠️ 風險
- **毛利率 Q1 從 60% 跌到 52%**（YoY -8.66pp）——產品組合稀釋是否能逆轉？
- 2026 Q1 EPS YoY -5.6%（短期 EPS 仍承壓）
- **本益比 63-67 倍** = 已高度反映成長預期，回調空間大
- 高盛 1,800 元目標價基於先進封裝 + CPO 全面放量假設，**任一環節延後都會衝擊**
- **CPO 商業化時程不確定**——高盛 2026 預估 3% / 樂觀者 9%，若慢一年 PE 重估失敗
- 弘塑 / 辛耘同為 CoWoS 三傑——雖目前互補但未來可能往後段擴
- 直接 [[Intel]] / AMD / Broadcom design-in **未揭露**（僅透過 [[TSMC]] 鏈間接）
- 股價已從低點翻倍以上、技術面短期過熱
