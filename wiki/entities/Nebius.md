# Nebius（NBIS）

## 1. 一句話定位

**荷蘭 neocloud 新生公司 + Yandex 拆分後重啟 + 預售模式 vs CoreWeave 高槓桿模式對照 anchor + KP #42 提到 vs CoreWeave Q2 miss 對照**——2024-07 起源（從 Yandex N.V. 國際資產拆分、被迫從俄羅斯 Yandex 全球業務拆分後重新註冊在荷蘭阿姆斯特丹）、2024-11 NASDAQ 上市（IPO via reverse merger from Yandex N.V.）、現任 CEO **Arkady Volozh**（前 Yandex 創辦人 + CEO、烏克蘭出身科技創業者）；業務組合：**AI Cloud（NVDA H200 / B100 GPU 租賃 + AI training + inference workloads）+ TripleTen（AI 教育 / coding bootcamp）+ 中亞 / 東歐市場 + AVRide（自駕） + Toloka（AI training data）+ ClickHouse 部分業務**；FY2025 全年營收 **~$700-900M**（YoY +500%+ 從 ~$120M 級別爆增、AI cloud 業務帶動）+ Forward PE **n/a 仍虧損**（FY2025 GAAP 淨損 ~$300-500M、含 SBC + 折舊）+ 12 月 **+200-400%**（自 2024-11 IPO 後）；五軸 **15/25**（路線 4 + 站別 3 + 耗材 4 + IP 2 + 客戶分散 2）= 跟 [[CoreWeave]] 12 / [[Lambda]] 13 同 neocloud 賽道；**預售模式 vs CoreWeave 高槓桿模式對照 anchor**（FOMO SOC KP #42）：**Nebius 預售模式 EBITDA 45% / 營益較穩健 vs CoreWeave 高槓桿 EBITDA 56% / 營益 1%** = **neocloud 兩種商業模式分歧**；**結構性論點**：**Nebius 是「**重新出發的 neocloud + 預售模式紀律 + 中亞 + 歐洲地緣分散 + 不押 hyperscaler 單一 partner**」**（vs CoreWeave 100% NVDA stack + Microsoft 60%+ 集中）。

## 2. 三層 thesis

### 產業層

- neocloud 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——與 [[CoreWeave]] / [[Lambda]] 同處同階段，但 Nebius 處於「**全新出發 + 規模追趕**」階段
  - 不做 general purpose cloud（vs AWS / Azure / GCP）
  - 不做 retail（純 enterprise + AI native + 學術）
  - 只做 GPU 算力 + 配套 networking + training stack + 教育產品
- vs **[[CoreWeave]] / [[Lambda]] / Crusoe / Together AI**結構性差異（**「Nebius = 預售模式紀律 + 地緣分散 anchor」**）：
  - **歷史**：Nebius 2024-07 拆分 / 2024-11 上市 + 從 Yandex 國際業務重啟、新生 18 個月（vs CoreWeave 2017 / Lambda 2012、新生）
  - **規模**：FY2025 營收 $700-900M vs CoreWeave $5.5-7B vs Lambda 推估 $500M-1B = **跟 Lambda 同級別、CoreWeave 的 1/7-1/10**
  - **客戶結構**：Nebius 客戶分散 (Top 5 客戶 ~30-40%) vs CoreWeave Microsoft 60%+ + Top 3 90%+ = **Nebius 客戶分散度勝**
  - **採購策略**：Nebius NVDA H200 / B100 主力 + AMD MI300 部分 multi-source（vs CoreWeave 100% NVDA stack）
  - **網路 reference architecture**：Nebius 有 InfiniBand + Spectrum-X 雙路、不純 NVDA reference customer（vs CoreWeave NCP Elite + NVDA backstop）
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 2-3（IPO 後 18 個月、機構持股初步、ARK 部分持倉、12 月 +200-400% 主要散戶散戶 FOMO）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1-2 層客戶（非 anchor）
  - **2026 Q1-Q2** AI cloud 業務 ramp 加速（H200 + B100 部署 + 中亞市場擴張）
- 賽道結構性論點：
  - **「neocloud 預售模式」是 Nebius 主打 thesis**：客戶預付 → Nebius 蓋產能 → 較低財務槓桿風險 = 跟 CoreWeave 高槓桿模式分歧

### 目的層

- 業務 mix（FY2025、推估）：
  - **AI Cloud（NVDA H200 / B100 GPU 租賃 + training stack）= 70-75% 營收**
    - 客戶：AI native startup + 學術機構 + Fortune 500 部分（不直接競爭 Microsoft / OpenAI）
    - **H200 first wave + B100 升級加速**
    - **預售模式 + 中等期合約**（vs CoreWeave 5-7 年長約 $50B backlog）
  - **TripleTen（AI 教育 / coding bootcamp）= 10-15% 營收**
    - 全球 coding bootcamp + AI / data 教育平台
    - **跟 OpenAI / Anthropic 培訓服務有部分競合**
  - **AVRide（自駕）+ Toloka（AI training data）+ ClickHouse = 10-20%**
    - Yandex 拆分後保留的多元業務、屬於 legacy 部分
- 客戶結構（**比 CoreWeave 分散**）：
  - **Top 5 客戶 ~30-40%**（vs CoreWeave Top 3 90%+ 集中、Lambda Top 5 ~40-50%）
  - **AI native startup**：歐洲 + 中亞 + 部分美國 AI native 公司
  - **學術 + 研究機構**：荷蘭 + 北歐 + 中亞 + 部分美國研究機構
  - **Fortune 500 部分**：歐洲企業 + 中亞 + 部分日韓
  - **TripleTen 教育平台用戶 ~100,000+**（B2C + B2B）
  - **中亞市場 anchor**：哈薩克 + 烏茲別克 + 喬治亞 + 亞美尼亞 AI native 客戶獨佔
- 商業模式 = **「預售模式 + 中亞地緣分散 + 多元組合（雲 + 教育 + 自駕 + data）」**：
  - **預售模式**：客戶預付 → Nebius 蓋產能 → 較低財務槓桿風險 = 跟 CoreWeave 高槓桿模式分歧
  - **中亞地緣分散**：荷蘭 + 芬蘭 + 中亞 + 部分美國 DC 部署 = 跟 hyperscaler 全球佈局重疊度低
  - **多元組合（雲 + 教育 + 自駕 + data）**：vs CoreWeave / Lambda 純 GPU 雲、Nebius 有非雲業務 cushion
- → 連 [[賣水人選股邏輯（投資版）]]：**GPU 雲端「分散版 + 預售模式」受惠者**——vs CoreWeave 是集中 + 高槓桿、Lambda 是分散 + 私募、Nebius 是「**分散 + 上市 + 預售模式 + 地緣分散**」
- [[控制點轉移（投資版）]]：拿到「**Yandex 30 年 IP + Arkady Volozh 經驗 + 中亞市場獨佔 + 預售模式紀律**」四重 anchor，但**比 CoreWeave / Lambda 控制點外溢少**（無 NVDA backstop / NCP Elite tier）

### 供應層

- 跟 [[NVDA]] 關係（**non-aligned**）：
  - **NVDA H200 / B100 主力客戶**（first wave 採購、但規模較 CoreWeave / Lambda 小）
  - **NVDA NCP non-Elite tier**（NVDA Cloud Partner 但非頂級認證）
  - **無 NVDA backstop**（不像 CoreWeave $6.3B 安全網）= Nebius 結構性風險缺乏 NVDA 兜底
  - **NVDA Spectrum-X + Quantum-X 雙路部署**（vs CoreWeave 純 Spectrum-X）
- 跟 [[AMD]] / Intel 關係：
  - **AMD MI300 部分 multi-source**（vs CoreWeave 100% NVDA stack）
  - **Intel Gaudi 部分採購**（多 source）
  - = Nebius 路線敏感度比 CoreWeave 低（但客戶數少）
- 跟 hyperscaler 關係：
  - **不直接競爭 AWS / Azure / GCP**（neocloud 賽道）
  - **跟 hyperscaler 重疊度低**（中亞 + 荷蘭 + 芬蘭主場）
- 跟 [[Anthropic]] / [[OpenAI]] / [[Mistral AI]] / Stability AI 等 AI native 關係：
  - 客戶之一（部分）= Nebius 是 European AI native 訓練 cluster 之一
  - 但比 CoreWeave / Lambda 規模小、ramp 慢
- 護城河：
  - **Yandex 30 年 IP + Arkady Volozh 經驗** = Nebius 技術 + 管理 IP
  - **中亞市場獨佔**（哈薩克 + 烏茲別克 + 喬治亞 + 亞美尼亞）
  - **預售模式紀律**（vs CoreWeave 高槓桿）
  - **多元組合（雲 + 教育 + 自駕 + data）**（vs CoreWeave / Lambda 純 GPU 雲）
- 風險：
  - **規模小 + 新生 + 競爭加劇**：vs CoreWeave 規模差 7-10x、vs Lambda 規模類似
  - **NVDA 沒有 backstop**：Nebius 不享 CoreWeave $6.3B 安全網、結構性風險裸露
  - **股價 +200-400% 已 price in 多年完美 ramp**：any miss = 劇烈回檔
  - **AI native 客戶 churn 風險**：歐洲 + 中亞 AI native 公司若轉向 hyperscaler / 自建 → Nebius 客戶 base 萎縮
  - **hyperscaler 自家 ASIC 擠壓**：AWS Trainium / Google TPU 等切走 Nebius 部分客戶
  - **Yandex legacy 業務 wind down**：AVRide + Toloka + ClickHouse 部分業務 ramp 慢、可能拖累整體成長
  - **TripleTen 教育平台跟 OpenAI / Anthropic 培訓服務有部分競合風險**
  - **地緣政治風險**：俄羅斯來源 + 中亞市場 + 美國 / 歐盟監管雙重風險
- → 連 [[控制點轉移（投資版）]]：拿到「**預售模式 + 地緣分散 + 多元組合**」三重 anchor、但**比 CoreWeave / Lambda 控制點外溢少**（無 NVDA backstop / 非 NCP Elite）

| 客戶分散 | **2** | Top 5 客戶 ~30-40%（比 CoreWeave 90%+ 分散、比 Lambda 40-50% 略勝），但整體規模小 + 客戶數少 |

**總分：15/25**

→ **「預售模式紀律 + 地緣分散 + 多元組合 bet」**：Nebius 五軸 15/25 是 neocloud 三家最高分（vs CoreWeave 12 / Lambda 13）。**主因**：路線敏感（4/5 多 source）+ 耗材（4/5 預售模式）+ 客戶分散（2/5 Top 5 30-40%）三軸驅動。但**IP（2/5）落後**+ **站別關鍵（3/5）非 NVDA reference customer**仍是結構性弱點。**Nebius vs CoreWeave 預售 vs 高槓桿對照 anchor**：Nebius 是「neocloud 預售模式紀律」的 anchor 樣本。
