# Public Service Enterprise Group（NYSE: PEG / PSEG）

## 1. 一句話定位

**新澤西最大 utility（PSE&G、2.4M 電力 + 1.9M 天然氣客戶）+ 核電 fleet 3,750MW（Salem 1 / 2 + Hope Creek 二核電廠、共 3 機組）+ 海上風電 ramp（Ocean Wind 1 + 2 + Atlantic Shores、跨大西洋沿岸）+ utility 80% + 核電 + 海上風電三軌**——總部 Newark NJ、紐約證券交易所上市、市值 **USD ~$45-55B（Mid Cap）**；客戶覆蓋 **2.4M 電力 + 1.9M 天然氣 utility 客戶（新澤西）** + 核電 PPA + 部分 wholesale；FY2025 營收 **USD ~$11-13B** + EBIT margin ~15-20%（vs CEG 高毛利 / VST 高毛利、PSEG utility-anchored 低 beta 防守性勝）+ Forward PE **18-22x**（vs CEG 30-32x / VST 20-22x 中間定位）；是 [[AI infra 電力戰場]] **第一層電力產生 + utility 區域 anchor**（跟 [[Constellation Energy]] 22 對照 / 跟 [[Duke Energy]] 19 規模對照）；核電 3,750MW 是「**東岸 utility-anchored 核電 fleet anchor**」（vs CEG PJM IPP / VST 跨三 ISO IPP）= **utility 監管 + 核電 baseload 雙重 anchor**。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - PSEG 是「**utility 監管 + 核電 baseload + 海上風電**」三軌 anchor
  - 跟 [[Constellation Energy]] 22 對照：CEG 純 IPP + 32.4GW 核電 + Calpine 26GW 氣電、PSEG utility 80% + 3.75GW 核電 + 海上風電 ramp = **規模 8.6x 差距、結構性差別**
- 新澤西 + 大西洋沿岸電力市場：
  - PJM Interconnection 容量緊缺 + Northern Virginia data center 集中區外溢
  - 新澤西 + 賓州 + 紐約 data center 客戶持續增長
  - 美東海上風電：Ocean Wind 1（取消）+ Ocean Wind 2 + Atlantic Shores Wind 跨大西洋沿岸 ~2.5-3GW potential（但 2024-2025 海上風電多次延宕 + 取消）
- 對應 [[AI infra 電力戰場]]：**第一層電力產生 + utility 區域 anchor**（vs CEG 純 IPP 規模差別）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]：**部分滿足**（utility + 核電 baseload + 跟 hyperscaler 直接 PPA potential、但目前無大型 hyperscaler PPA 公開）

### 目的層

- 業務 mix（2025 為主）：
  - **PSE&G utility（regulated electric + gas）**：**~80%**（穩定低 beta + 監管收益）
  - **PSEG Power（核電 + 氣電 + 海上風電）**：~18-20%
  - **PSEG Long Island（不再 deconsolidated 2026）**：~0%
- 核電 fleet（**3,750 MW 三機組**）：
  - **Salem 1**（1,243 MW、商業運轉 1977、licensed 至 2036）
  - **Salem 2**（1,243 MW、商業運轉 1981、licensed 至 2040）
  - **Hope Creek**（1,264 MW、商業運轉 1986、licensed 至 2046）
  - 3 機組 PSEG 100% 持股 Hope Creek + 共同持股 Salem（PSEG 57% + Constellation Energy 43%）
- **AI / hyperscaler 直接 PPA 占未來營收占比**：
  - 2025：**0%**（無已公開 hyperscaler PPA）
  - 2030+：估算 ~5-10%（PJM 容量市場 + 後續 hyperscaler PPA 簽約潛力）
- 客戶結構：
  - **PSE&G utility 客戶**（2.4M 電力 + 1.9M 天然氣、新澤西 anchor）
  - **核電 wholesale**（PJM market + 部分 long-term contracts）
  - **海上風電 PPA**（NJ Board of Public Utilities OREC + utility 後續配對）
- 商業模式核心：
  - **utility-anchored 80%**（regulated 穩定 + 低 beta）
  - **核電 baseload anchor**（3,750MW 跨三廠）
  - **海上風電 ramp**（長期成長軸）
  - **跨 PJM 區域曝險**（新澤西 + 賓州 + 紐約 data center 客戶外溢）
- 對應 [[賣水人選股邏輯（投資版）]]：**「utility 監管 + 核電 baseload + 海上風電」三軌**（vs CEG / VST 純 IPP）
- 對應 [[控制點轉移（投資版）]]：拿到「**utility 監管收益 + 核電執照 + 海上風電 leases + 新澤西 regulated 區域 anchor**」四層控制權

### 供應層

- 跟 [[Constellation Energy]] 競爭 + 互補（**核電 anchor 對比**）：
  - **CEG**：32.4GW 核電 + Calpine 26GW 氣電 + 純 IPP 多 hyperscaler PPA
  - **PSEG**：3.75GW 核電 + utility 80% + 海上風電 + 新澤西 utility anchor
  - **Salem 廠**：PSEG 57% + Constellation 43% 共同持股 = **雙頭協作 anchor**
  - **規模差 8.6x**（CEG 32.4GW vs PSEG 3.75GW）= 結構性差別
  - PSEG = **utility 防守性勝**（PE 18-22 vs CEG 30-32）
- 跟 [[Vistra]] 對比：VST 41GW 多元 + Meta + AWS hyperscaler PPA、PSEG 無 hyperscaler PPA + utility 防守
- 跟 [[Talen Energy]] 對比：TLN 2.5GW 核電 pure-play + AWS 1.92GW PPA、PSEG 3.75GW utility-anchored
- 跟 [[Duke Energy]] 對比：Duke 30+GW utility + 6 核電廠 ~10GW、PSEG 3.75GW 核電 + 新澤西 utility = 規模 vs niche 對比
- 跟 [[GE Vernova]] / [[Siemens Energy]] 關係：海上風電 + 燃氣輪機 + 變壓器供應商
- 跟 [[AMZN]] AWS / [[Microsoft]] / [[Google]] hyperscaler 關係：
  - **無已公開 hyperscaler PPA**（vs CEG / VST / TLN）
  - 但 PJM + 新澤西 data center 客戶持續增長、後續 hyperscaler PPA 簽約潛力
- 護城河：
  - **新澤西 utility 監管收益**（穩定 ~80% 營收）
  - **核電 3,750MW fleet + Salem 共同持股 anchor**
  - **海上風電 ramp**（長期成長）
  - **PJM 容量市場 + data center 外溢**
  - **Forward PE 18-22x 中間定位估值**
- 風險：
  - **無 hyperscaler 20 年 PPA = 長期 narrative 弱**
  - **海上風電延宕風險**（Ocean Wind 1 已取消、Atlantic Shores 多次延後）
  - **核電老化 uprate**：Salem 1980s + Hope Creek 1986 建造、license 延長至 2036-2046
  - **新澤西 utility 監管風險**：Rate case 審核可能影響獲利
  - **PJM 容量市場改革**
  - **政治風險**：2028 政權更替
