# CXMT（長鑫存儲 / ChangXin Memory Technologies）

⚠️ **未上市 / 國家隊 anchor / 2026 H2 上海 IPO pending**：合肥本部，2026-05 通過上交所科創板 IPO 審核（傳擬募資 USD ~4.2B / KRW 6.5T），仍**不可直接買進**——是用來校準 [[SK Hynix]] / [[Samsung Electronics]] / [[Micron]] **中國敞口風險**的 reference entity，是 [[中國半導體國產替代（投資對沖視角）]] concept 的記憶體 anchor。跨庫對接 llm-wiki [[華為]] / [[幻方量化]] / [[DeepSeek]] / [[開源作為武器]] / [[控制點轉移]] 鏈條。

## 1. 一句話定位

**中國 DRAM 國產龍頭 + 國家隊背景非純商業公司 + 全球 DRAM #4（7.67% Q4 2025、12 個月內從 3.97% 翻倍）+ HBM3 國產化 anchor**——把「**DDR5-8000 / LPDDR5X-10667 量產 + HBM3 樣品已交付華為昇騰、2026 年底量產 + 中國市場 NVDA-banned 環境下唯一規模玩家 + 2026-05 通過上交所 IPO 審核 + 營收 YoY +700% 史上最快成長 DRAM 廠**」綁進同一個故事，作為**美國 AI 受惠 thesis（SK Hynix / Samsung / Micron HBM 結構性短缺）的中國市場對沖反證**。

## 2. 三層 thesis

### 產業層

- **不是純商業擴張、是「國家戰略性產能」**：合肥市政府初始 100% 持股 + 安徽省整合 + 大基金二期持股 + 2026-05 上交所通過科創板 IPO 審核（傳募 USD ~4.2B）= 國家級擴產 anchor、不依純資本回報邏輯
- **DRAM 排名**（2026 Q1 Counterpoint）：Samsung 38% → SK Hynix ~27% → Micron 22% → **CXMT 7-8%**（從 2024 Q2 3.97% → 2025 Q4 7.67% = 12 個月**翻倍**）⭐
- **DRAM 結構**：
  - **DDR5**（消費 + server）：已量產 16Gb / 24Gb、速度 8000 MT/s
  - **LPDDR5X**（手機 + AI edge）：12Gb / 16Gb、速度 10,667 MT/s
  - **HBM3**（AI accelerator）：樣品已交付華為昇騰 + 寒武紀 + 海光、2026 H2 - 2026 年底量產、計畫分配 ~20% 總產能（300k wafer/月）
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：「**驗證期**」——從「能不能做出」到「能做多大」+「規格距離 SK Hynix 多遠」階段
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體階段、但 **NVDA banned** 環境下西方分析師多以 reference 角度報導、中國境內機構配置才剛起步（待 IPO 後升級）
- TAM：HBM3 中國市場（華為昇騰 + 寒武紀 + 海光 + 阿里 PPU + 字節）約佔全球 HBM 需求 25-30%、被制裁逼出 = CXMT 結構性受惠

### 目的層

- 真實角色：**「中國半導體自主路徑的 DRAM anchor + 國家戰略反封鎖工具 + NVDA/SK/Samsung China revenue 的結構性對沖」**——不是賣給最高出價者、是「**填補 NVDA 被禁後中國 hyperscaler 與 AI accelerator 的記憶體需求空缺**」+「**作為地緣政治籌碼 + 國家半導體閉環的最後一塊拼圖**」
- 三軌業務：
  - **DRAM 主體（DDR5 / LPDDR5X）**：中國市場主導、Samsung + SK Hynix + Micron 已從低階退出留下空間、CXMT 接管中國消費 + server + AI edge
  - **HBM**（AI 自主路徑必需）：跟 [[華為]] 昇騰 950PR / 950DT / 960 / 970 路線圖綁定、跟 [[幻方量化]] / [[DeepSeek]] V4 中國軟硬閉環協同
  - **政策對沖**：美國 export control 升級時、中國 hyperscaler 必須轉向 CXMT = 自我加固的需求 anchor
- 商業模式核心：**「政府補貼 + 國家市場 + 戰略客戶（華為 + 寒武紀 + 海光） + 設備自主化（拓荊 / 中微 / 北方華創）」四重綁定**
  - 不算經濟性、算戰略性
  - 韓國產業界已警告：CXMT 進中國市場將「結構性侵蝕 Samsung / SK Hynix / Micron 中國敞口」
- [[控制點轉移（投資版）]]：拿到「**中國 DRAM / HBM 自主控制點**」+「**美國制裁籬笆內的封閉市場定價權**」+「**作為 NVDA / SK Hynix 中國敞口縮減的鏡像 anchor**」

### 供應層

- **是「**反美國 AI 受惠 thesis 的鏡像賣水人**」**——西方 wiki 賣水人邏輯（SK Hynix / Samsung / Micron HBM 結構性短缺）的**對沖配對**
- 護城河四層：
  - **國家戰略護城河**：合肥 + 安徽 + 大基金 + 上交所 IPO 通道、不會因短期虧損倒下
  - **客戶 lock-in（被制裁倒逼）**：華為昇騰 / 寒武紀 / 海光 / 阿里 PPU / 字節 ML accelerator = NVDA H100 / H200 / B200 / GB200 中國替代品鏈
  - **設備自主化**：拓荊（沉積） / 中微（蝕刻） / 北方華創（多軌） / Naura / Maxwell / U-Preseason（HBM 封裝設備）= 整鏈閉環
  - **規模成長性**：合肥 fab 規劃 300k wafer/月 + 北京廠 + 上海廠擴張、CapEx ~CNY 50-60B/年
- 跟 [[SK Hynix]] 領先程度：**HBM3 落後 2 代**（SK Hynix 2024 H1 量產、CXMT 2026 H2 - 2026 年底）+ **DDR5 落後 ~1 代**（速度 8000 vs SK 9600 MT/s）+ 製程 1Z / 1α 對 SK 1c
- 跟 [[Samsung Electronics]] 領先程度：**HBM3 落後 ~2 代**、**LPDDR5X 接近**（10,667 MT/s 與 Samsung 10,667 MT/s 同速但良率落後）
- 跟 [[Micron]] 領先程度：**規模 ~1/3**（CXMT 7.67% vs Micron 22%）、但**結構性對中國市場切位增加**
- 跟 [[YMTC]]（NAND 對應）關係：兩家分工——CXMT 主 DRAM / HBM、YMTC 主 3D NAND，**中國半導體記憶體閉環雙頭**
- 跟 [[華為]] 關係：**戰略客戶**——昇騰 950PR / 950DT HBM 主供應、昇騰 960 / 970 路線圖綁定
- 跟 [[幻方量化]] / [[DeepSeek]] 關係：DeepSeek V4 在華為昇騰運行 → 間接 HBM 需求拉動 → CXMT 受惠

### ✅ 催化（中國本土）

- **2026 H2 HBM3 量產**：跟華為昇騰 950PR / 950DT 配套、中國 AI 自主路徑首次拿到「**全鏈閉環**」記憶體 anchor
  - `as_of: 2026-06-09, check_after: 2026-12-09`
- **2026-05 上交所科創板 IPO 審核通過**：擬募資 USD ~4.2B，是中國半導體 IPO 史上最大之一
  - `as_of: 2026-06-09, check_after: 2026-12-09, expires_on: 2027-06-09`
- **DDR5 / LPDDR5X 國產化主導**：中國消費 / server 市場逐步 NVDA-banned 環境下 CXMT 接管 Samsung / SK / Micron 退出的低階空間
- **2027 HBM3 漲價週期**：跟全球 HBM 結構性短缺同步、CXMT 訂單能見度延伸 2027-2028
- **昇騰 950PR / 950DT / 960 / 970 路線圖鎖死**：跟著華為昇騰每代升級拉動 HBM 需求

### ⚠️ 風險

- **美國 export control 升級（EUV / DUV / 化學品 / EDA 軟體）**：CXMT 是中國 BIS Entity List 主要鎖定對象、設備鏈仍依賴美日設備、若進一步加嚴可能延後 HBM3 量產
- **HBM3 量產時程 slip**：2026-04 Digitimes 報導 CXMT 「commercialization timeline 面臨不確定性」（Digitimes 2026-04-21）
- **規格落後 SK Hynix 2 代**：HBM3 vs SK Hynix HBM4 / HBM4E、HBM3E 落差將進一步擴大、無法切入西方 hyperscaler 市場
- **IPO 上市後估值風險**：傳募 USD 4.2B / 估值 USD 35-40B，但**美國 ADR 退市 + 中國 A 股估值波動風險**
- **政策驅動 vs 商業驅動的張力**：政府補貼可能掩蓋真實 ROIC、IPO 後股價 vs 戰略目標可能衝突
- **CapEx 規模拉緊資產負債表**：CNY 50-60B / 年 vs 營收年化 CNY 100-150B，**經營性現金流仍負**
- **客戶集中度極高**：華為 + 寒武紀 + 海光 = 三家政策客戶、若任一家受挫（如華為制裁加嚴）整鏈衝擊
- **YMTC 風險訊號參考**：YMTC 因美國 Entity List 後**HBM 路線受阻**、CXMT 風險路徑類似
