# ABB（ABBNY / ABBN.SW）

## 1. 一句話定位

**全球電力與自動化雙料巨頭 + 變壓器 / switchgear 雙料寡占（跟 [[Hitachi Energy]] / [[Siemens Energy]] 全球三強壟斷 60-120 GVA TAM）+ NVDA 800V HVDC 31 家共同制定者**——總部蘇黎世（瑞士、1988 ASEA + BBC 合併）；事業群：**Electrification（電氣化）+ Motion（馬達 / 驅動）+ Process Automation（流程自動化）+ Robotics（機器人）**；2020-07 把 Power Grids（含變壓器 / HVDC）80.1% 賣給 [[Hitachi]] 成立 [[Hitachi Energy]] = **ABB 本體保留 distribution transformer / switchgear / 中壓配電**，剩 19.9% Hitachi Energy 股份 2022 完全出售；現在 ABB 變壓器主力是**配電變壓器 + 中壓 switchgear（11kV-72kV）**而非超高壓（500kV+）；2025-10 跟 [[NVDA]] / [[Eaton]] / [[Schneider Electric]] **共同制定 800V HVDC architecture standard**（31 家伙伴之一）= AI data center 主供應鏈；Q1 2026 營收 **~$8.4B（YoY +6%）**、Electrification segment Q1 organic +12%、operational EBITA margin **~19%**、orders backlog **~$23B**；股價 12 個月 **+35-65%**；是 [[AI infra 電力戰場]] **第二層「電力傳輸」+ 第三層「電力分配」雙層 anchor**（vs ETN 純第三層 / GEV 純第二層）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - ABB 跟 GEV / Eaton 同走 narrative：data center 電氣設備從週期股 → 結構性成長
- **變壓器 + switchgear 雙料壟斷（全球三強）**：
  - 大型 power transformer（200-500MVA、500kV+）：**[[Hitachi Energy]] + ABB + [[Siemens Energy]]**（ABB 在 2020 把超高壓段賣 Hitachi 後實質上是「Hitachi Energy 主場、ABB 配電 + switchgear」）
  - 配電變壓器（11kV-72kV、distribution）：ABB + Schneider + Eaton 等多家
  - 中壓 switchgear（4.16kV-38kV）：ABB + Schneider + Eaton 三巨頭
  - → ABB 在「**全壓段 switchgear** + **配電變壓器**」雙料、在「**超高壓**」段透過 Hitachi Energy 間接受惠
- 全球變壓器 TAM 結構性緊縮：
  - 大型 transformer 交期 **18-36 個月**
  - 全球年產能 ~60-80 GVA（Hitachi Energy / GEV / Siemens Energy / ABB / Mitsubishi 五巨頭）
  - **AI data center 新增需求 +30-50 GVA / 年** = 結構性短缺到 2028+
- 對應 [[AI infra 電力戰場]]：**第二層 + 第三層雙層 anchor**（distribution 變壓器 + switchgear + 800V HVDC 共同制定）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]**三標準全滿**：變壓器 / switchgear 物理產能緊缺 + 持續 CapEx + backlog $23B 鎖死

### 目的層

- 業務 mix（2025）：
  - **Electrification（電氣化）~40%**：配電變壓器 + switchgear + UPS + busway + EV 充電（**AI data center 主受惠**）
  - **Motion（馬達 / 驅動）~25%**：工業馬達 + 變頻器（**data center HVAC 馬達受惠**）
  - **Process Automation（流程自動化）~20%**：DCS / SCADA / 礦業 / 化工
  - **Robotics（機器人）~10%**：工業機器人（vs FANUC / KUKA）
  - **Other ~5%**
- **AI / data center 直接占比**：
  - Electrification segment 中 ~20-25% 來自 data center end-market
  - 整體 ABB ~10-12% AI direct exposure
- 客戶結構：
  - **Hyperscaler 直接**：[[Microsoft]] / [[AMZN]] / [[Meta]] / [[Google]]（規模分散）
  - **Colo 廠**：Equinix / Digital Realty
  - **電力公司**：歐洲 / 北美 utility（變壓器 + switchgear OEM）
  - **OEM**：跟 [[NVDA]] / OEM 整合方案
  - **工業客戶**：Process Automation / Robotics 多元
- 商業模式核心：
  - **Electrification 配電 + switchgear turnkey**：跟 ETN / SU 三巨頭
  - **800V HVDC 共同制定**：NVDA 31 家伙伴之一 = 規格控制權延伸
  - **Robotics + Process Automation cross-sell**：data center 建廠 + 工業自動化 + 機器人整合方案
  - **ABB Ability 軟體平台**：硬體 + 軟體 EMS recurring
- 對應 [[賣水人選股邏輯（投資版）]]：**電力 anchor 賣水人 + 雙層配電 + 跨工業多元版**——比 ETN / SU 更多元（機器人 + 自動化）、AI 純度稀釋但下檔保護強
- 對應 [[控制點轉移（投資版）]]：拿到「**配電 + switchgear + 800V HVDC + ABB Ability 軟體**」多段控制點

### 供應層

- 跟 [[NVDA]] 路線：**2025-10 共同制定 800V HVDC architecture**（31 家伙伴之一）
  - vs Eaton 首發 reference architecture / Schneider 整合平台 / ABB 偏 switchgear + 配電
- 跟 hyperscaler 路線：規模分散、歐洲市場主力（vs ETN 北美主場）
- 跟 [[Eaton]] 競爭：
  - **ETN**：800V HVDC reference architecture 首發 + turnkey 整合 + 北美 backlog 領先
  - **ABB**：歐洲 anchor + Process Automation + Robotics cross-sell + 配電變壓器
  - **ETN**：北美 data center turnkey 勝
  - **ABB**：歐洲 anchor + 工業客戶多元勝
  - → 不同地緣主場、互補大於競爭
- 跟 [[Schneider Electric]] 競爭：
  - **SU**：EcoStruxure 整合平台 + 軟體深 + 全球 data center power #1
  - **ABB**：Process Automation + Robotics 多元 + ABB Ability 軟體
  - **SU**：軟體 + 整合平台勝
  - **ABB**：跨工業 multi-segment 勝
  - → 各有優勢
- 跟 [[Hitachi]] / [[Hitachi Energy]] 特殊關係：
  - **2020-07 ABB 把 Power Grids（含超高壓變壓器 / HVDC）80.1% 賣給 Hitachi → Hitachi Energy**
  - **2022 ABB 全出售剩 19.9% Hitachi Energy 股份**
  - → 現在 ABB 在超高壓 transformer 段是 Hitachi Energy 的客戶 / 競爭對手關係（複雜）
  - **大型 transformer 200-500MVA 主場 = Hitachi Energy（前 ABB 變壓器部門）**
  - **配電變壓器 + 中壓 switchgear = ABB 本體**
- 跟 [[Siemens Energy]] / [[GE Vernova]] 競爭：
  - **GEV**：北美變壓器 #1（Prolec 整合）+ 燃氣輪機 + 風電
  - **Siemens Energy**：歐洲變壓器 + 燃氣輪機 + 輸電
  - **ABB**：配電 + switchgear + Process Automation + Robotics 多元
  - → 三家不同主場、共同擴大電力設備 re-rating
- 護城河：
  - **百年技術品牌**：1883 ASEA + 1891 BBC = 130-140 年技術累積
  - **全球供應鏈基地**：歐洲 + 北美 + 亞太多廠
  - **跨 segment cross-sell**：Electrification + Motion + Process Automation + Robotics 整合方案
  - **ABB Ability 軟體**：硬體 + 軟體 recurring（vs Eaton Brightlayer / Schneider EcoStruxure）
  - **800V HVDC 共同制定者**：NVDA 31 家伙伴
- 風險：
  - **2020 出售超高壓變壓器段給 Hitachi**：ABB 失去超高壓段成長機會
  - **Eaton + Schneider 北美 / 全球 backlog 領先**：ABB 配電 ramp 慢於 ETN / SU
  - **中國品牌進入**：上海電氣 / 西電 等 switchgear 價格戰
  - **Process Automation 景氣循環**：礦業 / 化工景氣對 PA 段直接衝擊
  - **Robotics 競爭**：FANUC / KUKA / 安川電機
  - **PE 25-28 倍 + 12 個月 +35-65%**：估值已 price in

## ⭐ 變壓器 + switchgear 雙料壟斷邏輯（補正：2020 後架構）

### 大型超高壓變壓器（200-500MVA、500kV+）

```
全球三強壟斷（年產能 ~60-80 GVA）：
1. Hitachi Energy（前 ABB Power Grids、2020 拆出）= 全球 #1
2. Siemens Energy（前 Siemens 變壓器部門、2020 拆分）
3. GE Vernova（前 GE Grid + Prolec GE 整合）= 北美 #1
```

→ **ABB 本體不在「大型 transformer」主場、透過早期持股 Hitachi Energy 間接受惠（19.9% 股份 2022 已出售）**

### 配電變壓器（11kV-72kV、distribution）

```
多家競爭，ABB 是其中一家：
ABB + Schneider + Eaton + Hitachi Energy + Siemens Energy + 多家中國品牌
```

### 中壓 switchgear（4.16kV-38kV）

```
三巨頭壟斷：
ABB + Schneider + Eaton（北美三巨頭）
```

⭐ **AI data center 需要的「電網入口 → 機房配電」全段 switchgear + 配電變壓器 = ABB 雙料受惠**

## ⭐ 跟 [[Hitachi Energy]] 關係（補正 2020 拆分）

**2020-07 ABB Power Grids 拆分時間軸**：
- **2018-12** ABB 宣布把 Power Grids（含超高壓變壓器 + HVDC）80.1% 賣 Hitachi

- **2022** ABB 完全出售剩 19.9% Hitachi Energy 股份

**現況分工**：
- **大型超高壓 transformer（200-500MVA、500kV+）**：Hitachi Energy 主場

- **配電變壓器 + 中壓 switchgear**：ABB 本體保留主場
- → **ABB 跟 Hitachi Energy 現在是「不同壓段的 sister-company」**

## pair trade / 配置建議

### 多 ABB（多元電氣 anchor）

**配置**：核心持倉、3-5% 配置上限（純度稀釋於 ETN）。

### 配對思路

**多 ABB / 多 ETN（歐美雙頭）**：
- ABB 歐洲 anchor + 多元 / ETN 北美 anchor + 純度
- 跨地緣電力 narrative 雙頭

**多 ABB / 空 Hitachi Energy 母公司**：
- ABB 雙層配電 + 工業 / Hitachi 母公司 conglomerate 折價
- 邏輯弱

**多 ABB / 空 Schneider（地緣 + segment）**：
- ABB 多元 + Robotics + Process Automation 勝
- SU 軟體 + 整合平台勝
- → 各有優勢、不適合對沖

→ **結論**：ABB 是衛星倉、跟 ETN / GEV 形成電力戰場跨地緣 / 跨層曝險組合。
