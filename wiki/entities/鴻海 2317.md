# 鴻海 2317（Foxconn / Hon Hai Precision）

## 1. 一句話定位

**全球最大電子代工龍頭 + AI server #1 代工（市佔 ~40-50%）+ GB200 NVL72 主代工 + AI cloud / edge 雙線**——1974 起源（郭台銘創辦、Tucheng 新北土城）、目前全球最大 EMS（Electronics Manufacturing Services）+ ODM（Original Design Manufacturer）、世界 500 強第 27 名、市值 NT$3.5 兆+；**從 iPhone 代工龍頭轉型 AI server / NVDA stack 整合廠**：2024-2026 大舉重 pivot AI server、NVDA GB200 NVL72 **主代工**（市佔 50-60%）、Blackwell Ultra HGX 主代工、AI server FY2025 營收占比 ~10% → FY2026 估 ~15-18%；vs 廣達 / 緯創 / 智邦 三大差異：(1) **規模壓倒**（年營收 NT$6 兆+ vs 廣達 NT$1.5 兆 vs 緯創 NT$1 兆 vs 智邦 NT$500 億）、(2) **GB200 主代工 + 子公司分立**（鴻佰 BiwinTech、富士康工業互聯 FII、各 AI server 子公司分立）、(3) **跨 AI cloud（server）+ AI edge（iPhone、[[Apple|Apple Inc.]] Vision Pro、Tesla Cybercab）雙引擎**；**[[AI infra CapEx 三階段論]] 第三階段台灣鏈條 anchor 整合廠**——把 NVDA stack 在台灣完成系統整合 + 量產 + 出貨到 hyperscaler / neocloud / OpenAI Stargate；郭台銘 2025-09 退休、Young Liu 劉揚偉接任董事長並打造「**鴻海 = AI infra system integrator**」轉型。

## 2. 三層 thesis

### 產業層

- AI server 賽道 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」加速段——鴻海從 iPhone 代工龍頭轉型 AI server 系統整合廠
  - 主軸 AI server 代工市佔 ~40-50%（FY2025、業界估）
  - 客戶結構：[[NVDA]] reference design 主代工 + Microsoft / Meta / Google / AWS hyperscaler 全棧 + Tesla AI6 + AI native cloud（Anthropic / OpenAI / xAI 部分）
- vs 廣達 / 緯創 三大代工差異：
  - **規模壓倒**：鴻海年營收 NT$6 兆+ = 廣達 NT$1.5 兆 + 緯創 NT$1 兆 + 智邦 NT$500 億 = 三家加總（NT$3 兆）的 2 倍
  - **客戶結構**：鴻海拿 NVDA reference design 主代工（GB200 NVL72 市佔 50-60%）、廣達 + 緯創拿次要部位（CSP 自家 ASIC + 部分 NVL72）
  - **業務 mix**：鴻海是 AI cloud + AI edge 雙線、廣達 / 緯創 偏 server 純 play
- **「鴻海 = AI infra system integrator」結構性論點**：
  - 不只代工、是「**設計 + 機構 + 散熱 + 電源 + 組裝 + 出貨**」全棧整合（NVDA reference architecture 落地）
  - **2024-08 Hon Hai Tech Day 公開：NVDA GB200 NVL72 主代工**（劉揚偉宣告、世界第一個公開揭示）
  - **2025-09 Tech Day 公開**：Blackwell Ultra HGX 主代工 + **Robotaxi（Tesla Cybercab）AI compute 主代工** + **[[Apple|Apple Inc.]] Vision Pro 第二代主代工**
  - **2026-04 自家公告**：AI server FY2026 估營收 +200% YoY、AI cloud 占比 FY2027 將達 ~25%
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 3-4（鴻海股價 12 月 +70-90%、機構持股 + 媒體頭條飽和）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 1 + 2 + 6 + 7 層 NVDA stack 整合 anchor
  - **2026 Q3** Rubin 平台首批出貨：鴻海是 NVDA Rubin first wave 主代工（與 GB300 同期）
- vs 廣達 / 緯創 / 智邦 三家代工龍頭的 AI server 站別差異：
  - **鴻海 = NVDA reference design 主代工（GB200 NVL72 市佔 50-60%、AI cloud 規模王）**
  - **廣達 = AI server #2 代工（Meta / AWS / Google 客戶 + DGX 系列主代工）**
  - **緯創 = AI server + GPU baseboard（Wiwynn 子公司主力 AI HPC）**
  - **智邦 = AI networking switch（白牌交換器 + Spectrum-X 鏈條台廠對接）**

### 目的層

- 業務 mix（FY2025 公司公告）：
  - **消費智能（含 iPhone、[[Apple|Apple Inc.]] Vision Pro）= 50-55% 營收**
    - iPhone 主代工（Apple 主要 OEM、市佔 60-70%）
    - [[Apple|Apple Inc.]] Vision Pro 第二代主代工
    - 大宗：智慧型手機 + 平板 + 穿戴
  - **雲端網路（含 AI server、雲端設備）= 25-30%**（**FY2026 預估升至 30-35%**）
    - **NVDA GB200 NVL72 主代工**（市佔 50-60%）
    - NVDA Blackwell Ultra HGX 主代工
    - Microsoft / Meta / Google AI server 代工
    - **FII（富士康工業互聯 6088.SH）**：AI server 主要子公司、上海上市
  - **電腦終端（PC、NB）= 10-12%**
    - HP、Dell 等 NB 代工
  - **元件及其他（含 EV、AI edge）= 5-10%**
    - **Tesla Cybercab Robotaxi AI compute 主代工**（2025-09 Tech Day 公開）
    - **MIH 電動車聯盟 + 鴻海自家 Foxtron 電動車**
- 客戶結構（高度分散）：
  - **Apple = #1 客戶**（iPhone + Vision Pro、長期 30%+ 營收占比、結構性 anchor）
  - **NVDA = AI server 最大 reference design partner**（GB200 + Blackwell Ultra + Rubin 全棧）
  - **Microsoft + Meta + Google + AWS**：hyperscaler AI server 全棧
  - **Tesla + [[Apple|Apple Inc.]] Vision Pro 第二代**：AI edge 雙引擎
  - **AI native cloud**：Anthropic / OpenAI / xAI 部分（透過 hyperscaler 間接）
- 商業模式 = **「EMS 規模 + ODM 設計 + 系統整合」三軌**：
  - **EMS 規模**：iPhone 等大宗代工、低毛利（~5-7%）、規模優勢
  - **ODM 設計**：AI server 設計 + 代工、高毛利（~10-15%）+ NVDA reference design 站別
  - **系統整合**：NVDA stack 全棧整合（散熱 + 電源 + 組裝 + 測試 + 出貨）、AI cloud anchor 客戶轉到鴻海買全套
- → 連 [[賣水人選股邏輯（投資版）]]：**「全 AI cloud / edge 系統整合賣水人」**——不押 NVDA / AMD / Intel 誰贏（鴻海三家都代工）、押所有 AI 系統都需要的整合 + 出貨
- [[控制點轉移（投資版）]]：拿到「**NVDA reference design 主代工 + Apple iPhone 30% 營收 + Tesla Cybercab AI edge anchor + AI cloud / edge 雙引擎 + FII 上海掛牌融資**」五重 anchor、但客戶集中（Apple 30%+ + NVDA Stack ramp 集中）+ 毛利率薄（EMS 5-7% / ODM 10-15%）兩個結構性弱點

### 供應層

- 跟 [[NVDA]] 關係（**GB200 NVL72 主代工 anchor**）：
  - **NVDA reference design 主代工**：GB200 NVL72 市佔 50-60%
  - **Blackwell Ultra HGX 主代工**（與 廣達 並列、鴻海 ~50%）
  - **Rubin first wave 主代工**（2026 Q3）
  - **NVDA-Foxconn 合作機制**：NVDA 設計 reference design、鴻海拿 design license → 在台灣 / 越南 / 美國威斯康辛廠 / 墨西哥 / 印度組裝
  - = **NVDA reference design partner 最重型台廠**
- 跟 [[Microsoft]] / [[Meta]] / Google / AWS 關係：
  - hyperscaler AI server 全棧代工（含 ODM 設計 + EMS 量產）
  - Microsoft Maia ASIC 部分代工
  - Meta MTIA ASIC 部分代工
  - Google TPU 部分代工
- 跟 Tesla 關係：
  - **Cybercab Robotaxi AI compute 主代工**（2025-09 Tech Day 公開）
  - Model Y / Model 3 部分零組件代工（透過鴻海集團多家子公司）
- 跟 Apple 關係：
  - **iPhone 主代工**（市佔 60-70%、長期 30%+ 營收占比）
  - **[[Apple|Apple Inc.]] Vision Pro 第二代主代工**（2026-2027 量產）
  - Apple AirPods / Apple Watch 部分代工
- 跟 廣達 / 緯創 / 智邦 關係：
  - **競爭**：AI server 代工互相搶單（NVL72 主代工 = 鴻海 vs 廣達 + 緯創 分立）
  - **互補**：智邦白牌交換器 + 鴻海 server 整合（部分 hyperscaler 訂單）
- 護城河：
  - **NVDA reference design 主代工 + GB200 NVL72 50-60% 市佔**
  - **iPhone 主代工 + Apple 30%+ 營收 anchor 長期穩定**
  - **AI cloud / edge 雙引擎（Tesla Cybercab + Vision Pro 第二代）**
  - **FII（富士康工業互聯 6088.SH）上海掛牌融資管道**
  - **全球 30+ 國家生產基地**（中國 + 越南 + 印度 + 墨西哥 + 美國 + 台灣）
- 風險：
  - **毛利率薄**：EMS 5-7% + ODM 10-15%、結構性低於 SaaS / IC 設計
  - **Apple iPhone 集中度**（30%+ 營收）：若 iPhone 銷量大跌、整體營收衝擊
  - **NVDA Stack 採購 ramp 集中**：鴻海 AI server 業務拉動 = NVDA 業務拉動、若 NVDA 賽道放緩 → 鴻海連鎖
  - **地緣政治**：美中科技戰、Apple 移到印度 + 越南、鴻海需重 pivot 產能
  - **接班過渡**：郭台銘 2025-09 退休、Young Liu 接任、過渡期不明
  - **股價 12 月 +70-90% 已 price in 多年 NVDA reference design 站位**
- → 連 [[控制點轉移（投資版）]]：拿到「**NVDA reference design + Apple iPhone + Tesla AI edge + AI cloud / edge 雙引擎**」四重 anchor、但「客戶集中 + 毛利薄 + 地緣政治」三重風險

| 軸 | 分數 | 理由 |

| 路線敏感 | **4** | 代工 NVDA + AMD + Intel + 自家 ASIC（Microsoft / Meta / Google）= 多路線都代工、middleground 中性受惠、但 NVDA 集中度高 |
