# 鴻勁 7769（鴻勁精密 HON. PRECISION）

## 1. 一句話定位

**全球 SoC 測試分選機（FT handler）龍頭 + ATC 主動式溫控 + 水冷板三軌**——Final Test（FT）與 System Level Test（SLT）測試分類機為核心、以**主動式溫控系統（ATC）**為技術護城河（AI 晶片千瓦級功耗下測試溫控 = 必經站）；2025 年底掛牌上市（台股近年指標級半導體設備 IPO）；2025 全年營收 **NT$302.7 億（+166.3%）**、毛利率 **56.54%**、稅後 **123.62 億（+133.9%）**、EPS **75.71**；營收結構：**分選機 42% + ATC 主動控溫 33% + 水冷板 23%**；AI／HPC／ASIC 訂單動能強勁、2026 產能擴充目標 30% 上修至 **40%+**；**下一步攻 CPO 測試技術**（數位時代 IPO 報導標題級 anchor）= SemiAnalysis「CPO 測試設備受惠者」名單中唯一台股 handler 廠。

## 2. 三層 thesis（簡版）

### 產業層
- AI 晶片功耗 700W → 1.5kW+ → **測試時的溫控（ATC）從加分項變成必需品**——高功耗晶片測試不控溫=測不準+燒機
- CPO 良率地獄（0.95³² ≈ 19%）→ known-good-engine 篩選 → 分選機＋溫控＋水冷板三軌全部受惠
- 跟 [[Teradyne]]／Advantest ATE 的關係：**互補不競爭**——ATE 測電性、handler 搬運＋控溫＋分選、綁同一條測試產線

### 目的層
- 三軌結構 = 測試產線「非 ATE 段」一條龍：分選機（42%）+ ATC（33%）+ 水冷板（23%）
- 客戶：OSAT＋IDM 測試廠（AI／HPC／ASIC 鏈）——NVDA 供應鏈測試需求為主要拉力
- 毛利 56.5% = 定價力證據（溫控 IP 不是大宗設備）

### 供應層
- 風險：AI 測試需求集中（大客戶集中度）、新掛牌估值熱度、Advantest／Teradyne 若垂直整合 handler、產能擴充 40% 的執行風險
