# Infineon（IFNNY / IFX.DE）

## 一句話定位（Sticky）

> **歐洲 #1 功率半導體 + GaN/SiC 雙料 + 跨汽車/工業/AI server 三軸最廣分散的電力轉換 IC 龍頭。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **共識期**（800V HVDC + EV 雙引擎）+ 部分驗證期（AI server 電源 IC）。

TAM：
- 功率半導體 $50B+（2025）
- GaN AI server $5-10B（2025-2030 CAGR 50%+）
- SiC EV + 工業 $10-20B（2025-2030 CAGR 30%+）

跟 [[Wolfspeed]] / [[Navitas Semiconductor]] 純押 GaN 或 SiC 不同，**Infineon 是雙料 + 類比 IC 三軸並進**。

### 目的層

不是純晶片廠、是「**電力轉換 + 馬達控制系統解決方案商**」。從 EV 整車 inverter 到 AI server 800V PSU 都做 IC + module 整套。

連 [[半導體基礎建設化]]：類比晶片 + 功率半導體從消費 IC 升級為「基礎設施元件」。

### 供應層

**賣水人**（[[賣水人選股邏輯（投資版）]]）。
[[控制點轉移（投資版）]]：8" SiC wafer 量產領先（2025 量產、領先 [[Wolfspeed]] 6"→8" 轉換約 1-2 年）。
