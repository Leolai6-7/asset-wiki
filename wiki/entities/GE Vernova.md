# GE Vernova（GEV）

## 1. 一句話定位

**全球電力設備龍頭 + 北美變壓器 + 全球燃氣輪機 #1 + 風電 + power-to-rack 整合**——2024-04 從 GE（百年企業）拆分而來、總部 Cambridge MA；**三大事業群**：**電力（Power）**（燃氣輪機 / 蒸汽輪機 / 核電 OEM / 水力）+ **風電（Wind）**（陸風 + 海上風電）+ **電氣化（Electrification）**（變壓器 / 開關 / 電網軟體 / EMS）；2026-02 完成 **$5.275B 全額收購 Prolec GE**（剩餘 50%）= **北美變壓器 #1 + 唯一 power-to-rack 整合方案 OEM**（從燃氣輪機 → 變壓器 → 開關 → 機架配電全棧供應）；Q1 2026 營收 **$9.3B（YoY +16%）** + 總 backlog **$163B**（Q1 alone +$13B）、Electrification 段 Q1 2026 拿 **$2.4B data center 訂單（>整個 2025 全年）**、Prolec 在收購宣布後 backlog +25% 至 **$5B**、**Gas Power backlog + slot reservation 從 83GW → 100GW**（FY 2026 末預估 ≥110GW，其中 20GW 直接綁 data center 客戶）；hyperscaler「healthy conversations 鋪到 2035」（CEO Strazik 法說）= 包括 [[Microsoft]] / [[AMZN]] / [[Meta]] / Crusoe；股價 12 個月 **+85-140%**；是 [[AI infra 電力戰場]] **三層分工中第二層「電力傳輸」的 #1 anchor**（變壓器物理瓶頸 + 燃氣輪機 production slot 排到 2030）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - GEV 從 2024-04 GE 拆分後 12 個月內 +85-140% = 完整 re-rate
  - 但 backlog $163B + Q1 +$13B / 季度 = **ramp 未完成、估值仍 5-7 年 backlog 內**
- 全球變壓器緊缺：
  - 大型 power transformer 交期 **18-36 個月** → 緊缺到 2028+
  - 美國 / 歐洲 grid 老化：60% 美國變壓器運轉 25 年以上
  - 中國變壓器產能巨大但**地緣風險 + 安全審查**限制進入美歐
  - → GEV / Hitachi Energy / ABB / Siemens Energy 寡占北美 / 歐洲變壓器 = **GEV 收 Prolec 後北美最大**
- 全球燃氣輪機緊缺：
  - GE / Siemens Energy / Mitsubishi Heavy Industries 三家全球寡占
  - **GEV 燃氣輪機 production slots through 2030 = 限制 ~10GW / 年新出貨**
  - GEV 100GW backlog → **平均 backlog 10 年** = 訂單能見度結構性高
- 美國 PJM 容量市場 + ERCOT 電力需求暴增 = 推升新電廠建設 = GEV 燃氣輪機 + 變壓器雙頭受惠
- 對應 [[AI infra 電力戰場]]：**第二層電力傳輸 #1 anchor**（變壓器 + 燃氣輪機 + power-to-rack 整合 = 唯一全棧 OEM）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]**三標準全滿**：物理產能緊缺結構性改變 + 持續 CapEx + backlog $163B 鎖死現金流

### 目的層

- 業務 mix（Q1 2026）：
  - **Power（電力）~50%**：燃氣輪機 + 蒸汽輪機 + 核電 OEM + 水力
  - **Electrification（電氣化）~25-30%**：變壓器 + 開關 + 電網軟體 + EMS（**Prolec 整合後成長最快**）
  - **Wind（風電）~20-25%**：陸風（GE Onshore Wind）+ 海上風電（Haliade-X）
  - **AI / hyperscaler 直接占比**：
    - Electrification 段 Q1 2026 拿 $2.4B data center 訂單（>整個 2025 全年）= 該段 ~33% 直接 AI
    - Gas Power backlog 100GW 中 **~20GW（20%）直接綁 data center 客戶**
    - 整體 AI 直接占營收估算 **15-25%** + 持續上升
- 客戶結構（hyperscaler / data center 客戶 明細）：
  - **[[Microsoft]]**：variable agreement 鋪到 2035（具體規模未公開、含燃氣輪機 + 變壓器）
  - **[[AMZN]] AWS**：variable agreement 鋪到 2035
  - **[[Meta]]**：variable agreement 鋪到 2035
  - **Crusoe**（AI cloud startup）：variable agreement 鋪到 2035
  - 傳統公用事業 / IPP：CEG、VST、Talen、Duke Energy 等（GEV 是 gas turbine 主供）
  - 其他工業客戶 / 政府電網
- 商業模式核心：
  - **唯一 power-to-rack 整合 OEM**（燃氣輪機 → 變壓器 → 開關 → 機架配電全棧一家供）
  - **燃氣輪機 production slot 寡占**（10GW/yr × 三家 = 全球 30GW/yr 物理上限）
  - **Prolec 北美變壓器 #1**（2026-02 全額併購、原 50% 持股、北美 hyperscaler 接單壓倒性優勢）
  - **服務 recurring 收入**（installed base 維護 + 升級 + 數位化監控）
  - **EMS（energy management system）軟體**：Q1 2026 拿 hyperscaler 首個 EMS 訂單、Q2 拿第二個 = SaaS-like recurring
- 對應 [[賣水人選股邏輯（投資版）]]：**電力設備賣水人之中的賣水人**——不押誰贏 AI、所有 hyperscaler / IPP / 公用事業擴建電廠都需要 GEV 燃氣輪機 + 變壓器
- 對應 [[控制點轉移（投資版）]]：拿到「**燃氣輪機 + 變壓器 + 軟體 + 服務**」四段控制點 = power-to-rack 整合 = NVDA 800V HVDC 之外的另一個 architecture 控制點
