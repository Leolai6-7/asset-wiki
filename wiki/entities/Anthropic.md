# Anthropic

Claude 開發商。**「安全 / 對齊」市場敘事的代表**。2026 用 MCP 把自己從「AI 模型公司」變成「**AI 作業系統公司**」。Anthropic 是 asset-wiki 最值得追蹤的 AI 公司——三條結構性論述同時發生。

## 三個結構性論述（2026 Q1-Q2）

### 1. 對齊稅 + 國安風險 → [[政府風險溢價（AI 公司）]]
- 2026-04-06：被美國列為**國安供應鏈風險**
- 根本原因：拒絕讓五角大廈無限制使用 Claude
- 折現率上升 → 估值壓縮

### 2. MCP = 接口控制權 → [[接口控制權]]
- MCP **9,700 萬安裝**
- 所有主要 AI 公司支援（OpenAI 也被迫加入）
- 已**捐給 Linux Foundation**（AAIF）→ 治理可信、生態擴張更快
- 控制點從「模型」拉到「協議」

### 3. AI 安全變高溢價賣點 → [[AI 資安攻防成本曲線]]
- Claude $4K 找 22 個 Firefox 漏洞
- 「安全」變成企業願意付溢價的賣點
- 是 model layer **守住毛利的 playbook**

## 估值與業務（2026-06-09 重大更新 via FOMO SOC KP #43-#44）

### ⭐ 2026-05 Series H + 雙引擎融資（KP #44 - 2026-05-30）

- **Series H $65B、估值 USD $965B**（**正式超越 OpenAI**）
- **$36B TPU 租賃融資**（via Apollo + Blackstone）+ **Broadcom 擔保**
- **資本分層典範**：股權（brain：R&D + 人才）vs 債務（muscle：硬體 rental）= 模仿成熟資本密集行業（航空 / 能源）
- **Supply chain source locking**：[[Micron]] + Samsung + [[SK Hynix]] 參與股權 → 鎖定未來 HBM 需求
- → 對接 [[AI 融資結構（條件資本）]] + [[AI 記憶體結構性供給短缺]]
