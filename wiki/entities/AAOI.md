# AAOI（NASDAQ: AAOI）

## 1. 一句話定位

**全球少數「laser chip → epi → 模組組裝」全垂直整合的光模組廠、北美 hyperscaler 唯一非中國 1.6T LPO 量產商**——1997 年成立於德州 Sugar Land（Houston 外圍）、創辦人 Thompson Lin 至今 CEO；起家是有線電視（HFC）光纖網路產品、2017 年起轉戰資料中心光模組、2025-2026 因 AI 算力 / Microsoft 1.6T 拉量徹底重定位為「**AI 互連 chokepoint**」；獨家特徵 = **Sugar Land 自家 wafer fab 設計 + MBE/MOCVD 雙製程生產 DFB / EML / CW DFB / Analog QAM 雷射晶片** → 自家 chip 進自家模組 → 不依賴 [[Lumentum]] / [[Coherent]] 等對手供 die；2026 年 Q1 **拿 Microsoft + Oracle 推測雙巨頭 $200M 1.6T 訂單 + $53M 800G 訂單**、CEO Thompson Lin 2026-05-07 法說明言「真實需求 $1.4-1.5B、$1.1B FY 2026 guidance 是被產能 cap 住」；廠房擴張：Sugar Land 從 350,000 sqft → 500,000 sqft + Houston-area 總計 900,000 sqft、2027 底前 laser fab 容量擴 ~**350%**；2026-03 啟動 **1.6T LPO transceiver 量產出貨** = 美國 hyperscaler 國家安全替代鏈關鍵棋子；是 [[Serenity]] **「**Bottleneck Theory 第 5 層 Optical Transceivers vertical integration 樣本」**Serenity 公開 7x 報酬**、市值 **USD $15.28B**、股價 12 個月 **+896%**、Forward PE 226.58（虧損中、靠未來轉盈定價）。

## 2. 三層 thesis

### 產業層

- **光模組賽道**處於 [[市場四階段：懷疑／驗證／共識／反轉]] **「驗證 → 共識」加速段**：
  - 1.6T 模組需求 **2025 1.8M units → 2026 30M+ units**（17 倍增量、與 [[IQE]] / [[Lumentum]] / [[Coherent]] 訊號一致）
  - AAOI 自家口徑：**actual demand $1.4-1.5B、guidance $1.1B 被產能 cap** = **賽道處於整體供不應求**
- **垂直整合稀缺性**：
  - 全球能做 in-house DFB / EML laser chip + 模組組裝的廠：[[Lumentum]] / [[Coherent]] / Innolight / AAOI
  - **AAOI 是其中 4 家裡規模最小、純度最高的**——不做其他業務（不做汽車 / 不做工業 / 不做國防）、純光模組 + 光晶片
  - 對比 OEM 模組廠（旭創 / Eoptolink）= 買 die 組裝、AAOI 自己做 die
- **地緣政治紅利**：
  - Sugar Land Texas 生產 = 美國國家安全 / CHIPS Act / 對中脫鉤 narrative 直接受惠
  - Microsoft 因國安考量會優先扶植美國本土光模組商（vs 中國旭創 / Eoptolink / 海信）
  - 2027 底前 laser fab 擴 350% = **美國本土光模組 anchor 投資**
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 **3-4**（股價 12M +896% 已過 KOL / 機構發掘段）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 5 層光收發器 anchor 之一
  - 2026-03 啟動 1.6T LPO 量產 = **與 Microsoft / Oracle 同步啟動 AI infra build-out 的 datapoint**
- vs [[Lumentum]] / [[Coherent]] / [[Marvell]]：
  - **AAOI 是 pure-play 光模組 + 光晶片**、Lumentum 還有 industrial laser、Coherent 還有 SiC + 國防
  - AAOI 五軸看起來缺「客戶分散」分（hyperscaler 集中）、補「vertical integration 純度」分
  - = **與 [[Lumentum]] / [[Coherent]] 是同層光模組、非直接競爭、是並列 top-3 美國本土光模組商**

### 目的層

- 業務 mix（FY 2025 → Q1 2026 mix shift）：
  - **Data Center = 主軸**（Q1 2026 $81.4M、YoY +154%、占整體 54%）
    - 100G：41%（CableTV legacy / lower-end）
    - 200G/400G：46.7%（主力營收源、Microsoft / Oracle ramp）
    - 800G：5.6%（$4.6M、Q1 首次 volume shipment 完成至 hyperscaler）
    - 1.6T：尚未營收化（2026-03 開始量產、2026 H2 起認列）
  - **CATV / HFC = 衰退中**（傳統業務、放手）
  - **Telecom = 小段**（中游 metro / access）
- 商業模式 = **「laser chip + transceiver 全垂直整合」**：
  - 不買 die 組裝、自家 wafer fab 做 DFB / EML
  - 不做工業 laser、不做 SiC、不做汽車
  - **客戶高度集中**：Microsoft + Oracle 推測 + 1-2 家其他 hyperscaler = 占 70%+ 營收
  - Microsoft 有 **ROFR（Right of First Refusal）** 機制 = 等於半綁定產能
- 客戶結構（公開度有限、推測為主）：
  - **Microsoft（Azure）**：10-K 明確點名 2025 主要資料中心客戶、ROFR 機制
  - **Oracle**：1.6T $200M 訂單市場推測歸屬
  - **Meta / Amazon / Google**：未明確點名、可能有少量 200G/400G 訂單
  - **Telecom 客戶**：Verizon / AT&T 等少量 metro
- 客戶集中風險：**top 1 客戶 > 40%、top 2 > 70%**（極端集中、若 Microsoft 改採旭創 / Lumentum 影響不對稱）
- → 連 [[賣水人選股邏輯（投資版）]]：**「laser chip + 模組雙層賣水人」**——不只押模組、押所有需要 InP DFB / EML 的光通訊鏈
  - 跟 [[IQE]] 的「epi wafer 賣水人」**是上下游關係**（IQE 賣 epi wafer 給 AAOI / 對手）
  - 跟 [[Lumentum]] / [[Coherent]] 是**同層橫向 vertical integration 對手**
- [[控制點轉移（投資版）]]：拿到「**美國本土光晶片 + 模組 + Microsoft ROFR**」三重控制點

### 供應層

- 跟 [[Lumentum]] / [[Coherent]] 關係：
  - **同層 vertical integration 對手**（三家都自家做 die）
  - AAOI 規模較小（市值 $15B vs LITE $64B / COHR $70B）、但**純度最高**（純 photonics）
  - 美國本土生產 + 對中脫鉤 narrative = AAOI 比 [[Lumentum]] / [[Coherent]] 更直接受惠 CHIPS Act
- 跟 [[IQE]] 關係：
  - **上下游關係**：IQE 賣 6" InP epi wafer、AAOI 用 epi 做 DFB / EML chip
  - 如果 AAOI 自家 fab 容量不足、可能向 IQE / LandMark / VPE 買補位（公開度有限）
- 跟 OEM 模組廠（旭創 / Eoptolink / 海信）：
  - **直接競爭**：OEM 模組廠在 hyperscaler 主軸市場直接搶單
  - 中國 OEM 模組廠成本優勢、AAOI 用「美國本土 + 國安替代」narrative 切美國市場
  - 旭創 / 新易盛 800G / 1.6T 出貨量遠大於 AAOI、但 hyperscaler 國安考量會降低中國模組進入度
- 跟 CPO 鏈：
  - 2026 起 AAOI 推 **ELSFP（External Light Source Form-factor Pluggable）** = 給 CPO 外部光源
  - = AAOI 進入 [[CPO 供應鏈圖譜]] 第 4 層 CW DFB laser sources 賽道
  - 跟 [[SIVE]] 在 CW DFB 路線**直接競爭**（[[SIVE]] 純 chokepoint、AAOI 是 vertical 補位）
- pump laser / EML / DFB epi 競爭地位：
  - **In-house DFB / EML chip**（Sugar Land wafer fab）
  - **MBE + MOCVD 雙製程平台**（業界少數）
  - **800G transceiver 月產能 ~100,000 units（2026 Q1 出口）**
  - **1.6T LPO 2026-03 啟動量產**（與美國 hyperscaler 同步）
  - 200G EML chip 業界 [[Lumentum]] 唯一量產、AAOI 走 LPO / 200G 路線並行
- 護城河：
  - **Sugar Land 美國本土 wafer fab + 模組產線**（不可移地、CHIPS Act 候選）
  - **MBE + MOCVD 雙製程 IP**（Thompson Lin 從 EMCORE 帶過來的累積、~30 年）
  - **Microsoft ROFR + 多年合約**（半綁定產能）
  - **2027 laser fab 擴 350% = anchor 投資**（hyperscaler 等不及自己做）
  - **ELSFP for CPO** = 進入第 4 層 CW DFB 賽道、補一層 option
- 風險：
  - **客戶集中度極高**：Top 1 > 40%、Top 2 > 70%、Top 1 異動風險不對稱
  - **產能 ramp 跟得上嗎**：FY 2026 guidance $1.1B 已被產能 cap、若延後執行 = thesis 失效
  - **EPS 仍虧損**：-$0.66 EPS、Forward PE 226.58 = 純 thesis driven、估值無 anchor
  - **中國 OEM 模組廠價格戰**：旭創 / Eoptolink 規模大成本低、若美國 hyperscaler 不再堅持本土、AAOI 訂單可能流失
  - **CPO 提前商用化**：2027-2028 若 CPO 取代 pluggable、AAOI ELSFP 賽道窄、模組營收結構性衰退（vs [[Lumentum]] / [[Coherent]] 在 CPO 鏈位置更廣）
  - **股價 12M +896%**：估值 price in 完美執行、any miss 都是劇烈回檔
- → 連 [[控制點轉移（投資版）]]：「**laser chip + 模組 + 美國本土 + Microsoft ROFR + ELSFP for CPO**」五重 anchor、但下游被 hyperscaler 集中度約束

## ⭐ Serenity 重押論述

[[Serenity]] (@aleabitoreddit) 將 AAOI 列為 **Bottleneck Theory 「核心持倉」**之一、自陳取得 **7x 報酬**（公開 X 推文記錄）。

### Serenity 對 AAOI 的 reasoning

從 [[Serenity]] 公開 X 推文 + Singularity Research Fund / Johnson Lee / PANews 整理：

1. **「frontran institutions with photonics with names like $AAOI, $AXTI, $LITE, $COHR」**（Serenity 原推、2025-2026）
   - **意涵**：AAOI 是「**機構大跌眼鏡前的散戶能搶先進場的 chokepoint 之一**」、跟 [[AXTI]] / [[Lumentum|LITE]] / [[Coherent|COHR]] 同列為光通訊鏈 chokepoint 配置
2. **「AAOI 的供應鏈是 laser → design → assembly → sells the transceiver = the whole supply chain」**（Serenity 原推）
   - **意涵**：**vertical integration 純度** = 從 laser chip 到模組到客戶 = 第 5 層 Optical Transceivers 最深 chokepoint
   - 對比 OEM 模組廠（旭創 / Eoptolink）只做 assembly、AAOI 拿到 laser chip + 模組雙重定價權
3. **「they're also building external light sources (ELSFPs) so they're entering the CPO side too」**（Serenity 原推）
   - **意涵**：AAOI 不只押今天的 pluggable transceiver、還押明天的 CPO 外部光源 = **跨層 hedge**（第 4 層 CW DFB + 第 5 層 transceiver 雙重 position）
   - = AAOI 是「**第 5 層 + 第 4 層雙跨垂直整合 chokepoint**」
4. **產能 cap = thesis 強化**：Serenity 解讀 CEO「actual demand $1.4-1.5B vs guidance $1.1B」= **產能 cap 證明 chokepoint 真實存在**（非估值游戲、是物理瓶頸）
5. **美國國安替代 = 政治紅利不可逆**：Microsoft 等 hyperscaler 不會把 1.6T transceiver 完全交給中國 OEM、AAOI 是**美國本土光模組鏈唯一現成可拿大單的 anchor**

### Serenity 配置邏輯（推測）

- **[[AXTI]]** = 第 1+3 層 raw materials + InP substrate = 最上游 chokepoint
- **AAOI** = 第 5 層 transceiver + 第 4 層 ELSFP 跨層垂直整合 = **中下游 chokepoint**
- **[[SIVE]]** = 第 4 層 CW DFB laser pure-play = 純 chokepoint 期權
- **[[TSEM]]** = 跨第 4-5 層 SiPho foundry = defensible compounder
- **[[AEHR]]** = 第 6 層 burn-in test = early-stage chokepoint
- → **Serenity 五家配置 = Bottleneck Theory 7 層的覆蓋型組合**（從原料到測試、層層配置 chokepoint）
