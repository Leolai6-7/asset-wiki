# Bloom Energy（NYSE: BE）

## 1. 一句話定位

**全球固態氧化物燃料電池（SOFC）龍頭 + AI 資料中心 firm power 第四選擇（核電 / 氣電 / 變壓器 / **SOFC**）+ 2026 產能 1GW → 2GW 翻倍 + FY 2026 營收上修至 $34-38 億 USD + 跟 [[高力 8996|高力]] anchor 客戶關係（熱反應盒 + 熱交換系統主供）**——總部 San Jose CA、創立 2001、2018-07 IPO；旗艦產品 **Bloom Energy Server（俗稱 Bloom Box）**：高溫 SOFC stack 直接把天然氣 / 沼氣 / 純氫轉成電（**不經燃燒**），效率 60%+、可 24/7 連續運轉、5-10 分鐘部署、PUE 接近 1；過去靠校園 / 零售 / 製造業 microgrid 緩慢增長、**2024-2025 AI 資料中心電力短缺催化 SOFC 採用率暴增** → 2026-Q1 hyperscaler / colo 新訂單成倍增長、Bloom 跟 [[Oracle]] / Equinix / Quanta / American Electric Power（AEP）+ 數家 hyperscaler 簽多個 GW 級供電合約；**hyperscaler firm power 第四選擇**：跟 [[Constellation Energy]] 核電 / [[Vistra]] 氣電 + 核電 / [[GE Vernova]] 變壓器 + 燃氣輪機並列、是「**最快部署 + 最分散位置 + 最不需電網接入**」的 firm power 路徑；2026 一年內產能從 **1GW → 2GW 翻倍**（San Jose + Fremont + 印度 Tirupur 三地擴產）、FY 2026 營收指引從 $31-33 億上修至 **$34-38 億 USD**（+25-30% YoY）、非 GAAP 毛利率上修至 **~34%**；**跟 [[高力 8996|高力]] anchor 客戶關係**：高力長期供應 Bloom **熱反應盒（hot box）+ 熱交換系統**（SOFC 核心組件、佔高力營收 ~40%）= **Bloom 訂單暴增 → 高力 SOFC 業務同步放量**；[[AI infra 電力戰場]] **第四選擇 firm power anchor**（跟 CEG / VST / GEV 並列）+ [[AI infra 散熱戰場]] 跨戰場上游（透過 [[高力 8996|高力]] BPHE 鏈）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段、Bloom 從「校園 / 零售 niche」升級為「hyperscaler firm power 候選」
  - 2024 之前：firm power 三選一（核電 / 氣電 / 變壓器）= Bloom 不在主流選項
  - 2025-2026：AI 資料中心電力短缺 + 核電復役延宕（CEG TMI 2028 才上線）+ 變壓器交期 2-3 年 → **SOFC 是「最快部署 + 最分散」第四選擇**
  - 物理優勢：SOFC 不需大規模電網接入、5-10 分鐘部署、可分散在每個機房旁邊 = 跳過電力傳輸瓶頸
- AI 資料中心 firm power 缺口（[[AI infra 電力戰場]] 三層分工視角）：
  - **第一層電力產生**：CEG 核電（2028 復役）+ VST 氣電（即時可用但 carbon 多）+ TLN 核電（2026 上線）
  - **第二層電力傳輸**：GEV 變壓器（2-3 年交期）+ Hitachi / Siemens / ABB HVDC（標準化中）
  - **第三層電力分配**：Eaton / Schneider 800V HVDC（2025-10 reference architecture 首發、2026-2027 ramp）
  - **第四選擇（補位）**：**Bloom SOFC**——分散式、快速部署、跳過電網瓶頸、24/7 firm power
- 對應 [[AI infra 電力戰場]]：**hyperscaler firm power 第四選擇 anchor**
- 對應 [[控制點轉移（投資版）]]：Bloom 拿到「**SOFC 規格制定 + 模組化部署 + 燃料靈活性（天然氣 / 純氫 / 沼氣三選）**」三段控制點
- 在 [[資訊擴散四階段]]：機構 → 賣方（**2025-2026 機構大量切入**、Trump 政府能源安全焦點）→ 媒體層滲透中（華爾街日報 + Bloomberg 多次點名）→ ETF 尚未

### 目的層

- **業務組合**（2025 → 2026 推估）：
  - **Bloom Energy Server（SOFC 主機）**：~80% 營收（hyperscaler / colo / industrial）
  - **服務 + 配件**：~15% 營收（recurring 維護合約、20 年 PPA-like 結構）
  - **電解氫 (Electrolyzer)**：~5% 營收（hydrogen 生產雙曲線）
- **核心產品 SOFC stack**：
  - 高溫陶瓷固體氧化物（>700°C）+ 鎳基電極 + 多片串聯成 250kW 模組
  - **燃料靈活性**：天然氣（甲烷蒸氣重整）/ 沼氣 / 純氫 / 氨氣（後者開發中）
  - 效率 60%+（vs 傳統燃氣輪機 50-55%）+ 無燃燒 = NOx / SOx / PM 排放接近零
  - **熱反應盒（hot box）+ 熱交換系統**：熱回收 + 控溫核心、**[[高力 8996|高力]] 全球主供**
- **客戶結構**（2026-Q1 新進）：
  - **Hyperscaler 直接**：Oracle Stargate 多個 GW 級訂單、Microsoft / AWS / Meta / Google 都在評估中
  - **Colo 廠**：Equinix 多年合約（IBX 資料中心採用）+ Digital Realty + Iron Mountain
  - **製造業 / industrial**：Quanta Services + American Electric Power（AEP）
  - **零售 / 校園 / 校院**（傳統業務）：~30-40% 營收（穩定基本盤）
- **2026 全年指引**：
  - 產能翻倍 **1GW → 2GW**（San Jose + Fremont + 印度 Tirupur 三地擴產 $100M+ CapEx）
  - 營收 **$34-38 億 USD**（上修自 $31-33 億、+25-30% YoY、vs 2024 $14 億 = ~2.5x）
  - 非 GAAP 毛利率 **~34%**（上修自 30%）
  - 預期 2026 全年 EBIT margin 接近正、GAAP EPS 轉正
- 商業模式核心：
  - **「**SOFC 龍頭 + 燃料靈活性 + 模組化部署 + 跳過電網瓶頸 + 24/7 firm power**」**
  - **規格控制權**：SOFC stack 化學 + 燃料 reformer 設計 + 熱回收 IP（高力供應的零件）
  - **服務 recurring**：客戶簽 20 年服務合約（mirror PPA 結構）= 長期現金流
  - **燃料靈活性**：天然氣 → 純氫過渡的「**橋接 platform**」、政治正確雙頭過關（carbon 過渡 + 純氫長期）
- 對應 [[賣水人選股邏輯（投資版）]]：**firm power 賣水人**（不押 NVDA / AMD / Trainium 誰贏、押**所有 AI 資料中心都缺即時 firm power**）
- 對應 [[控制點轉移（投資版）]]：拿到「**SOFC 規格定義 + 燃料靈活性 + 模組化分散部署**」三段控制點 = 從「校園 niche」升級為「hyperscaler firm power 標準」

### 供應層

- 跟 [[NVDA]] 路線：**間接綁定**（不直接賣給 NVDA、賣給 NVDA 客戶 hyperscaler / colo / neocloud）
  - hyperscaler 部署 Bloom SOFC → 餵 NVDA GPU → AI infra 完整鏈
  - Oracle Stargate 多個 GW 級訂單可能直接供 NVDA Vera Rubin 機櫃
- 跟 hyperscaler 路線：
  - **Oracle Stargate**：2025-2026 多個 GW 級訂單（Larry Ellison Stargate $500B 五年計畫的 firm power 核心）
  - **Equinix**：IBX 資料中心多年合約（colo 龍頭 anchor 客戶）
  - **AWS / Microsoft / Meta / Google**：均在評估中、預期 2026 H2 - 2027 首批正式合約
- 跟 [[Constellation Energy]] / [[Vistra]] / [[GE Vernova]] 對比（**hyperscaler firm power 第四選擇**）：
  - **CEG**：核電 + Calpine 氣電、規模 60GW+、**24/7 baseload 純度勝**、但 2028 才 TMI 上線
  - **VST**：核電 + 氣電 + 跨三 ISO 地緣分散、規模 41GW、**地緣分散勝**、需電網接入
  - **GEV**：變壓器 + 燃氣輪機、**設備供應商角色**、不持有電廠
  - **Bloom Energy**：**最快部署（5-10 分鐘）+ 分散式（不需電網大規模升級）+ 燃料靈活性（碳橋接）**——適合「2026-2027 急需 + 電網瓶頸地區」
  - → **不是零和、是互補**：CEG / VST 是「baseload + 長期」、GEV 是「設備」、Bloom 是「即時 + 分散」
- 跟 [[Eaton]] / [[Schneider Electric]] 對比（**第三層電力分配 vs 第四選擇 firm power**）：
  - **Eaton / Schneider**：800V HVDC reference architecture turnkey、要求電網接入 + 變壓器降壓
  - **Bloom**：跳過電網瓶頸、直接在機房旁邊產電 = 完全不同層級
  - → **Bloom 是「自帶電源」、ETN/SU 是「分配電源」**
- 跟 [[高力 8996|高力]] 關係（anchor 客戶 / 主供）：
  - **高力供應 Bloom 熱反應盒（hot box）+ 熱交換系統**（SOFC 核心組件）
  - 高力 SOFC 業務佔營收 ~40%（業務組合：燃料電池 ~40% + AI 液冷 ~20% + 傳統 BPHE ~40%）
  - **Bloom 2GW 翻倍 = 高力 SOFC 業務翻倍** → 高力 2026 1-5 月營收 +153% YoY 一部分驅動力
  - 「**hot box 是 Bloom 心臟、BPHE 是高力心臟**」共生關係
- 跟燃料電池對手對比：
  - **FuelCell Energy（NASDAQ: FCEL）**：MCFC（熔融碳酸鹽）路線、規模小、效率低於 Bloom SOFC
  - **Plug Power（NASDAQ: PLUG）**：純氫 PEM fuel cell（低溫）、移動 / 物流主場、不直接競爭 Bloom 固定式 SOFC
  - **Doosan Fuel Cell**（韓國）：PAFC（磷酸）路線、規模小於 Bloom
  - **Mitsubishi Power**（日本）：MEGAMIE SOFC、規模小且偏 utility 大型機組
  - → **Bloom 是全球 SOFC 唯一規模化龍頭**
- 護城河：
  - **SOFC 規格 + 化學 IP**：陶瓷材料 + 鎳基電極 + 燃料 reformer 設計（25 年累積 IP）
  - **規模 + 製造 know-how**：2026 1GW → 2GW = 全球 SOFC 唯一 GW 級量產商
  - **燃料靈活性**：天然氣 / 純氫 / 沼氣 / 氨氣多選 = 政治正確雙頭過關
  - **服務 recurring**：20 年服務合約 = 長期現金流 + 客戶綁定
  - **「**最快部署 + 分散式 + 跳電網**」差異化定位**
- 風險：
  - **歷史虧損 + 燒錢**：2018 IPO 以來累計虧損 $4B+、2024 首次接近 EBIT 正、2026 才可能 GAAP EPS 轉正
  - **股價已暴衝**：2024 $3-5 → 2026 $50-80+ 區間（推測）、Forward PE 50-100x（推測）
  - **碳橋接政治風險**：若 SOFC 跑天然氣不被歸類為 carbon-free → hyperscaler 採用受限（需配合 RNG / 純氫）
  - **氣電 / 核電復役加速**：若 VST 氣電 + CEG TMI 2028 提前上線 → Bloom 第四選擇 narrative 變弱
  - **客戶集中度**：Oracle Stargate 單一大客戶集中度高（推測 30%+ 訂單）
  - **製造瓶頸**：印度 Tirupur 新廠 ramp 進度未公開、若延後 → 2GW 翻倍時程延宕
  - **競爭威脅**：Mitsubishi Power MEGAMIE SOFC 量產進度可能切入 Bloom 部分客戶
  - **燃料價格波動**：天然氣價格暴漲影響 unit economics
