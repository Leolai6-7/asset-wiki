# Samsung Electro-Mechanics（KRX: 009150 / 삼성전기）

## 1. 一句話定位

**Samsung 集團「玻璃基板 + ABF 載板 + MLCC + 相機模組」四軌平台**——韓國 Samsung 集團旗下、與 Samsung Electronics 主體分離上市（**不是 Samsung Foundry 但是其封裝鏈生態夥伴**），全球 **AI FC-BGA 載板第一大量產玩家**（2026 ABF 產能已被 Alphabet/Tesla/Apple/AWS/Broadcom 鎖死預訂），同時建 Sejong pilot line 跑玻璃基板、與 [[AVGO]] 簽 sample 供應 + Apple **Baltra**（AI server chip）samples 已交付。在玻璃基板賽道是 [[Absolics]] 之外的另一條韓國軌道，由 Samsung Display + Samsung Electronics + SEMCO 三家構成 **「Triple Alliance」**——但量產時程比 [[Absolics]] 晚 1-2 年。

## 2. 三層 thesis

### 產業層

- **三軌並進的平台公司**：(a) **Package Solutions**（FC-BGA、AI 加速器載板）+ (b) **Components**（MLCC + 電感、AI server 受惠）+ (c) **Optics & Communication**（相機模組）+ 新長腿 (d) **Glass Substrate**（Sejong pilot + Sumitomo Chemical JV）
- 在 **AI FC-BGA 載板**站「全球唯三」量產（Unimicron / 欣興 / 揭碼）—— **2026 全年 ABF 產能已售罄**，客戶名單 = Alphabet（Google TPU）+ Tesla（Dojo/D2）+ Apple（M 系列 server）+ AWS（Trainium/Graviton）+ [[AVGO]]（custom AI ASIC）= AI 鏈最廣覆蓋
- 在**玻璃基板** [[市場四階段：懷疑／驗證／共識／反轉]]：「**驗證初期**」——pilot line 在 Sejong、prototype 出貨 [[AVGO]]（2025）+ Apple（2025-2026）、mass production **2027+**（落後 [[Absolics]] 約 1 年）
- 在 [[資訊擴散四階段]]：機構（韓國基金）→ 賣方（KB、三星證券）→ 西方媒體（TrendForce、KED Global、Tom's Hardware）三階段已擴散完成，目標股價已被分析師 cap 至 KRW 1M（已遠超）

### 目的層

- 真實角色：**Samsung 集團的「對外載板供應商」**（vs Samsung Foundry 是內部 fab）——這是關鍵區分：SEMCO 上市分離，可賣給 Samsung 之外的客戶（[[AVGO]]、Apple、AWS），這也是它能拿 Apple Baltra 訂單的根本原因（Apple 不會直接買 Samsung Electronics 主體做的東西）
- 商業模式三角：
  - **FC-BGA 載板**（當下現金牛）：Q1 2026 Package Solutions 段營收 KRW 725B、**YoY +45%**
  - **MLCC + Components**（穩定現金流）：Q1 2026 Components 段 KRW 1.41T、YoY +16%
  - **Glass Substrate**（長期期權）：與 Sumitomo Chemical + Dongwoo Fine-Chem 三方 JV、2027 量產
- 真實戰略：**「站滿整個 Samsung 集團的封裝鏈 + 站滿全球 AI ASIC 鏈（除 [[NVDA]] 之外）」**——NVDA 的 GPU 載板 historically 走 Unimicron（台灣 [[Unimicron]] 已供 [[AMD]] 樣品），SEMCO 主打 **Google TPU + AWS + Apple + Broadcom** 四大非-NVDA hyperscaler / fabless ASIC 鏈
- [[控制點轉移（投資版）]]：拿到「載板層的 panel-level fab 服務」+「玻璃基板技術 + Sumitomo JV materials」+ Samsung Triple Alliance 整合控制點

### 供應層

- **路線雙押**：FC-BGA（短期）+ Glass Core Substrate（長期），不像 [[Absolics]] 純 glass pure play
- 護城河四層：
  - **規模 + 客戶 lock-in**：2026 ABF capacity 售罄 + 5 大 hyperscaler/fabless 客戶綁定
  - **Samsung Triple Alliance**：Samsung Display（玻璃加工經驗）+ Samsung Electronics（HBM/Foundry/設計）+ SEMCO（substrate）整合鏈、Samsung HBM4 直接搭 SEMCO 玻璃載板
  - **Sumitomo Chemical JV**：日本玻璃 core materials know-how + Dongwoo Fine-Chem Pyeongtaek 廠 → 上游材料自主
  - **股價市值**：KRW 126-156T 市值（USD 90-115B），規模遠超 [[Absolics]] / [[LPKF]] / [[SCHOTT]] 所有對手
- 競爭格局：
  - **vs [[Absolics]]**（韓國 SK 集團）：Absolics 早 1 年量產、SEMCO 規模大 100 倍、客戶覆蓋廣 → SEMCO 後發優勢明顯
  - **vs Intel 自用線**：Intel 2025-08 開始 IP licensing → SEMCO 有可能也是被授權方
  - **vs Powertech 力成**（台灣，[[Powertech 力成]] AMD Zen 7 panel）：兩家在 panel-level 載板正面對撞，但目標客戶不同（PT 走 [[AMD]] / Micron HBM；SEMCO 走 Apple / Google / AVGO）
  - **vs 欣興 / 揭碼**（台灣 ABF 載板）：高階 FC-BGA 三強鼎立
- 風險：
  - 玻璃基板量產比 [[Absolics]] 晚 1-2 年 → 失先發優勢
  - 2026 ABF 已售罄 = 短期已沒 upside、純看 2027+ 玻璃放量
  - 估值已 expensive：Forward PE 78.7（與 Disco Corp 並肩）
  - Apple 是高度議價買方、SEMCO 訂單金額 + margin 受擠壓

## ⭐ 對台股 TGV 設備廠的意義

### bull case 對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]]

- SEMCO 自己**不做 TGV 設備、不做雷射改質、不做切割** → 它買 [[LPKF]] LIDE + [[Disco Corp]] 切割 + 蝕刻電鍍設備 → 台廠**設備層生意不直接受 SEMCO 衝擊**
- SEMCO 2027 玻璃量產 = AI ASIC 玻璃載板**結構性需求驗證** → derisk 整個 [[TGV 製程鏈圖譜]] 賽道、台廠 design-in 路徑被 derisk
- Apple Baltra 採用玻璃基板 = 消費電子也開始用玻璃 → 進一步擴大 panel-level 玻璃載板 TAM → 台廠中長期受惠
- [[AVGO]] / Apple / Google TPU / AWS Trainium 玻璃化 → [[雷科]] 厚板切割、[[弘塑]] 蝕刻、[[辛耘]] 濕製程、[[萬潤]] AOI 在這四鏈外的補充供應商 slot 仍存在
- 韓系 [[Absolics]] vs SEMCO 內鬥 → 雙方 ecosystem 投資**反而擴大**整體賽道 capex

### bear case 對台廠

- **SEMCO + Absolics 整鏈閉環風險**：韓國集團整鏈內製化（Samsung HBM4 + SEMCO 載板 + Sumitomo JV materials）→ **Samsung 鏈完全不需要台廠任何 8 站設備之外的服務**
- Apple Baltra 採用 SEMCO 載板 → Apple 鏈 panel-level interposer 落韓不落台 → 台廠 ([[東捷]] / [[日月光 ASE]] TPK pilot / [[Powertech 力成]]) Apple 鏈延伸機會被擋
- [[AVGO]] Broadcom 鏈韓國優先供應 → 台廠 AVGO 載板鏈被分食（[[Powertech 力成]] panel 仍可拿 [[AMD]] 鏈但 AVGO 機會被擠）
- SEMCO 規模 USD 92B 市值 + Q1 2026 OP +40% → **資金流向韓國載板廠 vs 台灣設備廠**估值倍率拉開
- SEMCO 採購 [[LPKF]] LIDE 設備 → 強化 LPKF IP 收入 → LPKF 反過來告 [[鈦昇]] 的法律 ammunition 增加

### 最大威脅 / 機會

**SEMCO 對 [[鈦昇]] 是「平行存在 + 間接威脅」**——不是直接競爭（SEMCO 是 fab 服務 / 鈦昇是設備供應），但：

1. **設備層**：SEMCO 採購 [[LPKF]] 設備 → 加大 LPKF IP 收入 → LPKF 法律戰能量增加 → 鈦昇 IP 風險上升（間接威脅）
2. **fab 服務層**：SEMCO 與 [[Absolics]] 雙韓系把 panel-level interposer fab 中游做到全球 100% → 台廠 OSAT（[[東捷]] 志聖聯盟整廠 turnkey）的策略**在 Apple/Google/AVGO 鏈被堵**
3. **客戶層**：Apple Baltra 選 SEMCO → [[鈦昇]] 雖然有 [[Intel]] Clearwater Forest design-in，但 Apple 鏈 panel-level 落韓 → 鈦昇延伸 Apple 鏈機會被擋
4. **規模對比**：SEMCO 市值 USD 92B vs 鈦昇市值 NT$ 約 200 億（USD 6 億）= 150 倍規模差 → 在 Apple/Google 客戶面前議價力天差地別

→ **總結：SEMCO 是「規模 + 客戶 + 集團整合」三重壓制的平行存在**，但**不在設備層搶鈦昇生意**。對 [[鈦昇]] 是「分食 fab 服務層機會 + 強化 LPKF IP 收入間接增加 IP 訴訟風險」雙重間接威脅；不是直接對撞。

### 五軸評分（對 [[鈦昇]] / 對台廠設備）

| 軸 | 分數 | 說明 |
|---|---|---|
| 路線敏感（FC-BGA / glass / HBM4 整合） | 5/5 | 三軌並進、Samsung HBM4 鏈直接整合、Apple Baltra 鎖死 |
| 站別關鍵（fab + 載板整合站） | 4/5 | panel-level FC-BGA + glass + interposer 全鏈、Sumitomo JV 補材料 |
| 耗材性（重複性需求） | 2/5 | 載板是製成品而非耗材、但 5 大 hyperscaler 重複訂單性質強 |
| IP 護城河 | 3/5 | 自有 FC-BGA know-how + Sumitomo JV materials know-how + 對 Intel licensing 受惠 |
| 客戶分散 | 5/5 | Alphabet/Tesla/Apple/AWS/AVGO 五大客戶 + Samsung 內部 + SK 對手 = 客戶覆蓋廣 |

**SEMCO 五軸 19/25**——僅次於 [[Disco Corp]]（21/25）、[[LPKF]]（20/25），位列「foreign competitor」第三高。對台廠設備廠的「分食威脅 + 規模壓制」結構性最強。
