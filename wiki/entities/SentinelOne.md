# SentinelOne（NYSE: S）

## 一句話定位（Sticky）

> **AI-native EDR / XDR pure-play、Singularity Platform 全自動化端點防護、CRWD 的開源 telemetry friendly 替代者、AI 資安 Endpoint 軌第二純度玩家。**

## 三層 Thesis（Sticky）

### 產業層

[[市場四階段：懷疑／驗證／共識／反轉]] **驗證期**——AI-native EDR 賽道在 [[CrowdStrike]] 30-32% 寡占下、SentinelOne 是「**second source 純度首選**」。

TAM：[[AI 資安戰場（CSP vs Endpoint vs Network 三軌）]] Endpoint EDR/XDR 段、SentinelOne 10-15% 市佔。

### 目的層

**「AI-native EDR pure-play + 開源 telemetry friendly」**：跟 CRWD Falcon Platform 28+ 模組對比，SentinelOne Singularity Platform 走「**簡潔 + AI 自動化 + open telemetry**」路線。

商業模式：100% SaaS + Singularity Platform 模組訂閱、ARR ~$850M+、NRR 110-115%。

跟 [[CrowdStrike]] 21 + Microsoft Defender 25-30% 競爭格局：SentinelOne 是「**second source 純度型替代**」（CRWD 客戶想分散 vendor 時的首選）。

### 供應層

**賣水人**（[[賣水人選股邏輯（投資版）]]）：AI 時代 endpoint 攻擊頻率倍增、SentinelOne 是 EDR/XDR 軌 second source 純度首選。
[[控制點轉移（投資版）]]：EDR/XDR 是 endpoint 防護 chokepoint、SentinelOne 在 second-source 心態下持續切走 CRWD / Symantec / 老牌 AV 客戶。
