# 敘豐（3485.TWO）

## 1. 一句話定位

**高階 IC 載板濕製程設備龍頭**（FCBGA/ABF 佔營收 >90%）、2026-05-06 剛上櫃；TGV 端的 VSP 複合蝕刻機（薄玻璃 <0.1mm 夾持系統）已在客戶端量產 + 取得台灣發明專利、MOON 軟體 3D 翹曲補償打入「台系封測大廠 + 美系晶片供應鏈」但**未具名揭露**；**客戶集中極高**（欣興+長安科技合計 >90%）= 雙面刃。

## 2. 三層 thesis

### 產業層
- 主業是 **ABF 載板濕製程設備**——FCBGA 是 AI 晶片、HPC、CPU 的標配
- TGV 製程鏈**第 2 站化學蝕刻**（VSP 複合蝕刻機，與 [[辛耘]] / [[弘塑]] 同站競爭，但定位「載板延續」）
- [[市場四階段：懷疑／驗證／共識／反轉]]：本業（ABF 載板）已在「成長爆發期」、玻璃基板/FOPLP 屬「樣品驗證」期
- **anchor 訊號**：載板三雄（欣興/南電/景碩）2026 顯著調升 CapEx → 訂單能見度已到 2027

### 目的層
- **從載板設備延伸到玻璃基板的「延續者」**——不是 TGV 純題材廠
- 三層延伸路徑：
  - **核心**：FCBGA/ABF 載板濕製程設備（>90% 營收）
  - **延伸 1**：VSP 複合蝕刻機 → 玻璃基板（薄玻璃 <0.1mm 夾持系統，已量產）
  - **延伸 2**：MOON 軟體 3D 翹曲補償（已打入台系封測 + 美系晶片供應鏈）
- 護城河：**Class 100 高潔淨度腔體** + **二次修整顯影技術**（高階 ABF 濕製程龍頭定位）
- → 連 [[賣水人選股邏輯（投資版）]]：載板賣水人 + 玻璃基板 option value

### 供應層
- **是「賣水人」也是「延續者」**——載板既有 know-how 直接套用到玻璃基板
- 50 件有效專利布局台、中、日、韓、美 → IP 護城河
- VSP 技術優勢：物理受力僅重力 + 浮力 = 適合 FOPLP 大面板/極薄載板/玻璃基板
- 風險：
  - **客戶集中極高**（欣興+長安科技合計 94%）= **單一客戶風險 binary**
  - 設備生意 = 一次性銷售、毛利率易隨產品 mix 波動
  - TGV 量產實績有但**未揭露 design-in 名單**
- → 連 [[市場四階段：懷疑／驗證／共識／反轉]]：適合等 2026-2027 法說會揭露 TGV 客戶名單再加碼

### Re-rate 三角形
| 項目 | 狀態 |
|---|---|
| 營收品質 | ⚠️ 訂單能見度到 2027、但**客戶集中 94%** |
| 毛利率 | ⚠️ **56% → 53% 已開始下滑**（2024 存貨回沖效應淡出） |
| OpEx | ✅ 控制良好（IPO 後體質清楚） |
| 營業利益 | ❌ Q1 EPS YoY **-30%** = 短期承壓 |

→ **Re-rate 三角形 1/4 滿**——買的是「ABF 載板放量 + TGV option」，但**剛上櫃 + 客戶集中 + Q1 衰退**讓進場時點要等。**適合追蹤、不急著進**。

### ✅ 催化
- 載板三雄 2026 顯著調升 CapEx → 訂單能見度到 2027
- 欣興間接打入 [[NVDA]] 供應鏈 → 敘豐間接受惠 AI 載板放量
- VSP 複合蝕刻機（玻璃基板 / FOPLP）已量產 + 台灣發明專利
- MOON 軟體 3D 翹曲補償已打入台系封測 + 美系晶片供應鏈（待揭露名單）
- TGV 玻璃基板 2026 樣品驗證 → 2027-2028 量產（option value）
- 已打入 [[TSMC]] 先進封裝（如 CoWoS）供應鏈
- 50 件有效專利 → IP 護城河

### ⚠️ 風險
- **客戶集中極高**：欣興+長安科技 94% = **binary outcome 風險**
- **剛上櫃 1 個月**（2026-05-06）→ 股價/PE 波動極大
- **2025 毛利率 56% 含存貨回沖一次性**——2026 Q1 已降到 53.21%
- 2026 Q1 EPS YoY **-30%**——短期業績承壓
- TGV / 玻璃基板 design-in **未揭露名單**——驗證期還很長
- 競爭：[[弘塑]] / [[辛耘]] 同站、敘豐 PE 56 vs 弘塑 62、辛耘 58 → 不一定有 catch-up 空間
- 設備生意一次性 → 不像化學品/晶圓再生有重複性
