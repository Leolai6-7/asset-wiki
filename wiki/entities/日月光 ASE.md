# 日月光 ASE（3711.TW / NYSE: ASX）

## 1. 一句話定位

**全球最大 OSAT 龍頭 + [[TSMC]] CoWoS 「協力 + 分工」第一名**——透過子公司 SPIL（矽品）承接 NVIDIA CoWoP 開發、自有 FoCoS 平台 + 310×310mm FOPLP 全自動產線、跟 TPK 合作 2026 Q3 TGV pilot line。**不是 TGV 設備買方，是 TGV 量產整合方**。在「玻璃中介層 + 矩形面板 + 取代 ABF 載板」三條曲線上同時站位，是 CoWoS-S/L 之外**最完整的第二供應鏈**。

## 2. 三層 thesis

### 產業層
- 全球 OSAT 第一大、營收約 [[TSMC]] 10% 量級、市值約 NT$1.57 兆
- 賽道位置：[[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」過渡
  - CoWoS 已共識（NVDA 60% 鎖定、訂單 backlog 至 2027）
  - FOPLP / TGV 仍在驗證期（2026 Q3 pilot、2027 量產）
- TAM 三條曲線同時擴大：
  - 2026 先進封裝（LEAP）營收上修至 **>$3.5B（YoY +118%）**
  - 2026 ATM 毛利率 26-27%（vs Q1 26%）
  - 2027-2028 FOPLP / TGV / CoWoP 量產 = 第二波 re-rate
- 跟 [[Amkor]] 是「TSMC 二外包雙頭」（Amkor 拿 180-190k wafer / SPIL 拿 60-80k wafer 2026 年估計）

### 目的層
- **三段商業模式**：
  - **ATM（封測本業）** 75%：傳統封裝 + 測試，毛利率回升至 26-27%（AI mix 提升）
  - **LEAP（先進封測）** 14%（2026）→ 33%（2027）：CoWoS 委外 + FoCoS + FOPLP + CoWoP
  - **EMS（電子製造）** ~25%：iPhone 板級裝配、毛利率低但穩定現金流
- **真實角色**：不是「TGV 設備買方」，是「**TGV / FOPLP / CoWoP 量產整合方**」
  - 把 [[弘塑]] / [[辛耘]] / [[萬潤]] / [[鈦昇]] / [[雷科]] 的設備整合成產線、賺整合服務費
  - SPIL 主導 NVIDIA CoWoP 開發（Chip-on-Wafer-on-PCB，跳過載板）
  - 跟 TPK 中壢 pilot line 合作 TGV（2026-07 完工、2026 Q3 試產、2027 量產）
- 2026 資本支出 **$85 億美元**（2 次上修，21% 增幅）：$9B 廠房、$6B 機台
  - 高雄 K28 智慧工廠 2026 Q4 完工，類 CoWoS-L 產線驗證中
  - 310×310mm FOPLP 全自動產線 2026 完工

### 供應層
- **不是賣水人，是淘金者整合方**——這是跟 [[弘塑]]/[[辛耘]]/[[萬潤]] **完全不同的位置**：
  - 三傑賣設備 / 化學品 / 服務 → ASE 用三傑的東西組產線 → 賺整合服務費
  - 三傑 PE 58-67 倍（被當成熱題材）vs ASE PE 57 倍（被當成成熟封測）= **估值錯位**
- 跟 [[TSMC]] 是 **「協力 + 分工 + 局部競爭」三層關係**：
  - 協力：TSMC 把 CoW（Chip-on-Wafer）外包 = ASE 受惠 TSMC 產能瓶頸
  - 分工：TSMC 拿矽中介層高毛利、ASE 拿 RDL / 封裝 / 測試的中段
  - 局部競爭：CoWoP 跳過載板、FoCoS Bridge 走 EMIB 變體 = 不依賴 TSMC 製程
- 護城河：
  - **規模 + 客戶廣度**（NVIDIA / AMD / Broadcom / Apple / 高通全在客戶名單）
  - **地理多元化**（台灣 + 中國 + 韓國 + 美墨歐）→ 抗地緣風險
  - **跟 TSMC 多年量產級信任**（CoWoS 訂單 backlog 2027）
- → 連 [[賣水人選股邏輯（投資版）]] 的「**整合服務費**」變體：不是賣水，是用別人的水賣咖啡

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ LEAP YoY +118%、ATM 同時 +17% — 雙引擎 |
| 毛利率 | ✅ ATM 從 22% → 26-27%（AI mix + LEAP 拉升）|
| OpEx | ✅ CapEx $85B 高、但 LEAP 營收 $3.5B 撐得起 |
| 營業利益 | ✅ Q1 EPS YoY +85%、預期 Q2-Q4 持續 |

→ **Re-rate 三角形 4/4 滿**——跟 [[弘塑]]、[[德律]] 並列。但已被市場部分認知（PE 57 vs 三傑 60+）。

### ✅ 催化

- LEAP 營收 2026 YoY +118%（已 upgrade 一次）= 結構性 mix 提升
- 2027 LEAP 佔比 33%（vs 2026 14%）= 第二波 re-rate
- CoWoP / NVIDIA / SPIL **2027 量產**（領先 CoWoP-S/L 一個世代）
- TGV pilot 2026 Q3、量產 2027（TPK 合作 NT$5 億 + SPIL/ASE 整合）
- FoCoS 2026 H2 美/歐客戶 design-in（具體名單未揭露）
- 跟 [[Amkor]] 比，台灣供應鏈深 + 跟 TSMC 信任強 = 拿到 60-80k wafer 委外

### ⚠️ 風險

- **CapEx $85B 高 = 折舊壓力大**，若 2027 LEAP 不放量 → ROIC 壓縮
- 跟 [[Amkor]] CoWoS 委外瓜分（180-190k vs 60-80k）→ 不是第一順位
- **PE 57 已部分 priced in**（同業均 69.6 但 ASE 已是龍頭）
- EMS（電子製造）毛利率低，拖累整體 mix
- CoWoP / FoCoS / FOPLP / TGV 多路線並進 = 資源分散
- 跟 SPIL（矽品）整合的內部 friction（SPIL 拿 NVIDIA 訂單但 ASE 也想拿） = 投控架構複雜性

## ⭐ 對 TGV 投資 thesis 的位置

### TGV / 玻璃中介層 design-in 強度

ASE 是 TGV / 玻璃中介層 **整合方第一名**，但**直接 Intel / AMD / Broadcom design-in 仍 indirect**：
- **強**：跟 TPK 中壢 pilot line（2026 Q3）= 第一條台灣 TGV 整線
- **強**：FOPLP 310×310mm 全自動產線 2026 完工 = 為 TGV 矩形封裝鋪路
- **中**：SPIL 主導 NVIDIA CoWoP（跳過載板）= 玻璃基板的替代路線
- **弱**：直接 Intel EMIB / 玻璃載板 design-in 揭露有限（[[Amkor]] 拿 Intel EMIB 主合約）

### 跟 [[TSMC]] CoWoS 的關係：協力 / 分工 / 補位

**「協力 + 分工 + 局部競爭」三層**：

1. **協力（主軸）**：TSMC CoWoS 產能爆滿（2026 端 120-130k wafer），CoW 部分外包給 ASE/SPIL 60-80k wafer = ASE 受惠 TSMC 瓶頸
2. **分工**：TSMC 拿矽中介層 + CoW 高毛利、ASE 拿 RDL / 封裝 / 測試的中段 + EMS 後段
3. **局部競爭**：
   - **CoWoP（SPIL 主導）**= 取代 PCB 載板，繞過 TSMC CoWoS-L 路線
   - **FoCoS + FoCoS-Bridge** = 走 EMIB 變體，跟 TSMC InFO 同層競爭
   - **TGV pilot（TPK 合作）** = 預備玻璃中介層整線、不必經 TSMC CoWoS-X

→ ASE 不是替代 TSMC，是「**TSMC 高毛利保留下的中段補位 + 未來路線多軌押注**」。

### 估值定位（vs [[TSMC]] vs [[ASML]]）

| 公司 | PE | Re-rate 三角形 | 角色 |
|---|---|---|---|
| [[TSMC]] | ~22-25x | 4/4 | 製程定義者 |
| [[ASML]] | ~28-30x | 4/4 | 設備壟斷 |
| ASE | **57x** | 4/4 | OSAT 整合方 |
| [[弘塑]] | 63x | 4/4 | 賣水人（化學品 + 設備） |
| [[Amkor]] | ~38-40x | 待確認 | 美系 OSAT 二外包 |

→ ASE 估值**高於 TSMC / ASML 一倍 + 但低於三傑**——市場給的是「整合服務費 + 第二波 LEAP re-rate」雙重期權。
