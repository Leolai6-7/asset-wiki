# 高力（8996.TW）

## 1. 一句話定位

**台灣唯一大規模生產「真空硬銲板式熱交換器（BPHE）」廠商 + 台灣市佔 >90% + 全球前五大製造商 ~5.1% 市佔 + CDU 心臟級零件壟斷 + Bloom Energy SOFC 燃料電池 anchor 客戶 + 雙引擎雙爆發（AI 液冷 + 氫能燃料電池）**——AI 液冷散熱占比 ~20% 但成長最快 + 燃料電池 ~40%（Bloom Energy 主供）+ 傳統板式熱交換器 ~40%（熱泵 / 冷凍空調 / EV thermal）；**散熱戰場「賣水人之中的賣水人」**（CDU 不管誰做都要 BPHE）、跟 [[信昌電]]（800V HVDC MLCC）+ [[雙鴻]]（CDU + cold plate + manifold）+ [[奇鋐 3017|奇鋐]]（cold plate 50%+ + 4 大 CSP CDM 主供）組成「**800V HVDC 三角 niche specialist 賣水人**」籃子，[[AI infra 散熱戰場]] **niche specialist 唯一 anchor**。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**驗證 → 共識**」加速段、跟通用液冷 entity 同步但滯後 1 季（市場剛意識到 CDU 內部 BPHE = niche specialist）
- 機櫃功率密度 5 年 30kW → 1MW（**33x**）= 散熱**從零件升級為基礎建設**、**CDU 變成機房心臟**而 BPHE 變成 CDU 心臟
- 2026 液冷滲透率衝 **76%**（券商估）+ 單櫃散熱產值跳升 **4 倍** → CDU 需求 4 倍 = BPHE 需求 4 倍
- 跟 [[AI infra CapEx 三階段論]] 第三階段同步：散熱「**從 NVDA 設備往下游機櫃**」傳導的 BOM 倍增戰場
- 跟 [[AI infra 電力戰場]]（孿生戰場）：**Bloom Energy SOFC 燃料電池**是 hyperscaler 數據中心 firm power 解決方案（跟核電 + 氣電並列）、800V HVDC 機櫃驅動散熱需求
- **第二曲線**：氫能燃料電池（Bloom Energy 從 1GW → 2GW 翻倍至 2026 年底）= **AI 數據中心電力短缺直接催化 SOFC 採用率**
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體（媒體層滲透中、2026 Q1 EPS 6.54 元 + 1-5 月營收 +153% YoY 已上頭條、但細部技術差異仍在賣方層）

### 目的層

- **業務組合**（2025 → 2026 推估）：
  - **燃料電池**：~40%（Bloom Energy 主供 + 熱交換系統 + 熱反應盒）
  - **AI 液冷散熱**：~20%（CDU 內部 BPHE 主流產品、快速放量）
  - **傳統板式熱交換器**：~40%（熱泵 / 冷凍空調 / EV thermal management）
- **核心產品**：**真空硬銲板式熱交換器（Brazed Plate Heat Exchanger, BPHE）**
  - 透過真空高溫硬銲將數十至上百片不鏽鋼板焊接成密封式熱交換組件
  - **台灣唯一**大規模量產 + **全球少數**能做高品質
  - 應用範圍：CDU 心臟（液冷）/ 熱泵 / 冷凍空調 / SOFC 熱反應盒 / EV 電池冷卻 / 工業冷凍
- **散熱產品結構**：
  - **CDU 內部 BPHE**：採購方為 [[雙鴻]] / [[奇鋐 3017|奇鋐]] / [[台達電]] / [[Vertiv]] / Schneider / Eaton-Boyd 全球前列 CDU 廠
  - **CDM（液冷分流模組）+ 板式熱交換器**：自家整合產品
  - **CDU 整機**：從 BPHE 心臟向 CDU 整機升級的策略路徑（從心臟到系統）
- **AI server 客戶結構**：
  - **間接綁定全球 CDU 廠**：透過 [[雙鴻]] / [[奇鋐 3017|奇鋐]] / [[台達電]] / [[Vertiv]] / Schneider / Eaton-Boyd 餵 NVDA + hyperscaler
  - **不直接供 NVDA / hyperscaler**：屬於上游組件供應商
  - → **「散熱戰場的賣水人之中的賣水人」**：CDU 不管誰做、BPHE 都要採購高力（台灣 9 成市佔）
- **2026 全年指引**：營收 + 獲利**雙引擎放量**、AI 液冷 + 燃料電池一起往上走、富果直送預估 2026-2027 獲利倍數成長
- 商業模式核心：
  - **「**台灣 BPHE 90%+ 市佔壟斷 + 全球前五大 + CDU 心臟級零件 + niche IP 寡占**」**
  - **真空硬銲製程壁壘**：全球少數能做高品質、台灣唯一規模化、進入門檻極高
  - **雙引擎（AI 液冷 + 氫能 SOFC）**：對沖單一賽道風險、Bloom Energy 倍增產能提供基本盤
  - **從心臟到整機**：未來向 CDU 整機升級，可能跟 [[雙鴻]] / [[奇鋐 3017|奇鋐]] 部分競爭（目前互補）
- 對應 [[賣水人選股邏輯（投資版）]]：**「賣水人之中的賣水人」**——不押 NVDA / AMD / Trainium / Bloom Energy 客戶誰贏、押**所有 CDU 都要 BPHE + 所有 SOFC 都要熱反應盒**
- 對應 [[控制點轉移（投資版）]]：拿到「**台灣 BPHE 9 成市佔 + 全球前五大 + 真空硬銲製程 IP**」綁定 = 議價權**結構性高於下游零件廠**（沒有替代供應商）

### 供應層

- 跟 [[NVDA]] 路線：
  - **間接綁定**（透過 CDU 廠採購）：Rubin 1MW 機櫃 = CDU 大需求 = BPHE 大需求
  - 沒有 NVDA AVL 直接揭露
  - **CDU 心臟級零件**：Rubin 規格升級 = BPHE 升級（功率 + 耐壓 + 耐溫提升）
- 跟 [[雙鴻]] 關係：
  - 雙鴻 1.6MW L2L CDU 內部 BPHE **採購高力**
  - 高力是**潛在供應商 + 不直接競爭**
  - 雙鴻 → 高力的關係 = 系統商 → 心臟零件供應商
- 跟 [[奇鋐 3017|奇鋐]] 關係：
  - 奇鋐 CDU 內部 BPHE **採購高力**（奇鋐 CDU 仍補課中、BPHE 採購量隨 CDU 業務擴張）
  - 高力是**潛在供應商 + 不直接競爭**
- 跟 [[台達電]] 關係：
  - 台達 2.4MW/3MW L2L CDU + 4RU In-Rack CDU 內部 BPHE **採購高力**（推測）
  - 高力是**潛在供應商 + 不直接競爭**
- 跟 [[Vertiv]] / Schneider / Eaton-Boyd 關係：
  - 全球 CDU 廠 BPHE **潛在採購對象**（Vertiv 採購 Alfa Laval / 高力雙頭）
  - 高力可能透過國際 CDU 廠擴大全球市佔（從台灣 9 成 → 全球更高份額）
- 跟 Alfa Laval（瑞典上市）對比：
  - **全球 BPHE 龍頭**（>15% 全球市佔）vs 高力 ~5.1%
  - Alfa Laval 走 industrial 多元 / 高力 niche specialist + 雙引擎
  - 兩家**互補 + 部分競爭**（Vertiv 等可能雙頭採購）
- 跟 SWEP（Danfoss 子公司，瑞典）對比：
  - **全球 BPHE 前三**（與 Kelvion / 高力並列）
  - SWEP 強在 industrial cooling、高力強在 AI 液冷 niche 升級 + Bloom Energy
- 跟 [[信昌電]] 關係（**800V HVDC 三角賣水人**）：
  - 信昌電：800V HVDC PSU + BBU 大尺寸高壓 MLCC（10K+ 顆 / Rubin 機櫃）
  - 雙鴻 / 奇鋐：800V HVDC 機櫃液冷三鏈
  - 高力：800V HVDC 機櫃 CDU 心臟 BPHE
  - → **信昌電 + 雙鴻 / 奇鋐 + 高力 = 「800V HVDC 三角 niche specialist 賣水人」籃子**：MLCC（電源） + CDU + cold plate（液冷三鏈） + BPHE（CDU 心臟）= 跨越「電力 + 散熱」孿生戰場的台廠 niche specialist 組合
- **燃料電池 / Bloom Energy（第二曲線）**：
  - 高力長期供應 [[Bloom Energy]] **熱反應盒（hot box）+ 熱交換系統**（SOFC 核心組件）
  - Bloom Energy 2026 投資 $1 億美元擴產、年產能從 **1GW → 2GW**（2026 年底前翻倍）
  - Bloom Energy 2026 全年營收指引從 $31-33 億上修至 **$34-38 億**、非 GAAP 毛利率上修至 ~34%
  - **AI 數據中心電力短缺**催化 SOFC 採用率 → Bloom Energy 訂單暴增 → 高力 SOFC 業務同步放量
  - 跟 [[AI infra 電力戰場]]（[[Constellation Energy]] / [[Vistra]] / [[GE Vernova]]）並列「**hyperscaler firm power 解決方案**」
- 護城河：
  - **台灣 BPHE 90%+ 市佔壟斷**（全球前五大、~5.1% 全球市佔）
  - **真空硬銲製程 IP**：全球少數能做高品質、進入門檻極高
  - **CDU 心臟級零件**：沒有替代供應商、定價權強
  - **Bloom Energy SOFC anchor 客戶**：第二曲線基本盤
  - **雙引擎對沖**（AI 液冷 + 氫能 SOFC + 傳統熱泵 / EV thermal）
- 風險：
  - **2026 1-5 月營收 +153% YoY 已 price in**：股價已從 2025 起暴衝（12 月 PB 嚴重泡沫化分析）
  - **Alfa Laval / SWEP 國際大廠進入 AI niche**：可能切高力部分市佔（規模碾壓威脅）
  - **CDU 廠自研 BPHE**：[[雙鴻]] / [[奇鋐 3017|奇鋐]] / Vertiv 等可能自製、削弱高力心臟級壟斷
  - **Bloom Energy 客戶集中度高**：燃料電池業務單一大客戶風險
  - **PB 估值泡沫化**（913 理財估測站 12 月分析：6.7 分 / 題材好但 PB 嚴重泡沫化）
  - **市值小**（~NT$300-500 億區間，待校準）：流動性弱於上市大型股
  - **Rubin 量產時序延後 / CDU 規格收斂**
  - **真空硬銲產能擴張時程**：niche IP 雖強但產能擴張慢於 cold plate 廠

- **vs 規模王（[[奇鋐 3017|奇鋐]]）**：奇鋐是 cold plate / CDM 4 大 CSP 規模王、不在 niche specialist 籃子
- **客戶結構互補**：信昌（電源大廠 + BBU 大廠）+ 雙鴻（Supermicro + top 5 cloud + ODM）+ 高力（CDU 廠 + Bloom Energy）= 三家客戶不重疊
