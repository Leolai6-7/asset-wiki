# SUMCO（3436.JP / SUMCO Corporation）

## 1. 一句話定位

**全球矽晶圓 #2（~25% 市佔，跟 [[信越化學]] ~30% 並列雙頭壟斷 55-60%）+ 300mm 矽晶圓純 play + 跟信越化學形成「**日本矽晶圓雙頭壟斷**」結構 + AI capex driven 300mm 大尺寸晶圓結構性短缺最大受惠者**——1999 年由住友金屬礦山 + 三菱材料合資成立、東京證交所上市（3436.JP）、總部東京、主要 fab 在日本 + 印尼 + 美國；不做光阻劑、不做 pBN crucible、**只做矽晶圓**（vs 信越化學多元化），純度更高、純量級巨大；跟信越化學在矽晶圓賽道**不正面對打、共同壓制中國 [[GlobalWafers 6488|GlobalWafers]] / Siltronic（被併購後）**。在 [[Bottleneck Theory（瓶頸論）]] 是「**第 0 層 wafer 上游 anchor**」（任何 fab 任何 wafer 都要矽 substrate）、在 [[賣水人選股邏輯（投資版）]] 是「**真賣水人純度首選 + 全球矽晶圓雙頭壟斷另一頭**」。

## 2. 三層 thesis

### 產業層

- **全球矽晶圓市佔**（Q1 2026 業界推估）：信越化學（~30%）+ **SUMCO（~25%）**+ GlobalWafers（~17%）+ Siltronic（~11%）+ 中國新昇 / 中環股份（合計 ~10%）+ 其他 ~7%
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——
  - 驗證已完成：2024-2026 AI capex driven 300mm 結構性短缺、SUMCO + 信越雙頭規模 lock-in、印尼新 fab 量產
  - 共識未完成：市場仍把矽晶圓當週期商品（PB 估值法）、實際上 300mm AI / 先進製程 wafer 已脫鉤週期
- 在 [[資訊擴散四階段]]：機構 / 賣方深度覆蓋（jpm / Goldman / 野村 / 三菱 UFJ）、媒體層尚未爆炒（仍被當週期股）、ETF / 半導體 ETF 大量持倉
- TAM：300mm 矽晶圓市場 2024 USD 9.5B → 2030 USD 17B+（CAGR ~10%）；AI capex driven 結構性短缺；台積電 / Samsung / Intel / GlobalFoundries 全部要採購
- 跟 [[AI 記憶體結構性供給短缺]] mirror image：**矽晶圓上游同樣結構性短缺**、雙頭壟斷議價權強化
- [[Bottleneck Theory（瓶頸論）]] 視角：SUMCO + 信越化學 = **矽晶圓雙頭壟斷 chokepoint**（任何 fab 都要、雙頭定價、無真實替代）

### 目的層

- 真實角色：**「全球矽晶圓 #2 + 純度最高的矽晶圓 pure-play + 日本雙頭壟斷另一頭」**——不是「綜合材料廠」（vs [[信越化學]] 三條腿：矽晶圓 + 光阻劑 + pBN crucible）、是「**純 300mm + 部分 200mm 矽晶圓製造商**」、靠「**晶體生長 IP + 製程 know-how + 規模 lock-in + 印尼 / 美國新 fab 產能擴張**」拿到全球 fab AVL
- 業務組合（FY2025 推估）：
  - **300mm 矽晶圓**：~70%（AI / 先進製程主力、SOI + epi wafer）
  - **200mm 矽晶圓**：~25%（成熟 + 特殊製程 / power IC）
  - **再生晶圓 / 其他**：~5%
- 商業模式：純度導向、不做下游、與信越化學差異化
  - 信越化學：矽晶圓 + 光阻劑 + pBN + PVC + silicon 多元 → 多賽道分散
  - SUMCO：**只做矽晶圓**（300mm + 200mm + 部分 SOI）→ 純度高、規模大、ASP 受 AI driven 上升
- 核心 IP / 護城河：
  - **晶體生長 IP**（Czochralski 製程深度 know-how）
  - **300mm 大尺寸 wafer 量產 know-how**（全球 < 5 家規模化生產）
  - **規模 + 客戶 lock-in**（[[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[GlobalFoundries]] / Micron / SK Hynix 全部 AVL）
  - **fab 地緣分散**（日本 + 印尼 + 美國 + 台灣）
- **AI capex driven 結構性短缺**（2025-2030）：
  - TSMC / Samsung / Intel 18A / Rapidus 2nm / GlobalFoundries 全部產能擴張
  - 300mm wafer 需求 2030 翻倍
  - SUMCO 印尼新 fab 2026 量產（增 30%+ 產能）
- 對應 [[賣水人選股邏輯（投資版）]]：**「真賣水人純度首選 + 全球矽晶圓雙頭壟斷另一頭」**——不押任何 fab / 任何客戶 / 任何技術路線、押**所有 fab 都要 300mm wafer**
- 對應 [[控制點轉移（投資版）]]：拿到「**全球矽晶圓 25% 市佔 + 日本雙頭壟斷 + 300mm 大尺寸 wafer 規模 lock-in**」三層 chokepoint、控制權結構性（vs 中國國產替代追趕）
- 對應 [[半導體基礎建設化]]：矽晶圓從週期商品升級為 AI infra 上游元件（PB 估值法 → Forward PE 估值法 migration）

### 供應層

- 跟 [[TSMC]] 關係：
  - 主供應商（TSMC 300mm wafer ~30-40% 來自 SUMCO 推測）
  - 跟信越化學雙頭分配 TSMC AVL
- 跟 [[Samsung Electronics]] / [[SK Hynix]] / [[Micron]] 關係：
  - **記憶體三大廠都採購 SUMCO + 信越**（雙頭壟斷分配）
  - HBM / DRAM / NAND 全部要 300mm wafer
- 跟 [[Intel]] / [[GlobalFoundries]] 關係：
  - Intel 18A / GlobalFoundries 22FDX / FD-SOI 都要 SUMCO 300mm 或 SOI wafer
- 跟 [[信越化學]] 關係（**核心對手 + 雙頭壟斷合作**）：
  - **不正面對打**（市場規模足夠分割）
  - 共同壓制中國 [[GlobalWafers 6488|GlobalWafers]] / Siltronic
  - 雙方都拒絕降價戰（雙頭穩定）
  - 信越多元化更深（光阻劑 + pBN + PVC）/ SUMCO 純度更高
  - **PB 比較**：SUMCO PB ~2-3x（純度型）/ 信越 PB ~3-4x（多元化）
- 跟 [[GlobalWafers 6488|GlobalWafers]]（6488.TW、台廠 #3）對比：
  - GlobalWafers ~17% 全球市佔（跟 SUMCO 差距 8pp）
  - GlobalWafers 走「**Siltronic 併購（被歐盟阻擋）+ 美國 / 義大利 fab 擴張**」追趕路線
  - SUMCO + 信越雙頭壟斷實質上**結構性壓制 GlobalWafers**
- 跟 Siltronic（德國、Wacker 子公司）對比：
  - Siltronic ~11% 全球市佔（#4、跟 GlobalWafers 競爭）
  - 2022 GlobalWafers 併購 Siltronic 失敗（歐盟阻擋）
- 跟中國新昇 / 中環股份對比：
  - 中國國產替代追趕、合計 ~10% 全球市佔、主供應中國 fab
  - 對 SUMCO + 信越壟斷有威脅 long term、short term 仍規模 + 製程落後
- 跟 [[Bottleneck Theory（瓶頸論）]] 第 1-3 層上游關係：
  - SUMCO = **第 0 層 matrix substrate**（任何 wafer 都要、是 Bottleneck Theory 7 層之前的層 0）
  - 跟 [[AXTI]] InP substrate / [[信越化學]] pBN 不同層、但同邏輯（單一 / 雙頭供應）
- 跟 [[AI infra CapEx 三階段論]] 三階段關係：
  - 第一階段（CSP 講 CapEx）：間接受惠
  - 第二階段（NVDA 落地）：間接受惠
  - 第三階段（上游材料爆掉）：**直接受惠**（300mm wafer 結構性短缺）
- 護城河：
  - **全球矽晶圓 25% 市佔 + 雙頭壟斷**
  - **300mm 大尺寸 wafer 規模 IP + 製程 know-how**
  - **fab 地緣分散**（日本 + 印尼 + 美國）
  - **客戶 lock-in**（fab AVL 切換成本極高）
- 風險：
  - **AI capex 見頂風險**（300mm 短缺紓解、ASP 回壓）
  - **中國國產替代 long term**（新昇 / 中環股份成熟製程切入）
  - **PB 估值法傳統認知**（市場仍把 SUMCO 當週期股、Re-rate 慢）
  - **匯率（日圓貶值）**：SUMCO 主收入日圓計價 / 客戶國際分散
  - **電力 / 能源成本**：晶體生長能耗極高、日本電價上升壓力

## ⭐ SUMCO vs 信越化學「**矽晶圓雙頭壟斷**」深度對比

| 維度 | SUMCO（3436）| 信越化學（4063）| 比較 |
|---|---|---|---|
| **全球矽晶圓市佔** | **~25%** | **~30%** | 信越 #1 + SUMCO #2 = 55-60% 壟斷 |
| **業務純度** | **純 300mm + 200mm 矽晶圓** | 矽晶圓 + 光阻劑 + pBN + PVC + silicon 多元 | **SUMCO 純度勝**（矽晶圓 pure-play）|
| **多元化** | 弱 | 強（4-5 條腿）| **信越多元化勝** |
| **300mm 規模** | ✅ | ✅ | 並列 |
| **fab 地緣分散** | 日本 + 印尼 + 美國 + 台灣 | 日本 + 馬來西亞 + 美國 | 並列 |
| **客戶 lock-in** | 全 AVL | 全 AVL | 並列 |
| **Forward PE** | ~25-30x | ~25-30x | 並列 |
| **PB** | ~2-3x | ~3-4x | 信越溢價（多元化 + 護城河） |
| **市值** | USD ~$67-95B | USD ~$130-140B | 信越約 SUMCO 1.5-2x |
| **跨光通訊上游** | ❌（純矽）| ✅（pBN crucible + InP 上游 anchor）| 信越勝 |
| **規模碾壓中國** | ✅✅ | ✅✅ | 並列 |
| **AI 結構性受惠** | ✅✅✅（純 300mm）| ✅✅（300mm + 光阻劑 + pBN 三線並進）| 信越受惠面更廣 |

→ **結論**：「**SUMCO 純度 + 矽晶圓 pure-play vs 信越多元化 + 跨光通訊 InP**」分歧路線——
- 想要 **AI capex 矽晶圓最純的 beta + PB 估值法 → Forward PE 估值法 Re-rate 受惠** → **SUMCO**
- 想要 **多賽道並行 + 跨光通訊 InP + pBN crucible 單一供應商 + 多層 chokepoint** → **信越化學**
- **Leo 偏好**：兩家都符合「真賣水人純度首選」、但 SUMCO 純度更高 + 估值更低 + AI capex 純 beta、信越化學 chokepoint 廣度更深。**配置時可雙持**（信越 anchor + SUMCO 純度 alpha）。
