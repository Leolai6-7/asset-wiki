# Powertech 力成（6239.TW）

## 1. 一句話定位

**台廠 FOPLP 主力 + 記憶體封測龍頭 + AMD「2.5D panel」首例認證方**——把「**HBM 大單（Micron 獨家）+ FOPLP 量產（2027 中）+ AMD Zen 7 評估中 + 3D 光引擎 2026 量產**」綁進同一個故事。**不是 TGV 設備買方，是 FOPLP 矩形面板封裝整合方**。在台廠 OSAT 中最接近「**Pure-play AI panel-level packaging**」，跟 [[日月光 ASE]] 是 FOPLP 雙頭，但客戶 mix 截然不同（ASE = NVDA/AVGO，力成 = AMD/Micron）。

## 2. 三層 thesis

### 產業層
- 台廠第二大 OSAT（僅次 [[日月光 ASE]]）+ **全球記憶體封測龍頭**（Micron 主要合作方）
- 賽道位置：[[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」過渡
  - 記憶體封裝（HBM）已共識（Micron 獨家 HBM 訂單）
  - FOPLP 仍在驗證期（良率 >90%、2026 H2 客戶認證、2027 中量產）
  - 3D 光引擎 / CPO 仍在驗證期（2026 年底量產、2027-2028 系統量產）
- TAM 三條曲線同時擴大：
  - **Q1 2026 營收 NT$213.14 億（YoY +37.6%）= record**
  - 2026 H2 FOPLP 客戶認證、2027 年中量產
  - 2026 年底 3D 光引擎量產
- 跟 [[日月光 ASE]] 的差異：**「Pure-play」程度高 + 客戶 mix 不同（Micron + AMD vs NVDA + Apple）**

### 目的層
- **三段商業模式**：
  - **記憶體封測（DRAM / HBM）** ~50%+：客戶 Micron 獨家 HBM、Kioxia、Western Digital
  - **邏輯封測**：客戶 Intel + 其他
  - **FOPLP 先進封裝（新引擎）**：良率突破 90% → 2027 中量產，AMD Zen 7 評估中
- **真實角色**：不是「TGV 設備買方」，是「**FOPLP 矩形面板封裝整合方 + 記憶體 HBM 量產方**」
  - 跟 AMD 共同認證**「2.5D panel-based interconnect 首例」**（產業創新里程碑）
  - **3D 光引擎** EIC+PIC 整合用 TSV + Bump 連接、2026 年底量產
  - 跟 [[日月光 ASE]] 的 FoCoS-Bridge / CoWoP 是「**同層競爭 + 客戶切割**」
- 2026 資本支出 **NT$500 億（從 NT$400 億上修 25%、最新更上看 NT$500-700 億）**：
  - ~NT$300 億用於 FOPLP（含友達廠房接收）
  - 同時退出 Power Module 業務（高階產能保留給 AI/HPC）

### 供應層
- **不是賣水人，是「AMD + Micron + FOPLP 三軌押注的整合方」**——這是跟 [[弘塑]]/[[辛耘]] 完全不同的位置，跟 [[日月光 ASE]] 像但客戶 mix 不同：
  - **客戶 mix vs ASE**：
    - 力成：AMD + Micron + Intel = **「美系 + 記憶體」集中**
    - ASE：NVDA + AVGO + Apple + 高通 + TSMC = **客戶廣度更寬**
  - **技術 mix vs ASE**：
    - 力成：FOPLP（panel-level）+ 3D 光引擎（CPO）= **「面板 + 光封裝」雙軌**
    - ASE：FoCoS + CoWoP + FOPLP + TGV pilot = **「四軌並進」**
- 跟 [[TSMC]] 是 **「分工 + 客戶截然不同」二層關係**：
  - **分工**：力成做 panel-level、TSMC 做 wafer-level
  - **客戶切割**：TSMC CoWoS-S/L 重 NVDA，力成 FOPLP 重 AMD Zen 7
- 護城河：
  - **Micron 獨家 HBM 訂單**（全市場唯一 HBM3E 量產的非韓系記憶體）
  - **AMD「業界首例 2.5D panel-based interconnect」共同認證**（design-in 護城河）
  - **3D 光引擎 EIC+PIC 整合**（CPO 真實 design-in 而非概念）
- → 連 [[賣水人選股邏輯（投資版）]]：力成是「**Pure-play AI panel-level**」變體 + 記憶體穩定現金流

### ✅ 催化

- **AMD Zen 7「2.5D panel-based interconnect 首例認證」**（May 2026 公告、股價漲停 NT$283 → 6 月 NT$335+）
- **Micron HBM 獨家訂單**（記憶體超級循環、2026 末產能 sold out）
- **FOPLP 2026 H2 客戶認證、2027 中量產**（良率 >90%、產能 3K 已到位）
- **3D 光引擎 EIC+PIC 整合驗證完成**、2026 年底量產（CPO 真實 design-in）
- 2026 全年資本支出上修至 NT$500 億（朝 NT$700 億方向）= 結構性投資週期
- Q2 毛利率 guide >20%（vs Q1 19.4%）= 持續提升
- **PE 13.7 倍 vs 三傑 60 倍 = 估值折價 ~4-5 倍**（最大估值錯位！）

### ⚠️ 風險

- **客戶集中度高**：Micron + AMD + Intel 估佔營收 60%+ → 任一客戶降單衝擊大
- AMD Zen 7 「**仍在 evaluation**」，正式量產時程 2027-2028 = 真正放量在後
- FOPLP「**客戶認證**」階段 ≠ 量產 = 良率 95% ≠ 客戶採用 100%
- 3D 光引擎「**EIC+PIC 整合 ≠ 系統量產**」，客戶 alignment 仍要 2027-2028
- CapEx NT$500 億（朝 NT$700 億）= 友達廠房 + 新廠 → 2026-2027 折舊壓力前置
- **記憶體週期性**：HBM 訂單依賴 Micron 供需 → 若 2027 記憶體 oversupply 衝擊大
- 退出 Power Module 業務 = 短期營收 friction

## ⭐ 對 TGV / FOPLP 投資 thesis 的位置

### TGV / 玻璃中介層 design-in 強度

力成是 TGV / 玻璃中介層 **「FOPLP 端 anchor」**，但 TGV 本身的 design-in **弱於 [[日月光 ASE]] / [[Amkor]]**：
- **強**：**FOPLP 矩形面板封裝**——TGV 跟 FOPLP 不一定綁，但 FOPLP 是玻璃基板的可能載體
- **強**：AMD Zen 7「2.5D panel-based interconnect」首例 = **產業創新 design-in 護城河**
- **中**：3D 光引擎 EIC+PIC 用 TSV + Bump = 跟 TGV 製程鏈毗鄰但非同一賽道
- **弱**：直接 TGV 雷射 / 玻璃中介層 design-in **未揭露**（不像 ASE 跟 TPK 合作或 Amkor 跟 Intel EMIB）

**對台廠的對應關係**：
- 力成的 FOPLP 訂單 → 仍要買 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] 設備
- 力成的 3D 光引擎 → 可能進口 [[弘塑]] / [[萬潤]] 設備
- → **力成是台廠賣水人的「第二大下游客戶」**（次於 ASE）

### 跟 [[TSMC]] CoWoS 的關係：替代 / 分工 / 補位

**「分工 + 客戶切割」二層**（更純粹的關係）：

1. **分工**：TSMC 做 wafer-level CoWoS、力成做 panel-level FOPLP = **製程形式截然不同**
2. **客戶切割**：
   - TSMC CoWoS-S/L 重 NVDA / AVGO（60% / 15%）
   - 力成 FOPLP 重 **AMD Zen 7 + Micron HBM** = **跟 TSMC 不直接競爭**

→ 力成 **不替代 TSMC**，是「**TSMC 沒做的 panel-level 玩家**」。比 ASE/Amkor 更「**獨立於 TSMC**」（不依賴 CoWoS 委外）。是三家 OSAT 中**最 pure-play AI panel-level**。
