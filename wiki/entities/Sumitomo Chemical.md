# Sumitomo Chemical（住友化學，TSE: 4005）

## 1. 一句話定位

**日本百年綜合化學集團（1913 創立）+ 半導體先進材料隱形賣水人**——五大事業段（Agro & Life Solutions / **ICT & Mobility Solutions** / Advanced Medical Solutions / Essential & Green Materials / Sumitomo Pharma）並進，其中 **ICT & Mobility Solutions** 段是半導體 / 顯示器材料 platform（FY2024 營收 JPY 607B、Core OP JPY 70.6B），核心子公司是**韓國 Dongwoo Fine-Chem**（100% 持股、半導體 + 顯示器材料、Pyeongtaek 廠 + Iksan 研究室 + Pangyo R&D 中心）。**2025-11 與 [[Samsung Electro-Mechanics]] + Dongwoo Fine-Chem 簽 MOU 成立 Glass Core JV**（SEMCO 大股東 + Sumitomo 小股東 + Dongwoo 廠地）= 韓國 panel-level glass interposer 鏈**唯一外資化學材料夥伴**，2027 量產目標 [[Apple]] / [[AVGO]] / Google TPU / AWS / 大型雲端。

## 2. 三層 thesis

### 產業層

- **綜合化學集團**橫跨：農藥 + 半導體材料 + 醫療 + 通用化工 + 製藥 5 段、合併營收約 JPY 2.7T（FY2024）
- **ICT & Mobility Solutions** 是公司新長腿：FY2024 營收 JPY 607.0B（+19.6B YoY）+ Core OP JPY 70.6B（+20.5B YoY）= **唯一連續成長 + ROIC 11% 目標的 segment**（FY2027 目標）
- 半導體材料 + 先進封裝鏈位階：
  - **光阻劑（Photoresist）**：ArF 浸潤式 + i-line 厚膜光阻（先進封裝厚膜光阻 = 半導體後段 RDL / TGV 用）→ Osaka Works 擴 FY2025-FY2026 H1 sequentially commission
  - **高純度製程化學品**（韓國 + 美國新廠 = Korea Dongwoo + US plant、配 [[Intel]] / [[Samsung]] / [[TSMC]] 鏈擴美）
  - **化合物半導體材料**（GaAs / GaN sub）
  - **顯示器材料**（OLED / LCD polarizers、Dongwoo 主力）
  - **觸控感測 / 高純度鋁 / 工程塑膠 / 電池材料**（次要）
- 玻璃基板 design-in 訊息（最關鍵新訊號）：
  - **2025-11-05 SEMCO Glass Core JV MOU**：SEMCO（大股東）+ Sumitomo Chemical（小股東）+ Dongwoo Fine-Chem（廠地）三方
  - **Dongwoo Fine-Chem Pyeongtaek 廠**：JV 總部 + 初期 glass core 量產基地
  - **正式合約 2026 H2 簽署** → **2027 量產**
  - Sumitomo 具體技術角色**未公開**（公告僅提「technology accumulated by Sumitomo Chemical」+「pool their technologies and global networks」）—— **未驗證**
  - 推測角色：**化學材料側貢獻**（玻璃 core 配方 / dry film resist / process chemicals）+ **韓國本土製造在地化**（Dongwoo 廠地 + 質量保證系統）vs SEMCO 提供 panel-level fab 製程 know-how + Apple / Google / AVGO 客戶
- 賽道 timing：
  - 主業 ICT & Mobility 結構性成長：[[市場四階段：懷疑／驗證／共識／反轉]] **驗證期** → SEMCO JV 量產確認 = 走向**共識期**
  - 玻璃基板對 Sumitomo P&L 結構性影響在 2027+
  - 光阻劑 + 高純度製程化學品擴產對應 2026-2027 全球 fab capex 高峰

### 目的層

- 真實角色：**「日本綜合化學 + 韓國半導體材料雙重 platform」**——本社（日本）做光阻劑 / 顯示器 / 化工，Dongwoo Fine-Chem（韓國）做高純度製程化學品 + 半導體 / 顯示器材料、深耕韓國 fab / 載板廠 30+ 年
- 商業模式 4 段：
  - **製藥 Sumitomo Pharma**（FY2025 起獲利轉正、主業現金牛之一）
  - **Essential & Green Materials**（合成樹脂 + Petro Rabigh、營收最大但低利）
  - **ICT & Mobility Solutions**（半導體 / 顯示器材料 = 成長引擎、ROIC 11% 目標）
  - **Agro & Life Solutions + Advanced Medical Solutions**（穩定段）
- 玻璃基板 JV 的真實戰略：**「跟 SEMCO 綁進 Apple / Google / AVGO panel-level 載板鏈、輸入韓系最大載板廠平台、在 Samsung 集團之外取得獨立 panel-level glass 鏈位」**——而非自己做 glass core foundry
- [[控制點轉移（投資版）]]：拿到「**SEMCO JV 玻璃 core 材料側 + 韓國本土半導體材料製造 + Apple 鏈間接 anchor**」三重控制點
- 跟 [[AGC]] / [[Corning]] 的差異：AGC / Corning 是**玻璃材料 sheet 賣家**，Sumitomo 是**玻璃 core JV 股東 + 化學材料 (光阻 / 製程化學品) 賣家**——位階不同（Sumitomo 跟 SEMCO 綁更深）

### 供應層

- **路線**：化學材料多軌（光阻 + process chemicals + display + 化合物半導體 + 樹脂 + 製藥）+ JV 股權
- 護城河四層：
  - **百年化學 IP**（1913 創立、廣譜化學能力）
  - **Dongwoo Fine-Chem 韓國本土護城河**（30+ 年韓系 fab / 載板廠合作、Samsung / SK / LG 鏈深度整合）
  - **半導體光阻劑全球 top 5**（與 JSR、TOK、信越化學、Shin-Etsu Chemical 競爭）
  - **JV 股權 anchor**（SEMCO Glass Core JV 拿小股東 + 廠地、長尾期權）
- 競爭格局：
  - **vs JSR**（光阻劑直接競爭、JSR 被 JIC 收購已私有化）
  - **vs Tokyo Ohka Kogyo (TOK)**（光阻劑、ArF 段對手）
  - **vs 信越化學 / Shin-Etsu Chemical（4063.JP）**（光阻劑 + 矽晶圓更廣譜對手）
  - **vs [[AGC]] / [[Corning]] / [[SCHOTT]]**（玻璃材料賣家、Sumitomo 不直接競爭、是 JV 角度切入 glass core）
- 風險：
  - **玻璃基板 JV 角色未公開** = 真實技術 / 收入貢獻待 2026 H2 正式合約揭露
  - 本社營收結構性貢獻仍小：Glass Core JV 對 JPY 2.7T 集團營收貢獻**短期極微**
  - 主業大宗化學品（Petro Rabigh）景氣循環性高
  - Sumitomo Pharma 過去 5 年大幅減損、剛轉盈
  - 日圓波動：Q1 FY2026 因日圓升值匯損 JPY 4.5B 淨損

| 項目 | 狀態 |

## ⭐ 對台股 TGV 設備廠的意義

### bull case 對 [[鈦昇]] / [[雷科]] / [[弘塑]] / [[辛耘]] / [[萬潤]] / [[敘豐]]

- Sumitomo Chemical 自己**不做 TGV 設備、不做雷射改質、不做切割、不做檢測** → **不衝擊台廠 8 站設備生意**
- SEMCO JV 2027 量產確認 = panel-level glass interposer 鏈**結構性需求驗證** → derisk 整個 [[TGV 製程鏈圖譜]] 賽道
- Sumitomo 光阻劑 + 高純度製程化學品擴產 = 對應全球 fab CapEx 上行 → 台廠檢測 / 電鍍 / 蝕刻設備全鏈受惠
- Apple / Google / AVGO 玻璃化 → 整個 panel-level interposer TAM 放大 → 台廠中長期受惠

### bear case 對台廠

- **韓系玻璃 core 鏈整鏈閉環風險加深**：[[Samsung Electro-Mechanics]]（fab）+ Sumitomo Chemical（化學材料）+ Dongwoo Fine-Chem（韓國本土廠地）= 韓系 panel glass core **三方整鏈、不需要台廠任何材料 / 化學品供應**
- Apple Baltra 鏈固化在 SEMCO + Sumitomo + Dongwoo 體系 → 台廠（[[東捷]] / [[日月光 ASE]] TPK pilot / [[Powertech 力成]]）切入 Apple panel 鏈機會被進一步擋
- Sumitomo Chemical 在台廠光阻劑 / 化學品市場本來就有份額 → 韓系玻璃材料若被 Sumitomo 鎖死 → 台廠**化學品 / 光阻**供應鏈位階不變、但**玻璃 core 端被排除**

### 最大 takeaway

**Sumitomo Chemical 對台廠是「間接平行存在」**——不直接競爭設備、不直接搶台廠 fab 服務客戶，但**強化韓系玻璃整鏈閉環的化學材料側**，對台廠 OSAT 在 Apple / Google / AVGO 鏈延伸是「間接擋路者」。**對台廠設備鏈不創造 binary 威脅**，但對「台廠想做整廠 turnkey」（[[東捷]] G2C+ 聯盟）的策略 → Apple / SEMCO 鏈被韓 + 日 + 韓三方整鏈進一步固化。

### 五軸評分（對 [[鈦昇]] / 對台廠設備）

| 軸 | 分數 | 說明 |
|---|---|---|
| 路線敏感 | 3/5 | SEMCO JV 是小股東角色、光阻 + 製程化學品是主軸、玻璃 core 是長尾 |
| 站別關鍵 | 3/5 | 跨光阻（後段 RDL）+ 玻璃材料 + 製程化學品 + 顯示器、多站但非單一關鍵 |
| 耗材性 | 5/5 | 光阻 / 製程化學品 = **每片晶圓 / 每片載板都消耗** = 純耗材年金 |
| IP 護城河 | 4/5 | 百年化學集團 + Dongwoo 30 年韓系 fab 整合 know-how + ArF 光阻技術 |
| 客戶分散 | 5/5 | Samsung / SK / TSMC / Intel / 面板廠 / 製藥 / 農藥 / 大宗化工全分散 |

**Sumitomo Chemical 五軸 20/25**——與 [[LPKF]] 並列高分（路線 + IP 較弱、耗材 + 客戶分散滿分），但角色完全不同：Sumitomo 是「綜合化學集團 + JV 股東」非 binary thesis 對手。
