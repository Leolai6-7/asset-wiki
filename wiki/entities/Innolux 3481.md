# Innolux 3481（群創光電）

## 1. 一句話定位

**台廠 LCD 面板 #2（vs [[友達]]、奇美電合併後新公司）+ 鴻海集團（[[鴻海 2317|鴻海]]）部分持股 + 2024-2026 戰略轉型「**面板廠 → FOPLP（Fan-out Panel Level Packaging）半導體先進封裝廠**」first-mover + 透過 [[東捷]]、敘豐等設備鏈導入玻璃基板製程 + 玻璃基板 / FOPLP 賽道台廠唯一「**面板廠跨界進入半導體後段封裝**」案例**——2010 年由群創光電 + 統寶光電 + 奇美電合併、台股上市；面板週期見頂 + 中國國產替代下、走「**從顯示 → 半導體先進封裝轉型**」獨立路線；2024 公告投資 NT$150 億成立半導體先進封裝產線、跟 [[東捷]] / [[敘豐]] / [[弘塑]] 等設備鏈合作；2026-2028 量產 FOPLP 載板 + 玻璃基板 panel level interposer；跟集團母公司 [[鴻海 2317|鴻海]] AI server 業務形成「**面板 LCD 基本盤 + FOPLP 第二曲線 + 鴻海 AI server 整合**」三軸組合。在 [[玻璃基板與 FOPLP 賽道]] 是「**台廠面板廠跨界轉型 first-mover**」（vs SEMCO / Samsung 集團閉環）、在 [[賣水人選股邏輯（投資版）]] 是「**面板週期見頂 + FOPLP 期權型轉型 + 鴻海集團 anchor**」（14/25 推估）。

## 2. 三層 thesis

### 產業層

- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「懷疑 → 驗證」過渡期**——
  - 懷疑：LCD 面板週期見頂（中國 BOE / TCL 規模碾壓、ASP 跌）+ 群創 ROE 弱 + 過去多年虧損
  - 驗證進行中：2024 公告 NT$150 億 FOPLP 投資 + 跟東捷 / 敘豐 / 弘塑等設備鏈合作、2026-2028 量產 ramp
- 在 [[資訊擴散四階段]]：台灣機構 / 賣方覆蓋深、媒體層熱炒「面板廠轉型 FOPLP」、外資 ETF 配置中、AI 散戶散點觸及
- TAM：
  - FOPLP / 玻璃基板：2026 USD 1B → 2030 USD 8B+（CAGR ~40%、ABF 載板 displacement 部分）
  - LCD 面板：穩定但週期性 / 部分萎縮
  - 鴻海 AI server BOM 內整合：跟 [[鴻海 2317|鴻海]] AI server 業務同步
- 在 [[玻璃基板與 FOPLP 賽道]]：群創 = **「面板廠跨界進入半導體後段封裝」first-mover**、跟 SEMCO / Samsung 集團閉環 + IBIDEN / 欣興 ABF 廠路線完全不同
- 在 [[TGV 製程鏈圖譜]] / [[TGV 路線分歧（雷射改質 vs 雷射打孔）]] / [[手機與邊緣晶片端 TGV-FOPLP watchlist]]：群創是 FOPLP 線轉型代表
- 跟 [[ABF 載板 vs 玻璃基板 displacement]] 視角：群創 = ABF 載板 displacement 受益者（從面板廠跨界補位）

### 目的層

- 真實角色：**「台廠 LCD 面板 #2 + FOPLP 半導體先進封裝轉型 first-mover + 跟設備鏈合作補課製程 know-how + 鴻海集團 AI server 整合補位」**——不是「跟 ABF 載板廠正面對打」（vs IBIDEN / 欣興 / 南電 / 景碩規模 + 製程深度落後）、是「**面板廠跨界 + FOPLP 設備鏈合作 + 鴻海 AI server BOM 內部整合 + 從面板週期週期股 → 半導體 Re-rate**」
- 業務組合（FY2025 → FY2026 預期）：
  - **LCD 面板**：~70%（主基本盤、週期性、部分萎縮）
  - **FOPLP / 玻璃基板半導體先進封裝**：~5% → 2026-2028 ramp 至 20-30%（第二曲線）
  - **車用顯示 + 中型面板**：~25%（穩定）
- 商業模式：
  - **面板 LCD pure-play（基本盤）+ FOPLP 期權型第二曲線**
  - **跟 [[東捷]] / [[敘豐]] / [[弘塑]] 等設備鏈合作補課製程 know-how**
  - **鴻海集團整合**（AI server BOM 內整合、面板廠 + 載板廠 / FOPLP 廠一體化）
- 核心 IP / 護城河：
  - **面板廠規模 + know-how**（大尺寸玻璃 + LCD 製程 + 偏光片 + TFT 製程 know-how）
  - **跟設備鏈協同**（東捷 / 敘豐 / 弘塑等設備合作補課 FOPLP）
  - **鴻海集團 anchor**（部分持股 + AI server 業務整合）
  - **NT$150 億 FOPLP CapEx**（2024 公告投資）
- 對應 [[賣水人選股邏輯（投資版）]]：**「面板週期見頂 + FOPLP 期權型轉型」**——⚠️ **期權型受惠**（需 FOPLP 路線勝出 + 量產良率 + 客戶取得三重 binary）
- 對應 [[控制點轉移（投資版）]]：拿到「**面板廠規模 + FOPLP 設備鏈合作 + 鴻海集團 anchor + NT$150 億 CapEx**」混合 chokepoint、但**控制權弱**（製程深度落後 ABF 載板廠）
- 對應 [[半導體基礎建設化]]：面板廠跨界半導體封裝 = 結構性產業遷移代表

### 供應層

- 跟 [[鴻海 2317|鴻海]] 關係（**集團母公司**）：
  - 鴻海集團部分持股（具體比例需 verify、推估 ~10-15% 區間）
  - 鴻海 AI server 業務（GB200 NVL72 主代工）下游帶動群創 FOPLP 載板出貨機會
  - 鴻海集團整合：面板廠 + 載板廠 + AI server 代工一體化
- 跟 [[東捷]] 關係（**FOPLP 設備鏈核心夥伴**）：
  - 東捷供應群創 FOPLP 製程設備（玻璃 layup + 切割 + 雷射相關製程）
  - 群創跟東捷 + 敘豐 + 弘塑形成「**面板廠 + 設備鏈協同**」（東捷 / 敘豐主要設備、弘塑化學品）
- 跟 [[敘豐]] / [[弘塑]] 關係：
  - 設備鏈合作夥伴（敘豐主要設備、弘塑化學品）
- 跟 [[IBIDEN]] / [[欣興]] / [[南電]] / [[景碩]] 關係（**ABF 載板廠對手**）：
  - 群創跨界 FOPLP 半導體先進封裝 = **追趕者**
  - 規模 + 製程深度落後 ABF 載板廠
  - 但**面板廠規模 + 大尺寸玻璃 know-how + FOPLP 設備鏈合作**是差異化
- 跟 SEMCO（Samsung Electro-Mechanics）關係（**亞洲 FOPLP / 玻璃基板對手**）：
  - SEMCO 內部閉環（Samsung 集團、ABF + FOPLP + 矽電容多軸）
  - 群創追趕者位置
- 跟 [[Absolics]] / [[Amkor]] 關係（**美亞 OSAT 整合方**）：
  - Absolics + Amkor 走玻璃基板 OSAT 整合
  - 群創走面板廠跨界 FOPLP（不同路線、可能未來合作）
- 跟 [[F&S Electron]] 關係：
  - F&S Electron = Absolics 獨家供應商
  - 群創跟 F&S Electron 不直接競爭、但同屬玻璃基板 / FOPLP 賽道
- 跟 [[鈦昇]] / [[雷科]] 關係（**TGV 設備廠**）：
  - 鈦昇 + 雷科主要做 TGV 雷射設備
  - 群創跟 TGV 設備鏈合作（推測為下游採購）
- 跟 [[NVDA]] / [[Intel]] / [[Marvell]] 關係（**ABF 載板 / FOPLP 終端客戶**）：
  - 群創 FOPLP ramp 後可能爭取 NVDA / Intel / Marvell ABF 載板替代訂單
  - 但目前仍在「**追趕者**」位置、客戶取得時程不明
- 跟 [[玻璃基板與 FOPLP 賽道]] 視角：
  - 群創 = **面板廠跨界 first-mover**（vs 三星 SEMCO 集團閉環 + IBIDEN / 欣興 ABF 廠）
- 跟 [[ABF 載板 vs 玻璃基板 displacement]] 視角：
  - 群創 = ABF 載板 displacement 受益者（面板廠跨界補位）
  - 但 ABF 雙曲線受惠（[[欣興]] / [[IBIDEN]]）也在 displacement 賽道
- 護城河：
  - **面板廠規模 + 大尺寸玻璃 know-how**
  - **跟設備鏈協同**（東捷 / 敘豐 / 弘塑）
  - **鴻海集團 anchor**
  - **NT$150 億 FOPLP CapEx**
- 風險：
  - ⚠️ **FOPLP 路線需贏 + 量產良率 + 客戶取得三重 binary**（期權型風險）
  - ⚠️ **製程深度落後 ABF 載板廠**（IBIDEN / 欣興 / SEMCO 規模 + 製程 know-how 領先）
  - ⚠️ **LCD 面板週期下行壓力**（中國 BOE / TCL 規模碾壓、ASP 跌）
  - ⚠️ **群創過往多年虧損 + ROE 弱**（轉型資金壓力）
  - ⚠️ **NT$150 億 CapEx 回本時程不明**（FOPLP ramp 比預期慢風險）
  - ⚠️ **鴻海集團整合的兩面性**：鴻海 anchor 紅利 / 但也受鴻海集團 AI server 業務波動傳導
  - ⚠️ **市值小 + 流動性中**（vs 友達合併新公司、估值仍受面板週期錨定）
