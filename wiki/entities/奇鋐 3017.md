# 奇鋐（3017.TW）

## 1. 一句話定位

**全球 AI server 散熱模組龍頭 + 北美 4 大 CSP CDM(manifold) 主供 + NVDA GB200/GB300 cold plate 50%+ 市佔 + 3D VC（Vapor Chamber）一條龍 + 2025 營收破千億寫新猷 + 2026 Q1 EPS 20.17 元創歷史新高**——「**規模 + cold plate 市佔王**」型台廠液冷龍頭、跟 [[雙鴻]]（3324）形成「**台廠液冷雙頭**」三角戰、跟 NVDA 共同認證 UQD（universal quick disconnect）+ 浸沒式 / CDU / Rubin 雙路線並進、[[AI infra 散熱戰場]] **台廠 anchor #1 候選**（散熱戰場整體 anchor #4，僅次於 [[Vertiv]] / [[雙鴻]] / [[台達電]]）。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**共識**」階段、與 [[雙鴻]] 同列台廠液冷代表
- 機櫃功率密度 5 年 30kW → 1MW（**33x**）= 散熱**從零件升級為基礎建設**
- 2026 液冷滲透率衝 **76%**（券商估）+ 單櫃散熱產值跳升 **4 倍**
- 跟 [[AI infra CapEx 三階段論]] 第三階段同步：散熱「**從 NVDA 設備往下游機櫃**」傳導的 BOM 倍增戰場
- 跟 [[AI infra 電力戰場]]（孿生戰場）：**信昌電 / 台達 / 雙鴻 / 高力 / 奇鋐 = 800V HVDC 五角賣水人**
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體 → ETF（已 ETF 化、2025 EPS 20.17 元已上頭條 + 大摩目標價 NT$3,333 已 Citi NT$2,055 提前報導）

### 目的層

- **業務組合**（2026 Q1 結構）：
  - **AI 伺服器散熱**：~66.4%（Q1 2026，從去年同期 45.48% 大幅提升）
  - **桌機 / 筆電 / 工作站散熱**：~30-33%
  - **機箱 / 機殼 / 其他**：~5-10%
- **散熱產品全鏈**：
  - **Cold Plate（水冷板）**：銅基直接觸晶 GPU/CPU、**GB200 cold plate 全球市佔 50%+**（4 大 CSP 主供）
  - **CDM / Manifold（分流管）**：**4 大 CSP CDM 主供地位**、跟雙鴻 27% rack manifold 互補
  - **3D VC（Vapor Chamber）**：均熱片 / 散熱管自製、跟氣冷時代積累的 IP 直接過渡到液冷
  - **CDU**：自研但弱於雙鴻 1.6MW L2L、屬於補課位置
  - **UQD（universal quick disconnect）**：跟 NVDA 同步認證、Rubin 規格參與者
  - **浸沒式液冷**：R&D 進行中、量產 2028-2030 觀察
- **AI server 客戶結構**：
  - **NVDA GB200 / GB300 cold plate 主供**（雙鴻 + 奇鋐合計拿 70%、奇鋐單家 50%+）
  - **北美 4 大 CSP（Microsoft / AWS / Google / Meta）CDM 主供**
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 餵 NVDA + ASIC（AWS Trainium / Meta MTIA）
  - NVDA Rubin **VR 系列零件規格送樣中**（跟 [[雙鴻]] 同步驗證）
- **2026 全年指引**：營收與獲利**逐季成長**、下半年較上半年更樂觀、全年樂觀
- 商業模式核心：
  - **「**規模 + 市佔王 + 一條龍規模化**」**：cold plate + manifold + 3D VC + 機箱多軌、規模碾壓台廠純度型對手
  - **氣冷時代積累的 IP 全棧過渡到液冷**：3D VC 均熱 + 散熱管 + 散熱片 + cold plate 設計 → 直接導入液冷模組
  - **跟 NVDA 4 大 CSP 雙線綁定**：cold plate 4 認證供應商 + CDM 主供 = 雙重 lock-in
- 對應 [[賣水人選股邏輯（投資版）]]：**規模 + 市佔型賣水人**——不押 NVDA / AMD / Trainium 誰贏、押**所有 1MW 機櫃都得用奇鋐 cold plate + CDM**
- 對應 [[控制點轉移（投資版）]]：拿到「**cold plate 50%+ 市佔 + CDM 4 大 CSP 主供 + UQD 規格參與**」綁定 = 議價權**結構性高於純零件廠 niche specialist**

### 供應層

- 跟 [[NVDA]] 路線：
  - **GB200 / GB300 cold plate 主供**（4 認證供應商之一、單家 50%+ 市佔）
  - **UQD 認證 + 出貨**（universal quick disconnect、Rubin 互通性標準）
  - **Rubin VR 系列零件規格送樣中**（2026 Q2 開始驗證）
  - 透過 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] AI server ODM 間接餵 NVDA（具體比例未揭露）
- 跟 [[雙鴻]]（3324）對比（**核心對標**、見散熱戰場 anchor 排名）：
  - **cold plate**：奇鋐 **50%+ 市佔**（4 大 CSP 主供）vs 雙鴻 15-20%（Supermicro 主供）→ **奇鋐勝 2.5-3x**
  - **CDM / manifold**：奇鋐 4 大 CSP CDM 主供 vs 雙鴻 27% rack manifold UBS 估全球市佔 → **互補**（奇鋐 hyperscaler 直接 / 雙鴻 rack 級分散）
  - **CDU**：奇鋐補課中 vs 雙鴻 **1.6MW L2L CDU 超前部署** → **雙鴻勝（重要 IP）**
  - **3D VC / vapor chamber**：奇鋐強（氣冷時代積累）vs 雙鴻弱 → **奇鋐勝**
  - **全鏈整合**：奇鋐 cold plate + manifold + 3D VC + 機箱 vs 雙鴻 cold plate + manifold + CDU → **互補**（奇鋐廣 / 雙鴻深）
  - **客戶結構**：奇鋐 4 大 CSP 直供 + ODM vs 雙鴻 Supermicro + top 5 cloud + ODM → **奇鋐勝（hyperscaler 直接）**
  - **規模**：奇鋐 2025 營收 NT$1,396 億 vs 雙鴻 ~NT$235 億（**奇鋐約 6x**）
  - **2026 毛利率**：奇鋐 ~29.8% Q1 vs 雙鴻衝 30%+ → 接近並列
  - **2026 Q1 EPS**：奇鋐 **NT$20.17 元（單季創高）** vs 雙鴻 2025 全年 NT$28.26 → 奇鋐成長爆發
  - → **奇鋐強在 cold plate 市佔王 + hyperscaler 直接 + 規模、雙鴻強在 CDU + 全鏈深度 + 高利潤客製化、兩家是「**規模型 vs 規格深度型**」**
- 跟 [[Vertiv]] 對比：
  - 重疊：cold plate + manifold（奇鋐無 CDU 強 + 無 power 軌）
  - Vertiv 走 hyperscaler turnkey、奇鋐是**潛在零件供應商 + 部分競爭**
  - Vertiv 2026-04 併購 Strategic Thermal Labs（cold plate IP）→ 跟奇鋐部分競爭加劇
  - 但奇鋐 50%+ 市佔位置穩固、Vertiv 仍會採購（**互補 + 部分競爭**）
- 跟 [[台達電]] 對比：
  - 重疊：cold plate + manifold（台達多元 + power 軌 + CDU 強）
  - 台達電源 + 散熱整合勝、奇鋐純散熱規模勝
  - 台達 2.4MW/3MW L2L CDU vs 奇鋐 CDU 弱 = 規模 vs cold plate 市佔對比
- 跟 [[高力 8996|高力]] 關係：
  - 奇鋐 CDU 內部 BPHE 採購高力（高力台灣 9 成市佔、CDU 心臟）
  - 高力是**潛在供應商 + 不直接競爭**
- 跟 Boyd / CoolIT 對比：
  - Boyd（被 Eaton 2026-03 併購）：cold plate + manifold + CDU 全鏈、規模略大但被 Eaton 整合後變 power + cooling 雙軌
  - CoolIT：純液冷 IP（CHx2000 2MW / OMNI 4,000W）、技術 IP 強但無台廠規模成本
  - → 奇鋐是**亞洲規模化領頭**（vs 雙鴻 + 深圳 Cotran 拿 35% volume）、Boyd / CoolIT 走 IP / 規模高階路線
- 跟 [[鴻海]] / [[廣達]] / [[緯穎]] / [[緯創]] 關係：
  - **AI server ODM 必經之路**：cold plate / manifold / 3D VC 採購奇鋐
  - 跟 [[信昌電]]（MLCC）+ [[台達電]]（PSU）+ [[高力 8996|高力]]（BPHE）+ [[雙鴻]]（CDU + manifold）並列 ODM 鏈條 5 大零件供應商
- 護城河：
  - **cold plate 50%+ 市佔王**（4 大 CSP 主供、NVDA GB200/GB300 認證）
  - **CDM / manifold 4 大 CSP 主供**（hyperscaler 直接綁定）
  - **3D VC / vapor chamber 自製**（氣冷時代積累、液冷時代直接過渡）
  - **規模 + 認證壁壘**（NVDA UQD 認證 + 4 大 CSP 雙線 lock-in）
  - **2025 營收破千億**（NT$1,396 億 / +94.59% YoY、規模碾壓台廠純度型對手）
- 風險：
  - **2025 EPS + 2026 Q1 20.17 已 price in**（Forward PE 47x、Citi PT NT$2,055 大摩 PT NT$3,333）
  - **CDU 弱於雙鴻 1.6MW L2L**：浸沒式時代 IP 落後
  - **NVDA universal QD 標準化**：cold plate 供應商互通 = 削弱單一玩家定價權
  - **雙鴻 + 深圳 Cotran 亞洲鏈合圍**：cold plate 價格戰潛在風險
  - **Vertiv 自製 cold plate + Eaton-Boyd 整合**：國際對手收斂壓力
  - **Rubin 改散熱設計傳聞**（2026 初投信出貨 25 億回收）：題材已部分 burn out
  - **浸沒式 2028-2030 才量產**：純度玩家中期觀察點
  - **Rubin 量產時序延後 / 散熱規格收斂**
  - **GF Value 估值平均本益比觀點 2026 年底股價都高估**（同學會分析）

### 奇鋐 vs [[雙鴻]] NVDA Cold Plate / CDM 市佔（**核心回答**）

| 維度 | 奇鋐（3017）| 雙鴻（3324）| 優勢方 |
|---|---|---|---|
| **GB200 cold plate 全球市佔** | **50%+**（4 大 CSP 主供）| 15-20%（Supermicro 主供）| **奇鋐勝 2.5-3x** |
| **CDM / rack manifold 全球市佔** | 主供 4 大 CSP CDM | **27%**（UBS 估，2025）| **互補**（奇鋐 hyperscaler 直接 / 雙鴻 rack 級分散）|
| **CDU** | 補課中 / 弱 | **1.6MW L2L 超前部署 IP** | **雙鴻完勝** |
| **3D VC / vapor chamber** | **強（自製）** | 弱 | **奇鋐勝** |
| **UQD（NVDA 認證）** | **已認證 + 出貨** | 無自研 | **奇鋐勝** |
| **三鏈整合度** | **cold plate + manifold + 3D VC + 機箱**（廣）| **cold plate + manifold + CDU**（深）| **互補** |
| **客戶結構** | **4 大 CSP 直供 + NVDA + ODM** | Supermicro + top 5 cloud + Rubin sample | **奇鋐 hyperscaler 直接勝** |
| **規模** | ~NT$1,400 億 FY25 = **6x 雙鴻** | ~NT$235 億 FY25 | **奇鋐完勝（6x）** |
| **成長速度（2026 Q1）** | +110.17% YoY 營收 / EPS 20.17 元創高 | +121% YoY 1 月 / +91.7% 3 月 | **雙鴻 1 月稍勝、奇鋐 Q1 整體碾壓** |
| **毛利率** | 29.8% Q1 2026 | >30% 2026 衝 | **接近並列**（雙鴻略勝）|
| **大摩目標價** | **NT$3,333** | 無公開 | **奇鋐勝（外資加持）**|

→ **結論**：「**奇鋐 cold plate 市佔王 + hyperscaler 直接 + UQD + 規模王 vs 雙鴻 CDU IP + 三鏈整合 + 高利潤客製化**」分歧路線——
- 想要 **NVDA Cold Plate 市佔王 + 4 大 CSP 直供 + UQD + 規模碾壓** → **奇鋐**
- 想要 **CDU IP + 全鏈整合 + Rubin sample 高利潤客製化 + 速度更快** → **雙鴻**
- 想要兩家分散 → 持兩家當 pair（**台廠液冷雙頭**）
- **Leo 偏好**：兩家**互補**（奇鋐規模型 / 雙鴻規格深度型）—— 雙鴻偏 niche、奇鋐偏 anchor
