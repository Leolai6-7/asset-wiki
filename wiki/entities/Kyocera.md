# Kyocera（NYSE: KYO + 6971.JP、京瓷）

## 1. 一句話定位

**跨戰場 conglomerate + 1969 收購 AVX → 鉭電容全球 #2-3 + 石英陣營五巨頭之一 + 陶瓷封裝 / connector / 太陽能 / 印刷 / 通訊設備跨產業多元 + 京都老牌（1959 創立）**——日本京都精密設備 conglomerate、Components 50%（含石英 + AVX 鉭電容 + 陶瓷）+ Equipment 30% + Communications & Solutions 15% + Others 5% 跨戰場結構；**AVX Kyocera 鉭電容全球 #2-3**（跟 [[KEMET]] / Vishay 並列）= 補位 [[被動元件第三次週期（K 型復甦 + 三道防線）]] 第三道防線（鉭電容）anchor；FY2025 營收 ~¥2.0-2.3 兆 JPY（USD ~$13-15B）、Forward PE 14-18x、12M +5-20%；定位「**跨戰場 conglomerate + 客戶分散滿分 + 石英 + AVX + 多元**」、跟 [[GlobalFoundries]] 20 / [[Texas Instruments TXN]] 20 同分。

## 2. 三層 thesis

### 產業層

- **跨戰場 conglomerate**：跨「石英 + 陶瓷 + connector + 太陽能 + 印刷 + 通訊設備 + AVX 鉭電容」五大賽道
- **石英 timing 賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證**」段
  - Kyocera 石英 timing 段佔 Kyocera 整體 ~5-8% 營收（vs Epson Quartz Device 10%、TXC / NDK 純 timing 玩家）
  - 全球石英 timing 市場 ~USD 30-35 億（2025）+ CAGR ~5-8%
  - Kyocera 石英 timing 跟 [[TXC]] / [[NDK]] / [[Epson]] / [[Rakon]] 並列石英陣營五家
- **鉭電容賽道**在「**結構性短缺**」段（補位 [[被動元件第三次週期（K 型復甦 + 三道防線）]] 第三道防線）
  - **AVX Kyocera 鉭電容全球 #2-3**（市佔 ~15-20%、跟 [[KEMET]] / Vishay / Panasonic / ROHM 並列鉭電容寡占五家）
  - **1969 Kyocera 收購 AVX** → AVX Kyocera 段 = 鉭電容業務全球 anchor
  - **NVDA Vera Rubin 三道防線設計**：第三道鉭電容 = GPU 板高溫高壓區域最後保險（重要性提升）
  - 鉭電容交期 ~40 週 = 嚴重缺貨
- **陶瓷封裝賽道**：半導體陶瓷封裝寡占之一（IC package + HBM 陶瓷基板）
- **太陽能 + 印刷 + 通訊設備**：成熟期 + 跨戰場 sum-of-parts 結構
- [[資訊擴散四階段]]：機構（日本基金 + 京都企業分析）→ 賣方（日經 / 野村 / 大和）→ 西方媒體（Kyocera 美國上市 ADR KYO）部分擴散

### 目的層

- 主業 mix（FY2025）：
  - **Components**：~50% 營收 = 跨「石英 timing + AVX 鉭電容 + 陶瓷封裝 + 半導體零件 + 電子元件」多軌
    - 石英 timing：~5-8% Kyocera 整體營收
    - **AVX 鉭電容**：~15-20% Kyocera 整體營收（**= Kyocera 跨被動元件第三道防線 anchor**）
    - 陶瓷封裝：~10-15% Kyocera 整體營收
    - 其他電子元件：~10% Kyocera 整體營收
  - **Equipment**：~30% 營收 = 印刷設備 + 投影機 + 半導體設備 + 工業設備
  - **Communications & Solutions**：~15% 營收 = 通訊設備（手機 + 路由器）+ 系統整合
  - **Others**：~5% 營收 = 太陽能 + 醫療陶瓷 + 寶石
- **AVX Kyocera 鉭電容業務**：1969 收購 AVX 後 56 年累積、是 Kyocera 跨入被動元件鉭電容的關鍵戰略
- 客戶結構（FY2025）：
  - **半導體 / AI server**：NVDA / AMD / Intel / TSMC（陶瓷封裝 + 鉭電容 + 石英 timing）= ~20% 營收
  - **消費電子**：Apple / Samsung / 中國 OEM = ~15% 營收
  - **汽車**：Toyota / Honda / Tesla / 中國 EV（鉭電容 + 陶瓷 + 通訊）= ~15% 營收
  - **工業 / 醫療**：~15% 營收（陶瓷 + 醫療陶瓷 + 寶石）
  - **太陽能**：~5% 營收
  - **印刷設備**：~15% 營收
  - **通訊設備**：~15% 營收
- 商業模式：**多軌組合 + 京都本土 anchor + 全球分散產能**——五大事業群跨全球 200+ 子公司、京都 + 神奈川 + 鹿兒島 + 中國 + 美國 + 歐洲多地產能
- → 連 [[賣水人選股邏輯（投資版）]]：**跨戰場 conglomerate + 多客戶分散 + AVX 鉭電容 anchor** — 不押任何單一路線、押「**所有 AI server + 汽車 + 工業 + 通訊都需要 Kyocera 多軌組合**」

### 供應層

- **路線：跨戰場 conglomerate + 多賽道並進**：
  - 石英陣營 vs MEMS 路線分歧（同 TXC / NDK / Epson / Rakon、Kyocera 石英 timing 段）
  - 鉭電容 vs MLCC + 聚合物鋁固態電容三道防線（跟 KEMET / Vishay / Panasonic / ROHM 並列鉭電容寡占）
  - 陶瓷封裝 vs ABF 載板 vs 玻璃基板 displacement 三軌路線
- 護城河四層：
  - **京都老牌 conglomerate**：稻盛和夫 1959 創業以來累積 65+ 年技術 IP + 多元事業群
  - **AVX 鉭電容 IP**：1969 收購 AVX 後 56 年累積、跨入鉭電容寡占
  - **陶瓷封裝 IP**：半導體陶瓷封裝寡占之一
  - **客戶分散滿分**：跨半導體 + 消費電子 + 汽車 + 工業 + 醫療 + 太陽能 + 印刷 + 通訊七大客戶層
- 競爭格局：
  - **vs [[SiTime]]**（NASDAQ: SITM）：路線分歧、SiTime 高端 5G / AI server / 衛星 / 機器人、Kyocera 石英 timing 段是 conglomerate 一段
  - **vs [[TXC]]**（3042.TW）：Quartz Device 段同分歧（TXC 純 timing 玩家、Kyocera conglomerate）
  - **vs [[NDK]]**（6779.JP）：Quartz Device 段同分歧（NDK Apple iPhone + 光學晶振、Kyocera 純 timing 規模較小但跨多軌）
  - **vs [[Epson]]**（6724.JP）：兩家都 conglomerate、Epson 跨「印表機 + 投影機 + 機器人 + 石英 + 手錶」、Kyocera 跨「石英 + 陶瓷 + AVX + 太陽能 + 印刷 + 通訊」路線重疊度低
  - **vs [[Rakon]]**（NZX: RAK）：規模差 30-50x
  - **vs [[KEMET]]**（被 [[國巨]] 2020 收購）：鉭電容寡占同層、KEMET 屬於國巨集團、Kyocera AVX 獨立
  - **vs Vishay / Panasonic / ROHM**：鉭電容寡占五家分食
  - **vs [[村田 Murata]]** / [[太陽誘電 Taiyo Yuden]] / [[TDK]]：MLCC + 陶瓷封裝賽道對手
- 風險：
  - **conglomerate sum-of-parts 折價**：五軌多元組合可能被市場 discount
  - **[[SiTime]] MEMS 高端滲透**：5G / AI server / 衛星市佔提升 → Kyocera 石英 timing 段受壓
  - **太陽能 + 印刷成熟期**：兩段持續低成長
  - **JPY/USD 匯率**：高出口比重、日圓升值壓營收
  - **[[CapEx 見頂辯論]]** 兌現 → AI server / 汽車成長放緩
- → 連 [[控制點轉移（投資版）]]：**石英 + AVX 鉭電容 + 陶瓷封裝 + 太陽能 + 印刷 + 通訊六重控制點** = Kyocera 是日本跨戰場 conglomerate 典範
