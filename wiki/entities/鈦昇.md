# 鈦昇（8027.TW）

## 1. 一句話定位

**全球 TGV 雷射改質的 first-mover**，與德國 LPKF LIDE 對打的台廠唯一解；客戶是 [[Intel]]、台積電玻璃試產線、ABF 板廠；TGV 是命脈（虧損中燒錢卡位）。

## 2. 三層 thesis

### 產業層
- TGV 製程鏈第 1 站「雷射改質」（沒它後面 7 站都做不下去）
- [[市場四階段：懷疑／驗證／共識／反轉]]：「early adopter → 早期主流」過渡
- **anchor**：[[Intel]] Clearwater Forest（Xeon 6+）2026 H2 量產 = 第一個真實 anchor
- 已於美國 Arizona 設據點貼 Intel 供應鏈
- 領導 **E-Core 玻璃基板大聯盟**（[[辛耘]] 濕蝕刻、天虹、群翊、上銀）— 一站式方案

### 目的層
- 不是賣設備，是**定義水的人**
- 把「雷射改質 + 化學蝕刻」定義為 TGV 標準工法
- 跟 [[LPKF]]（德國，LIDE 專利擁有者）競爭定義權
- → 連 [[TGV 路線分歧（雷射改質 vs 雷射打孔）]]

### 供應層
- **押路線**（不是中性賣水人）
- 護城河：**每秒 8,000 孔 + 5μm 精度**的 process know-how + E-Core 聯盟整合能力
- 風險：Intel 良率若卡關、或 TSMC CoPoS 採其他工法 → 直接受傷
- → 連 [[控制點轉移（投資版）]]

### ✅ 催化
- Intel Clearwater Forest 2026 H2 量產（已宣告）
- E-Core 聯盟落地進度（[[辛耘]] / 天虹 / 群翊 / 上銀同步）
- 2026 H2 進入「小量產」、2027-2028 大量商業化
- 美國 Arizona 據點貼 Intel 供應鏈

### ⚠️ 風險
- **目前虧損 + P/B 11**（已從 200 元拉到 292 元）= 估值已 price in 很多期權
- Intel 良率若卡關 → 直接受傷
- **[[LPKF]] IP 戰（三層威脅，最大 binary risk）**：
  - EPO 2025-03 確認核心 LIDE 專利有效
  - 2025-09 韓國 KPCA 追加專利、2025 中國法律行動三線同步
  - **Intel 2023 專利明寫「LIDE-formed TGV 用於 CPO 架構」** → 即使技術做出來可能被 LPKF IP 鎖在 Intel 鏈門外
  - 唯一活路：證明雷射改質工法不落入 LIDE 專利 claim 範圍
- Hybrid Bonding 替代風險（雖然 sennn.nnna 說「短期不會」）
- TSMC CoPoS 採其他工法 → 鈦昇 design-in 受限

### ⭐ Thesis 校準（codex + LPKF + 手機端 + OSAT entity 校準後）

原 thesis「全球 TGV 雷射改質 first-mover」需要**收窄**為：

> 「**[[LPKF]] 沒進的台積電 CoPoS / 美國 Intel 鏈 second source + Amkor packaging 端的設備供應方**」

理由：
- LPKF 主推韓國 + 自有 Vitrion foundry → 台廠在 Intel Arizona / TSMC 鏈仍有空間
- 但 LPKF IP 威脅是 binary 風險（押的是「技術繞 LIDE + Intel 良率配合 + 美國地緣分散」三重期權）
- **不是「賣水人」而是「期權」**（codex 校準）
- 風險溢價要求應該調高、`thesis_confidence` 標 **low**（雖 `fact_confidence` 是 high）

### 🆕 2026-06 新增校準（手機端 watchlist + OSAT 校準）

**新風險**：
- **Samsung Electro-Mechanics 2026 拿 Apple Baltra + Broadcom 玻璃基板訂單** → 韓系玻璃供應鏈在 LIDE 之外卡位，是直接 thesis 威脅
- 即使鈦昇繞過 LPKF IP，**韓系供應鏈可能拿到 Broadcom design-in**

**新機會**：
- **TSMC CoPoS pilot line 2026-06 完成** → 鈦昇若拿到 TSMC 設備認證 = thesis 確認的最強訊號
- **[[Amkor]] 拿 Intel 玻璃基板 packaging 端獨家**（2028-2029 量產 anchor）→ packaging 整合方鎖定，鈦昇是雷射改質設備供應方，可透過 Amkor Arizona / Songdo K5 鏈進入
- **[[日月光 ASE]] 跟 TPK 中壢 NT$5 億 TGV pilot line（2026-07 完工、Q3 試產）** = 台灣第一條 TGV 整線，鈦昇 / [[辛耘]] 是設備供應方候選

**🎯 追蹤訊號**：
- 鈦昇法說會是否提 TSMC CoPoS / WMCM 認證進度
- Amkor Arizona ramp 進度與鈦昇是否拿到 design-in
