# Tellurian（NASDAQ: TELL）→ **2024 被 Woodside Energy 收購、現為 Woodside Driftwood LNG**

> **⚠️ 重要警語**：Tellurian Inc 已於 **2024-10 完成被 Woodside Energy（澳洲 LNG / NYSE: WDS）以 USD ~$1.2B 收購**、現為 Woodside 旗下「Driftwood LNG」資產、**不再獨立上市**。本 entity 為**歷史 reference + 現 Woodside Driftwood 段**、用於跟 Cheniere / Sempra / Cameron 三家對照、不適用五軸 25 分制評分。

## 1. 一句話定位

**Charif Souki 創立的美國 LNG 出口第二曲線創業（vs 同他創立的 Cheniere 第一曲線）+ Driftwood LNG Texas 27.6 MTPA（4 phases）超大規模計畫 + 2018-2024 融資困境 + Woodside Energy 2024-10 以 USD ~$1.2B 收購 + 改名 Woodside Driftwood LNG + 重啟工程 + 跟 Cheniere / Sempra 並列美國 LNG 三巨頭（但 Woodside 持有 = 澳洲股東主導）**——總部 Houston Texas、2017 Tellurian 上市（merger with Magellan Petroleum）；CEO Charif Souki 是 Cheniere Energy 創辦人（2002 起、2015 離職）、2017 重啟 LNG 出口創業；**Driftwood LNG 計畫**：Texas Lake Charles 附近、27.6 MTPA（4 phases × ~6.9 MTPA each）= **如果完成將是美國 LNG 出口最大廠**（甚至超過 Cheniere Sabine Pass + Corpus Christi 合計 ~55 MTPA）；**2018-2024 融資困境**：股價從 2018 高點 $7+ 跌到 2024-06 $0.50 區間（**99%+ peak drawdown**）、未能 FID（final investment decision）、現金燒盡；**2024-10 Woodside 收購完成**（USD ~$1.2B all-cash、premium ~75% over 30-day VWAP）；**Woodside 接手後重啟**：2024 Q4 宣布 Driftwood Phase 1 FID 重啟、目標 2027-2028 首次商業運轉、Phase 1 ~11 MTPA、Phase 2-4 視市場決定；**Tellurian 跟 Cheniere / Sempra 並列美國 LNG 三巨頭**（但 Woodside 持有 = 澳洲股東主導、sovereign 結構差異）；**非五軸評分**（reference only / 非可投資 entity、需透過 Woodside Energy WDS 間接持有）；對沖 Woodside Energy 業務曝險、是美國 LNG 賽道 sovereign 多元化代表。

## 2. 三層 thesis（reference only / 跟 Woodside Driftwood 現狀 + 跟 Cheniere/Sempra 對照）

### 產業層

- LNG 產業 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
- Driftwood LNG 在 Woodside 接手後加速：
  - 2024-10 Woodside 收購完成
  - 2024 Q4 宣布 Phase 1 FID 重啟、目標 2027-2028 ramp
  - Phase 1 ~11 MTPA = 中等規模美國 LNG 廠（vs Cheniere CCL Stage 3 ~10 MTPA 同級）
- Tellurian 歷史教訓：
  - 2018-2024 是 LNG 出口創業典型失敗案例：融資困境 + 無法達到 FID + 多年股價跌 99%
  - Charif Souki 第二曲線（Tellurian）vs 第一曲線（Cheniere）= 同一 founder 截然不同結果、verify 「**LNG 出口需要強現金流支撐 + 長約 anchor + 大型 strategic partner**」的結構性論點
- 美伊戰後 firm power 第五選擇 anchor 角度：
  - Driftwood LNG 在 Woodside 接手 + 重啟後跟 Cheniere / Sempra 並列美國 LNG 三巨頭
  - 但 Woodside（澳洲）持有 = sovereign 結構差異、美國股東無法直接受惠
- 對應 [[AI infra 電力戰場]]：**第五選擇 firm power anchor 一部分**（透過 Woodside Energy WDS 間接持有）

### 目的層

- **業務組合（Tellurian 歷史 + Woodside Driftwood 現狀）**：
  - **Tellurian 2017-2024 主要資產**：Driftwood LNG 開發權 + Bayou Bend CCS（碳捕集儲存）+ Driftwood Pipeline 中游
  - **Woodside Driftwood LNG 2024-10 後**：Phase 1 ~11 MTPA 重啟、目標 2027-2028 ramp、Phase 2-4 視市場
- **核心產品**：
  - Driftwood Phase 1 完成後 ~11 MTPA LNG 出口
- **客戶結構**（**待 ramp**）：
  - 2024 Woodside 收購前 Tellurian 多年無法簽長約（融資困境主因）
  - Woodside 接手後可能利用澳洲 + 全球客戶網絡（Shell / BP / Total / JERA / KOGAS / Aramco）重簽長約
- 商業模式核心：
  - **「Driftwood Phase 1 ramp + Woodside 澳洲 LNG 全球客戶網絡 + Texas Lake Charles 地理」**
  - Woodside 是「澳洲 LNG #2」（vs Chevron / Shell Australia LNG #1 / #3）、Driftwood 加入後成「澳洲 LNG #2 + 美國 LNG 新進玩家」雙引擎
- 對應 [[賣水人選股邏輯（投資版）]]：透過 Woodside Energy WDS 間接持有 = 不直接 anchor 美國 LNG 出口賽道

### 供應層

- 跟 [[Cheniere Energy]] 對比（**Charif Souki 兩條曲線 + 美國 LNG 結構性教訓**）：
  - **Cheniere（第一曲線、Charif Souki 2002-2015 創立並離職）**：成功 ramp 至美國 LNG #1（~50% 出口、SPL + CCL 兩大廠 ~55 MTPA）
  - **Tellurian（第二曲線、Charif Souki 2017-2024 創立並失敗）**：融資困境 + 99% drawdown + 2024-10 賣給 Woodside
  - → 同一 founder 截然不同結果、**verify LNG 出口需要「強現金流 + 長約 anchor + 大型 strategic partner」**結構性論點
  - Cheniere 受惠俄烏戰後（2022）+ 美伊戰後（2025-2026）兩次 windfall、Tellurian 錯過時點
- 跟 [[Sempra LNG]] 對比（**LNG 雙頭 + utility 多元 vs LNG pure-play 創業失敗**）：
  - Sempra：utility 母體穩定 + Cameron + Port Arthur + ECA Mexico 三線 LNG + 19/25 五軸
  - Tellurian：pure-play LNG 創業 + 無 utility 母體 + 融資困境 + 賣給 Woodside
  - → Sempra utility 多元化勝、Tellurian pure-play 無母體支援死於融資
- 跟 [[Cameron LNG]] 對比（**Sempra 50.2% 持股 anchor vs Woodside 100% 收購**）：
  - Cameron LNG：Sempra 50.2% 主控 + Total / 三井 / 三菱合資、多方治理
  - Driftwood LNG：Woodside 100% 持股、單一股東決策
  - → Woodside 結構性決策更快、但澳洲股東 + 無美國上市
- 跟 Woodside Energy WDS（**現持股母公司**）：
  - Woodside 是澳洲 LNG #2（vs Chevron / Shell Australia LNG）、市值 USD ~$40-50B
  - Woodside 收購 Driftwood = **澳洲 LNG 跨進美國市場**結構性 anchor
  - 跟 Cheniere / Sempra 競爭 = 多了一個澳洲玩家進入美國 LNG 出口賽道
- 治理變化：
  - 2017-2024 Tellurian：Charif Souki + 多位 Cheniere alumni 管理
  - 2024-10 後 Woodside Driftwood：Woodside 澳洲團隊 + 部分 Tellurian alumni 留任
- 護城河 / 風險：
  - **Driftwood LNG 工程進度**：Phase 1 重啟需 2027-2028 ramp
  - **Woodside 整合風險**：澳洲管理 + 美國運營文化差異
  - **澳洲 sovereign 結構**：美國股東無法直接持有（需買 WDS）
  - **客戶長約待簽**：Driftwood Phase 1 ramp 前需大量長約 anchor
  - **FERC + 環評**：Phase 1 重啟仍需法規審批
  - **Phase 2-4 不確定**：取決於市場前景 + Woodside 戰略決策

### ⭐ Tellurian 教訓（LNG 出口創業失敗典型）

| 維度 | Tellurian 失敗教訓 | vs Cheniere 成功 |
|---|---|---|
| **融資 anchor** | 無大型 strategic partner、無長期 SPA 鎖定 | 早期跟 BP / Shell / Total 簽 20 年 SPA、現金流 anchor |
| **FID 時點** | 多年無法達到 FID（2017-2024）| 2012 Train 1 FID、2016 首次出口 |
| **市場時機** | 錯過俄烏戰後（2022）+ 美伊戰後（2025-2026）兩次 windfall | 兩次 windfall 都受惠 |
| **管理層** | Charif Souki（Cheniere 創辦人）但 Tellurian 是其第二曲線 | Cheniere alumni 集體管理、深度 LNG 出口運營經驗 |
| **結果** | 99%+ 股價 drawdown、2024-10 賣給 Woodside | 美國 LNG 出口 #1 + Forward PE 12-15x |

→ **LNG 出口創業需要「強現金流 + 長約 anchor + 大型 strategic partner + FID 時點」四要素全滿**
