# Sempra（NYSE: SRE、含 Sempra Infrastructure LNG segment）

## 1. 一句話定位

**California utility 母公司 + Sempra Infrastructure LNG 段 + Cameron LNG 50.2% 持股主控 + Port Arthur LNG 全棧 + ECA LNG Mexico 太平洋出口 + AI infra 電力戰場 firm power 第五選擇 anchor（utility 多元版）**——總部 San Diego CA、1998 由 Enova（San Diego Gas & Electric）+ Pacific Enterprises（SoCalGas）合併形成、全美最大綜合能源 utility 集團之一；**兩大業務段**：(1) **Sempra California**（SDG&E 聖地牙哥 + SoCalGas 南加 utility，2,500萬人服務、regulated rate base）+ (2) **Sempra Infrastructure**（LNG 出口 + Mexico utility + 太平洋 LNG 戰略平台）；**Sempra Infrastructure LNG 全棧**：(a) **Cameron LNG Phase 1 完成 ~12 MTPA**（2019、Sempra 持股 50.2% + Total 16.6% + 三井 16.6% + 三菱 16.6%）+ (b) **Cameron LNG Phase 2 ~6.75 MTPA**（2025-2027 擴張）+ (c) **Port Arthur LNG Phase 1 ~13 MTPA**（2027-2028 ramp）+ (d) **ECA LNG Mexico 太平洋 Phase 1 ~3.25 MTPA**（2025-2026 ramp、唯一太平洋出口、規避巴拿馬運河）；客戶 TotalEnergies / 三菱 / 三井 / KOGAS / Saudi Aramco 多元；FY 2025 估算營收 USD ~$13-15B / Adj EBITDA $4.5-5.5B / Forward PE **18-22x**、市值 USD ~$50-55B / Mega Cap；12 個月漲幅 **+10-30%**（utility 屬性穩定、AI exposure 尚未完全 reflected）；**美伊戰後 firm power 第五選擇 anchor（utility 多元版）**：跟 [[Cheniere Energy]] LNG pure-play 22 形成「**LNG 雙頭」**（Cheniere pure-play vs Sempra utility 多元）、跟 [[AI infra 電力戰場]] 整鏈互補；五軸 **19/25**（路線 4 + 站別 4 + 耗材 4 + IP 3 + 客戶分散 4）= 略低於 Cheniere 22，差異在 utility mix-and-match 路線敏感稍弱 + IP 規模型集團 know-how 略弱、但 utility 多元 + Cameron 持股 + Port Arthur 全棧 + ECA Mexico 太平洋差異化是結構性護城河。

## 2. 三層 thesis

### 產業層

- LNG 產業 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段、Sempra 是「LNG 出口 + utility 雙引擎」混合曝險
- 戰後（美伊戰爭後）物理現實：
  - **Qatar Ras Laffan -17% 產能**（修復 3-5 年）+ 2030 累積缺口 **1,200 億立方公尺**
  - **5 個不可逆結構轉變**（[[FOMO SOC KP #46 — LNG 能源結構重塑（美伊戰後五大不可逆轉變）]]）→ Sempra 是 LNG 出口 #2 美國玩家
- 美國 LNG 出口三波：
  - **第一波**（2016-2022）：Cheniere 出口先發
  - **第二波**（2022-2024）：俄烏戰後歐洲被迫向美國買 LNG、Sempra Cameron Phase 1 跟進
  - **第三波 ⭐**（2025-2030）：美伊戰後 + AI 海外 hyperscaler firm power、Sempra Cameron Phase 2 + Port Arthur Phase 1 + ECA Mexico 三線並進 ramp
- California utility 母體：
  - SDG&E + SoCalGas 加州 utility 段 ~50-55% 營收、regulated rate base、穩定 ROE
  - 加州 AI 資料中心擴張（Bay Area + LA + Riverside / San Bernardino）→ utility 段間接受惠
  - 加州 wildfire 風險 + PUC 法規調整持續
- Mexico utility 段（IEnova、Sempra Infrastructure 一部分）：
  - 北墨西哥 utility + LNG terminal + pipeline 全棧
  - 對沖美國 utility 集中度、增加 LatAm 曝險
- 對應 [[AI infra 電力戰場]]：**第五選擇 firm power anchor（utility 多元版）**
- 對應 [[宋分 ＃20 — 能源結構性剛需]] **三標準全滿**：供給結構改變 + Cameron Phase 2 + Port Arthur Phase 1 CapEx $15B+ + LNG 20 年現金流
- 對應 [[控制點轉移（投資版）]]：跟 Cheniere 同樣**美國 LNG 從「價格接受者」→「價格制定者」**、Sempra 是次強受惠者
- 對應 [[Bottleneck Theory（瓶頸論）]]：**ECA LNG Mexico 太平洋 = 規避 Hormuz + 規避巴拿馬運河 chokepoint**、是美國 LNG 出口賽道唯一太平洋路徑 anchor

### 目的層

- **業務組合（2025 為主、2026-2028 Cameron Phase 2 + Port Arthur Phase 1 + ECA Mexico ramp 後 mix 改變）**：
  - **Sempra California（regulated utility）**：~50-55% 營收（SDG&E + SoCalGas、stable rate base）
  - **Sempra Infrastructure LNG**：~30-35% 營收（Cameron + Port Arthur + ECA Mexico）
  - **Sempra Infrastructure Mexico utility**：~10-15% 營收（IEnova、北墨西哥 utility + pipeline）
- **核心 LNG 資產**：
  - **Cameron LNG Phase 1**（2019 完成、~12 MTPA、Sempra 50.2% + Total 16.6% + 三井 16.6% + 三菱 16.6%）
  - **Cameron LNG Phase 2**（2025-2027 擴張 +~6.75 MTPA、Sempra 控股結構類似）
  - **Port Arthur LNG Phase 1**（2027-2028 ramp ~13 MTPA、Sempra 控股 + ConocoPhillips 25% + KKR 持股）
  - **ECA LNG Mexico Phase 1**（2025-2026 ramp ~3.25 MTPA、唯一太平洋出口、Sempra 主持）
  - **總容量 ramp 完成（2028）= ~35 MTPA**（vs Cheniere ~55 MTPA、Sempra 是美國 LNG #2）
- **客戶結構**（hyperscaler 海外資料中心間接 anchor）：
  - **TotalEnergies** Cameron Phase 1 主客戶（部分股權）
  - **三菱 / 三井 商社** Cameron Phase 1 主客戶（部分股權）
  - **KOGAS** Port Arthur Phase 1 長約
  - **Saudi Aramco** Port Arthur Phase 1 長約（中東買 LNG 反向 hedge）
  - **JERA / 東京 Gas 日本電力公司** 多家
  - hyperscaler 間接連結：Sempra LNG → 歐洲 / 日韓 / 印度電力公司 → hyperscaler 海外資料中心
- **2026-2028 重大催化**：
  - **Cameron LNG Phase 2 商業運轉**（2025-2027 分批 ramp）
  - **Port Arthur LNG Phase 1 商業運轉**（2027-2028 ramp）
  - **ECA LNG Mexico 太平洋 Phase 1 商業運轉**（2025-2026 ramp、規避巴拿馬運河 + Hormuz 雙重 chokepoint）
- 商業模式核心：
  - **「美國 LNG 出口 #2 + California utility 母體 + 規模 + Mexico 多元 + 太平洋差異化」**
  - **規格控制權**：標準化 LNG train + Henry Hub 採購公式（vs Cheniere 12 年運營 know-how 略遜）
  - **服務 recurring**：LNG 長約 + utility regulated rate base = 結構性現金流
  - **utility 多元護城河**：母公司含 California utility + Mexico utility = 比 Cheniere pure-play 多元化（防守性勝、alpha 略遜）
  - **太平洋出口差異化**：ECA Mexico 是美國 LNG 出口唯一太平洋路徑 = 服務日韓 / 印度市場無需經過巴拿馬運河
- 對應 [[賣水人選股邏輯（投資版）]]：**LNG + utility 雙引擎 anchor + 多元規模型**（vs Cheniere pure-play 純度型）
- 對應 [[控制點轉移（投資版）]]：拿到「**LNG + California utility + Mexico utility + 太平洋出口差異化**」四段控制點

### 供應層

- 跟 [[NVDA]] / hyperscaler 路線：**間接綁定**（不直接賣 NVDA / hyperscaler、賣給歐洲 / 日韓 / Mexico 電力公司 / utility → 為 hyperscaler 海外資料中心 + 加州境內 DC 發電）
- 跟 hyperscaler 海外資料中心連結（**2026-2030 結構性放大**）：
  - **AWS / Azure / Google** 加州資料中心 + 歐洲 / 日韓 / Mexico 資料中心
  - **LNG anchor + utility 母體雙引擎**：服務加州境內 hyperscaler DC（utility）+ 服務海外 hyperscaler DC（LNG 出口）
- 跟 [[Cheniere Energy]] 對比（**LNG 出口雙頭**）：
  - **Cheniere LNG（22/25）**：**美國 LNG 出口 #1（50%+）+ pure-play 出口商 + SPL + CCL 兩大廠 ~55 MTPA + SPA 80% 長約**、估值乾淨 PE 12-15x
  - **Sempra（19/25）**：**美國 LNG #2（~25-30%）+ Cameron + Port Arthur + ECA 三大廠 ~35 MTPA + utility 母公司多元**、估值 18-22x（utility 溢價）
  - → Cheniere 是 **pure-play alpha + 純度勝**、Sempra 是 **utility 多元 + 防守性勝 + 太平洋差異化**
- 跟 [[Cameron LNG]] 連結（**Sempra Infrastructure 50.2% 持股 anchor**）：
  - Cameron LNG 是 Sempra Infrastructure 50.2% 持股 + Total 16.6% + 三井 16.6% + 三菱 16.6% 合資、**非獨立上市**
  - Cameron Phase 1 已運轉 ~12 MTPA + Phase 2 2025-2027 ramp +~6.75 MTPA
  - **Sempra 透過 50.2% 持股 = 間接受惠 Cameron LNG 全週期**
  - Cameron LNG entity 在 wiki 中是 reference only（非投資標的）、Sempra 是 Cameron 的「可投資載體」
- 跟 [[Tellurian]]（→ Woodside Driftwood LNG）對比（**reference only / 已被 Woodside 收購**）：
  - Tellurian 2024 被 Woodside Energy（澳洲 LNG）收購、改名 Woodside Driftwood LNG
  - Sempra 仍是純美國上市 + California utility 母體 = sovereign 結構性勝
- 跟 [[Constellation Energy]] / [[Vistra]] / [[GE Vernova]] / [[Bloom Energy]] 對比（**firm power 五選一**）：
  - **CEG / VST**：境內 firm power（核電 + 氣電）
  - **GEV**：境內 + 全球變壓器 + 燃氣輪機
  - **Bloom**：境內 SOFC 分散式
  - **Sempra**：**境內加州 utility + 境外 LNG 出口雙引擎**（utility 多元版）
  - **Cheniere**：境外 LNG 出口 pure-play
  - → Sempra 是 **firm power 五選一中唯一兼具「境內 utility」+「境外 LNG」雙引擎**
- 跟 SoCalEdison / PG&E 加州 utility 同業：
  - SDG&E + SoCalGas vs Edison / PG&E：Sempra 是加州第二大 utility（next to PG&E）
  - 加州 wildfire 風險 + PUC 法規調整持續
- 跟 ExxonMobil / Shell / TotalEnergies LNG integrated majors：
  - Sempra 是 LNG + utility 雙引擎 hybrid、vs 整合石油大廠 LNG 是 mix-and-match 一段、Sempra 更聚焦
- 護城河：
  - **物理資產**：Cameron + Port Arthur + ECA Mexico 三大廠 ~35 MTPA、複製 8-10 年 + USD $15B+ CapEx
  - **California utility regulated rate base**：穩定 ROE 9-10%、抗景氣循環
  - **Cameron LNG 50.2% 持股 + 國際 JV partners**（Total / 三菱 / 三井）= 政治平衡 + 客戶 lock-in
  - **太平洋出口差異化（ECA Mexico）**：規避巴拿馬運河 + Hormuz 雙重 chokepoint
  - **政治紅利**：Trump 政府支持 LNG 出口 + 加州 utility regulated 穩定
- 風險：
  - **加州 wildfire 責任**：SDG&E / PG&E 都面臨 wildfire 法律責任（Camp Fire 2018 / Dixie Fire 2021 等）
  - **California PUC 法規調整**：rate case 審批週期 + 環評要求
  - **Cameron / Port Arthur ramp 延宕**：工程風險 + 環評 + 法規審批
  - **Qatar Ras Laffan 修復快於 3-5 年**：可能下修缺口估算
  - **歐洲再生能源加速**：wind + solar + 儲能取代 LNG 中期需求
  - **CSP 自建 LNG terminal**：MSFT / AWS 自建中游 / 上游氣電可能擠壓中介商
  - **颶風 + 氣候風險**：Cameron + Port Arthur 都在墨西哥灣 / Texas 颶風走廊
  - **Mexico 政治風險**：墨西哥能源政策反轉（如 AMLO 2018-2024 國有化趨勢）
  - **JV partners 不和**：Total / 三菱 / 三井 多方治理複雜
  - **PE 18-22x 已 partial price in**：但 utility 屬性穩定 + LNG 雙引擎 thesis 仍 fresh
