# Cadence Design Systems（NASDAQ: CDNS / 益華科技）

## 1. 一句話定位

**EDA（電子設計自動化）全球 #2（~28% 市佔，跟 [[Synopsys]] ~33% + [[Siemens]] EDA ~17% 形成「**EDA 三巨頭分食 78%**」）+ 1988 成立（Cadence 由 SDA Systems + ECAD 合併創立）+ Custom IC / analog IC 設計工具領先 + Spectre circuit simulator 業界標竿 + Tensilica DSP IP 全球 audio / 通訊 DSP 標準 + 2024 Q4 收購 BETA CAE Systems（multiphysics simulation）+ 2025 收購 Hexagon's design & engineering 部分 + AI agent for chip design（Cerebrus / Verisium / Allegro X AI）first-mover 跟進 + 跨晶片設計 / IP 授權 / system simulation + 任何晶片設計都要用 SNPS + CDNS 雙頭工具 = 全行業 fabless / IDM AVL**——納斯達克上市、總部 San Jose（加州）；不做晶片本身、**只做設計工具 + IP**；產品涵蓋 Virtuoso Custom IC / Allegro PCB / Spectre simulator / Innovus place & route / Tempus signoff / Genus synthesis / Tensilica DSP / Palladium emulation / Protium FPGA prototyping / Helium SiPho / Allegro X AI；跟 [[Synopsys]] 形成「**EDA 雙頭 + Siemens EDA 第三**」結構性寡占、毛利率 ~70%+、**全行業 fabless / IDM / SoC 設計都要用 SNPS + CDNS 雙頭**。在 [[賣水人選股邏輯（投資版）]] 是「**真正的『賣水人之中的賣水人』**」（不押 NVDA / AMD / TSMC / 任何晶片公司、押**所有晶片設計都要 CDNS**）、估值 22-23/25 頂級（略低 SNPS 24/25 主因 IP 廣度稍弱但 Custom IC 不可繞過）、跟 [[Disco Corp]] / [[村田 Murata]] / [[信越化學]] / [[SUMCO]] / [[Synopsys]] / [[Imec]] 並列「**架構級『賣水人之中的賣水人』**」第二陣營。

## 2. 三層 thesis

### 產業層

- **EDA 全球市佔**（Q1 2026 推估）：[[Synopsys]]（~33%）+ **Cadence（~28%）**+ Siemens EDA（~17%）+ 其他（~22%）= 三巨頭 78% 寡占
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「驗證 → 共識」加速段**——
  - 驗證已完成：FY2024-2025 多季財報持續超預期、AI 晶片設計 Cerebrus / Verisium 全面導入、訂單 backlog $6.7B+
  - 共識中：Forward PE 仍 40-50x（vs SNPS 35-45x、略貴於 SNPS、跟 Custom IC + analog 不可繞過匹配）
- 在 [[資訊擴散四階段]]：機構長期覆蓋、賣方深度分析、媒體層熱炒 AI 設計、ETF 大量配置（軟體 + 半導體 ETF）
- TAM：
  - EDA 全市場：2024 USD ~$15-18B → 2030 USD $30B+（CAGR ~12-15%）
  - AI 晶片設計 + AI agent 自動設計：新增 TAM 翻倍
  - BETA CAE + Hexagon D&E 整合後 system simulation：跨產業擴張 TAM（航太 + 汽車 + 工業 multiphysics）
- 跟 [[AI infra CapEx 三階段論]] 視角：
  - 第一階段（CSP CapEx）：間接受惠（NVDA / AMD / hyperscaler 自家 ASIC 設計需求）
  - 第二階段（NVDA 落地）：直接受惠（NVDA / AVGO / Marvell / 自研 ASIC 都要 CDNS、Custom IC analog 部分尤其依賴 Virtuoso + Spectre）
  - 第三階段（上游材料爆掉）：間接受惠（fab 製程 R&D 設計工具需求）
- [[Bottleneck Theory（瓶頸論）]] 視角：CDNS = **設計鏈 chokepoint**（任何 Custom IC + analog 設計繞不開 Virtuoso + Spectre、IP 授權生態 lock-in）
- 跟 [[賣水人選股邏輯（投資版）]]「賣水人之中的賣水人」：跟 [[Disco Corp]] / [[村田 Murata]] / [[信越化學]] / [[SUMCO]] / [[Synopsys]] / [[Imec]] 同級（CDNS 22/25 略低於 SNPS 24/25 但屬於同一陣營）

### 目的層

- 真實角色：**「EDA 全球 #2 + 任何 Custom IC + analog 設計都要用 CDNS + Virtuoso + Spectre 業界標準 + Tensilica DSP IP + AI agent for chip design 跟進 first-mover」**——不是「跟 fab 競爭」（vs TSMC / Samsung / Intel）、不是「跟 fabless 競爭」（vs NVDA / AMD / Apple）、是「**所有 fab / fabless / IDM 共用的設計工具供應商**」、特別在 Custom IC + analog + mixed-signal 不可繞過
- 業務組合（FY2025 推估）：
  - **EDA Software（synthesis / P&R / verification / Custom IC / analog）**：~60%
  - **IP（Tensilica DSP / Denali memory / SerDes / PCIe / DDR / Ethernet 等標準 IP 授權）**：~20%
  - **System Design & Analysis（BETA CAE multiphysics + Hexagon D&E + Allegro PCB + Spectre + Palladium emulation）**：~15%
  - **服務 + 教育 + 培訓**：~5%
- 商業模式：
  - **訂閱制 + maintenance**（recurring 高、毛利率 70%+）
  - **AI agent ARR 加價**（Cerebrus / Verisium / Allegro X AI = 額外 ARR）
  - **IP 授權**（Tensilica DSP / Denali memory / SerDes 自有專利）
  - **System simulation 整合 BETA CAE + Hexagon D&E**（跨晶片 / 航太 / 汽車 / 工業 multiphysics）
- 核心 IP / 護城河：
  - **Custom IC + analog 設計工具生態 lock-in**（Virtuoso + Spectre 30+ 年累積、analog / mixed-signal 不可繞過）
  - **Spectre circuit simulator**（業界 SPICE simulator 標竿、analog IC 設計師必用）
  - **Tensilica DSP IP**（全球 audio / 通訊 / 影像 DSP 標準、Qualcomm / Apple / NVDA / Samsung / MediaTek 都用）
  - **Denali memory IP**（DDR / LPDDR / HBM memory subsystem 業界標準之一）
  - **AI agent for chip design**（Cerebrus 自動 P&R / Verisium AI verification / Allegro X AI PCB layout）
  - **跨產業 lock-in**（fabless + IDM + 航太 + 汽車 + 工業 multiphysics + system simulation）
  - **客戶 lock-in 強度**：NVDA / Apple / Qualcomm / Intel / AMD / TSMC / Samsung 全 AVL、設計流程 deep integration
- 對應 [[賣水人選股邏輯（投資版）]]：**「真正的『賣水人之中的賣水人』」**——不押 NVDA / AMD / TSMC / 任何晶片公司、押**所有晶片設計都要 CDNS**（特別 Custom IC + analog 不可繞過）
- 對應 [[控制點轉移（投資版）]]：拿到「**Custom IC + analog 設計工具 lock-in + Spectre simulator 業界標準 + Tensilica DSP IP + AI agent first-mover**」四層 chokepoint、控制權結構性
- 對應 [[半導體基礎建設化]]：EDA 是「**全行業設計基礎建設**」、Re-rate 從週期軟體 → AI infra 元件級
- 對應 [[開源作為武器（投資版）]]：⚠️ CDNS 是**閉源 / 訂閱制**、跟開源 EDA（Yosys / Berkeley ABC / iVerilog）對比反向

### 供應層

- 跟 [[Synopsys]] 關係（**核心對手 + 雙頭壟斷 partner**）：
  - **EDA 雙頭壟斷**（合計 ~61% 全球市佔）
  - 競爭 / 互補：**CDNS Custom IC + analog + Spectre simulator 領先 / SNPS synthesis + verification + DesignWare IP 領先**
  - 客戶通常**雙頭採用**（fabless / IDM 用 SNPS + CDNS 雙頭工具、各有所長）
  - 兩家不正面降價戰、共同壓制 Siemens EDA + 開源
  - **AI agent for chip design**：SNPS DSO.ai / AI.Copilot first-mover、CDNS Cerebrus / Verisium 跟進、兩家技術路線競賽
- 跟 Siemens EDA 關係（EDA 第三）：
  - Siemens EDA ~17% 市佔（前 Mentor Graphics、2017 Siemens USD $4.5B 收購）
  - 強項：**PCB design Xpedition + Calibre DRC/LVS（驗證流程業界標準）**
  - 整合進 Siemens Xcelerator 工業軟體 + NVDA Omniverse 工業數位孿生（2024-03）
  - 落後 SNPS + CDNS 雙頭壟斷
- 跟 [[NVDA]] / [[AMD]] / [[AVGO]] / Marvell / Apple / Qualcomm 關係：
  - **所有 fabless 都採用 CDNS（多數雙頭 SNPS + CDNS）**
  - NVDA Rubin / Vera / Blackwell SoC 設計：CDNS Custom IC + analog 部分主導（Virtuoso + Spectre）
  - AMD MI300 / MI400 / Genoa：CDNS analog mixed-signal 部分主導
  - AVGO Tomahawk 5/6 + Marvell DSP：CDNS 工具部分主導
  - Apple M / A 系列：CDNS analog / DSP 部分主導（也用 SNPS）
  - **Qualcomm**：Tensilica DSP IP 重度授權客戶
- 跟 [[TSMC]] / [[Samsung Electronics]] / [[Intel]] / [[GlobalFoundries]] 關係：
  - **fab 全部支援 CDNS 工具 PDK（process design kit）**
  - TSMC 2nm / 3nm / Samsung 2nm / Intel 18A / GlobalFoundries 22FDX 全 PDK 都用 SNPS + CDNS 雙頭
  - **TSMC OIP（Open Innovation Platform）認證**：CDNS Virtuoso + Spectre 是 TSMC analog / Custom IC 認證標準工具
- 跟 [[Imec]] 關係：
  - Imec R&D + CDNS PDK / EDA 工具支持 pre-competitive R&D
  - CDNS 是 Imec 200+ 會員之一
- 跟自研 ASIC / hyperscaler 關係：
  - **Google TPU / AWS Trainium + Inferentia / Microsoft Maia / Meta MTIA 全部用 CDNS 工具設計**（雙頭 SNPS + CDNS）
  - hyperscaler 自研 ASIC ramp → CDNS TAM 結構性擴張
  - **特別 analog mixed-signal + SerDes + DDR memory subsystem** 部分 Custom IC 設計 = CDNS 強項
- 跟 [[AI infra CapEx 三階段論]] 視角：
  - CDNS 跨三個階段都受惠（軟體 + IP 訂閱制）
- 跟 BETA CAE Systems 收購（2024 Q4 完成）：
  - **multiphysics simulation + CAE 工具整合**（航太 + 汽車 + 工業）
  - 跟 SNPS Ansys USD $35B 併購類似戰略（規模小、~USD $400-600M 推估）
  - 整合進 Cadence System Design & Analysis 業務段
- 跟 Hexagon's Design & Engineering 部分收購（2025 完成）：
  - **MSC Software（multiphysics simulation）+ AEC（建築工程）部分整合**
  - 進一步擴大 system simulation TAM
- 跟 AI agent for chip design（Cerebrus / Verisium / Allegro X AI）：
  - **Cerebrus**：自動 P&R + signoff（深度強化學習）
  - **Verisium**：AI verification（自動測試生成）
  - **Allegro X AI**：PCB layout 自動化
  - 跟 SNPS DSO.ai / AI.Copilot 路線競賽
- 跟 [[NVDA]] AI Foundation Models for chip design（2024 GTC 公告）：
  - **NVDA + SNPS + CDNS + Siemens EDA 三家都在做 AI agent for chip design 合作**
  - NVDA 提供 AI Foundation Models（NeMo / NIM）+ EDA 廠提供工具整合
  - SNPS DSO.ai / CDNS Cerebrus / Siemens EDA Aprisa AI 路線競賽
- 跟開源 EDA（Yosys / Berkeley ABC / iVerilog 等）對比：
  - 開源 EDA 在 RISC-V 社群有部分採用
  - 商業 fab / fabless 仍 100% 用 SNPS + CDNS（驗證 / DFT / sign-off 工具開源無法替代）
  - CDNS 結構性壟斷不被開源威脅
- 護城河：
  - **Custom IC + analog 設計工具生態 lock-in + 30 年累積**
  - **Spectre simulator 業界標竿**
  - **Tensilica DSP IP**（audio / 通訊 / 影像 DSP 標準）
  - **AI agent for chip design 跟進 first-mover**
  - **訂閱制 + maintenance recurring + 毛利率 70%+**
  - **客戶 lock-in 強度極高**（設計流程 deep integration、切換成本極高）
- 風險：
  - **AI agent 競爭加劇**（SNPS DSO.ai first-mover + Google / OpenAI 部分競爭）
  - **BETA CAE + Hexagon D&E 整合 ramp 不確定**
  - **vs SNPS 規模差距**（SNPS ~33% vs CDNS ~28%、SNPS Ansys $35B 規模大於 CDNS BETA CAE + Hexagon）
  - **開源 EDA long term**（RISC-V 社群推開源 EDA）
  - **EDA TAM 增速放緩**（核心 EDA 軟體 CAGR ~10%、AI agent 額外溢價）
  - **晶片設計 cycle 週期性**（fabless / IDM CapEx 波動）
  - **Forward PE 40-50x 已 price in**（vs SNPS 35-45x、略貴）
  - **中美脫鉤 + 中國市場限制**（美 BIS 限制 CDNS 對中國 fab 出口）
  - **客戶集中度**：前 5 大客戶（NVDA / AMD / Intel / TSMC / Samsung）合計 25-30%

- **Cerebrus Intelligent Chip Explorer**：自動 P&R + signoff（深度強化學習）
- **Verisium AI**：AI verification（自動測試生成 + bug hunting）
- **Allegro X AI**：PCB layout 自動化
- **JedAI Platform**：generative AI for chip design platform
- **AI agent ARR pricing**：客戶加價 25-40% 額外
- **TAM 翻倍可能**（純 EDA $15-18B → AI agent 自動設計可能加 $5-10B）

→ AI agent = CDNS 的「**第二曲線**」、跟 BETA CAE + Hexagon D&E 整合 system simulation 並列雙引擎、跟 SNPS DSO.ai / AI.Copilot 路線競賽

## ⭐ Cadence vs Synopsys 互補關係（雙頭分工）

| 工具類型 | Synopsys 強項 | **Cadence 強項** |
|---|---|---|
| **RTL synthesis** | ✅✅✅ Design Compiler / Fusion Compiler 業界標準 | ✅ Genus（追趕） |
| **Place & Route** | ✅✅ IC Compiler II / Fusion Compiler | ✅✅ Innovus（追趕） |
| **Verification** | ✅✅✅ VCS simulator + Verdi debug 業界標準 | ✅ Xcelium（追趕） |
| **Custom IC + analog** | ✅ Custom Compiler（弱於 CDNS） | ✅✅✅ **Virtuoso 業界標準** |
| **Circuit simulator** | ✅ HSPICE / FineSim | ✅✅✅ **Spectre 業界標竿** |
| **DFT / signoff** | ✅✅✅ TetraMAX + PrimeTime 業界標準 | ✅ Modus + Tempus（追趕） |
| **PCB design** | ✅ 弱 | ✅✅ Allegro PCB（強、僅次 Siemens EDA Xpedition） |
| **Emulation** | ✅✅ ZeBu | ✅✅✅ **Palladium 業界標竿** |
| **DSP IP** | ✅ ARC DSP（弱於 CDNS） | ✅✅✅ **Tensilica audio / 通訊 / 影像 DSP 標準** |
| **Memory IP** | ✅✅ DesignWare DDR / HBM | ✅✅✅ **Denali 業界標準** |
| **SerDes / PCIe / Ethernet IP** | ✅✅✅ DesignWare 業界標準 | ✅✅ 強 |

→ **核心差異**：
- **SNPS**：digital flow（synthesis + verification + DFT + signoff）+ DesignWare IP 廣度 + Ansys multiphysics 規模
- **CDNS**：**Custom IC + analog + mixed-signal + Spectre simulator + Tensilica DSP + Palladium emulation 深度 + Denali memory IP**

→ **客戶都雙頭採用**（fabless / IDM 必用 SNPS + CDNS）

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| **路線敏感度（逆向）** | **5 / 5** | 不押 NVDA / AMD / TSMC / 任何晶片公司、所有 fab / fabless 設計都要 CDNS（特別 Custom IC + analog 不可繞過） |
| **站別關鍵度** | **5 / 5** | EDA 全球 #2 + Custom IC + analog + Spectre simulator + Tensilica DSP IP + Palladium emulation 業界標準 + 設計鏈 chokepoint |
| **耗材 recurring** | **5 / 5** | 訂閱制 + maintenance + IP 授權 recurring（年金型）、backlog $6.7B+ |
| **IP 控制** | **4 / 5** | Tensilica DSP + Denali memory + Virtuoso + Spectre + Palladium 強 IP；扣 1 因 IP 廣度略遜 SNPS DesignWare（USB / PCIe / DDR / Ethernet / SerDes 業界標準）|
| **客戶分散** | **3 / 5** | fabless + IDM + hyperscaler + 航太 + 汽車 + 工業全 AVL、極度分散；扣 2 因前 5 大客戶（NVDA / AMD / Intel / TSMC / Samsung / Qualcomm）合計 30%+ 集中、規模略小於 SNPS |

**總分 = 22 / 25** —— 跟 [[Synopsys]] 24 並列 EDA 雙頭、跟 [[Disco Corp]] 24 / [[村田 Murata]] 24 / [[信越化學]] 24 / [[SUMCO]] 24 / [[Imec]] 24（特殊）「頂級真賣水人」陣營（CDNS 略低 2 分）；**「架構級『賣水人之中的賣水人』第二陣營 anchor」**；EDA 全球 #2 + Custom IC + analog + Spectre simulator + Tensilica DSP IP + AI agent for chip design 跟進 first-mover。

→ 比 [[Synopsys]] 24 低 2 分主要在：**IP 廣度稍弱**（DesignWare USB / PCIe / DDR / Ethernet / SerDes 業界標準範圍大於 Tensilica DSP）+ **規模差距**（CDNS ~$85-105B vs SNPS ~$90-110B、CDNS BETA CAE + Hexagon D&E 規模小於 SNPS Ansys $35B 併購）；但 **Custom IC + analog 設計不可繞過** 是 CDNS 的結構性護城河、是 fabless 設計鏈剛性需求。
