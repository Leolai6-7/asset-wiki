# 景碩（3189.TW）

## 1. 一句話定位

**ABF 載板第三大 + BT 載板強項**（ABF 40% + BT 33% + 隱形眼鏡 18% + 基地台 5%）、產品線**中階為主**、近期打入 NVDA AI GPU 第三供應商 + 美系 AI CPU 供貨率 10%→50%；在 [[ABF 載板 vs 玻璃基板 displacement]] 是「**相對受益者**」——高階 AI ASIC 玻璃化打的是欣興/南電/IBIDEN，景碩中階產品**反而吃到三大主力外溢訂單**，BT 載板也受惠 T-glass 缺料漲價。

## 2. 三層 thesis

### 產業層

- ABF 載板 [[市場四階段：懷疑／驗證／共識／反轉]]「驗證 → 共識」加速段
  - ABF 載板 2028 缺口 35%、景碩產能利用率 86% → 95%
  - 2026-2027 持續擴產、ABF 產能 +25%
- 與 [[玻璃基板與 FOPLP 賽道]] 的關係：**最不直接威脅**——景碩主力在中階 CPU/伺服器，不在 AI ASIC 旗艦
- 與 [[ABF 載板 vs 玻璃基板 displacement]]：concept 預測「中低階守住、相對受益」**完全成立**
  - 玻璃化打 Intel Clearwater Forest / AMD MI / Broadcom ASIC 旗艦
  - 景碩主力在 Intel Sapphire/Emerald/Granite/Sierra Forest 中階 CPU、AMD EPYC 中階、AI server CPU
  - 高階 AI GPU/ASIC 玻璃化 = 競爭少了
- T-glass 缺料 → BT 載板漲價直接受惠（BT 33% 是景碩高曝險段）

### 目的層

- 主業 mix（2025-2026）：
  - **ABF 載板 40%**（持續提升中）
  - **BT 載板 33%**
  - **隱形眼鏡 + 消費（記憶體）18%**
  - **基地台 5%**
  - **其他 4%**
- AI 載板曝險：
  - **美系 AI 客戶 CPU 供貨率 10% → 50%**（重大訂單外溢受惠）
  - **2026 打入 NVDA AI GPU 第三供應商**（IBIDEN #1 + 欣興 #2 + 景碩 #3）
- 商業模式：中階 ABF + BT 雙引擎、客戶分散度三雄最高
- 客戶涵蓋 NVDA + Intel + AMD + Apple + Qualcomm（手機 SoC BT 載板）
- → 跟 [[賣水人選股邏輯（投資版）]]：中階 ABF + BT 賣水人位置最穩

### 供應層

- 跟 [[NVDA]] 路線：2026 打入第三供應商（最新進展、份額仍小）
- 跟 [[AMD]] 路線：EFB 體系欽點、2026-2027 在台百億美金擴產直接點名景碩
- 跟 [[Intel]] 路線：中階 Xeon 載板（不直接吃 Clearwater Forest 玻璃旗艦但吃其他中階 SKU）
- BT 載板：手機 SoC + 記憶體 + 載板價格因 T-glass 缺料漲價
- 玻璃基板對應策略：**觀望 + 中階 RDL 增層卡位**
  - 景碩是「在玻璃 core 上下進行 RDL 增層與細微線路電鍍的代表大廠之一」
  - 不自做玻璃 core，但做後段 RDL 增層
  - 玻璃化加速反而對景碩有利——主力產品線不被切、後段 RDL 仍有空間
- 護城河：
  - 客戶分散度三雄最高 = binary 風險最低
  - BT 載板**中國競爭追趕慢**（中國落後 3-4 年、短期不構成威脅）
  - T4 廠鎖定電動車 + AI 手機換機潮（次級成長極）
- 風險：中階 ABF 中國廠商價格戰、毛利率壓力
- → 連 [[控制點轉移（投資版）]]：景碩沒拿到旗艦控制點，但拿到中階分散度

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ ABF/BT 雙引擎 + 客戶分散度高 |
| 毛利率 | ⚠️ **18.96% 仍低**（vs 欣興、稼動率提升中）|
| OpEx | ✅ CapEx 強度低於欣興、折舊壓力相對小 |
| 營業利益 | ✅ Q1 EPS YoY +92% = 訂單外溢 + 稼動率提升 |

→ **Re-rate 三角形 3/4 滿**——是這波 ABF 上升循環**中等受惠者**，但同時 displacement 風險最低 = **risk-adjusted return 最佳**。

### ✅ 催化

- 2026 Q2-Q4 ABF 漲價週期延續
- 美系 AI CPU 供貨率 10% → 50% = 訂單外溢 + 稼動率提升
- 2026 打入 NVDA AI GPU 第三供應商（份額仍小但 design-in 確認）
- AMD EFB 體系欽點、2026-2027 在台百億美金擴產
- BT 載板因 T-glass 缺料 + 手機高階換機潮漲價（BT 33%）
- AI Agent 帶動通用伺服器 → CPU 需求 ABF 延伸至 2028
- 大摩 EPS CAGR 2025-2028（雖未具體列數但同步上修）
- Risk-adjusted：客戶分散度最高、玻璃化威脅最低

### ⚠️ 風險

- **PE 145 vs 同業折價但仍偏高**——主因 2025 EPS 基期低
- 中階 ABF 中國廠商價格戰**長期壓力**（短期不構成威脅但 3-5 年要追蹤）
- 毛利率僅 18.96%（vs 欣興 25%+）= 中階產品結構性低
- 客戶集中度雖比南電低、但仍有 Intel/AMD 雙頭依賴
- NVDA 第三供應商份額小、Blackwell/Rubin 主力仍是 IBIDEN + 欣興
- 玻璃化加速若超預期 → 中階 ABF TAM 也可能 cannibalize（小機率）

## ⭐ Displacement 風險評估

| 維度 | 評估 |
|---|---|
| 高階 ABF 被切（AI ASIC 玻璃化） | ✅ **低曝險**——景碩不主打 AI 旗艦 |
| 中階 ABF 守住（伺服器 CPU / HPC） | ✅✅ **最受惠**——主力產品線、訂單外溢 |
| 自己轉玻璃機會 | ⚠️ 觀望——後段 RDL 增層有位置、core 不自做 |
| 客戶轉走風險 | ✅ **三雄最低**——客戶分散度高 |

→ Displacement 總體：**受惠**（**三雄中最不受 displacement 衝擊**）

> **Thesis 校準（vs concept 內預測）**：concept 內「中低階守住、相對受益」**完全成立 + 加碼校準**——景碩不只「相對受益」，**還拿到了高階 AI CPU 訂單外溢 + NVDA 第三供應商 design-in**。在三家中是「**最確定的雙曲線受惠者**」（既吃 displacement 過渡期外溢、又吃 BT 漲價）。
