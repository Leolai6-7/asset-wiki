# YMTC（長江存儲，Yangtze Memory Technology Co.）

## 1. 一句話定位

**中國 NAND 國產龍頭 + Xtacking 架構（晶圓對晶圓直接鍵合 hybrid bonding）首創者 + 2026 Q1 13% 全球市佔（與 [[SanDisk]] / [[Micron]] 並列）+ 美 Entity List 制裁下 3 年內仍 capacity 翻倍 + 國產替代「中國 NAND 自給率」唯一頭部廠**——未上市（紫光集團控股 + 國家大基金 + 武漢產投三方共持）、總部武漢、跟 [[SanDisk]] / [[Kioxia]] / [[Samsung Electronics]] / [[SK Hynix]] / [[Micron]] 並列 NAND BIG 6 分食格局。2022-12 被美國商務部列入 Entity List 後曾被預判「3-5 年內難破百層」、實際 2024-2026 走 Xtacking 4.0（294 層）+ X4-9070 client SSD 公開上市、製程能力 **超預期 closing gap**。在 [[AI infra 3D NAND 戰場]] 是「**中國自給率國產替代 anchor + NVDA 採購 hedge 反向變數**」——hyperscaler / NVDA Vera Rubin ICMS multi-source 中**不會包含 YMTC**（美制裁）、但中國國產 AI server（華為昇騰 / 阿里平頭哥 / 寒武紀）+ 國產雲端（阿里雲 / 騰訊雲 / 華為雲）**結構性綁定 YMTC**。

## 2. 三層 thesis

### 產業層

- **NAND BIG 6 排名**（Q1 2026 Counterpoint）：Samsung（29%）→ SK Hynix+Solidigm（22%）→ Kioxia（14%）→ Micron（13%）= SanDisk（13%）= **YMTC（13%）**
- 在 [[市場四階段：懷疑／驗證／共識／反轉]]：**「懷疑 → 驗證」過渡期**——
  - 懷疑：美 Entity List 制裁（2022-12 限制 EUV / 14nm 以下設備）、表面上「3 年內難進先進製程」
  - 驗證進行中：2024 Xtacking 3.0 232 層、2025-2026 Xtacking 4.0 294 層（超預期 closing）、X4-9070 商業上市
- 在 [[資訊擴散四階段]]：機構（jpm / Goldman / Counterpoint）已覆蓋、台灣賣方有零散研究、媒體層（TechInsights / Tom's Hardware）熱炒中、ETF 因未上市無法配置
- TAM：3D NAND 全市場 2026 USD 58.7B → 2031 USD 76B（CAGR 5.3%）；中國國產替代政策驅動 + 國產 AI server 結構性配套
- [[宋分備忘錄 ＃1 — CSP-AI 通縮]] 視角：中國 CSP（阿里 / 騰訊 / 字節）NAND 國產替代 = YMTC TAM 隔離受惠軌
- [[Bottleneck Theory（瓶頸論）]] 視角：YMTC = 中國 NAND chokepoint（國產替代政策下無替代）、跟 [[SK Hynix]] HBM 給美 NVDA 是 mirror image（美中各自的單一供應商）

### 目的層

- 真實角色：**「中國 NAND 國產替代龍頭 + Xtacking 架構 IP 持有人 + 國家戰略級半導體企業」**——不是「跟 Samsung / SK / Micron 全球競爭」、是「**佔住中國國產替代市場 + 國家政策保護 + 國產 AI / cloud / consumer 全鏈陪跑 + 工業界製程突破代表**」、靠「**Xtacking 製程 IP + 紫光 + 國家大基金 + 武漢產投三方資金背書 + 國產替代政策驅動**」拿到中國市場
- 商業模式三段：
  - **Consumer NAND**（穩定）：手機 / 消費 SSD / 記憶卡（華為 / 小米 / OPPO / vivo 全綁）
  - **Enterprise NAND**（成長引擎）：國產 AI server（華為 Ascend / 寒武紀 / 燧原）、國產雲（阿里 / 騰訊 / 華為）
  - **客戶國產替代 anchor**：中國本土 GPU / NPU 全部要用 YMTC NAND
- 核心 IP / 護城河：
  - **Xtacking 架構**（首創）：CMOS 邏輯層 + NAND 儲存層分開製程、wafer-to-wafer hybrid bonding、可獨立優化兩層、整體 die size 縮小、I/O 性能上限提升
  - Xtacking 4.0：**294 層**（2025-2026 量產、跟國際 BIG 5 差距從 3 年縮至 1 年）
  - X4-9070 SSD：跟國際 PCIe 5.0 client SSD 性能 close gap
- **中國 NAND 自給率 anchor**：中國 2024 NAND 國產自給率 ~15%、2030 目標 50%+ → YMTC 是唯一頭部 + 國家計劃驅動
- **股權結構**：紫光集團（重整後深圳國資控股）+ 國家集成電路產業投資基金（大基金一期 / 二期）+ 武漢產業投資（湖北地方政府）+ 武漢市政府引導基金
- 對應 [[賣水人選股邏輯（投資版）]]：⚠️ **不是賣水人，是國家戰略選手**——綁定政策、不押技術路徑、押「國產替代政策強制執行 + 中美脫鉤」
- 對應 [[控制點轉移（投資版）]]：拿到「**Xtacking 架構 IP + 國家戰略級半導體企業 + 中國國產替代 anchor**」三層 chokepoint、但**控制權外部變數**（美中科技戰 + Entity List）
- 對應 [[開源作為武器（投資版）]]：⚠️ YMTC 是**閉源軌道**（不公開 fab 製程細節）、與華為 HarmonyOS / DeepSeek 開源策略對比反向

### 供應層

- 跟 [[NVDA]] 路線：
  - ❌ **不可能進 NVDA AVL**（美 Entity List 制裁、Rubin / Vera Rubin ICMS multi-source 完全跳過 YMTC）
  - → YMTC 是**反向避險變數**（NVDA 採購完全去 YMTC 化、中國市場完全去美國化 = 雙向脫鉤）
- 跟 [[SanDisk]] 對比（**並列 13% 市佔，但完全不同政治位階**）：
  - 規模並列（兩家都 ~13% 市佔）
  - SanDisk = 美國 pure-play + 賣 NVDA / hyperscaler / 全球 Enterprise SSD
  - YMTC = 中國國產龍頭 + 賣中國 AI / cloud / consumer / 國產替代
  - **mirror image**：兩家各自代表「美中 NAND 脫鉤」的兩端
- 跟 [[Kioxia]] 對比：
  - Kioxia = 日本 NAND BiCS pure-play、跟 SanDisk 共用 Yokkaichi/Kitakami JV fab
  - YMTC = 中國 Xtacking 純獨立、無國際 JV、純國產 fab（武漢長江存儲一廠 / 二廠）
  - **製程哲學差異**：Kioxia BiCS（CMOS-NAND 上下堆疊單片）/ YMTC Xtacking（CMOS + NAND wafer-to-wafer 鍵合）
- 跟 [[Samsung Electronics]] / [[SK Hynix]] / [[Micron]] 對比：
  - 三家美韓廠規模碾壓 YMTC（合計 64% vs YMTC 13%）
  - 但 YMTC 在中國市場**結構性政策保護**、規模碾壓無法傳導
- 跟 [[華為]] 關係：
  - 華為 Ascend AI 訓練 / 推理 server 結構性綁定 YMTC NAND
  - 華為手機（Mate 系列）NAND **大量採用 YMTC**（取代 SanDisk / Samsung）
  - 跟 [[DeepSeek]] 國產 AI 模型訓練 server 同樣綁定 YMTC NAND（推測）
- 跟 [[Disco Corp]] / [[Disco Corp|Disco]] 關係（背切設備）：
  - YMTC 仍**極度依賴日本 Disco 雷射切割設備**（Entity List 不限切割設備）
  - 但部分設備出口管制風險 long term（Disco 給 YMTC 的設備可能被加管）
- 跟美中科技戰路線：
  - Entity List（2022-12）：限制 14nm 以下邏輯製程設備 + EUV 進口
  - 實際 closing gap：2022 Xtacking 2.0 128 層 → 2024 Xtacking 3.0 232 層 → 2026 Xtacking 4.0 294 層（**超預期**）
  - 美方擔憂：若 YMTC 進入 enterprise SSD 全球競爭 → 對 Micron / SanDisk / Kioxia 衝擊大
- 護城河：
  - **Xtacking 架構 IP**（首創 + 國際專利布局）
  - **國家戰略級半導體企業**（紫光 + 國家大基金 + 武漢產投三方資金 + 政策保護）
  - **中國國產替代政策驅動**（中國 NAND 自給率政策目標 2030 50%+）
  - **Counterpoint Q1 2026 13% 全球市佔**（從 2022 Entity List 後仍上升）
- 風險：
  - ⚠️ **美 Entity List 加碼可能**：禁設備 → 禁原料 → 禁市場 → 全鏈鎖死
  - ⚠️ **無 EUV 限制先進製程 ceiling**：Xtacking 4.0 後若需 EUV 才能進一步 closing gap、可能撞牆
  - ⚠️ **全球市場進入限制**：YMTC 全球市佔 13% 可能停滯（沒辦法切美 / 歐 / 日 / 韓 / 台市場、只剩中國 + 部分東南亞）
  - ⚠️ **未上市 + 不透明**：財務、產能、客戶結構公開度低、機構研究 confidence 必須打折
  - ⚠️ **中美脫鉤反向 binary**：兩岸科技戰升級 → YMTC 全球銷售完全切斷
  - ⚠️ **紫光重整風險殘留**：母公司紫光集團 2022 重整後股權結構複雜、治理風險仍在

## ⭐ Xtacking 架構深度（YMTC 唯一技術差異化）

| 維度 | 傳統 BiCS（[[SanDisk]] / [[Kioxia]]）| Xtacking（YMTC）|
|---|---|---|
| 架構 | 單片：CMOS 邏輯層 + NAND 儲存層上下堆疊 | **雙片 wafer-to-wafer hybrid bonding**：CMOS / NAND 兩片獨立製程 + 鍵合 |
| Die size | 較大 | **較小**（CMOS / NAND 各自最佳化）|
| I/O 性能 | 受 CMOS 製程限制 | **獨立優化** → 高頻 I/O 上限拉高 |
| 量產良率 | 成熟 | 較難（鍵合精度要求高）|
| 製程節點 | BiCS 8 = 218 層 | **Xtacking 4.0 = 294 層** |
| IP 持有 | Kioxia / SanDisk 共持 | YMTC 獨家 |

→ **業界共識**：Xtacking 是 NAND 製程**真正的長期路徑**（vs BiCS 受限）、跟 [[SK Hynix]] / [[Samsung Electronics]] 也都在跟進 hybrid bonding 路線。YMTC 是 **first-mover**、但因 Entity List 制裁無法跟國際自由競爭。

## ⭐ 「美日 NAND 同盟」vs「中 NAND 國產替代」雙軌格局

| 軌 | 玩家 | NAND 製程 | 主市場 |
|---|---|---|---|
| **美日 NAND 同盟** | [[SanDisk]] + [[Kioxia]]（Yokkaichi/Kitakami JV）| **BiCS 8** | NVDA / hyperscaler / 全球 |
| **韓國雙頭** | [[Samsung Electronics]] + [[SK Hynix]] + [[Solidigm]] | V-NAND / TLC NAND | 全球 + 韓國本土 |
| **美國 Micron** | [[Micron]] | TLC NAND（NAND 是配角）| 全球 + 配 DRAM 雙引擎 |
| **中國國產替代** | **YMTC**（紫光 + 國家大基金 + 武漢產投）| **Xtacking 4.0** | 中國 + 部分東南亞 |

→ **6 家分食格局其實是「**美日同盟 + 韓國雙頭 + 美 Micron + 中國國產替代**」四軌結構**，YMTC 13% 市佔不是市場競爭結果、是**政策保護結果**。
