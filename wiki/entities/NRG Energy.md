# NRG Energy（NYSE: NRG）

## 1. 一句話定位

**美國第二大 retail electricity provider + Texas ERCOT firm power（氣電 + 燃煤）+ Reliant Energy + Green Mountain Energy + Vivint Smart Home 整合（retail + 智能家居 + 監控）+ 2023-03 USD $2.8B 收購 Vivint Smart Home 補完 retail + 智能家居整合**——總部 Houston TX、紐約證券交易所上市、市值 **USD ~$25-32B（Mid Cap）**；客戶覆蓋 **~8M+ retail electricity 用戶**（vs [[Vistra]] TXU Energy ~5M 德州第一、NRG 全美第二）+ Reliant + Green Mountain + Cirro 多品牌；FY2025 營收 **USD ~$25-30B** + EBIT margin ~10-15%（vs CEG / VST 結構性低毛利、商業模式偏 retail + spot）+ Forward PE **12-16x**（vs CEG 30-32x / VST 20-22x / TLN 22-26x **顯著折價**）；是 [[AI infra 電力戰場]] **第一層電力產生第三層 anchor**（retail + ERCOT 氣電 firm power、客戶分散度勝、規模 / IP 略遜 CEG / VST）。

## 2. 三層 thesis

### 產業層

- AI infra 電力 [[市場四階段：懷疑／驗證／共識／反轉]] 處於「**驗證 → 共識**」加速段
  - NRG 是「**retail + ERCOT 氣電 firm power**」的非核電 anchor、跟 CEG / VST 核電 anchor 形成「**全美電力 narrative 完整覆蓋**」
  - 跟 [[Vistra]] 23 vs NRG 20 路線差異：VST 核電 6.4GW + 氣電 30GW+ 跨三 ISO、NRG 氣電 + 燃煤 ~17GW 集中 ERCOT + Vivint Smart Home 整合
- ERCOT（德州）電力市場：
  - 美國最大 ISO（峰值需求 ~85GW、容量 ~125GW）
  - 2025-2030 需求 +40-60%（AI + 電動車 + 工業回流）= 結構性 ↑
  - NRG 是 ERCOT 第二大發電商 + retail 龍頭（Reliant + Green Mountain + Cirro）
  - 2021 德州冬季電網崩盤教訓 → 容量市場改革進行中
- PJM Interconnection 容量緊缺：
  - NRG 在 PJM 也有 retail + 部分氣電（規模小於 ERCOT）
- 對應 [[AI infra 電力戰場]]：**第一層電力產生第三層 anchor**（氣電 + retail）
- 對應 [[宋分 ＃20 — 能源結構性剛需]]：**部分滿足**（retail anchor + ERCOT 氣電 firm power、但無核電 baseload + 無 hyperscaler 20 年 PPA = 三標準滿足 2/3）

### 目的層

- 業務 mix（2025 為主）：
  - **Generation（氣電 + 燃煤 + 太陽能 + 儲能）**：~17GW = ~50-55%
  - **Retail electricity（Reliant + Green Mountain + Cirro）**：~35-40%（~8M+ 用戶）
  - **Vivint Smart Home（智能家居 + 監控）**：~10-12%
- **AI / hyperscaler 直接 PPA 占未來營收占比**：
  - 2025：~1-3%（無大規模 hyperscaler PPA）
  - 2030+：估算 **~5-10%**（ERCOT data center 客戶 retail + 容量市場間接受惠）
- 客戶結構：
  - **retail 終端**（Reliant ~5M 德州 + Green Mountain ~3M 跨州 + Cirro 商業 / 工業）
  - **Vivint Smart Home**（230 萬訂閱戶、智能家居 + 監控 + 太陽能銷售）
  - **無大規模 hyperscaler PPA**（vs VST / TLN / CEG 核電 / 氣電 PPA）
- 商業模式核心：
  - **retail-first 戰略**（從 IPP wholesale → 整合 retail + 智能家居 + 監控）
  - **跨德州 + PJM + ISO-NE** ISO 部分曝險
  - **Vivint 整合**：smart home + 監控 + 太陽能 + EV 充電 = 跨產業 cross-sell
- 對應 [[賣水人選股邏輯（投資版）]]：**「retail + ERCOT 氣電 + 智能家居整合 IPP」**（vs VST / CEG / TLN 核電 + 氣電 PPA-anchored）
- 對應 [[控制點轉移（投資版）]]：拿到「**retail 終端 + ERCOT 氣電 + Vivint 智能家居 + EV 充電**」四段控制權

### 供應層

- 跟 [[Vistra]] 競爭（**ERCOT retail + 氣電對手**）：
  - **VST**：核電 6.4GW + 氣電 30GW+ + TXU Energy ~5M 德州 retail = 規模 + 多 ISO + 核電 anchor
  - **NRG**：氣電 + 燃煤 ~17GW + Reliant ~5M 德州 retail + Vivint 230 萬 = **retail 規模勝 VST**（NRG retail 全美 #2 vs VST TXU 德州 #1）
  - **NRG 氣電 < VST 氣電**（NRG ~10-12GW vs VST 30GW+ + Cogentrix）
  - **NRG 無核電 anchor**（vs VST 6.4GW）= **AI baseload narrative 弱**
- 跟 [[Constellation Energy]] / [[Talen Energy]] 競爭（**核電 IPP**）：
  - CEG + TLN 都是核電 anchor + hyperscaler 20 年 PPA
  - NRG 無核電 + 無 hyperscaler PPA = **AI narrative 弱**、估值大幅折價
- 跟 NextEra Energy（**utility 龍頭**）：NextEra 太陽能 + 風電 + utility 規模龍頭、NRG 跟其 retail business 互補（NextEra 主 utility wholesale + 部分 retail、NRG retail-first）
- 跟 [[GE Vernova]] 補完關係：NRG 氣電擴建用 GEV gas turbine（NRG 是 GEV gas turbine 重要客戶之一）
- 跟 [[AMZN]] AWS / [[Meta]] / [[Microsoft]] / [[Google]] hyperscaler 關係：
  - **無已公開 20 年 PPA**（vs VST 2.6GW Meta / TLN 1.92GW AWS / CEG 5,650MW+ MSFT + Meta）
  - 但 ERCOT data center 客戶（Microsoft / AWS 德州 fab + data center）retail + 容量市場間接受惠
  - 未來 hyperscaler PPA 簽約潛力：ERCOT 氣電可後續配對
- 護城河：
  - **retail 全美 #2 + 德州 #2**（vs VST TXU 第一）
  - **Vivint 整合**（230 萬訂閱戶、跨 smart home + EV + 太陽能）
  - **ERCOT 氣電 + 燃煤 firm power**
  - **跨 ERCOT + PJM + ISO-NE 部分曝險**
  - **Forward PE 12-16x 估值乾淨**（vs CEG / VST / TLN 高估值）
- 風險：
  - **無核電 anchor = AI baseload narrative 弱**
  - **無 hyperscaler 20 年 PPA = 客戶分散勝但長期能見度弱**
  - **燃煤逐步退場**（2030+）
  - **ERCOT 電網脆弱**（2021 冬季崩盤、極端天氣）
  - **PJM 容量市場改革**
  - **氣價波動**：氣電 ~10-12GW 對 Henry Hub 敏感
  - **Vivint 整合執行**：$2.8B 收購、ARPU 增長 vs 流失率
  - **政治風險**：2028 政權更替

## pair trade / 配置建議

### 多 NRG（估值乾淨 + retail anchor）

**論點**：NRG 是 AI 電力戰場 retail + ERCOT 氣電第三層 anchor、PE 12-16x 估值最乾淨、Vivint 整合 ARPU 增長、無 narrative 溢價但下檔保護好

**配置**：衛星倉、3-5% 配置上限（無 narrative alpha、但 yield + 估值乾淨）

### 配對思路

**多 VST + 多 NRG**：核電 anchor + retail anchor 雙頭做多 ERCOT 電力 narrative

**多 NRG / 空 utility ETF（XLU）**：retail 整合 + Vivint 差異化 vs utility 平均

**多 VST / 空 NRG**：核電 + hyperscaler PPA 結構性勝 / 純 retail + 無 PPA 結構性弱

→ **結論**：NRG 是衛星倉、retail + 估值乾淨配置；core 配置仍是 VST / CEG
