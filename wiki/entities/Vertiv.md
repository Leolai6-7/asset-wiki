# Vertiv（NYSE: VRT）

## 1. 一句話定位

**全球資料中心散熱 + 電源整合 turnkey 龍頭**——pure-play 80% 營收純資料中心、$15B backlog（12-18 個月能見度）、跟 [[NVDA]] 共同開發 **800V DC 架構**（2026 H2 對齊 Rubin 量產）、2026-03 ThermoKey + 2026-04 Strategic Thermal Labs **雙併購全產業鏈整合**（heat rejection + 伺服器側 cold plate validation）、是 [[AI infra 散熱戰場]] **第一 anchor**。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**驗證 → 共識**」加速段、比 [[AI infra CapEx 三階段論]] 第三階段（光通訊 / 上游材料）**滯後 1-2 季**
- 機櫃功率密度 5 年 30kW → 1MW（33x）= 散熱**從 IT 室空調升級為 AI 基礎建設層**
- TAM：power + cooling 數據中心市場 **2026-2030 30% CAGR → $172.9B**（2030）
- 「白區（IT 設備）/ 灰區（後段基礎建設 UPS/CRAC）」邊界**正在被液冷打破**——Vertiv 同時跨白灰區
- 跟 [[AI infra 電力戰場]]（孿生戰場）整合方重疊：Vertiv vs Schneider Electric vs [[台達電]] = 三大 turnkey 整合方對打
- 跟 [[資訊擴散四階段]]：機構 → 賣方 → 媒體 → ETF（已 ETF 化、IGV / SOXX 持股）

### 目的層

- **核心業務結構**（FY2025 → FY2026 推估）：
  - Critical Infrastructure & Solutions **~78%**（電源 UPS + 冷卻 + 機架）
  - Services ~17%（安裝 + 維護 recurring）
  - Integrated Modular Solutions ~5%（modular data center）
- **AI 資料中心曝險**：**~80% 營收** = pure-play（vs 台達電 ~40% / Schneider 多角化）
- **Cooling + Power 雙軌**：是「**唯一一家結構性同時押兩個戰場**的西方廠商」——這是估值溢價來源
- 商業模式核心：
  - **整合 turnkey**：從機房規劃 → 機架 → UPS → CDU → cold plate → 維運**一條龍**
  - **直接綁 NVDA reference architecture**：Blackwell / Rubin 液冷 + 800V DC 共同開發 → 規格定義權 ≈ 沒有對手能複製
  - **規模 + 認證壁壘**：hyperscaler 級液冷專案**只有少數玩家能投標**（規模 / 認證 / 設備 / 服務四軸全備）
- 2026 兩起併購整合**全產業鏈**：
  - **ThermoKey S.p.A.**（2026-03）：heat rejection / 熱交換器專家 → 補資料中心**外側散熱**（chiller / dry cooler）
  - **Strategic Thermal Labs LLC**（2026-04）：**伺服器側 cold plate 設計 + 高密度驗證** → 補資料中心**內側散熱**（直接觸晶 D2C）
  - → 「**外側 + 內側 + 中間 CDU**」全棧 turnkey 閉環
- 對應 [[賣水人選股邏輯（投資版）]]：**整合 turnkey 賣水人**——不押 NVDA / AMD / Trainium 誰贏、押**所有 1MW 機櫃都得用 Vertiv-class 整合方**
- 對應 [[控制點轉移（投資版）]]：跟 NVDA 共同定義 Rubin 800V DC + universal QD 規格 = **拿到散熱戰場的規格參與權**（但 IP 定義權仍在 NVDA 手中）

### 供應層

- 跟 [[NVDA]] 路線：
  - Blackwell / Rubin 液冷 **reference architecture co-developer**
  - **800V DC 架構**：2026-03 NVDA GTC 共同發布、2026 H2 配 Rubin 量產
  - cold plate / CDU 是 NVDA 官方四家認證供應商之一（Boyd / CoolIT / Vertiv / Schneider）
- 跟 Schneider Electric 對比：
  - **規模**：Vertiv revenue ~$13.5B FY2026 vs Schneider ~€40B（**Schneider 規模 3x**）
  - **純度**：Vertiv 80% 資料中心 vs Schneider 30%（**Vertiv 純度勝**）
  - **AI 速度**：Vertiv 2026 Q1 +30% YoY / EPS +83% vs Schneider 個位數成長（**Vertiv 速度勝**）
  - → Schneider 規模大但 AI 純度低 / Vertiv 純度高速度快、估值分歧
- 跟 [[台達電]] 對比：
  - **重疊**：power module（UPS + PSU + busbar）兩家都做、800V DC 架構同步切入
  - **互補**：Vertiv **整合方 + 服務 + 大型 CDU**（北美 hyperscaler） / 台達 **零件供應商 + ODM 友好 + 中型 CDU**（亞洲 + ODM 鏈條）
  - **不直接搶單**：台達多透過 ODM（鴻海 / 廣達 / 緯創）餵 NVDA、Vertiv 直接服務 hyperscaler turnkey
  - → 兩家在 power module **同台對打但客戶結構不同**、cooling 上更接近**互補**（北美 hyperscaler vs 亞洲 ODM）
- 跟 [[雙鴻]] / 奇鋐 / [[高力 8996|高力]] 關係：
  - **採購方**：Vertiv 是雙鴻 / 奇鋐 / 高力的**潛在大客戶**（cold plate / manifold / BPHE 採購）
  - 2026-04 Strategic Thermal Labs 併購後 Vertiv 開始**自製 cold plate** → 跟雙鴻 / 奇鋐**部分競爭**
  - 但 turnkey 規模 + hyperscaler 客戶遠超純零件廠 → **採購 + 部分競爭並存**
- 跟 Boyd / CoolIT 對比：
  - Boyd：被 Eaton 2026-03 併購、power + cooling 整合（跟 Vertiv 完全同型）→ **Eaton-Boyd 是新興最直接對手**
  - CoolIT：純液冷 IP（CHx2000 2MW CDU、OMNI cold plate 4,000W）、niche 強但無 power 軌
- 護城河：
  - **規模 + 認證**：hyperscaler 級液冷專案投標**只有少數玩家能滿足**
  - **客戶分散**：四大 hyperscaler（Meta / Microsoft / AWS / Google）+ neocloud（CoreWeave / Lambda / Oracle）+ 主權 AI（**客戶分散度高 = 估值溢價**）
  - **服務 recurring**：17% 營收是維護 / 安裝 = 抗景氣循環
  - **NVDA 規格參與權**：800V DC + universal QD 共同定義
- 風險：
  - **估值已 price in**（Forward PE 40+、$15B backlog 已反映）
  - 整合方下吃**純零件廠**也可能反向被純玩家（CoolIT / Strategic Thermal Labs 級小公司被併購完）吃掉部分 IP
  - **NVDA universal QD 標準化** → 供應商互通 = 削弱單一玩家定價權
  - hyperscaler CapEx 突發剎車（如 [[CapEx 見頂辯論]] 失效）

### Vertiv vs [[台達電]] power module 重疊度（**核心回答**）

| 維度 | Vertiv | [[台達電]] | 重疊？ |
|---|---|---|---|
| **目標客戶** | 北美 hyperscaler 直接 turnkey | 透過 ODM（鴻海 / 廣達 / 緯創）餵 NVDA + 直接 ODM 客戶 | ⚠️ **間接重疊**——客戶不同層 |
| **PSU / UPS** | 大型 UPS + DC 配電（800V DC + busbar）| AI server PSU 60% 市佔 + 800V DC | ✅ **直接重疊**——800V DC 同台對打 |
| **CDU** | 大型 L2L + 跟 NVDA 共同定義 reference architecture | 2.4MW / 3MW L2L CDU + GB300 4RU In-Rack | ✅ **直接重疊**——但 CDU 規格相近 |
| **服務 / turnkey** | 17% 營收 services + hyperscaler turnkey | 弱（傳統製造業 ODM model）| ❌ **不重疊**——Vertiv 有 services moat |
| **規模** | $13.5B FY2026 | $20B+（多元）| 同等級 |

→ **結論**：「**競爭 + 互補**」——
- **power module 在 800V DC + CDU 是同台直接競爭**（規格相近 + 客戶可能重疊）
- **但客戶結構大不同**——Vertiv 走 hyperscaler turnkey、台達走 ODM friendly 零件 + 部分直接 hyperscaler
- **散熱與電力孿生戰場**：兩家都押雙軌、但**台達多元組合（電動車 / 家電 / 5G 30%+）稀釋 AI 純度**、Vertiv 純度勝
- → **Vertiv anchor 等級高於台達**（純度 + 速度 + 客戶分散 + NVDA 規格定義權）

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| **路線敏感度（逆向）** | **5 / 5** | NVDA / AMD / Trainium / Inferentia 誰贏都要液冷 + power、完全中性受惠 |
| **站別關鍵度** | **5 / 5** | 整合 turnkey + NVDA 規格共定義 + hyperscaler 級認證 = 不可繞過 |
| **耗材 recurring** | **3 / 5** | 17% services 維護 + 安裝 = recurring 中等（不像 [[Disco Corp]] 5/5）|
| **IP 控制** | **4 / 5** | NVDA 800V DC reference architecture 共定義 + Strategic Thermal Labs cold plate IP + ThermoKey heat rejection IP（但 universal QD 標準化削弱定價權）|
| **客戶分散** | **5 / 5** | 四大 hyperscaler + neocloud（CoreWeave / Lambda / Oracle）+ 主權 AI + colo + 邊緣 = 高分散 |

**總分 = 22 / 25** —— 散熱戰場 **anchor #1 候選**、僅次於 [[Disco Corp]] 24 / [[村田 Murata]] 24（賽道最高分）、與 [[SK Hynix]] 22+ 並列；**散熱戰場最高分**。

→ 比 [[Ciena]] 19、[[Coherent]] 19、[[Lumentum]] 19 更高 3 分（**整合 turnkey + 雙軌 power+cooling + 80% 純度**讓它在五軸全面勝光通訊純度玩家）。
