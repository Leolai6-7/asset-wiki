# MCP（Model Context Protocol）

[[Anthropic]] 發起、捐給 Linux Foundation（**AAIF**）的 AI agent 工具連接協議。**9,700 萬安裝**，所有主要 AI 公司支援。**= 協議層控制點**。

## 為什麼這是 asset-wiki 的核心 entity

不是因為 MCP 是技術，而是因為它是 **[[接口控制權]] 的最強範例**：

- Anthropic 不是賣模型，是**搶接口**
- 模型可以被超越，**協議一旦成為事實標準，控制權極黏**
- Chromium 是這個範式的歷史先例

## 規模指標

- **9,700 萬安裝**（2026 Q1）
- 所有主要 AI 公司支援（包括 OpenAI）
- 已捐給 **Linux Foundation 旗下 AAIF**
- AAIF 共同創辦人：Anthropic、Block、OpenAI 等

## 戰略意義

```
模型層     → 競爭激烈、易商品化
協議層     → MCP 控制（Anthropic）
執行層     → Managed Agents（Anthropic）
客戶層     → 1,000+ 年付 $1M+ 企業
```

= [[Anthropic]] 三層控制點
