# Epson（6724.JP、Seiko Epson）

## 1. 一句話定位

**全球印表機 #1 + 投影機 + 機器人 + 石英 timing（TCXO 全球 #1）+ 多軌組合王**——1942 長野創立的日本 Seiko 集團精密設備巨頭、Printers 50% + Visual Communications 15% + Robots 5% + Quartz Devices 10% + Others 20% 五軌組合；**TCXO（溫補晶振）全球 #1**、石英陣營日台三巨頭之一（跟 [[NDK]] / [[TXC]] 並列）；FY2025 營收 ~¥1.1-1.3 兆 JPY（USD ~$7-9B）、Forward PE 12-16x、12M +0-15%；定位「**多軌組合王 + Quartz Device 段 TCXO 全球 #1 + 多客戶分散 + 估值 conservative**」、跟 [[TDK]] 19 / [[GlobalFoundries]] 20 / [[Texas Instruments TXN]] 20 同分段。

## 2. 三層 thesis

### 產業層

- **多軌組合王**：跨「印表機 + 投影機 + 機器人 + 石英 timing」四大賽道、conglomerate 結構
- **石英 timing 賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]]「**驗證**」段
  - Epson Quartz Device 段佔 Epson 整體 ~10% 營收（vs 印表機 50% 主場）
  - **TCXO 全球 #1**：Epson Quartz Device 段 TCXO 寡占（vs [[TXC]] / [[NDK]] / [[Kyocera]] / [[Rakon]] 分食其他）
  - 全球石英 timing 市場 ~USD 30-35 億（2025）+ CAGR ~5-8%
- **印表機賽道**在「**成熟期 / 成長放緩**」段
  - 全球印表機 #1（vs HP / Canon / Brother）、市佔 ~25-30%
  - PrecisionCore inkjet 技術 anchor、低耗電 / 高速 / 環保
- **投影機賽道**在「**成熟期 + 商用領先**」段
  - 全球投影機 #1（vs BenQ / NEC / Sony）、市佔 ~30-35%
  - LCD 投影機 + 3LCD 技術 anchor
- **機器人賽道**在「**成長中 + niche 領導**」段
  - SCARA 機器人全球 #1（精密組裝、工業 niche）
  - 規模仍小（~5% 營收）但成長段
- [[資訊擴散四階段]]：機構（日本基金 + Seiko 集團分析）→ 賣方（日經 / 野村 / 大和）→ 西方媒體有限擴散

### 目的層

- 主業 mix（FY2025）：
  - **Printers**：~50% 營收 = Epson 基本盤、PrecisionCore inkjet 主力
  - **Visual Communications**（投影機 + 互動白板）：~15% 營收
  - **Quartz Devices**（石英 timing）：~10% 營收 = **TCXO 全球 #1 + 賣水人 segment**
  - **Robots**（SCARA + 6-axis）：~5% 營收 + 成長段
  - **Other**：~20% 營收（半導體封裝設備 + 智慧裝置 + 手錶機芯）
- **TCXO 全球 #1**：Epson Quartz Device 段 TCXO 寡占、跟 [[TXC]] / [[NDK]] 並列日台三巨頭、是 Epson 跨四軌的「**石英賣水人段**」
- 客戶結構：
  - **消費電子**：HP / Lenovo / Apple / Samsung / 全球印表機 OEM
  - **汽車**：Toyota / Honda / Tesla / 中國 EV（ADAS + IVI + 車聯網 timing）
  - **工業**：SCARA 機器人 / 投影機 / 半導體封裝設備 OEM
  - **AI server / 通訊**：NVDA / AWS / Google / Meta = 石英 timing 段受惠（規模仍小）
  - **手錶機芯**：Seiko Watch + 全球手錶 OEM
- 商業模式：**多軌組合 + Seiko 集團 anchor**——印表機 + 投影機 + 機器人 + 石英 timing + 手錶機芯五軌營業；長野 + 鹽尻 + 廣丘 + 馬來西亞 + 印尼 + 中國菲律賓多地產能
- → 連 [[賣水人選股邏輯（投資版）]]：**多軌組合王 + TCXO 全球 #1** — 不押任何單一路線、押「**所有印表機 + 投影機 + 機器人 + 石英 timing 都需要 Epson 多軌組合**」

### 供應層

- **路線：石英陣營 vs [[SiTime]] MEMS 路線分歧 + 多軌組合 conglomerate**：
  - Quartz Device 段石英 vs MEMS 分歧（同 TXC / NDK / Kyocera / Rakon）
  - **多軌組合**：印表機 + 投影機 + 機器人 + Quartz Devices + 手錶機芯五軌、conglomerate sum-of-parts 結構
  - **TCXO 全球 #1 是 niche differentiator**：Quartz Device 段 TCXO 寡占、跟 TXC / NDK 並列日台三巨頭
- 護城河四層：
  - **PrecisionCore inkjet IP**：印表機核心技術、30+ 年累積
  - **LCD / 3LCD 投影機 IP**：投影機全球 #1 護城河
  - **SCARA 機器人 IP**：精密組裝 niche 全球 #1
  - **TCXO 寡占 IP**：石英 timing 段全球 #1、跟 TXC / NDK 並列日台三巨頭
- 競爭格局：
  - **vs [[SiTime]]**（NASDAQ: SITM）：路線分歧、SiTime 高端 5G / AI server / 衛星 / 機器人、Epson 多軌組合 + TCXO 寡占
  - **vs [[TXC]]**（3042.TW）：Quartz Device 段同分歧（Epson TCXO #1、TXC 消費電子 + 汽車大宗）
  - **vs [[NDK]]**（6779.JP）：Quartz Device 段同分歧（Epson TCXO #1、NDK Apple iPhone + 光學晶振）
  - **vs [[Kyocera]]**（NYSE: KYO + 6971.JP）：兩家都 conglomerate、Kyocera 跨「石英 + 陶瓷 + AVX 鉭電容 + 太陽能 + 印刷」，Epson 跨「印表機 + 投影機 + 機器人 + 石英 + 手錶」、路線重疊度低
  - **vs [[Rakon]]**（NZX: RAK）：niche 玩家、Epson Quartz Device 段規模 ~Rakon 30-50x
  - **vs HP / Canon / Brother**：印表機賽道直接對手
  - **vs Sony / BenQ / NEC**：投影機賽道直接對手
- 風險：
  - **印表機萎縮**：紙本需求成熟期下降 → Epson 基本盤受壓
  - **[[SiTime]] MEMS 高端滲透**：5G / AI server / 衛星市佔提升 → Epson TCXO 段受壓
  - **conglomerate sum-of-parts 折價**：多軌組合可能被市場 discount
  - **JPY/USD 匯率**：高出口比重、日圓升值壓營收
  - **[[CapEx 見頂辯論]]** 兌現 + 印表機 + 投影機需求放緩
- → 連 [[控制點轉移（投資版）]]：**印表機 + 投影機 + 機器人 + TCXO + 手錶機芯五重控制點** = Epson 是日本精密設備 conglomerate 典範

### Re-rate 三角形

| 項目 | 狀態 |
|---|---|
| 營收品質 | ✅ 印表機 + 投影機 + 機器人 + Quartz Devices + 手錶五引擎 |
| 毛利率 | ⚠️ 印表機成熟期毛利率受壓、整體 op margin ~8-12% 中段 |
| OpEx | ⚠️ 多軌組合 capex 持續 |
| 營業利益 | ⚠️ conglomerate 折價、營業利益穩定但無爆發 |

→ **Re-rate 三角形 2/4**——多軌組合穩定但缺乏單一 catalyst、整體營收品質 + 多軌分散是護城河、但 conglomerate sum-of-parts discount。估值 Forward PE 12-16x 反映「**日本多軌組合王 + Quartz Device 段 TCXO #1**」defensive 定位。
