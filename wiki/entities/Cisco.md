# Cisco（NASDAQ: CSCO）

## 1. 一句話定位

**全球路由器 / 交換器歷史龍頭 + 2000-03 全球市值第一 ($550B 盤中) + 2024 Splunk $28B 併購 SecOps 補位 + Silicon One 自研網路 ASIC + Nexus 9k 資料中心交換 + DCI 補強位（vs [[Ciena]] 純度王 / [[Nokia]] 廣度王）+ AI infra 槓桿最低但估值便宜 + 客戶結構從「萬家企業 IT 部門」流失到「少數 hyperscaler」典型**——KP@FOMOSoc #48 把 Cisco 列為 Scale-Across 第三軌補位玩家（vs CIEN 純度王 + Nokia 廣度王）、但具體 thesis 擋付費牆；多元業務緩衝 + Forward PE ~17x（vs CIEN 80-91x / Nokia 43x）是「**DCI 賽道對但對 AI 純度懷疑**」的對沖配置；Splunk $28B（2024-03 完成）整合給 Cisco SecOps + Observability 新引擎、跟 [[CrowdStrike]] / [[Palo Alto Networks]] / Datadog 跨軌競爭；Arista Networks 是資料中心交換器直接對手（hyperscaler 已大規模轉向 Arista white-box）。

## 2. 三層 thesis

### 產業層

- 多賽道並行（每條都在 [[市場四階段：懷疑／驗證／共識／反轉]] 不同階段）：
  - **企業路由 / 交換**：成熟 + 共識（傳統 base、客戶流失）
  - **資料中心交換（Nexus 9k）**：⚠️ **驗證 → 共識**（vs Arista white-box + Nokia 7220 IXR-H6）
  - **Silicon One 自研 ASIC**：⚠️ **懷疑 → 驗證**（vs Broadcom Tomahawk + Marvell Innovium）
  - **Splunk SecOps + Observability**：共識（vs CRWD + PANW + Datadog）
  - **Webex 協作**：衰退（vs Microsoft Teams + Zoom）
  - **WiFi 6/7 + 邊緣**：穩定（Meraki）
- 跟 [[AI infra CapEx 三階段論]] **第三階段間接受惠**：
  - Silicon One ASIC 配套 hyperscaler scale-out
  - Splunk 配套 AI SOC observability
  - Nexus 9k 配套 hyperscaler 資料中心
- 跟 [[Hyper Rail Multi-Rail（光通訊整合技術）]]：**Scale-Across 補強位**（vs CIEN 純度王 + Nokia 廣度王）
- 跟 [[NVDA 網路 stack map]]：**hyperscaler 流失給 Arista white-box / Nokia 7220 IXR-H6 / NVDA Spectrum-X** 三面夾擊
- 跟 [[賣水人選股邏輯（投資版）]]：**多元業務 + 估值便宜對沖位**（vs CIEN 純度 / Nokia 廣度）
- 在 [[資訊擴散四階段]]：機構 / 賣方層滲透深、媒體層**已疲態**（Cisco 已被市場視為「傳統設備商」、AI infra 槓桿低）

### 目的層

- **核心業務結構**（FY2025 預估、後 Splunk）：
  - **Networking（含 Switching + Routing + Wireless）**：~55-60% 營收
    - **Switching（Nexus 9k + Catalyst）**：資料中心交換 + 企業 LAN base
    - **Routing**：傳統 enterprise + ISP base
    - **Wireless（Meraki + Catalyst Access）**：穩定 base
  - **Splunk Security + Observability**：~15-20% 營收（2024 整合後）
    - **Splunk Enterprise / Cloud**：SIEM Next-Gen 主力
    - **Splunk Observability**：APM + Logs + Metrics
  - **Security（Cisco 既有）**：~5-10% 營收（Secure Firewall + Umbrella + Talos threat intel）
  - **Collaboration（Webex）**：~5-7% 營收、衰退中
  - **Services**：~25-30% 營收、recurring 穩定
- **AI infra 曝險**：
  - **Silicon One ASIC**：跟 Broadcom Tomahawk + Marvell Innovium 對手、hyperscaler 自研 / white-box 衝擊大
  - **Nexus 9k 資料中心交換**：vs Arista 白牌 + Nokia 7220 IXR-H6 102.4 Tb/s 對撞
  - **Splunk AI Insights**：vs CrowdStrike Falcon LogScale + Datadog AI Observability
  - **DCI 補強位**：vs [[Ciena]] HyperRail / [[Nokia]] Multi-Rail
- **客戶結構**：
  - **傳統 enterprise（萬家企業 IT 部門）**：流失中、Microsoft / Cisco bundled 競爭
  - **Service Provider（電信 CSP）**：傳統 base、AI-RAN 紅利吃不到（vs Nokia）
  - **Hyperscaler**：**結構性流失**（hyperscaler 已大規模轉 Arista white-box + Nokia 7220 IXR-H6 + NVDA Spectrum-X）= 採購邏輯翻轉（低價 / 開放 / 大量）
  - **政府 / 國防 / 教育**：穩定 base
- 商業模式核心：
  - **「**多元業務 + 訂閱化轉型 + Splunk SecOps + Silicon One 自研 + 估值便宜對沖**」**五軸
  - **訂閱化轉型**：從 hardware perpetual license → software subscription（ARR 占比逐漸提升）
  - **Splunk 整合**：$28B（2024-03 完成）= 從「硬體中心」轉向「軟體 + 服務中心」
  - **Silicon One**：自研 ASIC 對抗 Broadcom + Marvell + NVDA Spectrum、但 hyperscaler 已多選 Broadcom Tomahawk
- 對應 [[賣水人選股邏輯（投資版）]]：**多元業務 + 估值便宜對沖位**（vs CIEN 純度 / Nokia 廣度、Cisco 是「DCI 賽道對但對 AI 純度懷疑」對沖）
- 對應 [[控制點轉移（投資版）]]：**控制點正在流失**（從「企業路由 / 交換」龍頭 → hyperscaler 轉向白牌 + Arista）

### 供應層

- 跟 [[Nokia]] 路線（**Scale-Across 廣度王 + 直接對手**）：
  - Nokia 三張牌（Infinera + NVDA $1B + 7220 IXR-H6 102.4 Tb/s）= 直接對標 Cisco Nexus 9k
  - Nokia 9 of top 10 hyperscaler 都用 vs Cisco 仍 enterprise 為主
  - Nokia FY2026 NI 指引 +12-14% vs Cisco Networking 預估 +1-3%
  - **意義**：Nokia 是「**反轉敘事**」+ Cisco 是「**結構性流失**」分歧路線
- 跟 [[Ciena]] 路線（**DCI 純度王 + 補強對手**）：
  - CIEN HyperRail co-developed with hyperscaler + WaveLogic 6 DSP 自研
  - Cisco DCI 是 routing / switching 補強、無 line system / coherent DSP 自研
  - **CIEN supply-constrained → 訂單外溢給 Nokia**（KP 立場、Cisco 在 line system 沒位）
- 跟 Arista Networks 路線（**資料中心交換直接對手**）：
  - **Arista 是 hyperscaler 主場**（AWS / Microsoft / Meta / Google 大規模轉向 Arista white-box）
  - Cisco Nexus 9k 在 enterprise 仍有市佔、但 hyperscaler 流失嚴重
  - **Cisco Silicon One vs Arista 7800R EOS**：Silicon One 自研、Arista EOS 軟體 + Broadcom Tomahawk
- 跟 [[CrowdStrike]] / [[Palo Alto Networks]] 路線（**Splunk SecOps 對手**）：
  - Splunk Enterprise SIEM 雖然成熟、但 CRWD Falcon LogScale + PANW Cortex XSIAM 是 next-gen 對手
  - Cisco Splunk + Cisco Secure Firewall + Umbrella + Talos = SecOps 整合、但純度上 CRWD / PANW 仍勝
- 跟 [[Microsoft]] 路線（**Webex vs Teams 衰退 + Defender vs Splunk 對沖**）：
  - Microsoft Teams 把 Webex 打到衰退
  - Microsoft Defender + Sentinel bundled 進 M365 E5 + Azure = Splunk 平台威脅
- 跟 NVDA Spectrum-X 路線（**hyperscaler ASIC 流失**）：
  - NVDA Spectrum-X / Quantum-X 提供 InfiniBand + Ethernet ASIC
  - Cisco Silicon One 在 hyperscaler 流失給 NVDA + Broadcom + Marvell
- 跟 Broadcom + Marvell ASIC 路線（**自研 ASIC 對手**）：
  - Broadcom Tomahawk 6 ASIC 在 hyperscaler 主場
  - Marvell Innovium + Teralynx 路徑差異化
  - Cisco Silicon One **市佔結構性流失**
- 護城河：
  - **企業 enterprise 客戶結構深 + Cisco IOS / NX-OS 軟體 ecosystem 鎖死**
  - **Splunk SecOps + Observability 整合**（2024-03 完成、$28B 投資）
  - **Silicon One 自研 ASIC**（雖弱但仍是稀有的自研網路 ASIC 玩家之一）
  - **Talos threat intelligence**（全球 top 3 商業 threat intel）
  - **Meraki cloud-managed 邊緣**（中小企業滲透深）
  - **多元業務緩衝 + 訂閱化轉型**
- 風險：
  - **hyperscaler 結構性流失**（轉向 Arista + Nokia + NVDA + Broadcom）= AI 紅利吃不到
  - **Webex 衰退**（vs Microsoft Teams）
  - **Splunk 整合 execution 風險**（$28B 是 Cisco 史上最大併購、整合複雜）
  - **Silicon One 市佔流失**（vs Broadcom Tomahawk + Marvell）
  - **AI infra 槓桿低**（vs Nokia / CIEN / Coherent / Lumentum 直接受惠 AI infra ramp）
  - **採購邏輯翻轉**（hyperscaler 要求低價 / 開放 / 大量 = Cisco 高毛利 + 封閉 ecosystem 結構性不適合）
  - **Microsoft Defender bundle 威脅 Splunk SecOps**

## ⭐ DCI 賽道對沖位 thesis（vs CIEN 純度王 / Nokia 廣度王）

### 三家分食架構

| 公司 | DCI 純度 | 估值（Fwd PE）| 客戶集中度 | 業務多元緩衝 | AI 紅利 |
|---|---|---|---|---|---|
| [[Ciena]] | **5/5（純）** | **80-91x（極貴）**| 1/5（極集中）| 1/5（無）| **5/5（極大）** |
| [[Nokia]] | 2/5（多元）| 43x（貴）| 4/5（分散）| 4/5（強）| 3/5（中）|
| **Cisco** | **2/5（多元）** | **~17x（便宜）** | 4/5（分散）| **5/5（最強）** | **1/5（最低）** |

→ **Cisco 是「**DCI 配置雜訊**」**——估值便宜但 DCI 槓桿極低、AI 紅利吃不到。**意義**：
- 重押 DCI thesis：CIEN > Nokia > Cisco
- 對沖 DCI thesis（不確定哪家拿單）：Nokia > Cisco > CIEN
- 對沖 AI infra thesis（懷疑 AI 過熱）：**Cisco** > Nokia > CIEN
- 三家持有：DCI 賽道完整曝險

### 為什麼 KP 把 Cisco 列為對沖位

- Cisco 客戶結構從「萬家企業」→「少數 hyperscaler」流失中、AI infra 槓桿低
- 但 Forward PE ~17x（vs CIEN 80-91x / Nokia 43x）= 估值便宜
- 多元業務（Networking + Splunk + Security + Services）緩衝
- 股息 ~2.5-3.0% 防守
- → 「**DCI 賽道對的時候、Cisco 是估值便宜的對沖配置**」

## 五軸評分（25 分制）

| 軸 | 分數 | 理由 |
|---|---|---|
| **路線敏感度（逆向）** | **2 / 5** | 多元業務 + 估值便宜 + 股息 = 對沖位、但 AI 紅利吃不到 |
| **站別關鍵度** | **2 / 5** | hyperscaler 結構性流失、enterprise 仍有但 base 業務、AI infra 槓桿低 |
| **耗材 recurring** | **4 / 5** | 訂閱化轉型 + Splunk ARR + Services recurring 穩定 |
| **IP 控制** | **3 / 5** | Silicon One 自研 + Cisco IOS / NX-OS ecosystem、但 hyperscaler 已多選 Broadcom Tomahawk |
| **客戶分散** | **5 / 5** ⭐ | enterprise + ISP + 政府 + 教育 + Service Provider 全球分散、無單一 > 10% |

**總分 = 16 / 25** —— 跟 [[Cloudflare]] 16 並列、低於 [[Nokia]] 18 / [[Ciena]] 19；**對沖位 anchor**（多元業務 + 估值便宜 + 股息）、不是 AI infra alpha。
