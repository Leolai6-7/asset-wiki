# Tower Semiconductor（NASDAQ: TSEM）

## 1. 一句話定位

**全球領導級 specialty foundry、矽光子 PIC（Photonic Integrated Circuit）foundry 龍頭、AI 光通訊鏈跨第 4-5 層 SiPho 平台「賣水人之中的賣水人」**——1993 年從 National Semiconductor 以色列分部分拆、總部 Migdal Haemek（以色列）、擁 **2 個以色列 fab（150mm + 200mm）+ 美國 Newport Beach（CA）+ Uozu（日本，原 Panasonic）**、加 **2024 起與 Intel 簽約用 Intel 新墨西哥廠 300mm 矽 foundry 容量**（投資 $300M 設備）；2023-08 [[Intel]] **$54 億收購案因中國監管未過終止、Intel 賠 $353M 終止費**、Tower 反而獨立成長 + 拿到 Intel 300mm foundry 補位、**從「被併購對象」變「特殊 foundry 隱形冠軍」**；2026 年三大 strategic 客戶 anchor 同步落地：**2026-02-05 [[NVDA]] 戰略合作生產 1.6T-class SiPho 光引擎 + 模組**、**2026-03-23 [[Coherent]] 合作 demo 400Gbps/lane 矽光子調變器（指向 3.2T 模組）**、與 [[Marvell]] 配合 SiPho（NVDA + Marvell $2B Alliance 鏈內合作）；矽光子業務 **2024 $106M → 2025 $228M → 2025 年底年化 run rate $360M+**、Q1 2026 矽光子 YoY **+3 倍**、收取 SiPho 客戶**預付款 $290M**（產能買斷訊號）；公司整體 Q1 2026 營收 **$414M（YoY +15%）**、Q2 2026 guidance **$455M（YoY +22%）**、毛利率回升至 26.8%、市值 **USD $29.35B**、12 個月 **+580.8%**、Forward PE 69.93；是 [[Serenity]] 框架中與 **Soitec ($SOI)** 並列「**Safest Longs**」defensible compounder = **跨層 SiPho foundry 賣水人**。

## 2. 三層 thesis

### 產業層

- **specialty foundry + 矽光子 PIC foundry 賽道**處於 [[市場四階段：懷疑／驗證／共識／反轉]] **「驗證 → 共識」加速段**：
  - SiPho PIC 是 1.6T → 3.2T 模組商用化的**物理前提**（光電整合單晶片化）
  - 矽光子 wafer **全球能規模化生產的 PIC foundry < 5 家**：**Tower / GlobalFoundries / TSMC / IMEC** + 部分自研（Coherent / Intel SPB）
  - **Tower 是其中規模 + 客戶 + 製程穩定性最 mature 的純 SiPho foundry**——客戶包含 [[Lumentum]]、[[Coherent]]、Marvell、Cisco、NVDA、InP / SiGe 多 IDM
- **AI 光通訊賽道結構性需求**（[[AI infra CapEx 三階段論]] 第三階段最關鍵 anchor 之一）：
  - 1.6T 模組需求 2025 1.8M → 2026 30M+ units（17 倍增量）
  - 2027-2028 CPO 商用化拐點：CPO **必須走 SiPho PIC 路線**、矽光子 foundry 容量是 CPO ramp 的物理瓶頸
  - 3.2T 已開始 demo（2026-03 Tower x Coherent 400Gbps/lane）= **下一代擴張曲線**已開始投影
- **特殊 foundry 賽道結構性「賣水人」位階**：
  - 不押任何單一客戶（NVDA / Coherent / Marvell / Cisco 多客戶平行）
  - 不押任何單一路線（SiPho / SiGe / RF SOI / BCD / 影像 sensor / power management 多製程平台）
  - = **與 [[TSMC]] 的「邏輯 foundry 賣水人」位階相似、但聚焦 specialty + photonics**
- 賽道 timing：
  - [[資訊擴散四階段]] 階段 **3-4**（股價 12M +580% 已過 KOL / 機構發掘段）
  - [[Hyper Rail / Multi-Rail（光通訊整合技術）]] / [[CPO 供應鏈圖譜]] 第 4-5 層光引擎 + 模組 anchor foundry
  - 2026-02 NVDA partnership = 賽道 anchor 訊號（最重要客戶之一綁定）
- vs [[TSMC]] / GlobalFoundries / [[Samsung Electronics]] foundry：
  - TSMC 邏輯製程龍頭、但 specialty / photonics 是次要業務（最近才接 [[NVDA]] SiPho 訂單）
  - GlobalFoundries 美國本土 specialty foundry、AESC EV / RF / SOI 強、SiPho 略遜 Tower
  - Samsung 邏輯製程 + DRAM、SiPho 不是主軸
  - **Tower 是 SiPho PIC pure-play / leadership** = **比 TSMC 賽道更窄但純度更高**

### 目的層

- 業務 mix（2025 推估）：
  - **Silicon Photonics（SiPho）**：**$228M（2025）→ year-end run rate $360M+** ⭐⭐
    - 1.6T / 3.2T 光引擎 + 模組 PIC
    - 客戶包含 [[Lumentum]] / [[Coherent]] / Marvell / NVDA / Innolight / 旭創 等
    - **2026 Q1 +3x YoY** = 最強成長軌
  - **SiGe BiCMOS**：RF / 無線 / 雷達 / 光通訊 driver
    - 用 300mm wafer bonding 與 SiPho stack 整合 = SiPho 模組必備
  - **RF SOI**：5G / 6G 智慧手機 PA 模組
  - **BCD（Bipolar-CMOS-DMOS）**：power management IC
  - **影像 sensor**：消費電子 / 工業
  - **Discrete & MEMS**：sensor / RF
- 商業模式 = **「specialty foundry pure-play」**：
  - 不做邏輯 7nm/5nm/3nm（讓 TSMC / Intel 競爭）
  - 不做 DRAM / NAND（讓 Samsung / Micron 競爭）
  - **專做 specialty 製程**：RF SOI / SiGe / BCD / SiPho / MEMS / power 等
  - 用「**多客戶 + 多製程平台**」取代「**單一大客戶 + 邏輯 ASP**」= 賽道穩定但成長慢的傳統 foundry 模式
  - **2025 起 SiPho 業務爆發 = 從傳統穩定 → 高成長 hybrid 模型**
- 客戶結構（公開度有限）：
  - **NVDA**：2026-02 戰略合作生產 1.6T SiPho 光引擎 + 模組 ⭐⭐
  - **Coherent**：2026-03 demo 400Gbps/lane 矽光子調變器（指向 3.2T）⭐
  - **Marvell**：2026-04 NVDA + Marvell $2B Alliance 鏈內配合 SiPho（透過 Marvell DSP / SerDes）
  - **Cisco**：Silicon One G300 1.6T OSFP 模組合作（2026-02）
  - **Lumentum**：Lumentum 的 SiPho 路線部分外包 Tower
  - **Intel / AMD / 影像 sensor IDM / 智慧手機 PA fabless**：specialty 平台多客戶
- 客戶高度分散風險：相比 [[AAOI]] / [[SIVE]] 客戶極端集中、Tower 是**多客戶分散組合** = **defensible compounder 特質**
- → 連 [[賣水人選股邏輯（投資版）]]：**「specialty foundry 賣水人之中的賣水人」**——不押 NVDA vs Marvell vs Coherent 誰贏、押所有需要 SiPho PIC 的鏈
- [[控制點轉移（投資版）]]：拿到「**SiPho PIC 製程平台 + NVDA / Coherent / Marvell 同時綁定 + 以色列 + 美國（Intel 300mm）+ 日本三地產能**」四重控制點

### 供應層

- 跟 [[NVDA]] 關係：
  - 2026-02 戰略合作生產 **1.6T-class SiPho 光引擎 + 模組**
  - = NVDA 押注 **CPO 替代 pluggable** 的物理前提就在 Tower SiPho 平台
  - 與 NVDA 對 [[Lumentum]] / [[Coherent]] $4B 戰略投資（2026-03）+ Marvell $2B（2026-04）形成「**NVDA 鎖定整個光通訊鏈 chokepoint 多家配置**」
- 跟 [[Coherent]] 關係：
  - 2026-03 demo 400Gbps/lane 矽光子調變器（指向 3.2T 模組）
  - Coherent 自家 SiPho 線追趕 [[Lumentum]]、與 Tower 合作補位
  - = **Tower 是 Coherent SiPho 路線的外部 wafer foundry 補位**
- 跟 [[Marvell]] 關係：
  - 2026-04 NVDA + Marvell $2B Alliance、Marvell DSP / SerDes + Tower SiPho PIC 配合
  - = Tower 提供 wafer、Marvell 提供 DSP、共同進入 NVDA AI factory
- 跟 [[Lumentum]] / [[Coherent]] 自家 SiPho 線：
  - **互補非完全對手**：兩家有自家 SiPho 容量、Tower 補位整體鏈瓶頸
  - 跟 [[IQE]] / [[AXTI]] 上下游關係不同——Tower 是**矽光子製程平台、不需 InP wafer**（SiPho 走矽 wafer 路徑）
  - 但 SiPho **必須與 InP CW DFB laser 整合**（CPO 模組）= [[SIVE]] / [[Lumentum]] / [[Coherent]] CW laser 提供光源、Tower 提供 SiPho 處理引擎
- 跟 OEM 模組廠（旭創 / Eoptolink）：
  - **不直接競爭、是上游**：OEM 模組廠用 Tower SiPho wafer 加工成 1.6T / 3.2T 模組
  - = Tower **跨越「中國 vs 美國」OEM 競爭**、兩邊都是客戶
- 跟 [[Intel]] 關係（2023-08 Intel 收購案後遺產 + 2024 新合作）：
  - **2023-08 Intel $54 億收購案因中國反壟斷審批延宕終止、Intel 賠 $353M 終止費**
  - **2024 起 Intel 提供 300mm 矽 wafer foundry 服務給 Tower**（用 Intel 新墨西哥廠）+ Tower 投資 $300M 設備
  - = Tower **拿到 Intel 300mm 容量補位**而不需自建 300mm fab
  - **Intel 變成 Tower 的容量供應商**（角色反轉）
- pump laser / EML / DFB epi vs SiPho 競爭地位：
  - **SiPho PIC 路線龍頭**（與 GlobalFoundries / TSMC 競爭）
  - **SiGe BiCMOS + 300mm wafer bonding**：用 SiGe 高頻 driver 與 SiPho stack = **業界少數能整合的平台**
  - **400 Gbps/lane PAM4 demo（2026-03）**：與 [[Coherent]] 共同 demo、指向 3.2T 商用化
  - **2025 年底 SiPho run rate $360M+**：規模超過 GlobalFoundries SiPho 段
- 護城河：
  - **SiPho PIC 製程平台 + 300mm wafer bonding 整合能力**（與 SiGe + InP 跨製程）
  - **多客戶 anchor**：NVDA + Coherent + Marvell + Cisco + Lumentum 同時綁定
  - **以色列 / 美國 / 日本三地產能 + Intel 新墨西哥 300mm 補位**（地緣風險分散）
  - **Intel 收購案經驗 = 監管 / 整合風險 IP**（Tower 知道大規模整合如何撐住）
  - **Q1 2026 收取 SiPho 客戶預付款 $290M**（產能買斷 anchor、降低 ramp 風險）
- 風險：
  - **[[NVDA]] 自家 SiPho 線（NVIDIA Photonic Solutions）擴張**——若 NVDA 自建 SiPho 平台、Tower 訂單流失
  - **GlobalFoundries / [[TSMC]] SiPho 擴張**——TSMC 對 [[NVDA]] 拿 SiPho 訂單、未來 Tower 可能與 TSMC 直接競爭（TSMC 規模優勢）
  - **以色列地緣政治風險**：Migdal Haemek fab 在以色列、區域衝突風險
  - **Forward PE 69.93 + Trailing PE 108.88**：估值偏高、any miss 風險
  - **股價 12M +580%**：大部分 alpha 已釋放、追高空間有限
  - **3.2T CPO ramp timeline 不確定**：若 2027-2028 CPO 商用化推遲、SiPho 成長率放緩
  - **客戶結構雙刃**：多客戶分散是 defensible 優勢、但每個客戶都不是「絕對主導」、議價力不如 TSMC vs Apple
- → 連 [[控制點轉移（投資版）]]：「**SiPho PIC 製程平台 + 多客戶 anchor + 三地產能 + Intel 300mm 補位**」四重控制點、但被 NVDA 自家 SiPho / TSMC SiPho 擴張未來可能 partial cannibalize

## ⭐ Serenity 重押論述

[[Serenity]] (@aleabitoreddit) 將 TSEM 列為 **Bottleneck Theory 「Safest Longs」defensible compounder**，與 **Soitec ($SOI)** 並列為「**跨層 SiPho foundry 賣水人**」。**vs [[SIVE]] 高 beta chokepoint 期權、vs [[AAOI]] 中 beta vertical integration**——**TSEM = 低 beta defensible compounder**，三者形成 Serenity 五家組合的 risk spectrum 結構。

### Serenity 對 TSEM 的 reasoning

從 [[Serenity]] 公開 X 推文 + Singularity Research Fund / Johnson Lee / PANews 整理：

1. **「Safest Longs」defensible compounder 定位**（Serenity 原推、與 Soitec 並列）
   - **意涵**：在 Bottleneck Theory 7 層 chokepoint 配置中、TSEM 是**最低 beta、最 defensible 的 anchor**
   - 不是「最尖端 alpha」、是「**最穩 anchor compounder**」
   - 對應投資人：保守型 chokepoint 配置、可作為 portfolio core
2. **跨第 4-5 層 SiPho foundry 賣水人**（推測 Serenity reasoning）
   - **意涵**：TSEM 同時供應第 4 層 CW DFB laser 模組封裝 + 第 5 層 transceiver SiPho PIC
   - 不單押任何一層、跨層收租 = **比 [[SIVE]]（純第 4 層）/ [[AAOI]]（純第 5 層）更分散**
3. **「不單押任何客戶、跨層 NVDA + Coherent + Marvell + Cisco + Lumentum 同時綁定」**
   - **意涵**：NVDA $2B 對 Marvell / $4B 對 Lumentum+Coherent，**這些錢最終都會流到 TSEM 的 SiPho wafer**
   - = TSEM 是 NVDA 投錢、誰拿訂單都受惠的賣水人
4. **與 Soitec ($SOI) 並列為「**Safest Longs**」defensible compounder（vs SIVE 高 beta、AAOI 中 beta）**
   - 對應 Serenity 五家配置的 **risk spectrum**：
     - **超高 beta**（純期權型）：[[SIVE]]、[[AXTI]]、[[AEHR]]
     - **中 beta**（vertical integration）：[[AAOI]]
     - **低 beta**（defensible compounder）：**TSEM + Soitec**
   - = TSEM 是 Serenity 框架中**最保守的 anchor**

| 層 | Chokepoint | TSEM 位置 |
|---|---|---|
| 1. Raw Materials | Ga/In/As 採礦 + 純化 | ❌ 不在 |
| 2. Growth Equipment | pBN crucibles (Shin-Etsu) | ❌ 不在 |
| 3. InP Substrate | [[AXTI]] + Sumitomo Electric | ❌ 不在 |
| 4. Laser Sources (CW DFB) | [[SIVE]] / [[Lumentum]] / [[Coherent]] | ⭐ **跨層**（SiPho 平台用於 laser packaging）|
| **5. Optical Transceivers** | [[AAOI]] / [[Lumentum]] / [[Coherent]] / Innolight | ⭐⭐ **主場**（SiPho PIC foundry for 1.6T/3.2T 模組）|
| 6. Testing & Qualification | [[AEHR]] | ❌ 不在 |
| 7. Optical Cable & Fiber | [[Corning]] | ❌ 不在 |

→ **TSEM 跨第 4-5 層、是 Bottleneck Theory 中位階特殊的 SiPho foundry 賣水人**。

→ vs OEM 模組廠（旭創 / Eoptolink / Innolight）：OEM 廠買 Tower SiPho wafer 加工成 1.6T / 3.2T 模組、**Tower 是 OEM 上游、不是直接競爭**。

→ vs [[AAOI]]：兩者都做光通訊、但 AAOI 是 transceiver vertical integration、Tower 是 SiPho **foundry 平台**——**AAOI 賣模組、Tower 賣 wafer**、兩者上下游互補。
