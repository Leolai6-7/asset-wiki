# Foxconn Interconnect Technology FIT（6088.HK / 鴻騰精密）

## 1. 一句話定位

**鴻海集團 80% 持股連接器子公司 + 高速 connector 全球 top 3 + NVDA NVLink + GPU server + CPO 連接器主力 + AI server 連接器 BOM 30-40% 雙鏈受惠（鴻海 ODM 內製 + 外售）+ 跟 [[Amphenol]] / Molex / TE Connectivity 形成「**全球高速 connector 四強分食**」**——[[CPO 供應鏈圖譜]] 第 6 層 connector 對手位、跟 [[Amphenol]] entity 明寫「**鴻海 FIT = APH 的對手**」對位、鴻海集團 AI server 整機代工 + AI infra 上游 connector 雙鏈整合受惠者、[[AI infra CapEx 三階段論]] 第三階段間接受惠。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] + [[CPO 供應鏈圖譜]] 第 6 層 connector 戰場、進入 [[市場四階段：懷疑／驗證／共識／反轉]] 「**驗證 → 共識**」過渡（vs [[Amphenol]] 已 ETF 化、FIT 港股估值仍乾淨）
- 全球 connector 市場 ~$80B（2025）→ ~$120B（2030）、高速 connector + 光纖 connector 占比 +50%
- 跟 [[AI infra CapEx 三階段論]] 第三階段：1.6T 光模組 + NVDA Rubin 1MW 機櫃 → connector 用量翻倍
- 跟 [[CPO 供應鏈圖譜]] 第 6 層：高速電 + 光纖 connector + 電源 connector 三軌賣水人
- 跟 [[NVDA 網路 stack map]]：NVLink + Spectrum-X + Quantum-X + ConnectX-9 + BlueField-4 全 stack connector 需求
- 在 [[資訊擴散四階段]]：機構 → 賣方層滲透（鴻海集團 AI server anchor 已 ETF 化、FIT 子公司滲透略滯後）

### 目的層

- **業務組合**（FY2025 預估）：
  - **Connector**：~50%（**主力業務**）—— 高速電 + 光纖 + 電源 + 行動 connector
  - **無線網路 / WiFi 模組**：~20-25%
  - **音響 / Acoustic**（Belkin 子品牌、Linksys + Phorus）：~15-20%
  - **5G / 工業 / 醫療**：~10-15%
- **Connector 細拆**：
  - **High-speed connector**：NVLink + PCIe Gen5/Gen6 + 224G 高速電傳輸、AI server 主力
  - **光纖 connector**：CPO + plug-in optic 配套、CPO ramp 受惠
  - **電源 connector**：800V HVDC + 機櫃內配電
  - **行動 connector**：iPhone + 智能手機 Lightning + USB-C base
- **AI server 客戶結構**：
  - **鴻海集團內部供應**（NVDA DGX / HGX 整機代工）：自家 ODM 鏈條
  - **NVDA**：NVLink + Spectrum-X / Quantum-X 配套（具體比例未揭露、推估 15-25%）
  - **4 大 CSP**（[[AMZN]] / [[Microsoft]] / [[Google]] / [[Meta]]）：透過鴻海 ODM 餵 + 部分直供
  - **AMD / AVGO ASIC**：透過鴻海 ODM 整機代工
  - **[[Apple]] + 其他 OEM**：base 業務
- **產能 + 擴張**：
  - 廣州 + 深圳 + 河南 + 越南 + 印度 + 墨西哥多地產能
  - 高速 connector 線 ramp（224G / 800G / 1.6T 配套）
  - **規避美中貿易戰**（多地擴張 + 印度 / 墨西哥 hedge）
- 商業模式核心：
  - **「**鴻海集團 80% 持股 + AI server ODM 內製連接器 + 外售 + 高速 connector 全球 top 3**」**：雙鏈受惠（ODM 內製 + 外售）
  - **「**規模 + 鴻海集團議價權勝過獨立 connector 廠**」**：透過鴻海 AI server 整機代工 lock-in
  - **跟 [[Amphenol]] / Molex / TE Connectivity 分食**：高速 connector + 光纖 connector + 電源 connector 三軌全線、規模略小但鴻海 ecosystem 加持
  - **Belkin 子品牌（Linksys + Phorus）多元化**：消費電子保護
- 對應 [[賣水人選股邏輯（投資版）]]：**鴻海 ODM 內製整合 + 規模型 connector 賣水人**——不押 NVDA / AMD / Trainium 誰贏、押**所有 AI server connector 都得用、且鴻海 ODM 必經之路**
- 對應 [[控制點轉移（投資版）]]：**鴻海集團整合 stack lock-in**（vs [[Amphenol]] 純零件廠模式）= 議價權**集團整合型 vs APH 純度型**

### 供應層

- 跟 [[NVDA]] 路線：
  - **NVLink spine connector + ConnectX-9 + BlueField-4 配套**（具體比例未揭露、推估 15-25%）
  - 跟 NVDA GB200 / GB300 / Rubin 整機代工配套（透過鴻海 ODM）
  - NVDA Rubin 1MW 機櫃 + universal QD + 45°C 標準 → connector 用量 + 規格升級
  - 跟 [[Amphenol]] 共同供應 NVDA（hyperscaler multi-source 慣例）
- 跟 [[Amphenol]] 對比（**核心對標**、APH entity 明寫「FIT = APH 對手」）：
  - **APH**：全球 connector #1（市值 $157B、市佔 ~12% 全球）+ AI 純度高（CommScope CCS 併購補光纖）+ 客戶 >100,000
  - **FIT**：全球 connector top 3-5（市佔 ~5-7% 全球）+ 鴻海 ODM 內製整合 + 規模略小但集團 ecosystem 加持
  - **APH 純度勝 + 規模勝**：12M +98.4% / Forward PE 29x（vs MPS 52-68x / Ciena 80-91x 乾淨估值）
  - **FIT 集團整合勝**：鴻海 80% 持股 + AI server ODM 內製 + 港股估值更乾淨
  - **共同壓制 Molex（Koch Industries 子）+ TE Connectivity（TEL）+ Yamaichi + Hirose**
- 跟 Molex（Koch 子公司、私有）對比：
  - Molex 規模略大、私有 = 不可直接押
  - Molex backplane connector 強、FIT 高速 connector 跟進
- 跟 TE Connectivity（NYSE: TEL）對比：
  - TEL 市值 $90B、全球 connector #2-3
  - 跟 FIT 高速 + 光纖 + 電源全線競爭
  - FIT 鴻海 ODM lock-in 勝、TEL 規模 + 全球分散勝
- 跟 [[鴻海]]（2317.TW）關係（**母公司**、80% 持股）：
  - 鴻海集團 AI server 整機代工龍頭（NVDA DGX + GB200/GB300 + Rubin 整機）
  - FIT 是鴻海 ODM 內製 connector 主供應商 + 對外銷售雙鏈
  - 鴻海透過 FIT 拿到 connector ecosystem 加持（vs 廣達 / 緯創 / 緯穎需採購 APH / Molex / TEL）
  - **鴻海 + FIT 整合 = AI server ODM 鏈條最完整 connector 控制權**
- 跟 [[廣達]] / [[緯穎]] / [[緯創]] 關係（**AI server ODM 對手**）：
  - 廣達 / 緯穎 / 緯創無自家 connector 子公司 = 需採購 APH / Molex / TEL / FIT
  - FIT 部分外售給廣達 / 緯穎 / 緯創 = **不正面競爭 + 部分合作**
  - 但鴻海 ODM 鏈條會優先用 FIT = **議價權集團整合勝**
- 跟 [[POET Technologies]] 關係：
  - POET 跟 FIT 800G/1.6T pluggable transceiver 合作（已揭露）
  - FIT 光纖 connector + POET 光引擎 = 部分配套
- 跟 [[Lumentum]] / [[Coherent]] / [[Innolight]] / [[AAOI]] 關係：
  - 光通訊 transceiver 玩家 + FIT 光纖 connector 配套
  - **FIT 是 1.6T 光模組產業鏈下游連接器供應商**
- 跟 [[CPO 供應鏈圖譜]] / [[Bottleneck Theory（瓶頸論）]]：
  - 第 6 層 connector「**Beneficiary**」（跟 [[Innolight]] 同層）—— 非 chokepoint、規模 + 客戶 lock-in 勝
- 護城河：
  - **鴻海集團 80% 持股 + AI server ODM 內製 lock-in**
  - **高速 connector 全球 top 3-5**
  - **規模 + 多地產能（廣州 + 深圳 + 越南 + 印度 + 墨西哥）**
  - **三軌 connector 全線**（高速電 + 光纖 + 電源 + 行動）
  - **跟 NVDA NVLink + Spectrum-X / Quantum-X 配套**
- 風險：
  - **集團依賴度高**（鴻海集團佔 FIT 業務 30-40%）
  - **規模略小於 [[Amphenol]] / Molex / TEL**（市值 $4-6B vs APH $157B / TEL $90B）
  - **港股流動性 + 估值滯後 A 股 / 美股**
  - **NVDA universal connector 標準化**削弱供應商定價權
  - **CPO 全面取代 plug-in optic**（plug-in 光纖 connector 業務萎縮）
  - **鴻海集團議價權**（FIT 內供 transfer pricing 可能壓制毛利率）
  - **Belkin / Linksys / Phorus 消費電子業務波動**（base 業務拖累）

| 層 | FIT 定位 |

| **第 4 層 Laser Sources** | ❌ 不在 |
| **第 5 層 Optical Transceivers** | ❌ 不在（部分跟 [[POET Technologies]] 合作配套 connector）|
| **第 6 層 連接器** | ⭐⭐⭐ **高速電 + 光纖 + 電源三軌全球 top 3-5**（vs [[Amphenol]] / Molex / TE Connectivity 同層）|
| **第 7 層 Optical Cable & Fiber** | ❌ 不在（[[Corning]] / Prysmian 主導）|

→ **FIT 在 Bottleneck Theory 框架中是「**第 6 層 Beneficiary**」**——跟 [[Innolight]] 同樣「跟著賽道漲、可替代、有競爭」**——這跟 [[Amphenol]] 第 6 層龍頭規模型 Beneficiary 是「**規模 vs 集團整合**」對撞。

| 軸 | 分數 | 理由 |
