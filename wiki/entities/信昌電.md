# 信昌電（6173.TWO）

## 1. 一句話定位

**全台唯一同時擁有「介電陶瓷粉末自製 + 大尺寸 / 中高壓 MLCC 量產」垂直整合的 niche 廠**（華新科集團 43.13% 持股之上櫃子公司）——主攻**1206 / 1210 / 1812 / 2220 以上大尺寸 + 數百至千伏耐壓 MLCC** + 自研 **Mega Cap 堆疊式電容**（單價為一般單體 7-9 倍）+ NP0 共振電容（單價為同尺寸 X7R 的 3 倍以上），**直接綁 NVDA GB200 → Rubin 1MW 機櫃電源（PSU + BBU）**——機櫃用量 **3,000-4,000 顆 → 突破 10,000 顆**是公司法說 2026-05-21 自己給的數字、不是賣方推估；台廠中高壓 MLCC 跟[[禾伸堂]]（3026）並列雙頭、跟 [[國巨]]（鉭電容 / 全品線）/ [[華新科]]（大中華 #1 規模戰）走完全不同的「**規格深度型 niche 賣水人**」路線。

## 2. 三層 thesis

### 產業層

- **中高壓 MLCC 子賽道**在 [[市場四階段：懷疑／驗證／共識／反轉]] 的「**驗證 → 共識**」加速段、但**比通用 MLCC 滯後一步**（4-5 月才被市場大規模 price in）
  - 800V HVDC 數據中心架構：PowerShelf 從 3kW → 110kW 推升中高壓 MLCC 需求
  - GB200 機櫃 132kW、單 5.5kW PSU 需 1,400-1,800 顆大尺寸 MLCC、單 BBU 需 700-960 顆 → **單機櫃 3,000-4,000 顆**
  - NVDA Rubin 1MW 機櫃（功耗 ~7.5x GB200）→ **單機櫃逾 10,000 顆**（公司法說 2026-05-21 親口）
  - 信昌電專攻的 **1206 / 1210 以上大尺寸 + 高耐壓 + 高可靠度**是藍海（門檻高、對手少、不卷低中階）
- **產業結構性緊缺**：高壓 MLCC 產能稼動率 85-90%、特殊品交期 **16 週**（正常 8 週）、客戶主動尋求長期合作 = 賣方市場
- 跟 [[MLCC 嵌入式基板賽道]] 的微妙關係：
  - 嵌入式 MLCC 目前商業化以**低壓高容**（村田 / 太陽誘電 / SEMCO）為主，**中高壓嵌入式技術尚未成熟**
  - 但 [[村田 Murata]] 2026 已量產 **1.25kV C0G 1210 size MLCC**——這代表「高壓 MLCC 可以做到 1210 板裝、嵌入式化的物理條件已具備」
  - → **中高壓 niche 短期受惠（2026-2028 大放量）+ 中長期被嵌入式切時程未定（2029+ 風險）**
- 跟 [[ABF 載板 vs 玻璃基板 displacement]] 關係：**間接受惠**（機櫃用量倍增 → 板載 MLCC TAM 短期擴大）
- 在 [[資訊擴散四階段]]：機構 → 賣方 → 媒體（媒體層滲透中、5 月底股價漲停潮即訊號）

### 目的層

- 2020 前三季產品 mix（最新公開細項）：
  - **MLCC = 52%**
  - 介電瓷粉 = 24%
  - 磁性元件 = 12%
  - 晶片電阻 = 11%
  - 其他 = 1%
- 2025 全年營收結構轉型中：MLCC 比重上升、AI 應用快速擴大
- **AI 營收占比**：2026 Q1 約 **6.5-8%**、全年指引「正式突破 10%」
- 客戶結構：
  - **直接打入 NVDA GB200 / Rubin 機櫃電源大廠 + BBU 大廠供應鏈**（卡位 HVDC 商機已被工商時報 2026-05-07 報導）
  - 禾伸堂產能被 GPU 晶片廠包掉、訂單**外溢給信昌電**（中高壓雙頭分工）
  - 訂單能見度 **>6 個月**、客戶主動長期合作協議
- 商業模式核心：「**全台唯一陶瓷粉末自製垂直整合 + 大尺寸 / 中高壓 niche 規格深度**」
  - 粉末技術朝**200 奈米以下超細微粒**發展（高階規格門檻）
  - **Mega Cap 堆疊式電容**：解決高壓 + 散熱 + 防斷裂、單價為一般單體 **7-9 倍**
  - **NP0（C0G）共振電容**：GB200 LLC 緩衝迴路單迴路用 10-30 顆並聯、單價為同尺寸 X7R **3 倍以上**
- 對應 [[賣水人選股邏輯（投資版）]]：**規格深度型賣水人**——不押誰贏，所有 800V HVDC 機櫃都得用
- 對應 [[控制點轉移（投資版）]]：拿到「**中高壓 niche + 介電粉末自製**」垂直整合控制點 = 議價權**結構性高於通用 MLCC**

### 供應層

- 跟 [[NVDA]] 路線：透過**機櫃電源大廠 + BBU 大廠**間接打入 NVDA Rubin AVL（公司未具名）
  - GB200：3,000-4,000 顆 / 機櫃 → Rubin 1MW：10,000+ 顆 / 機櫃（**~2.5-3x BOM 翻倍**）
  - 法說會明確說「AI 訂單迅速且快速的進入到公司」（陳根群總座）
- 跟 [[國巨]] 差異化：
  - **業務 mix**：信昌電 MLCC ~52%（純度近似 [[華新科]]）vs 國巨 MLCC 17.7%（鉭 + 阻全品線）
  - **規格深度**：信昌電 1206-2220 + 千伏級 vs 國巨高階主打 X6S 0402-0805 中小尺寸（X6S 在 GB200 主板 85%）
  - **完全不重疊**：國巨打「主板板載小尺寸 MLCC」、信昌電打「電源 PSU/BBU 大尺寸高壓 MLCC」
  - 規模差距：信昌電市值 ~370 億 vs 國巨 1 兆 + 10 倍以上 → 信昌電是「中高壓 niche pure-play」
- 跟 [[華新科]] 差異化（信昌電的母公司！）：
  - **集團從屬關係**：[[華新科]] 43.13% 持有信昌電（控制股東）
  - **業務分工**：[[華新科]] 主攻中階通用 MLCC + 安規 + 中高壓（630V 主力、研發 1,000V+）；信昌電主攻**大尺寸 + 千伏以上中高壓 + Mega Cap + 介電粉末**
  - → 信昌電是「**華新科集團內的中高壓 niche specialist**」、不是直接對打
  - 風險：母公司 [[華新科]] 可能優先內供瓷粉、減少對信昌電外售（潛在內部交易調度）
- 跟 [[禾伸堂]]（3026）：
  - **台廠中高壓 MLCC 雙頭**：禾伸堂 HVC-X7R + NP0（100V-10,000V）長年深耕
  - 禾伸堂產能已被 GPU 晶片廠包掉 → **外溢訂單給信昌電**（產業緊缺溢出）
  - → **不是零和、是共同擴大蛋糕**
- 跟 [[村田 Murata]] / [[太陽誘電 Taiyo Yuden]] / [[TDK]] / [[Samsung Electro-Mechanics]] / KEMET / Vishay：
  - **村田 1.25kV C0G 1210 MLCC** = 2026 已量產 = 信昌電中高壓 niche **遠期競爭對手**
  - TDK 為 AI server PSU 出 MLCC solution（指南）
  - 但日韓中高壓主打**車規 + 工業**為主、AI server 中高壓**尚未有絕對寡占者** → 信昌電有窗口期
- 嵌入式被動元件 / [[MLCC 嵌入式基板賽道]]：
  - **無公開 embedded MLCC 產品線**（與 [[國巨]] / [[華新科]] 同病）
  - **規模太小**（市值 NT$370 億）無資源跟載板廠（SEMCO / IBIDEN）做 co-development
  - 安慰：**中高壓嵌入式尚未商業化、信昌電 niche 短期不受切**（vs 通用 MLCC 已被切）
  - 警訊：村田 1.25kV C0G 1210 量產 = 中高壓嵌入化的物理條件已具備、**2029+ 風險**
- 護城河：
  - **全台唯一**陶瓷粉末自製 + MLCC 成品一條龍
  - **大尺寸高壓 niche 規格深度**（1206-2220 + 千伏級 + Mega Cap + NP0）
  - 客戶綁定（NVDA Rubin AVL via 電源大廠）+ 16 週交期 + 訂單能見度 6 個月以上
  - 母公司 [[華新科]] 集團背書 + 馬來西亞地緣分散（透過 [[華新科]]）
- 風險：
  - **嵌入式 MLCC 滲透高壓時程未定**（村田 1.25kV C0G 1210 = 物理條件已具備）
  - 母公司 [[華新科]] 可能優先內供瓷粉 / 減少外售（內部交易調度風險）
  - 規模小（市值 370 億）= R&D 投入有限、難跟上日系高階迭代
  - 銀 / 鈀 / 鈦酸鋇粉原物料價格波動
  - PE 57 倍 vs 同業 119 倍**看似便宜**、但 EPS 預估僅 3.1 元（券商）= **體質 + 估值錯位**
  - 上櫃股流動性弱於上市股、散戶比例高、短線波動劇烈

### ✅ 催化

- **NVDA Rubin 1MW 機櫃 2027 量產**（MLCC 用量 3-4K → 10K+ = **2.5-3x BOM 倍增**）
- HVDC 800V 數據中心架構滲透（PSU 110kW 化）
- 中高壓 MLCC 漲價週期（[[村田 Murata]] +15-35%、4 月起）+ 信昌電交期 16 週 → 漲價跟漲

- 人形機器人 + 低軌衛星新興應用 2027 開始放量
- 集團內 [[華新科]] 大中華供應鏈聯合作戰

### ⚠️ 風險

- **中高壓嵌入式 MLCC 商業化時程未定**（村田 1.25kV C0G 1210 已量產 = 物理條件具備、**2029+ 風險逼近**）

- 母公司 [[華新科]] 瓷粉內供調度（集團內部交易減少外售）
- 規模僅 370 億 → R&D 跟不上日系迭代
- 銀 / 鈀 / 鈦酸鋇粉 / 鎳原物料漲價未必 100% 轉嫁
- 中國風華 / 三環中高壓**國產替代**正在追趕（但目前 1206-1812 大尺寸落後）
- NVDA Rubin 機櫃**用量 10K+ 數字僅來自公司法說 1 個來源**（未交叉驗證外資 / 賣方研報）
- 上櫃股、散戶持股高 → 短線波動劇烈、被處置股機率高
- 中美關稅 + 出口管制曝險（台灣 + 馬來西亞）

## ⭐ pair trade 提案：多信昌電 / 空華新科

**論點**：信昌電 + [[華新科]] **同集團、同 MLCC 漲價週期、同 AI 機櫃曝險**，但**體質 + 估值 + 嵌入式曝險全面領先**。

|---|---|---|---|
| 毛利率 | **28.4%** | 18.3% | 信昌電 **+10.1pp** |
| EPS YoY（2026 Q1）| **+70%** | +40-69.7% | 信昌電 |
| PE | **57 倍** | 81 倍 | 信昌電（**折價 30%**）|

| AI 利基 | **中高壓 niche pure-play** | 中階通用 + 中高壓研發中 | 信昌電（規格深度勝）|
| 護城河 | **介電粉末自製 + Mega Cap + NP0** | 馬來西亞地緣分散 + 規模 | 信昌電（IP 護城河深）|
| Re-rate 三角形 | **3/4** | 2/4 | 信昌電 |

### Pair Trade 可行性分析

**👍 合理性**：
1. **體質 / 估值 / niche / 嵌入式曝險四軸全勝**信昌電
2. PE 折價 30% + 毛利率 +10pp = **基本面套利**機會明確
3. 同 AI 機櫃曝險 → MLCC 漲價 / Rubin 延宕 等系統性風險可對沖

**👎 風險**：
1. **同集團風險**：[[華新科]] 43.13% 持有信昌電——[[華新科]] 跌信昌電也會被拖累（β 高度同步）
2. **流動性不對稱**：信昌電上櫃 + 市值 370 億 + 處置股風險 → 多單放量困難 / 空單借券難
3. **內部交易調度**：母公司可調瓷粉內供、影響信昌電外售收入 → pair 邏輯被破壞
4. **規模差距**：370 億 vs 2,052 億 = 5.5x、空 [[華新科]] 等量比例的多信昌電籌碼會擠壓上櫃股流動性
5. **散戶持股高**：兩家短線波動同步、pair spread 反向擴大風險

### 結論

> **方向上合理、但執行上有限制**：
> 1. 純基本面 / 估值 / Re-rate 套利 → **信昌電是更好的多單**（不需要對沖、單押也勝）
> 2. 真要做 pair trade → **多信昌電 / 空 [[華新科]] 比例 1:2-3**（補償流動性差距）+ **嚴格控倉**（兩家同跌風險高）
> 3. 替代方案：**多信昌電 / 空中國風華（公開市場可借券）** = 跨地緣 + 跨體質 pair、避開同集團風險

→ **建議**：信昌電可獨立做多倉、不需 pair；如要對沖系統性風險，**空中國 MLCC / 空 [[南電]] / 空通用 MLCC ETF** 比空 [[華新科]] 更乾淨。
