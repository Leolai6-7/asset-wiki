# Innolight（中際旭創 300308.SZ）

## 1. 一句話定位

**中國光模組 #1 + 全球 transceiver 市佔 30%+ + 1.6T 量產領先（2026 H1 ramp）+ NVDA Blackwell/Rubin 800G/1.6T 主供 + LightCounting #1 連續 5 年**——OEM 模組廠（vs [[Lumentum]] / [[Coherent]] / [[AAOI]] vertical integration）的全球規模龍頭、[[CPO 供應鏈圖譜]] 第 5 層光模組組裝 + 跨 hyperscaler 供應 + [[Bottleneck Theory（瓶頸論）]] 第 5 層 Beneficiary（非 chokepoint、可被替代但規模 + 客戶 lock-in 強）、[[AI infra CapEx 三階段論]] 第三階段 1.6T 光模組量爆增**首批 30 倍跳升**最大受惠者。

## 2. 三層 thesis

### 產業層

- [[AI infra 散熱戰場]] 進入 [[市場四階段：懷疑／驗證／共識／反轉]] **共識階段**、Innolight 是「光通訊賽道從共識到反轉前」的全球規模王
- 1.6T 光模組 2025 ~180 萬顆 → **2026 3,000 萬顆+（NVDA 占比 60%+）**= **十幾倍跳升**（見 [[AI infra CapEx 三階段論]] 訊號 1）
- 跟 [[賣水人選股邏輯（投資版）]] 連結：OEM 模組賣水人（不像 [[AAOI]] / [[Lumentum]] / [[Coherent]] vertical integration 高純度、但**規模 + 客戶分散勝**）
- 跟 [[Hyper Rail / Multi-Rail（光通訊整合技術）]]：1.6T 模組 17 倍增量結構性放大 = Innolight 主受惠者
- 跟 [[CPO 供應鏈圖譜]] 第 5 層：光模組組裝同層 [[Lumentum]] / [[Coherent]] / [[AAOI]] / Eoptolink（新易盛 300502）
- 在 [[資訊擴散四階段]]：已 ETF 化（中國 A 股、12M +500-800% 漲幅、外資配置滿了）

### 目的層

- **業務組合**（FY2025 預估）：
  - **光模組（transceiver）**：~85-90%（**主力業務**）—— 100G / 200G / 400G / 800G / **1.6T 全線**
  - **光器件**（光晶片組件、ELS）：~10-15%（**部分 vertical integration**）
- **光模組細拆**（按速率）：
  - **800G**：[[NVDA]] / [[Google]] / [[Microsoft]] / [[Meta]] / [[AMZN]] 全 hyperscaler 供應、市佔 25-30%
  - **1.6T**：**2026 H1 量產領先**（vs [[AAOI]] 2026-03 / [[Coherent]] 2026 H2）、目標市佔 30%+
  - **400G / 200G / 100G**：傳統 base、穩定貢獻
- **AI server 客戶結構**：
  - **NVDA**：Blackwell + Rubin 800G/1.6T 主供（具體比例未揭露、推估 25-35%）
  - **Google**：TPU + Spectrum-X + Hyper Rail 配套（傳統大客戶）
  - **Microsoft / AWS / Meta / Oracle**：4 大 CSP 直供
  - **CoreWeave / Lambda**：NVDA 直接生態 ramp 中
  - 客戶集中度比 [[AAOI]] / [[Coherent]] / [[Ciena]] 分散得多
- **產能 + 擴張**：
  - 蘇州 + 銅陵 + Hubei 三廠擴產
  - **Thailand 海外廠**（規避中美貿易戰 + 對美出口、2025 ramp）
  - 1.6T 量產 line 2026 H1 開出
- 商業模式核心：
  - **「**中國光模組 #1 + 全球 transceiver 規模王 + 客戶最分散 + 1.6T 量產領先**」**：規模 + 認證 + 客戶分散三軸都勝過 vertical integration 對手
  - **OEM 模組廠模式**：採購 [[Lumentum]] / [[Coherent]] / [[IQE]] EML / pump laser → 組裝 + 測試 + 客製化
  - **部分 vertical integration**：自研光器件 + 部分光晶片組件 + 包裝 + 測試
  - **「**中國本土 light asset 但有 Thailand 海外廠 hedge**」**：規避美國 ITAR / Section 301 限制
- 對應 [[賣水人選股邏輯（投資版）]]：**規模型 OEM 模組賣水人**——不押 NVDA / Google / Meta / Microsoft 誰贏、押**所有 hyperscaler 光模組都要用**
- 對應 [[控制點轉移（投資版）]]：**沒有強控制權**（OEM 模組廠定位、競爭格局分散、被 [[Lumentum]] / [[Coherent]] / [[IQE]] InP 上游 chokepoint 壓制）——但**規模 + 客戶分散**提供下檔保護

### 供應層

- 跟 [[Bottleneck Theory（瓶頸論）]] / Serenity 框架：
  - **第 5 層 Beneficiary**（非 chokepoint）——「跟著賽道漲、可替代、有競爭」
  - 跟 [[AAOI]] vertical integration 不同：Innolight 採購 EML / pump laser → OEM 組裝
  - 跟 Eoptolink（新易盛 300502）並列「中國 OEM 雙頭」
  - vs [[Lumentum]] / [[Coherent]] vertical integration EML 自製 = **不同層級**
- 跟 [[Lumentum]] 關係（**上游 + 部分對手**）：
  - **採購 LITE EML / pump laser → OEM 組裝**（依賴 LITE 上游）
  - 同時跟 LITE transceiver 業務直接對打（LITE 自做模組）
  - LITE 2026 H1 EML 供應 >30% 缺口（[[AI infra CapEx 三階段論]] 訊號 2）= **Innolight 量產取得直接受影響**
  - → **Innolight 是 LITE 客戶 + 對手雙重關係**
- 跟 [[Coherent]] 關係：
  - **採購 COHR EML → OEM 組裝**（依賴 COHR 上游）
  - COHR FY2025 transceiver $5.81B / 25% 市佔 vs Innolight 30%+ 市佔
  - **Innolight 規模 > COHR transceiver 業務**、但 COHR vertical integration EML 自製 + SiC 第二曲線多元
  - → 跟 LITE 同樣是「客戶 + 對手」
- 跟 [[AAOI]] 對比（OEM vs vertical integration）：
  - **AAOI vertical integration**（in-house DFB / EML laser chip + 模組）= **chokepoint 深度勝**
  - **Innolight OEM 模組廠**（採購 EML + 組裝）= **規模 + 客戶分散勝**
  - AAOI 2026-03 1.6T LPO 北美本土量產、Innolight 2026 H1 全球量產
  - **AAOI Microsoft ROFR + 純度高、Innolight 全 hyperscaler 直供 + 規模碾壓**
- 跟 Eoptolink（新易盛 300502）對比：
  - **中國 OEM 雙頭**（Innolight + Eoptolink）
  - Innolight 規模略大（~6x 營收）+ 客戶 NVDA 直接綁定
  - Eoptolink 800G 跟進 + 跟 Google 客戶綁定強
  - → **共同壓制中國 OEM 第三梯隊**
- 跟 [[NVDA]] 路線：
  - **NVDA Blackwell / Rubin 800G / 1.6T 主供**（具體比例未揭露、推估 25-35%）
  - NVDA 2026-03 投資 [[Lumentum]] $2B + [[Coherent]] $2B 後 = NVDA 直接綁 EML 上游、Innolight 透過 LITE/COHR 拿到 EML
  - 跟 NVDA Spectrum-X / Quantum-X 配套（光通訊配置 transceiver 一定要用）
- 跟 [[Ciena]] / [[Nokia]] 關係（DCI 廠商）：
  - Ciena / Nokia 做 DCI 系統、需要 1.6T transceiver
  - Innolight 透過 Ciena / Nokia 配套出貨
  - 跟 [[Lumentum]] / [[Coherent]] 同樣是 Ciena / Nokia 供應商
- 跟 [[POET Technologies]] 關係：
  - POET 跟 Mitsubishi Electric 合作 1.6T Teralight = 跟 Innolight 1.6T 部分競爭
  - 但 POET 量產規模遠落後 Innolight
- 跟 [[IQE]] / [[AXTI]] / [[信越化學]]（InP 上游 chokepoint）關係：
  - Innolight 是 InP 整鏈下游間接受惠者
  - InP 供應緊繃 → EML 缺貨 → Innolight 量產取得受限（中期風險）
- 護城河：
  - **中國光模組 #1 + 全球 transceiver 30%+ 市佔**
  - **1.6T 量產領先**（2026 H1）
  - **客戶最分散**（NVDA + 4 大 CSP + Ciena + Nokia + ODM）
  - **Thailand 海外廠**（規避美國 ITAR / Section 301）
  - **規模碾壓 vertical integration 對手**（AAOI / LITE transceiver 業務 / COHR）
  - **LightCounting #1 連續 5 年**（行業地位確認）
- 風險：
  - **OEM 模組廠定位 = 沒強控制權**（被 LITE / COHR / IQE 上游 chokepoint 壓制）
  - **美國 ITAR / Section 301 出口管制升級風險**（Thailand 廠 hedge 但不完全）
  - **NVDA 直接綁 LITE / COHR EML = 中期可能繞過 OEM 中間商**
  - **CPO 取代 plug-in optic 風險**（2027-2028 hyperscaler 全面 CPO 化 → transceiver 業務萎縮）
  - **AAOI 北美本土 anchor 在 NVDA / Microsoft 拿走部分高端市場份額**
  - **中國 A 股流動性 + 外資配置已滿**（估值 stretched、Forward PE 30-50x）
  - **Innolight 不是 chokepoint = 中長期 displacement 風險**

| 軸 | 分數 | 理由 |
