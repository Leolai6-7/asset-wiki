# 宋分 #02 — 如果我今天從零開始學投資，我不會先看盤

[[宋分（美股送分題）]]（2026-02-15）。**多數散戶學投資的順序是錯的**。

## 一句話

> 用市場的思維去對抗市場，注定會輸。多數人不是因為判斷錯誤而賠錢，是因為學習順序錯誤。

## 散戶錯誤路徑

```
看盤 → 學技術分析 → 跟單 → 用市場波動做決策 → 追漲殺跌
```

**問題**：用市場自己的邏輯跟市場對賭——市場的短期走勢設計就是要讓多數人做錯。

## 機構正確順序

```
1. 理解公司   (做什麼？怎麼賺錢？護城河？)
2. 理解產業   (趨勢？競爭？公司位置？)
3. 理解現金流 (結構？可持續？成長空間？)
4. 最後才看價格 (是否合理？)
```

## 應該先學的三件事

| | 內容 | 為什麼 |
|---|---|---|
| **會計/財報** | 三大報表 | 所有投資分析的基礎語言 |
| **產業分析** | 護城河、生命週期、技術變革 | 判斷哪個賽道值得 |
| **心理學** | 行為偏差、群體行為、決策流程 | 不是預測市場，是管理自己 |

## 零基礎時間表

- 前三個月：學會計，能讀懂一份 10-K → 連 [[10-K 閱讀法（分析師底層 #1）]]
- 三到六個月：深入研究一個產業
- 六到九個月：小額實踐，記錄每筆交易理由
- 之後：持續學習、反思、累積
