# 宋分 #14 — 現在該出手抄底了嗎？怎麼看「相對低點」？

[[宋分（美股送分題）]]（2026-03-27）。**你不需要抓到絕對底部。重點是辨識相對低點 vs 陷阱低點**。

## 一句話

> 目標是在「相對低點」分批建倉，而非在「絕對底部」一次買入。

## 機構觀察三訊號

### 1. 壞消息出來但不再繼續跌
- 對利空消息的反應越來越鈍 = 賣壓耗盡
- **「壞消息 + 不跌 = 賣方出盡」**

### 2. 強勢股撐住
- 部分股票在大盤下跌中持續相對強勢
- 背後通常有機構在逆勢買入
- → [[抗跌清單]]

### 3. 市場出現分化
- 早期下跌「無差別拋售」
- 後期出現分化（好公司與壞公司脫鉤）
- = 市場從「恐慌模式」轉向「**選擇模式**」

## 相對低點 vs 陷阱低點

| 相對低點 | 陷阱低點 |
|---|---|
| 三訊號中至少出現兩個 | 反彈成交量不足 |
| 成交量逐漸萎縮 | 每次反彈高點越來越低 |
| 技術面正背離 | 信用利差仍擴大 |
| 信用利差趨穩 | 領導股繼續破底 |

## 分批買入策略

```
第一批：第一個止跌訊號出現 → 20-30% 倉位
第二批：第二個訊號確認 → 加碼到一半
第三批：分化明確、反彈趨勢確立 → 完成建倉
```

## 五個「不該出手」訊號

1. **過度樂觀**（剛反彈就喊「底部已確認」）
2. **情緒面太嘈雜**（多空雙方喊話、VIX 在高位震盪）
3. **基本面沒改變但超跌**
4. **資金流向不明確**
5. **技術指標混亂**

- 「強勢股撐住」 → [[抗跌清單]]

- 「分化 = 選擇模式」 → [[被動賣壓 vs 主動買盤]] 機構買入第二階段
