# FOMO SOC KP #45 — AI PC 時代到來 + 多家 Mega Cap 一週動態

**作者**：KP@FOMOSoc（2026-06-06 發布、KP 思考筆記第 45 期）
**性質**：五大主題（升息 / Windows+CUDA / Intel CPU / Alphabet 史上最大融資 / Microsoft Build / NVDA 記憶體配置）、混合付費鎖

## 一句話

> AI PC 時代 = 「**協同設計**」結構性轉變、NVIDIA RTX Spark + CUDA 把消費 PC 變特洛伊木馬、Intel Xeon 戰略反擊 orchestration layer、Alphabet $84.75B 史上最大融資破紀錄、Microsoft Build 2026 棄爭模型皇冠定位「**最優秀的協調者**」、NVDA Vera Rubin NVL72 LPDDR5X 配置砍半揭示**三層記憶體架構**（HBM4 / LPDDR5X / NAND）。

## 中心命題

> 「**NVIDIA 變成了所有租客都必須打交道的水電公司**」

> 「**最關鍵的不是你用的基礎模型有多聰明、而是你能不能把公司的隱性知識、專屬資料與工作流程持續地餵給模型**」（Microsoft Build 2026）

## 主題 5：NVDA Vera Rubin NVL72 三層記憶體架構 ⭐

### LPDDR5X 配置砍半（戰術決策）
- 不是 HBM4、是 LPDDR5X **-50%**
- 優先**快速量產 vs 規格極致**
- 單櫃 TCO 降 USD $800k

### 三層記憶體架構
| Tier | 角色 | 元件 | 受惠者 |
|---|---|---|---|
| **Hot** | GPU on-package | **HBM4** | Samsung / [[SK Hynix]] / [[Micron]] |
| **Warm** | CPU side | **LPDDR5X** | 同上 |
| **Cold** | Storage | **SSD（NAND）** | 同上 + WD / Solidigm |

→ **Samsung + SK Hynix + Micron 三家全棧受惠**
