# 宋分備忘錄 #8 — 市場創新高，卻是初期牛市的典型結構

[[宋分（美股送分題）]] 2026-04-27 備忘錄。**核心命題**：**創新高 ≠ 過熱**。**邊漲邊懷疑** = 初期牛市常見現象。

## 一、經濟動能轉變（兩種週期）

| | 過去 | 現在 |
|---|---|---|
| 動能來源 | 政府政策（QE / 補貼） | **企業自發投資 + 生產力** |
| 週期類型 | 金融週期（央行驅動） | **實體 CapEx 週期** |
| 持續性 | 短（隨利率轉向） | **長（沒人敢停止投資）** |

> **實體 CapEx 週期 > 金融週期**——更持久。

## 二、實體投資週期啟動

企業被**競爭壓力「迫使」投資 AI 與自動化**：
- 不投資 → 被淘汰
- 投資 → 帶動需求
- **自我強化的正循環**

## 三、獲利結構改善

EPS 成長來自兩條腿：
1. 營收加速（top-line）
2. 成本控制

兩者並行 = **正向營運槓桿** 的結構性改善（對應 [[宋分 #23 — 分析師底層系統 #2（營業槓桿）]]）。

## 四、市場情緒「健康」的特徵

| 訊號 | 含義 |
|---|---|
| 創新高 | 不必然過熱 |
| 仍存懷疑聲浪 | **共識未過度擁擠** |
| 邊漲邊懷疑 | 初期牛市典型 |

過熱訊號應該是「沒人懷疑、所有人都看好」——**現在不是**。

## 五、資金重配（關鍵）

```
擁擠 → 變淡:  記憶體、光通訊
受寵 → 放大:  CPU 復興、核心算力 anchor（NVDA 等）
```

對應 [[宋分備忘錄 #2 — HBM iPhone Moment-Meta-軟體 PE]] 提到的「**核心 / 衛星**」配置升級。

## 六、財報驗證三件事（市場等什麼）

| 證據 | 含義 |
|---|---|
| 營收變動率加速 | top-line 動能 |
| 訂單積壓增長 | backlog 可見性 |
| AI 收入明確量化 | first proof |

這三件事出現 → 初期牛市 **正式進入中期**。

## 關鍵金句

> 「**當市場邊漲邊懷疑，通常才剛開始**。」

> 「過去靠政策、現在靠企業自發。」
