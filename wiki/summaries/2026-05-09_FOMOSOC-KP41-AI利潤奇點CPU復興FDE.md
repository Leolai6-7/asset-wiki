# FOMO SOC KP41 — AI 利潤奇點 + CPU 復興 + Forward Deployed Engineer 戰略

**作者**：KP@FOMOSoc
**發布**：2026-05-09
**來源**：[FOMO SOC 思考筆記第 41 期](https://www.fomosoc.com/p/aicpuanthropic-oaiai-kp41)
**性質**：全文公開、無付費牆

## 重點

> 三大論點疊加：
> 1. **AI 利潤奇點**：Token 售價年降 40%（趨緩）vs 成本年降 60-70%（仍快）→ **2026 起出現毛利率拐點**
> 2. **CPU 復興**：AMD / ARM / Intel 三家財報共同驗證 AI 驅動 CPU 結構性供不應求
> 3. **FDE 戰略**：OpenAI / Anthropic 複製 Palantir 10 年驗證的「Forward Deployed Engineer」模式、直接解決企業「試點煉獄」

## 五大主題深度整理

### 1. Token 經濟學拐點（高盛框架）

| 指標 | 數字 |
|---|---|
| Token 售價年降 | 40%（**趨緩**）|
| Token 成本年降 | 60-70%（仍快）|
| Token 用量 2030 倍數 | **2026 年的 25 倍**（+2,400%）|
| 日查詢數 2025→2030 | 50 億 → **230 億**次 |
| Agent 查詢佔比 2030 | 30% |
| 企業端成長倍數 2030 | **24 倍** |
| 企業端成長倍數 2040 | **55 倍**（巔峰）|

→ **自我強化飛輪**：成本下降 → Agent 加強 → 利用率上升 → 利潤上升 → 投資優化 → 成本下降 (loop)

### 2. 企業 AI ROI 量化

| 應用 | 日均成本 | 對標人力日薪 | ROI |
|---|---|---|---|
| **程式開發 Agent** | $13.39 | ~$300 | ✓ 極佳 |
| 資料輸入 Agent | $59.68 | ~$80 | ✓ 可行 |
| 客服 Agent | $92.90 | ~$90 | ✗ 略高 |

**核心洞察**：「AI 的終極價值不是 1:1 替代勞動力來省錢、而是透過釋放『**未滿足需求**』來把餅做大」

### 3. 採用曲線（S 型而非 J 型）

| 階段 | 內容 |
|---|---|
| 初期 | 企業需時清理數據、建立數據治理、確認 ROI |
| 中期（2030 前後）| 競爭 FOMO 推動加速採用 |
| 頂部 | **35-40% 滲透率**（非 100%）|

**現況**：70-90% 企業在做 POC、不到 25% 規模化部署。

### 4. CPU 三家財報

| 公司 | 關鍵數字 |
|---|---|
| **AMD** | 資料中心 YoY +57%、伺服器 CPU 連 4 季創紀錄、2030 市場 $600 億 → **$1,200 億**（翻倍、CAGR 35%）、Q2 指引 +70%+ |
| **ARM** | Q4 YoY +20%（創紀錄）、資料中心版稅 YoY +100%+、AGI CPU $20 億→ **$150 億**（2031）、CPU 容量需求 **4 倍** |
| **Intel** | Xeon 需求超前供給、贏得 **NVIDIA DGX 系統主 CPU 位置**、雙位數延續至 2027 |

### 5. FDE 戰略（OpenAI / Anthropic 學 Palantir）

| 公司 | 動作 |
|---|---|
| **OpenAI** | 「The Deployment Company」合資企業（估值 **$100 億**、背後私募基金控制數千投資組合公司）|
| **Anthropic + Accenture** | 多年合約、訓練 **3 萬員工**使用 Claude |
| **Anthropic + Blackstone / Goldman / Hellman** | 成立 **$15 億**公司專攻中型企業 |

→ FDE = 派駐**資深工程師至客戶現場**、親自代碼實現端對端部署，解決「**髒活**」（系統整合、安全、合規）。

## 跟 wiki 概念的深度連結

### ⭐ 新概念落地：**[[AI 利潤奇點（Token 經濟學拐點）]]** ⭐
- KP 引高盛 framework：Token 售價/成本剪刀差驅動的「毛利率拐點」
- 這是 [[AI 通縮三路徑]] / [[Jevons Paradox（投資版）]] 的**「利潤端」量化版**
- 對應 2026 起的 inflection point

### ⭐ 新概念落地：**[[Forward Deployed Engineer 戰略（FDE）]]** ⭐
- AI 公司從「賣 API」升級為「賣 deployment + service」
- 對應 [[控制點轉移（投資版）]]：控制點從 platform 轉向 vertical solution
- 對應 [[資訊擴散四階段]] 第 3-4 階段（從機構轉企業實裝）的關鍵 enabler
- 直接挑戰 [[Palantir]] 企業 IT 預算（待建 entity）

### 強化 [[Jevons Paradox（投資版）]]
- Token 用量 25x + 採用 35-40% 巔峰 = 兩變數抵消後 TAM 倍數爆炸
- 是 Jevons 在 AI Token 經濟最強驗證

### 強化 [[賣水人選股邏輯（投資版）]]
- 高盛四軸 = 賣水人新分類：
  1. 成本壓制者（半導體）= 算力供應鏈賣水人
  2. 規模與分發（雲端）= 平台層賣水人
  3. **軟體商業模式升級** = Cloudflare / Accenture / Microsoft「TAM 擴張型」賣水人 ⭐ 新軸
  4. 採用加速者 = IT 服務 / FDE 模式

### 強化 [[CapEx 見頂辯論]]
- CPU 三家「供不應求」訊號 = CapEx 仍向上、見頂訊號未到

### 對接 [[控制點轉移（投資版）]]
- **軟體商業模式「人頭 → 工作量」**：訂閱費跟產出綁定、控制點從 SaaS 廠商轉向白領薪資池
- **FDE 戰略**：AI 公司從 platform → vertical solution

### 對接 [[效率→安全切換]]
- FDE 直接解決企業「安全、合規」門檻 → 效率→安全切換在 AI 應用層的具體實踐
