# 宋分 #32 — 為什麼左側價值投資人總是賺不到右側？

[[宋分（美股送分題）]]（2026-06-06）。**價值投資反思系列**。承接 #33（安全邊際被誤解）+ #30（連續上修）+ 備忘錄 #6（市場世界觀切換）。

## 核心命題

> 左側交易：「**價格錯了**」、等待回歸內在價值。
> 右側交易：「**價值變了**」、不斷驗證證據增加部位。
> **AI 行情下、左側框架失效。**

## 左 vs 右核心對照

| | 左側 | 右側 |
|---|---|---|
| **假設** | 價格錯了 | 價值變了 |
| **操作** | 越跌越買 | 越漲越驗證 |
| **安全感來源** | 低價 | 證據累積 |
| **心理錨點** | 內在價值 | 邊際變化 |
| **適合行情** | 週期股、深度價值 | 時代級趨勢、re-rate |

## AI 時代為什麼左側失效

> AI 行情下、市場**不斷重新計算價值**（100 → 200 → 300）。
> 「上漲」不是「泡沫」、是「**驗證後上修**」。

### 左側盲點

- 用過時的內在價值錨定
- 把每次上修當泡沫
- 不願承認「我看錯了」

### 價值投資的雙面性

> **擅長避開泡沫、卻不一定擅長參與新科技革命**——因為革命剛開始時通常都很貴。

| 案例 | 左側結果 |
|---|---|
| 2000 .com | 避過血洗 ✓ |
| 2008 金融海嘯 | 避過血洗 ✓ |
| 2014-2024 美股 | 錯過 ✗ |
| 2024-2026 AI | 錯過 ✗ |

## 右側機構套路（試單驗證確認）

```
試單 (5-10%) → 驗證 → 確認 → 趨勢延續
       季度檢視  加到核心     主升段持有
```

| 階段 | 部位 | 目的 |
|---|---|---|
| 試單 | 5-10% | 開始追蹤、不錯過 |
| 驗證 | 季度 thesis 確認 | 證據累積 |
| 確認 | 核心比例（20-30%） | 主升段持有 |
| 趨勢延續 | 持續 + trim 點 | 把握主升段 |

→ 在「**不確定**」中參與、用部位管理對沖風險。

## 心理難題：「沒有答案的時候做決定」

### 兩種安全感的差異

| | 左側 | 右側 |
|---|---|---|
| 安全感來源 | 低價、犯錯空間 | 證據累積、驗證 |
| 接受的痛 | 帳面虧損但便宜 | 高位震盪但有 confirmation |
| 風險 | 時代轉換期、價值回不來 | 證據反轉、賣得不夠快 |

> 兩者都無對錯、**關鍵在於理解自己在交易什麼**。

## 核心金句

> 擅長避開泡沫、卻不一定擅長參與新科技革命——因為革命剛開始時通常都很貴。

> 在沒有答案的時候做決定 = 投資的核心難題。

> 左側從低價獲得安全感、右側從證據累積獲得安全感。
