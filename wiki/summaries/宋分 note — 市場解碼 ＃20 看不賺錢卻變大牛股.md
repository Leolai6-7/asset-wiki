# 宋分 note — 市場解碼 #20：為什麼「看不賺錢」的公司最容易誕生大牛股

[[宋分（美股送分題）]] 2026-04-29 substack note。**核心命題**：「會計上的『利潤』不等於企業真正的價值創造能力。」很多被低估的成長股，是因為**策略投資被當作費用而非資產**。

## Framework：費用化的策略投資 ≠ 真正燒錢

| 案例 | 性質 | 結果 |
|---|---|---|
| Amazon 物流網 / Prime / 早期 AWS | 費用化但建護城河 | 後來爆發 |
| Netflix 內容庫 | 費用化但建用戶資產 | 訂閱複利 |
| Microsoft license → subscription | 短期表現變差 | 長期估值大爆發 |
| **WeWork** | **真燒錢** | **失敗** |

差別在於：**支出是否創造防禦性**？

## 三條評估準則（不要盲目追高費用公司）

| 準則 | 問什麼 |
|---|---|
| 1. 防禦性 | 支出是否創造 moat / lock-in？ |
| 2. 現金流可預測性 | 投資後現金流會不會更穩？ |
| 3. 規模效率 | 投資能不能複利擴張？ |

**三個都符合 → 「被偽裝成費用的資產」**。

## 6 題 checklist（文末）

1. 這筆支出是一次性還是持續性？
2. 是否提升 customer LTV / retention？
3. 是否建立難以複製的競爭優勢？
4. 規模化後 unit economics 會不會改善？
5. 管理層解釋邏輯是否清晰？
6. 同業是否做不到 / 做不起？

## 投資啟示

**Forward PE 看起來貴 ≠ 真的貴**——若大部分「貴」來自「**費用化的策略投資**」，那是估值幻象。

之後做 PE 估值要做「**策略投資調整**」後的版本才準。
