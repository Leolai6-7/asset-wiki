# 宋分 #05 — 散戶要如何像機構一樣買在起漲點？

[[宋分（美股送分題）]]（2026-03-07）。**機構和散戶買在不同的價位，是因為他們在不同的「資訊擴散階段」做決策**。

→ 完整概念 [[資訊擴散四階段]]

## 一句話

> 資訊擴散到你手上的時候，通常已經是第二或第三階段。

## 資訊擴散四階段

1. **機構研究** → 股價幾乎沒反應
2. **賣方升級** → 機構客戶建倉，股價開始上漲
3. **媒體/社群擴散** → 散戶首次聽到，股價已大幅上漲
4. **ETF 被動買入** → 最後一波買盤，最貴

## NVDA 案例（2023-2026）

| 階段 | 時期 |
|---|---|
| 1 機構研究 | 2023 初 |
| 2 賣方升級 | 2023-2024 |
| 3 媒體擴散 | 2024-2025 |
| 4 被動 / 反轉 | 2025-2026 |

## ⭐ 下一個「第一階段」候選

宋分點名**三個方向**——**這是 asset-wiki 應該優先追蹤的線索**：

| 方向 | 邏輯 |
|---|---|
| **能源** | AI 資料中心電力需求爆發 |
| **電力基礎設施** | 電網、變壓器、配電；訂單能見度 2028-2030 |
| **光通訊** | AI 資料中心高速互連；早期進入者顯著優勢 |

## 機構判斷階段的三訊號

1. 分析師預期修正的方向（上修速度加速 / 減速？）
2. 管理層指引的品質（積極 → 保守？）
3. **邊際買家的身份**（機構 / 散戶 / 被動基金？）
