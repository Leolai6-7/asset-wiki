# 宋分 #33 — 你以為的「安全邊際」，可能只是讓你錯過牛市的理由

[[宋分（美股送分題）]]（2026-05-23）。**價值投資反思系列**。承接 #21（反彈該不該上車）+ #11（停損看錯）+ #14（相對低點判斷）。

## 核心命題

> 安全邊際 ≠ 低 PE、≠ 便宜股票。
> 安全邊際 = **犯錯空間**——理解力 + 部位管理 + 判斷波動 vs 基本面改變的能力。

## 三組顛覆性對比

| 表面誤解 | 真實機制 |
|---|---|
| 低 PE = 安全 | 低 PE 通常基本面在衰退、不安全 |
| 高 PE = 危險 | 高 PE 可能是基本面持續改善的正確定價、更安全 |
| 破線就停損 = 紀律 | 紀律 = **基本面改變時停損**、不是機械式 |
| 全保守 = 安全 | 全保守錯過牛市、不算安全 |
| 機構有內線 = 優勢 | 機構優勢在**部位管理 + 風險調整** |

## 安全邊際的真實定義

### 三層構成

1. **理解力**：知道為什麼漲 / 跌 / 該不該守
2. **部位管理**：分批 + 季度檢視 + trim 紀律
3. **判斷力**：波動 vs 基本面改變 的辨識

→ 安全 = **犯錯空間** + 還能存活。

## 紀律的反差

> 紀律是基本面改變時停損、**不是機械式破線就出場**。

機械停損的問題：
- 把「短期波動」當「基本面變化」處理
- 容易賣在最低點、追在最高點

真正紀律：
- 每天問「我買的原因還在嗎？」
- 基本面變化 → 立刻 trim / 出場
- 純波動 → 守住

## 成熟配置 = 核心 + 進攻

| 倉位 | 比例 | 屬性 |
|---|---|---|
| **核心穩定** | 60-70% | 穩定現金流公司、長期持有 |
| **進攻** | 30-40% | 高 beta 標的、抓 alpha |

→ 動態調整、市場階段 + 個人風險承受 都會影響比例。

## 機構優勢的真實來源

| 散戶誤解 | 真實情況 |
|---|---|
| 內線消息 | 內線是非法、不可持續 |
| 更好情報 | 第一手資料散戶也能拿到 |
| **真正優勢** | **部位管理 + 風險調整 + 不 all-in 紀律** |

## 長期成功者的特徵

1. 懂自己能承受多少風險
2. 知道何時進攻何時防守
3. 經歷週期後**還能存活**

> 投資是**存活遊戲**、不是預測遊戲。
