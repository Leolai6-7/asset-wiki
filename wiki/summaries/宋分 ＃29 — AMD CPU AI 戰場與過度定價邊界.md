# 宋分 #29 — AMD：CPU 是 AI 下一個戰場，但市場是不是已經把終局價格提前買完了？

[[宋分（美股送分題）]]（2026-05-05）。**重估邊界判斷教學**。承接 #13（類比晶片結構性重估）+ 備忘錄 #3（AI 半導體受惠者擴散）。

## 核心命題

> CPU 在 AI 確實重要、AMD 重估合理；但**判斷邊界**才是分析師真正的工作。
> 20-30 倍 PE 合理 → 30-40 倍開始 stretched → 40-50 倍進入過度定價。

## 資金流向擴散三階段

```
GPU (NVDA/AMD) → 記憶體 (HBM) → CPU (AMD/Intel)
```

→ AI 投資鏈條依序傳導、CPU 是第三階段。

## 結構性重估三要素（缺一不可）

| 要素 | AMD 案例 |
|---|---|
| **定價權出現** | EPYC 30%+ server 市佔、可漲價不折讓 |
| **CPU/GPU 成本比例改變** | 過去 1:8 → AI server 1:2（高階 CPU 拉貴） |
| **TAM 暴增** | 825-1,100 億 → 3-4.5 兆（30x） |

→ 三件事同時改變才叫「結構性重估」。

## 估值區間校準

| PE 區間 | 狀態 | 行動 |
|---|---|---|
| 20-30x | 合理重估 | 加碼 |
| 30-40x | 預期完美執行 | 守、不加 |
| 40-50x | 終局定價、不容失誤 | trim |

→ 27x 對應 70-80% 成長率（合理）。

## AMD 財務 anchor

- 2026 EPS：6+
- 2027 EPS：11-13
- 資料中心營收比重：37% → 52%
- 營益率排序：Embedded > Data Center > Client

## 過熱警訊三條件（同時出現 = 過度定價）

1. 成長率停滯但 PE 持續拉高
2. 敘事極端化（「受益」→「一統江湖」）
3. 市場不容許失誤（任何 miss 都暴跌）

## 核心金句

> 最難的不是看對趨勢，是判斷市場何時從「未充分定價」轉向「過度定價」的轉折點。

> 分析師工作不是抓底、是判斷邊界。
