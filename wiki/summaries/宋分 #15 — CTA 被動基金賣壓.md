# 宋分 #15 — CTA/被動基金賣壓要到什麼時候？

[[宋分（美股送分題）]]（2026-03-28）。**賣壓不是一種力量，是多種機制的疊加**。

→ 完整概念 [[被動賣壓 vs 主動買盤]]

## 一句話

> 理解被動賣壓的來源和節奏，是判斷市場何時止跌的關鍵。

## 內部人賣出（不算被動）

| 機制 | 易誤讀 |
|---|---|
| **10b5-1 計劃** | 預設自動執行，常被誤讀為「內部人看空」 |
| **禁售期** | 財報前後限制；結束後可能集中賣出 |
| **揭露要求** | Form 4 / 13F = 追蹤機構的工具 |

## 被動賣壓四來源

1. **ETF/被動基金** — 贖回 → 賣底層；負向回饋循環
2. **退休金/主權基金** — 再平衡觸發
3. **對沖基金** — 風險模型強制減倉 / Margin call
4. **企業回購暫停** — 財報禁售期間

## 機構買入三階段（市場止跌順序）

```
1. 大型股先行（藍籌/龍頭）
2. 成長股跟進
3. 高 Beta 股最後
```

## 市場止跌的觀察點

- **大型股先止跌** = 第一個訊號
- **成長股止跌** = 重新為成長付溢價
- **高 Beta 股反彈** = 風險偏好恢復 = 修正結束
