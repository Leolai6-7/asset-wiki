# 宋分 note — 備忘錄 #7 Follow-up QA（token 定價）

[[宋分（美股送分題）]] 2026-04-20 substack note。**核心觀點**：市場卡住不是因為 AI 沒價值，而是因為 **token 計價機制還沒被理解**。

## 核心一條

> **Token 會便宜，但「不可替代的 token」不會便宜。**

AI compute 比較像「**區域型電力市場**」而非全球商品市場。**地理 + 場景 + 整合深度**才是真正的 pricing 軸線。

## 六則 QA 精煉

| Q | 核心回答 |
|---|---|
| Token 會跌價？ | 會。但 **workflow 整合 + 低延遲的 token 不會跌** |
| 價跌怎麼撐 revenue？ | 使用量爆發 + **計價模式升級**（per-token → per-task → subscription package） |
| ROI 怎麼證明？ | 已有 cost savings + efficiency，**等 first proof 公司財報 margin 改善** |
| Headcount 是好指標？ | 不是。看 **workflow 自動化比例 + per employee token usage** |
| 宏觀影響？ | 短期 CapEx 抵銷消費萎縮 + 長期就業效應仍灰色 |
| Workflow lock-in？ | AI 整合進核心 ops = **基礎設施而非 optional tools**，是估值溢價的真正來源 |

## 關鍵啟示

**這篇 QA 是備忘錄 #7 的延伸 + AI 估值的「token 經濟學」教學起點**：

- **Token re-rate** = 從 per-token 變成 per-task / subscription packages
- **First proof 公司**會率先 re-rate，剩下的等財報追認
- **Workflow lock-in** = 估值溢價的最深源頭（不在硬體、不在模型、在 workflow 整合層）
