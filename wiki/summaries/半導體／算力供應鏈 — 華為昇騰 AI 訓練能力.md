# 半導體／算力供應鏈 — 華為昇騰 AI 訓練能力

> TrendForce / IEEE Spectrum / Reuters 等多源整理：華為昇騰路線圖（910C → 950PR → 960 → 970）+ 叢集策略（Atlas 950 SuperPoD 8,192 卡）+ DeepSeek V4 確認運行於昇騰 950PR。

## 一句話核心

**「華為晶片不能訓練大模型」這個 narrative 已經過時，但單晶片仍只有 H100 約 40%**——華為靠叢集規模 + 軟體優化（CANN/MindSpore）+ DeepSeek 級客戶背書補單卡缺口。**真正的 unresolved question** 是訓練出的模型品質能否與 NVIDIA 平起平坐，這要等 DeepSeek V4 的第三方獨立驗證。

## 重點摘要

| 維度 | 現況 |
|---|---|
| **單晶片算力** | 昇騰 910C 約 H100 40%（FP16 800 TFLOPS vs H100 ~2000）；昇騰 950PR 預計 2026 Q1，FP8 1 PFLOPS |
| **叢集策略** | Atlas 950 SuperPoD：8,192 卡、FP8 8 exaflops、宣稱對標 NVDA NVL144 |
| **軟體生態** | CANN 對標 CUDA、MindSpore 對標 PyTorch；成熟度落後但 DeepSeek 已花數月完成移植 |
| **客戶背書** | DeepSeek V4 確認在昇騰 950PR 運行（Reuters 2026/4/4），訂購數十萬片 |
| **獨立驗證** | 目前**全為 DeepSeek 內部測試**，無 LMSYS / ARC / 第三方研究者基準——這是論點最大缺口 |

## 產業／供應鏈延伸調查：中國 AI 算力替代路徑

中國 AI 算力替代不是「華為一家對抗 NVDA」，而是**多家晶片廠 + 多家代工廠 + 多家應用廠商的並行替代路徑**。完整地圖：

### 1. 中國 AI 晶片廠分層

| 廠 | 定位 | 旗艦 | 關鍵限制 |
|---|---|---|---|
| **華為** | NPU + 自研系統 | 昇騰 910C / 950PR | 受出口管制、HBM 受限 |
| **寒武紀（Cambricon）** | 雲端 NPU | 思元 590 | 良率與量產規模 |
| **海光（Hygon）** | x86 + AMD 授權衍生 | 深算 DCU | AMD 授權能持續多久 |
| **燧原（Enflame）** | 雲端訓練 NPU | 邃思 3.0 | 軟體生態 |
| **壁仞（Biren）** | GPGPU | BR100（被禁產） | 已被踢出 TSMC，幾近停擺 |
| **摩爾線程（Moore Threads）** | 通用 GPU | MTT S4000 | 製程受限 |

**真實格局**：華為昇騰 + 寒武紀是 DeepSeek 點名合作的兩家，已**事實上**成為中國訓練側雙頭。其他廠仍在推理或邊緣場景。

### 2. 中國半導體製造瓶頸

| 環節 | 中國能力 | 缺口 |
|---|---|---|
| **代工製程** | 中芯國際（SMIC）N+2（~7nm 等效），昇騰 910C 用之 | 落後 TSMC 4-5 代；EUV 缺失 |
| **HBM** | 長鑫存儲（CXMT）已宣布 HBM2 樣品（2025-2026） | 落後 SK Hynix HBM3E / HBM4 兩代以上 |
| **裝置** | 北方華創、中微等本土化 | 高階曝光機（光刻）零突破，必依 ASML |
| **EDA** | 國微等開發中 | Synopsys / Cadence 仍是事實標準 |
| **特氣 / 光阻** | 部分替代 | 高階 photoresist 仍依日本 |

**最緊的瓶頸**：HBM。昇騰 950PR 號稱「自研 HBM」（華為宣稱），但實際良率與規格未獲第三方驗證。HBM 是訓練側決勝點（見 [[HBM iPhone moment]]）。

### 3. 出口管制下的中國替代路徑

| 路徑 | 機制 | 代表 |
|---|---|---|
| **a. 全自主棧** | 中芯製造 + 華為設計 + CANN 軟體 + DeepSeek 應用 | 昇騰 + DeepSeek V4 |
| **b. 灰色採購** | 透過第三國經銷或降級版（H800 / H20） | 多家中國雲廠 |
| **c. 雲端繞道** | 中國公司租用境外算力（新加坡、馬來西亞 hyperscaler） | 字節跳動部分訓練 |
| **d. 開源蒸餾** | 用境外開源模型蒸餾後在本土硬體繼續訓練 | DeepSeek 早期路線 |

**Reuters 2026/4 訊號**：DeepSeek V4 拒絕讓 NVDA / AMD 提前取得做調校，**只給中國晶片商先跑**——是路徑 (a) 從技術上「跑得通」轉向「政策上選邊」的拐點。

### 4. 與 [[Musk Terafab]] 的對比

| 維度 | 華為 + 中芯 + DeepSeek | Musk + Intel + Tesla/xAI |
|---|---|---|
| **動機** | 出口管制下被迫自主 | 戰略主動，鎖控制權 |
| **製程** | SMIC N+2（落後 TSMC 4 代） | Intel 18A（與 TSMC N2 同代） |
| **軟體** | CANN（自研，未成熟） | CUDA 兼容 + 自研堆疊 |
| **應用客戶** | DeepSeek（已綁定） | Tesla / xAI / SpaceX（自家） |
| **時程** | 已量產、已部署 | 2027 量產 |
| **真風險** | HBM、製程世代差 | Intel 18A 良率 |

**共通點**：都是 [[控制點轉移]] 案例——AI 算力的戰略價值已壓過晶圓代工比較利益。

## 投資啟示（快速）

- **直接受惠（中國上市，多數無法直接買）**：華為（未上市）、中芯國際（H 股 0981.HK）、寒武紀（A 股 688256）、海光（A 股 688041）、長鑫（未上市）
- **負面影響**：
  - **[[NVDA]]**：中國市場（H20 / B20）營收逐步流失，但全球 hyperscaler 需求仍主導
  - **AMD**：MI 系列在中國的滲透更難
  - **SK Hynix / Micron**：HBM 中國市場份額受 CXMT 國產化擠壓
- **間接觀察**：DeepSeek V4 上線後若能達到 GPT-4.5 / Claude Opus 同檔次，是中國訓練側「品質追平」的訊號——這比硬體規格參數重要 10 倍

## 風險與失效情境

1. **DeepSeek V4 獨立驗證不及預期**：昇騰能跑但跑不出好模型，narrative 倒退
2. **出口管制升級到應用層**：美國禁止昇騰部署到「美國有實質利益」的市場（東南亞、中東），國際擴散被切
3. **HBM 缺口長期無解**：中國 HBM 自主仍需 3-5 年，期間訓練側仍受制於走私 HBM
4. **CANN 生態無法跨出 DeepSeek**：除 DeepSeek 外，其他模型廠仍綁 CUDA，華為陷入單一客戶風險
