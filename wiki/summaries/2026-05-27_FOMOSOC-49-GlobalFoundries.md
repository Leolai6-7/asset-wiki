# FOMO SOC #49 — GlobalFoundries（KP@FOMOSoc 2026-05-27）

## 一句話

> GlobalFoundries 將自己定位為跨多條量子計算技術路徑的**不可或缺基礎設施提供者**——利用既有半導體製造能力捕捉**政府資金**與**長期客戶關係**；是「**混凝土裡的鋼筋**」典型賣水人 anchor。

## 核心 thesis

### Primary Investment Thesis：量子計算的「收費員」

不押單一量子路徑（superconducting / photonic / trapped-ion）、押**所有路徑都需要的基礎設施製造**：
- **cryo-CMOS controls**（低溫 CMOS 控制晶片）
- **advanced packaging**（先進封裝）
- **3D heterogeneous interconnects**（3D 異質整合互連）

### 關鍵 supporting points

1. **平台多功能性**：GFS FDX 平台支援五種量子模式、相容於九家受 **$2B 政府配額**補助公司中的**八家**
2. **客戶背書**：**PsiQuantum + Quantinuum + Diraq** 公開依賴 GFS 製造能力商業化
3. **政府信心訊號**：$375M 隱含估值底（1% equity stake 反推）= 官方認定 GFS 為「**準國防資產**」
4. **既有獲利**：vs 量子新創燒錢、GFS 年營收 **~$7B** + 毛利率改善、服務 NVDA 供應鏈 + 汽車 MCU

## 數據 anchor

| 指標 | 數值 |
|---|---|
| 政府量子計算配額（總額） | **$2B** |
| GFS 獲配額 | **$375M** |
| GFS 隱含估值（從 1% equity stake 反推） | ~**$37.5B** enterprise value |
| GFS 年營收 | **$7B+**（baseline）|
| 政府股權 | **~1%** strategic position |
| GFS FDX 平台相容九家受配額公司 | **8/9** |

## IBM Anderson vs GFS 對比（製造哲學）

- **IBM Anderson**：垂直整合自有 fab、製造自己 superconducting qubit
- **GFS**：平台型製造、為多家客戶代工不同 qubit 設計
- → **GFS 賣水人邏輯勝**：不押誰贏量子計算

## 2009 AMD/GFS spinoff 框架（開頭）

- AMD 2009 分拆 GFS（fabless / foundry 分家）
- 17 年軌跡（2009 → 2026）擋付費牆

## ⚠️ 自警惕（KP 隱含 + 付費牆擋住）

1. **付費牆擋住 60% 內容**——詳細財務 / 估值 / 競爭定位 / AI infra 深度 / 風險 / Mubadala dynamics 全部擋住
2. **「3% 營收成長卻股價翻倍」**——隱含「Re-rate 三角形 reset」可能在付費牆後深展、無法確認
3. **量子計算商業化進程**——PsiQuantum / Quantinuum / Diraq 三家仍在燒錢階段、商業化 5-10 年起算
4. **政府入股 1% 是相對小額**——不像 Intel 2024 政府入股 10% 程度、GFS 1% 是 anchor 訊號而非 dominate
5. **8/9 量子公司 vs 9/9 完整**——剩下 1 家可能是 IBM 自家 fab 路線（垂直整合）
