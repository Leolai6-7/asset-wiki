# 宋分 #11 — 你不是不知道停損，是不知道自己什麼時候看錯

[[宋分（美股送分題）]]（2026-03-21）。**多數人不是不懂停損，是無法辨識自己什麼時候看錯**。

→ 完整概念 [[看錯三類型]]、[[市場四階段：懷疑／驗證／共識／反轉]]

## 看錯三類型

| 類型 | 訊號 | 應對 |
|---|---|---|
| **產業方向看錯** | 領頭公司調策略、CapEx 方向變 | **果斷退出** |
| **公司競爭力看錯** | 同業表現持續優於、市佔流失 | **換股** |
| **時機看錯** | 基本面改善但股價低迷 | **不需停損**，管理倉位 |

## 正確的加碼時機

> 加碼不應該基於「股價跌了所以便宜」。

加碼應該基於：
- 新的正面資訊**確認了論點**
- **確定性提高了**，而不只是價格降低
- 你對公司的**理解加深了**，而非只想攤平

## 最危險訊號

> **好消息不再推動股價上漲**

- 代表市場已充分定價所有好消息
- 或代表有人知道你不知道的壞消息
- = [[預期差]] 為零/負

## 市場四階段

```
1. 懷疑（最好進場、最難下手）
2. 驗證（穩步上升、風險報酬仍好）
3. 共識（加速上漲、風險報酬惡化）
4. 反轉（好消息不再推動 → 大跌）
```

## 核心金句

> 知道自己在哪個階段看錯，比知道「要停損」更重要。
> 最危險的不是看錯，而是不知道自己看錯了。
