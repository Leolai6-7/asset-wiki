# 宋分備忘錄 #13 — 下一個 20 年的入口革命：AI Agent、流量重分配與新 Alpha

[[宋分（美股送分題）]] 2026-05-25 備忘錄。**入口革命 + 控制權重新洗牌的大格局篇**。承接備忘錄 #7（Robotaxi）+ #8（AI 獲利擴散）。

→ 核心 concept [[Agentic Internet 入口革命（UCP）]]（待建）

## 一、資訊商品化 → 新 alpha 浮現（反直覺）

| 變化 | 結果 |
|---|---|
| AI 同質化資訊 | 機構策略趨同、**擁擠交易**風險擴大 |
| 資訊優勢消失 | **問題優勢**浮現 |
| 新 alpha | 框架完整性 + 產業理解 + 市場嗅覺 |

> 知道「該問什麼問題」、本身就是 alpha。

## 二、Agentic Internet（核心 anchor）

### iPhone 時刻類比

iPhone 改變網路入口 → Uber / TikTok / 微信
Agent → 下一波同等級 winner

### Google UCP（Universal Commerce Protocol）

- Google 推出、象徵電商進入 Agent 時代
- 流量掌握權 → 「**最常替用戶做決定的 AI**」
- chokepoint：誰控制 Agent、誰控制 commerce 流量
- 對應 [[控制點轉移（投資版）]]：「**控制 Agent 入口 = 控制下一個 20 年的流量**」

### 競賽玩家

| 公司 | 角色 |
|---|---|
| Google | UCP 推出者 + 搜尋既有入口 |
| Meta | AI 商業入口 call option |
| Amazon | 電商既有入口 + Alexa Agent |
| Apple | Siri Agent + 系統級整合 |
| OpenAI | ChatGPT 入口 + Universal Plug |
| Anthropic | Claude API + MCP 協議 |
| Shopify | 商家端 SaaS 接入點 |
| Stripe | 金流 chokepoint |

## 三、Meta 隱藏 call option（核心個股 anchor）

### 三層 thesis 升級

- **商品推薦**：Instagram / WhatsApp 推薦商家
- **交易導流**：Shop on Instagram + WhatsApp Pay
- **workflow 執行**：AI agent 代用戶完成購物

### 估值差距

| 現定價 | 真正 thesis |
|---|---|
| 廣告公司 PE | AI 商業入口 PE |

→ 差距 = call option 價值。

## 四、流動性轉向實體 → CapEx 受惠

| 情境 | 影響 |
|---|---|
| QE 過去 | 流動性流向金融資產 |
| **縮表 + 適度通膨** | 流動性流向實體投資（CapEx、AI infra） |

- 有獲利、有生產力的公司**有利**
- 無法將 AI 支出轉換為現金流的公司**受罰**
- 對應 [[AI 變現能見度分歧（證明給我看階段）]]：Google / AWS 上漲 vs Meta 大跌的根因
