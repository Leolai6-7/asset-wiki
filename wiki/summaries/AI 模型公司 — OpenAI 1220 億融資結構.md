# AI 模型公司 — OpenAI 1220 億融資結構

## 一句話核心

OpenAI 的 1,220 億不是純現金，是**條件資本 + 循環投資**織出來的對賭票據——三分之一綁定「IPO 必須發生」、另一大塊綁定「投資人同時是供應商」，這個結構讓「AI 估值」變成「閉環內部記帳」，不是傳統 VC 退出邏輯。

## 重點摘要

- **估值與規模**：估值 $852B，單輪 $122B 融資，比沙烏地阿美 IPO（$29.4B）大四倍。**人類商業史上最大單輪。**
- **條件資本 35% 不是錢**：Amazon $50B 只有 $15B 現金到帳，$35B 要等 IPO 或 AGI 里程碑才撥款 → IPO 從「可選退出」變成「合約義務事件」。
- **循環投資（CSP-Model 互鎖）**：
  - Nvidia 投 $30B → OpenAI 用來買 Nvidia GPU
  - Oracle 借 $50B 債 → 蓋資料中心給 OpenAI 租
  - Microsoft 持股 27% + 是最大雲端供應商
  - 錢從投資人 → OpenAI → 投資人的產品線，閉環。
- **單位經濟極差**：2025 營收 $20B、年虧 $14B、2030 累計燒錢預估 $665B。**每賺 1 元燒 1.69 元。**
- **付費滲透率 5.5%**：9.1 億週活躍用戶只有 5.5% 付費，OpenAI 在補貼 94.5% 用戶的算力。
- **跑道僅 1 年**：以目前算力支出速度，$122B 約只夠撐一年（Zombit）。
- **Sora 關閉是戰略訊號**：每天燒 $15M、營收 $2.1M，下載量掉 66% → OpenAI 從「消費者科技明星」轉向「基礎設施公用事業」路徑。
- **全球 VC 81% 流向 AI**（2026 Q1 Crunchbase）→ OpenAI、Anthropic、xAI 三家吃掉 $188B / $242B。生技、金融科技被擠出資本市場。

## 產業/供應鏈延伸調查（重點）

### 一、AI 融資 vs 傳統 VC 的三個根本差別

| 維度 | 傳統 VC | AI 模型公司融資 |
|---|---|---|
| 退出邏輯 | IPO 或併購是「機會」 | IPO 是合約鎖死的「義務」（Amazon 條件） |
| 投資人身份 | 純財務投資人 | 同時是核心供應商（Nvidia、Microsoft、Oracle） |
| 資金性質 | 純現金 | 35-60% 條件資本（compute commitment、收入分潤、AGI tripwire） |
| 估值錨點 | DCF / 可比交易 | 算力消耗速度 × 跑道月數 |
| 風險集中度 | 分散在多輪、多投資人 | 高度集中在「同一個 AI 不泡沫化」單一押注 |

→ 這套打法在 [[Anthropic 被列為國安威脅]]、xAI 千億級融資、Meta 自建模型都重複出現。**AI 模型公司估值已脫離傳統 PE/DCF 框架**，本質是「算力期權」。

### 二、循環投資（CSP-Model 互鎖）的真實風險

- **正向飛輪期**：AI 商業價值持續增長 → 投資人收回賣 GPU/雲端的營收 → 帳面 IRR 美麗 → 推升所有玩家估值。
- **連鎖爆破風險**：
  - 油價飆 / 電力成本暴漲（中東地緣風險） → 資料中心經濟模型崩
  - Oracle $50B 債、Microsoft Azure CapEx、Nvidia 應收帳款 全部坐在同一個假設上
  - 如果 OpenAI 推遲 IPO → Amazon $35B 不撥款 → 跑道縮短 → 算力購買力下降 → Nvidia / Oracle 營收下修 → CSP-AI 通縮辯論被快進
- → 連到 [[宋分備忘錄 ＃1 — CSP-AI 通縮]]、[[CapEx 見頂辯論]]、[[FCF 拐點]]。

### 三、供應鏈層級的真贏家

| 層 | 公司 | 受惠機制 | 風險 |
|---|---|---|---|
| 晶片 | NVDA、AVGO | 條件資本流回，先進製程訂單鎖到 2028 | 客戶集中度（OpenAI 單一風險） |
| 代工 | TSMC | 先進製程、CoWoS、HBM 三重受惠 | 同上 |
| 雲端 | Microsoft、Oracle、Amazon | 雲端營收、又能持股升值 | Oracle 槓桿過高、電力供應 |
| 能源/電力 | 核電、燃氣、變壓器、輸配電 | 資料中心電力剛需 → [[能源結構性剛需]] | 政策、地緣 |
| 模型層 | OpenAI、Anthropic、xAI | 「最後一段跑道」 | IPO 條件、單位經濟、政府風險 |

→ **真贏家在賣水人這層（晶片＋代工＋電力＋雲端基礎設施）**，模型層是高風險押注。對應 [[半導體基礎建設化]]、[[AI 半導體基礎建設化]]。

### 四、投資啟示（asset-wiki 角度）

1. OpenAI 估值 $852B 是「閉環內部記帳」估值，不是公開市場可承擔的價格。IPO 後將面臨**戴維斯雙殺**——本益比壓縮 × 公開市場對單位經濟容忍度低。
2. **真正可長期持有的 AI 受惠標的是供應鏈中游（晶片、代工、電力）**，不是模型層。
3. CSP 的 CapEx 結構若被質疑，OpenAI 是第一張倒下的骨牌——關注 [[FCF 拐點]] 的時間表。
4. Sora 關閉 → OpenAI 從多產品線收斂 → 暗示「AGI 賣消費級訂閱」的故事正在退場，「賣 API + 賣企業 agent」變主敘事 → 與 [[微軟 Copilot 條款僅供娛樂]]、[[AI 訂閱制 unit economics]] 連動。
