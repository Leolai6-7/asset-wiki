# 宋分 #30 — 為什麼你總是在市場漲完之後，才開始相信？

[[宋分（美股送分題）]]（2026-05-09）。**「連續上修」操作框架**。承接 #18（強勢股下跌中發現）+ #05（散戶買在起漲點）。

## 核心命題

> 市場交易的不是「最好的產業」、是「**還沒被算清楚、未來會持續上修的確定性**」。
> 散戶交易「絕對好壞」、機構交易「**邊際變化**」。

## 三個連續上修判斷指標

| 指標 | 訊號 | 操作意義 |
|---|---|---|
| **需求結構性加速** | RPO backlog 暴增（AWS $3,640 億）、合約負債年增 50% | 確認需求真實 |
| **定價權增強** | 漲價幅度擴大、不需折讓、客戶接受 | 確認競爭力 |
| **公司不給上限** | guidance 「需求超過供給」、「看不到天花板」 | 確認上修空間 |

→ 三條都成立 = **EPS 上修期開始** = 機構進場時機。

## 市場三階段論

```
想像力階段 ────→ 驗證階段 ────→ 確定性階段
高 beta 暴漲       篩選有料          Mega Cap 回流
```

| 階段 | 特徵 | 操作策略 |
|---|---|---|
| **想像力** | 故事驅動、高 beta | 高勝率 + 嚴停損 |
| **驗證** | 篩選能交付的 | 加碼有 backlog 的 |
| **確定性** | 資金回流穩定現金流 | NVDA / AVGO / Mega Cap |

→ 散戶常在「想像力→驗證」斷層時退場、錯過「驗證→確定性」最豐厚段。

## 機構 vs 散戶反差

| | 機構 | 散戶 |
|---|---|---|
| 進場時機 | 30-40% 信心 + 部位試單 | 等到 80%+ 確定才進 |
| 觀察 | 邊際變化、上修速度 | 絕對好壞 |
| 操作 | 分批 + 季度驗證 | All-in 或 All-out |
| 心態 | 看到上修可繼續 | 「漲了」才信 |

## 三步驟風險管理

1. **分批佈局**：拆 3-5 份、不 all-in
2. **季度驗證敘事**：每次 earnings 檢查三指標、斷掉 → 縮手
3. **交易「邊際變化」**：不問好不好、問「比上次預期是好是差」

## 核心金句

> 散戶最痛的不是錯過、是「**我那時就看到了但沒進場**」——因為他們在等市場告訴他可以買、但市場永遠不會告訴你。

> 機構也不是 100% 確定才進場、是 30-40% 信心 + 部位試單 + 觀察上修。
