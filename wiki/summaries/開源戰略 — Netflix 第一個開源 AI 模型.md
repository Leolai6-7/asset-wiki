# 開源戰略 — Netflix 第一個開源 AI 模型

**一句話核心**：Netflix 開源 VOID 不是慈善，是**對影視後製工具市場投的一顆手榴彈**——一家不靠賣工具賺錢的內容買家，用免費工具把工具公司的利潤中心變成自己的免費基礎設施。

## 重點摘要

### 事件

- Netflix 在 Hugging Face 開源 **VOID** 模型（Apache 2.0），影片物件移除 + 物理重生成
- **盲測 64.8% 偏好率擊敗 Runway（18.4%）**——25 人盲測
- Netflix 第一個開源 AI 模型

### VOID 的技術定位（窄而深）

- **「四值遮罩」（quadmask）** 設計：標記「要刪除物件」「重疊區」「受影響物件」「保留背景」
- **物理感知**：不只刪除物件，理解物件被刪除後其他東西怎麼動
  - 範例：車禍畫面移除一台車，另一台繼續正常行駛，碎片火焰消失，路面恢復
- **技術取捨**：選了「深度理解場景物理」，放棄「通用生成能力」
- **無法做**：生成新內容、風格轉換、特效——只做物件移除，但做到最好

### 為什麼開源（投資視角拆解）

| 表面 | 賭注 |
|---|---|
| 技術社群貢獻 | 重新定義「後製」成本結構 |
| Apache 2.0 商用自由 | 把後製從「Runway/Adobe SaaS 費用」變成免費基礎設施 |
| 看起來像 Llama / TensorFlow 劇本 | 其實更像 **Google 開源 Android** 的劇本——把對手利潤中心變免費 |

> 核心邏輯：**Netflix 是全球最大內容買家**（年數百億美元購置 / 製作）。後製成本下降 50% → **直接增加 Netflix 利潤**，**不需要靠工具賺錢**。

### 錢的流向變化

| | VOID 之前 | VOID 之後 |
|---|---|---|
| 後製公司 | Netflix 付錢給後製公司 | 後製流程被壓縮 |
| 工具公司 | 後製公司付 SaaS 給 Adobe/Runway | 這塊 SaaS 收入消失 |
| Netflix | 付全鏈條成本 | 降低自身內容成本 |

## 產業／供應鏈延伸調查

### 1. 直接受害者：影視 SaaS 工具公司

- **Runway**：上月才完成新一輪融資、估值繼續漲；VOID 證明「物件移除」這個具體任務上，**免費 > 付費**
  - 護城河被一個不靠賣工具賺錢的公司挖了一鏟
  - 估值風險：營收成長假設可能下修
- **Adobe（ADBE）**：Creative Cloud 含 After Effects + Premiere
  - 整體仍有完整工作流護城河，但「特定 AI 功能溢價」會被免費替代品壓縮
  - 短期影響有限，**長期 PE 倍數承壓**（PE 壓縮邏輯見 [[PE 壓縮公式]]）
- **Pika、Synthesia、HeyGen** 等小型 AI 影片工具：**最先被擠壓**的一群——他們沒有 Adobe 的工作流綁定

### 2. 連鎖反應：其他內容平台會不會跟進

每個內容平台都有「**降低後製成本 = 直接增加利潤**」的相同動機：

| 平台 | 跟進可能性 | 觸發點 |
|---|---|---|
| **Disney+** | 高 | 內容預算最高、AI 後製可幫 Star Wars / Marvel 大型製作降本 |
| **Amazon Prime Video** | 高 | AWS 有 AI 基礎建設，自然延伸 |
| **Apple TV+** | 中 | Apple 開源傳統不強，但有 MLX 框架 |
| **YouTube / Google** | 高 | 已有 Veo 系列，自帶開源傳統 |

**結論**：VOID 不是孤立事件，**是內容平台「自己做工具」風潮的起點**。

### 3. 上游硬體賣水人連動

- VOID 需要 inference 算力 → 對 [[NVDA]]、[[AMD]] 邊緣 GPU 需求增加
- 開源 + 本地部署 → **雲端 GPU 託管商（CoreWeave、Lambda Labs）** 可能受惠
- TSMC 製程仍是底層受惠（[[TSMC]] 是基礎建設化的最終勝者）

### 4. Netflix 自身估值含義

- Netflix 內容成本占營收約 **50–55%**（年 ~$170 億）
- 如果開源 AI 後製工具能把後製成本壓縮 10–20%（行業 estimate）→ **年省 $1–5 億 OpEx**
- 對 Netflix 是**直接毛利率提升** → [[營業槓桿拆解（五層損益表）]] 第三層改善
- 投資推論：Netflix 在做的是**結構性成本下降**，非一次性事件
  - 但市場是否定價？**目前共識仍視 VOID 為 PR/social goodwill，預期差存在**

### 5. 影視製作上游：勞動力市場衝擊

- 傳統幾秒鐘物件移除鏡頭，需要特效團隊**幾天手工處理**
- VOID 級工具普及 → 後製人力需求結構性下降
- 連結 [[AI 通縮三路徑]]「去中介化」路徑——影視中後製外包鏈被 disrupt
- 受影響：北美 / 印度 / 韓國的 VFX 外包公司、後製工作室
