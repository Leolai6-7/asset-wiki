# FOMO SOC KP #44 — 多家個股一週總覽

**作者**：KP@FOMOSoc（2026-05-30 發布、KP 思考筆記第 44 期）
**性質**：多家個股一週敘事翻轉、**全文免費**

## 一句話

> 五家 narrative shift 同時發生——Tesla/SpaceX 合併傳言（80-90% vs 預測市場 40%）、Marvell 從 ASIC 第二名翻成「interconnect 寡占」、Snowflake 從「被威脅」變「企業 AI agent 可信執行環境」、Dell 因 pull-through effect 單日 +30%、**Anthropic Series H $65B 估值 $965B 超越 OpenAI + $36B TPU 租賃融資 + Micron/Samsung/SK Hynix source locking** 全棧融資創新。

## 五家敘事翻轉一覽

| Company | Old | New | Catalyst |
|---|---|---|---|
| Tesla/SpaceX | 兩家獨立 | AI 生態整合 | Dan Ives 80-90% 預測 |
| **Marvell** | ASIC 第二名 | Interconnect 寡占（光 DSP **60%**）| Celestial AI + XConn + Polariton 三併購 |
| **Snowflake** | Legacy 倉儲被威脅 | 企業 AI agent 可信執行環境 | AWS **$60B 5 年合約** |
| **Dell** | PC OEM | 整廠 AI infra refresh | 單日 +30%、AI server +757% YoY |
| **Anthropic** | Capital burn | $965B 估值超越 OpenAI + 雙軌融資 | Series H $65B + TPU 租賃 $36B |

## Dell pull-through effect ⭐（KP 44 期核心）

### 財務驚奇
- 營收 **YoY +88%**（單季 $43.8B 級別、原文 typo $438B）
- AI server 營收 **YoY +757%**（單季 $16.1B 級別）
- 營業 leverage 20 年低點（OpEx/Revenue **8.4%**）

### Pull-through thesis
> 企業升級 AI cluster → 同步升級「**電力 / 散熱 / 網路 / 儲存**」整廠
> = Dell 不只是 GPU server、是「**整廠升級**」受惠者

### 護城河
- 系統整合專業
- **Dell Financial Services**（融資）→ 跟 HPE / Lenovo 結構性差異化
- 企業需要實戰工程支援部署大型 GPU cluster

## Marvell interconnect 寡占 ⭐

### 過去 vs 現在
- 過去：Marvell = 「**ASIC 第二名**」、跟 [[AVGO]] 競爭 custom silicon
- 現在：**Interconnect = 最大 segment、YoY +70%**

### 戰略併購補強
- Celestial AI（光通訊）
- XConn（CXL switch）
- Polariton（量子光學）
- → scale-out + scale-up + scale-across 全棧

### 關鍵市場錯定價
- 市場把 interconnect 跟傳統 networking 並列
- 實際 **光 DSP 市占 ~60%** = 獨立護城河

## Snowflake 180 度翻轉

- AWS **5 年 $60B** infrastructure 合約（2.4x 前約）
- AWS Graviton（成本 CPU）+ NVDA GPU（推理）= 證明 custom ARM 生產可行
- Snowflake = **企業 AI agent 可信執行環境**

## Anthropic Series H + TPU 租賃 ⭐⭐ 雙引擎融資

### 股權輪
- **Series H $65B**、估值 **$965B**
- **超越 OpenAI 估值**

### 債務創新
- **$36B TPU 租賃融資**（Apollo + Blackstone）+ **Broadcom 擔保**
- 資本分層：股權（brain：R&D + 人才）vs 債務（muscle：硬體 rental）

### Supply chain source locking
- **Micron + Samsung + SK Hynix 參與股權**
- → 供應商鎖定未來 HBM 需求
- 模仿成熟資本密集行業（航空 / 能源）資產融資 + 股權分離
