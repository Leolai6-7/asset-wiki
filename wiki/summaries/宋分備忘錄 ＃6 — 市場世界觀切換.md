# 宋分備忘錄 #6 — 市場正在切換一個更大的東西

[[宋分（美股送分題）]] 2026-04-13 備忘錄。**最大格局的一篇**。市場進行「世界觀切換」——從**效率優先**轉向**安全優先**。這是**結構性轉變，不是短期行情**。

→ 核心概念見 [[效率→安全切換]]

## 一、從「效率世界」到「安全世界」

| | 過去 20 年 | 現在 |
|---|---|---|
| 供應鏈 | 哪裡最便宜 | 哪裡不會被斷供 |
| 運輸 | 哪條路最快 | 衝突下還能活下來 |
| 資本 | ROI 最高優先 | 多路徑冗餘 |

> **用更高的成本，換更高的確定性。**

### 永久成本提升

- **「成本不會回到以前」**
- 能源 / 航運 / 製造 / 食品帶上「風險溢價」
- **不是通膨暫時現象，是定價結構的永久性改變**

## 二、結構性機會驗證三條件

不要急著下結論：

1. **供給結構真的改變？**（新增產能？去單一依賴？）
2. **CapEx 持續？**（工業/電網/能源/資料中心；連續數季）
3. **現金流變穩定？**（長約？定價權？毛利率波動下降？）

> 只有現金流被改變，市場才會給估值；否則仍是週期股估值。

## 三、AI 產業邏輯反思（歷史視角）

| 案例 | 基礎建設 | 真正贏家 |
|---|---|---|
| 鐵路 | 報酬差 | 沿線商業 |
| 電信 | CapEx 巨、利潤被壓 | 上層服務 |
| 網路 | 基礎設施不賺錢 | Google/Meta/Amazon |

**共通點**：每次科技革命最賺錢的都不是基礎設施，是「最不需投入資本」的應用層。

→ 機構正在思考：**被錯殺的 SaaS、洗牌後的強者，會不會才是 AI 時代最賺錢的？**

> 「**不要走極端、不要急著定價贏家**。」
> 「找現在階段還沒 fully price in 的公司。」

## 四、財報季的真正看點

### 不看 EPS beat，看「**利潤率轉折**」（Margin Inflection）

```
Q1 = 高點（壓力頂點）→ 後面修復 → 評價上修 → 股價提前反應
還沒最差     → 後面下修 → 股價繼續走低
```

> 同一份財報會有**完全相反的股價反應**——關鍵是是否觸底。

### 重點公司

1. **ASML**：資本週期變強？整個半導體 CapEx 是否重啟？
2. **台積電**：AI 是否填補消費電子/手機/汽車的需求空缺？看**各終端配比**
3. **消費品**：定價權是否還在？

### CapEx 決策 = 訊號
- 願意投資 → 公司相信需求是真的
- 不敢投資 → 短期行情

### 消費電子底部訊號（反直覺）

> 記憶體漲幅預估**有一點點放緩** → 反而是消費電子的底

不是等記憶體跌，是等**漲速放緩**那一刻。

## 五、最終思考

> 「市場看起來很混亂，但其實正在慢慢變得更清楚。**清楚的不是答案，是該怎麼問問題**。」

> 「市場永遠會先給你一個很簡單的故事，但**真正的機會通常在那個還需要驗證的地方**。」
