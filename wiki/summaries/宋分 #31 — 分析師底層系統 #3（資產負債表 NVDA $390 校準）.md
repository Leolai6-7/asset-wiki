# 宋分 #31 — 分析師底層系統 #3：90% 散戶只看損益表，真正的分析師都在看資產負債表

[[宋分（美股送分題）]]（2026-05-29）。**系列教學第三篇**、承接 #17（10-K 教學）+ #23（營業槓桿）。以 [[NVDA]] $390 時點為案例。

→ 完整概念 [[資產負債表健康度診斷]]（待建）

## 核心命題

> **損益表會做帳、資產負債表騙不了人。**
> 分析師看「變化」、不看絕對數字。

## 五大關鍵指標（NVDA $390 校準）

| 指標 | NVDA 表現 | 判斷 |
|---|---|---|
| **營運現金流（CFO）** | YOY 強勁、QOQ 季增 | 需求真實 ✓ |
| **融資活動** | 長期為負、回購 + 配息 $200 億 | 自給自足 ✓ |
| **應收帳款** | 增速未超營收、DSO 未惡化 | 收款健康 ✓ |
| **庫存結構** | 原料 + 在製品上升、成品未失控 | **做不完** ✓ |
| **長期負債** | 幾乎無增、負債比 25%、利息保障 528x | 抗風險 ✓ |

→ 五項全綠 = 真正大成長循環。

## 額外健康指標

| 指標 | NVDA 數據 | 含義 |
|---|---|---|
| 股東權益 | $838 億 → $1,954 億 | 內生增長 |
| 合約負債 | 年增 50%、$31.17 億 | 客戶搶交期 |

## 健康 vs 危險組合（判斷邏輯）

### 健康組合（NVDA）

```
營收成長 + 現金流轉強 + 合約負債增加 + 毛利改善
= 真正大成長循環
```

### 危險組合（反面教材）

```
營收成長 + 應收帳款暴增 + 庫存堆積 + 現金流惡化
= 龐氏騙局徵兆
```

## 庫存結構的解讀（關鍵）

> 「**做不完**」vs「**賣不掉**」= 完全相反的訊號。

| | 「做不完」（NVDA） | 「賣不掉」（警訊） |
|---|---|---|
| 原料 | 上升 | 下降 |
| 在製品 | 上升 | 下降 |
| 成品 | 未失控 | 堆積 |
| CapEx | 高檔 | 衰退 |
| 結論 | 供應追不上需求 | 需求衰退前兆 |

## NVDA $390 thesis 校準結論

- 結構性大成長 ✓ 不是泡沫
- 合約負債暴增 + 庫存原料結構揭露「做不完」
- 槓桿極低 + 自由現金流強勁 + 內生增長
- → 在這個時點：**estimates 仍偏保守、上行空間仍在**
