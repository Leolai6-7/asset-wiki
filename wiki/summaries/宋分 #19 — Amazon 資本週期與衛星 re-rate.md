# 宋分 #19 — Amazon 為什麼盤整數年卻一啟動就多年大多頭？

[[宋分（美股送分題）]] 2026-04-21 深度文。**核心命題**：Amazon 是「**資本週期股**」而非成長股——前期 CapEx 壓低 EPS、後期現金流爆發驅動 re-rate。衛星（Kuiper）會不會是下一輪觸發？

## 一、三段資本週期（Amazon 是機器，不是股）

```
階段 1：電商物流建設     → CapEx 燒錢、EPS 難看
階段 2：AWS 高毛利引擎   → ROIC 上升、第一次 re-rate
階段 3：AI + 衛星基礎建設 → 進行中、第二次 re-rate 等待中
```

**這個模式很簡單但很反直覺**：股價盤整期 = 市場對利潤釋放時機的誤判。

## 二、會計策略是隱藏護城河

Amazon 把**未來投資列為費用化而非資本化**：
- 物流網建設費用化
- Prime 補貼費用化
- 基礎設施投入費用化

**短期財報難看 → 長期競爭力深化**。會計上的「利潤」 ≠ 真正的價值創造能力。

## 三、ROIC × Organic Growth 才是 re-rate 觸發

| 條件 | 含義 |
|---|---|
| ROIC 上升 | 資本效率改善 |
| Organic Growth 持續 | 再投資空間還在 |
| **兩者並存** | **大牛股觸發點** |

> 「市場不是在找『成長最快的公司』，是在找『**成長可以複利的公司**』。」

## 四、追蹤指標四件套

| 指標 | 訊號意義 |
|---|---|
| 單位成長 vs 配送成本比率 | 物流自動化是否真實降本 |
| 第三方服務費成長 | 第三方 marketplace take rate |
| Backlog 年增幅 > 營收年增幅 | AWS 供應緊張訊號 |
| 營益率何時觸底回升 | 利潤爆發週期前兆 |

## 五、隱藏 margin engine：廣告 + Prime

- **廣告佔比持續提升** + **Prime 漲價空間**
- 足以**覆蓋物流重資產燒錢**
- 成為利潤核心驅動（市場還沒完全認知）

## 六、衛星（Kuiper）= 下一輪 re-rate 觸發？

- 衛星不只是新業務，**是 Amazon 掌握「連網能力」這一基礎層**
- 若形成**長約訂閱模式** → 驅動下一輪估值重評
- 與 AWS 整合形成 vertical stack（compute + connectivity）
- 對抗 Starlink 的差異化定位

## 關鍵金句

> 「Amazon 從來不是成長股，是**資本週期股**。」

> 「會計上的『利潤』，從來不等於企業真正的價值創造能力。」
