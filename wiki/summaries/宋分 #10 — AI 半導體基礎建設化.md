# 宋分 #10 — AI 是否正在將半導體從景氣循環股變成基礎建設公司？

[[宋分（美股送分題）]]（2026-03-17）。**這個轉變如果成立，估值框架需要全面重寫**。

→ 完整概念 [[半導體基礎建設化]]

## HBM 雙週期結構

```
傳統 DRAM → 仍遵循舊景氣循環
HBM      → 可能形成獨立、更穩定的需求週期
```

→ 一家記憶體公司可能**同時存在兩種營收週期**——對估值方法論是巨大挑戰。

## 台積電 = 範例（[[TSMC]]）

```
「晶圓代工廠」 → 「AI 基礎設施公司」
訂單式關係    → 長期合作夥伴
週期性擴產    → 基礎設施建設
景氣循環 PE   → 基礎設施類估值
```

## 三家公司的延伸案例（待後續 ingest 為 entity）

### Microsoft：四次重新定價
1. PC 時代（Windows/Office）
2. 成熟期（沒成長的現金牛）
3. SaaS/Cloud 轉型（Nadella）
4. **AI 時代（OpenAI 合作）**

### Amazon：三個飛輪
1. 電商飛輪
2. AWS 飛輪
3. **AI 基礎設施飛輪**

### Costco：透過會員制現金流實現「**永久第一階段**」
- 會員費 = 穩定可預測現金流 → 持續投資價格競爭力
- 估值倍數**長期高於同業**
- 啟示：**穩定的現金流結構可以支撐看似不合理的高估值**

## 六個重新定價指標

1. 營收結構（AI 營收佔比）
2. 合約結構（短訂單 → 長合約）
3. 客戶關係（供應商 → 策略夥伴）
4. 資本支出（週期擴產 → 基礎設施）
5. 現金流（波動 → 穩定）
6. 同業估值（vs 基礎設施類）

## 四個可追蹤的 AI 方向

1. 算力基礎設施（GPU/HBM/封裝）
2. 電力基礎設施（電源管理、資料中心電力）
3. 網路基礎設施（光通訊、高速互連）
4. 軟體基礎設施（AI 工具、模型服務平台）

## 半導體 re-rate 三階段

```
1. 敘事形成 → 2. 數據驗證 → 3. 共識確立
```

## 關鍵風險

- AI CapEx 週期結束 → 回歸景氣循環
- 供給最終追上需求
- 技術路線改變 → 顛覆供應鏈
