# FOMO SOC KP40 — 五大巨頭 Q1 2026 財報 AI 變現分歧

**作者**：KP@FOMOSoc
**發布**：2026-05-02
**來源**：[FOMO SOC 思考筆記第 40 期](https://www.fomosoc.com/p/5-kp40)
**性質**：全文公開、無付費牆

## 重點

> AI CapEx 已成「**入場資格**」、總投入 6,500-7,250 億美元無法回頭。市場開始用「**變現能見度**」而非「**雄心壯志**」區分贏家。未來 12-24 個月為「**證明給我看**」階段。

## 五大巨頭分歧矩陣

| 公司 | 變現能見度 | 市場反應 | 核心數字 |
|---|---|---|---|
| **Google** | **最高** | **大漲** | RPO $4,620 億（超 AWS）、GCP +63%、Gemini 2,800 企業客戶、TPU 2027 對外銷售 |
| **Amazon** | 中高 | 正面 | RPO $3,640 億、AWS YoY +28%（15 季最快）、自研晶片 $200 億年化 |
| **Microsoft** | 中 | 溫和 | AI 年化 $370 億（YoY +123%）、Copilot 2,000 萬席位、GitHub Copilot 6 月轉用量計費 |
| **Meta** | **最低** | **大跌** | Q1 營收 +33%、2026 CapEx 上調至 $1,250-1,450 億、元宇宙累積虧損 $830 億 |
| **Apple** | 有限 | 平穩 | 營收 $1,112 億、Services 毛利率 76.7%、$1,000 億回購、記憶體成本壓縮毛利 |

## 跟 wiki 概念的深度連結

### 強化 [[AI infra CapEx 三階段論]]
- 本期是「第一階段（CapEx 入場資格）→ 第二階段（變現能見度分歧）」轉折點 anchor
- 數字 anchor：5 家合計 CapEx $6,500-7,250 億 vs Google 4,620 億 RPO + Amazon 3,640 億 RPO = backlog 兩年能見度

### 新概念落地：**[[AI 變現能見度分歧（證明給我看階段）]]** ⭐
- KP 提出的 framework：**5 家 hyperscaler 已從「CapEx 競賽」進入「ROI 證明」**
- Google 用 backlog 解決能見度問題、Meta 用「廣告效率提升」隱晦回應、Apple 用「MacBook Neo + Services」側面證明

### 對接 [[市場四階段：懷疑／驗證／共識／反轉]]
- Google = 從**驗證 → 共識**（市場給予「清晰能見度」溢價）
- Meta = 從**共識 → 反轉**（市場質疑「內部黑箱」投資）
- Amazon = 共識（多年加速段穩定）
- Microsoft / Apple = 驗證（依賴未來訊號）

### 對接 [[預期差]]
- Google 變現能見度被低估 → 大漲（預期差正向）
- Meta 元宇宙虧損 + CapEx 黑箱被低估 → 大跌（預期差負向）
- Apple 記憶體成本壓力被低估 → 平穩待釐清

### 對接 [[賣水人選股邏輯（投資版）]]
- 5 大 hyperscaler 都是 1.6T 光模組 / HBM / 變壓器 / 散熱賣水人鏈條的買家
- **無論變現分歧結果如何、賣水人受惠不變**（即使 Meta 大跌但 CapEx 上調至 $1,250-1,450 億）

### 對接 [[控制點轉移（投資版）]]
- **Google TPU 對外銷售**（2027 對外開放）= 從內部工具升級為「**晶片供應商**」、跟 NVDA 直接競爭
- **AWS Trainium / Graviton 年化 $200 億** = 從工具升級為產品線
- → 兩家都把控制點從「應用」上移到「晶片」

### 對接 [[資訊擴散四階段]]
- 5 家分歧訊號是「**從機構到買賣方分歧**」階段
- 散戶（ETF / 媒體）尚未消化「變現能見度」框架 → 仍是 alpha 來源

## 受影響 entity

- [[Google]] — 補強「TPU 對外銷售 + Gemini 企業 + RPO 訂單積壓」（變現能見度最高）
- [[Meta]] — 補強「CapEx 上調 + 元宇宙累積虧損 + 三層 AI 系統」（市場大跌訊號）
- [[Microsoft]] — 補強「Copilot 2,000 萬席位 + GitHub Copilot 使用量計費 pivot + AI 年化 $370 億」
- [[Apple]] — 補強「MacBook Neo + Services 毛利 76.7% + $1,000 億回購 + 廢除淨現金中性」
- 待建 [[Amazon]] entity — AWS + RPO $3,640 億 + 自研晶片 $200 億年化
