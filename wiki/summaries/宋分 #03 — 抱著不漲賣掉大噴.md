# 宋分 #03 — 為什麼股票抱著都不會漲，賣掉就大噴？

[[宋分（美股送分題）]]（2026-02-21）。**這不是運氣，是對「確定性」的理解方式與市場不同**。

→ 完整概念 [[確定性門檻模型]]

## 核心洞察

> 確定性不是線性累積的，是在跨過門檻的瞬間爆發的。

```
   水位（確定性）緩慢上升 → 水壩漫過 → 瞬間湧出
   = 股價長期橫盤 → 突然暴漲
```

你在橫盤期失去耐心賣出 = 剛好錯過門檻被跨過的瞬間。

## 確定性的三個來源

1. **公司自我證明**：重複性（一次好可能是意外、連續好才是趨勢）
2. **產業確認**：第二、三家公司也確認 → 從「公司故事」升級為「產業故事」
3. **市場體制改變**：整體風險偏好轉變 → 原本被忽略的論點突然被定價

## 四個實務原則

1. **耐心是最稀缺的投資優勢**
2. **不要用股價來衡量你的論點是否正確**（股價不動 ≠ 論點錯誤）
3. **追蹤確定性的三個來源**，而非只看股價
4. **接受「提前」的成本**——太早 ≠ 錯誤，但需管理時間成本（倉位大小）
