# 宋分備忘錄 #1 — CSP / 軟體 / NVDA / AI 通縮

[[宋分（美股送分題）]] 2026-03-09 備忘錄。四個看似獨立的主題其實指向同一個問題：**AI 投資的回報何時、以何種方式兌現？**

## 四個主題

### 1. CSP 焦點從「CapEx 太高」轉向「CapEx 何時見頂」

- 焦點轉移本身就是訊號——市場已接受高 CapEx 是新常態
- 真正的催化劑：[[FCF 拐點]]
- 機構正在追蹤各 CSP 的 CapEx 增速是否放緩
- → [[CapEx 見頂辯論]]

### 2. 軟體股反彈但機構謹慎

機構需要看到三個確定性中至少兩個才會積極買入：

1. **營收成長加速**（AI 驅動是否開始貢獻）
2. **利潤率擴張**（效率優化完成、利潤趨勢上升）
3. **可見度改善**（管理層指引清晰、客戶意願回升）

沒有足夠確定性 = 反彈可能只是技術性反彈。

### 3. NVDA 盈利 38% 但股價持平

- 不是矛盾，是市場定價的本質
- **股價反映「預期變化」，不是「結果好壞」**
- 38% 符合預期 = 沒有新資訊 = 股價不動
- → [[NVDA]]、[[PE 壓縮公式]]

### Hyperscaler 預付 HBM 訂單到 2028

- 暗示 CapEx 不會短期見頂
- 對「FCF 拐點即將」的多方敘事是挑戰

### 4. AI 通縮的可能性

三條路徑（→ [[AI 通縮三路徑]]）：

1. **生產力提升**：同樣產出更少投入 → 通縮
2. **去中介化**：AI 替代中間環節
3. **商品化**：「夠好」品質常態化、溢價消失

**央行誤判風險**：AI 帶來真實通縮 → 央行寬鬆 → 資產泡沫

## 四主題交叉點

> 所有這些都指向同一個核心問題：**AI 的長期回報將以什麼形式兌現？**

- CSP CapEx 不見頂 → AI 投資持續 → 通縮壓力持續
- 軟體股缺乏確定性 → 可能是因為 AI 通縮正在壓縮軟體定價能力
- NVDA 盈利成長但股價不動 → 市場已在尋找下一個催化劑
