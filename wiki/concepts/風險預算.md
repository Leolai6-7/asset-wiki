# 風險預算

[[宋分（美股送分題）]] 在 Note #08 提出的機構與散戶根本差異：**機構用「風險單位」管理投資，散戶用「金額」**。

## 一句話

> 機構不是用「金額」管理投資，而是用「風險單位」。

## 機制

```
每個部位佔用一定的「風險預算」，而非一定的「資金」
波動率上升時，同一筆錢佔用的風險預算會增加
→ 高波動時期，機構自動減少部位大小
```

## 為什麼散戶在底部沒有錢

```
散戶沒有風險預算概念
  ↓
下跌初期就「抄底」用掉大量資金
  ↓
繼續下跌「加碼攤平」用掉更多資金
  ↓
真正底部時已沒資金可部署
  ↓
被迫在最壞時機出場或錯過反彈
```

## 機構加碼依據：風險訊號，不是價格下跌

不會因為「跌很多 = 便宜」而買入，而是觀察：

→ [[三個風險指標]]：信用利差 / VIX 結構 / 利率預期

## 散戶三錯 vs 機構三對

| 散戶（戰爭/高波動時） | 機構 |
|---|---|
| 不停刷新聞（Doom Scrolling） | 降低交易頻率 |
| 不停看價格 | 等待真正有意義的資訊 |
| 不停調整部位（試圖避險/抓底） | 保全資本（活下來 > 賺到錢） |

## 長期存活者的三個特質

### 1. 永遠不用盡所有資本
- 保留至少 **20-30% 現金或等價物**
- 市場永遠可能比想像更極端
- 保留資本 = 保留選擇權

### 2. 拉長投資時間軸
- 短期不可預測，長期均值回歸
- 讓時間成為盟友

### 3. 允許自己偶爾看錯
- 沒人能次次正確
- 建立**允許犯錯的投資系統**（分散、分批、風險管理）

## 跟 [[三個風險指標]] 的關係

風險預算 = 倉位管理的**內部紀律**
三個風險指標 = 倉位調整的**外部訊號**

兩者配對：當訊號惡化 → 風險預算自動收縮 → 部位減小（不是因為「看空」，是因為「波動率擴大」）
