# 資訊擴散四階段

[[宋分（美股送分題）]] 在 Note #05 提出的關鍵洞察：**機構和散戶買在不同的價位，不是因為資訊不對稱，而是因為他們在不同的「資訊擴散階段」做決策。**

## 四個階段

| 階段 | 誰知道 | 股價反應 |
|---|---|---|
| **1. 機構研究** | 少數機構（買方分析師調研） | 幾乎沒反應 / 細微異常量 |
| **2. 賣方升級** | 機構客戶（投行報告） | 開始明顯上漲 |
| **3. 媒體/社群擴散** | 散戶 | **股價已大幅上漲** |
| **4. ETF 被動買入** | 所有人 | 最後一波買盤 / 最貴 |

## 散戶買在高點的機制

```
資訊到散戶手上時 → 已經是階段 3 或 4 → 股價已反映機構判斷
```

不是散戶笨，是**資訊的物理擴散順序**決定了散戶永遠買在後段。

## 對應 [[市場四階段：懷疑／驗證／共識／反轉]]

- 機構研究 ≈ 懷疑期
- 賣方升級 ≈ 驗證期
- 媒體擴散 ≈ 共識期
- ETF 被動 ≈ 反轉期

## 機構判斷定價階段的訊號

1. **分析師預期修正的方向**（盈利預期上修速度加速 / 減速？）
2. **管理層指引的品質**（積極 → 保守？）
3. **邊際買家的身份**（機構 / 散戶 / 被動基金？）

> 邊際買家是被動基金 = 階段 4 = 退場時機。

## NVDA 案例（2023-2026）

| 階段 | 時期 | 特徵 |
|---|---|---|
| 1 機構研究 | 2023 初 | 少數 AI 研究者意識 GPU 需求爆發 |
| 2 賣方升級 | 2023-2024 | 財報持續超預期、目標價上調 |
| 3 媒體擴散 | 2024-2025 | 散戶大量買入 |
| 4 被動 + 反轉 | 2025-2026 | CapEx 何時見頂、估值倍數壓縮 |

→ 連到 [[NVDA]]、[[CapEx 見頂辯論]]、[[PEG Ratio 警告]]

## 下一個「階段 1」候選（Note #05）

宋分點名三個方向：

1. **能源**（AI 資料中心電力需求）
2. **電力基礎設施**（電網、變壓器、配電；訂單能見度 2028-2030）
3. **光通訊**（高速互連；早期進入者顯著優勢）

→ 跟 [[效率→安全切換]] 的「實體稀缺資產」、[[AI 受惠路徑：集中→擴散]] 接合。

## 實戰守則

- **不要在第三階段買入第一階段的價格預期**
- 要找階段 1 機會，需要自己做研究——而非等媒體告訴你
- **最好的時機永遠在「大多數人還不相信」的時候**
