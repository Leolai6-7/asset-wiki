# 賣水人選股邏輯（投資版）

llm-wiki 已有 [[賣水人選股邏輯]] 概念——asset-wiki 這版本是**投資角度**重切：在 AI 產業爆發期，**不賭誰贏，賭所有人都需要的東西**。

## 一句話

> 在產業爆發期，與其挑選勝出的終端品牌，不如買進每個玩家都必須採購的耗材、設備或檢測服務。

## 三層放大效應

```
量放大：    AI CapEx ↑ → 所有玩家都採購
規格升級：  1.6T → 3.2T → ...
平方放大：  量 × 規格升級
```

→ 賣水人受惠程度 ≫ 終端品牌。

## 「賣水人之中的賣水人」

更深一層：**不依賴任何一條技術路徑**的賣水人。

| 例 | 為什麼是賣水人之中的賣水人 |
|---|---|
| [[SiTime]] timing 元件 | CPO 誰贏都要用 timing |
| ASML 微影設備 | 任何 fab 擴產都要 |
| Cadence/Synopsys EDA | 任何晶片設計都要 |
| Cabot Microelectronics CMP | 任何先進製程都要 |

### 軟體供應鏈

## 投資操作

### 選賣水人的優勢
- **不需賭誰贏**（NVDA vs AMD？Anthropic vs OpenAI？）
- 在 [[市場四階段]] 任何階段都受惠
- 估值在「不性感」階段可入手（[[預期差]]）

### 選賣水人的劣勢
- 倍數放大不如終端贏家（NVDA 從 30 → 200x）
- 在 AI CapEx 減速時可能急跌
- → 用 [[CapEx 見頂辯論]] 框架追蹤

## ⭐ 五軸評分（codex 校準）

原本「賣水人 vs 押路線」二分法太粗糙。**真實光譜應該用五軸評分**。

⚠️ **2026-06-05 修訂**：原 15 分制（每軸 0-3）改為 **25 分制（每軸 0-5）** — subagent 校準 ABF/玻璃基板廠時用更細粒度分級，本表全面 rebase。

| 軸 | 內容 | 5 = 最高 | 0 = 最低 |
|---|---|---|---|
| **路線敏感度（逆向）** | 路線分歧的曝險（**高分代表中性 / 不敏感**） | 5 = 多路線都受惠 | 0 = 押單一路線（binary 期權） |
| **站別關鍵度** | 在製程鏈是否不可繞過 | 5 = 必經之路 | 0 = 可被替代 |
| **耗材 recurring** | 是否有重複性收入 | 5 = 化學品/耗材主導 | 0 = 一次性設備 |
| **IP 控制** | 是否擁有專利 / 標準 | 5 = 持有專利定義權 | 0 = 跟隨者 |
| **客戶分散** | 客戶結構是否分散 | 5 = 多客戶分散 | 0 = 單一客戶 |

### 關鍵發現（25 分制 rebase 後）

- **頂級真賣水人**：[[Disco Corp]] 24 / **[[村田 Murata]] 24** / [[LPKF]] 20 / [[SiTime]] 20——都是國際 / 全球玩家
- **村田 vs Disco 並列頂級**：村田是「被動元件全鏈寡占 + 三線並進（MLCC + 矽電容 + iPaS）」、Disco 是「雷射切割壟斷 + 耗材年金」
- **ABF 鏈最高並列**：[[欣興]] 19 = [[IBIDEN]] 19（IBIDEN 勝 IP、欣興勝耗材）
- **台股最強**：[[弘塑]] 19 / [[欣興]] 19 並列
- **risk-adjusted 最佳**：[[景碩]] 17——不性感但下檔保護好
- **單一客戶極端風險**：[[F&S Electron]] 13（Absolics 獨家、2026-03 合約到期 binary）
- **純跟隨者**：[[華新科]] 13（跟 F&S Electron 並列，但風險不同）
- **期權 = 低分區**：[[鈦昇]] 7 / [[雷科]] 8——買的是「路線贏 + design-in」雙重 binary
- **顯性失敗組**：[[南電]] 9——ASIC 60% 集中 + IP 弱 + 玻璃落後（**做空候選**）
- **五軸評分能讓「真賣水 vs 期權 vs displacement 受害」一目了然**
