# 賣水人選股邏輯（投資版）

llm-wiki 已有 [[賣水人選股邏輯]] 概念——asset-wiki 這版本是**投資角度**重切：在 AI 產業爆發期，**不賭誰贏，賭所有人都需要的東西**。

## 一句話

> 在產業爆發期，與其挑選勝出的終端品牌，不如買進每個玩家都必須採購的耗材、設備或檢測服務。

## 三層放大效應

```
量放大：    AI CapEx ↑ → 所有玩家都採購
規格升級：  1.6T → 3.2T → ...
平方放大：  量 × 規格升級
```

→ 賣水人受惠程度 ≫ 終端品牌。

## 「賣水人之中的賣水人」

更深一層：**不依賴任何一條技術路徑**的賣水人。

| 例 | 為什麼是賣水人之中的賣水人 |
|---|---|
| [[SiTime]] timing 元件 | CPO 誰贏都要用 timing |
| ASML 微影設備 | 任何 fab 擴產都要 |
| Cadence/Synopsys EDA | 任何晶片設計都要 |
| Cabot Microelectronics CMP | 任何先進製程都要 |

## 2026 AI 賽道的賣水人圖譜

### 算力供應鏈
- **晶圓代工**：[[TSMC]]、[[Intel]] foundry
- **設備**：ASML、AMAT、KLAC、LRCX
- **EDA**：Cadence、Synopsys
- **timing / 類比 IC**：[[SiTime]]、MPS、ADI、TXN
- **HBM**：SK Hynix、Samsung、Micron

### 電力供應鏈
- 電力產出：Vistra、Constellation
- 變壓器：GE Vernova

### 軟體供應鏈
- 觀察性：Datadog、Snowflake
- 資安：[[AI-SPM]] 賽道（CRWD、PANW、NET、ZS、Wiz）

## 投資操作

### 選賣水人的優勢
- **不需賭誰贏**（NVDA vs AMD？Anthropic vs OpenAI？）
- 在 [[市場四階段]] 任何階段都受惠
- 估值在「不性感」階段可入手（[[預期差]]）

### 選賣水人的劣勢
- 倍數放大不如終端贏家（NVDA 從 30 → 200x）
- 在 AI CapEx 減速時可能急跌
- → 用 [[CapEx 見頂辯論]] 框架追蹤

## ⭐ 五軸評分（codex 校準）

原本「賣水人 vs 押路線」二分法太粗糙。**真實光譜應該用五軸評分**，每軸 0-3 分：

| 軸 | 內容 | 高分代表 | 低分代表 |
|---|---|---|---|
| **路線敏感度** | 公司會不會因技術路線分歧消失 | 0 = 多路線都受惠（中性） | 3 = 押單一路線（binary） |
| **站別關鍵度** | 在製程鏈是否不可繞過 | 3 = 必經之路 | 0 = 可被替代 |
| **耗材 recurring** | 是否有重複性收入 | 3 = 化學品/耗材主導 | 0 = 一次性設備 |
| **IP 控制** | 是否擁有專利 / 標準 | 3 = 持有專利定義權 | 0 = 跟隨者 |
| **客戶集中度** | 客戶結構是否分散 | 3 = 分散多客戶 | 0 = 單一客戶 |

### 範例評分（TGV 賽道）

| 公司 | 路線敏感 | 站別關鍵 | 耗材 recurring | IP 控制 | 客戶分散 | **總分** | 定位 |
|---|---|---|---|---|---|---|---|
| [[弘塑]] | 0（多路線） | 2 | 3（化學品） | 1 | 3 | **9/15** | **真賣水人** |
| [[辛耘]] | 0 | 2 | 2（晶圓再生） | 1 | 2 | 7/15 | 中性賣水 |
| [[萬潤]] | 1 | 3（後段壟斷） | 0 | 1 | 2 | 7/15 | 後段同步 |
| [[鈦昇]] | 3（押路線） | 3 | 0 | 1（vs LPKF 弱） | 0（Intel 集中） | **7/15** | **期權** |
| [[雷科]] | 3 | 3 | 0 | 1（vs Disco 弱） | 1 | 8/15 | 期權 |
| [[LPKF]] | 0 | 3 | 1 | **3（LIDE 專利）** | 2 | **9/15** | **真賣水（IP）** |
| [[Disco Corp]] | 0 | 3 | **3（耗材年金）** | 2 | 3 | **11/15** | **真賣水（壟斷）** |
| [[SiTime]] | 0 | 2 | 2 | 2 | 3 | 9/15 | 真賣水 |

### 關鍵發現

- **真正的「賣水人」是 [[Disco Corp]]、[[LPKF]]、[[弘塑]]、[[SiTime]]**——多軸都拿高分
- **台股 TGV 押路線玩家（[[鈦昇]] / [[雷科]]）不是真賣水人，是「期權」**——路線敏感度太高
- **五軸評分能避免「binary 押路線誤讀為賣水人」的盲點**
