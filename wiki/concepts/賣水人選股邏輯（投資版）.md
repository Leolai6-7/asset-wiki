# 賣水人選股邏輯（投資版）

> ⚠️ **#P11 單一真值政策**：本檔所有五軸分數為**建檔時快照**、現值一律以各 entity 為準（entity 是分數唯一真值）；歷史波次表不回頭同步、衝突時 entity 勝。

llm-wiki 已有 [[賣水人選股邏輯]] 概念——asset-wiki 這版本是**投資角度**重切：在 AI 產業爆發期，**不賭誰贏，賭所有人都需要的東西**。

## ⚠️ 雙評分體系（K1 codex 質疑落地、2026-06-09 補位）

從 #K1 開始本表採用 **[[結構影響分 vs 可投資五軸分（雙評分體系）]]**：

- **結構影響分**（25 分制）：適用所有 entity（含 [[Imec]] 24 / [[FOMO SOC]] 22 / [[Cameron LNG]] 19 / [[Tellurian]] 18 等不可投資 entity）
- **可投資五軸分**（25 分制）：只適用上市可獨立投資 entity（**排除** KOL / consortium / 私募未 IPO / 已下市 / 子公司無獨立 ticker、欄位填 `n/a`）

**解決 thesis 矛盾**：[[Imec]] / [[FOMO SOC]] / [[Cameron LNG]] / [[Tellurian]] 不再進可投資 ranking 池。

⚠️ **本表所有 entity「總分」欄位 = 可投資五軸分**；不可投資 entity 標 `n/a` + 註明原因；結構影響分另外列在跨戰場 anchor 矩陣 [[6 戰場交集圖譜]] 使用。

## ⚠️ confidence gate（K1 落地）

從 #K1 開始本表採用 **[[五軸分數 confidence gate（低信心給區間 + thesis-dependent flag）]]**：

- **high**：精確分（如 ASML 25、Disco 24）
- **medium**：精確分 + review trigger
- **low**：**區間 + thesis-dependent flag**（如 [[IQE]] **15-19/25**、看飛利浦 design-in 確認窗口）

⚠️ 假精度比沒有分數更危險、區間給法是對讀者誠實的最低標準。

## 一句話

> 在產業爆發期，與其挑選勝出的終端品牌，不如買進每個玩家都必須採購的耗材、設備或檢測服務。

## 三層放大效應

```
量放大：    AI CapEx ↑ → 所有玩家都採購
規格升級：  1.6T → 3.2T → ...
平方放大：  量 × 規格升級
```

→ 賣水人受惠程度 ≫ 終端品牌。

## 投資操作

### 選賣水人的優勢
- **不需賭誰贏**（NVDA vs AMD？Anthropic vs OpenAI？）
- 在 [[市場四階段]] 任何階段都受惠
- 估值在「不性感」階段可入手（[[預期差]]）

### 選賣水人的劣勢
- 倍數放大不如終端贏家（NVDA 從 30 → 200x）
- 在 AI CapEx 減速時可能急跌
- → 用 [[CapEx 見頂辯論]] 框架追蹤

## ⭐ 五軸評分（codex 校準）

原本「賣水人 vs 押路線」二分法太粗糙。**真實光譜應該用五軸評分**。

⚠️ **2026-06-05 修訂**：原 15 分制（每軸 0-3）改為 **25 分制（每軸 0-5）** — subagent 校準 ABF/玻璃基板廠時用更細粒度分級，本表全面 rebase。

| 軸 | 內容 | 5 = 最高 | 0 = 最低 |
|---|---|---|---|
| **路線敏感度（逆向）** | 路線分歧的曝險（**高分代表中性 / 不敏感**） | 5 = 多路線都受惠 | 0 = 押單一路線（binary 期權） |
| **站別關鍵度** | 在製程鏈是否不可繞過 | 5 = 必經之路 | 0 = 可被替代 |
| **耗材 recurring** | 是否有重複性收入 | 5 = 化學品/耗材主導 | 0 = 一次性設備 |
| **IP 控制** | 是否擁有專利 / 標準 | 5 = 持有專利定義權 | 0 = 跟隨者 |
| **客戶分散** | 客戶結構是否分散 | 5 = 多客戶分散 | 0 = 單一客戶 |
