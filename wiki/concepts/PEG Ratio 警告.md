# PEG Ratio 警告

由 [[宋分（美股送分題）]] 在 Note #9 重新定義的 PEG 用法：

> **PEG < 1 不自動代表便宜，它是「警告訊號」而非「買入指標」。**

## 公式

```
PEG = PE ÷ 預期成長率
```

## 反直覺解讀

- 傳統解讀：PEG < 1 = 成長被低估 → 買入
- 宋分解讀：PEG < 1 **代表市場對成長持續性有懷疑**——不然 PE 不會這麼低相對成長率

## NVDA 範例（Notes #4、#10）

NVDA **PEG = 0.37**

- 傳統角度：超便宜
- 宋分角度：市場**把 NVDA 當循環股而非成長股看**——
  - 2026 有信心
  - 2027 存疑（**NVDA 的赤字不是數據，是時間**）

## 估值三步驟（Note #9）

PEG 在宋分工具鏈中的正確位置：

```
1. DCF        → 確認內在價值（下檔保護）
2. PEG        → 識別錯配（警告）
3. Forward PE → 預測目標價（時機）
```

PEG 不是進場訊號，是檢查清單裡的一格。

## 大漲時點

> **大漲常在「認知從懷疑轉向相信」時發生**，不是盈餘驚喜。

當 PEG 從「警告」變成「重新定價中」（市場開始相信成長持續性），PE 倍數擴張 → 股價漲。
