# 控制點轉移（投資版）

llm-wiki 已有 [[控制點轉移]] 概念框架——asset-wiki 這版本是**投資角度**重切：**追蹤「誰控制關鍵節點」的移動**，並用控制點位置決定估值溢價。

## 一句話

> 所有優勢都是暫時的；估值溢價跟著控制點走。

## 三層控制點

```
1. 物理層（晶圓、製造、能源、土地）
2. 平台層（CSP、模型、雲算力）
3. 協議/接口層（MCP、API 標準、業務流程）
```

**控制點越上層 = 護城河越深 = 估值溢價越高**。

但**控制點會移動**——這就是「轉移」。

## 2026 Q1-Q2 觀察到的轉移

| 從 | 到 | 案例 |
|---|---|---|
| TSMC 比較利益 | 自建 fab | [[Intel]] Terafab、[[華為]] 昇騰 |
| 模型品質 | **接口協議** | [[Anthropic]] MCP |
| API 提供 | 託管 agent 平台 | Anthropic Managed Agents |
| 搜尋 | 答案層（AEO） | [[Google]] 防守 |
| 賣晶片 | 賣完整堆疊 | [[NVDA]] CUDA + TensorRT + Groq |

## 估值含意

控制點搶到的公司**獲估值溢價**：

- [[Anthropic]]：拿 MCP → 從「AI 模型公司」變「[[AI 作業系統公司]]」
- [[Intel]]：拿 Terafab anchor → 從失敗 IDM 變美國產能政治受惠者
- [[NVDA]]：CUDA 鎖定 → 推理市場護城河

控制點失去的公司**估值壓縮**：

- [[OpenAI]] 失去接口（MCP 跟隨者）→ 模型層商品化暴露
- 純模型公司（無 CSP、無協議、無接口）→ 全面壓縮

## 投資操作

| 看到 | 動作 |
|---|---|
| 公司搶到新控制點 | 觀察 [[市場四階段：懷疑／驗證／共識／反轉]] 還在懷疑期 → 進場 |
| 控制點受威脅 | [[看錯三類型]] 中「公司競爭力看錯」訊號 → 換股 |
| 控制點完全失去 | 「產業方向看錯」訊號 → 果斷退出 |
