# 6 戰場交集圖譜

把 wiki 既有 8 個戰場（TGV / MLCC / CPO / DCI / 電力 / 散熱 / 3D NAND / 800V HVDC）的**跨戰場玩家**整理成矩陣——同一家廠跨幾個戰場 = 風險分散 / 結構性受惠倍增 / 估值溢價。

→ 跟 [[賣水人選股邏輯（投資版）]] 的「**單戰場最佳選**」互補：本 concept 是「**跨戰場 anchor 選**」、那個是「**單戰場 niche specialist 選**」。

## 一句話

> 一家公司跨幾個戰場 = 結構性受惠倍增 + 路線敏感度更低 + 估值溢價合理。**跨 2-3 戰場 = anchor 候選 / 跨 1 戰場 = niche specialist / 跨 0 戰場 = 不投**。

## ⭐ 跨戰場矩陣的「**雙刃劍**」現象

跨戰場越多 = 結構性受惠倍增 + 但也有兩個風險：
1. **整合風險上升**：跨戰場意味著經營複雜度倍增（如 Synopsys + Ansys 35B 整合 / [[鴻海 2317|鴻海]] + 群創整合）
2. **估值不一定溢價**：市場可能用「**集團折價**」估值（Hitachi PE 15-18 vs GE Vernova PE 35-40）

→ 跨戰場 anchor 的 alpha 來源是「**Sum-of-Parts vs 集團折價**」差距。

## ⭐ 配置思路：跨戰場 anchor + 單戰場 niche specialist 雙軌

| 軌 | 角色 | 例子 | 倉位邏輯 |
|---|---|---|---|
| **跨戰場 anchor 軌** | 防守 + 多受惠 | [[Vertiv]] + [[Schneider Electric]] + [[Eaton]] + [[Hitachi]] + [[信越化學]] + [[Synopsys]] + [[Apple|Apple Inc.]]（Edge AI 終端品牌） | 底倉 anchor、5-10% 配置每家 |
| **單戰場 niche specialist 軌** | 高 alpha + 純度 | [[信昌電]] + [[雙鴻]] + [[高力 8996|高力]] + [[SiTime]] + [[AEHR]] + [[Lumentum]] + [[Coherent]] + [[Disco Corp]] | 衛星 alpha、2-5% 配置每家 |

→ 「**anchor + niche 雙軌**」可同時拿到「**結構性受惠倍增 + 純度 alpha**」、不必選邊。
