# 修正三階段

由 [[宋分（美股送分題）]] 在備忘錄 #4 提出的修正進程識別：**最後階段是「最強股票被無差別拋售」**。

## 三階段順序

```
Phase 1：垃圾股先跌
Phase 2：一般股跟跌
Phase 3：最強股票終於被賣 ←─ 投降式賣壓 / 修正尾聲
```

## 為什麼 Phase 3 是訊號

- 最強股票的持有者**最後才投降**
- 當連最強都被無差別賣出 → 持有者已經不再堅持
- 這種「**最後的投降**」通常是修正尾聲
- 歷史上，**優質股被無差別拋售時，底部通常已經不遠**

## 修正尾聲 ≠ 立刻反彈

備忘錄 #4 強調：

> 修正尾聲 = 風險報酬比改善，不是立刻反彈訊號

## 同步出現的兩個訊號

備忘錄 #4 提到修正尾聲常伴隨：

### 1. 反向定價開始浮現
- 油價過度悲觀（供給端結構問題被低估）
- 利率預期過於鷹派
- 被錯殺板塊跌破合理估值

### 2. AI 通縮交易才剛開始
- 稀缺實體資產 / 算力即價值 / 人類真實性溢價（見 [[AI 通縮三路徑]]）

## 與 [[散戶 vs 機構買股差異]] 的連結

- **散戶**：Phase 3 投降 → 認賠
- **機構**：Phase 3 開始「**換手**」——從恐慌賣家到價值買家

## 與 [[三個風險指標]] 的連結

修正尾聲需要用三指標確認**不是真正的危機**：

- 信用利差：是擴大成系統風險，還是穩定下來？
- VIX 結構：短期飆但長期沒升 = 暫時恐慌
- 利率預期：殖利率下降 = 衰退恐懼 / 穩定 = 僅情緒調整

「**新聞仍混亂 + 技術面看弱 + 多數人仍懷疑**」= 真正底部的特徵（Note #16）
