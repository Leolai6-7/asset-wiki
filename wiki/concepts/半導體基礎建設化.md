# 半導體基礎建設化

[[宋分（美股送分題）]] 在 Note #10、#13 提出的估值框架轉變假說：**AI 正在從根本改變半導體產業的本質——從景氣循環產業轉向長期基礎設施**。

## 一句話

> 如果半導體真的從「景氣循環」變「基礎設施」，估值框架需要全面重寫。

## 估值框架的轉變

| | 舊框架（景氣循環） | 新框架（基礎設施） |
|---|---|---|
| 估值 | 週期平均 PE | DCF / 基礎設施類估值 |
| 操作 | 用高點 PE 買、低點 PE 賣（逆週期） | 長期持有 |
| 倍數 | 18-25x | 30-50x+ |

## 六個重新定價指標（Note #10）

機構觀察的轉換訊號：

1. **營收結構改變** — AI 相關營收佔比持續上升
2. **合約結構改變** — 從短期訂單 → 長期合約
3. **客戶關係改變** — 從供應商 → 策略夥伴
4. **資本支出性質改變** — 從週期性擴產 → 基礎設施投資
5. **現金流品質改變** — 從波動 → 穩定可預測
6. **同業估值比較** — 相對於基礎設施類公司的估值差距

## HBM 的雙週期結構

```
傳統 DRAM    → 仍遵循舊景氣循環
HBM         → 可能形成獨立的、更穩定的需求週期
```

→ 一家記憶體公司可能**同時存在兩種營收週期**——對估值方法論是巨大挑戰。

## 類比 IC 的角色轉變（Note #13）

| | 傳統角色 | AI 時代新角色 |
|---|---|---|
| 在電子產品中的位置 | 配角（電源/訊號/感測） | **AI 基礎設施關鍵元件** |
| 營收依賴 | 終端景氣循環 | 資料中心電源管理 |
| 估值 | 週期平均 PE | 結構性重估 |

### AI 資料中心電源管理需求

- 單一 AI 伺服器功耗是傳統的數倍至十倍
- 每代 AI 晶片對電源管理要求**指數增長**
- 電源管理複雜度創造**高進入門檻**

### TXN vs ADI 比較維度

| | TXN | ADI |
|---|---|---|
| 規模 | 全球最大類比之一 | 高效能領域領先 |
| 資本支出 | 自有 300mm 晶圓廠（infra 思維） | 高價值/高毛利導向 |
| 策略 | 長期成本優勢 | 併購 + AI 電源佈局 |

關鍵比較：AI 營收佔比 / 資本支出策略 / 客戶集中度 / 毛利率與 FCF 趨勢

## 重新定價三階段（Note #10）

```
1. 敘事形成（少數分析師調框架）
2. 數據驗證（財報驗證結構改變）
3. 共識確立（多數接受新框架、估值倍數完成轉換）
```

## 關鍵風險

- **AI CapEx 週期結束** → 半導體可能回歸傳統景氣循環
- **供給最終追上需求** → 打破結構性稀缺論述
- **技術路線改變** → 顛覆現有供應鏈

## 跟 [[HBM iPhone moment]] 的關係

HBM iPhone moment = 半導體基礎建設化在 HBM 子領域的具體實現。
本 concept = 更大的框架，包含 GPU / 類比 IC / 光通訊等多領域。

## 跟 [[PB 估值法（記憶體週期）]] 的張力

PB 估值法說「週期不會消失」，半導體基礎建設化說「結構性轉變」。
**兩派並陳**，投資者要持續用六個重新定價指標追蹤誰是對的。

## 待 ingest 的延伸案例（Note #10）

- **Microsoft**：四次重新定價循環（PC / 雲端轉型 / SaaS / AI）
- **Amazon**：三個飛輪（電商 / AWS / AI 基礎設施）
- **Costco**：會員制現金流 → 永久第一階段

## 跟「半導體基礎建設五大 chokepoint」的關係

跟既有的「半導體基礎建設化」思維配套——五個 chokepoint 都受惠：

| Chokepoint | 代表 | 五軸 | 角色 |
|---|---|---|---|
| **微影設備** | ASML | — | EUV + High-NA EUV 壟斷、任何 fab 擴產都要 |
| **矽晶圓** | [[信越化學]] + [[SUMCO]] | 24 + 24 | 雙頭壟斷 55-60%、任何 fab 都要矽 substrate |
| **切割設備** | [[Disco Corp]] | 24 | 60-70% 切割研磨壟斷 + 耗材年金 |
| **R&D 公共財** | [[Imec]] | 24 ⚠️ 特殊 | 200+ 會員、pre-competitive R&D 中立平台 |
| **EDA 設計工具** | [[Synopsys]] + [[Cadence]] + [[Siemens]] EDA | 24 + 22 + — | **三巨頭 78% 寡占、任何晶片設計都繞不開**——詳見 [[EDA 三巨頭分食（Synopsys／Cadence／Siemens EDA）]] |

⭐ **EDA 是「設計層」chokepoint**——比矽晶圓 / 光阻劑 / 切割設備更上游（晶片還沒生產就先用 EDA 設計）、比 Imec R&D 更實作（Imec 是 pre-competitive R&D、SNPS + CDNS 是商業生產用工具）
