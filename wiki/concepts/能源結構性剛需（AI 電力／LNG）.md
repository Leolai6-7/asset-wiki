# 能源結構性剛需（AI 電力／LNG）

[[宋分（美股送分題）]] #20 三標準（**長期供給結構改變 + 持續 CapEx + 可持續現金流**）落地 AI infra 電力戰場 + LNG 出口賽道——把「**結構性需求**」跟「**週期性需求**」拆開、定義什麼樣的能源 entity 配得上「結構性 re-rate」。

## 一句話

> 結構性能源 ≠ 週期性能源——AI 電力 + LNG 出口因為「需求剛性 + 多年合約 anchor + CapEx 不可逆」三條件全滿、是少數可長期重估的能源賽道。

## 宋分 #20 三標準

[[宋分備忘錄 ＃3 — AI 半導體受惠者擴散]] 提到 #20 三標準辨識「結構性 re-rate」：

| 標準 | 內容 | 失敗條件 |
|---|---|---|
| **1. 長期供給結構改變** | 供給端發生不可逆變化（如 hyperscaler PPA 鎖死多年產能、LNG 出口需 5-10 年建廠）| 短期波動回到均值 |
| **2. 持續 CapEx** | 投資需求持續放大、不會在 2-3 年見頂 | CapEx 見頂、ROI 收斂 |
| **3. 可持續現金流** | 不靠 commodity 價格暴漲、靠合約 / 規格鎖定 | 商品價格決定論 |

→ **三條件全滿** = 配得上結構性 re-rate（Forward PE 從 10-12x → 18-25x）
→ **缺一條** = 仍是週期性、PB 估值或 commodity 倍數適用

## AI 電力戰場落地

### 三條件對照表（utility）

| 公司 | 長期供給結構改變 | 持續 CapEx | 可持續現金流 | 落地 |
|---|---|---|---|---|
| **[[Vistra]]** | ✅ Meta 2.6GW + AWS PPA 多年鎖死 | ✅ 核電 + 氣電持續擴 | ✅ PPA 20+ 年現金流 | **三條件全滿、結構性 re-rate**（五軸 23/25）|
| **[[Constellation Energy]]** | ✅ MSFT TMI 政治焦點 + Calpine 26GW 整合 | ✅ 核電 32.4GW 持續運轉 | ✅ PPA + ZEC 多年鎖定 | **三條件全滿、結構性 re-rate**（五軸 22/25）|
| **[[NRG Energy]]** | ✅ ERCOT firm power 鎖定 + 三客戶 PPA | ✅ 氣電 + 零售雙線 | ✅ 零售合約 + capacity payment | **三條件全滿、結構性 re-rate**（五軸 21/25）|

→ Vistra / Constellation / NRG 三家是 AI 電力戰場「**結構性 re-rate 三選一**」。

### 對比週期性 utility 失敗組

| 公司 | 哪一條失敗 | 為什麼仍週期性 |
|---|---|---|
| 舊式 utility（regulated only）| ✗ 長期供給結構未改變 | PPA 短、commodity 價格驅動 |
| 純煤電 utility | ✗ 持續 CapEx 反向（去煤）| CapEx 收斂、退煤資產減損 |
| 純綠電 utility（無 firm power）| ✗ 可持續現金流（綠電出力波動）| ITC / PTC 政治紅利依賴 |

→ 「**firm power**」（核電 + 氣電 + LNG）是 AI 電力剛需的關鍵特徵。

## LNG 出口賽道落地

### 三條件對照表（LNG）

| 公司 | 長期供給結構改變 | 持續 CapEx | 可持續現金流 | 落地 |
|---|---|---|---|---|
| **[[Cheniere Energy]]** | ✅ SPL + CCL 55 MTPA + 歐亞長約 | ✅ Stage 3 持續擴建 | ✅ **SPA 80% 長約 + Henry Hub +115% 公式** | **三條件全滿、結構性 re-rate**（五軸 22/25）|
| **[[Sempra LNG]]**（Sempra 子公司）| ✅ Cameron + Port Arthur 多廠擴張 | ✅ Cameron T4 + ECA Phase 2 | ✅ 長約 + utility 子公司現金流支撐 | **三條件大致全滿、結構性 re-rate**（五軸 19/25）|
| **[[Woodside Energy]]** | ✅ 澳洲 NWS + Pluto + Scarborough + Driftwood | ✅ Tellurian 收購 + Phase 1 建設 | ✅ 油氣 25% 混合 + 多年合約 | **三條件大致全滿**（五軸 20/25）|

### LNG 三家差異化

| 公司 | 結構性優勢 |
|---|---|
| **Cheniere** | 美國 LNG 出口 #1 + Forward PE 12-15x 估值乾淨 + 純度高 |
| **Sempra LNG** | 多廠擴張 + Cameron 子公司結構（[[Cameron LNG]] reference）+ utility 母公司現金流支撐 |
| **Woodside** | 澳洲 LNG operator #1 + 跨大洋 sovereign 分散 + 美澳雙路徑 + 油氣 25% 混合 |

→ 三家構成 **LNG 結構性 re-rate 三選一**，跟 utility firm power 三家並列「AI infra 電力戰場 firm power 第五選擇」。

## 為什麼 LNG 算 firm power 第五選擇

`firm power 四選一`原本：核電（Vistra / Constellation）+ 氣電（Vistra / Talen）+ 變壓器（GE Vernova）+ SOFC（Bloom Energy）

但 LNG 是「**境外 firm power 對應方**」：
- 美國 hyperscaler PPA 鎖內陸氣電
- 歐洲 / 日本 / 韓國 hyperscaler 沒辦法直接買美國氣電 → 改買 LNG（同一氣源、出口型態）
- **跨地理結構性 firm power 對接** = LNG 是 firm power 的境外 anchor

→ Cheniere / Sempra / Woodside 是境外 firm power 三家。

## 對「commodity 價格決定論」的反證

傳統 LNG / utility 觀點：價格決定盈利，週期性。

宋分 #20 反證：合約 anchor + CapEx 鎖定 + 供給結構改變 ≠ commodity 暴漲依賴。

| 證據 | 內容 |
|---|---|
| **Cheniere Henry Hub +115% 公式** | SPA 合約定價公式、不靠 spot price 波動 |
| **Vistra Meta 2.6GW** | 20+ 年 PPA 鎖定、不靠 ERCOT spot price |
| **MSFT TMI PPA** | 多年合約、不靠 PJM spot price |
| **Woodside Pluto** | 長約 + 跨大洋出貨、不靠單一市場 spot |

→ **合約 anchor + 長期 supply structure 改變** 把 commodity 公司轉成「**結構性 service 公司**」估值範式。

## 不適用的能源 entity

| Entity | 為什麼不適用結構性 re-rate |
|---|---|
| 舊式 regulated utility | 第一條失敗 |
| 純再生能源（無 firm power）| 第一條 + 第三條失敗 |
| LNG terminal 純運營商（無上游氣源 / 無長約）| 第一條失敗 |
| Driftwood LNG（Tellurian 已被 Woodside 收購）| 結構整合中、五軸 n/a |

## 對 hyperscaler 估值的暗示

如果三家 utility + 三家 LNG 配得上結構性 re-rate（Forward PE 18-25x）、則：
- hyperscaler CapEx 投入 firm power = 結構性投入（vs 一次性費用）
- hyperscaler 計入的「電力成本」應該用 ROI 計算（[[Forward PE 估值法]] 對應 ROIC）、不是 OpEx 一次性
- → 對 [[Microsoft]] / [[Amazon]] / [[Google]] / [[Meta]] / [[Oracle]] 估值有結構性向上 implication

## 何時要重檢

- AI CapEx 見頂訊號（[[CapEx 見頂辯論]]）→ 第二條失敗、re-rate 撤回
- hyperscaler 從多年 PPA 改回 spot 採購 → 第一條失敗
- LNG SPA 公式被打破（如 spot 完全取代）→ 第三條失敗
