# FCF 拐點

由 [[宋分（美股送分題）]] 反覆強調的 CSP（雲端服務商）估值催化點：**真正觸發估值重新定價的不是 CapEx 見頂本身，而是 FCF（自由現金流）開始改善**。

## 一句話

> CSP 的估值催化劑是 FCF 拐點，不是 CapEx 見頂。

## 機制

```
CapEx 成長放緩  +  營收持續成長
                ↓
            FCF 開始改善
                ↓
        市場用新框架重新定價
                ↓
            估值 re-rate
```

## 為什麼不是 CapEx 見頂

- 「CapEx 見頂」是一個未來預期，市場可能提前定價（如 NVDA 38% 盈利成長但股價持平）
- 「FCF 改善」是已實現的現金流數據，是 hard fact
- 「Hyperscaler 預付 HBM 訂單到 2028」說明 CapEx 短期不會見頂——更需要看 FCF

## 與 [[CapEx 見頂辯論]] 的差別

| | CapEx 見頂 | FCF 拐點 |
|---|---|---|
| 性質 | 預期 | 已實現 |
| 訊號可靠性 | 容易誤判（會反覆） | 較硬 |
| 市場反應 | 提前定價 | 觸發 re-rate |

## 待 ingest 連到

- [[CSP 永動機]]（備忘錄 #3：CapEx → 服務 → 經常性收入 → 現金流 → 再 CapEx 循環）
- 各 CSP 的 FCF 追蹤（Amazon AWS / Microsoft Azure / Google GCP）
