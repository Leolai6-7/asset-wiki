# 三個風險指標

由 [[宋分（美股送分題）]] 在 Notes #16、#19 反覆使用的市場風險判讀框架：**用信用利差、VIX 結構、利率預期三個指標區分「反彈 vs 真底部 vs 系統風險」**。

## 三個指標

| 指標 | 訊號邏輯 |
|---|---|
| **信用利差** | 擴大 = 風險上升；穩定 = 情緒波動非系統風險 |
| **VIX 結構** | 短期飆高但長期沒升 = 暫時恐慌；雙端齊升 = 系統風險 |
| **利率預期** | 殖利率下降 = 衰退恐懼；穩定 = 僅情緒調整 |

## 真正底部的特徵（Note #16）

```
新聞仍混亂  +  技術面看弱  +  多數人仍懷疑
```

三個都齊 = 大概率底部。

## 三種市場狀態判讀

### A. 反彈 ≠ 新多頭
- 信用利差穩定、VIX 短飆長平、殖利率穩
- 「情緒事件」而非結構

### B. 真底部
- 三指標都進入「重新定價」階段但**未崩潰**
- 新聞混亂 + 多數人懷疑

### C. 系統風險
- 信用利差擴大
- VIX 雙端齊升
- 殖利率下降（衰退恐懼）

## 實戰：2026-03-20 解讀（Note #19）

當時三指標讀數：

- 信用利差：**1 月底 2.68 → 3.27**（方向轉了，但非危機）
- **VIX ≈ VIX3M**：市場不再當短期事件，而是定價「延長的不確定性」
- 10 年期殖利率上升至 **4.39%**（真正恐慌時殖利率應下降，現在股跌+利率升 = 定價 **higher for longer**）

→ 結論：**不是底部也不是崩盤，是「風險重新定價」**。

## 機構三動作（同 Note #19）

當市場進入風險重新定價時：

1. **降低犯錯成本**（縮小單筆部位）
2. **保持彈性**（保留現金/可調整）
3. **等確認訊號才擴大部位**
