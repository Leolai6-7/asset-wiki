# AI 廣告信任危機

聊天機器人廣告 vs 搜尋廣告的根本不同：**同一公司既當答案提供者又當廣告主 = 不可分離的利益衝突**。20 年信任契約被 2 年打碎。

## 一句話

> Google 搜尋的 20 年信任契約 → AI 聊天兩年打碎。

## 為什麼根本不同

### 傳統搜尋廣告（可信任的分離）
```
用戶 → Google 搜尋 → 結果頁（自然 + 廣告）
                       ↑       ↑
                    答案層    廣告層
                    被分離標示
```
**廣告 ≠ 答案**——用戶知道哪個是廣告。

### AI 聊天廣告（不可分離）
```
用戶 → ChatGPT → 答案文字流
                   ↑
            廣告 嵌入 答案
```
**廣告 = 答案**——用戶**無法區分**。

## 階級化污染

```
聊天機器人 → 推薦引擎 → 搜尋排名 → 內容創作 → 真實世界
```

GPT 已產生 **94% 推薦引擎污染**（2026 Q1 數據）。

→ 不只是廣告問題，是**整個資訊流的可信度問題**。

## 受影響的個股

### 受害最深
- **[[Google]]**：搜尋 query 流失 + 搜尋廣告 inventory 下降
- **[[Meta]]**：推薦廣告依賴用戶信任
- 廣告分發中介（Trade Desk、AppLovin）

### 並存機會
- **[[Google]]**：Gemini + AI Overviews 抓住答案層 → 仍是廣告分發龍頭
- AEO（Answer Engine Optimization）取代 SEO → 新工具賽道

### 受惠
- **新興 AEO 公司**（待 ingest entity）
- 內容信任認證業（如 Adobe Content Credentials）
- [[Anthropic]]（不做廣告 = 信任優勢）

## 對廣告 ARPU 的衝擊

```
傳統搜尋廣告 ARPU = 高（用戶信任 + 高轉換率）
AI 聊天廣告 ARPU = ?
- 若無信任：低（用戶警覺、轉換差）
- 若維持信任：可能更高（個人化深度）
- 但維持信任的成本是「禁止利益衝突」 = 商業模式根本問題
```

## 三種可能演化

| 路徑 | 對 Google 含義 |
|---|---|
| **AI 廣告監管化** | 政府介入、利益衝突被禁 → Google 重新拿回控制權 |
| **完全分離化** | AI 答案與廣告完全分流 → AEO 賽道暴漲 |
| **用戶習慣 AI 廣告** | 信任契約重建 → Google ARPU 維持 |
