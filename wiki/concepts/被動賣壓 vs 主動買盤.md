# 被動賣壓 vs 主動買盤

[[宋分（美股送分題）]] 在 Note #15 拆解市場止跌機制：**賣壓不是一種力量，是多種機制的疊加**。理解每種機制的觸發條件與結束時間，才能判斷市場何時止跌。

## 兩種力量

| 被動賣壓（CTA/ETF） | 主動買盤（機構選擇） |
|---|---|
| 程式化系統性賣出 | 基於基本面研究的選擇性買入 |
| 不區分個股品質 | 選擇性承接特定股票 |
| 觸發技術性賣出 → 所有股票一起被賣 | 在價格扭曲中對沖被動賣壓 |
| 與基本面無關 | 跟 [[抗跌清單]] 直接相關 |

## 內部人賣出機制（不算被動）

### 10b5-1 計劃
- 高管預先設定的自動賣出計劃
- 即使公司前景良好也按計劃執行
- **投資者常誤讀為「內部人看空」**

### 禁售期（Blackout）
- 財報前後 2-4 週開始、公布後 1-2 天結束
- 禁售期結束後可能集中賣出

### 揭露要求
- Form 4：交易後 2 個工作日內申報
- 13F：機構每季揭露持股
- → 追蹤機構動向的重要工具

## 被動賣壓的四個來源

| 來源 | 觸發機制 |
|---|---|
| **1. ETF/被動基金** | 投資者贖回 → 基金賣底層；負向回饋循環 |
| **2. 退休金/主權基金** | 資產配置再平衡（股票漲後超標 → 自動賣股買債） |
| **3. 對沖基金** | 風險模型觸發強制減倉、Margin call |
| **4. 企業回購暫停** | 財報禁售期間少了一個買家 |

## 機構買入的三階段（市場止跌）

當賣壓消退，機構建倉遵循明確順序：

```
1. 大型股先行（藍籌/產業龍頭）
   ↓
2. 成長股跟進（重新為成長付溢價）
   ↓
3. 高 Beta 股最後（風險偏好完全恢復）
```

## 市場止跌的順序訊號

對應上述順序：

1. **大型股先止跌** — 大型藍籌不再創新低 = 第一個止跌訊號
2. **成長股止跌** — 市場開始重新為成長付溢價
3. **高 Beta 股反彈** — 風險偏好完全恢復 = 修正結束

## 連到流動性錯誤定價（[[複利測試]]）

宋分備忘錄 #5 提到「流動性錯誤定價才是真正機會」——本 concept 是那個論點的具體機制：

- 被動賣壓 = 流動性錯誤定價的來源
- 主動買盤 = 在錯誤定價中建倉
- **長期投資者的真正機會**

## 跟 [[抗跌清單]] 的關係

- 抗跌股 = **主動買盤對沖被動賣壓**的結果
- 抗跌清單 = 主動買盤布局的可見證據
