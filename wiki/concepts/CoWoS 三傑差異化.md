# CoWoS 三傑差異化

「**CoWoS 三傑 = 弘塑、辛耘、萬潤**」是市場給[[TSMC]] CoWoS 供應鏈的非官方稱號。三家**位置完全不同、賺錢方式不同**——把它們籠統當「CoWoS 受惠」就會錯過 alpha。

→ 解決 codex P2 「CoWoS 三傑反覆出現但無 cluster concept」

## 三傑全景對照

| 維度 | [[弘塑]] 3131 | [[辛耘]] 3583 | [[萬潤]] 6187 |
|---|---|---|---|
| **CoWoS 站別** | **上游濕製程跨多站**（蝕刻+電鍍+CMP） | **中段濕製程單站深耕** | **WoS 後段最後一哩**（點膠+散熱+AOI） |
| **獨佔程度** | 站別覆蓋寬 | 站別深 | **後段近壟斷**（國內） |
| **商業模式** | 設備 65% + **化學品 18% 消耗品** + 代理 + 軟體 | **三條腿**：設備 + 晶圓再生 + Intel 18A 代理 | **純設備、後段同步出貨** |
| **賣水人類型** | 中性、跨站受惠 | 中性、多元支撐 | **量同步型**（CoWoS 量 ↑ 直接受惠） |
| **TGV 暴露** | 跨多站（蝕刻+電鍍+CMP）| 第 2 站（化學蝕刻） | **後段非直接**（TGV 走完仍需點膠+AOI） |
| **第二曲線** | TGV option | TGV option + 晶圓再生穩定 | **CPO 矽光子設備**（2026 3% → 2028 69%）|

## 三種 thesis（按獨立性排序）

### 弘塑：跨站賣水人（最分散）
- 不押任何單一站別
- **化學品消耗品**比重提升 = 長尾現金流
- Re-rate 三角形 **4/4 滿**（asset-wiki 第一個 4/4 entity）
- PE 同業折價 4 倍（62 vs 276）
- → 安全、但 upside 較分散

### 辛耘：多元支撐（最穩）
- CoWoS 訂單 + 晶圓再生現金流 + Intel 18A 代理
- 三條腿走路 = 下檔保護最好
- 毛利率從 41% 降到 30%（代理稀釋）= 主要警訊
- → 穩定 + TGV 是免費 call option

### 萬潤：後段同步（最 concentrated）
- WoS 後段近壟斷（點膠 + 散熱 + AOI）
- **訂單能見度 2027** + CPO 第二曲線
- 高盛目標價 365 → 800 → **1,800**（三次大幅上修）
- **PE 63-67、Q1 EPS YoY -5.6%、毛利率 60% → 52%** = 估值錯位
- → 故事最清晰但已 priced in

## 投資組合視角

### 三選一
- 風險偏好低 → **弘塑**（4/4 + 折價）
- 防禦性 → **辛耘**（三條腿）
- 押 CoWoS 量 + CPO 第二曲線 → **萬潤**（但 PE 已 priced in）

### 三家全買（核心-衛星）
- 弘塑當核心（最穩、PE 最便宜）
- 辛耘當下檔對沖（晶圓再生 + 代理）
- 萬潤當題材衛星（CPO option）
- → 完整覆蓋 CoWoS 整個製程鏈

### 對照組（不該混在三傑裡的）
- [[鈦昇]] / [[雷科]] / [[東捷]]：**TGV 押路線**（不是 CoWoS 三傑 thesis）
- [[德律]]：AI 伺服器檢測（不是 CoWoS 核心）
- 萬潤的 CPO 矽光子設備 vs [[SiTime]] 的 CPO timing 元件：**完全不同層**，不要混

## 🆕 三傑共同 bullish 訊號（2026-06 玻璃材料 + OSAT subagent 校準）

- **[[Corning]]-TSMC CoWoS 玻璃載板合作** = 玻璃基板供應鏈正式進入台灣端
- **[[日月光 ASE]] TPK 中壢 NT$5 億 TGV pilot line 2026-07 完工** = 台灣第一條 TGV 整線（三傑都是濕製程設備候選）
- **[[Amkor]] Intel 玻璃基板 packaging 端獨家**（2028-2029 量產 anchor）= 美國端 anchor 鎖定
- **2026 H2 玻璃基板供應鏈進入「執行階段」**，三傑都是濕製程 / 化學品 / 封測後段供應方

## 三傑共同的盲點（codex 提醒）

- 直接 [[Intel]] / [[AMD]] / [[AVGO]] / [[NVDA]] design-in **多為間接**（透過 TSMC 鏈、E-Core 聯盟、產業文點名）
- 若 TSMC CoWoS 減速 → 三家同時受影響
- 萬潤 CPO 是真的 unique upside，但時點 2026-2028 還未驗證
- 應該追蹤的**領先指標**：[[TSMC]] CoWoS 月產能 ramp、HBM 供應、Intel/AMD 訂單能見度
