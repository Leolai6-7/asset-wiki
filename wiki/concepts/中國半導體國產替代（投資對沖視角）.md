# 中國半導體國產替代（投資對沖視角）

> **這個 concept 不是「中國 play」、而是「**美國 AI 受惠 thesis 的對沖視角**」**。

asset-wiki 既有的 [[AI 記憶體結構性供給短缺]] / [[HBM iPhone moment]] / [[Forward PE 估值法]] thesis 全部基於「**全球 HBM / 3D NAND / AI 算力結構性短缺 → SK Hynix / Samsung / Micron / NVDA 結構性受惠到 2030**」假設。本 concept = **這個假設的鏡像 anchor**：**中國市場 ~25-30% 全球需求被國產替代接管的對沖情境**。

→ 對接 [[效率→安全切換]]（地緣脫鉤是長期主旋律）+ [[控制點轉移（投資版）]]（中國半導體控制點移到自主路徑）+ 跨庫 llm-wiki [[華為]] / [[幻方量化]] / [[DeepSeek]] / [[開源作為武器]] 鏈條。

## 一句話

> 中國半導體國產替代不是要打敗美國 AI 鏈、是要**收編中國市場那 25-30% 的全球需求**——對 SK Hynix / Samsung / Micron / NVDA 是**結構性敞口削弱**、對 [[CXMT]] / [[華為]] / YMTC / 寒武紀是**封閉市場的賣水人**。

## 三條 anchor

```
anchor 1：HBM segment 中國接管 → SK / Samsung / Micron 中國收入 -30 至 -50%
anchor 2：3D NAND segment 中國接管 → Kioxia / SanDisk / WDC 中國敞口削弱
anchor 3：AI 算力中國接管 → NVDA China revenue 20% → < 5%（已發生）
```

每條 anchor 都對應 **asset-wiki 既有受惠者 thesis 的對沖 leg**。

### anchor 1：HBM 中國市場接管（[[CXMT]] 對 SK / Samsung / Micron）

| 維度 | 西方 thesis 假設 | 對沖反證（CXMT 接管） |
|---|---|---|
| HBM 全球需求 | 結構性短缺到 2030 | **西方需求 + 中國需求**結構性分裂、中國 25-30% 被 CXMT 接管 |
| SK Hynix 中國 DRAM 敞口 | 30-35% | **2027-2030 假設 -30 至 -50%** |
| Samsung 中國 DRAM 敞口 | 25-30% | **2027-2030 假設 -20 至 -30%** |
| Micron 中國 DRAM 敞口 | 15-20% | **2027-2030 假設 -30 至 -40%**（CHIPS Act 美中分離極化）|
| 結構性短缺 thesis | 持續至 2030 | **打 7-8 折**（西方需求仍短缺、中國需求脫鉤）|
| HBM Forward PE re-rate | 6.4x → 15-25x infra 級 | **西方仍 re-rate、估值上限的「全球壟斷」溢價打折** |

**核心校準**：[[AI 記憶體結構性供給短缺]] thesis 仍然成立、但**全球壟斷**敘事需要拆成 **「西方壟斷 + 中國市場分裂」**——三巨頭最終估值上限約 80-85% 原假設。

**監控指標**：
- CXMT HBM3 量產時程（2026 H2 - 2026 年底是否兌現）
- CXMT IPO 後 A 股表現 + 估值揭露
- 華為昇騰 950PR / 950DT / 960 / 970 路線圖出貨
- Samsung / SK / Micron Q4 2026 + Q1 2027 中國 segment 揭露（segment YoY 衰退率）

### anchor 2：3D NAND 中國市場接管（[[YMTC]] 對 [[Kioxia]] / [[SanDisk]] / [[Western Digital]]）

| 維度 | 西方 thesis 假設 | 對沖反證（YMTC 接管） |
|---|---|---|
| 全球 NAND 6 家分食 | Samsung 29% / SK+Solidigm 22% / Kioxia 14% / Micron 13% / SanDisk 13% / **YMTC 13%** | YMTC 中國市場接管後可能擴至 15-18% 全球 |
| Kioxia AI Enterprise SSD 純度王 | 「結構性 re-rate +2,400%」 | 中國市場小（Bain 限），衝擊較輕 |
| SanDisk + Kioxia 美日 NAND 同盟 | HBF 標準化 + capex +40% YoY | **美日同盟對抗中國 NAND 國產替代**、市場結構性分裂 |
| Solidigm（[[SK Hynix]] 子）| QLC 51% 市佔 majority | 透過 SK Hynix 母公司部分中國 LP Server 敞口、YMTC 衝擊小 |
| HBF（NAND-as-DRAM）| 2027 量產、SanDisk + SK Hynix 標準化 | 中國若不採用 HBF 標準 → 雙標分裂 |

**核心校準**：[[AI infra 3D NAND 戰場]] 中「6 家分食」格局**結構性穩定**、但**中國 13% 市佔由 YMTC 接管後**：
- Samsung 中國 NAND 敞口最大、衝擊最深
- Kioxia / SanDisk 美日同盟反而**結構性受惠**（西方市場壟斷度提升）
- Solidigm（透過 SK Hynix）位置在「**中國 BIS Entity List 邊緣**」、不確定性最高

**[[YMTC]]（武漢長江存儲）**：
- 3D NAND 龍頭、Xtacking 製程創新（COMS-bonded array 早於 Kioxia）
- 2022-12 被列 BIS Entity List、TSMC / Samsung / SK Hynix / 美設備商斷供
- 2024-2025 緩慢恢復、跟 CXMT 雙頭中國半導體記憶體閉環
- 未上市、國家戰略性產能 anchor、跟 [[CXMT]] 形成「**中國半導體記憶體閉環雙頭**」
- 完整 entity 已 ingest（2026-06-09 codex P3）、見 [[YMTC]]

### anchor 3：AI 算力中國市場接管（[[華為]] 昇騰對 [[NVDA]]）

| 時期 | NVDA China revenue % | 華為昇騰 + 寒武紀 + 海光 中國 AI 算力市佔 |
|---|---|---|
| 2022 Q1 | ~25% | <5% |
| 2023 Q1 | ~22% | ~10% |
| 2024 Q1 | ~15% | ~20% |
| 2025 Q1 | ~12% | ~35% |
| 2026 Q1 | **< 5%** ⭐ | **~55-60%** ⭐ |

→ **已實現的對沖反證**：NVDA China revenue 從 20% → < 5%、華為昇騰已接管中國 AI 算力 55-60% 市佔（剩餘 35-40% 由寒武紀 + 海光 + 阿里 PPU + 字節 ML 分食）。

**核心校準**：anchor 3 已經發生、市場已部分 price in、但**間接傳導**：
- NVDA 估值 = 已扣除中國敞口 → 反而是「**clean exposure to 西方 hyperscaler / 主權 AI**」
- 但對 [[AVGO]] / [[AMD]] / [[Micron]] 等中國敞口仍 5-15% 的廠商，**進一步惡化是中期風險**
- 跨庫 llm-wiki [[華為]] / [[DeepSeek]] V4 / [[幻方量化]] 鏈條 = anchor 3 的軟硬閉環見證

## 對沖實務操作（投資端落地）

### 1. 給 entity 加「中國敞口 + 制裁風險」標記

每個受影響 entity 都需在 risk 段加一行：

```markdown
### ⚠️ 中國敞口風險（[[中國半導體國產替代（投資對沖視角）]] 對沖視角）
- 中國 DRAM 敞口 ~30-35%
- CXMT HBM3 2026 H2 量產 → 2027-2030 中國 HBM 收入接近 0
- 整體營收衝擊：約 -10 至 -15%
```

**已標記 entity 清單（落地後完成）**：
- [[SK Hynix]] ✅
- [[Samsung Electronics]] ✅
- [[Micron]] ✅
- [[Kioxia]]（待補、衝擊較輕）
- [[SanDisk]]（待補、衝擊較輕）
- [[NVDA]]（已 price in）

### 2. 給 thesis 標「中國市場萎縮假設」+「中國國產替代加速」雙情境分析

[[AI 記憶體結構性供給短缺]] / [[HBM iPhone moment]] / [[AI infra 3D NAND 戰場]] 應加「對沖情境」子段：

```markdown
### ⚠️ 對沖情境（[[中國半導體國產替代（投資對沖視角）]]）

Bull case（thesis 維持）：中國市場仍依賴西方供應、CXMT / YMTC 規格不夠、估值滿配
Base case（thesis 打 8 折）：中國 25-30% 全球需求被國產替代接管、西方廠商營收 -10 至 -15%
Bear case（thesis 打 5-6 折）：中國全鏈閉環 + 美中地緣裂解加深、西方廠商營收 -20 至 -30%
```

### 4. 估值校準

對 [[SK Hynix]] / [[Samsung Electronics]] / [[Micron]] 三家公平 PE：

```
原假設（全球壟斷）：Forward PE 15-25x infra 級
對沖校準（西方 + 中國分裂）：Forward PE 12-20x infra 級（打 8 折）
極端情境（中國全閉環 + 西方需求放緩）：Forward PE 8-15x（打 5-6 折，PB 派部分回歸）
```

→ **不是說 thesis 錯、是上限被裁切**。這就是「**對沖視角的真正功能：不是反向操作、是給多頭 thesis 加上限**」。
