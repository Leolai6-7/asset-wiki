# 接口控制權

[[控制點轉移（投資版）]] 在**協議/接口層**的具體實現。**搶到接口 = 搶到生態流量 + 系統性風險**。

## 一句話

> Anthropic 不是在賣模型，是在搶接口。

## 機制

```
模型層    競爭激烈，易商品化（DeepSeek $0.28/M token 壓制）
平台層    被 CSP 鎖（OpenAI 靠 Microsoft Azure）
協議/接口層 ⭐ 一旦成為事實標準，控制權極黏
```

→ 控制協議的公司**穿透所有上層**，賺生態流量。

## 歷史先例

| 案例 | 接口控制者 | 受惠機制 |
|---|---|---|
| **Chromium** | Google | 瀏覽器引擎 → 搜尋分發 |
| **Android** | Google | 手機 OS → 廣告分發 |
| **Linux** | Linux Foundation | server OS → 雲服務 |
| **MCP** | [[Anthropic]] | AI agent 工具連接 → ? |

## MCP = 2026 最強案例

→ 完整見 [[MCP（Model Context Protocol）]]

- **9,700 萬安裝**
- 所有主要 AI 公司支援
- 已捐給 Linux Foundation（AAIF）→ 治理可信、生態擴張更快
- Anthropic 從定義者變成**生態流量收穫者**

## 投資操作

### 搶到接口的公司
- **估值範式轉換**：[[Anthropic]] 從「AI 模型公司」→「[[AI 作業系統公司]]」
- 看 [[市場四階段]]：哪些公司在懷疑期就已經拿到接口？

### 失去接口的公司
- 模型層商品化暴露
- 護城河剩「分發 + CSP」
- [[OpenAI]] 是反例

### 中性受惠者
- 接口生態的 [[賣水人選股邏輯（投資版）]]：
  - **[[AI-SPM]] 賽道**（CRWD/PANW/NET）保護 MCP 安全
  - 接口工具/應用層

## 系統性風險

接口控制權**附帶系統性風險**：

> **MCP 大規模安全事件**（12 個月內若發生）：
> 徹底重新定義 AI 安全 → 所有 agent 賽道估值要重估
