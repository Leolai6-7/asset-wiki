# 抗跌清單

[[宋分（美股送分題）]] 在 Note #18 提出的機構強勢股辨識法：**強勢股的真正面目不是在上漲時顯現的，而是在市場下跌時被發現的**。

## 一句話

> 強勢股不是漲出來的，是在下跌中被發現的。

## 機構三步驟

### 第一步：觀察最糟糕的日子
- 大盤重挫時，**不是看誰跌最多，是看誰跌最少**
- 在恐慌日仍能維持相對強勢的股票，背後通常有結構性買盤支撐
- **壞消息中的表現比好消息中的表現更有資訊量**

### 第二步：建立「抗跌清單」
- 持續追蹤在**多次下跌**中都表現抗跌的股票
- 單次抗跌可能是巧合，**多次抗跌才是訊號**
- 這是市場轉折時**最先部署資金的候選名單**

### 第三步：觀察誰在反彈時率先動作
- 市場止跌後，**最先反彈的往往就是抗跌清單上的標的**
- 反彈通常伴隨成交量放大 → 機構在積極買入

## 「無視壞消息」= 強勢股特徵

- 真正的強勢股對壞消息產生「**免疫**」反應
- 整個板塊因利空下跌，強勢股可能微幅回調甚至不跌
- **賣方出盡 + 買方控盤** = 機構已完成持倉建立

## 被動賣壓 vs 主動買盤

→ 完整見 [[被動賣壓 vs 主動買盤]]

- 被動賣壓無差別賣出
- 主動買盤在被動賣壓製造的價格扭曲中**選擇性承接**
- 抗跌股 = 主動買盤對沖了被動賣壓

## 散戶的觀察時機錯誤

| 錯誤 | 為什麼錯 |
|---|---|
| **在上漲時觀察** | 看到漲了才關注，但價格已反映機構判斷 |
| **在下跌時恐慌** | 忙著擔心自己的持股，而非觀察強勢 |
| **錯過最佳觀察窗口** | 下跌是最佳觀察時機，散戶在這時最不想看盤 |

## 正確的順序

```
下跌中觀察 → 反彈初期確認 → 共識形成前布局
```

## 與「相對低點」訊號的連結（Note #14）

[[相對低點識別]]（未獨立 ingest）的三訊號之一就是「強勢股撐住」：

- 在大盤下跌中部分股票持續相對強勢
- 抗跌股**數量開始增加** = 買盤力量擴散
- 抗跌清單建立和追蹤 = 機構的具體操作

## 跟 [[修正三階段]] 的關係

- 修正 Phase 3（最強股票被無差別拋售）= 抗跌清單失效
- 修正末期 → 抗跌股逆勢撐住，意味底部可能不遠
