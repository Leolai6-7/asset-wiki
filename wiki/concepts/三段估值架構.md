# 三段估值架構

[[投資四元問題框架（ABCD）]] **C 軸點名的缺件**、本檔正式落地。原始 framework 來自 [[宋分（美股送分題）]] TXN +19% note（敘事建立／基本面追上／成長減速＝壓縮三段）、補上本庫活案例與 B／C／D 軸接線。

## 核心公式

> **股價 = EPS × PE。三段＝報酬來源在 ΔPE 與 ΔEPS 之間輪動。**

| 階段 | 報酬主引擎 | 一句話 |
|---|---|---|
| 一、敘事建立 | **ΔPE > 0 主導** | 買的是 narrative、不是數字 |
| 二、基本面追上 | **ΔEPS 主導**、PE 持平或邊漲邊消化 | 最舒服的持有段 |
| 三、估值壓縮 | **ΔPE < 0、壓縮速度 > EPS 成長** | 賺 EPS、賠 PE |

## 階段一：敘事建立（PE 擴張驅動）

| 維度 | 內容 |
|---|---|
| 特徵 | 財報驚喜首現、分析師上調啟動、PE 快速擴張遠離歷史均值與同業 median；漲幅大部分由倍數貢獻 |
| 可觀測訊號 | Forward PE vs 同業 median gap 急速擴大；EPS 仍低甚至虧損；[[Re-rate 捕捉法]] 三角形 2-3/4（thesis 階段、option 性質） |
| 對應操作 | 小部位試水（D 軸進場階段 1）、**預設證偽條件**；主風險＝**敘事證偽**、any miss = -50% 級回檔 |
| 活案例 | [[AAOI]] 12M **+896%**、Forward PE **226**（虧損中、純 thesis 定價、估值無 anchor）；[[Lumentum]] 12M **+1,542%**、Forward PE **52-59**（vs hardware median ~25、已 price in 多年完美 ramp） |

## 階段二：基本面追上（EPS 兌現）

| 維度 | 內容 |
|---|---|
| 特徵 | 強財報持續、EPS 連續上修；股價盤整等獲利追上、或邊漲邊消化（倍數不再創高） |
| 可觀測訊號 | 連續上修三指標（RPO／合約負債暴增＋定價權增強＋公司不給上限、宋分 #30）；**[[Re-rate 捕捉法]] 三角形 4/4 ＝階段二的確認工具** |
| 對應操作 | trigger 兌現後加碼至目標部位（D 軸進場階段 2-3）；最舒服持有段、拿住不折騰 |
| 活案例 | [[欣興]] 轉骨結構：TTM PE **142** →（2026E EPS 17）~54x →（2027E EPS 24）**~38x**、EPS 4.38→17→24 把倍數消化掉；[[國巨]] PE **30→60** 補漲＋EPS 17 兌現（三角形 4/4、漲價＋mix 雙引擎） |

## 階段三：估值壓縮（共識飽和）

| 維度 | 內容 |
|---|---|
| 特徵 | EPS 仍成長但增速放緩、estimate 上修停止、共識飽和；**PE 壓縮速度 > EPS 成長** → 股價不動甚至下跌 |
| 可觀測訊號 | 好消息＋不漲（[[預期差]] ≈ 0）；PE 從高位向歷史均值回歸；利率／折現率上行放大壓縮（PE ≈ 1/(r−g)、[[PE 壓縮公式]]） |
| 對應操作 | 啟動 [[進場三階段與出場三階段（宋分）]] 出場段：減 10-20% → 再減 20-40% → 趨勢反轉果斷砍 |
| 活案例 | TXN 2025：類比成長減速、處於壓縮段（PE 向歷史平均 ~25x 回歸）；通用案例：降息預期 3 次→0 次、PE 25→20、EPS 上升股價照樣不動（宋分 Note #18） |

## 階段移位不是單行道（TXN 活案例）

TXN 2026-04 財報 +19%：資料中心營收 **YoY +60% / QoQ +90%**、AI 變成可見成長來源 → 從階段三**直接重啟回階段一**（2026 PE 36x、2027 PE 32x vs 歷史平均 ~25x）。

三條實戰推論：
1. **新高 PE ≠ re-rate 結束**——看到 PE 創高就退場、可能錯過整段 re-rate
2. **敘事與基本面的時間差＝alpha 主來源**——等 earnings 完整驗證才進、已經晚了
3. 最佳獵場＝「敘事剛建立、基本面還沒完全追上」的窗口（階段一末 → 階段二初）

## 邊界規則（只回答 C 軸）

本框架**只回答 C（估值還沒 price in）**：判斷「現在的漲跌由 PE 還是 EPS 驅動、下一段誰接棒」。不判斷結構真假（A 軸、用 [[Bottleneck Theory（瓶頸論）]]／[[賣水人選股邏輯（投資版）]]）、不判斷市場認知位置（B 軸）、不管進出節奏（D 軸）。A 錯了、三段估值只是幫你精確計時一場必輸的局。

## 監控指標

| 指標 | 觸發行動 |
|---|---|
| 漲幅拆解：ΔPE 貢獻 vs ΔEPS 貢獻（每季） | ΔPE 貢獻 > 70% 持續兩季＝仍在階段一、禁加碼至目標部位 |
| EPS estimate 上修動能（revision breadth） | 連續上修停止＋PE 仍在高位＝階段二→三移位警戒 |
| 好消息＋不漲 | 出現即觸發出場階段 1（減 10-20%） |
| Forward PE vs 歷史均值／同業 median gap | gap 收斂中＋EPS 增速放緩＝階段三確認 |
