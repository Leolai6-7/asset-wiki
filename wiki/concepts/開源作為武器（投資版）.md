# 開源作為武器（投資版）

llm-wiki 已有 [[開源作為武器]] 概念——asset-wiki 這版本是**投資角度**重切：**開源不是慈善，是壓縮對手定價的競爭武器**。

## 一句話

> 不靠 X 賺錢的公司把 X 免費送出去，壓縮靠 X 賺錢的公司。

## 公式

```
開源可持續性 = 主營收是否獨立於開源產品
```

| 主營收 ⊥ 開源產品 | 結果 |
|---|---|
| ✅ 獨立 | 可長期開源（壓對手） |
| ❌ 不獨立 | 開源燒到一定程度必須切閉源 |

## 2026 的四個案例

| 案例 | 主營收 | 開源 | 持續性 |
|---|---|---|---|
| **[[幻方量化]] / DeepSeek** | 量化交易 | 開源模型 + 極低定價 | ✅ 可持續（[[算力本業派 AI 公司]]） |
| **[[Netflix]] VOID** | 訂閱（內容） | 開源影片 AI 工具 | ✅ 可持續（降低自己 SaaS 成本 = 內容平台變工具廠） |
| **[[Google]] Gemma** | 廣告 | 開源小模型 | ✅ 可持續（廣告獨立於模型） |
| **[[Meta]] LLaMA → Muse 閉源** | 廣告 | 開源 LLaMA / 閉源 Muse Spark | ❌ Muse Spark 直接創造變現 → 切閉源 |

## Meta 是最重要的對照

Meta 的 LLaMA 服務「廣告生態」（不直接賣模型）→ 可開源；
**Muse Spark 直接變現 → 必須閉源**。

→ 同一家公司，**開源 vs 閉源由「主營收結構」決定，不是價值觀**。

## 投資角度

### 開源攻擊者
- 競爭壓力 ↓（不需擔心市佔分配）
- 但**直接從中無法賺錢**（除非可繞道：服務、企業版、infra）
- 估值押注：**生態 + 衍生 SaaS** vs 純模型

### 開源受害者
- [[OpenAI]] / [[Anthropic]] 純模型層公司
- DeepSeek 一條免費破壞他們所有 SaaS 訂閱
- 反制：[[Anthropic]] 用 [[接口控制權]]（MCP）+ [[對齊稅（alignment tax）]]（安全溢價）守毛利

### 賣水人邏輯
- **不管開源/閉源誰贏，算力供應鏈都受惠**
- [[NVDA]] / [[AVGO]] / [[TSMC]] 是 [[賣水人選股邏輯（投資版）]] 的中性受惠者
