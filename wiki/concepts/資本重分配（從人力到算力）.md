# 資本重分配（從人力到算力）

「**成長中裁員**」的真實機制——**不是衰退，是預算搬遷**。改寫「裁員 = 利空」的反射動作。

## 一句話

> 成長中裁員不是「公司不好」，是「公司在把錢從人力預算搬到算力預算」。

## 三種裁員（必須區分）

→ 連 [[AI Washing（裁員包裝）]]

| 類型 | 真實機制 | 投資啟示 |
|---|---|---|
| **衰退裁員** | 業務萎縮 → 削成本 | 利空 |
| **CapEx 重分配** | AI 預算搬遷 → 人力轉算力 | **看似利空、實為加碼** |
| **真被 AI 取代** | 工作流程自動化 | 個別崗位利空、毛利提升 |

但**對外都講「AI 驅動重組」**——需要區分真假。

## 為什麼是「成長中」

- 公司營收還在 ↑
- 但人力預算 ↓
- 因為**算力預算 ↑↑↑**（規模更大）
- → 是預算結構改變，不是縮編

## 對 EBIT 結構的長期影響

```
傳統公司：
營收 ─► 人力（變動成本）─► 利潤

AI 化公司：
營收 ─► 算力（固定資本支出 + 折舊）─► 利潤
```

→ 連 [[五層損益表（營業槓桿）]]：
- **OpEx ↓**（裁員直接降費用）
- **CapEx ↑↑**（算力大投資）
- **毛利結構性改善**（如果 AI 真的 work）
- → 高 **[[五層損益表（營業槓桿）|營業槓桿]]**

## 對勞動市場的衝擊

| 層級 | 衝擊 |
|---|---|
| 入門 / 重複性工作 | 立即受影響 |
| 中階管理 | 6-12 個月後 |
| 高階 / 創意 | 長期持續調整 |
| **AI infra / AI eng** | 反向上漲 |

## 投資操作

### 看到大公司「AI 驅動裁員」
不要立即賣，先問：
1. 是哪一種裁員？
2. CapEx 是否同步 ↑↑？
3. 毛利結構是否在改善？
4. → 若是 CapEx 重分配 → **是加碼訊號**

### 受惠者
- **算力供應鏈**（NVDA、AVGO、TSMC）
- **電力供應鏈**（Vistra、Constellation、GE Vernova）
- **AI infra 公司**（Datadog、Snowflake）

### 受害者
- **HR / 招聘公司**（ZipRecruiter、Workday 招聘模組）
- **諮詢業中階**（Accenture、IBM 中階消失）
