# 政府風險溢價（AI 公司）

[[Anthropic]] 2026-04-06 被美國列為**國安供應鏈風險**事件揭示的新估值變數：**政府風險進入 AI 公司折現率**，類似新興市場的主權風險溢價。

## 一句話

> 從現在起，AI 公司的折現率 r 必須加上「政府風險溢價」這個新分量。

## 機制（套 [[PE 壓縮公式]]）

```
PE ≈ 1 / (r - g)
r = 無風險利率 + 信用利差 + 政府風險溢價  ← 新增
```

當政府風險溢價 ↑ → r ↑ → PE 壓縮。

## Anthropic 案例

- 拒絕讓五角大廈無限制使用 Claude
- → 被美國列國安威脅
- → 政府採購可能被禁
- → AI 安全敘事的「對齊稅」變現實

→ 完整見 [[對齊稅（alignment tax）]]

## 三種政府風險

| 類型 | 機制 |
|---|---|
| **直接禁令** | 政府公開列為威脅、禁採購 |
| **連坐封殺** | 政府客戶被告知「不能用 X」 |
| **採購監管化** | AI 採購須過審查（增加 procurement 摩擦） |

## 影響哪些公司

| 公司 | 風險敞口 |
|---|---|
| [[Anthropic]] | 高（已被列） |
| [[OpenAI]] | 中（對齊較鬆，較配合政府） |
| [[Google]] / [[Microsoft]] / [[Meta]] | 中（大公司分散） |
| [[DeepSeek]] | 在中國視角是「保護」、在美國視角是「禁止採購」 |
| 中性受惠 | [[NVDA]]、[[AVGO]]、[[TSMC]] 等供應鏈（誰贏都受惠） |

## 三種應對

### 1. 公司層：分散政府採購敞口
- 政府客戶佔比過高 → 政治風險高
- 多元客戶結構 → 政府風險溢價較低

### 2. 投資層：分散到供應鏈
- 政府風險主要打 model layer
- 算力供應鏈（[[賣水人選股邏輯（投資版）]]）相對保護

### 3. 對沖層：Sovereign AI
→ [[Sovereign AI]]

各國推自主 AI → 不依賴美國模型 → 區域市場碎片化但**剛需穩定**

## 連到 [[效率→安全切換]]

宋分備忘錄 #6 的「效率→安全」在 AI 公司估值的具體實現：
- 過去：誰技術強就買誰
- 現在：誰**地緣安全 + 對齊到位**才能採購
- 成本提升、政府風險溢價成為**永久結構性變數**
