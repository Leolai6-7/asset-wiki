# TGV 路線分歧（雷射改質 vs 雷射打孔）

[[TGV 製程鏈圖譜]] 第 1 站內的**最大押注分歧**——TGV 賽道內部，誰會贏？

## 一句話

> 鈦昇押「雷射改質 + 化學蝕刻」（LPKF LIDE 路線的台廠版）；雷科押「雷射直接打孔 + 後段填孔」（挑戰日系獨佔）。

## 兩條路線對照

| 維度 | 雷射改質 + 蝕刻（LPKF LIDE 路線） | 雷射直接打孔 |
|---|---|---|
| **代表台廠** | [[鈦昇]]（8027） | [[雷科]]（6207） |
| **國際對標** | LPKF（德國 LIDE 專利擁有者） | 日系（三菱等） |
| **核心步驟** | 雷射改質玻璃分子結構 → 化學蝕刻融掉 | 雷射直接打孔 → 後段濕製程填孔 |
| **規格** | 鈦昇：每秒 8,000 孔，精度 5μm | 雷科：飛秒鑽孔、CoWoS 已用 |
| **熱影響區** | 較小（雷射只標記） | 較大（直接打孔） |
| **量產良率** | 較穩定（兩步驟可分別優化） | 依雷射波長精度 |
| **單機價格** | — | 雷科 $4,000-5,000 萬 NTD |
| **客戶 anchor** | Intel Clearwater Forest 2026 H2 | AMD/NVIDIA 認證 2026 Q1 定案、Q4 放量 |

## 投資啟示

### 押路線 vs 賣水人
這是一個**押路線**的 concept——跟 [[賣水人選股邏輯（投資版）]] 是相反路線。
- 押對：高 upside（單機 single source 變定義水的人）
- 押錯：直接清零（產業切到另一條路線就完全失去 TAM）

### 兩家共同點
- 都是 **TGV 純度高**的台股
- 都已有 design-in 證據（[[鈦昇]] Intel、[[雷科]] AMD/NVIDIA）
- 2027-2028 才是真正量產期

### 兩家差別
| | [[鈦昇]] | [[雷科]] |
|---|---|---|
| TAM 暴露 | **TGV 純粹題材** | TGV + CoWoS + SiC + 厚板切割（**多元**） |
| 現金流 | **目前虧損**（卡位燒錢） | CoWoS 已是現金來源 |
| Anchor 客戶 | Intel（單一） | AMD + NVIDIA（雙端） |
| 押注性質 | All-in TGV | TGV 是其中一條 |
| 失敗後果 | 高 | 中（其他線可撐） |

## 兩條路線可能同時存活的情境

不一定是「贏家通吃」：
- 不同產品/節點可能用不同工法
- Intel 走改質、TSMC CoPoS 走打孔的可能性
- 對沖：**兩家都拿一些**就是 hedge 路線分歧

## 第三條路（東捷）

[[東捷]] 走 **雷射改質 + 整線聯盟**（志聖+富臨）——
- 規格類似鈦昇（每秒 10,000 孔、±5μm）
- 但賣的是「整線方案」而非單站設備
- 客戶仍是台廠封測（日月光/力成/群創），**未進入北美 IDM**
- 是「鈦昇路線」的 alternative，但 thesis 較弱

## TGV vs Hybrid Bonding（更大的路線分歧）

不只 TGV 內部的路線分歧，TGV 整個賽道還面臨：

- **Hybrid Bonding（銅柱直接接）** 可能完全跳過 TGV，做 chip-to-chip 直接連
- 目前 sennn.nnna 文：「他有很多物理限制⋯⋯**高機率在這次最先進的戰場上，我們暫時還不會看到他**」
- **暫時不會** ≠ 永遠不會 → 仍是長期風險
